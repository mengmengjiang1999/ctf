# 已核验的外部来源

访问日期：2026-09-04。

本仓库的历史提交没有保存大多数平台题面。以下链接只用于核验赛事归属、题名或核心思路；逐题 README 中由附件复原的描述仍然不是官方原文。

## BUUOJ / WUSTCTF 2020

- [WUSTCTF 2020 官方 Writeup](https://wust-ais.github.io/2020/03/30/wctf2020_official_wp/)：可核验 Cr0ssFun、level3 等题目的名称与官方解法概述。
- [usualCrypt 解题记录](https://ngiokweng.github.io/2022/02/23/ACTF%E6%96%B0%E7%94%9F%E8%B5%9B2020-usualCrypt-WriteUp/)：可核验 BUUOJ 题目锚点、变表 Base64 与大小写交换思路。该链接是第三方 writeup，不是官方题面。

## SECCON CTF 2023

- [SECCON CTF 2023 Quals 官方结果](https://www.seccon.jp/2023/seccon_ctf/result_of_seccon_ctf_2023_quals.html)：用于区分 2023 Quals 与 Finals。
- [CTFtime 任务索引](https://ctftime.org/tasks/?page=174)：列出 2023 Domestic Finals 的 `muck-a-mac`、`v_v_m_m_v_m_m`、`Paillier 4.0`、`KEX 4.0` 等题名。它是赛事索引，不是官方题目包。

## 使用原则

1. 找到官方题目仓库后，优先替换第三方来源。
2. 只总结外部 writeup，不复制全文或图片。
3. 下载到仓库的官方附件应记录原链接、访问日期和 SHA-256。
4. 来源互相冲突时保留“待核实”状态，并在 issue/提交说明中记录分歧。
