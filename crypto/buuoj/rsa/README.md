## Writeup

### 思路

先按同名前缀配对题目与脚本；`BabyRsa.py`、`bbbbrsa.py`、`drsa.py`、`rsa*.py`、`rsaroll.py` 分别是独立解题记录。后续应逐题拆目录。

```bash
cd "crypto/buuoj/rsa"
file BabyRsa bbbbrsa flag.enc pub.key
```
