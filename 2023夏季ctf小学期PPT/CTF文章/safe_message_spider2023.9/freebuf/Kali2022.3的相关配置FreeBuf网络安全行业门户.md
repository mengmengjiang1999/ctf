# 序言

在我们学习网络网络安全过程中，Kali是一款不可或缺的工具，里面集成了各种各样的工具，方便大家去使用。然而，很多小伙伴安装好了Kali之后却不知道如何进行相关配置，例如怎么样进行静态IP的设置和开启SSH服务，从而让远程连接工具去连接，方便我们去管理Kali，下面就让我来给大家讲一下吧。

# 一、设置静态IP

### 打开Kali的网络配置文件

`vim /etc/network/interfaces﻿`

### 在文件内添加如下内容

    
    
    auto eth0
    iface eth0 inet static     //配置静态网卡
    address 192.168.40.188     //配置静态IP地址
    netmask 255.255.255.0      //配置子网掩码
    gateway 192.168.40.2       //配置网关
    

>
> 注：可以把其他的虚拟机的静态ip改成同一个网段（网络号），例如192.168.40.x,方便Xshell等远程连接工具连接，如果Kali中网络配置文件配置好之后输入`ip
> addr`之后任然没有ipv4地址，则手动编辑网络连接设置中的ipv4地址设置

### 重启网络服务

`service networking restart`

# 二、开启SSH端口

### 启动SSH的配置文件

`vim /etc/ssh/sshd_conf`

> 注：在Kali老一点的版本中，SSH服务的配置文件是/etc/ssh/ **ssh_conf** ，不是 **sshd_conf**
> ，我这里的版本是Kali2022.3

### 修改相关配置文件

`PermitRootLogin prohibit-password`

修改后：

`PermitRootLogin yes`

### 启动SSH服务

`service ssh start`

### 设置为开机自动启动SSH服务

`update-rc.d ssh enable`  
或者使用  
`systemctl enable --now ssh`

> 注：update-rc不要写成update -rc，中间没有空格

# 三、软件更新升级

### 配置源

  * 打开配置源的文件  
`vim /etc/apt/sources.list`

  * 添加源

#### aliyun 阿里云

    
    
    deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib
    
    deb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib
    

#### ustc 中科大

    
    
    deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib
    
    deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib
    

# 四、更新软件

  * 使用Advanced Packaging Tool(APT)方式进行更新

    
    
    apt update      #刷新存储库索引
    apt upgrade     #升级所有可升级的软件包
    

# 五、软件安装

### deb包安装

  * 安装：`dpkg –i deb sogoupinyin.deb`

  * 卸载：`dpkg –e sogoupinyin.d`

### apt方式安装

  * 搜索：`apt search xxx`

  * 安装：`apt-install xx`

### 源码方式安装

  1. 配置 ./configure

  2. 编译 make

  3. 安装 make install

### 实例——安装谷歌拼音

    
    
    apt install fcitx   # 必须先安装依赖
    apt search fcitx-googlepinyin`
    apt-get install fcitx-googlepinyin`
    
    reboot
    

  * Ctrl+Space启动输入法

# 六、启动自带服务

### 启动MySQL

    
    
    service mysql start     # 开启
    service mysql stop      # 结束
    service mysql restart   # 重启
    service mysql status    # 状态
    

配置文件：

  * `/etc/mysql/my.cnf`

### 启动Apache

  * `service apache2 start`

  * 默认根路径：/var/www/

  * 默认配置文件：/etc/apache2/apache2.conf

### 启动Nginx 配置文件

  * /etc/nginx/nginx.conf

  * 默认端口配置

    
    
    /etc/nginx/sites-available/default
    /etc/init.d/nginx sta
