# **漏洞描述**

DedeCMS-V5.7.91-UTF8后台mail_file_manage.php存在任意文件删除漏洞

#  **影响版本**

DedeCMS-V5.7.91-UTF8

#  **漏洞分析**

mail_file_manage.php文件

![1682434510_6447e9ce0c6c087340b4f.png!small](https://image.3001.net/images/20230425/1682434510_6447e9ce0c6c087340b4f.png!small)

该代码存在任意文件删除漏洞的原因在于，程序在删除文件时直接使用了变量 $filename，而该变量的值来自用户输入，即 $activepath 和
$filename 可以通过 GET 或 POST 参数传递，攻击者可以构造恶意请求，修改 $filename
的值为绝对路径下的任意文件，导致删除了不应该被删除的文件，甚至是系统重要文件。

代码中存在任意文件删除漏洞的原因是变量 $filename 的值未经过任何过滤或验证，而是直接被拼接在 $cfg_basedir.$activepath
后面，形成了完整的文件路径，最终被用于执行 unlink() 函数删除文件。攻击者可以通过构造恶意请求，将任意文件路径拼接到 $filename
中，从而删除任意文件。

#  **修复建议**

为了避免任意文件删除漏洞，应该对 $filename
的值进行过滤和验证，以确保它只包含合法的文件名或相对路径，不包含任意的绝对路径或目录遍历符号。常见的防御措施包括：

限制文件名的字符集，只允许包含数字、字母、下划线、点号等安全字符。

拒绝包含特殊字符或目录遍历符号的文件名，例如 ../、..、./ 等。

检查文件路径是否位于允许访问的目录之下，以防止攻击者越权访问系统文件或其他敏感文件。

对删除操作进行权限验证，只允许具有足够权限的用户或管理员执行删除操作。
