IP定位软件中的工具多种多样，我们应该怎样选择合适的工具来进行IP定位过程中的应用？IP Tools 中包含了五种功能不同的工具分别是：Ping
工具、Traceroute 工具、HTTPHead 工具、CDN 工具与 DNS 工具，下面就简单介绍下这些工具：

● Ping 工具：可以从遍布全球的探测点对给定的 IP 地址或域名发起 Ping 请求，以检测被探测主机的连通状况，同时可以根据 Ping
时延大小初步判断被探测主机所在国家或城市。

● Traceroute 工具：可以从遍布全球的探测机对给定的 IP地址或域名发起 Traceroute
请求，显示从世界不同国家或地区到目标主机的网络路径信息。是用来侦测主机到目的主机之间所经路由情况的重要工具，也是最便利的工具。前面说到，尽管
Ping工具也可以进行侦测，但是，因为 IP头的限制，Ping不能完全的记录下所经过的路由器。所以 Traceroute 正好就填补了这个缺憾。

● HTTPHead 工具：可以从遍布全球的探测机对目标网址发起 HTTP Head请求并获取 HTTPHeader
字段信息，可以用来检测目标网址在世界不同地方的连通情况。

● CDN 工具：可以从遍布全球的探测机对给定的域名进行 dns 信息查询，获得域名对应的 A（Address） 记录和 CNAME信息。

● DNS 工具：可以向全球大量的公共 DNS 服务器查询您给定的域名的 A 记录，可以获知某个域名在全球的 A 记录解析情况。

A（Address）记录：A (Address)
记录是用来指定主机名（或域名）对应的IP地址记录。用户可以将该域名下的网站服务器指向到自己的网页服务器(web
server)上。同时也可以设置域名的子域名。

CNAME：CNAME 被称为规范名字。这种记录允许您将多个名字映射到同一台计算机。 通常用于同时提供 WWW 和 MAIL
服务的计算机。例如，有一台计算机名为“r0WSPFSx58.”（A记录）。 它同时提供
WWW和MAIL服务，为了便于用户访问服务。可以为该计算机设置两个别名（CNAME）：WWW 和 MAIL。

根据上面的简介，可以快速了解各个工具的功能。在实际运用中，可以根据需求的不同选取适合的工具进行使用。
