擎天神是全球网络拓扑测绘系统，系统界面如下图所示。该系统通过不同级别不同颗粒度的网络拓扑可视化功能，展示全球互联网的拓扑关系，包含全球、国家间、国家内、AS
域间、AS 域内的三维地理拓扑和二维逻辑拓扑。其中，以AS 为最小颗粒度，可以查看国家与国家之间的网络出口和入口；以 IP
为最小颗粒度，可以查看国家与国家、国家与 AS、AS 与 AS 之间的路由器出口和入口。

![image.png](https://image.3001.net/images/20200416/1587024780_5e98138c5b072.png!small)

它的主要功能有：全球网络拓扑测绘，包含全球级别、国家级别（国家间与国家内）和 AS 级别（AS 域间和 AS 域内）、POP
级别、路由器级别（核心路由器、中路由器、边缘路由器）和 IP 级别。支持全球 54,772个AS域，近43亿全量
IP。网络拓扑分为地理拓扑和逻辑拓扑。国家级别拓扑提供 AS 号、AS 包含的 IP 量、AS 直连的国家或地区数量、直连的 AS 数量和节点度数。AS
级别拓扑提供 AS 名称、AS 类型、传输度数、AS 包含的 IP 量、连通的 AS 数量、连通的 IP 数量和 AS
连接的类型（包含对等互连、服务商与客户相连和同机构 AS 相连）。国家间相连的 AS 明细，AS 间相连的路由器明细。指定地区下 AS
域内拓扑，提供路由器连接关系、路由器接口 IP 和路由器详细信息（如路由器位置、在网络中承担的角色和网络带宽等）。
