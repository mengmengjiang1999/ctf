**Tool-X是一个由python编写的用于安装kali linux黑客工具的安装程序。在Tool-X的帮助下，你可以任意在Root或非Root的Android设备中安装黑客工具。Tool-X中为我们提供了近251款黑客工具，这些工具可供termux
app和GNURoot Debian终端使用，你可以通过单击来安装任何你需要的工具。Tool-X专为Termux和GNURoot
Debian终端而设计。现已支持Ubuntu。**

**![Tool-X：在AndroidUbuntu平台安装Kali的各种攻击工具](https://image.3001.net/images/20190119/1547856603_5c426adbbb3c3.jpg!small)**

## 如何使用？

> 输入 0：表示安装所有工具
>
> 输入 1：显示所有可用工具，并通过编号选择想要安装的工具
>
> 输入 2：显示工具类别
>
> 输入 3：用于在termux中安装操作系统
>
> 输入 4：更新Tool-X
>
> 输入 5：关于我们
>
> 输入 x：退出

 **当前支持系统：**

> Android
>
> Ubuntu

## 如何在termux中安装？

打开termux app并键入以下命令。

    
    
    apt update
    
    pkg install git
    
    git clone https://github.com/Rajkumrdusad/Tool-X.git
    
    cd Tool-X
    
    chmod +x install.aex
    
    sh install.aex 如果无法正常执行请键入 ./install.aex

现在，Tool-X已成功安装。键入Tool-X运行Tool-X。

现在你可以在终端的任何位置，通过键入Tool-X来打开Tool-X。

## 如何在GNURoot Debian终端中安装？

打开GNURoot Debian app并输入以下命令。

    
    
    cd && git clone https://github.com/Rajkumrdusad/Tool-X.git
    
    cd Tool-X
    
    chmod +x install.aex
    
    sh install.aex 如果无法正常执行请键入 ./install.aex

现在，Tool-X已成功安装。键入Tool-X运行Tool-X。

现在你可以在终端的任何位置，通过键入Tool-X来打开Tool-X。

## 如何在Ubuntu中安装？

    
    
    sudo apt-get Update
    
    sudo apt-get install git
    
    sudo git clone https://github.com/Rajkumrdusad/Tool-X.git
    
    cd Tool-X
    
    chmod +x install.aex
    
    sudo sh install.aex 或 ./install.aex

现在，Tool-X已成功安装。键入Tool-X运行Tool-X。

现在你可以在终端的任何位置，通过键入Tool-X来打开Tool-X。最后提醒大家一句，请勿将该工具用于任何非法目的！
