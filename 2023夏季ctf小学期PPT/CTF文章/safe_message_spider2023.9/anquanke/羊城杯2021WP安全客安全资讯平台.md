由$X\equiv ((Z1+inv _{Z1})*inv_2)\ (mod\ n)以及a\equiv ((inv_ {Z1}-X)*inv _Y)\
(mod\ n)$得：  
  
2X\equiv Z1+inv_{Z1}\ (mod\ n)\ \ \ \ \ \ (1)

X+aY\equiv inv_{Z1}\ (mod\ n)\ \ \ \ \ \ (2)

两式相减得：  
  
X-aY\equiv Z1\ (mod\ n)\ \ \ \ \ \ (3)  
  
(2)*(3)得：  
  
X^2-a^2Y^2\equiv 1\ (mod\ n)  
  
即:  
  
X^2-DY^2\equiv 1\ (mod\ n)
