pcap数据包内关键结构体

struct pcap_pkthdr {
        struct timeval ts;      /* time stamp */
        bpf_u_int32 caplen;     /* length of portion present */
        bpf_u_int32 len;        /* length this packet (off wire) */
};
 ts：    抓取时间
 caplen：4字节 保存下来的包长度
 len：   4字节 数据包的真实长度
