源码、编译

测试程序源码如下：

vuln只是命名习惯了...并不是指漏洞函数

#include<stdio.h>
#include<stdlib.h>
#include<string.h>

int func(int a) {
    int num = a; 
    printf("%d",a);
    getchar();
    getchar();
    return 1;
}

int func_wrapper(int b) {
    func(b+1); 
    int num = b;
    printf("%d",num);
    getchar();
    getchar();
    getchar();
    return 2;
}


int vuln(int num){
    printf("%d",num);
    return 0xff;
}

int main(int argc, char** argv) {
    func_wrapper(1);
    vuln(2);
    return 0;
}


程序没有什么特别的，注意getchar()因为没有参数，就是用来nop掉然后开始表演的，也不会影响堆栈平衡

编译：gcc -m32 main.c -o test
