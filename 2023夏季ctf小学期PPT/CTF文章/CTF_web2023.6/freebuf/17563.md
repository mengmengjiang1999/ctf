Linux 基础学习

Linux 是一套免费使用和自由传播的类 Unix 操作系统，Linux 能运行主要的 UNIX 工具软件、应用程序和网络协议。是一个性能稳定的多用户网络操作系统。今天各种场合都有使用各种 Linux 发行版，从嵌入式设备到超级计算机，并且在服务器领域确定了地位，通常服务器使用 LAMP（Linux + Apache + MySQL + PHP）或 LNMP（Linux + Nginx+ MySQL + PHP）组合。

Linux 基础命令

增删改查

Linux系统的使用是通过命令进行操作，所以我们需要学习一些基础命令，比如最基本的 “增删改查” 命令

创建目录：mkdir

删除目录或文件夹：rm

删除非空目录：rm -if file 目录

删除日志 rm *log(等价：$find ./ -name "*log" -exec rm {} ；)

移动（剪切）：mv 原文件 目标文件

查看当前目录下的内容：ls

-a 列出所有文件，包括隐藏文件

-l 以列表形式显示

-1 以分行显示

-t 按时间排序

-r 排倒叙

-R 包含目录的子目录及文件

基础命令

复制文件：cp 原文件 目标文件

复制目录：cp -r 原目录 目标目录

找到文件/目录位置：cd

切换到上一个工作目录：cd -

切换到home目录：cd or cd ~

切换到/root目录：cd /root

显示当前路径：pwd

更改当前工作路径为path：$cd path

Linux 目录结构

Linux系统下的一切都是通过文件夹及文件来显示的，根目录（/）下有着许多的文件夹比如：

/boot：存放的启动Linux时使用的内核文件，包括连接文件以及镜像文件。

/etc：存放所有的系统需要的配置文件和子目录列表，更改目录下的文件可能会导致系统不能启动。

/lib：存放基本代码库（比如c++库），其类似于Windows里的DLL文件，几乎所有的应用程序都需要用到这些共享库。

/sys：这是Linux2.6内核的一个很大的变化。该目录下安装了2.6内核中新出现的一个文件系统sysfs。sysfs文件系统集成了下面3种文件系统的信息：针对进程信息的proc文件系统、针对设备的devfs文件系统以及针对伪终端的象被创建的时候，对应的文件和目录也在内核对象子系统中象被创建的时候，对应的文件和目录也在内核对象子系统中。

/run：是一个临时文件系统，存储系统启动以来的信息。当系统重启时这个目录下的文件应该被删掉或清除。如果你的系统上有/var/run目录应该让它指向run。

/lost+found：般情况下为空的，系统非法关机后，这里就存放一些文件。

/tmp：这个目录是用来存放-些临时文件的。

/root：系统管理员的用户主目录。

/home：用户的主目录，以用户的帐号命名的。

/usr：用户的很多应用程序和文件都放在这个目录下，类似于windows下的program files目录。

/usr/src：内核源代码默认的放置目录。

/var：存放经常修改的数据，比如程序运行的日志文件(/var/log 目录下）。

/proc：管理内存空间！虚拟的目录，是系统内存的映射，我们可以直接访问这个目录来，获取系统信息。这个目录的内容不在硬盘上而是在内存访问这个目录来，获取系统信息。这个目录的内容不在硬盘上而是在内存里，我们也可以直接修改里面的某些文件来做修改。

proc目录的内容不在硬盘上而是在内存里，我们也可以直接修改里面的某些文件，比如可以通过下面的命令来屏蔽主机的ping命令，使别人无法你的机器：

echo 1 > /proc/sys/net/ipv4/icmp echo_ ignore. _all

（ 1 不允许 0 允许）

练习：

首先我们打开终端，输入：cd / 这时我们到达了根目录下

先使用 ls 命令查询当前位置下的内容

使用mkdir命令，创建一个名字为123的文件夹

界面不会提示，我们可以再次使用 ls 命令去查看

这时已经有了123这个文件

我们可以使用 cd /123 进入该文件夹查看发现没有内容

我们可以使用 vim 1 来创建一个文档

这时我们会进入文档内部，我们可以在这里书写内容

按 i 键进行书写

书写完成我们需要保存并退出，按下 esc 键，这时我们来到了可视模式下按下组合键 shift 和 ：键，这时输入 wq 保存退出直接回车即可（q 不报存退出 有时需要 q！强制退出）

再次 ls 已经该路径下已经有了 1 这就是我们刚才创建的文件

那么当我们不想要这个文件可以使用 rm 命令+文件名

但是当我返回到根路径下想要使用 rm 删除123

这时我们可以使用 rm -rf 123删除
