实际情况：数据中心过载

炎热的服务器机房、嗡嗡作响的冷却系统、大量彩色电缆和闪光灯：这就是经典数据中心的样子。在这种环境下，如何有效地解决网络中的差异？

网络必须以稳定的方式运行。24小时7天，即使管理员下班，具有高数据速率的服务器仍然以高带宽连续运行，同时提供许多不同的服务。但是这里总是存在负载峰值和数据包丢失。由于这种复杂性，管理员必须密切关注所有网络进程，为不同的错误类别做好准备，并能够快速做出反应。

此外，用户可能会抱怨网络速度慢、VoIP 系统质量差或服务器问题。责任往往归咎于管理员，但是导致这种问题的原因有很多种，所有网络层都可能出现不一致，因此，Allegro 网络万用表分析和关联网络第 2 层到第 7 层的所有数据。

Allegro 分析用于在几秒钟内检测错误的提示和重要指标

根据应用程序，特定的指标为可能的问题来源提供重要信息。

存储系统：

对于存储系统，要检查的一个变量是数据传输速度。应特别注意服务器硬件、客户端或其他连接的网络是否可以支持指定的速度。随着时间推移的数据吞吐量，可以找出哪些应用程序/IP 地址产生或接收特别高的流量。Allegro 网络万用表可精确检测这些应用程序/IP。这些信息可以揭示特别大的数据传输的实时冲突，例如办公时间的备份。还可以找出哪个组件是瓶颈。TCP-Zero-Window 参数的调查有助于检测接收器过载。

Web 服务器：

错误并不总是在管理员的影响范围内。Web 服务器可能无法以足够快的速度响应请求的 Web 内容以供内部和外部使用。为了确定可以追溯到 Web 服务器的问题，Allegro-Packets 工具会分析对服务器的请求。指标是每秒对服务器的请求数，请求峰值的时间及其原因，以及传输数据的数量和大小。通过被动测量响应时间，可以确定响应时间是否随时间变化以及哪些服务必须等待很长时间才能得到响应。特别是在请求未得到答复的情况下，应检查哪些请求受到影响以及原因。由于请求延迟的增加，即使是罕见的 TCP 重传也会导致零星的问题。

VoIP：

VoIP 数据包应始终优先于其他数据，以确保语音质量。如果出现问题，Allegro 仪表会确定以下关键数据来确定原因：同时进行的呼叫数量、使用的带宽和编解码器、抖动、数据包丢失、MOS 分数和失败的呼叫。还应始终考虑是否在两个方向上都正确配置了QoS。

工业服务器：

由于生产停机可能会导致相当大的收入损失，因此应经常检查以确保服务器是否可靠运行、是否出现故障以及服务器是否因额外的、不必要的任务而超载。工业领域的网络流量大多比较均匀。Allegro 系统随时关注异常值、故障、带宽和延迟。当然，还监控行业协议特定的响应时间。

为了弄明白一个问题，必须考虑不同的网络类别或层。可以使用 Allegro 网络万用表等通用测量工具，逐层分析并清晰显示结果。使用这种方法，可以分析自制问题和零星错误。此外，数据包突发变得可见。

访问数据以评估数据中心状况

为了评估数据中心的状态，可以使用 Allegro 分析工具在现场监控特定的服务器。这仅提供了对网络当前状态的简要见解。如果在定义的时间范围内未发生特定错误，则可能不会记录该错误。因此，建议将 Allegro 网络万用表集成到网络管理员可远程访问的网络中。可通过管理型交换机提供简单访问。管理型交换机允许配置镜像端口。这可以将全部或部分流量路由到测量系统。此方法可用于连续监视或在特定时间段内进行监视。有必要在镜像端口上安装 Allegro 仪表。监控工具可以接收、读取和图形处理这些数据。许多交换机支持将网络流量转发到另一个 IP 地址的 ERSPAN/GRE。优点是要监视的服务器可以位于与测量系统不同的位置，并且不需要更改连接。但是，网络必须能够处理额外的流量。

最有利的是测量系统，如 Allegro 网络万用表，可通过网络浏览器远程访问。您不需要在远程站点，您可以灵活地使用终端设备（台式电脑、智能手机），并且多个管理员可以使用一台设备来调查不同的参数。监控虚拟机也可以节省宝贵的时间。

虚拟化是数据中心的日常话题。可能有多个物理服务器运行大量虚拟机。在这样的环境下如何分析问题？虚拟机需要额外的预防措施。如果流量进入物理网络，则可以使用已知路由将流量路由到测量系统。但是，可能还需要调查多个虚拟机之间的内部流量。那里的问题可能会导致外部干扰。在这里，可以在虚拟机中使用 ERSPAN 来转移流量。也可以在同一个VM主机上搭建一个虚拟的测量环境来接收流量，而不必进入物理网络，优点是网络负载少。

使用 Allegro 网络万用表进行高效故障排除

10/25/40/100 GBit/s 的高带宽需要专用的测量设备，例如生产商 Allegro Packets 的监控工具。传统的笔记本电脑可能会因大量 IP 地址和连接而过载，或者必须对流量进行严格过滤，以便千兆接口就足够了。记录原始数据是必不可少的；笔记本电脑无法像专用分析设备那样快速有效地存储高带宽网络数据。原始数据使网络管理员能够更深入地以回顾的方式解决问题。

Allegro Packets 的网络故障排除程序可以通过提取原始数据进行更深入的分析来缩小错误范围。这对于检测零星错误特别有用，因为不可能将这些错误记录在目标记录中。因此，可以存储数据的 Allegro 网络万用表是必不可少的。在这种情况下，数据包提取可以节省大量时间。为了在错误成为问题之前检测到错误，应提供尽可能多的实时测量数据以获得完整的概览，并使网络管理员能够处理任何问题。准备好的通用概述允许您通过查看最重要的关键数据来识别网络状态。
