美国国防部拥有多达 1.75 亿个 IP 地址
2022-11-10 13:41:57

近年来我国 IPv4 地址资源十分紧张，因此一直在从运营商以及企业方面推动 IPv6 的建设，目前已经取得初步成效。根据外媒消息，美国国防部（五角大楼）委托一家位于弗洛里达州的小公司寻找网络漏洞，并同时交出了 1.75 亿个IP 地址的控制权，但并没有公布是 IPv4 还是 IPv6 地址。

这家公司名为全球资源系统 (Global Resource Systems), 该公司于 2021 年 1 月 20 日起便开始管理这些 IP 地址。五角大楼发言人称，该公司将识别潜在的漏洞，以便防止未经授权的用户使用美国国防部的 IP 地址空间。

外媒表示，全球资源系统公司成立于去年 9 月，没有任何公开网站，目前也找不到该公司签订的合同。这项关于 IP 地址的计划是由五角大楼一个名为“国防数字服务”的小组负责的。

目前的互联网就是由美国国防部在上世纪发明的，因此 IP 地址资源牢牢掌握在美国手中。目前 IPv4 理论有 42 亿多个，但是公网 IP 地址范围仅有 36.47 亿个，虽然有一个国际组织负责分配 IP 地址资源，但美国仍牢牢掌控着大量 IP 地址，因此需要使用 IPv6 来逐步替代 IPv4。

另外查询国内外IP地址，IP数据云查询，国外IP可以到城市，国内可查到街道。
