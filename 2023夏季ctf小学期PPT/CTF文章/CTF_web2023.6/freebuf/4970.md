IP地址定位工具有哪些
2022-11-28 11:30:08

IP Tools 中包含了五种功能不同的工具分别是：Ping 工具、Traceroute 工具、HTTPHead 工具、CDN 工具与 DNS 工具。

1、Ping 工具：可以从遍布全球的探测点对给定的 IP 地址或域名发起 Ping 请求，以检测被探测主机的连通状况，同时可以根据 Ping 时延大小初步判断被探测主机所在国家或城市。

2、Traceroute 工具：可以从遍布全球的探测机对给定的 IP地址或域名发起 Traceroute 请求，显示从世界不同国家或地区到目标主机的网络路径信息。是用来侦测主机到目的主机之间所经路由情况的重要工具，也是最便利的工具。前面说到，尽管 Ping工具也可以进行侦测，但是，因为 IP头的限制，Ping不能完全的记录下所经过的路由器。所以 Traceroute 正好就填补了这个缺憾。

3、HTTPHead 工具：可以从遍布全球的探测机对目标网址发起 HTTP Head请求并获取 HTTPHeader 字段信息，可以用来检测目标网址在世界不同地方的连通情况。

4、CDN 工具：可以从遍布全球的探测机对给定的域名进行 dns 信息查询，获得域名对应的 A（Address） 记录和 CNAME信息。

5、 DNS 工具：可以向全球大量的公共 DNS 服务器查询您给定的域名的 A 记录，可以获知某个域名在全球的 A 记录解析情况。

A（Address）记录：A (Address) 记录是用来指定主机名（或域名）对应的IP地址记录。用户可以将该域名下的网站服务器指向到自己的网页服务器(web server)上。同时也可以设置域名的子域名。

另外IP地址查询工具有IP数据云，能查到区县级信息、宿主信息。
