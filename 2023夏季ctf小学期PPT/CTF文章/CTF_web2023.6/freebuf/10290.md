Dripping Blues靶机渗透
2022-06-22 18:52:43

1.靶机介绍

靶机下载地址：https://www.vulnhub.com/entry/dripping-blues-1,744/
靶机介绍：
Description
get flags。
difficulty: easy
靶机IP：10.8.0.104

2.端口发现

扫描靶机信息，发现开放了21、22、80端口，21端口ftp可以匿名登录

3.FTP登录

输入用户名ftp和空密码成功登录，查看当前目录有个respectmydrip.zip，无法解压，下载下来查看

get respectmydrip.zip /home/hl/respectmydrip.zip将文件下载到本地查看

4.zip暴力破解

赋权，解压，居然需要密码


fcrackzip -D -u -p /usr/share/wordlists/rockyou.txt respectmydrip.zip，得到密码072528035，解压后得到respectmydrip.txt 和secret.zip两个文件


cat respectmydrip.txt，得到just focus on "drip"，不知道啥意思，解压secret.zip还是需要密码，没有爆破成功

5.WEB登录

访问80端口，得到下面内容

查看http://10.8.0.104/robots.txt，得到以下内容

访问http://10.8.0.104/dripisreal.txt得到提示

http://10.8.0.104/etc/dripispowerful.html无法访问，但这个应该可以文件包含一下，之前得到一个drip，尝试一下，出来一张图片，查看源码发现密码imdrippinbiatch，尝试一下解压secret.zip，密码不对，那这个应该就是其他用户的密码

http://10.8.0.104/index.php?drip=/etc/passwd，发现thugger用户

6.ssh登录

尝试利用用户名thugger和密码imdrippinbiatch，成功登录ssh

查看user.txt文件，得到flag：5C50FC503A2ABE93B4C5EE3425496521

进入.ssh目录，得到authorized_keys、id_rsa、id_rsa.pub应该是thugger用户登录的秘钥文件

7.提权

find / -perm -u=s -type f 2>/dev/null直接查找可利用提权，发现polkit，上网查询polkit有CVE-2021-3560提权漏洞。
polkit是一个应用程序级别的工具集，通过定义和审核权限规则，实现不同优先级进程间的通讯：控制决策集中在统一的框架之中，决定低优先级进程是否有权访问高优先级进程。
Polkit在系统层级进行权限控制，提供了一个低优先级进程和高优先级进程进行通讯的系统。和 sudo 等程序不同，Polkit 并没有赋予进程完全的 root 权限，而是通过一个集中的策略系统进行更精细的授权。

https://github.com/Almorabea/Polkit-exploit下载exp，利用scp传到靶机
scp CVE-2021-3560.py hugger@10.8.0.104:/tmp

赋权，执行，得到root权限，成功拿到flag：78CE377EF7F10FF0EDCA63DD60EE63B8！！！
