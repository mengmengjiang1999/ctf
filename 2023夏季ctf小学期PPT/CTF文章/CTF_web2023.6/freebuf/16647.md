华云安漏洞安全周报【第62期】
2021-12-09 13:43:10

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 11.29~2021.12.5）CNNVD接报漏洞790个，其中信息技术产品漏洞（通用型漏洞）204个，网络信息系统漏洞（事件型漏洞）586个；CNNVD接报漏洞预警65份，其中华云安报送预警9个，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2021-43267-Linux Kernel TIPC 远程代码执行漏洞、CVE-2021-41816-Ruby 缓冲区溢出漏洞、CVE-2021-22095-VMware Spring AMQP 拒绝服务漏洞、CVE-2021-43527-Mozilla NSS 缓冲区堆溢出漏洞、CVE-2021-42358-WordPress 跨站请求伪造漏洞、CVE-2021-42365-WordPress 跨站脚本漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

CVE-2021-43267-Linux Kernel TIPC 远程代码执行漏洞

超危

2021年11月29日，华云安思境安全团队发现 Linux Kernel TIPC 组件中存在一处远程代码执行漏洞，目前此漏洞的 PoC 已在互联网上公开。TIPC（Transparent Inter Process Communication）是一种专为集群内通信而设计的协议，它可以配置为通过 UDP 或直接通过以太网传输消息。该漏洞是由于应用对 MSG_CRYPTO 类型的消息验证不足导致，成功利用此漏洞的攻击者可以远程或本地执行任意代码攻击，获取内核权限，从而攻击整个系统。

https://cdn.kernel.org/pub/linux/kernel/v5.x/ChangeLog-5.14.16

CVE-2021-41816-Ruby 缓冲区溢出漏洞

高危

2021年11月30日，华云安思境安全团队发现 Ruby 官方发布安全更新，披露了 Ruby 组件中存在一处缓冲区溢出漏洞。Ruby 是松本行弘个人开发者的一种跨平台、面向对象的动态类型编程语言。该漏洞是由于在传递非常大的数据时会导致缓冲区溢出字符串（＞700 MB）到 CGI.escape_html。

https://www.ruby-lang.org/en/news/2021/11/24/buffer-overrun-in-cgi-escape_html-cve-2021-41816/

CVE-2021-22095-VMware Spring AMQP 拒绝服务漏洞

中危

2021年11月30日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Spring AMQP 组件中存在一处拒绝服务漏洞。Spring AMQP 是将核心 Spring 概念应用于基于 AMQP 的消息传递解决方案的开发。该漏洞是由于 Spring AMQP Message 对象在其 toString() 方法中，将从消息体中创建一个新的 String 对象，缺少对对象的大小的限制与过滤，这可能会导致带有超大消息的 OOM 错误。

https://tanzu.vmware.com/security/cve-2021-22097

CVE-2021-43527-Mozilla NSS 缓冲区堆溢出漏洞

高危

2021年12月2日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Mozilla NSS 组件中存在一处缓冲区堆溢出漏洞。Mozilla Network Security Services（NSS）是一个函数库（网络安全服务库），该产品可跨平台提供 SSL、S/MIME 和其他 Internet 安全标准支持。该漏洞是由于在 NSS 验证证书的方式中存在缺陷，攻击者可通过使用 NSS 编译的客户端应用程序发起 SSL TLS 连接来触发漏洞。

https://www.mozilla.org/en-US/security/advisories/mfsa2021-51/#CVE-2021-43527

CVE-2021-42358-WordPress 跨站请求伪造漏洞

高危

2021年12月2日，华云安思境安全团队发现 WordPress 官方发布安全更新，披露了 WordPress 的 Contact Form With Captcha 组件中存在一处跨站请求伪造漏洞。该漏洞是由于在 ~ /admin /tables/ admin-structure-table.php 文件中没有充分的转义参数，插件容易受到跨站点脚本攻击。成功利用此漏洞的攻击者可诱导用户访问特制网页从而在易受攻击的网站上执行任意操作。

https://wordfence.com/vulnerability-advisories/#CVE-2021-42358

CVE-2021-42365-WordPress 跨站脚本漏洞

中危

2021年12月2日，华云安思境安全团队发现 WordPress 官方发布安全更新，披露了 WordPress 的 Asgaros Forums 组件中存在一处跨站脚本漏洞。该漏洞是由于在 ~ /admin /tables/ admin-structure-table.php 文件中没有充分的转义参数，插件容易受到跨站点脚本攻击。成功利用此漏洞的远程攻击者可能会注入任意 web 脚本，窃取潜在的敏感信息、更改网页外观等。

https://wordfence.com/vulnerability-advisories/#CVE-2021-42365
