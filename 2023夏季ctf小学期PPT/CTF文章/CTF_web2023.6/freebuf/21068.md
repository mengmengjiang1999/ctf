恶意软件 Raccoon Stealer 将目标转向加密货币

Tag：Raccoon，Stealer

事件概述：

8月3日，Sophos 发布恶意软件 Raccoon Stealer 的新研究报告。报告显示 Raccoon Stealer 不仅从网站窃取密码、Cookie 和信用卡等数据信息，而且现在还针对加密货币钱包窃取信息。Raccoon Stealer 是一种广泛使用的信息窃取恶意软件，与许多信息窃取软件一样，它作为服务出售，而不是独立的恶意软件出售。Raccoon 的开发人员会严格的控制该恶意软件的访问权限，通过 Tor 托管用户部署的僵尸，并且 Raccoon 恶意软件的每个可执行程序都有一个与客户绑定的签名。如果 Raccoon 恶意软件样本出现在 VirusTotal 或其他恶意软件网站上，Raccoon 开发人员可以追踪到可能泄露样本的客户。

信息窃取工具只是攻击者更大入侵的一部分有针对性的攻击，攻击者通过其他方式获得访问权限后手动部署信息窃取程序。

技术详情：

信息窃取工具最常见的方法是通过垃圾邮件，压缩的可执行文件或作为恶意文档 dropper 的有效载荷进行传播，攻击者也可以使用恶意网站或 p2p 共享服务来传播恶意软件，或伪装成盗版软件，也可以由植入程序来安装该恶意软件。

近期， Raccoon 样本都是通过利用恶意网站的单个 dropper 活动分发的。该活动背后的参与者还使用搜索引擎优化来增加寻找特定软件包的人访问恶意站点的机会。在 Google 上搜索“[软件产品名称] 破解”会返回指向声称提供绕过许可要求的软件下载的网站的链接。

虽然这些网站将自己标榜为破解合法软件的存储库，但实则交付的文件是伪装的 dropper 。此活动中的 dropper 不仅携带 Raccoon 恶意软件，还携带其他恶意软件，包括crypto-miners和clippers，其中 clippers 是通过在交易期间修改受害者的系统剪贴板，以及更改目标钱包来窃取加密货币的恶意软件。

Android 银行恶意软件 FluBot 针对澳大利亚银行展开攻击活动

Tag：FluBot， Android，澳大利亚

事件概述：

Android 银行恶意软件的 FluBot 最初于2020年末在西班牙被发现，然后在接下来的几个月中在欧洲广泛地传播，现在正以澳大利亚银行为目标展开攻击活动。 Netcraft 研究人员还在近期监控发现 FluBot 恶意软件伪装成澳大利亚银行、 墨尔本银行、 BankSA、 联邦银行、 澳洲大南方央行、 澳大利亚汇丰银行、 澳大利亚国民银行、 圣乔治银行、 Suncorp 和 UBank 等银行应用程序的页面。

技术详情：

FluBot 恶意软件通过包含诱饵链接的短信传播，短信通常伪装成来自提供跟踪物流更新的快递公司，诱饵页面试图诱骗潜在受害者下载、安装伪装成包裹跟踪应用程序的恶意软件 FluBot。FluBot 在受害者设备成功安装后，定期收集设备上安装的应用程序列表，回传给该恶意软件的命令与控制服务器，服务器以返回覆盖的应用程序列表命令作为响应。

一旦受害者设备中的某个应用程序启动，FluBot 会立即在合法应用程序之上显示一个覆盖层。该覆盖层模仿合法应用程序，旨在收集受害者的网上银行凭证，然后将收集到的信息通过命令和控制服务器发送给 FluBot 背后的犯罪组织。

爱沙尼亚政府数据泄露，超28万公民信息受到影响

Tag：政府，数据泄露，爱沙尼亚

事件概述：

爱沙尼亚国家信息系统在7月30日遭到黑客攻击后，超过28万公民的信息遭到泄露。据报道称，黑客已经获取了286,438公民的姓名和 ID 编号信息，并且可以从9,000个 IP 地址发出请求获取公民照片的信息。在此次数据泄露事件中，黑客利用照片传输服务漏洞，从身份文件数据库(KMAIS)下载身份扫描文件，并没有直接破坏网络服务。

RIA 负责人表示黑客获取的数据仅仅只有政府系统存储的身份照片信息，而且黑客获取的照片、ID代码、姓名信息，不足以访问任何爱沙尼亚国家电子服务，这也表示身*份证、流动身*份证、智能身*份证等信息没有遭到泄露。爱沙尼亚政府表示，将通过爱沙尼亚警察和边防警卫委员会的电子邮件通知受影响的公民，并且爱沙尼亚警方已对该名涉事黑客进行了逮捕。

北爱尔兰卫生部数据发生泄露后，暂停疫苗接种认证服务

Tag：卫生部，COVID-19，数据泄露

事件概述：

据外媒报道，北爱尔兰卫生部（DoH）表示 COVIDCert 服务的一些用户会收到其他用户的数据信息。在 DoH 数据发生泄露后， COVIDCert 暂时暂停了疫苗接种认证服务。COVIDCert 是一个独立于英格兰和威尔士使用的 NHS COVID Pass 的系统，该系统可以使北爱尔兰的全面接种者能够获得确认其 COVID-19 疫苗接种状态的数字证书。公民可以通过 COVIDCert 官网或移动应用程序访问该服务。

东南亚多个关键基础设施成为间谍活动的目标

Tag：基础设施，间谍活动，东南亚

事件概述：

针对国家基础设施（CNI）的网络攻击一直是国家面临的主要问题，这些攻击事件会对电力、水、交通行业造成巨大的破坏，对公民产生严重的影响，对组织和政府产生巨大的压力。2010年伊朗震网事件，2015年乌克兰电网事件，2021年的美国殖民地输油*管道事件，是基础设施网络安全成为当下安全的重中之重。

赛门铁克于8月5日发表白皮书，主要围绕疑似2020年11月至2021年3月期间针对水公司、电力公司、通信公司、国防组织四个关键基础设施的间谍活动展开，并且表示攻击者可能对SCADA（资料采集与监视系统）感兴趣。

研究人员虽然没有观察到这些针对关键基础设施攻击的初始感染媒介，但对其攻击深入分析后发现攻击者主要目标为在关键机基础设施内部进行凭证窃取和横向移动，且广泛的使用ProcDump、PAExec、Mimikatz 等凭证转储工具。由于这些攻击活动的目标地理位置和部门的相似、不同目标组织几乎都存在下载器和键盘记录器以及使用的相同 IP 地址等迹象表明这些针对多个东南亚基础设施的攻击活动背后是同一个攻击者。

在针对这些基础设施的攻击活动中，攻击者使用了DLL查找顺序劫持、LSASS 驱动程序 ProcDump 窃取凭据等技术。研究人员虽然无法确定这些针对基础设施攻击的最终目标是什么，但间谍活动似乎是攻击者最有可能的动机。具体详细报告您可以通过访问下方参考链接获取。

医院网络中使用的 Translogic PTS 系统被曝存在 PwnedPiper 漏洞

Tag：TransLogic，PwnedPiper，医院

事件概述：

近日，Armis 研究人员在 Swisslog Healthcare 公司的 Translogic PTS 系统中发现了九个关键漏洞，这些漏洞统称为 PwnedPiper 漏洞。Swisslog 的 Translogic PTS 系统对医院运营至关重要，它通过气动管道网络实现了物流和材料在整个医院的运输自动化。北美超过80%的医院和全球3,000多家医院都在使用该系统。PTS 系统在患者护理中也起着至关重要的作用，并且这些医院几乎100%的时间都在使用该系统。

Translogic PTS 系统中存在的 PwnedPiper 漏洞包括 CVE-2021-37160、CVE-2021-37163、CVE-2021-37167、CVE-2021-37161、 CVE-2021-37162、CVE-2021-37165 、CVE-2021-37164、CVE-2021-37166、 CVE-2021-37160。

这些漏洞允许攻击者完全接管 Translogic Nexus 控制面板，该面板为 Translogic PTS 的所有当前型号提供支持。较旧的 IP 连接 Translogic 站点也受到影响，但 Swisslog Healthcare 不再支持这些较旧的站点。

Armis 于 2021 年 5 月 1 日向 Swisslog Healthcare 报告了这些漏洞，Swisslog Healthcare 于8月2日发布了 PwnedPiper 漏洞的安全公告。Armis 还在报告中提供了这些漏洞的缓解措施：

1、阻止在 Translogic PTS 站上使用 Telnet（端口 23）；

2、部署访问控制列表 (ACL)，其中 Translogic PTS 组件只允许与 Translogic 中央服务器 (SCC) 通信；

3、 利用 Snort IDS 规则检测。

伊朗政府部门泄露的文件显示伊朗对 ICS 感兴趣

Tag：伊朗，ICS，数据泄露

事件概述：

英国新闻媒体 Sky News 发表报道称，来自伊朗的五份机密文件揭示了关于如何利用网络攻击击沉一艘货船或炸毁加油站的燃油泵的秘密研究，其中获得的内部文件还包括关于全球航运业使用的卫星通信设备信息，以及控制世界各地智能建筑的照明、供暖和通风等基于计算机的系统信息。

据称，这份57页研究报告是由一个名为“13号情报小组”编制的，“13号情报小组”是“Shahid Kaveh”秘密攻击性网络单位的一个小组，“ Shahid Kaveh”单位又是伊朗伊*斯*兰革命卫队（IRGC）网络司令部的一部分。外媒报道还称泄露的机密文件显示伊朗在针对工业控制系统（ICS）等方面正在寻求提高其攻击性网络能力。

这五份机密报告具体包括以下内容：

1）关于建筑管理系统的文件：该份文件从 2020 年 11 月 19 日开始，着眼于所谓的建筑管理系统——控制智能建筑中的灯光、供暖和通风等事物的计算机技术；

2）关于压载水的文件：该份文件着眼于大型货船上的复杂系统，这些系统可以远程控制过滤和压载水等设备；

FatalRAT 木马分析报告

Tag： FatalRAT，木马

事件概述：

近日，AT&T 研究人员观察到一种新的远程访问木马（RAT）FatalRAT，该木马通过论坛和Telegram 渠道分发，并试图通过软件或媒体文章诱使用户下载恶意木马。据研究人员分析FatalRAT 样本发现，样本能够执行防御规避技术、获取系统持久性、记录用户按键信息和通过加密的命令和控制通道进行渗透。

技术详情：

FatalRAT 在完全感染系统之前会进行多项测试，首先会进行虚拟机/沙箱检测，查询注册表。如果目标环境不是虚拟机、沙箱环境，恶意木马便会执行解密包含 C2 地址、新恶意软件文件名、服务名称的配置字符串，将册表项 DisableLockWorkstation 设置为“1”，使用 CTRL+ALT+DELETE 锁定计算机。然后激活木马的键盘记录程序，收集目标主机 IP 、用户名等其他信息，将收集到的信息以包含 XOR 在内的加密方式通过8080端口回传给恶意 C2。FatalRAT 还会通过创建新服务和设置“Software\Microsoft\Windows\CurrentVersion\Run\SVP7”注册表启动项实现恶意软件在受害主机的持久性。此外，该恶意木马还会在受害主机上检测安全软件，并且将检测到的软件信息重命名为产品名称发送给 C2，等待接收攻击者的下一步命令。

思科修复 Firepower 设备管理器 (FDM) On-Box 软件中的远程代码执行漏洞

Tag：Firepower，远程代码执行

事件概述：

思科于近日在新发布的软件版本中修复了ban Firepower 设备管理器（Firepower Device Manager，FDM） On-Box 软件中的漏洞 CVE-2021-1518。FDM On-Box 用于配置 Cisco Firepower 防火墙，为管理员提供管理和诊断功能。CVE-2021-1518 漏洞是由 Positive Technologies 研究人员发现的。此漏洞是由于对特定 REST API 命令的用户输入的清理不足，攻击者可以在获得受影响设备的有效用户凭据后，通过向受影响设备的 API 子系统发送精心设计的 HTTP 请求来利用此漏洞，成功利用此漏洞的攻击者可以在底层操作系统上执行任意代码。该漏洞影响 FDM On-Box 6.3.0、6.4.0、6.5.0、6.6.0 和 6.7.0版本，思科通过发布软件版本6.4.0.12、6.4.4和6.7.0.2修复了该漏洞。

思科修复 VPN 路由器中的严重漏洞

Tag：VPN，严重漏洞

事件概述：

思科于近日在新发布的软件版本中修复了影响多个小型企业 VPN 路由器的认证前安全漏洞 CVE-2021-1609 和 CVE-2021-1602，这两个漏洞允许远程攻击者触发拒绝服务或在脆弱设备上执行命令和任意代码，且无需身份认证就可以远程利用漏洞。

CVE-2021-1609(CVSS 9.8)是由于HTTP请求验证不当造成的漏洞，CVE-2021-1602(CVSS 8.2)是由用户输入验证不足造成漏洞的，这两个安全漏洞均存在于 web 管理界面。CVE-2021-1609 漏洞影响 RV340、RV340W、RV345 和 RV345P 双 WAN 千兆 VPN 路由器，CVE-2021-1602 漏洞影响 RV160、RV160W、RV260、RV260P 和 RV260W VPN 路由器。

攻击者可以通过向受影响路由器的 Web 的管理界面发送恶意制作的 HTTP 请求来利用这些漏洞。这些漏洞并不互相依赖，受一个漏洞影响的版本可能不受另一个漏洞的影响。思科已于8月4日发布软件更新来解决这些漏洞。
