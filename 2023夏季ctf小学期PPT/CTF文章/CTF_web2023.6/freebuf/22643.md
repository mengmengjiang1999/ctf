一款调用FOFA API的自动漏洞挖掘工具：AutoSRC
2021-07-12 19:18:21

简介

AutoSRC是一款自动化漏洞扫描工具，使用者仅需设置FOFA的邮箱和Token即可。

安装

git clone https://github.com/pwnwikiorg/AutoSRC.git

cd AutoSRC

python3 autosrc.py -e <FOFA EMAIL> -k <TOKEN>


使用

#设置FOFA的邮箱和Token即可
python3 autosrc.py -e <FOFA EMAIL> -k <TOKEN>
