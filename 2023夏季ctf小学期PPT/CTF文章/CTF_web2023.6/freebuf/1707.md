Viper安装

1.安装docker

本次搭建viper的机子为kali 2022.03 安装docker命令如下

apt-get update

curl -sSL https://get.daocloud.io/docker | sh

service docker start


2.安装docker-compose

安装compose的时候没有出现错误，在chmod的时候kali系统不要加/local这层目录，即可！

curl -L https://get.daocloud.io/docker/compose/releases/download/1.25.5/docker-compose-`uname -s`-`uname -m` > /usr/bin/docker-compose

chmod +x /usr/bin/docker-compose

3设置安装目录

export VIPER_DIR=/root/VIPER

4.生成安装目录，并进入目录

mkdir -p $VIPER_DIR && cd $VIPER_DIR


5.生成docker-compose.yml

用tee命令把代码写入到docker-compose.yml里

#network_mode:"host" 引号里的东西不要动，就是host

#command：["123456"] 123456是登录密码，自己设置即可。(vps一定要设置强密码)

tee docker-compose.yml <<-'EOF'
version: "3"
services:
  viper:
    image: registry.cn-shenzhen.aliyuncs.com/toys/viper:latest
    container_name: viper-c
    network_mode: "host"
    restart: always
    volumes:
      - ${PWD}/loot:/root/.msf4/loot
      - ${PWD}/db:/root/viper/Docker/db
      - ${PWD}/module:/root/viper/Docker/module
      - ${PWD}/log:/root/viper/Docker/log
      - ${PWD}/nginxconfig:/root/viper/Docker/nginxconfig
    command: ["123456"]
EOF

6.启动viper

cd VIPER

docker-compose up -d


所有的docker-compose命令必须在安装目录执行才会有效果

7.登录网页


  * 等待系统启动,访问 https://yourip:60000登录. 用户名:root 密码:自定义密码

8.关闭&重启容器

docker-compose stop

docker-compose start
