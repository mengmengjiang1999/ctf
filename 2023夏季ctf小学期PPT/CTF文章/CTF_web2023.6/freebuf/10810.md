自己动手搭建Blog利器之Chevereto图床
2022-06-11 22:55:46

在日常写公众号等Blog文章时，我喜欢使用Obsidian作为笔记和编辑工具，使用Markdown语法来撰写文章，但是一直以来困扰我的一个问题就是在文章中插入图片时，如果直接使用本地存储的图片，在发布公众号等Blog时，就需要将本地图片一张一张上传，操作起来十分麻烦，如果使用网上收费的一些图床，又感觉太贵了，但使用免费图床又怕不安全，这时候突然想到我有一个闲置的轻量级腾讯云服务器，于是就开始了折腾之旅，自己动手搭建Chevereto图床。

系统环境

硬件配置：腾讯云轻量服务器2核2G内存4Mbps带宽40G SSD硬盘

软件配置：Centos 7.6.1810

所需软件：Nginx、PHP、Mysql和Chevereto

搭建步骤

Nginx安装配置

Nginx是一个高性能的HTTP和反向代理web服务器，由于其本身轻量级的特性，此处选择使用Nginx而不是Apache，Centos系统安装Nginx比较简单直接使用yum指令即可：

yum install nginx

安装成功后需要正确配置nginx，首先通过locate指令找到nginx.conf文件的位置：

[root@VM-16-15-centos ~]# locate nginx.conf
/etc/nginx/nginx.conf
/etc/nginx/nginx.conf.default


修改user为nginx，找到http那一栏，在其中加入下面的内容，注意修改server_name为自己的服务器的IP或域名。

server {
# 监听80端口
listen 80;
# 服务器的IP或域名
server_name 127.0.0.1;
# 默认网站根目录
root /var/www/chevereto;

# 不添加这行可能部分页面会出现403错误
autoindex on;
index index.php;

# fastcgi configurationg
location ~ \.php$ {
# php服务监听端口
fastcgi_pass   127.0.0.1:9000;
fastcgi_index  index.php;
fastcgi_param  SCRIPT_FILENAME  $document_root$fastcgi_script_name;
include        fastcgi_params;
}

# Image not found replacement
location ~* (jpe?g|png|gif) {
log_not_found off;
error_page 404 /content/images/system/default/404.gif;
}

# CORS header (avoids font rendering issues)
location ~ .(ttf|ttc|otf|eot|woff|woff2|font.css|css|js)$ {
add_header Access-Control-Allow-Origin "*";
}

# Pretty URLs
location / {
try_files $uri $uri/ /index.php?$query_string;
}

之后保存配置文件中的修改内容，使用如下命令重启Nginx。

systemctl restart nginx

这里我们使用的是80端口，那么还需要将防火墙的80端口开放。

firewall-cmd --zone=public --add-port=80/tcp --permanent  防火墙开放80端口  
systemctl restart firewalld`  重启防火墙

PHP安装配置

若直接采用centos中的yum安装php，采用如下指令

sudo yum -y install php

但这样只能安装5.4版本的PHP，远远不够，因此我们要手动更新rpm即可，那么先获取rpm：

rpm -Uvh https://dl.fedoraproject.org/pub/epel/epel-release-latest-7.noarch.rpm
rpm -Uvh https://mirror.webtatic.com/yum/el7/webtatic-release.rpm

然后可以利用如下命令查看PHP的安装包

yum list | grep php

根据自己需要的版本选择安装对应的版本和拓展包即可，其中php-fpm必须安装，其是一个管理PHP 进程池的工具，主要用于用于接受web服务器的请求：

yum -y install php72w php-fpm php72w-cli php72w-common php72w-devel php72w-mysql php-mbstring

安装完成后可通过php -v指令查看安装的PHP具体版本信息，下面开始具体配置PHP，找到/etc/php.ini文件，修改并添加如下项：

;配置最大上传文件大小
upload_max_filesize = 10M 

;PHP可接受的最大POST数据
post_max_size = 20M

;每个脚本的最大执行时间，由于上传文件过大，执行时间也应变长
max_execution_time = 300

;配置mbstring
mbstring.language = all 
mbstring.internal_encoding = UTF-8
mbstring.http_input =auto
mbstring.http_output =UFT-8
mbstring.encoding_translation = On
mbstring.detect_order = UTF-8
mbstring.substitute_character = none
mbstring.func_overload = 0

同时需要在/etc/php-fpm.conf文件中增加如下配置：

[www]
listen=127.0.0.1:9000

设置PHP的默认服务端口为9000，这与在Nginx中的设置也是一致的，下面可开启PHP服务并查看9000端口是否被占用

systemctl start php-fpm
netstat -lnt |grep 9000

MySQL安装配置

Centos中默认安装了MariaDB，它是轻量级的MySQL数据库，这里我们需要使用如下指令重新安装MySQL

wget https://dev.mysql.com/get/mysql57-community-release-el7-11.noarch.rpm
yum -y localinstall mysql57-community-release-el7-11.noarch.rpm
yum -y install mysql-community-server 

有些同学在安装过程中可能会碰到这样的错误：

Failing package is: mysql-community-libs-compat-5.7.38-1.el7.x86_64
GPG Keys are configured as: file:///etc/pki/rpm-gpg/RPM-GPG-KEY-mysql

产生这样错误的原因是MySQL的GPG升级了，需要输入如下指令再安装：

rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-2022
yum install mysql-server

提示安装成功后，即可使用如下指令启动mysql

systemctl start mysqld

下面就对MySQL数据库进行配置，先通过如下指令找到mysql的默认密码

grep "password" /var/log/mysqld.log

再使用默认密码登录之后修改密码：

ALTER USER 'root'@'localhost' IDENTIFIED BY '新密码';` 

之后通过以下指令完成对MySQL数据库的基本配置：

CREATE DATABASE chevereto; #为图床创建数据库chevereto 
CREATE USER 'cheveretouser'@'localhost' IDENTIFIED BY '图床用户的密码'; #创建新用户 
GRANT ALL PRIVILEGES ON chevereto.* TO 'cheveretouser'@'localhost'; #添加权限 
FLUSH PRIVILEGES; #刷新权限 
exit #退出mysql

Chevereto图床安装配置

这里选择Chevereto 1.4.2的版本（从1.5版本开始不支持中文了），创建Chevereto图床源码的存放路径，并通过如下指令下载并解压安装包：

mkdir -p /var/www/chevereto
wget https://github.com/rodber/chevereto-free/releases/download/1.4.2/1.4.2.zip
unzip 1.4.2.zip

同时赋予php的session与nginx相同的用户操作权限：

chown -R nginx:nginx /var/lib/php/session/

在Chevereto安装包的app路径下新建settings.php文件，并将如下针对数据库的配置内容复制进去：

<?php
$settings = array (
'db_host' => 'localhost',
'db_name' => 'chevereto',
'db_user' => 'cheveretouser',
'db_pass' => '数据库密码',
'db_table_prefix' => 'chv_',
'db_driver' => 'mysql',
'db_pdo_attrs' => 
array (
),
'debug_level' => 1,
);
?>

输入对应IP地址/install登录服务器，总是报错：

sessions are not working on this server due to missing write permission on session save path(php.ini session.save_path)

在网上搜了很多解决办法，最终定位到两个原因，第一个是因为PHP没有权限操作Chevereto文件所在的文件夹，通过如下指令修改：

chmod -R 777 /var/www/chevereto/ 

另一个原因是php-fpm的配置文件中的用户与Nginx不一致，这里将 /etc/php-fpm.d/www.conf中的user和group都改为与Nginx一致的nginx，之后重启php-fpm就正常了，进入如下界面，输入管理员账号邮箱等信息之后就可正常使用。

其他问题

问题提示chevereto gd library is not enabled in this server，首先查看自己当前php的版本

php  -v
PHP 5.6.40

查看yum中是否有对应版本的包

yum list | grep gd 

我这里就选择对应服务器php的版本安装gd library

yum install php56-php-gd.x86_64 -y

查看gd.so的所在路径

find / -name gd.so
/usr/lib64/php/modules/gd.so

通过vim /etc/php.ini编辑php的配置文件，并添加如下内容，之后重启php-fpm即可

#文件末尾填入
extension=/opt/remi/php56/root/usr/lib64/php/modules/gd.so
