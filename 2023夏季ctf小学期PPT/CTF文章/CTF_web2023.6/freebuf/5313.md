企业扩张过程中，数据安全建设容易忽略的风险——数据接口安全
2022-11-25 19:21:55

随着《网络安全法》和《数字安全法》的推出与落实，更多企业开始在信息化的建设过程中考虑数据安全。当前主流的建设思路是从数据全生命周期的视角出发，将数据从生成到销毁的整个过程进行通盘设计，看似安全的背后实则存在很多问题。


如上图所示，数据治理生命周期包含：数据采集和生成、数据传输、数据存储备份和恢复、数据处理和使用、数据共享和交换、数据销毁等几个主要步骤。

企业初步建设数据安全时，会对数据进行分级分类、数据脱敏等一系列处理，对数据的生命周期也有较好的管理。但随着企业扩张，业务系统增多，老旧业务变动等，企业数据风险会在监控视野之外不断扩大，一旦遭受恶意的攻击与利用，将造成严重的数据损失，例如数据泄露等。

风险发生时，首当其冲的便是数据接口安全。

什么是数据接口

通常数据接口是通过API进行提供的，API又称为应用程序编程接口，是一个软件与另一个软件互动的方式。应用程序在通过API进行数据互动时，往往会增加权限校验来保护数据在可控的范围内流动，不同的业务类型对权限控制的要求也不同。

  分类                      描述                                      安全现状                   
开放型API   频繁出现在金融业相关的开放银行倡议中，促进特定行业的创新和提高服务整合   存在认证和委托授权                                 
私有型API   通常在数据中心或私有云网络环境中部署和运行，以运营管理、内部服务支撑为主  认证和授权可能存在，但也有可能认为攻击暴露面有限，而被忽视             
合作伙伴API  向特定的外部供应商提供对内部API的有限访问，以推动数字供应链       访问程度控制权位于内部和外部API之间，可能通过API网关管控，但缺少安全方面的考虑



数据服务接口常见风险

由于数据服务接口是企业信息系统直接对外的，所以存在很多种风险，以下仅列举常见的几种风险攻击类型：

漏洞攻击：API数据接口服务的本质还是基于http协议的Web服务，所以常见Web漏洞仍然会出现在API数据接口服务之中。

身份验证攻击：攻击者可以通过伪造身份，来突破数据分类分级和数据权限管控限制，访问到不属于自己权限范围内的数据。例如：攻击者可以获取合法客户端的凭据、窃取 API 密钥或拦截并使用身份验证令牌。

授权错误：授权决定了每个用户的访问级别。如果授权管理出现错误，API客户端可能会访问不应该向其提供的数据，从而增大了数据泄露的可能。

拒绝服务类型攻击（DDoS）：攻击者恶意大量且频繁地向API数据接口服务发送调用数据包，会使数据接口服务的实际负载超出设计时可承受的负载能力，将会导致数据接口服务反应缓慢甚至停摆，致使正常的数据接口请求得不到响应，影响正常业务的推进。

除了上述罗列，OWASP团队列举了更多常见的API漏洞类型，感兴趣的同学可以自行访问。

https://owasp.org/www-project-api-security/

易被忽略的风险

在企业业务扩张的过程中，接口会随着业务系统不断更新。新的接口往往经过认真的考虑和精心的设计，无论是权限控制还是安全性，都得到了很大的保障。

最容易忽视的是老旧的接口。很多业务系统同时存在老版本和新版本多个接口，同一个数据在新接口上层层设卡，却在老接口上门户洞开，这便给数据访问留下了隐患。

另外一种情况，不是业务系统进行升级，而是业务本身发生了变动，原有的系统正常运转，但是升级的时候忽视了该系统的存在。久而久之，系统接口的安全性也就跟不上当前情况下安全建设的步骤，仍然会给数据安全带来风险。

如何保护接口安全

在日益庞大与复杂的业务系统中，API接口的风险是不可避免的，及时发现风险并采取相应措施至关重要。当前企业建设接口防护的基础逻辑是从攻和防两方面进行建设：

在“守”方面，常见的方式是通过防火墙来进行API接口的管理，所有的接口数据都经过防火墙的过滤，从而增强数据安全性。

在“攻”方面，企业往往会申请第三方渗透测试服务，来持续地对企业进行模拟攻击，发现接口服务的攻击入口，并通过尝试不同的黑客攻击手段来查看疏于管理的API接口会产生怎样的安全风险。

渗透测试是验证当前API接口安全性的有效手段。当前，多数安全公司提供的渗透测试服务还停留在人工测试的阶段，人工黑客使用各种零散工具对数据服务API接口进行检测，检测结果依赖渗透团队能力与个人天赋，渗透结果存在不确定性，智能自动化的渗透测试工具将有效解决这些问题。

智能自动化渗透测试平台

目前，处于国内行业领先的智能自动化渗透测试工具为Vackbot，它是国内首款结合AI智能决策的智能自动化渗透测试平台。Vackbot集成了API路径发现等功能，并覆盖常见的API安全漏洞，集成国际领先的黑客攻击技术，能自动建立攻击标靶模型，推演攻击路径，选取最优攻击突破口，能有效发现被遗忘、疏于管理的数据服务API接口，并对其进行安全检测，将渗透所消耗的时间缩减至原先的十分之一，极大程度地提高了渗透效率，节省渗透的时间成本。

除了常规的API检测，Vackbot渗透测试机器人还拥有内网渗透功能，经过授权后，Vackbot在API接口安全检测之后可以尝试突破内网并对API数据接口服务安全隐患所导致的风险进行量化评估，回溯展示整个渗透测试过程，帮助定位需优先处理的重要安全漏洞，有利于安全修复方案的落地与推进。

同时，Vackbot智能自动化渗透测试平台支持云模式和内网独立部署等多种模式，云模式的服务只需开通账号即可进行API安全检测，独立部署模式则可以通过网络隔离更好的保护企业隐私数据。
