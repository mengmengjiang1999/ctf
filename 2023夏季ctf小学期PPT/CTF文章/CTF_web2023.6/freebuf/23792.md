当企业出海成为时代热潮，出海过程中的网络安全问题也备受关注。恶意攻击、数据盗用等网络安全事件令人防不胜防。

据 Akamai 统计， 仅在2020年，全球范围内勒索软件攻击时间就增加715%，网络钓鱼攻击增加了600%，上半年 DDoS 攻击增加了151%；从2018年7月到2020年6月 Akamai 在所有客户处观察到的 Web 应用攻击超过100亿次，撞库攻击超过1000亿次。对企业而言，这些数据的背后，无疑潜藏着巨大的安全隐患。

面对不断加剧的网络安全风险，企业如何持续更新自身安全策略？

如何改善信息保护机制，防御日益多样的网络攻击？

如何在保护数据资产的同时，为用户提供良好的使用体验？

2021年7月23日， Akamai 出海·网络安全峰会（大中华区）将邀请多位资深网络安全防御技术专家，与企业领导者、技术开发者共同探寻未来网络安全防御策略，讨论网络安全领域的热门话题。更有 OWASP （Open Web Application Security Project）组织新加坡分会主席 Wong Onn Chee 先生 带来关于 API 安全及个人信息保护的独到见解。
