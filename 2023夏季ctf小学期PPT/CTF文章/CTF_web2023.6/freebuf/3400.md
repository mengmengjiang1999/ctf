使用Python库对Webshell密码进行多线程爆破
2023-01-15 10:39:29

前言

前两天发的“Python一个超好用的CTF库”中，我们有很多常见的功能，可以对WebShell进行一系列的操作。

功能主要有下：

标靶

假设我们需要爆破的为192.168.1.123中的shell.php。

使用

from qsnctf import * 
a = WebShellCracking('http://192.168.1.123/shell.php', threadline=50,mode="GET")
print(a.results)

在上面的示例中，threadline为爆破线程数，如果网站有waf限制，也可以增加一个

from qsnctf import * 
a = WebShellCracking('http://192.168.1.123/shell.php', sleep_time=1,mode="GET")
print(a.results)

这样就可以每秒停止一次访问了

当然，Python库中的字典是有限的，使用者也可以自己增加字典：

from qsnctf import *
pass_list = ['aaa','bbb','cccc']
a = WebShellCracking('http://192.168.1.123/shell.php', threadline=50, passlist=pass_list ,mode="GET")
print(a.results)

当然，你也可以写一个读入txt文件的方法，写到list里，然后再传参。

接下来a.results将会输出爆破成功的密码，如果没有成功则为空（None）
