HTTP协议是什么？
来自WIKI：超文本传输协议（英语：HyperText Transfer Protocol，缩写：HTTP）是一种用于分布式、协作式和超媒体信息系统的应用层协议

简单说HTTP协议就是使文本和媒体类的资源能够在互联上进行传输的协议

HTTP 请求包

一、请求信息

 1. 请求方法，Method
 2. 请求路径，Path
 3. HTTP协议版本，Version of protocol
 4. 请求头部，Headers

二、请求方法

常用方法

  * GET：主要的获取信息方法，大量的性能优化都针对该方法，幂等方法
  * HEAD：类似GET，但服务器不发送BODY，用于获取HEAD元数据，幂等方法
  * POST：用于HTML FORM提交表单、新增资源等
  * PUT：更新资源，带条件时是幂等方法。
  * DELETE：删除资源，幂等方法。
  * CONNECT：建立tunnel隧道
  * OPTIONS：显示服务器对访问资源支持的方法，幂等方法
  * TRACE：回显服务器收到的请求，用于定位问题。安全风险

三、协议版本

 1. HTTP/0.9 已过时
 2. HTTP/1.0
 3. HTTP/1.1
 4. HTTP/2.0

HTTP/1.0和HTTP/1.1的区别

 1. HTTP/1.1采用持续连接(Connection: Keep-Alive)


  * 缓存处理
  * 带宽优化及网络连接的使用
  * 错误通知的管理
  * 消息在网络中的发送
  * 互联网地址的维护

HTTP 响应包

响应信息

 1. 状态行：协议版本、响应码、状态信息
 2. 响应头部：Headers

响应码

常见的HTTP响应码

  * 1xx消息——请求已被服务器接收，继续处理
      + 100 Continue 服务器收到请求头，客户端继续发送
      + 101 Switching Protocols:切换定义头中的协议
  * 2xx成功——请求已成功被服务器接收、理解、并接受
      + 200 OK 请求成功响应返回
      + 201 Created 请求已实现，新资源产生
      + 202 Accepted 服务器已接受请求尚未处理
  * 3xx重定向——需要后续操作才能完成这一请求
      + 301 Moved Permanently 被请求的资源已被永久移动到新的位置
      + 302 Found 要求客户端执行临时重定向
  * 4xx请求错误——请求含有词法错误或者无法被执行
      + 400 Bad Request 客户端错误
      + 401 Unauthorized 未认证，用户没有必要的凭证
      + 403 Forbidden 服务端已理解请求，拒绝执行
      + 404 Not Found 请求失败，请求的资源未在服务器中发现
      + 405 Method Not Allowed 请求行中的请求方法不能获取到响应的资源
  * 5xx服务器错误——服务器在处理某个正确请求时发生错误
      + 500 Internal Server Error 服务器不支持当前请求所需要的某个功能。
      + 502 Bad Gateway 作为网关或者代理工作的服务器尝试执行请求时，从上游服务器接收到无效的响应
      + 503 Service Unavailable 由于临时的服务器维护或者过载，服务器当前无法处理请求。
