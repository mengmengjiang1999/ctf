重磅！安全狗容器安全、微隔离、云主机安全三款产品全线入围Gartner CWPP市场指南
2021-07-22 10:14:02

近日，国际专业咨询机构Gartner重磅推出2021年云工作负载保护平台（CWPP）市场指南（Market Guide for Cloud Workload Protection Platforms）。

作为国内云安全CWPP领导厂商，安全狗凭借综合且完善、强大的云工作负载解决方案，包含容器安全产品、微隔离产品、云主机安全产品在内，荣誉入选，是国内首家云工作负载安全三款产品入选的厂商。

Gartner作为全球最具权威的IT研究与顾问咨询公司，从1979年创建至今，已有40多年的专业服务积累，其研究范围覆盖全部IT产业。Gartner的研究与咨询服务一直被认为是客观技术思想领导的权威来源，例如美国国会要讨论有关推动当今经济的关键性商业及技术问题之前，它们会经常调用Gartner的分析员。其在安全领域的调查与研究结果，也成为国际风向标，影响各国安全行业的发展方向。

安全狗成立于2013年，自成立以来就致力于提供云安全领域相关产品、服务及解决方案，是国内最早引入云工作负载安全（CWPP）概念，并成功构建相应产品线的专业云安全厂商。

入选厂商名单部分截图

在此次2021年云工作负载保护平台（CWPP）市场指南（Market Guide for Cloud Workload Protection Platforms）报告中，Gartner也指出一些具有启发性的安全见解：

Occasionally, we still find enterprises using end-user-focused EPP offerings designed for desktops, laptops and tablets on server workloads. These are ill-suited to the requirements of dynamic hybrid, multicloud workload protection. The risk profile and threat exposure of a server workload is markedly different from that of an end-user-facing system. Enterprises that use an EPP offering designed for end-user-supporting devices are putting enterprise data and applications at risk. In contrast, CWPP offerings focus on the protection needs of server workloads in a modern hybrid (on-premises and cloud-based), multicloud (that is, using multiple public cloud IaaS providers) data center.

有时，我们仍然发现企业在服务器工作负载上使用专为台式机、笔记本电脑和平板电脑设计的以最终用户为中心的EPP产品。这些并不适合动态的混合云、多云的工作负载保护的要求。服务器工作负载的风险状况和威胁暴露情况与面向最终用户的系统明显不同。使用专为支持最终用户的设备设计的 EPP 产品的企业正在将企业数据和应用程序置于风险之中。 相比之下，CWPP 产品专注于现代混合（本地和基于云）、多云（即，使用多个公有云 IaaS 提供商）数据中心中服务器工作负载的保护需求。（翻译仅供参考）

The shift to cloud-native application development using container-based application architectures, microservices-based applications and adoption of serverless PaaS requires new CWPP capabilities both for development and at runtime. Cloud-native applications require specific solutions designed to address the protection requirements of cloud-based systems.

向使用基于容器的应用架构、微服务的应用以及无服务器 PaaS 的云原生应用发展的转变需要新的CWPP能力来进行开发及运行。云原生应用程序需要专门的解决方案来满足基于云的系统的保护要求。（翻译仅供参考）

从以上Gartner分析的内容可以发现，随着全球经济业务数字化的发展，企业数据和应用的安全稳定性也越发重要。为此，能在多种云环境中为企业数据中心服务器工作负载提供全面安全防护的CWPP在未来安全市场仍占有重要的一席之地。对于当下火热的云原生概念，Gartner也明确指出，CWPP解决方案需包含能覆盖开发及运行时安全的新能力。

此次安全狗入选的云工作负载安全解决方案系列产品，是安全狗根据实际的多种安全场景，结合近几年概念的演进和大量的安全实践所开发出来的，主要包含主机安全产品——云眼、微隔离产品——云隙、容器安全产品——云甲、补丁管理产品——云网等在内，其可以横跨物理服务器、公有云、私有云、混合云、容器等多种数据中心环境，部署方式更加灵活、防护层面更加丰富，可以实现高效维护云端工作负载安全目标等一系列的特点有优势，与Gartner团队的观点不谋而合。

领跑CWPP细分赛道

安全狗CEO陈奋凭借扎实的安全经验背景以及敏锐的商业嗅觉，早于国内其他厂商捕捉到CWPP的广阔市场需求并抢先做好充分的公司战略发展规划与部署。在其带领下，研发精英团队围绕CWPP概念打造的云工作负载产品矩阵及解决方案一一落地后，得到国内外权威专业机构授予的软著等资质证明，其全面且强大的云端负载保护能力先后为千行百业提供了突出的安全防护服务，还先后获得国内重大CWPP领域项目，如中国移动一期和中国移动二期、全国金融行业最大单等项目，安全实力广受用户认可。在与时俱进的技术深耕以及项目实践经验沉淀下，安全狗在CWPP细分赛道上占据领先优势，独占鳌头。

此次入选 Gartner 2021年云工作负载保护平台（CWPP）市场指南，不仅是对安全狗多年来深耕于CWPP领域获得阶段性成果的实力认可，更是为安全狗未来继续在这领域里精耕细作的一剂“强心针”。未来，安全狗将结合国家发展政策以及国内外技术发展趋势，继续扩大和巩固自身在国内云安全行业的领先优势，以市场需求为动向，坚持自主创新，驱动旗下产品的快速提升，积极发挥生态优势，以助力广大用户创造更大的价值，获得成功，为我国的数字经济转型贡献更多的力量！
