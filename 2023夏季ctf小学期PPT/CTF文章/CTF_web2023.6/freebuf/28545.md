mac如何简单的安装CobaltStike4.2
2021-01-23 10:23:58

简介cs

Cobalt Strike是一款美国Red Team开发的渗透测试神器，常被业界人内称为CS.自去年起， Cobaltstrike升级到3.0版本，脱离了MSF框架后在国内安全圈大火，成为了渗透测试中不可缺少的利器。 其拥有多种协议主机上线方式，集成了提权，凭据导出，端口转发，socks代理，office攻击，文件捆绑，钓鱼等功能。 同时，Cobalt Strike还可以调用Mimikatz等其他知名工具，因此广受黑客喜爱。 目前已是4.2版本 后门自测 项目官网:https://www.cobaltstrike.com

下载mac版本4.2

[CS4.2](链接: https://pan.baidu.com/s/1bS0IDydA8U9r08JRcaYL0w 密码: pihv)

解压到文件夹

下载好 cobaltstrike4.2-cracked.zip 解压，然后将下载好的汉化包 CobaltstrikeCN.jar 以及图标文件 cobaltstrike.icns 拷贝到同级目录下，最终的目录效果如下：

mac 的需要将两个文件拖到teamservice同级目录下

命令启动

1.1 在终端中 开启服务器
cd 你的解压缩文件切换到你的目录
chmod 775 teamservice给权限
./teamservice 192.168.1.3 admin启动 ip +密码

1.2 新建终端，我们打开客户端 要先进你的4.2目录
java -Xdock:icon=cobaltstrike.icns -Dfile.encoding=UTF-8 -javaagent:CobaltStrikeCN.jar -XX:ParallelGCThreads=4 -XX:+AggressiveHeap -XX:+UseParallelGC -jar cobaltstrike.jar
1.3 我们输入密码admin 就是刚才你在服务器设置的ip+密码 成功进入
用户名称随意就行。

制作APP

打开我们系统自带的auto（机器人）

将我们的命令贴进去
cd /Users/edison/Documents/CobaltStike4.2Mac && java -Xdock:icon=cobaltstrike.icns -Dfile.encoding=UTF-8 -javaagent:CobaltStrikeCN.jar -XX:ParallelGCThreads=4 -XX:+AggressiveHeap -XX:+UseParallelGC -jar cobaltstrike.jar
点击保存
此时已经制作好了，接下来我们换图片，在应用程序中找到，我们右键显示将图片拖过去就好了
