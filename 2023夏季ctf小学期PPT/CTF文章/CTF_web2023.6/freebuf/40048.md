AWS Marketplace 官网落地中国，宁盾上架多款产品助力企业身份安全
2020-01-14 16:26:34

AWS Marketplace官方网站 (https://awsmarketplace.amazonaws.cn/) 上周在中国全面落地。之前拥有有效AWS中国账户的用户可以通过 Amazon Elastic Compute Cloud (Amazon EC2) 控制台浏览 AWS Marketplace China 中的第三方软件。


AWS Marketplace China网站提供了更加友好的产品界面，其中包括了产品点评和更多学习资源以方便客户了解第三方软件产品，同时客户能够通过多个搜索筛选条件或关键词快速找到他们感兴趣的产品。登录到AWS中国账户后，使用“从网站启动”选项，只需几次点击即可快速部署Amazon 系统映像（AMI）产品；如果需要更多的配置选项，也可以使用Amazon EC2控制台启动产品。使用“您的Marketplace软件”菜单，可以轻松查看和管理订阅过的软件产品。用户还可以将产品收藏到他们最喜欢产品的列表中，方便后续查看。



作为入驻AWS Marketplace China的第一批ISV，宁盾上架了三款产品（以“nington”作为关键词搜索或者选择供应商为“宁盾”进行查看）：



多因素认证

为数据中心基础设施、网络层及应用层账号登录提供身份二次验证；

含APP令牌、硬件Token、短信令牌、邮件令牌、H5令牌、推送认证、企业微信/钉钉“扫一扫”免密认证等形式；

并兼容Google、RSA等第三方令牌；

覆盖网络设备、VPN、虚拟桌面、堡垒机、服务器、安全设备等，满足企业本地及云端全场景的账号登录保护需求。


WiFi认证

在网络接入层校验员工、访客、合作伙伴、外包人员等用户的身份；

提供短信、协助扫码、邮件审批、用户名密码、企业微信免密扫码等多种认证形式；

兼容多品牌异构无线有线网络设备，满足多分支统一认证需求；

实现统一身份认证和权限控制，确保企业入网合规。


单点登录

统一身份认证和单点登录门户，集成本地及云端的B/S、C/S应用；

实现用户一次认证即可访问权限范围内所有应用；

统一管理AD、LDAP、数据库、企业微信/钉钉等多账号源；

可配套多因素认证产品增强单点登录门户安全，无需部署多套系统；

可集成WiFi认证，当用户登录WiFi后，无需再验证身份即可进入应用门户，提升员工办公效率。


宁盾DKEY AM一体化身份管理平台


以上三款产品作为宁盾一体化身份管理平台（DKEY AM）的三大功能模块，帮助企业提升从基础设施到网络接入及应用层的统一身份管理及安全访问控制。借助AWS Marketplace，宁盾DKEY AM能实现即插即用、云端快速部署，从而助力企业的云和移动化发展。


了解更多产品请访问AWS Marketplace China网站或可参阅AWS Marketplace China常见问题了解更多信息。

了解宁盾更多产品信息或需购买宁盾AMI软件产品授权，请直接拨打热线400-658-2855或访问官网www.nington.com咨询。
