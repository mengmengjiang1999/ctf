什么是 IP SSL 证书，如何申请？
2022-07-19 15:29:06

SSL证书通常是颁发给域名的，但是有些企业没有域名只有 IP，或者不方便使用域名，IP 地址要实现https加密，这时可申请IP SSL证书。下面将从IP SSL证书的作用、申请条件和申请流程三个方面来让您详细了解 IP SSL证书。

申请IP SSL证书有什么好处呢？

1、用 IP SSL证书可以很好地防流量劫持；

2、IP 地址比域名复杂，不容易记忆，有了企业型IP SSL证书，可以有效提高IP的身份辨识度，减少被假冒的风险；

3、公网 IP 能直达设备，应用更广。

申请IP SSL证书要满足的条件：

1、只能是公网IP；

2、申请者必须有该IP的管理权限；

3、只可以申请单个IP或多个IP绑在一起的SSL证书，不支持IP段通配符证书。

IP SSL证书的类型

IP SSL证书分为基础级 IP SSL证书（DV）和标准企业级 IP SSL证书(OV)。


基础级 IP SSL证书是适合对 IP 具有管理权限的个人申请，仅能实现对网站信息实现 HTTPS 加密，防止信息被窃取、监听或篡改。


标准企业级 IP SSL证书进公司或组织可以申请，个人无法申请，同时申请者也必须对 IP 具有管理权限。标准企业级 IP SSL证书除了具备基础级 IP SSL证书的作用外，还可以验证网站身份，防止钓鱼网站假冒，同时提高企业形象，增加用户安全感。

申请 IP SSL证书的流程

1、进入沃通官网产品中心IP SSL证书申请入口，选择合适的 IP SSL证书，DV 或 OV，提交订单；

2、生成 CSR 文件和 Key，下载 CSR 文件和 Key 并保存在安全的位置；

3、配合完成验证；

DV型 IP SSL证书的验证方式：验证 IP 管理权限，上传指定验证文件到网站根目录（通过 80 或 443 端口验证，如果您不能开放 80 或 443 端口）。一般 30 分钟就可完成验证。

OV型 IP SSL证书的验证方式：除了上述 DV 型 IP SSL证书的验证方式外，还要验证公司真实性，以电话或邮件方式进行企业审核。1-3 个工作日可完成验证。

4、获取 IP SSL证书，部署到服务器上。

以上就是为 IP 地址申请SSL证书，实现 IP地址的 HTTPS 加密的全过程。有任何关于SSL证书的疑问，均可私信联系我们。
