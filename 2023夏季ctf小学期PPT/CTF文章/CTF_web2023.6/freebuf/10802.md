亚马逊云科技发布十大最受中国出海企业青睐的云服务
2022-05-23 21:37:47

北京2022年5月23日 /美通社/ -- 2022年5月23日，亚马逊云科技根据中国出海企业海外使用云服务的情况，发布了十大最受中国出海企业青睐的亚马逊云科技服务榜单。榜单显示，计算、存储、网络三大基础设施类服务是出海企业的首选，包括弹性计算云服务器Amazon Elastic Compute Cloud (Amazon EC2)、内容分发网络服务Amazon CloudFront和对象存储服务Amazon Simple Storage Service (Amazon S3)；同时，出海企业广泛选择亚马逊云科技"专门构建"的数据库和数据分析服务，其中Amazon Aurora是出海企业最青睐的数据库服务。此外，从出海企业海外使用亚马逊云科技服务的增速看，出海企业正加速推动"云边一体"， Amazon Outposts增速最快； AI/ML类服务的增速也非常显著。

夯实基础架构，出海企业首选亚马逊云科技计算、存储、网络基础设施服务三大件

出海企业无论所属行业以及规模大小，均希望通过上云建立起全球统一的业务部署，满足不同地区业务随时的变化和需求，稳定、持久以及可根据业务需求自动伸缩的云基础设施服务毫无意外的成为出海企业首选的亚马逊云科技服务。亚马逊云科技云基础设施在全球的广泛覆盖，以及基础设施类服务的稳定性、可靠性和安全性，是出海企业选择亚马逊云科技的重要原因。

根据亚马逊云科技的数据显示，计算服务Amazon EC2最受中国出海客户青睐。Amazon EC2是亚马逊云科技最早提供的云服务之一，16年以来为满足客户多样性的算力需求，亚马逊云科技对这一底层基础技术持续迭代创新。通过打造创新的云服务器虚拟化引擎Amazon Nitro，亚马逊云科技不但为客户提供更高的计算和网络性能，也确保了Amazon EC2的更快创新。目前亚马逊云科技提供多达475种计算实例选择，跨越多种云端处理器架构，包括基于x86架构的Intel和AMD处理器，并根据云上工作负载推出基于ARM架构的自研芯片Amazon Graviton，满足几乎所有工作负载和业务的需求。

除Amazon EC2服务之外，出海企业为解决全球客户需求以及构建全球化网络，网络类服务也非常受他们的青睐。其中Amazon CloudFront以低延迟、高传输速度向全球客户安全分发数据、视频、应用程序和 API；Elastic Load Balancing可在多个 Amazon EC2 实例间自动分配应用程序的访问流量，Amazon Direct Connect可以在本地和亚马逊云科技区域之间轻松建立专用网络连接。

存储类服务Amazon S3也是很多出海企业的选择。Amazon S3是亚马逊云科技最早提供的云服务之一，时至今日这一经典的存储服务仍在不断进化和完善中。它具有业界领先的可扩展性、数据可用性、安全性和性能，以及99.999999999% (11 个 9) 的持久性，作为云上存储的事实标准，得到业界广泛的兼容性认可。如今，Amazon S3存储的对象数量已经超过 200 万亿，每秒需要处理数千万个请求。

借助亚马逊云科技"专门构建"的大数据服务驱动业务成长，Amazon Aurora成出海企业最青睐的数据库服务

越来越多的企业欲借助云服务建立起数据驱动的业务创新能力，但出海企业却面临着管理分散在全球各地的业务、实现数据整合和统一管理等诸多挑战。为加快获得数据洞察，出海企业希望能在云上建立全球统一的数据平台，在获得高性能的同时减轻数据库运维负担并降低运维成本。

出海企业的这一诉求也反映在十大最受中国出海企业青睐的亚马逊云科技服务榜单上，其中数据库、数据分析类服务就占据了四个席位，包括专为云平台打造的关系型数据库Amazon Aurora、托管式关系数据库服务Amazon Relational Database Service (Amazon RDS)、内存数据库服务Amazon ElastiCache、键/值数据库服务Amazon DynamoDB，以及支持对 PB 级日志分析和对文本和非结构化数据进行搜索、可视化和分析的Amazon OpenSearch Service。

为了满足客户不同的数据库、数据分析需求，同时客户在使用过程中不必在性能、规模或成本之间做出妥协，亚马逊云科技提供全面而深入的、专门构建的大数据服务。其中，Amazon Aurora 凭借其在性能、成本以及跨区域灾难恢复等诸多优势获得出海企业的认可，成为出海企业最青睐的数据库服务。作为目前亚马逊云科技历史上用户数量增速最快的云服务，Amazon Aurora既具有传统商业数据库的高性能和可用性，又具有开源数据库的简单性和成本效益。此外，Amazon Aurora Global Database集群可跨越多个地理区域，跨区域数据复制延迟通常不超过1 秒；在发生区域级业务系统中断时，通常不超过1 分钟可实现跨区域灾难恢复，致力于在最大限度上确保客户全球业务的连续性，还可以贴近各地终端用户，降低访问延迟，提高客户体验。

加速推动"云边一体"，出海企业使用Amazon Outposts的增速最快

随着数字化创新和转型的大潮从互联网等领域向越来越多传统行业渗透，如车联网、智能工厂、医疗保健等行业，越来越多企业或有很多边缘的负载工作场景，或既有本地也有云上混合的工作负载。这些企业希望能打通本地和云上的工作负载，得到更多洞察，同时还能简化运营的复杂性，获得一致的混合体验。出海企业 "云边一体"的诉求，促使他们正加速采用Amazon Outposts，将云计算能力延伸到本地以及各种边缘场景中，如支持制造过程的控制系统、在设备附近运行机器人应用程序、在边缘环境运行医疗保健关键应用等。

亚马逊云科技数据显示，出海企业在海外使用的亚马逊云科技服务中，Amazon Outposts增速最快。Amazon Outposts是运行在企业本地的亚马逊云科技基础设施和服务，它拥有跟亚马逊云科技数据中心里相同的软件、硬件、API接口。Amazon Outposts让出海企业获得本地与云上一致的亚马逊云科技服务体验，包括更稳定的网络连接，更低的网络延迟，同时减轻运营负担，降低成本。在一些需要本地保存数据的合规场景，Amazon Outposts还可以帮助企业灵活应对海外国家和地区的合规要求。

AI赋能创新，出海企业采用AI/ML服务增速显著

人工智能、机器学习技术日渐普及，出海企业都希望能够加快利用人工智能、机器学习技术打造智能产品及其增值服务、为各地区提供本地化和个性化的服务体验以及实现自身业务流程智能化。出海企业需要在最大限度减低成本和开发周期基础上，实现AI应用的快速上线。

亚马逊云科技的数据显示，出海企业采用AI/ML类服务增速显著。借助亚马逊云科技开箱即用的人工智能类服务，出海企业可加速AI应用的上线，如使用深度学习技术将文本转换为众多语言语音的 Amazon Polly、使用机器视觉服务进行物体识别及图像审核等增值服务的 Amazon Rekognition、推荐系统 Amazon Personalize、多国语言翻译 Amazon Translate、从扫描文档提取表单和表格中的文本和数据的 Amazon Textract等。此外，出海企业还广泛使用亚马逊云科技完全托管的机器学习服务Amazon SageMaker，消除了机器学习过程中的繁重工程工作，让开发高质量模型变得更加轻松，确保了出海企业持续提升打造智能化场景和平台的能力。

截至目前，亚马逊云科技提供超过200大类广泛而深入的云服务，凭借引领行业的安全合规理念和实践，覆盖全球的基础设施，全球超过十万家合作伙伴网络成员的解决方案，服务中国出海企业十余年所积累的成熟和丰富的客户实践，以及亚马逊全球业务体系的强大支撑，亚马逊云科技将助力更多的出海企业加快海外业务的数字化转型和创新。
