华云安漏洞安全周报【第123期】
2023-03-10 10:33:26

根据国家信息安全漏洞库（CNNVD）统计，本周（2023.02.20~2023.02.26）CNNVD接报漏洞209个，其中信息技术产品漏洞（通用型漏洞）122个，网络信息系统漏洞（事件型漏洞）87个，CNNVD接报漏洞预警146份，其中华云安报送预警13份！预警报送数量均持续位居前列！

本周重点关注漏洞包括：CVE-2023-25613 Apache Kerby 注入漏洞、CVE-2023-20858 VMware Carbon Black App Control 安全漏洞、CVE-2023-25693 Apache Airflow 输入验证错误漏洞、CVE-2023-25956 Apache Airflow 安全漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2023-25613 Apache Kerby 注入漏洞

威胁等级：超危

漏洞描述：

2022年02月20日，华云安思境安全团队监测发现 Apache 官网发布了安全更新，披露了Apache Kerby 2.0.3之前版本存在注入漏洞 。Apache Kerby 是一个 Java Kerberos binding，提供了丰富、直观和可互操作的实现。未经身份验证的攻击者可构建特制代码利用该漏洞导致LDAP 注入。

情报来源：

https://lists.apache.org/thread/ynz3hhbbq6d980fzpncwbh5jd8mkyt5y

02CVE-2023-20858 VMware Carbon Black App Control 安全漏洞

威胁等级：超危

漏洞描述：

2023年02月21日，华云安思境安全团队监测发现 VMware 官网发布了安全更新，披露了 VMware Carbon Black App Control 8.7.8（8.7.x）之前版本、8.8.6 （ 8.8.x ）之前版本和 8.9.4 （8.9.x.）之前版本存在安全漏洞。VMware Carbon Black App Control是 VMware 的一款应用允许列表解决方案，用于锁定服务器和关键系统，防止不必要的更改。未经身份验证的攻击者构建特定语法可利用该漏洞访问底层服务器操作系统。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2023-0004.html

03 CVE-2023-25693 Apache Airflow 输入验证错误漏洞

威胁等级：超危

漏洞描述：

2023年02月24日，华云安思境安全团队监测发现 Apache 官网发布了安全更新，披露了 Apache Airflow Sqoop Provider 3.1.1之前版本存在输入验证错误漏洞。Apache Airflow 是一个由开源社区维护的，专职于调度和监控工作流的 Apache 项目，主要用于调度和监控工作流。未经身份验证的攻击者可以通过该漏洞从中获取到包含敏感信息的错误消息。

情报来源：

https://lists.apache.org/thread/79qn8g5xbq036f8crb115obvr22l52q4

04CVE-2023-25956 Apache Airflow 恶意代码执行漏洞

威胁等级：高危

漏洞描述：

2023年02月24日，华云安思境安全团队监测发现 Apache 官网发布了安全更新，披露了 Apache Airflow AWS Provider 7.2.1之前版本存在安全漏洞。Apache Airflow 是一个由开源社区维护的，专职于调度和监控工作流的 Apache 项目，主要用于调度和监控工作流。未经身份验证的攻击者可以配置 lib_jars 字段的攻击者上传恶意 jar 文件远程执行恶意代码。

情报来源：

https://lists.apache.org/thread/07pl9y4gdpw2c6rzqm77dvkm2z2kb5gv
