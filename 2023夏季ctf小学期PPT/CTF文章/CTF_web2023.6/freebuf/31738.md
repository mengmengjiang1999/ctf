# 国家密码管理局组织开展2020年商密抽查

关键词：国家密码管理局、商用密码、抽查

近期，国家密码管理局组织对电子认证服务机构密码使用情况、电子政务电子认证服务机构业务开展情况进行随机抽查，并将依法查处违法违规行为。以规范电子认证服务密码使用、电子政务电子认证和政务活动中使用电子签名、数据电文管理，全面提升商用密码服务保障能力。

# 信安标委举办2020年第二次工作组“会议周”

关键词：信安标委、网络安全国家标准、会议

为落实2020年全国信息安全标准化技术委员会（以下简称“信安标委”）工作要点，加快推进网络安全国家标准研究和制修订工作，信安标委秘书处将于2020年11月8日—14日举办2020年第二次工作组“会议周”活动。

本次“会议周”活动采取线上线下结合的形式举办。

# 等级保护2.0与可信计算3.0攻关示范基地正式启动

关键词：等级保护、可信计算

2020年10月28日，攻关示范基地启动会暨揭牌仪式在北京工业大学隆重召开。国家网络安全等级保护制度2.0与可信计算3.0攻关示范基地的成立，旨在组织国内产、学、研、用各领域单位，开展等级保护2.0和可信计算3.0联合攻关、适配测试和应用示范等工作，加速促进国家等级保护2.0要求的落地和推广。

# 国家网信办对手机浏览器进行专项整治

关键词：网信办、浏览器、整治

为有效解决网民反映强烈的手机浏览器网络传播乱象，国家网信办即日起对手机浏览器进行专项集中整治，集中整治将多措并举、标本兼治，着力解决三大突出问题： 一 是发布“自媒体”违规采编的各类互联网新闻信息，如歪曲解读经济民生政策、散布“小道消息”、传播谣言信息、翻炒旧闻编造“新闻”等； 二是发布“标题党”文章，如恶意浮夸、“唱衰”“卖惨”、冒名炒作等； 三是发布违背社会主义核心价值观的不良信息，如传播低俗图文视频、炒作明星绯闻隐私和娱乐八卦等。

UC、QQ、华为、360、搜狗、小米、vivo、OPPO等8款影响力较大的手机浏览器被纳入首批重点整治范围。

# 工信部通报第五批131款侵害用户权益行为APP

关键词：APP、整治、侵权

近期，工信部组织第三方检测机构对手机应用软件进行检查，督促存在问题的企业进行整改。截至目前，尚有131款APP未完成整改，上述APP应在11月2日前完成整改落实工作。

此次检测中，输入法类、旅游出行类、电商类、音视频类等APP检测发现问题较多，部分应用商店及移动应用分发平台管理主体责任缺位，SDK企业存在违规收集用户个人信息的行为。后续我部将对问题突出、有令不行、整改不彻底的相关企业，采取全面下架、停止接入、行政处罚以及纳入电信业务经营不良名单或失信名单等措施，依法严厉处置。

# 教育部：网络安全等16个领域纳入国家安全教育

关键词：教育局、网络安全、国家安全教育

从教育部获悉，为深入学习贯彻总体国家安全观，结合教育系统实际，教育部2020年9月印发了《大中小学国家安全教育指导纲要》。指导纲要指出，国家安全教育要实现全领域、全学段覆盖，相关内容纳入不同阶段学生学业评价范畴，且纳入大中小学生综合素质档案。

指导纲要指出，网络安全的主要内容包括网络基础设施、网络运行、网络服务、信息安全等方面，是保障和促进信息社会健康发展的基础。维护网络安全必须践行“没有网络安全就没有国家安全，没有信息化就没有现代化”的理念，强化依法治网、技术创新、国际合作等，树立网络空间主 权意识。

# 美国医疗系统遭“史上最严重网络安全威胁”

关键词：勒索软件、医院、医疗服务

FBI和美国其他两个联邦机构在周三的联合警报中警告称，他们有“威胁到美国医院和医疗服务商的网络犯罪的可靠信息”。恶意网络参与者正在使用勒索软件瞄准医疗行业，这可能导致数据被盗及医疗服务中断。

美国网络安全公司麦迪安首席技术官查尔斯卡玛卡在一份声明中表示：“我们正在经历美国有史以来最严重的网络安全威胁。”他担心犯罪分子可能在接下来的几周内向数百家医院部署恶意软件。
