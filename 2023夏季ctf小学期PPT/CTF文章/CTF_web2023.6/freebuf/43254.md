DJI大疆创新诚聘各类信息安全岗位
2019-08-21 12:00:24

深圳市大疆创新科技有限公司（简称“DJI 大疆创新”），总部位于中国深圳，在北京、上海、西安设有专业研发中心。

大疆以“The Future of Possible（未来无所不能）”为主旨理念，致力于成为全球飞行影像系统先驱。2006年创立至今，全球员工人数超过12,000人，客户遍布全球百余个国家和地区。

技术创新是大疆的立足之本。从飞行控制系统起家，大疆凭借稳定高效的消费级和专业级的航拍飞行平台为人熟知，并将技术移植到地面增稳设备，实现“天地一体”的拍摄解决方案。十二年间，DJI大疆创新不断革新技术和产品，开启了全球飞行影像新时代；我们的产品应用在影视、农业、地产、新闻、消防、救援、能源、遥感测绘、野生动物保护等多个领域，重塑了人们的生产和生活方式。

大疆也极其注重文化的锤炼、塑造和输出，推崇“尊重梦想、追求纯粹”的价值观，力图以梦想为源动力，开辟创新、拼搏、极致的创作净土，吸引和影响更多的人。如果你志存高远、怀揣梦想，决心踏实做事、创造价值，那就加入DJI吧！在这里，与更多真知灼见者碰撞，与更多志同道合者同行！


热招岗位

【信息安全架构师】 30-50k

工作职责

1. 负责设计公司信息系统安全框架，组织各部门开展相应的信息安全建设；

2. 建设和优化安全响应机制，担当安全战备值班负责人；

3. 制定各类安全技术标准和规范，主导或参与信息安全前沿技术预研。

任职要求

1. 本科以上学历，5年以上信息安全从业经验，信息安全各领域知识全面，在多个领域有实战经验；

2. 熟悉各类信息安全攻击技术原理和常见的实施手段；

3. 优秀的组织、协调能力；强大的执行力，结果导向，热爱技术钻研。

【渗透测试工程师（Web渗透方向）】20-40k

工作职责

1. 负责核心业务及产品的黑、白盒方式的渗透测试工作；

2. 负责安全应急响应，指导开发工程师快速修复漏洞；

3. 负责公司业务相关的 Web 安全技术研究；

4. 对业界最新漏洞进行分析及响应。

任职要求

1. 本科及以上学历，3年以上安全领域渗透测试从业经验，在大型互联网公司安全部门任职2年以上优先；

2. 熟悉主流系统、网络、Web 漏洞攻击原理、检测绕过、安全防护方案；

3. 熟练使用包括但不限于 Java/PHP/Ruby/C# 等语言，能独立完成源码审计和漏洞挖掘；

4. 在各大公司 SRC、freebuf、漏洞盒子、乌云等平台上，发表过有独到见解、技术创新、思路创新的漏洞或文章、知名 CTF 比赛中成绩靠前者优先；

5. 具备良好的沟通能力和团队协作能力，热爱安全工作且有职业素养。

【渗透测试工程师】20-40k

工作职责

1. 负责核心业务及产品的黑、白盒方式的渗透测试工作；

2. 负责安全应急响应，指导开发工程师快速修复漏洞；

3. 负责公司业务相关的 Web 安全技术研究。

任职要求

1. 本科及以上学历，2年以上的安全领域渗透测试从业经验；

2. 熟悉常见的web安全漏洞，如XSS、XXE、SQL注入，webshell上传等的原理，具备独立挖掘和利用常见web漏洞的能力；

3. 熟悉安卓app的运行原理，熟悉常见的app安全漏洞，能够独立完成对app的静态分析和动态调试；

4. 对业界已知安全漏洞PoC有调试分析的经验，例如：Struts2命令注入、Commons-beanutils反序列化等。

5. 熟练掌握一种或几种脚本语言，能编写相应的安全脚本工具；

6. 有很强的执行力，面对技术困难不轻易放弃，对安全技术有热爱。

【安全运营工程师】20-40k

工作职责

1. 负责安全工具运营，包括策略配置、效果验证、数据分析等；

2. 负责漏洞管理，跟进项目组漏洞修复的进度，并对相关数据进行分析；

3. 负责收集业务安全需求，制定并优化安全规则与策略，不断完善各类安全业务场景；

4. 参与内部安全制度及流程建设工作。

任职要求

1. 本科及以上学历，1年以上安全领域从业经验；

2. 具备 Python、Ruby、Java 等任一语言的开发经验；

3. 熟悉常见的 Web 安全漏洞和安全攻防，熟悉入侵检测、WAF、IDS、蜜罐等安全防护手段；

4. 熟知 《GDPR》、《个人信息安全规范》、《信息安全等级保护管理办法》等信息安全相关的政策法规；

5. 有安全和网络相关证书，如CISSP、CISA、CISP 、CCNP、CCIE等认证者优先；

6. 具备良好的沟通能力和团队协作能力，文档撰写能力强，有较强的责任心、事业心、抗压能力。

【信息安全工程师（终端安全软件开发方向）】20-40k

工作职责

1. 负责Linux或Mac OS客户端安全软件（如MDM、NAC、桌管、透明加密等软件）的开发；

2. 负责客户端功能模块设计、开发及优化；

3. 负责关键安全技术的预研。

任职要求

1. 本科及以上学历，3年以上开发经验；

2. 熟悉C++语言开发，有Android平台开发经验者优先；

3. 熟悉Windows或Linux或Mac OS核心编程，有跨平台开发经验优先；

4. 具备钻研精神，有良好的学习能力。

【信息安全工程师（后台开发）】20-40k

工作职责

1. 负责各系统的维护和开发工作;

2. 负责新系统的需求分析，方案设计及实现，输出技术文档；

3. 负责系统的部署，性能优化等工作。

任职要求

1. 熟练使用Python、Java开发，具备三年及以上的相关开发经验；

2. 熟悉Flask/Django/Tornado、SpringBoot，SpringMVC等常用的开发框架；

3. 熟悉使用Mysql数据库及调优能力，了解Redis、MongoDB；

4. 熟悉Linux/Unix环境、熟悉TCP/IP、HTTP/HTTPS等通信协议；

5. 熟悉Web安全、移动安全，了解相关漏洞以及测试工具；

6. 熟悉NodeJs，PHP开发者优先考虑；

7. 熟悉分布式、缓存、消息、负载均衡实现者优先考虑。
