变量覆盖

定义

变量覆盖指的是可以用我们的传参值替换程序原有的变量值。

风险

变量覆盖可以让我们修改某些关键变量的值，可能造成越权访问、写入webshell等危害。

造成未授权访问的案例：Joomla未授权访问漏洞(CVE-2023-23752)



变量覆盖的场景

肯能造成遍历覆盖的方法：

  * extract()

  * parse_str()

  * $$

  * mb_parse_str

  * import_request_variables()

  * register_globals

  * array_merge


extract()函数

extract()函数用来将变量从数组中导入到当前的符号表中。

例如


<?php
$a="testname";
$my_array=array("a"=>"C","b"=>"l", "c"=>"F");
extract($my_array);
echo"\$a = $a; \$b = $b; \$c = $c";
?>
​
输出：
$a=C; $b=T; $c=F

parse_str()函数

parse_str — 将字符串解析成多个变量

使用例子


<?php
$str="first=value&arr[]=foo+bar&arr[]=baz";
​
// 推荐用法
parse_str($str, $output);
echo$output['first']; // value
echo$output['arr'][0]; // foo bar
echo$output['arr'][1]; // baz
​
// 不建议这么用
parse_str($str);
echo$first; // value
echo$arr[0]; // foo bar
echo$arr[1]; // baz
?>



如果在parse_str中可以直接传参，也可以覆盖变量


<?php
$name="tom";
parse_str("name=Bill&age=60");
echo$name."<br>";
echo$age;
?>


注意：

7.2.0 以后不带第二个参数的情况下使用 parse_str() 会产生 E_DEPRECATED 警告。所有创建的变量(或者在设置第二个参数的情况下，返回数组里的值)， 都已经 urldecode() 了。

$$

$$产生的漏洞主要是因为foreach遍历数组的值，然后将获取的数组键名作为变量，数组中的值作为变量的值。

foreach循环只适用于数组，并用于遍历数组中的每个键/值对。


<?php
$colors=array("red","green","blue","yellow");
​
foreach($colorsas$value) {
echo"$value<br>";
}
?>
输出:
red
green
blue
yellow




$$类似于套娃。


<?php
$var="ee";
$$var="eeknight";
echo$var;
echo"<br>";
echo$$var;
echo"<br>";
echo"$ee";
?>
输出：
ee
eeknight
eeknight

php.ini的配置register_globals

register_globals字面意思是注册全局变量

当php.ini中register_globals=On时，传递过来的值会被直接注册为全局变量，当为off时，需要到特定的数组中去得到。PHP 4.2.0 版开始配置文件中 register_globals 的默认值从 on 改为 off 了。

例子，检测register_globals是否开启


<?php
echo"Register_globals: ".(int)ini_get("register_globals")."<br/>";

if($auth){
echo"hello!";
}
?>


在php.ini中开启

array_merge覆盖数组键

如果输入的数组中有相同的字符串键名，则该键名后面的值将覆盖前一个值。

<?php

echo "变量覆盖<br>让public的值变为true<br>";

$query = $_GET;

$arr = array("public"=>false, "name"=>'张三');
// 对数组中的键值进行变量覆盖

// 漏洞修复
// Remove the public key as it is only supported coming from the route definition
/*
if (array_key_exists('public', $query)) {
	unset($query['public']);
}
*/

// 如果输入的数组中有相同的字符串键名，则该键名后面的值将覆盖前一个值。
$query = array_merge($arr, $query);
if ($query["public"] == true)
{
    echo "bypass!!!<br/>";
    var_dump($query);
}
else
{
    echo "try again<br/>";
    var_dump($query);
    exit(0);
}
/**
 * payload: ?public=true
 */

?>


附加说明

 1. parse_str()

    php.ini文件中的magic_quotes_gpc设置影响该函数的输出。如果已启用，那么在parse_str()解析之前，变量会被addslashes()转换。

 2. import_request_variables()

    该函数在最新版本的 PHP 中已经不支持。

    支持的版本：PHP 4 >= 4.1.0, PHP 5 < 5.4.0。

 3. register_globals

    register_globals从php5.3.0起废弃，并从php5.4.0时移除。


漏洞防御

 1. addslashes()

    addslashes()在每个双引号（"）前添加反斜杠。

 2. 使用原始变量，不进行变量注册；

 3. 验证变量存在，如果一定要进行变量注册，可以在注册变量前先判断变量是否存在。
