巴斯夫中国数字中心-招聘岗位
2023-02-28 15:21:50

德国领先的全球化工公司-巴斯夫中国数字中心正在寻找新的网络安全人才。巴斯夫中国数字中心是巴斯夫在全球范围内的第二个专门成立的数字中心，也是在亚洲的第一个数字中心，重申其在巴斯夫发展的承诺。。

如果你对国际化的工作氛围、前沿的技术和灵活的工作安排感兴趣，请查看以下公开职位。

威胁情报高级专家(Senior Specialist, Threat Intelligence)

工作职责：

- 确定情报要求，并将所有利益相关者整合到威胁情报办公室威胁共享社区中。

- 发展并支持与外部利益相关者和合作伙伴在共享事件和威胁信息方面的关系。

- 收集，分析并向高级管理层和其他关键利益相关者传播威胁情报。

- 提供口头简报，视觉演示和书面报告，包括已识别威胁的可能性和影响。

- 收集、分析和传播技术指标，增强检测和保护能力。

- 与事件响应团队密切合作，加强分析并提供更多背景信息。

- 设计，开发和交付项目，以提高情报能力，资源，技能和外展能力。

- 为威胁参与者创建并向所需的利益相关者提供个人威胁配置文件。

- 管理情报供应商的提要和报告，并评估其绩效。

- 根据威胁情报和其他附加信息执行预测性安全分析。

任职要求:

- 应用IT，计算机科学或类似技术学徒学位

- 4年以上网络安全/威胁情报专业经验

- 网络高级持续性威胁、参与者、基础设施和 TTP 方面的高级知识

基础设施和网络，包括协议、已知端口和服务

- 以下安全相关技术：IPS、IDS、SIEM、防火墙、DNS、加密、HIDS、NIDS、代理、漏洞管理和企业级设备。

- 首选产品相关知识：ThreatQ平台和MISP

- 有条理，注重细节，具有较强的多任务处理能力

首选认证：GCTI（GIAC 网络威胁情报）或 CTIA（认证威胁情报分析师）和 ISC2 CISSP（认证信息系统安全专业人员

网络隔离高级专家(Senior Specialist Network Segregation)

工作职责：
- 咨询和客户支持
- 支持团队内的初级和系统工程师，以及其他产品团队
- 负责大中型企业安全环境中复杂IT系统（硬件/软件）的设计、构建、配置和运行
- 管理全球、区域和本地 IT 基础设施项目的端到端交付和变更请求
- 负责外部服务提供商的业务导向和运营管理，包括
o 在运营层面引导承包商
o 培训供应商以及相关人员
- 在您的专业领域设计，引入和优化运营流程和服务
- 与内部专家单位密切合作，监控SLA，KPI，OLA的遵守情况，并确保服务履行的文件和质量保证
- 服务文档、设计和规划

任职要求:
- 商业IT学士学位（大学，文学学士，应用科学大学），信息技术大学学位（大学，文学学士，应用科学大学）
- 至少5年以上的大中型企业环境中的安全运营工作经验
- 对云和内部部署环境中的防火墙安全基础设施以及底层安全技术有很好的了解
- 在实施和操作防火墙安全解决方案方面经验丰富，包括必要的流程和指南
- 体验脚本和自动化目的的编程语言（Javascript，Python等）
- 在TCP / IP，TLS和HTTP的高级协议知识方面具有高度发达的知识，并且在网络和服务器管理方面具有非常强大的背景，在大型企业环境中具有很强的安全重点

高级专家，网络安全架构(Senior Specialist, Cyber Security Architecture)

工作职责：
- 与所有战略业务领域协商，就安全要求的评估提供建议
- 支持安全标准的制定，这些标准适用于IT和产品系列的所有技术。
- 负责安全项目的启动，并在这些项目中扮演专业看守的角色。
- 在IT组织内积极开展知识交流和跨团队合作。与不同的内部利益相关者和社区进行沟通和协调，以提高解决方案设计过程中的安全意识，并为业务战略增加价值。
- 引导供应商确保符合巴斯夫的安全要求；此外，对安全漏洞和偏差进行升级和解决。
- 积极参与同事的行业网络，讨论特殊主题和发展。将这些讨论的结果纳入他/她的评估。
- 参与与外部机构和社区的关系管理（例如，政府机构、当局、新闻界）。
- 制定和评估减少已确定的安全风险的措施，这些措施是由未来的威胁所构成的。
- 评估通过安全技术改进业务和创新的可能性；将其纳入战略业务要求
- 评估各种创新技术，并参考商业环境中的安全问题（例如，物联网、大数据和网络安全分析、云）。
- 对不同的内部利益相关者和倍增者的安全战略的应用和建议

任职要求:

- 完成IT领域（商业信息学、工业工程、计算机科学、IT安全、数学）的硕士学位或类似学位
- 至少有5年的类似岗位工作经验
- 理解力快，有较强的概念和分析能力，有解决实际情况的意识
- 具有较强的IT/OT安全技术知识和基础知识，如：网络分段、防火墙、终端安全、异常情况检测等
- 网络安全架构和咨询
- 希望了解零信任原则
- 对中国网络安全解决方案的了解
- 评估和实施新的网络解决方案
- 熟悉通用安全标准者优先，如NIST、ISO27000等

网络安全, 漏洞管理(Cyber Security, Vulnerability Management)

工作职责：
- 你将负责日常执行我们为巴斯夫组织提供的中央漏洞管理和修复服务。这包括跟踪和协调所有修复活动。
- 你的部分工作将是报告关键指标，以了解业务部门如何遵守安全要求，并了解流程的运行情况。
- 你将负责新范围的漏洞管理扫描服务的入职工作，并不断寻求改善和成熟的服务。
- 你将与第三方供应商进行联络，并建立/保持良好的工作关系。
- 作为我们CISO组织的一部分，你将与网络安全防御中心、安全治理以及我们的IT运营单位紧密合作。

任职要求:

- 你有至少1-3年的漏洞管理或其他相关网络安全领域的经验
- 你有支持攻击面管理（ASM）工具和流程的经验，包括与漏洞管理、GRC和升级管理的整合
- 你可以在一个多国/全球团队中独立工作，并带来结构化、分析性、注重质量的方法
- 您已经完成了（商业）信息学的大学/技术学院相关学科的学位，或通过多年的相关专业经验和进一步培训获得的同等知识和技能。
- 如果有公认的证书，如CISSP、CISM、CRISC、CISA或其他证书，将是一个很好的证明。
- 在信息安全管理方面有实践经验，对相关规范和标准有了解。
- 你有很好的沟通能力，能够与整个巴斯夫的利益相关者保持一致并进行沟通。
- 流利的英语语言能力

网络安全（事件响应者）(Cyber Security (Incident Responder))

工作职责：

- 您将成为巴斯夫集团网络防御团队中积极进取、技术娴熟的DFIR专家团队的一员
- 完成安全事件分类、分析、解决和关闭的技术方面，专注于复杂事件和高风险事件。
- 您执行数字调查和取证分析。
通过应用分析结果来改善安全控制和运营流程，以提高巴斯夫的整体安全成熟度水平。
- 此外，请您主动为我们的侦查和预防性安全监控提供建议/开发用例，以检测巴斯夫企业网络内的可疑活动。
- 作为安全专家社区的一员，您将与巴斯夫集团的其他运营部门密切合作。
- 深入了解用于事件分析的各种开源和商业分析工具，包括基于网络和主机

任职要求:

- 应用IT，计算机科学或类似技术学徒学位
- 4年以上网络安全/网络防御专业经验
- 对微软Windows和Linux等主流操作系统的原理和结构的高级知识
- 能够用以下至少一种编程语言进行编程：C，PERL，Python，Assembly（x86，x64）和常见的UNIX shell

IT安全顾问(IT Security Consultant)

工作职责：

- 我们的网络合规管理团队负责评估、验证和报告巴斯夫应用程序和IT解决方案的网络安全合规状态。
- 你将负责检查技术规范和/或实施是否符合我们内部安全规则集的要求。
- 与我们的合作伙伴一起检查最佳实践、标准解决方案，并与他们的安全控制实施进行比较。
- 确定必要的措施来改善安全相关的解决方案，使其符合巴斯夫的标准/要求。
- 作为CISO组织的一部分，你将与安全治理、安全架构、风险管理和补救团队紧密合作

任职要求:

- 你至少有4-5年的ISO 27001和内部安全规则集的经验
- 你可以在一个跨国/全球团队中独立工作，并带来结构化、分析性和注重质量的方法。
- 你已经完成了（商业）计算机科学方面的大学/技术学院学位，或通过多年的相关专业经验和进一步培训获得的同等知识和技能。
- 具有评估以下几个领域的解决方案的技术专长。
o IAM认证/授权
o 静止/传输加密
o 操作概念
o 应用安全
o 网络安全
o 端点安全
o 云安全
- 你有很好的沟通能力，能够与整个巴斯夫的利益相关者保持一致和沟通。
- 流利英语和中文（母语）语言能力
