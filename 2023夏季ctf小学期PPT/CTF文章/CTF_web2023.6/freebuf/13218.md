【安全公告】Spring Framework 存在远程代码执行漏洞
2022-04-08 16:36:53

Spring 框架是一款目前主流的 Java EE 轻量级开源框架，提供了IOC、AOP及MVC等功能，解决了开发人员在开发中遇到的常见问题，一直被广大开发人员作为 Java 企业级应用程序开发的首选。

漏洞描述

日前，Spring官方发布安全公告，披露其Spring框架中存在一个远程代码执行漏洞(CVE-2022-22965)。由于Spring框架存在处理流程缺陷，攻击者可以利用该漏洞，在远程未授权的条件下，实现对目标主机的后门文件写入和配置修改，继而通过后门文件访问获得目标主机权限。该漏洞会影响运行在JDK9+上的Spring MVC和Spring WebFlux应用程序。特定的漏洞要求应用程序作为WAR部署在Tomcat上运行，如果应用程序部署为Spring Boot可执行jar包，即默认值，并不容易受到攻击。而该漏洞的性质更为普遍，存在被通过其他方式利用的可能。

目前，漏洞利用细节已大范围公开，Spring官方已发布补丁修复该漏洞。未来智安建议受漏洞影响的产品/服务厂商和信息系统运营者尽快进行自查，并及时升级至最新版本。

漏洞名称

Spring Framework 远程代码执行漏洞

漏洞等级

高危

漏洞范围

版本低于5.3.18和5.2.20的Spring框架或其衍生框架构建的网站或应用。

修复建议

 1. 官方补丁：https://github.com/spring-projects/spring-framework/releases
    Spring 框架版本5.3.18和5.2.20是官方发布的解决该漏洞的版本，目前已可用；Spring Boot发布进程正在进行中。
 2. 未来智安解决方案：未来智安XDR扩展威胁检测响应系统，基于上万个规则、数十种行为建模和机器学习来发现流量中异常行为和攻击，兼具检测发现、分析溯源、响应处置优势特点。通过XDR扩展威胁检测响应系统的智能事件分析引擎可自动生成有效事件，通过自动化安全编排能力实现快速运营处置，还可以快速扩展终端数据和威胁检测能力，使检测范围更加全面，自动生成完整攻击事件。更新最新安全防护规则，即可轻松抵御此高危风险。
