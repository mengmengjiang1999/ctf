华云安漏洞安全周报【第49期】
2021-09-02 15:47:33

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 8.23~2021.8.29）CNNVD接报漏洞1158，信息技术产品漏洞（通用型漏洞）215个，网络信息系统漏洞（事件型漏洞）943个，其中华云安报送漏洞257个；CNNVD接报漏洞预警77份，其中华云安报送预警9份；漏洞报送数量及预警报送数量持续位居前列！（数据来源于CNNVD）

本周重点关注漏洞包括：XStream 多个安全漏洞、OpenSSL 缓冲区溢出漏洞、F5 BIG-IP 多个安全漏洞、VMware 多个安全漏洞、CVE-2021-26084-Confluence OGNL 注入漏洞、CVE-2021-3634-Libssh 缓冲区溢出漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

XStream 多个安全漏洞

严重

2021年8月23日，华云安思境安全团队发现 XStream 官方发布安全更新，披露了 XStream 组件中存在 CVE-2021-39139-XStream 代码执行漏洞、CVE-2021-39140-XStream 拒绝服务漏洞、CVE-2021-39141-XStream 代码执行漏洞、CVE-2021-39144-XStream 代码执行漏洞、CVE-2021-39145-XStream 代码执行漏洞、CVE-2021-39146-XStream 代码执行漏洞、CVE-2021-39147-XStream 代码执行漏洞、CVE-2021-39148-XStream 代码执行漏洞、CVE-2021-39149-XStream 代码执行漏洞、CVE-2021-39150-XStream 服务器端请求伪造漏洞、CVE-2021-39151-XStream 代码执行漏洞、CVE-2021-39152-XStream 服务器端请求伪造漏洞、CVE-2021-39153-XStream 代码执行漏洞、CVE-2021-39154-XStream 代码执行漏洞。XStream 是 Java 类库，用来将对象序列化成 XML/JSON 或反序列化为对象，不需要其它辅助类和映射文件，使得 XML 序列化不再繁琐。成功利用这些漏洞的攻击者，可能导致在服务器上本地执行命令、拒绝服务、服务端请求伪造。

情报来源：

https://x-stream.github.io/news.html

OpenSSL 缓冲区溢出漏洞

高危

2021年8月24日，华云安思境安全团队发现 OpenSSL 官方发布安全根系，披露了 OpenSSL 组件中存在 CVE-2021-3711、CVE-2021-3712 两处缓冲区溢出漏洞。OpenSSL 是一个开源的能够实现安全套接层（SSLv2/v3）和安全传输层（TLSv1）协议的通用加密库，该产品支持多种加密算法，包括对称密码、哈希算法、安全散列算法等。成功利用这两个的漏洞的远程攻击者，可构造恶意数据执行信息泄露攻击，最终可能会造成服务器敏感性信息泄露或程序崩溃。

情报来源：

https://www.openssl.org/news/vulnerabilities.html

F5 BIG-IP 多个安全漏洞


高危

2021年8月24日，华云安思境安全团队发现 F5 官方发布安全更新，披露了其 BIG-IP 等产品中存在经过身份验证的远程命令执行、XSS、CSRF、SSRF 和拒绝服务等29个安全漏洞。F5 BIG-IP 是一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。此次更新共修复了13个高危漏洞、16个中低危漏洞，攻击者可以利用这些漏洞执行任意系统命令、XSS 攻击、SQL 注入、访问任意文件等。对此，华云安建议相关用户参考官方公告及时升级更新。

情报来源：

https://support.f5.com/csp/article/K50974556

VMware 多个安全漏洞

高危

2021年8月25日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 vRealize Operations Manager 组件中存在跨站请求伪造、访问控制中断、任意文件读取等6个安全漏洞。vRealize Operations Manager 是 VMware 官方提供的针对 VMware 虚拟化平台的一套运维管理解决方案。成功利用这些漏洞的攻击者在未授权的情况下，可构造恶意数据执行服务器请求伪造、越权访问、日志文件读取等攻击，最终可导致服务器敏感性信息泄露、控制 vROps 群集添加节点等。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2021-0018.html

CVE-2021-26084-Confluence OGNL 注入漏洞

超危

2021年8月26日，华云安思境安全团队发现 Atlassian 官方发布安全更新，披露了 Confluence Server & Confluence Data Center 组件中存在一处 OGNL 注入漏洞。Confluence 是 Atlassian 公司的一个专业的企业知识管理与协同软件，也可以用于构建企业wiki。该漏洞允许经过身份验证或在某些情况下未授权的攻击者，在 Confluence Server 或 Confluence Data Center 实例上执行任意代码。

情报来源：

https://confluence.atlassian.com/doc/confluence-security-advisory-2021-08-25-1077906215.html

CVE-2021-3634-Libssh 缓冲区溢出漏洞

低危

2021年8月27日，华云安思境安全团队发现 Libssh 官方发布安全更新，披露了 Libssh 组件存在一处缓冲区溢出漏洞。Libssh 是一个用于访问 SSH 服务的 C 语言开发包，它能够执行远程命令、文件传输，同时为远程的程序提供安全的传输通道。该漏洞是由于 Libssh 允许在密钥重新交换操作中改变密钥交换方法。改变密钥交换方法时，如果采用不同长度的 hash，将会导致缓冲区错误。

情报来源：

https://www.libssh.org/security/advisories/CVE-2021-3634.txt
