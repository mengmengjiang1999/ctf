华云安漏洞安全周报【第48期】
2021-08-26 10:13:09

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 8.16~2021.8.22 ）CNNVD接报漏洞563个，信息技术产品漏洞（通用型漏洞）95个，网络信息系统漏洞（事件型漏洞）468个，其中华云安报送漏洞197个；CNNVD接报漏洞预警72份，其中华云安报送预警6份；漏洞报送数量持续位列第一！（数据来源于CNNVD）

本周重点关注漏洞包括：CVE-2021-20032-SonicWall Analytics 远程代码执行漏洞、CVE-2021-34523-Microsoft Exchange Server 权限提升漏洞、CVE-2021-22123-Fortinet FortiWeb 命令注入漏洞、CVE-2021-35936-Apache Airflow 信息泄露漏洞、CVE-2021-34730-Cisco Small Business 路由器远程代码执行漏洞、CVE-2021-22029-VMware Workspace ONE UEM 控制台拒绝服务漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

CVE-2021-20032-SonicWall Analytics 远程代码执行漏洞

超危

2021年8月17日，华云安思境安全团队发现 SonicWall 官方发布安全更新，披露了 SonicWall Analytics 组件中存在一处远程代码执行漏洞。SonicWall Analytics 是一种强大的情报驱动分析服务，可以解决安全以及网络性能问题，SonicWall Analytics 的使用场景多，适配于多种防火墙。SonicWall Analytics 2.5 On-Prem 存在配置错误漏洞，该漏洞是由于 Java 调试线协议 (JDWP) 接口安全配置错误导致，成功利用此漏洞的攻击者在未授权的情况下，构造恶意数据造成远程代码执行，最终控制目标设备。

情报来源：

https://psirt.global.sonicwall.com/vuln-detail/SNWLID-2021-0018

CVE-2021-34523-Microsoft Exchange Server 权限提升漏洞

超危

2021年8月18日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Microsoft Exchange Server 组件中存在一处权限提升漏洞。 Microsoft Exchange Server 是一套电子邮件服务组件，是个消息与协作系统，支持多种电子邮件网络协议，如 SMTP、NNTP、POP3 和 IMAP4。成功利用此漏洞的攻击者可在低权限的情况下，构造恶意数据实现权限提升。

情报来源：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2021-34523

CVE-2021-22123-Fortinet FortiWeb 命令注入漏洞

高危

2021年8月18日，华云安思境安全团队发现 Fortinet 官方更新了 Fortinet FortiWeb 命令注入漏洞的安全通告。FortiWeb 是 Fortinet 研发的一款 Web 应用防火墙。该漏洞是由于 SAML 服务器配置不当，成功利用此漏洞的远程攻击者在获得权限的情况下，构造恶意数据，从而执行系统命令注入攻击。

情报来源：

https://fortiguard.com/advisory/FG-IR-20-120

CVE-2021-35936-Apache Airflow 信息泄露漏洞

中危

2021年8月18日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Airflow 组件中存在一处信息泄露漏洞。Apache Airflow 是一套用于创建、管理和监控工作流程的开源平台，具有可扩展和动态监控等特点。Apache Airflow 2.1.2 之前版本存在安全漏洞，该漏洞是由于日志服务器没有身份验证引起，成功利用此漏洞的攻击者允许读取 DAG jobs 的日志文件。

情报来源：

https://lists.apache.org/thread.html/r53d6bd7b0a66f92ddaf1313282f10fec802e71246606dd30c16536df%40%3Cusers.airflow.apache.org%3E

CVE-2021-34730-Cisco Small Business 路由器远程代码执行漏洞


超危

2021年8月19日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Small Business RV110W、RV130、RV130W 和 RV215W 路由器中存在一处远程代码执行漏洞。Cisco Small Business RV110W、RV130、RV130W 和 RV215W Routers 都是思科（Cisco）的 VPN 路由器产品。该漏洞的由于对传入 UPnP 流量的验证不当造成，攻击者可以通过向受影响的设备发送精心设计的 UPnP 请求来利用此漏洞。成功利用此漏洞的攻击者可以凭借 root 用户在底层操作系统上执行任意代码或导致设备异常重启，从而导致拒绝服务（DoS）。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-cisco-sb-rv-overflow-htpymMB5

CVE-2021-22029-VMware Workspace ONE UEM 控制台拒绝服务漏洞


中危

2021年8月20日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware Workspace ONE UEM 控制台存在一处拒绝服务漏洞。VMware Workspace One 是一个用于支持跨设备应用于快速交付、管理应用程序的平台。该平台包含 VMware Horizon 和 VMware Horizon Cloud，将访问控制、应用程序管理和多平台端点管理集成到一个平台中，可高效管理多个设备。该漏洞是由于软件控制台中对于 /API/system/admins/session REST API 端点的请求速率限制不当造成。成功利用此漏洞的远程攻击者可以发送大量请求并执行拒绝服务攻击。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2021-0017.html
