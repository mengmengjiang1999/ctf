2022-03-04 17:36:00

Harbor

随着虚拟化环境越来越受到认可和欢迎，私有的registry server 逐渐成为企业研发、生产环境必备的云基础设施。研发、测试甚至运维人员往往会将调试好的应用镜像，推送到registry server 以便一键化部署。但便捷高效的仓库一旦失控，便意味着研发、测试用应用镜像泄露，从某种程度上来说不亚于代码仓库泄露！！！

Harbor 是由 VMware 公司中国团队为企业用户设计的 Registry server 开源项目，包括了权限管理(RBAC)、LDAP、审计、管理界面、自我注册、HA 等企业必需的功能，同时针对中国用户的特点，设计镜像复制和中文支持等功能。

它还有一个“有趣”的功能：允许任意用户获取被配置为public的镜像。

问题

很多人对“公开”这个范围可能存在误解，以为是向注册用户公开，往往会有这样的配置：把自助注册功能关闭，项目级别设置为“公开”。实际上，harbor的“公开”，是向所有用户公开，包括未认证用户，这样实际上就造成了应用部署镜像泄露。

应用部署镜像泄露：

可以想象一下，存放着springBoot一键运行的app.jar的应用镜像泄露是什么危害：

配置文件、密码、地址信息泄露，私钥信息泄露，class文件反编译......

几乎可以获取运行环境内的全部信息（除了不在内网环境）

快速攻略

1.历史漏洞利用：

Harbor任意管理员注册漏洞复现

2.公开镜像信息泄露利用：

v1.x:

获取projects：

https://demo.goharbor.io/api/projects

获取repos：

https://demo.goharbor.io/api/repositories?project_id=1&q=

获取tags：

https://demo.goharbor.io/api/repositories/repo_name/tags?detail=true

v2.x:

获取projects：

https://demo.goharbor.io/api/v2.0/projects

获取repos：

https://demo.goharbor.io/api/v2.0/search?q=project_name

获取tags：

https://demo.goharbor.io/api/v2.0/projects/project_name/repositories/image_name/artifacts?with_tag=true&with_scan_overview=true&with_label=true&page_size=15&page=1
