HiddenEye

HiddenEye是一款带有高级功能的现代网络钓鱼工具，目前该工具仅支持Android平台，广大研究人员可以使用该工具来进行网络钓鱼测试。

工具运行条件

Python3

Wget

PHP

Sudo

工具安装

BlackArch官方代码库：

sudo pacman -S hidden-eye

sudo hidden-eye

GitHub代码库克隆：

git clone https://github.com/DarkSecDevelopers/HiddenEye.git

工具运行（Linux）

chmod 777 HiddenEye

sudo apt install python3-pip

cd HiddenEye

sudo pip3 install -r requirements.txt

python3 HiddenEye.py

工具运行（Arch Linux或Manjaro）

chmod 777 HiddenEye

sudo pacman -Syu

sudo pacman -S python-pip

cd HiddenEye

sudo pip3 install -r requirements.txt

sudo python3 HiddenEye.py

针对Android用户

用户空间App安装

首先，从应用商店安装用户空间App，然后安装并配置Kali，接下来设置ssh用户名和密码。Kali运行之后，它将会要求用户输入ssh密码以及sudo密码，然后运行aptupdate来更新系统。操作命令如下：

apt install python3 && python3-pip && unzip && php&& git

git clonehttps://github.com/DarkSecDevelopers/HiddenEye.git

chmod 777 HiddenEye

cd HiddenEye

pip3 install -r requirements.txt

python3 HiddenEye.py

TERMUX App安装

从PlayStore安装{Termux}，然后运行下列命令：

pkg install git python php curl openssh grep

pip3 install wget

git clone -b Termux-Support-Branchhttps://github.com/DarkSecDevelopers/HiddenEye.git

chmod 777 HiddenEye

cd HiddenEye

python HiddenEye.py

ASCII错误修复

找到dpkg-reconfigure，选择"All locales"，然后选择"en_US.UTF-8"。重启设备之后，打开命令行窗口，然后运行命令："locale"。接下来，你将会使用"en_US.UTF-8"来作为默认语言，而不是之前的POSIX了。
