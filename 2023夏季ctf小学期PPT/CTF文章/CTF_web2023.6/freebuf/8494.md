销售易招聘DevSecOps工程师
2022-09-06 16:56:52

销售易（Neocrm），是融合新型互联网技术的企业级CRM开创者。销售易致力于通过新型互联网技术，打造符合数字化时代下企业需求的新一代CRM产品，将企业同客户互动的全过程数字化、智能化，帮助企业转型为真正以客户为中心的数字化运营组织，实现业绩的可持续增长。

销售易CRM服务了不计其数的世界五百强企业、国内行业领军企业，为客户提供企业营销全流程的产品功能。同时也成为国内唯一连续五年入选Gartner SFA魔力象限的企业。

基于业务安全需要招聘高级安全工程师（DevSecOps方向）一名。

工作内容：


1.主导公司DevSecOps体系建设及落地；
2. 制定DevSecOps制度及流程；
3. 参与公司产研流程的安全需求评审、安全架构评审、代码审计、安全验收工作等工作；
4. 参与对研发人员开展的安全开发培训以及安全意识培训。

任职要求：


1. 5年以上安全相关工作经验
2. 具备DevSecOps或者SDL等研发安全方案的实践经历；
3. 具备良好的沟通协调能力和执行力；
4. 对常见WEB、系统漏洞的原理、危害、利用方式以及修复方案有深入的认识；
5. 熟悉白盒代码扫描、IAST、DAST等产品架构及技术实现，熟练掌握各种检测机制的优缺点；

加分项：

熟悉常见代码安全问题分类和指南，如OWASP TOP10、SAN/CWE、Oracle Secure Coding Standard；
熟悉流行的CI / CD工具，例如Jenkins
在互联网公司落地过SDL流程或者有白盒代码扫描，WEB黑盒扫描，RASP等安全能力研发经验者


简历投递邮箱：lizy02@neocrm.com （请注明来自FreeBuf）
