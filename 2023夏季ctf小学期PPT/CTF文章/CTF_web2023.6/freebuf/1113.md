一、预备知识

1.java中的反射机制

简介：java反射是指在程序的运行状态，对于任意一个类，都能获取到这个类的所有属性和方法，对于任意一个对象，都能够调用它的任意一个方法和属性(包括私有的方法和属性)，这种动态获取程序信息以及动态调用对象的功能就称为java语言的反射机制。

举个例子：

先给定一个类Person:

class Person{

private String name;

privateint age;

public String toString(){

return "User{"+"name="+name+",age="+age+"}";

}

public String getName(){

return name;

}

public void setName(String name){

this.name = name;

}

public int getAge(){

return age;

}

public void setAge(int age){

this.age = age;

}

}

这里我们得到Person类，那么如何通过反射获得类的方法或者属性呢？

A. 先看看怎么获得类的实例

（1）调用某个对象的getClass方法，获取该类的class对象

例子：

核心代码为：

import java.lang.reflect.Method;

Person person = new Person();

Class clazz = person.getClass();

Method method = clazz.getMethod("setName", String.class);

method.invoke(person, "Tom");

从输出我们可以看出Reflaction类执行了Person类中的setName方法

（2）调用某个类的Class属性，获取该类对应的class对象

Class clazz = Person.class;

system.out.println(clazz.getName());

（3）调用class类中的forName静态方法，获取该类对象

Class clazz = Class.forName("类的路径包括包名")

以上三种方法获得了某个类的Class对象，接下来看怎么获得方法和属性。

B. 获取方法

(1)getMethods()方法

//核心代码：

Class clazz = Person.class;

Method[] methods = clazz.getMethods();//getMethod则仅获取第一个方法

//invoke(Object obj, Object... args); invoke调用特定的方法

for(Method method : methods) {

System.out.println(method);

}

(1)getDeclareMethods()方法

//核心代码：（例子就不截啦）

Class clazz = Person.class;

Method[] methods2 = clazz.getDeclareMethods();//getDeclareMethod则只获取第一个方法

//invoke(Object obj, Object... args); invoke调用特定的方法

for(Method method : methods2) {

System.out.println(method);

}

getMethods和getDeclareMethods的区别在于：

getMethods()获取运行时类及其父类的声明为public的方法

getDeclareMethods()获取运行时类的所有方法

至此我们知道了怎么通过反射获得一个类的class对象、怎么获得其中的方法和怎么调用其中的方法

2.HashMap

HashMap是一个散列表，主要用于存储键值对，实现了Map接口，根据键的HashCode值存储数据，访问速度快。HashMap是jdk中常被使用的类，继承了Serialize接口，有readObject方法，可调用一些类或者类中的方法，从而直接或者间接执行一些危险的函数。

二、URLDNS反序列化链

1.简介

URLDNS是ysoserial中的一条利用链，利用效果是触发一次DNS请求，适合于反序列化漏洞验证。利用过程较为简单，不用依赖于第三方库。

漏洞形成原理：HashMap中的readObject实现了反序列化，通过利用链传入相应的值，最终使得dnslog给出回显。

关于hashcode:

1. hashCode()的作用

hashCode用于获取哈希码，实际上返回一个int整数，用于确定该对象在哈希表中的索引位置。哈希表也叫散列表，是一种可以通过key-value直接访问的数据结构，实现快速查找、插入和删除。用到的算法叫哈希算法，就是将任意长度输入，转换成固定长度的哈希值输出。

以漏洞触发点的HashMap为例，当我们需要向里面添加对象时，先调用这个对象的hashCode()方法，得到对应的哈希值，再以哈希值为key，对象为value将其放到HashMap中。当需要添加一个新的对象时，可以先获取新对象的哈希值，与现存的哈希值进行对比，不相等则直接存入；如果相等就调用equals()方法进行对象之间的比较，相同则不存，不同则表示哈希冲突了，增加一个链表存放新对象。

三、总结

总的来说就是由于HashMap中实现了序列化接口，可通过传入序列化后的值进行反序列化，并形成DNS请求。具体来说就是只需要new一个hashMap对象，然后给它的key赋值为一个java.net.URL对象，然后设置这个URL对象的hashCode值为-1，反序列化的时候会重新计算hashCode，从而触发DNS请求。

URLDNS利用链只是ysoserial中最简单的一条链，后续将依次学习介绍其他链。
