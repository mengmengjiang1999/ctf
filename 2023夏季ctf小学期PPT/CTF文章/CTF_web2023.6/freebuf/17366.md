1.数据类型:

​ 数，字符串，列表（list），元组（tuple），集合（set），字典（dictionary），自定义类（面向对象）

其实就是和绝大多数语言一样，但是之后会使用，所以我们赘述一下

  * 列表赋值b=[ 1, "abc", 7 ],同样使用索引用时从0开始计算，列表中的元素可以直接替换：b[2]="abcd"，再次输出b，显示[1,"abc","abcd"]

  * 元组与列表基本相同，但是里面的元素值无法该变且元组利用()定义，b=（1,2,3）

  * 字典是利用键值对的类型存储，{键：值，键：值，键：值}类似map类型对象，取值时格式为 字典名["对应键名"]

  * 集合利用set来定义：f = set("hasjdkhasjk")，输出时会显示("h","a","s","j","d","k")，可以看出，集合中定义的字符串输出时会将内容显示为一个一个字符输出，并且会去重。一般利用的更多的就是去重功能。当定义另一个集合为 h = set("hdjashjh")，f - h就显示两个集合的差集，即("k")

4.python控制流（分支循环语句）

1）条件分支结构

if语句：

在python中if不需要 {} 嵌套语句，并且可以和elif语句进行搭配使用，如下：

a=23
b=12
if(a>33):
    print("dasda")
    if(b<34):
        print("那年18，哥谭笑话")
elif(a>1 and b>1):
    print("你tm劈我瓜是吧")


while语句：

a=2
while(a<10):
    print("你批我1次瓜")
    a+=1


for语句：

遍历列表

a=["sdsa","sda","sda","dsa"]
for i in a:
    print(i)


for i in range(0,10):
    print("hello")


2）终端结构

break语句：

全部退出，整个循环直接退出

a=["sdsa","sda","sda","dsa"]
for i in a:
    if(i=="sda"):
        break
    print(i)


continue语句：

中断一次循环，继续下一次循环

a=["sdsa","sda","sda","dsa"]
for i in a:
    if(i=="sda"):
        continue
    print(i)


输出乘法口诀：

#end=""代表不换行输出
for i in range(1,10):
    for j in range(1,i+1):
        print(str(i)+str("+")+str(j)+"="+str(i*j),end="  ")
    print()


逆向输出乘法口诀表：

for i in range(9,0,-1):
    for j in range(i,0,-1):
        print(str(i)+str("*")+str(j)+"="+str(i*j),end=" ")
    print()


5.作用域：

python同其他编程语言一样，对象都具有作用域的不同，全局变量与局部变量，但是更容易理解一些

i=10 #全局变量
def func():
    j=9 #局部变量
    print(j)
print(i)
func()


此时j就是局部变量，只能在函数中调用，但是i是全局变量，可以在全局中使用

7.函数参数使用：

参数就是函数与外界沟通的接口

形参与实参：

相信我们学过编程语言的小伙伴都了解了这两个参数的区别与联系了：

形参一般就是函数定义的时候使用的参数

实参一般在函数调用的时候使用的参数就是实参

def func(a,b):#此时ab为形参
    if(a>b):
        print("a比b大")
    else:
        print(str(a)+"比"+str(b)+"小或相等")

func(5,7)#此时ab为实参


8.python模块使用

模块是python中为了使程序实现更加方便，将一些函数按照需求组合在一起

要实现这一类方法的时候，直接导入模块即可，模块中的函数叫做模块的方法

系统自带的模块安装在lib目录中：

导入模块：

import 模块名：

from 模块名 import 方法（在模块中导入方法）

模块的类别（来源不同分类）：

9.文件操作

我们可以利用python来进行对于文件的打开，关闭，读取，合并，写入等操作

使用python进行文件操作可以自动对于程序进行处理，如合并多个文档等

文件的操作

首先打开文件：open(文件地址，操作形式)

w：写入（有可能将原本的内容进行覆盖）

r：读取

b：二级制

a：追加（在文本末尾加入内容）

#文件的读取
h=open("路径","r")
b=h.read()
print(b)
h.close()

#文件的写入(追加，非追加)
data="你tm劈我瓜是吧?,撒日朗"
h=open("路径","a+")
h.write(data)
h.close()
a=open("路径","r")
b=a.read()
print(b)
a.close()


其中写入时，添加操作方式中w为非追加，即将原本的内容进行覆盖，a+为非追加，即在文件之后添加内容。

10.python异常处理

当我们在使用爬虫的时候，可能会遇到异常，但是如果不及时进行处理，很可能会爬到一般直接崩溃。

异常处理会在遇到异常时直接跳过异常的代码执行下面的内容

#异常处理
try:
    for i in range(0,10):
        print(i)
        if(i==5):
            print(i)
            print(jsk)
except Exception as err:
    print("被玩坏了")


此时也可以在异常处理中直接输出（err）即此时会输出错误信息

我们也可以在函数内部创建一个异常处理函数

for i in range(0, 10):
    print(i)
    try:
        if (i == 5):
            print(i)
            print(jsk)
    except Exception as err:
        print("被玩坏了")
