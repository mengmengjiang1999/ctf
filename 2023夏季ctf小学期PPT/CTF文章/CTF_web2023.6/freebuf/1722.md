pyenv install 3.9.5

pyenv local 3.9.5

python -V

安装最新版本的frida

pip install frida-tools


对ios手机的操作

已越狱。

下载指定版本的frida-server

通过爱思助手将安装包上传到ios手机上

dpkg命令详解：https://www.cnblogs.com/my-show-time/p/15535087.html

查看frida包名 dpkg -l|grep frida

卸载软件包. dpkg -r re.frida.server

安装frida-server dpkg -i frida_16.0.10_iphoneos-arm.deb

安装frida-ios-dump

proxychains git clone https://github.com/AloneMonkey/frida-ios-dump.git

pip install -r requirements.txt --upgrade -i https://pypi.tuna.tsinghua.edu.cn/simple

安装iproxy

apt search iproxy

apt install libusbmuxd-tools

将ios手机通过USB连接到虚拟机

测试是否链接成功 frida-ps -U ，如果识别不到，尝试 虚拟机——可移动设备——Apple——断开连接，然后重新连接

iproxy 2222 22

测试端口转发是否成功：重开一个终端

账号密码 root alpine

./dump.py Aftenposten


显示手机上的应用 python dump.py -l

用应用的名字或者包名砸壳 python dump.py [app name]/[app bundle]

python dump.py com.xxx
