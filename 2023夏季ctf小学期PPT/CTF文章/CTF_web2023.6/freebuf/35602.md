挂载时常见错误及解决

问题一：两边都ping的通，但挂载时却报连接超时

解决步骤：

1 确认源端nfs进程是否开启

2 在源端和目标端/etc/hosts目录下配置两端的ip+主机名，并检查配置是否正确

3 重新挂载。


问题二：vmount: Operation not permitted.

解决步骤：

1 检查源端权限和属主赋予是否正确

2 若是aix上挂载nfs报此错误，可设置nfs参数nfso -p -o nfs_use_reserved_ports=1

3重新挂载。


问题三：ORA-27054

NFS file system where the file is created or resides is not mounted with correct options

解决步骤：给大家附上一张各个版本操作系统的挂载参数。
