金融行业网络威胁研究报告

Tag：金融行业

事件概述：

近日，微步情报局从威胁情报视角出发，对金融行业机构真实环境中所面临的整体网络威胁进行深度统计分析并探究部分真实行业威胁事件，致力于为金融行业客户伙伴输出情报侧发现的威胁态势，为整体网络安全防御体系建设提供参考依据。本篇专题研究报告发现金融机构当前面临的网络威胁简要概括如下：

  * 金融机构生产运营过程中面临着大批量的网络攻击活动，其中以源自互联网侧的网络渗透攻击为主、其次为钓鱼邮件攻击；
  * 金融机构内部主机失陷占比最多的是挖矿木马，其次是僵尸网络及其下载衍生的各类家族木马，勒索病毒和APT 类攻击占比最小，但依然存在真实攻击案列发生；
  * 金融机构普遍存在内部网络资产暴露、敏感数据泄露等互联网侧威胁，黑客组织对金融机构敏感数据的兴趣逐渐升温；
  * 金融机构供应链安全问题形势严峻，传统的网络、服务、运维等安全信任体系值得反思。

上篇主要讲述金融行业背景，基于互联网侧攻击态势分析、失陷主机统计分析、互联网暴露面及数据泄露统计分析等情报侧风险发现；下篇主要讲述全球金融行业网络威胁态势，基于金融企业安全建设现状分析、金融企业实战化能力提升典型实践案例提升企业网络安全实战化能力。完整内容需关注“微步在线研究响应中心”查看，或者在公众后台回复“金融”关键词获取完整版PDF报告。

谷歌商店被曝存在伪装成 Android 防病毒软件的 SharkBot 银行木马

Tag：SharkBot，Android，谷歌商店

事件概述：

近日，NCC Group 研究人员在谷歌商店发现了一款伪装成具有系统清理功能的防病毒软件的 SharkBot 银行木马。该木马于2021 年10月首次发现，与其他银行木马不同的是可以通过模拟受感染设备上的触摸/点击按钮实现从自动转账系统 (ATS) 转账，拦截新通知并直接回复信息。截至撰写文章时，该木马仍然存在于谷歌商店中。

技术详情：

SharkBot 银行木马通过滥用 Android 设备的 Accessibility 权限，监测应用程序使用情况。当用户打开银行应用程序时，SharkBot 银行木马执行匹配的网络注入，窃取用户凭据，并从 C2 服务器接收命令以执行发送短信、更新配置文件、卸载应用程序、关闭AV工具等恶意操作。

多家金融服务商成为“Access:7”供应链漏洞的最新受害者

Tag：供应链漏洞，Access:7

事件概述：

近日，PTC 的 Axeda 软件被披露存在7个安全漏洞，这些漏洞统称为“ Access:7 ”。这些漏洞可能被武器化，以未经授权访问金融、医疗和物联网设备。Access:7 漏洞可以让黑客远程执行恶意代码、访问敏感数据、修改配置以及关闭受影响设备中的特定服务。

由于受 Access:7 漏洞影响的 Axeda 软件被出售给许多设备制造商，此供应链漏洞可能会波及到许多下游制造商的设备，超过100家不同制造商的150 多种设备型号受到影响，构成重大供应链风险。除 ATM 机、自动售货机、现金管理系统外，易受攻击的设备还包括医学成像实验室机器、标签打印机、条形码扫描系统、SCADA 系统、资产监控和跟踪解决方案、物联网网关和工业切割机的所有设备。Access:7 漏洞信息如下：

  * CVE-2022-25246：在 AxedaDesktopServer.exe 服务中使用硬编码凭据，可以远程接管设备；
  * CVE-2022-25247：ERemoteServer.exe 中的一个漏洞，可用于发送特制命令以获取远程代码执行 (RCE) 和完整的文件系统访问权限；
  * CVE-2022-25251：Axeda xGate.exe 代理中缺少可用于修改代理配置的身份验证；
  * CVE-2022-25249：Axeda xGate.exe 代理中的目录遍历漏洞，允许远程未经身份验证的攻击者获取 Web 服务器上的文件系统读取访问权限；
  * CVE-2022-25250：Axeda xGate.exe 代理中的拒绝服务 (DoS) 漏洞；
  * CVE-2022-25252：Axeda xBase39.dll 组件中的缓冲区溢出漏洞，可能导致拒绝服务 (DoS)；
  * CVE-2022-25248：ERemoteServer.exe 服务中的信息泄露漏洞，允许将实时事件文本日志暴露给未经身份验证的攻击者。

参考链接：https://thehackernews.com/2022/03/critical-access7-supply-chain.html

DanaBot 恶意软件针对乌克兰国防部进行 DDoS 攻击

Tag：DanaBot，国防部，乌克兰，邮件服务

事件概述：

3月2日，在俄罗斯入侵乌克兰期间，Zscaler 研究人员监测发现攻击者利用 DanaBot 恶意软件瞄准乌克兰国防部网络邮件服务器发起了基于 HTTP 的分布式拒绝服务 (DDoS) 攻击。DanaBot 于2018年首次被发现，是一个恶意软件即服务平台，旨在窃取凭据和进行银行欺诈。

研究人员认为此次攻击活动无论从时间还是目标角度出发，与2022年俄罗斯入侵乌克兰有着密不可分的联系，但目前尚不清楚这是否是个人黑客行为还是国家支持的行为，亦或许可能是假旗操作。如果攻击者的动机是攻击乌克兰，那么除了 DDoS 攻击之外，攻击者很可能还在使用 DanaBot 更典型的功能进行攻击，例如针对任何相关受害者进行凭证盗窃和文件窃取。

事件概述：

3月7日，罗马尼亚石油供应商 Rompetrol 证实遭到网络攻击，为保护数据安全，该公司暂时暂停了网站和 Fill&Go 应用程序的运营。攻击者疑似还入侵了 Rompetrol 的炼油厂 Petromidia，但 Petromidia 运营疑似未受到影响。据外媒 BleepingComputer 称 Hive 勒索软件团伙疑似是此次攻击的幕后黑手， 此勒索软件团伙要求 Rompetrol 石油供应商支付200万美元的赎金，以获取解密器并保证不泄露窃取的数据。

谨防针对石油和天然气公司的网络钓鱼活动！

Tag：Formbook，网络钓鱼

事件概述：

近日，Malwarebytes 威胁情报团队监测发现针对石油和天然气公司的恶意软件活动，攻击者通过伪装成来自沙特阿拉BO公共石油和天然气公司沙特阿美的网络钓鱼邮件投递恶意软件 Formbook。该恶意软件是一种信息窃取程序，主要通过暗网交易，自 2016 年以来一直被许多威胁者所利用。

随着俄罗斯与乌克兰冲突继续升级，俄罗斯政府于3月3日公布了针对其国内基础设施的一系列分布式拒绝服务 (DDoS) 攻击的幕后黑手，发布了一份包含攻击者在攻击期间使用的 17,576 个 IP 地址和 166 个域名的列表。这些列表包含了美国联邦调查局 (FBI)、中央情报局 (CIA) 以及《今日美国》等多家媒体出版物的网站域名。

FBI：RagnarLocker 勒索软件变种至少入侵了52个美国关键基础设施实体

Tag：RagnarLocker，勒索软件，美国，关键基础设设施

事件概述：

近日，美国 FBI 和 CISA 联合发布告警信息，称 Ragnar Locker 勒索软件团伙已经破坏了10个关键基础设施部门的至少52个实体组织的网络，包括关键制造业、能源、金融服务、政府和信息技术部门等。 Ragnar Locker 勒索软件团伙自2019年12月下旬以来一直处于活跃状态，主要通过更改其工具、技术和程序 (TTP) 以保持隐藏状态。但据联邦调查局透露该组织通常使用 VMProtect、UPX 和自定义打包算法，在受害者的站点上部署自定义 Windows XP 虚拟机。RagnarLocker 勒索软件遍历所有正在运行的服务，并终止托管服务提供商通常用于远程管理网络的服务，然后尝试静默删除所有卷影副本，从而阻止用户恢复加密文件。

参考链接：https://www.ic3.gov/Media/News/2022/220307.pdf

微步点评：

缓解此类攻击的措施：

  * 离线备份关键数据；
  * 确保关键数据的副本位于云端或外部硬盘驱动器或存储设备；
  * 保护您的备份并确保无法从数据所在的系统访问数据以进行修改或删除；
  * 使用具有强密码的多因素身份验证，包括远程访问服务；
  * 保持计算机、设备和应用程序的补丁和最新；
  * 监控有关泄露VPN 登录凭据的发布以及更改密码和设置的网络威胁报告；
  * 考虑为从组织外部收到的电子邮件添加电子邮件横幅；
  * 禁用未使用的远程访问/远程桌面协议 (RDP) 端口并监控远程访问/RDP 日志；
  * 审核具有管理权限的用户帐户，并以最低权限配置访问控制；
  * 实施网络分段。

TA416 组织利用 PlugX 变体瞄准欧洲政府实体展开攻击

Tag：TA416，APT，PlugX，欧洲

事件概述：

随着乌克兰、俄罗斯冲突升级，Proofpoint 研究人员监测发现 TA416 威胁组织加快了针对欧洲政府外交实体、参与难民和移民服务的个人的攻击行动，且该组织目标方向与俄罗斯和乌克兰之间的紧张局势和现在的武装冲突吻合。TA416 组织通过 Web 漏洞来攻击受害者，然后通过电子邮件中的恶意 URL 投递各种更新后的 PlugX 恶意软件有效载荷。从历史上看，该组织主要提供网络漏洞 URL 和恶意软件 URL 以投递恶意软件。2022 年，该组织开始转变为分析用户，然后以社工的方式提供恶意软件 URL。这疑似是 TA416 组织在提升防御规避能力的尝试。

技术详情：

从2021年11月初开始，该组织通过使用合法的电子邮件营销服务 SMTP2Go 冒充联合国大会秘书处会议服务助理向目标投递电子邮件，然后通过 DropBox URL 提供 PlugX 恶意软件。

组织关联：

TA416 与公开披露的集团“Red Delta”之间存在重叠。2020年8月和2021年 11 月的两次活动都针对欧洲外交实体，都利用 SMTP2Go 冒充可能与最终目标通信的外交组织展开攻击。

惠普修复了影响笔记本电脑、台式机、PoS 系统的 UEFI 固件的16 个严重漏洞

Tag：惠普，UEFI，严重漏洞

事件概述：

FinCEN 还提供了危险信号示例，有助于识别可能与逃避制裁有关的可疑活动，并提醒金融机构他们有责任根据《银行保密法》报告此类事件。在 FinCEN 告警信息中包含的所有危险信号列表中，以下三个具体与勒索软件攻击和其他网络犯罪活动的潜在洗钱有关：

  * 客户从外部钱包收到CVC，并立即在多个 CVC 之间发起多次快速交易，但没有明显的相关目的，然后在平台外进行交易。这可能表明试图破坏各个区块链上的监管链或进一步混淆交易；
  * 客户发起涉及CVC 混合服务的资金转移；
  * 客户具有被区块链跟踪软件识别为与勒索软件相关的直接或间接交易风险。

面对俄罗斯日益增长的经济压力，FinCEN 表示美国金融机构必须警惕俄罗斯可能逃避制裁的行为。
