华云安漏洞安全周报【第90期】
2022-07-01 10:11:13

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.6.20~2022.6.26）CNNVD接报漏洞147个，信息技术产品漏洞（通用型漏洞）108个，网络信息系统漏洞（事件型漏洞）39个；CNNVD接报漏洞预警149份，其中华云安报送预警11份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-22980-Spring Data MongoDB SpEL 表达式注入漏洞、CVE-2022-2068-OpenSSL 命令注入漏洞、CVE-2022-20828-Cisco ASA Software 命令注入漏洞、CVE-2022-32549-Apache Sling日志注入漏洞、CVE-2022-29168-Wire 代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-22980-Spring Data MongoDB SpEL 表达式注入漏洞

威胁等级：高危

漏洞描述：

2022年6月20日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Spring Data MongoDB 组件中存在一处 SpEL 表达式注入漏洞。Spring Data MongoDB 是 Spring Source 的一个子项目，旨在为关系型数据库、非关系型数据、Map-Reduce 框架、云数据服务等等提供统一的数据访问 API。该漏洞是由于对用户输入未进行合理的过滤，成功利用此漏洞的攻击者通过使用包含 SpEL 表达式占位符的 @Query 或 @Aggregation 注释存储库查询方法，从而在应用程序未清理用户提供的输入的情况下进行 SpEL 表达式注入。

情报来源：

https://tanzu.vmware.com/security/cve-2022-22980

02 CVE-2022-2068-OpenSSL 命令注入漏洞

威胁等级：中危

漏洞描述：

2022年6月21日，华云安思境安全团队发现 OpenSSL 官方发布安全更新，披露了 OpenSSL 组件中存在一处命令注入漏洞。OpenSSL 是一个开放源代码的软件库包，应用程序可以使用这个包来进行安全通信，避免窃听，同时确认另一端连接者的身份。该漏洞是由于错误地处理了 c_rehash 脚本，成功利用此漏洞的攻击者可能会在运行 c_rehash 时执行任意命令攻击。

情报来源：

https://www.openssl.org/news/secadv/20220621.txt

03 CVE-2022-20828-Cisco ASA Software 命令注入漏洞

威胁等级：中危

漏洞描述：

2022年6月22日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Adaptive Security Appliances Software（ASA Software） 组件中存在一处命令注入漏洞。Cisco Adaptive Security Appliances Software（ASA Software）是思科的一套防火墙和网络安全平台，该平台提供了对数据和网络资源的高度安全的访问等功能。该漏洞是由于对未定义的命令参数处理不当引起，成功利用此漏洞的攻击者可在受影响的 ASA FirePOWER 模块的底层操作系统上执行任意命令攻击。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-asasfr-cmd-inject-PE4GfdG

04 CVE-2022-32549-Apache Sling 日志注入漏洞

威胁等级：超危

漏洞描述：

2022年6月22日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Sling 组件中存在一处日志注入漏洞。Apache Sling 是一个 Java 平台的开源 Web 框架，旨在在符合 JSR-170 的内容存储库（例如 Apache Jackrabbit ）上创建以内容为中心的应用程序。该漏洞是由于用户拥有不正当权限引起，成功利用此漏洞的攻击者在具有伪造日志能力的情况下通过注入虚假日志和可能损坏的日志文件，从而修改日志信息掩盖踪迹。

情报来源：

https://lists.apache.org/thread/7z6h3806mwcov5kx6l96pq839sn0po1v

05 CVE-2022-29168-Wire 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年6月25日，华云安思境安全团队发现研究人员公开披露了 wire 组件中存在一处代码执行漏洞。Wire 是一个安全的消息传递应用程序。该漏洞是由于在 Wire-web 应用程序中渲染 “@mentions” 时容易因转义不足引起，成功利用此漏洞的攻击者通过发送恶意制作的消息并诱使用户打开，从而在应用程序上下文中注入或执行代码。

情报来源：

https://github.com/wireapp/wire-webapp/security/advisories/GHSA-jgv3-4j56-fvh6
