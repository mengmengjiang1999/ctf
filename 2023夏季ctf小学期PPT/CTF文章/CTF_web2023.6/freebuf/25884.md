如何使用Adfsbrute测试活动目录联合身份验证服务（ADFS）的凭证
2021-04-20 15:37:32

Adfsbrute

Adfsbrute这个脚本可以帮助广大研究人员测试针对活动目录联合身份验证服务（ADFS）的凭证数据，并计算一个组织中活动目录联合身份验证服务（ADFS）的URL，并允许对其执行密码喷射或暴力破解攻击。

Adfsbrute的核心思想是在每次测试之间以随机和高延迟的方式执行密码喷射攻击，并使用代理列表或Tor来增加蓝队研究人员的检测难度。除此之外， 在执行暴力破解哦攻击或测试凭证的过程中，Adfsbrute还可以使用“用户名：密码”的形式来测试存储在日志文件中的凭证，以避免对其进行两次测试。

注意，该脚本仅可用于安全测试目的，请不要将其用于其他恶意用途。

工具下载

Adfsbrute基于Python开发，因此广大用户需要先在本地设备上安装并配置好Python环境，然后再使用下列命令将该项目源码克隆至本地：

git clone https://github.com/ricardojoserf/adfsbrute.git

工具使用

./adfsbrute.py -t TARGET [-u USER] [-U USER_LIST] [-p PASSWORD] [-P PASSWORD_LIST] [-UL userpassword_list]

[-m MIN_TIME] [-M MAX_TIME] [-tp TOR_PASSWORD] [-pl PROXY_LIST] [-n NUMBER_OF_REQUESTS_PER_IP]

[-s STOP_ON_SUCCESS] [-r RANDOM_COMBINATIONS] [-d DEBUG] [-l LOG_FILE]

支持的参数介绍如下：

* -t: 目标域名，例如：test.com

* -u: 单个用户名，例如：agarcia@domain.com

* -U: 用户名列表文件，例如：users.txt

* -p: 单个密码，例如：Company123

* -P: 密码列表文件，例如：passwords.txt

* -UP: 凭证列表文件，格式为“用户名：密码”，例如：userpass.txt

* -m : 每次测试的最小随机间隔秒数，默认：30

* -M : 每次测试的最大随机间隔秒数，默认：60

* -tp: Tor密码（使用Tor修改IP地址）

* -pl: 使用一个代理列表

* -n: 修改IP地址前的请求数量，默认：1

* -s: 成功后终止运行，即找到一个正确凭证，默认：False

* -r: 用户名密码随机组合，默认：True

* -d: 显示调试信息，默认：True

* -l: 包含已测试凭证的日志文件路径，默认：tested.txt

工具使用样例

使用密码“Company123”进行密码喷射攻击，Tor密码为“test123”，每三次请求后修改IP地址：

python3 adfsbrute.py -t company.com -U users.txt -p Company123 -tp test123 -n 3

使用密码“Company123”进行密码喷射攻击，Tor密码为“test123”，每次请求后修改IP地址，10-20秒随机延迟，用户名顺序不随机：

python3 adfsbrute.py -t company.com -U users.txt -p Company123 -tp test123 -m 10 -M 20 -r False

寻找ADFS URL地址：

python3 adfsbrute.py -t company.com

使用Tor

如需使用Tor在每次发送请求后修改IP地址，你则需要对密码进行哈希计算：

tor --hash-password test123

在文件/etc/tor/torrc中，取消掉ControlPort和HashedControlPassword变量的注释，然后添加下列内容：

ControlPort 9051

HashedControlPassword 16:7F314CAB402A81F860B3EE449B743AEC0DED9F27FA41831737E2F08F87

重启Tor服务，然后使用这个密码以参数的形式传递给脚本（"-tp test123"或"--tor_password 123"）：

service tor restart
