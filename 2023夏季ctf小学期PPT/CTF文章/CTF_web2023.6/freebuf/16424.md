导 语

华云安一直持续跟进和研究前沿漏洞、复现和编写漏洞检测脚本（PoC），并赋能给自身产品。

根据近期漏洞爆发与华云安安全实验室研究情况，本周输出以下重要PoC漏洞检测脚本。涉及Grafana监控工具、Apache Airflow平台、GitLab以及其他摄像机、路由器等IoT设备相关漏洞，其风险等级、危害程度等均为高危。

华云安以下产品具有同步支持以下漏洞的检测和验证或者利用的能力：

灵洞威胁与漏洞管理平台Ai.Vul

灵鉴弱点识别与检测系统Ai.Scan

灵刃智能化渗透攻防系统Ai.Bot

蚂蚁PoC漏洞扫描工具

猎鹰Exp漏洞利用工具

01 CVE-2021-43798

//基本信息

编号：CVE-2021-43798

名称：Grafana路径遍历漏洞

等级：HIGH

CVSS：7.5

发布时间：2021-12-10

// 漏洞描述及危害

Grafana是Grafana实验室的一套提供可视化监控界面的开源监控工具。该工具主要用于监控和分析Graphite、InfluxDB和Prometheus等。Grafana 8.0.0-beta1至8.3.0存在安全漏洞，攻击者可利用该漏洞执行目录遍历攻击，访问本地文件。

//影响范围

Grafana 8.0.0-beta1至8.3.0

//解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://github.com/grafana/grafana/security/advisories/GHSA-8pjx-jj86-j47p

02 CVE-2021-38540

// 基本信息

编号：CVE-2021-38540

名称：Apache Airflow 未授权漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-09-09

//漏洞描述及危害

Apache Airflow是美国阿帕奇（Apache）基金会的一套用于创建、管理和监控工作流程的开源平台。该平台具有可扩展和动态监控等特点。Apache Airflow 中存在授权问题漏洞，该漏洞源于产品的import端点缺少授权保护。攻击者可通过该漏洞在DAG中添加或修改变量导致拒绝服务、信息泄露或代码执行。

//影响范围

Apache Airflow >= 2.0.0

Apache Airflow <= 2.1.2

//解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。补丁链接：

https://lists.apache.org/thread.html/rb34c3dd1a815456355217eef34060789f771b6f77c3a3dec77de2064%40%3Cusers.airflow.apache.org%3E

03 CVE-2021-22214

//基本信息

编号：CVE-2021-22214

名称：GitLab 请求伪造漏洞

等级：HIGH

CVSS：8.6

发布时间：2021-06-08

// 漏洞描述及危害

GitLab是美国GitLab公司的一款使用Ruby on Rails开发的、自托管的、Git（版本控制系统）项目仓库应用程序。该程序可用于查阅项目的文件内容、提交历史、Bug列表等。GitLab CE EE存在安全漏洞，该漏洞源于当对内部网络的webhook请求被启用时存在请求伪造漏洞。

当对内部网络的webhook请求被启用时攻击者可以利用存在缺陷的web应用作为代理攻击远程和本地的服务器。

//影响范围

GitLab CE EE

//解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。补丁链接：

https://gitlab.com/gitlab-org/cves/-/blob/master/2021/CVE-2021-22214.json

04 CVE-2021-41951

//基本信息

编号：CVE-2021-41951

名称：Montala ResourceSpace 跨站脚本漏洞

等级：MEDIUM

CVSS：5.5

发布时间：2021-11-15

//漏洞描述及危害

Montala ResourceSpace是英国Montala公司的一种开源数字资产管理工具。使用户能够组织他们的数字资产。Montala ResourceSpace 9.5 和 9.6 rev 18277版本存在跨站脚本漏洞，攻击者可以通过让受害者访问精心制作的URL来执行恶意的JavaScript。

//影响范围

Montala ResourceSpace 9.5

Montala ResourceSpace 9.6

//解决方案

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：https://www.resourcespace.com/

05 CVE-2021-33544

//基本信息

编号：CVE-2021-33544

名称： Geutebrvck G-Cam E2 和 G-Code 代码执行漏洞

等级：CRITICAL

CVSS：9.6

发布时间：2021-07-27

// 漏洞描述及危害

Geutebrück G-Cam E2是manualslib的一个摄像机。Geutebrück G-Cam E2 存在命令注入漏洞，该漏洞源于受影响的产品容易受到命令注入的攻击。这可能允许攻击者可利用该漏洞远程执行任意代码。受影响的产品及版本：E2 Series cameras – G-CAM：1.12.0.27版本及之前版本、1.12.13.2版本、1.12.14.5版本；Encoder G-Code：1.12.0.27版本及之前版本、1.12.13.2版本、1.12.14.5版本。

//影响范围

E2 Series cameras G-CAM 1.12.0.27

Encoder G-Code 1.12.0.27

//解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。补丁链接：

https://us-cert.cisa.gov/ics/advisories/icsa-21-208-03

06 CVE-2021-35336

//基本信息

编号：CVE-2021-35336

名称：Tieline IP Audio Gateway 信息泄露漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-07-01

//漏洞描述及危害

IP Audio Gateway是Tieline的一个音频编解码器。Tieline IP Audio Gateway存在访问控制错误漏洞，该漏洞源于Tieline Web Administrative Interface中的漏洞可能允许未经身份验证的用户使用高特权帐户访问系统的敏感部分。

//影响范围

Tieline IP Audio Gateway

//解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。补丁链接：

https://pratikkhalane91.medium.com/use-of-default-credentials-to-unauthorised-remote-access-of-internal-panel-of-tieline-c1ffe3b3757c

07 MPSec ISG1000本地文件包含漏洞

//基本信息

编号：无

名称：MPSec ISG1000本地文件包含漏洞

等级：HIGH

CVSS：7.5

发布时间：2021-06-10

//漏洞描述及危害

迈普通信技术股份有限公司成立于1993年，是国内领先的网络产品及解决方案供应商。迈普通信技术股份有限公司MPSec ISG1000安全网关存在本地文件包含漏洞，攻击者可利用该漏洞获取敏感信息。

//影响范围

MPSec ISG1000

//解决方案

当前官方暂未发布修复方案，建议受影响的用户及时关注更新官方：http://www.maipu.cn/
