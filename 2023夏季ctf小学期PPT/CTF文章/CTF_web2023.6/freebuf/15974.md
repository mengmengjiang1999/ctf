netdiscover -r 192.168.88.0/24或者：arp-scan -l查看靶机的ip地址

访问IP地址：192.168.190.131，并不能直接访问，在hosts文件中添加网址，成功访问

成功找到flag1，根据flag1可以看出要得到flag2需要登录才可以拿到，我们扫描一下

访问wp-login这里看到是wordpress的系统，kali里面有测试工具，用wpscan扫描有户名和密码只有用户名没有密码，回想起flag1提示要用cewl生成密码

建议使用cewl生成字典，这里学习一下cewl的用法。

Cewl

Cewl是一款采用Ruby开发的应用程序，你可以给它的爬虫指定URL地址和爬取深度，还可以添额外的外部链接，接下来Cewl会给你返回一个字典文件，你可以把字典用到类似John the Ripper这样的密码破解工具中。除此之外，Cewl还提供了命令行工具。

cewl讲解地址

再次使用wpscan，密码用我们生成的密码字典找到可以登录的用户Jerry和tom，登录jerry发现flag2，它说：如果你不能利用WordPress并走捷径，还有另一种方法。希望你能找到另一个切入点。

登录tom发现并没有flag3，另一个切入点，突然想起还没有扫描端口，扫描端口

发现还有个7744端口开放着，刚才的tom账户有可能是SSH账户，使用tom做ssh登录但是并不能直接cat flag3，查看flag时遇到了问题，默认提供的是rbash(受限shell)，仅能实现少量功能。

这里查看了网上大佬的解决方法可以用vi来设置获取一个新的shell

vi
进入底行模式
set shell=/bin/sh
shell

然后设置环境变量：

export PATH=/usr/sbin:/usr/bin:/sbin:/bin可怜的老汤姆总是追着jerry什么意思哦，jerry又有什么压力呢，我们去jerry家看看，发现flag4，查看后发现要用

git out？git？好吧，猜到git我也不会

使用sudo -l，查看当前身份可运行命令时，提示tom用户无法运行sudo命令；这时想到可以尝试登陆jerry用户。

使用su jerry，输入前面得到的密码，登陆jerry用户。发现jerry可以用git命令，这里在GTFOBins里看看

https://gtfobins.github.io/gtfobins/git/

应用提权：

sudo git help config
