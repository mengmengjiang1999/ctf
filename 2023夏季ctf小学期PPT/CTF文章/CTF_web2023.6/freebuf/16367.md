利用windows server 2012 和phpstudy2018 搭建安全狗本地测试环...
2022-01-01 16:11:08

注：写这篇文章的初衷，我在搭建这个环境的时候，在网上没找到好用的教程，都是解决某一个点，或者安装过程中的某一个问题，但是没有一个全流程的这样一个搭建笔记，所以我在找了很多文章，参考了很多大佬的笔记后，环境搭建完成后，打算写这样一个全流程的搭建笔记，希望可以帮到和我一样的小白在搭建这个环境的时候可以更加省心省时间。

这里先讲一下我在搭建过程中用到的东西：

1.     VMware Workstation 15.5 pro
  2.	Windows Server 2012 R2 (x64)- DVD(Chinese-Simplified)
  3.	迅雷
  4.	phpstudy2018 
  5.	sqli-labs-master
  6.	网站安全狗(APACH版)V4.0正式版








我这里用找win server 2012的镜像开始讲起，这里用到了一个好用的资源网站，

https://msdn.itellyou.cn/ 进入后直接搜索，我用的是下图中框中的这个镜像

然后我们点开详细信息会发现，这个网站只支持用ed2k链接的方式下载，这里需要用到迅雷，

复制上面框中的内容然后打开迅雷（一定要登录，不然速度很慢，登录后几分钟就下载好了）

然后就是新建虚拟机，把刚下载好的镜像添加就行了，按步骤一步一步来，这里不多说。

安装好win 2012 的虚拟机后，我们进去win 2012虚拟机后，先进行一个操作：就是切换用户为administrator
操作的话很简单，按 ctrl+alt+delete 就可以看到切换用户的选项了。(如下图所示，我这里是已经创建过管理员用户的图，没有的创建的话这里会显示，直接创建就行)

创建完管理员用户，登录管理员账户，因为之后有一个操作需要我们用管理员用户来操作。（我这里提前让大家切换成管理员账户）

然后会发现用浏览器下载东西下载不了，这里需要设置一下。

为了安全，Windows服务器默认禁用了从网上下载文件的安全选项。此错误即是出现在这里，所以打开这个选项即可：

控制面板 —— Internet选项 ——安全 —— 找到“自定义级别” —— 找到“下载”项，其中有“文件下载”勾选框，勾选“启用“即可。

不要忘记点应用

到这里就可以在虚拟机上通过浏览器下载东西了，但是我们会发现一个问题，我们在vm workstation上 想点安装 vmtools的时候，
发现不能安装，经过我搜索资料发现，Windows Server 2012 R2操作系统上安装vmtools需要先安装下面两个补丁

注意：按照我说的顺序来安装

在VMware虚拟机中的Windows Server 2012 or Windows Server 2012 R2操作系统上安装Windows8.1-KB2919442-x64.msu 与 Windows8.1-KB2919355-x64.msu更新文件。
下面是安装这两个补丁的链接，

下载Windows8.1-KB2919442-x64.msu链接：https://www.microsoft.com/zh-cn/download/details.aspx?id=42162

下载Windows8.1-KB2919355-x64.msu链接：https://www.microsoft.com/zh-cn/download/details.aspx?id=42335

在安装第二个补丁（第二个补丁其实是一组补丁）的时候，先把这组补丁的其他所有补丁都打完，最后再安装KB2919355这个补丁即可，如下图所示:

安装补丁后重启虚拟机，然后重启VMware Workstations，再来安装vmtools即可成功安装。

前面的准备工作有点长，现在正式开始搭建绕waf的测试环境，接下来就是安装phpstudy和sqli-labs，这里不多说，网上博客写这个的很多，
我这里给一个参考链接：https://binghe.blog.csdn.net/article/details/84262285?spm=1001.2101.3001.6650.2&utm_medium=distribute.pc_relevant.none-task-blog-2%7Edefault%7ECTRLIST%7Edefault-2.no_search_link&depth_1-utm_source=distribute.pc_relevant.none-task-blog-2%7Edefault%7ECTRLIST%7Edefault-2.no_search_link&utm_relevant_index=5

操作完上面这些步骤，我们已经搭建好了可以使用的sqli-labs的靶场，下面我们开始装安全狗，直接去官网下载即可，我这里用的是 网站安全狗(APACH版)V4.0正式版。

下面我们需要进行以下配置，

按照下面链接文章的一步步操作，开放80端口。

https://jingyan.baidu.com/article/e75057f2c463e8ebc81a8960.html

然后我们需要查看apache服务有没有，如下图所示


如果没有，不要慌，因为我当时也没有，上图是我已经安装好后截的图，下面我来讲怎么安装

注：以下操作一定要用管理员权限打开dos命令窗口(上面我们已经切换成管理员账户了所以直接打开cmd窗口就行，我这里只是再强调一遍)

然后输入以下命令：

httpd.exe -k install -n apache2.4        //创建Apache服务，第一遍可能会有询问，再输一遍就好了


然后我们再去查看上面的这个位置，应该就有apache服务了

然后我们就可以安装网站安全狗插件了

安装完这些后，重启虚拟机，然后打开phpstudy点启动，记得看安全狗这个软件是否启动了（废话）。然后访问，发现安全狗可以正常拦截了

到这里整个安全狗本地测试环境到这里就搭建好了，可以愉快的进行测试了。
