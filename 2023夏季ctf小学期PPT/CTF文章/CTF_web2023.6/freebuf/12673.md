DigiCert 的SSL证书种类
2022-04-24 14:38:01

DigiCert是可信CA机构，是行业根证书颁发机构之一，它的证书几乎兼容所有主流浏览器。DigiCert 专注于SSL证书和SSL管理工具，并收购了 Symantec 的证书业务。

现在，DigiCert 系列证书可在沃通CA官网申请：

DigiCert 证书申请地址：https://www.wosign.com/other_ssl.htm


DigiCert 证书

DigiCert 提供的 SSL证书类型丰富，主要有 Basic 系列、Secure Site 以及 Secure Site Pro 系列，还有保留了 Geotrust、Thawte、RapidSSL 等 SSL品牌。

DigiCert 系列：

DigiCert 系列产品专门面向企业提供SSL证书，分为OV和EV两个级别。主要包括DigiCert Basic SSL、Secure Site SSL、Secure Site Pro SSL三款。

DigiCert Basic SSL

这是 DigiCert 比较基础的SSL证书，满足企业的基本加密需求，提供基本安全保障。普通的单位组织均可申请这款证书。

DigiCert Secure Site SSL

包涵基础版的所有功能，支持优先支持和验证，拥有智能签章，支持组织列表检查、黑名单检查和恶意软件扫描。多被中高需求用户选择。

DigiCert Secure Site Pro SSL

是 Secure Site 的专业版，强制128位加密，零妥协证书，提供完整的加密服务。拥有漏洞评估、CT日志监控、欺诈检查等，多被银行证券等金融行业选择。

Geotrust 品牌

Geotrust 是 DigiCert 旗下的品牌，可以实现相对低成本地部署SSL数字证书和实现各种身份认证，为用户提供 DV、OV、EV三个等级的SSL证书。因其相对经济实惠，Geotrust在市场上累计了大量的用户，知名度较高。

RapidSSL 品牌

Rapid SSL是 GeoTrust 的下属品牌，现属于 DigiCert 旗下业务，使用DigiCert的根证书，面向个人和小微企业提供的SSL/TLS证书产品，主要是DV SSL证书，不限制服务器安装数量。 Rapid SSL采用在线验证方式，一般只需要10分钟就可以完成服务器证书的签发。RapidSSL是低成本解决网站https安全问题的选择之一。

Thawte 品牌

Thawte是比较早的SSL证书颁发机构，产品包括DV、OV、EV多个级别，累积了众多的忠诚客户。现属 于DigiCert 旗下子品牌。

DigiCert 品牌证书产品种类众多，选择多样，从 DV SSL 到 EV SSL、搭配灵活，支持多个域名合并一张证书集中管理，非常方便。
