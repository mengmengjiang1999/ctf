不容小视的漏洞CVE-2022-30190: Microsoft 支持诊断工具远程代码执行漏洞爆出！
2023-02-10 11:07:17

漏洞描述:

从Word等调用应用程序或者使用URL协议调用MSDT时存在RCE (Remote Code Execute)远程代码执行漏洞. 成功利用漏洞者可以使用调用应用程序的权限运行任意代码.

在去年爆出CVE-2021-40444时因为MSHTML存在RCE, 而今年CVE-2022-30190的发现者受到CVE-2021-40444的启发而发现了这个漏洞.


漏洞背景：

2022年5月30日，各大网站发布了CVE-2022-30190的在野利用通告，漏洞等级：严重，处置建议：立即修复。目前该漏洞的补丁已经发布，漏洞的细节以及漏洞的EXP（Exploit）已经公开，在野利用也已经被发现。

作者已经在第一时间完成漏洞复现


漏洞状态：

漏洞细节: 已公开

漏洞PoC: 已公开

漏洞EXP: 已公开

漏洞在野利用: 已发现

攻击复杂度: 复杂

攻击路径: 远程

补丁情况: 官方暂未给出补丁

影响范围: 全局

数据保密性影响: 数据泄露

CVSS评分:

7.8/7.3

阿里云评分:

8.6

临时修补建议：

一. 禁用 MSDT URL 协议可防止故障排除程序作为链接启动，包括整个操作系统的链接。仍然可以使用“获取帮助”应用程序和系统设置中的其他或附加故障排除程序来访问故障排除程序。请按照以下步骤禁用：

1、以管理员身份运行命令提示符。

2、备份注册表项，执行命令“reg export HKEY_CLASSES_ROOT\ms-msdt filename ”

3、执行命令“reg delete HKEY_CLASSES_ROOT\ms-msdt /f”。

如何撤消解决方法

1、以管理员身份运行命令提示符。

2、导入备份注册表项，执行命令“reg import filename”

二. 移除DataStore 文件

 1. 点击[开始], 在其中输入msc, 在你的搜索框当中会出现一个应用程序, 点击打开
 2. 一个新的窗口将会被打开, 在这里面搜索Windows Update, 并且右键停止Windows Update
     1. 
 3. 现在我们可以关闭msc这个窗口, 回到桌面
 4. 按住ctrl右边的windows键, 并且同时按下R键, 会出来一个输入框
 5. 输入%windir%SoftwareDistributionDataStore在搜索框当中, 并回车或点击OK
 6. 这会打开一个新的窗口, 将下面三个文件全部删除
 7. 随后重复第一步和第二步, 这步需要将Windows Update打开

想要察觉是否被攻击?


你可以打开regedit(windows注册表)查看过去是否有连接的情况, 根据端口以及可疑IP(域名)进行判断.
