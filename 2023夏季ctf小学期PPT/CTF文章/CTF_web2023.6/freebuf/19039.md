02 CNNVD采用的重点漏洞回顾

■ SonicWall Analytics 远程代码执行漏洞

漏洞编号：CVE-2021-20032

危害等级：超危

漏洞类型：代码问题

漏洞描述：由于存在Java 调试线协议 (JWDP) 服务漏洞，未经身份验证的攻击者可利用该漏洞在系统内执行任意代码。

■ VMware vCenter Server 任意文件上传漏洞

漏洞编号：CVE-2021-22005

危害等级：超危

漏洞类型：代码问题

漏洞描述：VMware vCenter Server 存在代码问题漏洞，该漏洞源于在Analytics服务中上传文件时文件验证不足导致。未经身份验证的攻击者可以通过网络访问443端口，在目标系统上传和执行任意文件。

■ 飞利浦 Vue PACS 安全配置漏洞

漏洞编号：CVE-2021-33020

危害等级：高危

漏洞类型：配置错误

漏洞描述：由于该平台仍在使用过期的安全密钥，攻击者可以通过使用曾经泄露的密钥对系统发起攻击。

■ VMware vCenter Server 远程执行代码漏洞

漏洞编号：CVE-2021-21972

危害等级：超危

漏洞类型：代码问题

漏洞描述：具有443端口访问权限的恶意攻击者可以通过向vCenter Server发送精心构造的请求，最终造成远程任意代码执行。

■ 飞利浦 Vue PACS 身份信息明文传输漏洞

漏洞编号：CVE-2021-33024

危害等级：高危

漏洞类型：代码问题

漏洞描述：由于该平台在传输或存储身份验证凭据时使用了明文传输，攻击者可以通过嗅探、网络流量拦截获得身份验证凭据，从而进行进一步攻击。
