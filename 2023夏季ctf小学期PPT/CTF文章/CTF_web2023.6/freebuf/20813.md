oracle

用户管理

用户分类

SYS/SYSTEM用户

系统用户

应用用户

用户名

字母开头，包含数字、$、_，不超过30个字符

区分大小写，自动转换为大写

保留字、特殊字符使用双引号包含

账户状态

打开 (OPEN)

锁定 (LOCKED)

过期 (EXPIRED)

过期并锁定 (EXPIRED & LOCKED)

正常过期 (EXPIRED(GRACE))

超时锁定 (LOCKED(TIMED)

过期并超时锁定 (EXPIRED & LOCKED(TIMED))

正常过期并锁定(EXPIRED(GRACE)&LOCKED)

正常过期并超时锁定 (EXPIRED(GRACE)&LOCKED(TIMED))

默认表空间、临时表空间、表空间配额

表空间保存用户创建的任何模式对象

新建用户默认使用USER表空间

新建用户默认使用TEMP表空间

身份验证

数据库身份验证

SQL> select * from dba_users;

DBA_USERS视图

SQL> select text from dba_views where view_name='DBA_USERS';

SQL> select * from sys.user$;

外部身份验证(操作系统)

加入操作系统ora_dba组

添加外部用户

SQL> select value from v$parameter where name='os_authent_prefix';

SQL> create user "OPS$WINDOWS\USER1" identified externally;

SQL> grant connect to "OPS$WINDOWS\USER1";

禁止操作系统身份验证

%ORACLE_HOME%\network\admin\sqlnet.ora SQLNET.AUTHENTICATION_SERVICES=(NONE)

全局身份验证 (LDAP)

创建用户检查清单

确定用户需要存储数据的表空间

确定每个表空间的限额

指定默认表空间和临时表空间

创建用户

授予用户权限和角色

创建用户

SQL> create user aaron identified by soccer;

删除用户

SQL> drop user aaron; SQL> drop user aaron cascade;

锁定/解锁用户

SQL> alter user aaron account lock;

SQL> alter user aaron account unlock;

强制用户密码过期

SQL> alter user aaron password expire;

配置文件

密码和资源限制的命名的集合

SQL> create profile "sec_profile" limit failed_login_attempts 6

password_lock_time 1

password_grace_time 7

password_life_time 90

password_reuse_max 5

password_verify_function 密码检查函数名;

SQL> alter user 用户名 profile "sec_profile";

修改密码

SQL> alter user 用户名 identified by “newpasswd” ;

配置文件

删除配置文件

SQL> drop profile developer_prof;

SQL> drop profile developer_prof cascade;

查看配置文件

SQL> select * from dba_profiles;

Oracle系统权限

创建表、创建用户等影响数据字典的操作

SQL> create session;

SQL> create table;

SQL> create user;

SQL> select any table;

SQL> grant 权限 to 用户名;

SQL> grant 权限 to 用户名 with admin option;

SQL> revoke 权限 from 用户名;

查看Oracle系统权限

SQL> select * from dba_sys_privs;

SQL> select * from dba_sys_privs where grantee='scott';

Oracle对象权限

针对表和相关对象执行SELECT、INSERT、UPDATE、DELETE操作

SQL> grant select on hr.employees to scott;

SQL> grant select on hr.employees to john with grant option;

SQL> grant all on hr.regions to scott;

SQL> revoke all on hr.regins from scott;

对象权限的撤销会级联，系统权限不会

查看Oracle对象权限

SQL> select * from dba_tab_privs;

SQL> select grantee,privilege,grantor,grantable from dba_tab_privs where owner='scott' and table_name='employees';

Oracle角色

创建角色、赋予角色权限

SQL> create role 角色名;

SQL> grant create session to 角色名;

SQL> grant insert,update,delete on hr.employees to 角色名;

SQL> revoke all from 角色名;

角色赋予用户

SQL> grant 角色名 to 用户;

查看角色

SQL> select * from dba_role_privs;

限制sysdba角色远程登录

SQL> select value from v$parameter where name='remote_login_passwordfile';

默认为exclusive

SQL> alter system set remote_login_passwordfile='none' scope=spfile;

查看sysdba角色用户

SQL> select * from v$pwfile_users;

赋予sysdba角色到用户

SQL> grant sysdba to 用户名;

数据字典保护

SQL> grant select any table to 用户名;

SQL> select value from v$parameter where name='O7_DICTIONARY_ACCESSIBILITY';

SQL> alter system set O7_DICTIONARY_ACCESSIBILITY=false scope=spfile;

SQL> select * from sys.user$;

PUBLIC权限

一种角色、隐式赋予每位用户、能执行很多PL/SQL

SQL>select table_name from dba_privs where grantee='PUBLIC' and privilege='EXECUTE' and table_name like 'UTL%';

不安全的程序包 UTL_FILE、UTL_TCP、UTL_SMTP、UTL_HTTP

SQL> revoke execute on 程序包名 from public;

Oracle常见问题

弱口令、默认口令

应用用户赋予DBA角色

Oracle补丁管理

临时修补程序 (Interim)

精确版本，修复具体问题，缺少测试，不集成

CPU修补程序 (Critical Patch Update)

特定发布版积累修补程序，3个月发布一次

修补程序集 (PatchSets)

产品修补集合，升级版本号，11.1.0.6到11.1.0.7

Oracle审计

审计SYSDBA

审计以sysdba、sysoper连接数据库的用户

SQL> select value from v$parameter where name=' audit_sys_operations';

Windows记录在Windows应用程序日志中

Unix/Linux记录位置由audit_file_dest参数控制

SQL> select value from v$parameter where name=' audit_file_dest’;

数据库审计

SQL> select value from v$parameter where name=' audit_trail ';

默认是none，支持以下参数：

OS: 审计记录写入操作系统

DB: 审计记录写入sys.aud$

XML: 与OS相同，格式为XML

DB_EXTENDED、XML_EXTENDED 开启审计记录：

SQL> alter system set audit_trail='db' scope=spfile;

SQL> audit create any trigger;

SQL> audit insert on ar_parties whenever successful;

SQL> audit session whenever not successful;

SQL> noaudit insert on ar_parties;

查看审计结果

SQL> select * from sys.aud$;

显示数据库审计

SQL> select * from dba_audit_trail;

触发器审计

--保存审计值

create table salary_audit

( EmployeeID number,

OldSalary number(9,2),

NewSalary number(9,2),

Username varchar2(50),

DateChange date,

constraint pk_salary_audit primary key

(EmployeeID,DateChanged) );

create or replace trigger audit_salaries

after update on hr.employee

for each row

begin

if (:NEW.Salary > :OLD.Salary*1.20) then

insert into salary_audit (EmployeeID,OldSalary,NewSalary, Username,DateChanged)

values (:NEW.EmployeeID, :OLD.Salary,NEW.Salary, User,sysdate);

end if;

end; /

测试修改

SQL> update Employee set Salary=Salary*2 where EmployeeID=1;

SQL> commit;

查看审计记录

SQL> select * from Salary_Audit;
