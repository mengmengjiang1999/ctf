三大数据库的端口分别如下：

sql server ：1433

mysql ：3306

oracle ：1521

access适合小网站

sql server的最高权限用户是sa

mysql的最高权限用户是root

Jsp网站：tomcat+struts2环境搭建

我们常用的中间件有：IIS（80），Apache（80）, Nginx, tomcat(8080), jboss(8080), weblogic(7001)，redis（6379），tengine

如何知道对方的服务器是什么系统：

1：通过系统扫描器：Nmap，天镜，Nessus，极光。

2：通过web页面的大小写来区分，Linux区分大小写，Windows不区分大小写。

3：通过ping值来区分。

4:通过网站后缀名也可以区分。

中间件weblogic的默认口令是weblogic，jboss的默认口令是admin admin，tomcat的默认口令是tomcat。

网站的三种访问模式：多端口，多ip，主机头。

内网ip一般有：192.168.x.x 172.16.x.x 10.x.x.x
