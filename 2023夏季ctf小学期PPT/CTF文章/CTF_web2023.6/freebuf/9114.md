0x01 Virtual Private Network相关介绍

Virtual Private Network即（Virtual Private Network）虚拟专用网络，是通过在公共网络上建立专用网络进行加密通讯。Virtual Private Network的使用场景在企业单位或学校中极为广泛，一般企业或学校内部使用的内网系统为了安全起见不允许公网进行访问。但对于一些使用场景中用户不在公司或学校内的时候就无法正常访问到内网的系统。Virtual Private Network的使用可以通过以建立虚拟专用网连接进行访问内网。
Virtual Private Network可通过服务器、硬件、软件等多种方式实现。它涵盖了跨共享网络或公共网络的封装、加密和身份验证链接的专用网络的扩展。Virtual Private Network主要采用了隧道技术、加解密技术、密钥管理技术和使用者与设备身份认证技术。

0x02 Virtual Private Network的分类

根据Virtual Private Network的不同划分标准，可以对Virtual Private Network进行如下几个分类：

1.按照Virtual Private Network的协议进行分类

按照Virtual Private Network的三种隧道协议PPTP、L2TP和IPSec。其中PPTP和L2TP协议工作在OSI模型的第二层，又称为二层隧道协议，IPSec是第三层隧道协议。还有一种基于SSL的V P N技术。SSL协议位于TCP/IP协议与各种应用层协议之间，是目前最常用的Virtual Private Network形式。

2.按照V P N的应用分类

根据Virtual Private Network网络的应用可以将Virtual Private Network分为三类：Client-LAN类型、LAN-LAN类型、ExtranetV P N类型。
Client-LAN类型又称Access V P N(远程接入Virtual Private Network)：实现客户端到网关，使用公网作为骨干网在设备之间传输V P N的数据流量。应用场景比如员工出差远程连接公司内网办公。
LAN-LAN类型又称Intranet V P N(内联网Virtual Private Network)：实现网关到网关，通过公司的网络架构连接来自同公司的资源。应用场景比如实现不同地域的分公司局域网内网通过该种方式进行内网互联。
Extranet Virtual Private Network（外联网Virtual Private Network）即与合作伙伴企业网构成Extranet，将一个公司与另一个公司的资源进行连接，这和上一种Virtual Private Network类似。

3.按照所用的设备类型分类

网络设备提供商针对不同客户的需求，开发出不同的Virtual Private Network网络设备，主要为交换机、路由器和防火墙。
（1）交换机式Virtual Private Network：主要应用于连接用户较少的Virtual Private Network网络。
（2）路由器式Virtual Private Network：路由器式Virtual Private Network部署较容易，只要在路由器上添加Virtual Private Network服务即可。
（3）防火墙式Virtual Private Network：这是最常见的一种Virtual Private Network的实现方式，许多厂商都提供这种配置类型。

0x03 HW中网络设备Virtual Private Network使用

在HW打点中有时候会打点到目标的网络设备路由器或是一些安全设备等，通过若口令或其他方式在进入后台获取到设备的权限得到的分数是非常有限的，通过获取到的设备我们下一步如何进行利用是否能通过获取到的有用信息最大化利用获取更高的分数。

目前在众多厂商的网络设备中大多都能够实现web界面方式管理，且在后台中都有Virtual Private Network访问功能，如下两截图列举了某两厂商的网络设备。目前网络设备中对于几种常用的Virtual Private Network方式PPTP、L2TP、SSL和IPSec等方式都是支持的，在获取到设备后台权限后，我们通过配置任意一种Virtual Private Network都可以达到实现访问设备所连接内网的目的，可以进一步对设备部署的内网进行内网渗透。


0x04 SC Virtual Private Network基本配置步骤

SC Virtual Private Network即Secure Connect Virtual Private Network的缩写，在系统中有时候指SSL Virtual Private Network，SC Virtual Private Network与其他几种Virtual Private Network的配置过程基本相同，根据不同产品的特点略有细微差别，但总体配置点都是一样的。
在SC Virtual Private Network的配置中大致配置项如下：
1.配置SC Virtual Private Network地址池
SC Virtual Private Network地址池用于Virtual Private Network用户登录到内网系统后为用户进行地址分配，当我们使用Virtual Private Network登录到内网，这时会从SC Virtual Private Network配置地址池中分配一个IP地址给用户。

2.配置SC Virtual Private Network实例
实例配置要根据登录需求，在配置前应先查看设备各个接口的地址和连接情况，判断外网接口和内网接口然后根据需求进行入口地址和出口地址选择，并对Virtual Private Network登录组和地址池进行相应选择。
3.创建三层安全域
安全域是为对某些接口统一管理，与路由器VLAN概念x相似是个虚拟的概念，默认网络设备中配置的安全域中已经将接口进行不同域的划分，在配置Virtual Private Network入口时创建的隧道接口需要创建新的域进行管理。

4.创建隧道接口
隧道接口是为Virtual Private Network访问的出口和入口选择相应的网卡接口，一般配置入口即为访问网络设备的公网地址接口网卡，出口为内网网段网卡接口。

5.创建访问策略
通过SC Virtual Private Network拔入后需要有相应的安全策略允许才能访问内网中的资源，通过安全策略可以控制不同用户的访问权限。默认情况下我们需要创建一个域在通过创建一条该域从到trust区域的安全策略，这样才能实现虚拟连接。
6.创建Virtual Private Network登录用户
Virtual Private Network账户是用户登录到 Virtual Private Network时授权与认证的凭证，起到安全防护作用，Virtual Private Network配置完成后通过创建的用户进行远程登录。

0x06 小结

在日常hw中如果能够获取到一些网络设备的后台权限很多时候都认为是没有day就没有办法进行下一步利用了，但目前大部分设备都有内置Virtual Private Network功能，获需通过今天介绍的这种方式能够对读者在今后的实战中有所思路上的帮助，网络设备的Virtual Private Network根据协议分类有多种，可以进行多种配置进行尝试，另外再告诉大家一个配置技巧，在一般的网络设备中所有的配置使用方法功能都可以通过设备厂商的产品说明书中找到。
