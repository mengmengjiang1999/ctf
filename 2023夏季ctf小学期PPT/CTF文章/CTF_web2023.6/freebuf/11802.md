华云安漏洞安全周报【第84期】
2022-05-19 14:36:19

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.5.9~2022.5.15）CNNVD接报漏洞608个，信息技术产品漏洞（通用型漏洞）137个，网络信息系统漏洞（事件型漏洞）471个；CNNVD接报漏洞预警165份，其中华云安报送预警13份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-1633-Google Chrome for Android UAF 漏洞、Microsoft 5月多个安全漏洞、CVE-2022-28829-Adobe Framemaker 越界写入漏洞、CVE-2022-30525-Zyxel 防火墙命令注入漏洞、CVE-2022-22282-SONICWALL SSLVPN SMA1000访问控制绕过漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-1633-Google Chrome for Android UAF 漏洞

威胁等级：高危

漏洞描述：

2022年5月9日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome for Android 组件中存在一处 UAF 漏洞。Chrome 是一款快速、易用且安全的网络浏览器。该漏洞是由于 Sharesheet 释放后重用引起，成功利用此漏洞的攻击者通过诱使用户访问特制网页，从而触发释放后重用错误，导致在系统上执行任意代码攻击。

情报来源：

https://chromereleases.googleblog.com/2022/05/chrome-for-android-update.html

02Microsoft 5月多个安全漏洞

威胁等级：严重

漏洞描述：

2022年5月10日，华云安思境安全团队发现 Microsoft 官方发布5月份安全更新，共发布了76个漏洞的补丁程序，其中 Microsoft Windows 漏洞51个。主要涵盖了 Microsoft Windows 和 Windows 组件、Microsoft Windows ALPC、Windows Failover Cluster Automation Server、MicrosoftGraphics Component、Microsoft Excel、Microsoft Windows WLAN Auto Config Service 等多个产品和组件。在漏洞安全等级方面，有3个严重漏洞，50个高危漏洞；在漏洞类型方面，主要有27个为输入验证错误漏洞，17个为信息泄露漏漏洞，16个为竞争条件问题漏洞以及16个其他漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：

https://msrc.microsoft.com/update-guide/releaseNote/2022-May

03CVE-2022-28829-Adobe Framemaker 越界写入漏洞

威胁等级：高危

漏洞描述：

2022年5月10日，华云安思境安全团队发现 Adobe 官方发布安全更新，披露了 Adobe Framemaker 组件中存在一处越界写入漏洞。Adobe Framemaker是 Adobe 公司的一套用于编写和编辑大型或复杂文档（包括结构化文档）的页面排版软件。该漏洞是由于在处理嵌入字体时的边界错误引起，成功利用此漏洞的攻击者通过诱使用户打开恶意创建的特制文件，从而触发越界写入，最终导致在目标系统上执行任意代码攻击。

情报来源：

https://helpx.adobe.com/security/products/framemaker/apsb22-27.html

04CVE-2022-30525-Zyxel 防火墙命令注入漏洞

威胁等级：超危

漏洞描述：

2022年5月12日，华云安思境安全团队发现 Zyxel 官方发布安全更新，披露了 Zyxel 防火墙组件中存在一处命令注入漏洞。Zyxel 是网络宽带系统及解决方案的供应商，Zyxel USG FLEX是一款防火墙，提供灵活的 VPN 选项（IPsec、SSL 或 L2TP），为远程工作和管理提供灵活的安全远程访问。该漏洞是由于在 CGI 程序中未对用户输入进行过滤引起，成功利用此漏洞的攻击者可修改特定文件，从而在易受攻击的设备上执行一些操作系统命令。

情报来源：

https://www.zyxel.com/support/Zyxel-security-advisory-for-OS-command-injection-vulnerability-of-firewalls.shtml

05CVE-2022-22282-SonicWall SSLVPN SMA1000 访问控制绕过漏洞

威胁等级：高危

漏洞描述：

2022年5月13日，华云安思境安全团队发现 SonicWall 官方发布安全更新，披露了SonicWall SSLVPN SMA1000 组件中存在一处访问控制绕过漏洞。Sonicwall SMA1000系列产品是一系列安全移动访问解决方案。简化了对跨本地、云和混合数据中心托管的企业资源的端到端安全远程访问。该漏洞是由于 SMA1000 系列设备未正确限制对资源的访问权限，导致不正确的访问控制问题。

情报来源：

https://psirt.global.sonicwall.com/vuln-detail/SNWLID-2022-0009﻿
