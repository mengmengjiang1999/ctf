华云安漏洞安全周报【第102期】
2022-10-14 11:25:05

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.9.12~2022.9.18）CNNVD接报漏洞290个，信息技术产品漏洞（通用型漏洞）152个，网络信息系统漏洞（事件型漏洞）138个，其中华云安报送漏洞47个；CNNVD接报漏洞预警95份，其中华云安报送1份；漏洞报送数量位列第三！

本周重点关注漏洞包括：CVE-2022-31474-WordPress BackupBuddy 任意文件下载漏洞、Microsoft 9月份多个安全漏洞、Lenovo BIOS 9月份多个安全漏洞、CVE-2022-32190- Google Golang 路径遍历漏洞、CVE-2022-36067-vm2沙箱逃逸漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-31474-WordPress BackupBuddy 任意文件下载漏洞

威胁等级：高危

漏洞描述：

2022年9月13日，华云安思境安全团队发现 WordPress BackupBuddy 插件中存在一处任意文件下载漏洞。BackupBuddy 是一个易于使用的 WordPress 备份插件，旨在让 WordPress 网站管理人员轻松管理网站备份。该漏洞是由于存在任意文件读取和下载漏洞，成功利用此漏洞可造成敏感信息泄露。

情报来源：

https://packetstormsecurity.com/files/168292/WordPress-BackupBuddy-8.7.4.1-Arbitrary-File-Read.html

02Microsoft 9月份多个安全漏洞

威胁等级：严重

漏洞描述：

2022年9月14日，华云安思境安全团队发现 Microsoft 官方发布9月份安全更新，共包括64个漏洞的补丁程序，主要涵盖了Microsoft Windows and Windows Components、 Azure and Azure Arc、 .NET and Visual Studio and .NET Framework、 Microsoft Edge (Chromium-based)、 Office and Office Components、 Windows Defender、 Linux Kernel等多个产品组件。在漏洞安全等级方面，有超危漏洞5个，高危漏洞57个，中危漏洞1个，低危漏洞1个。在漏洞类型方面，主要有 31 个远程代码执行漏洞，18 个权限提升漏洞， 6 个信息泄露漏洞以及9个其他漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Sep

03Lenovo BIOS 9月份多个安全漏洞

威胁等级：严重

漏洞描述：

2022年9月15日，华云安思境安全团队发现 Lenovo 发布 BIOS 更新，Lenovo 本次更新修复了 Desktop、Desktop - All in One、Hyperscale、Lenovo Notebook、Smart Edge、Smart Office、Storage、ThinkAgile、ThinkPad、ThinkServer、ThinkStation、ThinkSystem 等数百款设备型号中的多个漏洞。Lenovo是一家全球知名的ICT科技企业，也是全球智能设备的领导厂商。这些漏洞可能会导致信息泄露、权限提升、拒绝服务，并在某些情况下导致任意代码执行，此次漏洞影响范围较广，华云安建议相关用户及时到 Lenovo 官方下载安装对应的安全补丁进行更新！

情报来源：

https://support.lenovo.com/us/en/product_security/LEN-94953

04CVE-2022-32190- Google Golang 路径遍历漏洞

威胁等级：超危

漏洞描述：

2022年9月15日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Golang 组件中存在一处路径遍历漏洞。Google Golang是一种静态强类型、编译型语言。该漏洞是由于 JoinPath 和 URL.JoinPath 不会删除附加到相对路径的路径元素触发，成功利用此漏洞的攻击者可能导致访问系统敏感文件。

情报来源：

https://groups.google.com/g/golang-announce/c/x49AQzIVX-s

05 CVE-2022-36067-vm2沙箱逃逸漏洞

威胁等级：超危

漏洞描述：

2022年9月16日，华云安思境安全团队发现 Github 官方披露了 vm2 组件中存在一处沙箱逃逸漏洞。vm2 是 nodejs 实现的一个沙箱环境，一般用于测试不受信任的 JavaScript 代码。该漏洞是由于沙箱设置没有管理正确的异常处理，导致可以绕过沙箱保护，成功利用此漏洞的攻击者可以在运行沙盒的主机上获得远程代码执行权限。

情报来源：

https://github.com/patriksimek/vm2/security/advisories/GHSA-mrgp-mrhc-5jrq
