Android渗透-01：安卓手机刷入Kali Nethunter
2022-07-17 19:06:15

在安卓逆向或者安卓抓包中，经常会使用root过的的机器，本篇以Oneplus7pro机器为例，详细介绍如何在Android10刷入Kali Nethunter。

主要步骤：

  * 刷入氧OS 10.3.5 系统

  * ​BootLoader解锁

  * 刷入 TWRP

  * 刷入Data解密包和Magisk

  * 刷入 Kali Nethunter

  * 进入 Nethunter 使用

以下讲解详细刷机过程


一、刷入氧OS 10.3.5

1、首先下载刷机需要的系统版本，这里我尝试成功的版本是 OOS 10.3.5 版本，下载地址：https://yun.daxiaamu.com/OnePlus_Roms_2/%E4%B8%80%E5%8A%A07%20Pro/，找到相应的版本，下载的版本如下：

开始刷机

  * 我选择的虚拟机 win7 环境进行刷机，注意在刷机前需要安装好 9008 相关的驱动，可以使用“一加全机型万能工具箱v3.8.5” 或者 “一加万能工具包_V5.3” 进行安装，或者直接下载9008 相关的驱动

  * 双击 MsmDownloadTool V4.0.exe工具，显示如下

手机关机后，同时按住“音量上下键”，几秒后将usb线插入电脑，手先不要松开，在设备管理器中会显示 9008端口，然后点击 “Start" 开始刷机，然后可以松手，截图如下：

耐心等待几分钟，刷机完成后，自动会重启进入全新的系统，此时可以拔掉usb

二、BootLoader 解锁

打开开发者选项

  * 设置-> 关于手机-> 版本号，连续点击多次，然后进入开发者模式

  * 手机通过USB连接kali，进入开发者选项，允许 USB调试

      + 可以在kali中输入： adb devices （查看设备）

解锁 Bootloader

  * 进入开发者选项，打开 ”OEM 解锁“，即 ”允许解锁引导加载程序“

  * 进入 bootloader 界面

      + 在kali终端输入：adb reboot bootloader；或者打开“高级重启”，然后按住电源键，选择进入”引导器加载“

      + 运行fastboot oem unlock

      + 然后使用 音量键选择解锁选项，使用电源键确定，解锁成功；自动会重启，解锁也会自动清楚所有配置，所以需要进入重新配置下；进入系统后重新开启“开发者选项”，关闭“系统自动更新”，开启 “usb调试”

三、刷入 twrp

刷入twrp 需要 adb 的工具，我使用的kali系统，可以事先在kali上安装好 android 相关的工具，然后设置环境变量

  * 进入 fastboot模式：adb reboot bootloader

  * 开始刷入 twrp

      + 下载twrp，这里我使用的非官方的：https://forum.xda-developers.com/t/recovery-3-4-0-10-unified-official-unofficial-twrp-for-oneplus-7-7-pro-5g-stable.3932943/

下载完成后，将 twrp 刷入 a和b分区：

  * fastboot flash boot_a twrp-3.4.0-10-guacamole-unified-Q-mauronofrio.img

  * fastboot flash boot_b twrp-3.4.0-10-guacamole-unified-Q-mauronofrio.img

  * 使用音量键选择 “recovery mode" ,再按电源键进入 twrp

  * 再次刷入 zip的 twrp，zip的twrp会同时刷入 ab区，可以再输出的提示：

      + 将 zip的包push到手机：adb push twrp-3.4.0-10-guacamole-unified-installer-mauronofrio.zip /sdcard/AAA

使用twrp刷入zip的twrp

四、刷入data解密包和Magisk

步骤：先格式化 data分区，然后刷入解密包，再刷入 Magisk

  * 下载 data 解密包和Magisk

      + data解密包：https://androidfilehost.com/?fid=17248734326145725184

      + Magisk：https://github.com/topjohnwu/Magisk/releases

  * 格式化 data 分区：

      + 选择 wipe -> Format Data，如果中文的话，就是 清除-> 格式化Data 分区

  * 刷入 Disable_Dm-Verity_ForceEncrypt_11.02.2020.zip 解密包

      + 首先还是 adb push 到手机上

  * 刷入 Magisk-v23.0.zip

  * 重启系统，跟着向导设置重新设置，这里密码和指纹都先不设置，直接跳过，进入系统之后，再安装 Magisk-v23.0.apk

      + 此时发现系统已经root了

五、刷入 kali nethunter 包

  * 下载 kali nethunter包，地址:https://www.kali.org/get-kali/#kali-mobile

      + 下载与手机型号对应的包：

  * adb push 到手机：adb push nethunter-2022.2b-oneplus7-oos-ten-kalifs-full.zip /sdcard/AAA

  * 进入 twrp，刷入 nethunter

      + adb reboot recovery 进入recovery模式，进入到 twrp中

      + 然后通过twrp刷入 nethunter-2022.2b-oneplus7-oos-ten-kalifs-full.zip 这个zip包

      + 等待几分钟，刷入完成，重启系统

六、进入nethunter

关闭系统更新：

  * adb shell

  * su

  * pm disable --user 0 com.oneplus.opbackup

  * pm clear com.oneplus.opbackup

ssh连接

  * 点击 nethunter 应用，点击 kali chroot Manager ，然后点击 Start kali chroot

  * 选择左侧 ”kali service“，开启 ssh服务

  * 使用nethunter终端，修改 root的密码，输入passwd root，然后输入密码，成功后，就可以使用 ssh连接了

3、vnc连接

  * 选择左侧”KeX Manager“，配置发现有些问题，所以直接再net hunter的kali终端执行如下命令

      + vncserver -localhost no，第一次需要输入密码

  * 使用vnc连接工具连接，

  * 成功使用vnc连接

刷机完成
