华云安漏洞安全周报【第115期】
2023-01-03 13:35:30

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.12.19~2022.12.25）CNNVD接报漏洞1309个，其中信息技术产品漏洞（通用型漏洞）144个，网络信息系统漏洞（事件型漏洞）1165个；CNNVD接报漏洞预警63份，其中华云安报送预警12份！预警报送数量均持续位居前列！

本周重点关注漏洞包括：CVE-2022-46421 Apache Airflow 命令注入漏洞、CVE-2022-40145 Apache Karaf 注入漏洞、CVE-2022-22461 IBM Security Verify Governance 加密问题漏洞、CVE-2022-45347 Apache ShardingSphere 安全漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-46421 Apache Airflow 命令注入漏洞

威胁等级：超危

漏洞描述：

2022年12月20日，华云安思境安全团队发现Apache发布了安全通告，披露了 Apache Airflow Hive Provider 5.0.0之前版本存在命令注入漏洞。Apache Airflow是一套用于创建、管理和监控工作流程的开源平台。攻击者可以对hive_cli_params参数不正确初始化，在目标系统上执行任意操作系统命令。

情报来源：

https://lists.apache.org/thread/09twdoyoybldlfj5gvk0qswtofh0rmp4

02CVE-2022-40145 Apache Karaf 注入漏洞

威胁等级：超危

漏洞描述：

2022年12月21日，华云安思境安全团队发现Apache官网发布了安全公告，披露了Apache Karaf 4.3.8之前版本和4.4.2之前的4.4.x版本存在注入漏洞。Karaf是Apache旗下的一个开源项目，Kara是一个轻量级的OSGi容器，可以用于部署各种组件应用程序。攻击者利用该漏洞可以执行远程代码攻击。

情报来源：

https://karaf.apache.org/security/cve-2022-40145.txt

03CVE-2022-22461 IBM Security Verify Governance 加密问题漏洞

威胁等级：高危

漏洞描述：

2022年12月21日，华云安思境安全团队发现 IBM官方发布了安全通告，披露了IBM Security Verify Governance, Identity Manager 10.0.1版本存在安全漏洞。IBM Security Verify Governance是IBM公司的一款集成网络设备的智能身份访问平台，该产品包括生命周期管理、访问风险评估和身份认证管理等功能。攻击者可以利用该加密算法漏洞解密获取高度敏感信息。

情报来源：

https://www.ibm.com/support/pages/node/6850845

04CVE-2022-45347 Apache ShardingSphere 安全漏洞

威胁等级：超危

漏洞描述：

2022年12月22日，华云安思境安全团队发现 Apache 官方发布了安全公告，披露了Apache ShardingSphere-Proxy 5.3.0之前版本存在安全漏洞。Apache ShardingSphere 是一个开源生态系统,由一组分布式数据库中间件解决方案。攻击者可以通过构造一个特殊的MySQL客户端来绕过身份认证并执行命令。

情报来源：

https://lists.apache.org/thread/l5rz7j4rg10o7ywtgknh2f5hxnv6yw3l
