华云安漏洞安全周报【第108期
2022-11-11 14:32:09

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.10.31~2022.11.6）CNNVD接报漏洞766个，其中信息技术产品漏洞（通用型漏洞）320个，网络信息系统漏洞（事件型漏洞）446个，其中华云安报送153个；CNNVD接报漏洞预警103份，其中华云安报送预警8份；漏洞报送数量及预警报送数量均持续位居前列！


本周重点关注漏洞包括：Juniper Networks Junos OS 10月多个安全漏洞、CVE-2022-43286-Nginx NJS 释放后使用漏洞、CVE-2022-31690-Spring Security Oauth2 Client 权限提升漏洞、CVE-2022-3602-OpenSSL 缓冲区溢出漏洞、Checkmk 11月多个安全漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

Juniper Networks Junos OS 10月多个安全漏洞

威胁等级：高危

漏洞描述：

2022年10月31日，华云安思境安全团队发现 Juniper Networks 官方发布安全更新，披露了 Junos OS 组件中存在多个安全漏洞。Juniper Networks Junos OS 是一套专用于该公司的硬件设备的网络操作系统，该操作系统提供了安全编程接口和 Junos SDK。本次更新共修复了6个 Junos OS 的 J-Web 组件中的漏洞，包括反序列化、XSS、XPATH注入、路径遍历、本地文件包含等。目前这些漏洞已经修复，华云安建议相关用户到 Juniper Networks 下载更新高版本。

情报来源：

https://supportportal.juniper.net/s/article/2022-10-Security-Bulletin-Junos-OS-Multiple-vulnerabilities-in-J-Web?language=en_US

CVE-2022-43286-Nginx NJS 释放后使用漏洞

威胁等级：超危

漏洞描述：

2022年10月31日，华云安思境安全团队发现 Github 官方发布安全更新，披露了 Nginx NJS 组件中存在一处释放后使用漏洞。Nginx 是一款轻量级 Web 服务器/反向代理服务器及电子邮件（IMAP/POP3）代理服务器，NJS 是其中的一个支持扩展 NGINX 功能的脚本语言组件。该漏洞是由于 njs_json.c 中的 njs_json_parse_iterator_call 函数非法复制内存导致的基于堆的释放后重用（UAF），攻击者成功利用此漏洞可能导致拒绝服务或远程代码执行。

情报来源：

https://github.com/nginx/njs/commit/2ad0ea24a58d570634e09c2e58c3b314505eaa6a

CVE-2022-31690-Spring Security Oauth2 Client 权限提升漏洞

威胁等级：高危

漏洞描述：

2022年11月1日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Spring Security Oauth2 Client 组件中存在一处权限提升漏洞。VMware Spring Security 是一套为基于 Spring 的应用程序提供说明性安全保护的安全框架。该漏洞是由于攻击者可以通过修改客户端向授权服务器发起的请求，成功利用此漏洞在某些特定情况下可能导致权限提升。

情报来源：

https://tanzu.vmware.com/security/cve-2022-31690

CVE-2022-3602-OpenSSL 缓冲区溢出漏洞

威胁等级：高危

漏洞描述：

2022年11月2日，华云安思境安全团队发现 OpenSSL 官方发布安全更新，披露了 OpenSSL 组件中存在一处缓冲区溢出漏洞。OpenSSL 是一个开源的能够实现安全套接层（SSLv2/v3）和安全传输层（TLSv1）协议的通用加密库，该产品支持多种加密算法，包括对称密码、哈希算法、安全散列算法等。该漏洞是由于在 X.509 证书验证中可以触发缓冲区溢出，特别是在名称约束检查中，攻击者利用该漏洞可以导致拒绝服务或远程代码执行。

情报来源：

https://www.openssl.org/blog/blog/2022/11/01/email-address-overflows/

Checkmk 11月多个安全漏洞

威胁等级：高危

漏洞描述：

2022年11月3日，华云安思境安全团队发现 Checkmk 官方发布安全更新，披露了 Checkmk 组件中存在代码注入、任意文件读取、换行注入、SSRF 等多个漏洞。Checkmk 是使用 Python 和 C++ 开发的 IT 基础设施监控解决方案，Checkmk 的开源版监控工具基于 Nagios Core，并提供与 NagVis 的集成，用于可视化和生成基础设施、服务器、端口和进程的拓扑图。成功利用此漏洞的攻击者可在未经身份验证的情况下组合利用漏洞来控制受影响的设备。

情报来源：

https://checkmk.com/company/our-customers
