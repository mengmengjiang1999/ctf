不仅限于数字藏品，NFT下半场将会如何发展？
2022-10-27 10:24:11

前不久，以太坊创始人 Vitalik Buterin 在以太坊中文社区的直播中表示，NFT 不应该太昂贵，要注重作用。

如今谈及 NFT ，似乎映入人们脑海的更多是 JPG 图片、数字藏品等主流表现形式，其实作为如今最出圈的区块链概念， NFT 投机热潮后，实际的应用场景和落地尝试有哪些？未来可能会怎么发展？

01
爆炸式增长的 NFT迎来“出圈”

毫无疑问，在过去的一年， NFT 成为了区块链领域最快也最强的出圈工具。

市场热度层面，根据 Google 搜索趋势显示， NFT 的市场关注度在 2021 年 2 月 21 日首次超过 DeFi 之后，它的搜索热度便一骑绝尘，远远将 DeFi 甩在身后。

也就是说，在最近的几个月中，币价下跌，原先的 DeFi 市场乃至整个行业的社群都变得冷清，但 NFT 市场不断活跃，搜索量、关注度不断增长（其实单单是近来抢白过程中涌现的令人啼笑皆非的段子式事件，就足见 NFT 市场的热度不减）。

交易数据层面，在 2021 年，人们交易了价值超过 400 亿美元的 NFT，不过绝大部分是图片等“艺术形式”的收藏品类 NFT。

它们通过对绝大部分参与者而言不啻于“玄学”的“ NFT 稀有度排名”，决定 NFT 价格或价值，却也让大部分用户忽视了这之外的实用型 NFT，甚至不少普通用户可能以为 NFT 仅限于图片、视频、音乐等收藏艺术品类。

Y Combinator联合创始人、风险投资家 Paul Graham 就认为，将 NFT 完全视为骗局是愚蠢的，因为目前尚不清楚它们未来的效用会是怎样的，自己永远不敢预测该技术的所有可能用途。

简言之，NFT 目前更多还只是一种无形的寄托，无论是现实世界中的艺术品映射链上实现“艺术品的 NFT 化”，还是链上原生的“ NFT 艺术品”，本质上都只是抽象化的名义上的所有权。

如何脱离目前以收藏品等为主流的“障眼法”，真正将“非同质化”的特性应用到切实的应用场景和现实痛点中，或许是 NFT 在下半场迎来继续繁荣的关键。

02
NFT “下半场”，收藏品之外的世界？

NFT 下半场的商业模式需要进行调整，其实 NFT 的种类也确实在越发多样化，在传统的游戏与收藏品领域之外，NFT 更深层的应用属性也一直在被不断发掘完善。

当下在 NFT 收藏品、卡牌、游戏之外，“社交代币”、”虚拟服饰”甚至于“时尚”对应的 NFT 场景，就不断提供新的令人讶异的应用思路。

譬如之前欧足联推出的 2 万张 NFT 形式欧洲足球锦标赛 VIP 门票，以及耐克利用“CryptoKick ID”来验证球鞋真伪的 NFT 尝试等。

此外NFT 和 DeFi 结合算是一个主流的探索方向，也已经有相当的项目在做探索尝试了，最直接的结合逻辑就是抵押借贷层面的场景拓展：

借款人可以抵押任何 ERC-721 代币（NFT 资产），其他用户则可以按需提供贷款。若该借款人接受此笔贷款，则将收到贷款人的 wETH 和 DAI，与此同时，该 NFT 资产被锁定至 NFTfi 智能合约中，直至借款人还清贷款。如果借款人没有在到期日之前还清贷款，该 NFT 资产将转给贷款人。

对于贷款人而言，可以为其喜欢的任何 NFT 资产提供贷款，以及自行设置贷款额、贷款期限以及希望在到期后借款人归还的总金额。贷款期限从 7 日、14 日、30 日和 90 日不等。

本质上这都等于赋予了原先收藏价值明显但流动性极低的NFT以等同其它数字货币一样的高流动性，不过这个设计的流程无疑会很复杂且漫长，因为目前还没有相对公允的市场定价机制，作抵押物还要考虑风险控制等。

但至少这方面的尝试很有创造性，NFT 与 DeFi 之间的界限会愈发地模糊。

03
结合DeFi之外，一些有意思的NFT探索

前不久 ETHGlobal NFT 黑客松「NFTHack2022」在上周经过为期三天的的激烈角逐后，有 16 个项目成功入围决赛圈，其中就包含与 DAO 的融合、助推 Web 3.0 、NFT 基础设施以及以创作者为核心的特点等维度的探索尝试。

个别项目也确实令人耳目一新，包括 NFT 收据协议 NFTpay、「Web3 版Discord」ZeusDAO 等，虽然目前大多数获胜项目处于 MVP（最小化可实行产品）阶段或测试阶段，但能够为我们提供很多有价值的思路。

NFTpay：NFT 收据协议

NFTpay 可以帮助用户制作 NFT 形式的区块链托管，且在 IPFS 上免费托管：
1.免费托管收据结帐页面；
2.无需与外部供应商建立合作关系来管理收据，也无需支付来自 Stripe 等供应商的特定费用；
3.收据自动托管为 NFT，收据和交易信息永远保留在以太坊网络上；
4.使用加密技术进行支付和结算，可以选择使用信用卡或 ERC20 代币付款；
5.在成功的付款后，应用程序会将以 NFT形式表示的收据发送给买家；

NFTpay 可以分为三个主要使用阶段——创建票据、完成支付、生成 NFT 收据和查看每个地址的交易历史。

ZeusDAO：「Web3 版」Discord， 更开放的社区管理协议

ZeusDAO 是为每个 NFT 项目服务的社区平台，在该平台中，项目的管理员可以插入他们的主网站，所有社区管理都可以在那里进行，而无需 Discord 的参与。

用户在 ZeusDAO 中拥有对应的 Zeus NFT，所有 Zeus NFT 都具有 3 个特征（Gold、Silver、Bronze）之一，可以类比为 Discord 的访问级别。其中， NFT 持有者可以登陆对应项目主网，没有 ZeusNFT 的只能访问首页，且持有 ZeusNFT 的人一旦连接主网，就可以访问网站内的更多选项卡（就像 Discord 频道一样），具体取决于 NFT 的访问特征。

Zeus NFT 持有者可以访问主网站上的金、银、铜等标签，只有管理员/创始人现在可以发布任何视频内容（从管理仪表板），通过这个社区，用户可以像在 Discord 中一样保持访问信息（但在 Zeus NFT 平台只需连接他们的 Web3 钱包）。

3个不同特征对应的选项卡充当这3个信息中心，管理员可以在其中发布信息，就像他们在 Discord 中一样，社区想要的下一件事情是做 AMA 的平台，也即可以在直播中与社区聊天——目前 Discord 无法处理这种级别的带宽。

在 Livepeer 的帮助下，该团队在协议中构建了一个功能，使得Zeus NFT 持有者可以连接到主网站上的 AMA，并且只有 NFT 持有者才能访问直播。

其实这样的想象空间更大，甚至就是从现有的一些 NFT 应用场景中进行延伸，就可以探索它下半场可以实现的商业模式。

譬如目前很多 NFT 都被作为培育社区的工具之一，有许多 NFT 被当作会员凭证——为项目方和用户提供一种在社区中区分身份的形式，使得社区成员拥有特定的 NFT，有机会参加项目对应的社交活动和聚会，并提供了与其他同类 NFT 持有者联系的机会。

04
小结

DeFi 本身就是强金融属性，所以大部分打通 DeFi 与 NFT 的创新尝试，本质上就是一方给玩法，一方给资产，通过 DeFi 的形式解锁 NFT 资产的融资方式，为其进入 DeFi 世界彻底打开大门。

理论上，这样既从 NFT 中引入了更多样化、更大体量的资产类别以满足 DeFi 发展需求，同时也盘活了 NFT 世界内原本的「沉睡资产」，赋予了 NFT 资产全新的的应用可能。

不过目前面临的挑战主要也有两方面： NFT 世界资产的潜在流动性相比链上原生资产仍较差、NFT 资产的公允价值尚需市场消化，这既是未知风险，也算是蓝海机遇。

而对 NFT 而言，更多场景的探索拓展，想象空间同样很大——如何找到一种将 NFT 和更多领域（DAO、社交、社区管理、财务等）合法性地相结合的方法，或许会是接下来更值得期待的 NFT “范式转变”。
