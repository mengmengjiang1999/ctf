ubuntu20.04安装docker
2021-04-01 10:47:21
 1. 安装ubuntu很容易,一直下一步下一步就可以了
 2. 安装docker: curl -s https://get.docker.com/ | sh
  * 安装完docker需要手动启动服务 service docker start
 1. . 可以看一下自己的ubuntu集成那些python环境whereis python,ubuntu20.04都是3.0以上的版本
 2. 下一步需要安装docker-compose,因为docker-compose做环境可以一键方便管理,不用再学习docker语法
 3. 安装docker-compose:pip3 install docker-compose,因为是python3需要用pip3,pip默认为python2
  * docker-compose -v查看自己的版本
 1. 下载git clone https://github.com/vulhub/vulhub.git,在任意目录下下载,必须要记得自己在那个目录下哪里下载vulhub,或者whereis vulhub可以查一下自己下载到了哪里(因为有人遇到过,不是我自己)
 2. 注意:拉取vulhub可能速度太慢了可以换成别的下载源,也可以fq下载:https://github.com/vulhub/vulhub/archive/master.zip,再上传到ubuntu中,也可评论发给你哈哈哈......
 3. 进入..vulhub/flask/ssti输入命令docker-compose up -d启动环境因为我这已经更新了配置文件,只要出现done绿色的字就表示已经环境已经搭建好了
 4. 关闭环境:docker-compose down
