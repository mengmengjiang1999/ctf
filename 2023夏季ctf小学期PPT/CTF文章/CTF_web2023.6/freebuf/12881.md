华云安漏洞安全周报【第78期】
2022-04-12 13:56:18

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.3.28~2022.4.3）CNNVD接报漏洞1194个，信息技术产品漏洞（通用型漏洞）380个，网络信息系统漏洞（事件型漏洞）814个；CNNVD接报漏洞预警135份，其中华云安报送预警22份，预警报送数量位列第二！


本周重点关注漏洞包括：CVE-2022-0342-Zyxel 身份验证绕过漏洞、CVE-2022-1125-Google Chrome UAF 漏洞、CVE-2022-1154-Vim UAF 漏洞、CVE-2022-22965- Vmware Spring Framework 代码执行漏洞、CVE-2022-22675-Apple 多款产品越界写入漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-0342-Zyxel 身份验证绕过漏洞

威胁等级：超危

漏洞描述：

2022年3月29日，华云安思境安全团队发现 Zyxel 官方发布安全更新，披露了 Zyxel 组件中存在一处身份验证绕过漏洞。Zyxel 主要产品包括 DSL 局端及用户端接入设备、路由器设备、网络安全设备、无线局域网接入设备、网络语言电话及以太网交换机等。该漏洞是由于防火墙中的 CGI 程序中缺少适当访问控制机制的缺陷引起，成功利用此漏洞的攻击者可以绕过Web身份验证并获得设备的管理访问权限。

情报来源：

https://www.zyxel.com/support/Zyxel-security-advisory-for-authentication-bypass-vulnerability-of-firewalls.shtml

02 CVE-2022-1125-Google Chrome UAF 漏洞

威胁等级：高危

2022年3月29日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome 组件中存在一处 UAF 漏洞。Chrome 是一款可让您更快速、轻松且安全地使用网络的浏览器。该漏洞是由于 Portal 组件中存在“释放后使用”的错误引起，成功利用此漏洞的攻击者通过触发释放后使用错误，从而在目标系统上执行任意代码攻击。

https://chromereleases.googleblog.com/2022/03/stable-channel-update-for-desktop_29.html

03 CVE-2022-1154-Vim UAF 漏洞

威胁等级：超危

漏洞描述：

2022年3月30日，华云安思境安全团队发现 GitHub 官方发布安全更新，披露了 Vim 组件中存在一处 UAF 漏洞。vim是一款基于 UNIX 平台的编辑器。该漏洞是由于 regexp_bt.c 中 utf_ptr2char（） 函数中存在“释放后使用”错误引起，成功利用此漏洞的攻击者通过发送特殊设计的恶意文件诱使用户打开，从而触发释放后使用错误，造成任意代码执行攻击。

情报来源：

https://github.com/vim/vim/commit/b55986c52d4cd88a22d0b0b0e8a79547ba13e1d5

04 CVE-2022-22965- Vmware Spring Framework 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年3月31日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Vmware Spring Framework 组件中存在一处代码执行漏洞。Vmware Spring Framework是一套开源的 Java、JavaEE 应用程序框架。该漏洞是由于应用程序作为 WAR 部署在 Tomcat 上运行时产生的缺陷引起，成功利用此漏洞的攻击者通过数据绑定，从而执行远程代码攻击。

情报来源：

https://tanzu.vmware.com/security/cve-2022-22965

05 CVE-2022-22675-Apple 多款产品越界写入漏洞

威胁等级：高危

漏洞描述：

2022年3月31日，华云安思境安全团队发现 Apple 官方发布安全更新，披露了 Apple iOS 和 Apple iPadOS 中存在一处越界写入漏洞。Apple iOS 是一套为移动设备所开发的操作系统。Apple iPadOS 是一套用于 iPad 平板电脑的操作系统。该漏洞是由于 AppleAVD 子系统中的边界错误引起，成功利用此漏洞的攻击者通过运行恶意制作的程序，从而触发越界写入，导致使用内核权限执行任意代码攻击。

情报来源：

https://support.apple.com/en-us/HT213219
