内网渗透中的信息收集
2022-02-21 16:38:56

当我们拿下一台主机后，希望通过这台主机进行横向渗透，首先需要进行信息收集，内网信息收集主要是从以下几个方面进行

• 操作系统

windows

systeminfo | findstr OS

linux

uname -a  
cat /proc/version   #查看内核版本

lsb_release -a  #列出所有信息


• 系统服务

windows

wmic service list brief

net stat


linux

service --status-all #查看所有进程
service [service] status #查看指定服务状态
service [service] stop #关闭指定进程
service [service] start #启动指定进程
service [service] restart # 重启指定进程

• 系统进程

windows

tasklist
wmic process get name,processid

linux

ps -aux
ps -ef

• 系统补丁

windows补丁信息可以配合工具快速找出windows可以利用的漏洞

systeminfo | findstr KB
wmic qfe get caption,description,hotfixid,installedon

• 内网IP地址段

ipconfig /all #windows

ifconfig  #linux

• 系统权限

net user #查看所有用户
whoami #查看当前用户


linux

whoami #查看当前用户

• 系统共享

windows

net share
wmic share get name,path,status

• 网络连接与端口

netstat -ano #windows

netstat -anplt #linux
  * -a 显示所有选项
  * -t (tcp)仅显示tcp相关选项
  * -u (udp)仅显示udp相关选项
  * -n 拒绝显示别名，能显示数字的全部转化成数字。
  * -p 显示建立相关链接的程序名


• 系统用户

net user #windows查看系统用户
net localgroup #查看用户组

cat /etc/passwd #linux 查看用户
cat /etc/shadow #linux 查看密码
cat /etc/passwd/group #查看用户组

• arp路由

windows

arp -a
route print

linux

arp -a
route

• 任务计划

at #高版本window中at已被弃用
schtasks # windows

crontab -l # linux

• 启动信息

wmic startup get command,caption

linux

dmesg > test.txt
tail test.txt

• 开机时间

net statistics workstation #windows

cat /proc/uptime| awk -F. '{run_days=$1 / 86400;run_hour=($1 % 86400)/3600;run_minute=($1 % 3600)/60;run_second=$1 % 60;printf("系统已运行：%d天%d时%d分%d秒",run_days,run_hour,run_minute,run_second)}' #Linux

windows 其他相关信息收集

防火墙

netsh firewall show config #查看防火墙相关配置

netsh advfirewall  set allprofiles state on #打开防火墙配置
netsh advfirewall  set allprofiles state off #关闭防火墙配置

netsh advfirewall firewall add rule name="pass nc" dir=in action=allow program="c:\nc.exe" #允许指定程序入站
netsh advfirewall firewall add rule name="out nc" dir=out action=allow program="c:\nc.exe" #允许指定程序出站

netsh advfirewall firewall add rule name="Remote Desktop" protocol=TCP  dir=in localport=3389 action=allow 

#允许rdp端口通过

注册表

reg query /? #查看注册表帮助信息


reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v PortNumber #查看RDP开放端口


reg add  HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 0 /f #开启远程桌面


reg add  HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 1 /f #关闭远程桌面



reg query HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD #查看RDP状态

域控

ipconfig /all #查看 DNS 网关以及域名

nslookup [域名]#查看解析出的域控ip与DNS是否一致


systeminfo #确定用户登录域


net config workstation #查看当前用户，以及工作域


net group /domain #查询域内所有信息


net group ""domain admins" /domain #查看指定域成员信息


net accounts /domain #查看域密码策略


nltest /domain_trusts #查看域信任的列表


这就是我总结的全部内容，不是很全，在这里当作笔记记一下
