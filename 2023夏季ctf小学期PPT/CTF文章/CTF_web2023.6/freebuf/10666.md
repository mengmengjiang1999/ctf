首站圆满落幕！Fortinet Accelerate 2022中国区全国路演盛大起航
2022-06-14 10:53:07

2022年6月9日，Fortinet Accelerate 2022中国站全国十地路演首站在武汉拉开帷幕。在严格遵守防疫规则的情况下，百余位来自电信、交通、制造等多个行业的企业 CSO、 CIO、网络安全负责人，以及亚马逊云科技、太平洋电信等 Fortinet公司合作伙伴相聚一堂，就数字化转型趋势下，企业网络安全态势以及应对方案创新与前瞻等，现场进行了专业的分享与交流。

现场用户在对零信任访问、安全和网络高效融合、无缝连接多云网络的云安全架构、护航OT安全保护数字资产与创新发展等Fortinet Security fabric 四大代表解决方案进行细致了解的同时，也对Fortinet合作伙伴亚马逊云科技、太平洋电信等在云安全、SASE等领域协同场景进行了深入了解，并有不少观众对现场展出的亚马逊云科技“元创市集”、太平洋电信弹性网络等产品和服务兴趣浓厚。

（Fortinet华中区销售负责人 祁志钧）

现场的分享和交流围绕Fortinet四大场景解决方案进行。首先是网络与安全的融合， Fortinet华中区销售负责人祁志钧表示，当前网络攻击面持续扩大、网络攻击手段不断演化，企业内的防护产品和供应商也在无序增加，这一切都给最终的企业用户带来了更大的挑战。融合与整合已经是当前网络安全领域无法避免的一个趋势。落地网络安全网格架构，融合网络与安全、整合各种供应商的产品和方案，进而实现集中的可视化和管控，实现自动化和智能化的威胁防御与处理。

（Fortinet华南区资深安全工程师 张城若）

Fortinet华南区资深安全工程师张城若则从零信任安全访问的角度指出，面对当今网络复杂性、扩大的攻击面以及对网络安全缺乏可见性的全新挑战，只有以零信任的理念，做到对 “谁在网络中” 、 “什么在网络中” 和 “谁访问了哪些应用程序” 了如指掌，也就是实现应用、身份、网络、终端4个层面的访问控制与管理，才能确保安全无虞。

（Fortinet华中区资深安全工程师 陈龙）

在谈到数字化转型带来的安全挑战话题时，Fortinet华中区资深安全工程师陈龙认为，数字化转型正在推动IT/OT网络连通、融合，而事实证明OT风险与OT连通性成正比。基于Fortinet Security Fabric安全架构能够构建工业物联网安全体系，实现集中的可视化和数据保护，以及端到端的防御自动化，降低网络安全风险，减轻OT团队的安全负担，保障生产的安全运行。

而对于云安全，他指出混合云和多云已经成为未来的主导趋势，同时企业纷纷上云也导致了“安全空窗”、“网络复杂度增加”以及“网络安全技术人员短缺”。他认为，云安全不仅要从基础设施等架构层面来看待，还要通过应用程序的生命周期来认识，也就是我们不仅要保护云基础设施的安全，还要能够将安全能力覆盖从构建、部署到运行的全生命周期。

（亚马逊云科技 解决方案架构师 陆从尧）

对此，亚马逊云科技解决方案架构师陆从尧也提到，传统安全缺乏可见性、自动化程度低，也不能在敏捷与安全之间兼顾。但是在云时代，敏捷与安全需要兼得。亚马逊云科技与客户共担安全责任，并建议除了亚马逊云科技平台提供的基础安全能力之外，云平台用户也需要借助于Fortinet等亚马逊云科技合作伙伴的云安全服务，实现平台的可见性和可控制，以及应用安全和网络安全。

（太平洋电信 产品总监 魏清晨）

太平洋电信产品总监魏清晨表示，数字化转型时代下随时随地办公的新模式，给企业和个人带来信息安全挑战，SASE这种网络安全新模式，同时作为覆盖所有访问边缘的云原生安全平台，能够给企业带来全面的增益。太平洋电信使用Fortinet产品打造SASE解决方案，通过云网融合的骨干网络资源，为客户提供零信任（ZTNA）企业安全访问解决方案等。未来太平洋电信将与Fortinet以及亚马逊云科技携手赋能产业数字化转型，为企业用户提供云网安全架构咨询和管理服务，从0~99建设可信任的 IoT数字空间，携手共建数字化工业互联网。

Fortinet Security fabric作为当前市场上唯一可见已经在多个行业落地的网络安全网格架构，在数字化转型带来的新的安全态势下拥有无可比拟的优势。而Fortinet Security fabric安全架构的基础是FortiOS，经过了10年的精心打磨，它已经成为整个架构的共同基础，可以部署在任何地方，云端、容器、虚拟机、物理机等。无处不在的FortiOS让与会的观众与嘉宾领略到了它的真实魅力。

除了精彩专业的演讲外，大会还进行了抽奖等趣味活动，让到场的网安专业人士在收获满满知识的同时，也获得了轻松的体验。在武汉站完美落幕的同时，也标志着Fortinet Accelerate 2022中国区全国十地路演的下一站已经蓄势待发——广州站将在6月30日举行。
