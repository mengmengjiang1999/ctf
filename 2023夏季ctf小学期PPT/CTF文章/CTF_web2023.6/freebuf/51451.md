X Brute Forcer：一款小巧易用的CMS密码爆破工具
2018-03-28 15:00:25

X Brute Forcer是一款支持对多种常见CMS实施密码爆破攻击的工具。目前，X Brute Forcer所支持的CMS包括WordPress , Joomla , DruPal , OpenCart , Magento。


简单爆破脚本

[1] WordPress （自动识别用户名）
[2] Joomla
[3] DruPal
[4] OpenCart
[5] Magento
[6] All （自动识别CMS）

使用

简易命令格式  完整命令格式       描述  
-l      --list       站点列表
-p      --passwords  密码列表


示例

perl XBruteForcer.pl -l list.txt -p passwords.txt

Linux 安装

git clone https://github.com/Moham3dRiahi/XBruteForcer.git
cd XBruteForcer
perl XBruteForcer.pl -l list.txt -p passwords.txt 

Android 安装

下载Termux

cpan install LWP::UserAgent
cpan install HTTP::Request
git clone https://github.com/Moham3dRiahi/XBruteForcer.git
cd XBruteForcer
perl XBruteForcer.pl -l list.txt -p passwords.txt 

Windows 安装

下载Perl
下载XBruteForcer
提取XBruteForcer到桌面
打开CMD并输入以下命令:
cd Desktop/XBruteForcer-master/
perl XBruteForcer.pl -l list.txt -p passwords.txt
