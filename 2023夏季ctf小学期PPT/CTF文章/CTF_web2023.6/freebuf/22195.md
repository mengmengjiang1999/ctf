pip手动引入python依赖
2021-07-24 14:58:08

安装Pandas需查看其依赖包

需要分别安装如图pytz、numpy、python-dateutil三个依赖包

分别查看所需依赖包版本信息

下载对应版本的whl文件，附下载地址：https://www.lfd.uci.edu/~gohlke/pythonlibs/

进入下载好的包的路径，用pip install python_dateutil-2.8.2-py3-none-any.whl，进行install

由于本地已经安装过了，所以会有is already installed 的提示。
至此以安装完成，若应用其他whl，也可按此方法。

依次执行以下命令：
--pandas
pip install python_dateutil-2.8.2-py3-none-any.whl
pip install pytz-2021.1-py3-none-any.whl
pip install numpy-1.21.1+mkl-cp39-cp39-win_amd64.whl
pip install pandas-1.3.0-cp39-cp39-win_amd64.whl
--requests
pip install urllib3-1.26.6-py3-none-any.whl
pip install certifi-2021.5.30-py3-none-any.whl
pip install idna-3.1-py3-none-any.whl
pip install charset_normalizer-2.0.3-py3-none-any.whl
pip install requests-2.26.0-py3-none-any.whl
