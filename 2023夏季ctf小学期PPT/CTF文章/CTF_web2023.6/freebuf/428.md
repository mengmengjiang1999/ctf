关于Spamhaus 域名信誉API

即日起Spamhaus Intelligence API 的域名信誉API Beta 2.0的免费测试申请通道正式开启。

本次发布的 域名信誉API Beta 2.0 公开了许多额外的数据点。这意味着用户可以根据需要自定义 API 调用以查询有用的信息。

该数据集提供了 Spamhaus 研究人员观察到的所有域名的有价值的上下文信息。安全从业人员和邮件送达性专业人士可以增强现有数据源或直接使用此数据进行审核、调查、保护和控制。

域名信誉API提供了哪些数据？

我们的研究人员观察和分析的每个域名都列在此数据集中。通过各种 API 调用，提供了与每个域名相关的元数据，包括：

具体介绍一下API提供的查询功能？

>域名高阶数据查询

- 返回通用的域名相关信息，包括域名最后一次被发现的时间，是否失陷，与之相关联的域名集群以及域名的信誉评分。

信誉通过数字代表：零是中性，正数表示更优良的信誉，负数表示较差的信誉。

>信誉维度查询

- 信誉在多个领域进行评估，称为维度。这使用户能够了解他们的信誉需要加强的领域。

我们分享了组成您的域名信誉评分的各种维度（得分），让您了解哪个维度可能会拖低您的信誉评分，以便您采取有建设性的步骤来改善您的域名信誉。以下领域有与之相关的分数：

SMTP：SMTP 领域的信誉。

identity：域名身份的信誉，例如所有者和注册商。

infra：域的基础设施的信誉，例如名称服务器和主机。

malware：与恶意软件、机器人和此类威胁分发有关的域名的信誉。

human：域名的人类信誉。此维度代表 Spamhaus 研究人员对域名的观点。

3rdparty：可信第三方提供与域名相关的信誉评分。

>域名标签tag

- 这些用于标记某些类型的行为，包括与域名相关的滥用类型，例如钓鱼，或者它是哪种类型的域名，例如重定向器。一个域名可以关联多个标签，为用户提供全面的图像。以下是我们的研究人员使用的标签列表：

>域名上下文查询

-- 深入了解研究人员观察到域名的位置，例如邮件、pdns节点、“dkim-header”

>域名黑名单查询

- 查看域名是否在 Spamhaus 域名黑名单列表中，并查看黑名单记录过期的时间

>域名发件数据查询

- 发送查询域名电子邮件的 IP 地址

>NS域名解析服务器信誉查询

- 查询域名的权威名称服务器列表及信誉度和托管域名数

>域名A记录信誉查询

- 列出域名解析为的 A 记录指向IP地址列表及信誉值

>域名集群查询

- 用于在某些领域中相关联的域名，包括电子邮件验证、注册和基础设施。这些集群哈希用于将域名与以下两个领域中的行为模式相关联：

Auth - 与与电子邮件相关的认证模式有关的行为模式

Infra - 与域名注册模式相关的模式 - 注册时间以及使用的基础设施。

>主机/子域名黑名单查询

- 近期（如果可用）在 Spamhaus DNS 拦截列表中列出的特定域名下的主机名/子域名

>恶意软件查询

-- 与域名相关联的恶意软件名称，文件哈希以及最后一次出现的时间戳等
