Firefox Pwn学习&amp;CorCTF Outfoxed
2021-09-08 15:54:44

文章背景

一直想研究除了V8以外其它浏览器引擎，前几天在Inctf里面有个webkit的jsc，这周在corctf就出了个firefox的SM（spidermoney），类型是一个基本的越界，没怎么涉及到JIT，当时是本地打通了，远程不是很好适配，下面是对其的一个总结。

环境搭建

环境我们还是跟着官方给的文档去搭。官方给的文档里面有两个方法，一种是利用Mercurial，还有一种就是git了。这里以推荐的Mercurial搭，git类似。

hg clone https://hg.mozilla.org/mozilla-central
cd mozilla-central
hg branches
hg update 版本
patch < patch文件
cd mozilla-central
./mach bootstrap
./mach build

这里需要注意在build之前 ，都默认选项就行，然后在首目录下修改mozconfig。
如果想要debug版本，添加ac_add_options --enable-debug就行，然后mk_add_options MOZ_OBJDIR=@TOPSRCDIR@/obj/ 目录名指定编译后的目录，还有就是如果只编译控制台就ac_add_options --enable-application=js。不过在实际搭建中可能因为网速代理的原因导致不是很容易把源码拉下来，这就可以使用官方推荐的离线下载，这里
