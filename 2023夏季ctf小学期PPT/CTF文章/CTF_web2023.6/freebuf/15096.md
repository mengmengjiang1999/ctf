Solarwinds Web Help Desk漏洞分析
2022-02-09 10:57:07

0x01 概述

Solarwinds Web Help Desk是美国Solarwinds公司的一套服务台和资产管理软件。该软件支持集中式知识库、IT资产管理、项目和任务管理等功能。Web Help Desk 收集并自动处理工单管理任务，可以更好地服务及跟踪任务，包括工单分配、途径选择和升级，找出事故工单对应的单个问题，以优化组织结构，关联问题工单与 IT 资产，并跟踪资产服务请求的历史记录，简化从服务请求到解决问题的流程。

根据CVE-2021-35232漏洞描述，在SolarWinds Web Help Desk产品中存在硬编码凭据，通过这些凭据，可以对Web Help Desk主机具有本地访问权限的攻击者允许对数据库执行任意HQL查询，并利用该漏洞窃取用户的密码哈希或将任意数据插入数据库中。

InternalCommunicationUtils.isAllowedAddress函数检查我们的请求是否来自环回地址，因此无法远程利用此漏洞。但是，这个函数判断存在安全隐患，这也是此漏洞比较有意思的地方：当Solarwinds Web Help Desk 在同一主机上部署反向代理时，此函数将会失效。因为在JSP里，获取客户端的IP地址的方法是来自request.getRemoteAddr()，这种方法在大部分情况下都是有效的。但是在通过Apache、Squid等反向代理软件后就不能获取到客户端的真实IP地址了，因为request.getRemoteAddr()将返回一个环回IP地址或者本地的其他网卡IP地址，从而绕过判断。
