值得收藏的信息安全网址，第一弹，国外篇
2020-08-04 11:05:05
【原创-信息安全的那些事儿】Best Cyber Security Web Sites on the planet！全球最好的网络安全网站！如有漏网，欢迎大家帮助补全。
排名不分先后，打不开的，需要翻墙的，更新不及时的已经去掉！

1.We Live Security

简介：出自老牌杀毒软件公司ESET，在斯洛伐克、美国、加拿大、德国和阿根廷拥有研究团队，ESET于1992年在斯洛伐克创立，至今仍处于恶意软件检测和分析的前沿，遍布全球180个国家。
网址：https://www.welivesecurity.com

2. McAfee Blogs

简介：McAfee杀毒软件公司的官方博客。
网址：https://www.mcafee.com/blogs

3.Krebs on Security

简介：Brian Kerbs的个人博客。Brian Kerbs属于半路出家，1995年至2009年期间在《Washington Post》担任记者，为《Security Fix》博客撰写了1300多篇博文。后来一直致力于调查网络犯罪和计算机安全方面。
网址：https://krebsonsecurity.com/

4.Dark Reading

简介：这是一个安全专家线社区。社区成员包括安全研究人员和技术专家。只要你英语够好，可以学到很多内容。
网址：http://www.darkreading.com/

5.Schneier on Security

简介：Bruce Schneier的个人博客。他是一位国际知名的安全技术专家，被《经济学人》称为“安全大师”。同时他也是哈佛大学伯克曼克莱恩互联网与社会中心的研究员，哈佛大学肯尼迪学院公共政策讲师，电子前沿基金会AccessNow和Tor项目的董事会成员，是电子隐私信息中心（Electronic Privacy Information Center）和VerifiedVoting.org的顾问委员会成员。总之就是很牛的一位大神级人物啦。
网址：https://www.schneier.com/

6.threatpost

简介：Threatpost是一个独立的新闻网站，为全球成千上万的专业人士提供IT和商业安全方面的主要信息来源。《华尔街日报》、微软全国广播公司(MSNBC)、《今日美国》(USA Today)和国家公共广播电台(National Public Radio)等主要新闻机构都将Threatpost作为信息安全方面的权威信息来源。唯一缺点，广告多。
网址：https://threatpost.com/

7.Naked Security

简介：Naked Security 是 Sophos （守护使公司）的威胁新闻室，提供计算机安全问题和最新的关于互联网威胁的新闻和研究，还有很多免费的安防软件可以下载。多年荣获了很多荣誉，2020年6月，Naked Security在欧洲安全博客奖上获得“最佳供应商博客”和“网络安全传奇-最佳综合博客”。
网址：https://nakedsecurity.sophos.com/

8.Graham Cluley

简介：反病毒专家Graham Cluley的个人博客，访问有些慢，请耐心等待。曾为Sophos和McAfee高级职员。上面的Naked Security博客就是这位大神创建的。
网址：https://www.grahamcluley.com/

9.Infosecurity Magazine

简介：Infosecurity Magazine 隶属于Infosecurity Group，该杂志主要提供信息安全行业的知识和研究。
网址：http://www.infosecurity-magazine.com/

10.CSO Online

简介：IDG旗下，三姐妹之一，专注服务于企业首席安全官（CSO），提供安全策略，提供安全新闻、分析和研究。
网址：http://www.csoonline.com/

11.CIO Security

简介：IDG旗下，三姐妹之一。专注服务于全球的首席信息官（CIO）。
网址：https://www.cio.com

12.Techworld Security

简介：IDG旗下，三姐妹之一，专注于系统平台安全。
网址：https://www.computerworld.com

13.Security Affairs

简介：Pierluigi Paganini的个人博客。Pierluigi Paganini是ENISA(欧盟网络和信息安全机构)和网络G7小组的成员，安全传播者、安全分析师和自由撰稿人。我最喜欢的网站之一，发布安全事件很及时。著有：《The Deep Dark Web》和《Digital Virtual Currency and Bitcoin》。
网址：https://securityaffairs.co/wordpress/

14.ZoneAlarm Blog

简介：ZoneAlarm是Check Point软件技术公司旗下官方博客。ZoneAlarm为家庭电脑用户提供企业级别的保护，免受病毒、间谍软件、黑客和身份盗窃的侵害。说白了，更多的是推销自己的产品。
网址：https://www.zonealarm.com/

15.Troy Hunt

简介：Troy Hunt个人博客，微软澳大利亚地区主管，微软最具价值的安全专家。
网址：https://www.troyhunt.com/

16.RSA Blogs

简介：美国RSA信息安全公司的官方博客。
网址：https://www.rsa.com/en-us/blog

17.Help Net Security

简介：1998年开始运营，专注信息安全。是一些全球最大的信息安全事件的媒体赞助商，例如RSA会议。
网址：https://www.helpnetsecurity.com/

18.Security Weekly

简介：Security Weekly，安全周刊。顾名思义就是每周提供信息安全方面的新闻、漏洞、黑客和研究。2005年创刊至今，里面有很多小的周刊。其中最为有名的是Paul's Security Weekly。
网址：https://securityweekly.com/

19.ZDNet

简介：Zero Day Net，在软件/硬件安全研究、漏洞、威胁及电脑攻击方面，保持领先地位。
网址：https://www.zdnet.com/blog/security/

20.Security on TechRepublic

简介：TechRepublic官方安全博客。
网址：https://www.techrepublic.com/topic/security/

21.Cisco Blogs

简介：Cisco官方博客。
网址：https://blogs.cisco.com/security

22.SANS Institute Security Awareness Tip of the Day

简介：SANS学院成立于1989年，是一个合作研究和教育组织，它的项目在世界各地有超过16.5万名安全专业人员参与。从安全审计人员、网络管理员到首席信息安全官，许多人都在分享他们学到的经验教训，并共同寻找解决他们面临的挑战的办法。这是它下面的每日提示（tip of the day）网站，每天都有一个新的主题。你可以从中找到很多灵感。划重点！！这个每日提示网站是支持中文下载的。
网址：https://www.sans.org/tip-of-the-day

23.Quick Heal Blog

简介：Quick Heal Technologies Ltd，是印度防病毒研究和开发的先驱，并设立了计算机安全标准的基准。成立于1995年，是IT安全领域最受信赖的品牌之一。在印度有分公司，在美国、日本、阿联酋和肯尼亚设有4个全球办事处。想了解三哥的发展水平，这里就对了。
网址：https://blogs.quickheal.com/
