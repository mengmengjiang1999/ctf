gitnote+GitHub云笔记软件推荐分享
2021-01-18 16:08:26

开篇

好记性不如烂笔头，工作这么多年发行日常需要很多记忆的东西，当时感觉自己记忆好，但时间久了你会发行开机密码你都记不住了，所以需要一款笔记软件帮助自己总结各种知识，记录各种事物。本来想在微信里发，但是传播的范围太小了，分享给更多需要的人。

笔记软件选择的考量因素

本地存储

因为云端的笔记，总感觉数据不可控，尤其是国内的大环境，总让人感觉数据上传到别人家服务器，就不是你的了，说你违规你就违规，说删除可能都不需要经过你同意，所以我想找个本地存储的。

无限分类

学网安的人都知道，知识分类比较多，为了方便管理文档，至少需要三级分类，分类非常重要，比如Qownnote这个笔记，就只能使用标签的方式，使用很不方便。

md支持

支持Markdown，大家都懂哈哈。

大数据的支持

因为要长期使用，长期积累，笔记软件应该要几万篇查询要保证速度。

加密支持和收费

最好能对重要数据加密，另外就是最好免费，可能的话，十年内不要倒闭

mybase的弊端

我几乎找遍了互联网，发现mybase是符合我的需求的，但是没有云端功能，建了好几个数据库，比较麻烦，所以找了个比较完美的方案，gitnote+github这种模式，主要是不要钱，不按流量收费，数据放Git上放心而且空间大小无限，可以对接私人仓库。

gitnote介绍

GitNote 是一款基于 Git 的跨平台笔记软件，内置 git 支持无须本地有任何 git 环境，拥有 git 的全部特性，可以任意的恢复笔记版本记录，依托 github 的免费不限量私人仓库，笔记没有空间的限制，数据完全属于你自己。

轻量级的 todo 管理，在笔记中快速便捷创建 Todo ，富文本编辑器,不仅支持各种复杂的文字编辑,还支持快捷键、公式、语法高亮、Todo、图片粘贴,等等功能，另外支持漂亮的 markdown 的编辑器,而且还支持编写幻灯片功能,方便你进行幻灯片演讲。

官方网址：https://www.gitnoteapp.com

根据我测试，最新版的有个bug，你使用远程添加仓库的时候会报错。所以需要使用添加本地仓库的方式。
