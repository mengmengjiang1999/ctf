项目地址

https://github.com/1dayluo/subnya

开发进度

去年年底学习go，却发现自己很快喜欢上了它。这是新人第一个go语言项目，希望大佬们多多包涵谅解，也欢迎提出意见和issue。

使用的话，可以用git clone命令，然后直接运行 `go run main.go`，使用 --help可以查看帮助

你也可以直接用以下命令下载可执行文件。（默认可执行文件保存在 ./config/subnya/config 目录下)

go install  github.com/1dayluo/subnya@latest  

介绍

在关注h1和bugcrowd的社区大佬的youtube视频的时候，经常看到有人提到recon自动化很重要，其中就包括了随时关注要挖掘的对象的随时可能新增的子域名（例如 新功能的上线）。另外，作为一个开发转入安全的人来说，从工具/自动化入手对我来说可能更好一些。

SubNya就是在这样的背景下开发出来的，一个是保证监控的对象是文件夹（后续可能考虑按照文件夹内的文件名对数据库进行分类），另一个就是采用多个数据库存储方式，redis用于检测文件的md5变化，而sqlite则用于保存监控domain下的submain，和不同时间下，新增子域名和减少的子域名。目前子域名遍历采用的是Subfinder，后续考虑扩展。

最后的结果也会输出到output文件夹下（按照日期生成）



功能有以下

Usage: main [--update] [--run] [--output]

Options:
  --update, -u           Check update in monitor
  --run, -r              start subdomain finder and update data(include response status code) in sqlite
  --output
  --help, -h             display this help and exit

-u 用于先对文件进行更新检查，看有无新的domain，然后会对新增的domain跑一遍

-r 用于对已转入数据库内的domain进行检查，并且根据当前检查结果与数据库已有进行对比

--output是用于输出在文件，否则默认输出在console里。

其中，相关的配置都在 `config/config.yml` 里
