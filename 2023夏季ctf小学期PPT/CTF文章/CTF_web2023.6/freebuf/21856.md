无root打造超级黑客手机termux+nethunter

hi，大家好。我是铁汉fhoenix。

记得以前我初中的时候爸妈题目又不会，于是给我了一部手机。当然，为了不让我玩游戏，手机配置及差。本身我对游戏没有兴趣。后来一次偶然，接触到了termux，直到坚持到现在。这是我以前发给kali与编程的文章，今天搬来。以后我还会发跟多和手机有关的内容。

在手机上安装kali

首先工具，termux（酷安，西西软件园，fdroid，googleplay均可下载）vnc viewer（好像只有百度有）

1.打开termux（要等很长时间。。）

2.pkg update 更新，中途会停下，按y继续。

3.pkg upgrade升极

4.申请存储访问权限 termux-setup-storage

5.安装 wget pkg install wget

6. 下载 安装脚本wget -O install-nethunter-termux https://offs.ec/2MceZWr

7.给脚本执行权限chmod +x install-nethunter-termux

8.运行安装脚本 ./install-nethunter-termux

9.下载 安装脚本 wget -O install-nethunter-termux https://offs.ec/2MceZWr

10.给脚本执行权限chmod +x install-nethunter-termux

11.运行安装脚本 ./install-nethunter-termux

12.进入kali ,nh

13.apt update更新

14.apt upgrade升极

OK,以上安装完成。

kali命令 说明

nethunter 启动 Kali NetHunter 命令行界面

nethunter kex passwd 配置 KeX 密码 (仅在第一次使用前需要)

nethunter kex & 开始 KeX 会话服务

nethunter kex stop 停止 Kali NetHunter 桌面

nethunter <command> 在 NetHunter 环境中运行命令

nethunter -r 以 root 身份启动 Kali NetHunterk 命令行界面

nethunter -r kex passwd 配置 root 用户的 KeX 密码

nethunter -r kex & 以 root 身份开始 KeX 会话服务

nethunter -r kex stop 停止 root 身份运行的 KeX 会话服务

nethunter -r kex kill 杀掉所有的 KeX 会话

nethunter -r <command> 以 root 身份在 NetHunter 环境中运行命令

nethunter 命令可以缩写成 nh ，Kali

NetHunter 默认的用户名 kali 的密码也是 kali

root 密码没有设置 可以输入 sudo passwd 来修改 root 用户的密码

完成

1、注意在termux开启状态才可以用vnc

2、安装 kali 工具集合可以使用 apt install kali-linux-default 大小大概为2.6GB左右（进入termux,输nh再输apt in....）

3、termux中kali本身不带工具，用指令apt list列出所有工具，apt install AAAA安装，（如安装sqlmap,apt install sqlmap）
