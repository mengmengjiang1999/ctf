Twitch 安全漏洞的影响微乎其微
2021-10-18 16:00:18

Twitch 为最近的安全漏洞提供了更新，该公司确认它只对少数用户产生了有限的影响。

Twitch在更新中淡化了最近的安全漏洞，该公司表示它只影响了少数用户。

根据更新，属于用户或主播的登录凭据或完整支付卡数据没有暴露。

该事件的根本原因是服务器配置更改，允许未经授权的第三方进行不当访问。Twitch 密码尚未暴露，该公司认为存储 Twitch 登录凭据的系统没有被访问，这些凭据是用 bcrypt 散列的。

“Twitch 密码尚未暴露。我们也相信，存储 Twitch 登录凭据的系统（使用 bcrypt 散列）未被访问，完整的信用卡号或 ACH/银行信息也未被访问。暴露的数据主要包含来自 Twitch 源代码存储库的文档，以及创作者支付数据的子集。我们对暴露的文件中包含的信息进行了彻底审查，并确信它只影响了一小部分用户，对客户的影响很小。我们正在联系那些直接受到影响的人。”

本月初，一位匿名 4chan 用户在 4chan 讨论板上发布了一个 128GB 文件的 torrent 链接，泄露的档案包含从 6,000 个内部 Twitch Git 存储库中窃取的敏感数据。使用 #DoBetterTwitch 标签的泄密者声称已泄露数据以应对今年夏天针对平台主播的骚扰袭击。8 月，主播使用相同的标签在 Twitter 上分享了针对他们的仇恨袭击的证据，当时平台上的聊天内容充斥着仇恨内容。

“他们的社区也是一个令人作呕的有毒污水池，因此为了在在线视频流领域引发更多破坏和竞争，我们已经完全控制了他们，并且在第一部分中，正在从近 6,000 个内部 Git 存储库中发布源代码，”阅读泄密者发布的消息。


名为“抽搐泄漏第一部分”的匿名用户线程声称存档包含：

  * 整个 twitch.tv，提交历史可以追溯到早期
  * 移动、桌面和视频游戏控制台客户端
  * 平台使用的各种专有 SDK 和内部 AWS 服务
  * Twitch 拥有的所有其他财产，包括 IGDB 和 CurseForge
  * 亚马逊游戏工作室未发布的 Steam 竞争对手
  * Twitch SOC 内部红队工具（笑）
  * 以及从 2019 年到现在的创作者支出报告。
