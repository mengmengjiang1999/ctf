白嫖各大博客平台图床

由于平时写文章都是在本地，图片也是在本地，在发布文章时需要将本地图片上传到图床，所以有了这篇文章

本文拿csdn为例，写一个自动将本地图片上传到csdn图床的工具

分析图片上传流程

首先登录csdn，发布文章
然后打开burpsuite，上传图片

然后返回burpsuite看下都有哪些请求

可以看到这里的post请求Host地址是csdn-img-blog.oss-cn-beijing.aliyuncs.com，请求体有图片，是上传图片的点无疑了

再看下post请求，除了图片之外还有下面这些参数
'OSSAccessKeyId'
'policy'
'key'
'success_action_status'
'signature'
'callback'

这些参数哪来的呢？
看这条post请求上面的get请求，返回内容是json数据

{
    "code":200,
    "msg":"success",
    "message":null,
    "data":{
        "accessId":"xxx",
        "policy":"xxx",
        "signature":"xxx",
        "dir":null,
        "expire":"xxx",
        "host":"https://csdn-img-blog.oss-cn-beijing.aliyuncs.com",
        "callbackUrl":"xxx",
        "filePath":"80f0cef8c5414a39955bb4319deaebbe.png"
    }
}


对比post请求数据发现
accessId对应OSSAccessKeyId
policy对应policy
filePath对应key
signature对应signature
callback对应callbackUrl
success_action_status对应200
那这条get请求参数是什么呢？
一条cookie
把cookie删掉试试，返回结果401
删除部分cookie参数，最终测试发现，cookie的有效参数只有UserName和UserName

所以，上传图片流程就是

 1. 先登录拿到cookie

 2. get请求拿到post请求用到的信息

 3. post图片

get请求拿到的东西是什么呢，可不可以手工伪造？如果可以，那就可以跳过get请求
网上查了下阿里oss的使用方式
这里的post请求就是通过oss的 客户端签名直传的方式上传
policy是base64编码，解码后可以看见是上传大小限制和时效限制
signature是对policy的签名
key是路径，设置为${filename}，则保持上传时的文件名
callback是base64编码的，解码后是一些图片信息和图片名，图片位置

实际测试，图片名是由callback中的filePath控制的
把filePath改为../a.png和a/a.png都会返回400
filePath设置为已经存在的图片，返回200上传成功，但实际访问时发现，还是原来的图片

综上，先拿到cookie（时效性长），然后获取oss的上传参数（时效性短，时效后上传会返回AccessDenied），再上传图片

写脚本

 1. 用burp取出cookie中的UserName和UserName信息，csdn登录一次的cookie能用很久，就不用脚本操作了

 2. get请求获取参数
    经过测试，请求头至少要有这三个信息

 3. post上传图片

完整代码

import json
import requests
import os
import re


savepath=r"C:\Users\xxx\Desktop"
cookie = 'UserName=xxx; UserToken=xxx; '
mdpath = input('输入md文件位置:')

def getParam(cookie):
    header = {
        'X-Image-App': 'direct_blog',
        'X-Image-Suffix': 'png',
        'cookie':cookie
    }
    resp = requests.get('https://imgservice.csdn.net/direct/v1.0/image/upload?watermark=&type=blog&rtype=markdown',headers=header)
    resjs = json.loads(resp.content.decode('utf-8'))
    return resjs

def uploadPic(resjs,picpath):
    data = {
        'OSSAccessKeyId' : resjs['data']['accessId'],
        'policy' : resjs['data']['policy'],
        'key' : resjs['data']['filePath'],
        'success_action_status' : 200,
        'signature' : resjs['data']['signature'],
        'callback' : resjs['data']['callbackUrl']
    }
    img = 'image.png'
    req = requests.post('http://csdn-img-blog.oss-cn-beijing.aliyuncs.com',data=data,files={'file':(img,open(picpath, "rb"), "image/jpeg")})
    if 'AccessDenied' in req.text:
        return uploadPic(getParam(cookie),picpath)
    reqjs = json.loads(req.text)
    return reqjs['data']['imageUrl']
if __name__ == "__main__":
    dirpath = os.path.dirname(mdpath)
    with open(mdpath,'r',encoding='utf-8') as fp:
        data = fp.read()
    pics = re.findall('\!\[\]\((.*)\)',data)
    print('共{}个图片'.format(len(pics)))
    i = 0
    resjs = getParam(cookie)
    for pic in pics:
        i+=1
        print('正在上传第{}个'.format(i))
        picabs = '%s\\%s'%(dirpath,pic.replace('/','\\'))
        picremotepath~~~~ = uploadPic(resjs,picabs)
        data = data.replace(pic,picremotepath)
    file = os.path.basename(mdpath)
    filei = file.split('.')
    newfile='{}\\{}_res.{}'.format(savepath,'.'.join(filei[:-1]),filei[-1])
    with open(newfile,'w',encoding='utf-8') as fp:
        fp.write(data)
    print('文件已写入:{}'.format(newfile))
