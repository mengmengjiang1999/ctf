ADAM挖矿：持续关注DeFi赛道ADAMoracle未来将包罗万象

什么是DeFi？

DeFi的英文全称为Decentralized Finance，也被称做Open Finance，即去中心化金融。DeFi产品以公链为底层框架，以智能合约为核心机制，通过去中心化协议来构建开放式金融系统，旨在让世界上任何一个人都可以随时随地、无须许可的进行开放金融活动。在现有的金融系统中，无论是最基本的存取转账、还是贷款或衍生品交易，主要都是由中央系统控制和调节。DeFi则希望通过分布式开源协议建立一套低门坎、透明度高、可访问性强和具有包容性的点对点金融系统。

随着DeFi协议的出现之后，就有一句话随之而出，那就是没有预言机，DeFi协议就没有办法获得正常运行所需要的所有数据，由此看出，预言机对于DeFi协议是非常重要的，甚至可以说预言机就是DeFi协议作为区块链之外的数据来源，在区块链DeFi中什么是预言机呢？

预言机定义的：区块链外信息写入区块链内的机制，一般被称为预言机 (oracle mechanism) 。预言机的功能就是将外界信息写入到区块链内，完成区块链与现实世界的数据互通。ADAMoracle作为首个支持广域节点喂价的多链去中心化预言机，直击当下预言机攻击事件层出不穷的痛点，着眼于预言机安全功能的升级，关注预言机风控体系的建立，对此，小编带你深入了解ADAMoracle未来将包罗万象。

经过数年的发展，预言机领域已经历多次迭代。预言机1.0属于中心化应用，由中心化机构提供数据至智能合约运行；预言机2.0是去中心化应用，当前市场上的主要代表有Chainlink和MakerDao联盟预言机；预言机是现实世界和区块链系统能够实现数据互通有无的桥梁，其核心功能是做数据信息传输。数据是至关重要的，这就要求预言机产品不断提升数据传输的安全、精准、高效等性能。这既是预言机领域的发展趋势，也是我们提出的预言机3.0时代必须具备的特点。

数据上链:用户通过智能合约向 ADAMoracle 发起数据请求，并且附带相应的 数据需求参数（链上），其实也是一笔 ADAM 的通证转账，在转账事务的payload中携带有数据请求的参数；其节点组成的网络通过订阅 ADAMoracle 合约的日志获取相关信息； ADAMoracle System 拆解用户需求（链下）；拆解后的任务由不 同的节点通过外部的 API 数据源完成，获取数据返回；返回的数据 发送至 ADAMoracle System； ADAMoracle System 将数据再次返回至链上的 ADAMoracle 智能合约上；ADAMoracle 链上合约整合数据（利用不同节点提供的数据的概率分配、去除异常值（Outliers）等操作），同时根据最终结果纪录每一个提供数据的节点声誉，最终将结果发送给用户的智能合约，完成整个流程。

实现跨链数据传递：ADAMOracle SaaS System 采用“中继链”概念, 这一系统将接收 到的外部链请求通过 ADAM EVM 虚拟机将外部链请求的智能合约 翻译成 ADAMoracle 虚拟机标准的智能合约，将实现跨链连接 ETH、BTC、 OKExChain、Polkadot 等, 打通整个生态, 实现“人人皆可做数据 的搬运工”。

ADAM通证的做用：ADAMoracle 是通过支付Token ADAM 来激励数据的提供方，即持续 地提供有效数据的提供方将持续地获得 ADAM 的奖励。同时数据的使用者将需要支付一定额度的ADAM，以此形成良性的循环，这意味着 ADAMoracle 的使用越多，ADAM 的价值越高。 可以大胆预言：区块链未来必将通过预言机来传递链外 数据，预言机是区块链不可或缺的一环。

ADAM的挖矿产出将分阶段进行。第一阶段的总奖励为 1200 万 ADAM。每个后续阶段的总挖矿奖励将减少 20%。1200万ADAM用完后，进入第二阶段。第二阶段的奖励总量比第一阶段减少20%，为960万；该规则将在后期继续，直到所有 6000 万 ADAM 被挖出。

今天，由不同预言机组成的大型网络支持许多重要的加密项目的功能。如果没有预言机，DeFi 项目将不得不仅仅依赖其网络中可用的信息，这将极大地限制其在多区块链未来（包括跨链）中的能力。
