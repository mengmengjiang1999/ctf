C++友元函数
2021-06-15 17:28:13

类的友元函数是定义在类外部，但有权访问类的所有私有（private）成员和保护（protected）成员。尽管友元函数的原型有在类的定义中出现过，但是友元函数并不是成员函数。
友元可以是一个函数，该函数被称为友元函数；友元也可以是一个类，该类被称为友元类，在这种情况下，整个类及其所有成员都是友元。
如果要声明函数为一个类的友元，需要在类定义中该函数原型前使用关键字friend

例子：
代码：

#include<iostream>

using namespace std;

class Box
{
	double width; //没加属性，默认是private属性
public:
	friend void printWidth(Box box);  //友元函数printWidth()不是任何类的成员函数
	void setWidth(double wid);
};

void Box::setWidth(double wid) 
{
	width = wid;
}

void printWidth(Box box)    //友元函数printWidth()不是任何类的成员函数，所以不能Box::printWidth()
{
	cout << "Width of box:" << box.width << endl;  //printWidth()是Box的友元，它可以直接访问该类的任何成员，所以可以直接访问私有属性
}

int main()
{
	Box box;
	box.setWidth(10.0);
	printWidth(box); 
	return 0;
}

对上面的例子添加了友元类的使用。
代码：

#include<iostream>

using namespace std;

class Box
{
	double width; //没加属性，默认是private属性
public:
	friend void printWidth(Box box);  //友元函数printWidth()不是任何类的成员函数
	friend class BigBox;
	void setWidth(double wid);
};

class BigBox    //BigBox是Box的友元类，它可以直接访问Box类的任何成员
{
public:
	void Print(int width,Box &box)
	{
		box.setWidth(width);
		cout << "width of the box:" << box.width << endl;
	}
};

void Box::setWidth(double wid) 
{
	width = wid;
}

void printWidth(Box box)    //友元函数printWidth()不是任何类的成员函数，所以不能Box::printWidth()
{
	cout << "Width of box:" << box.width << endl;  //printWidth()是Box的友元，它可以直接访问该类的任何成员，所以可以直接访问私有属性
}

int main()
{
	Box box;
	box.setWidth(10.0);
	printWidth(box); 
	BigBox bigbox;
	bigbox.Print(20,box);
	return 0;
}


结果：


因为友元函数没有this指针，则参数要有三种情况：
要访问非static成员时，需要对象做参数；
要访问static成员或全局变量时，则不需要对象做参数；
如果做参数的对象是全局对象，则不需要对象做参数。
可以直接调用友元函数，不需要通过对象或者指针。

class Integer
{
	friend void Print(const Integer &obj);
};

void Print(const Integer &obj)
{
	//函数体
}

void main()
{
	Integer obj;
	Print(obj); 
}
