Barracuda修复Load Balancer ADC中的高危漏洞
2020-03-10 15:27:49

网络安全公司Rapid7近日披露了Barracuda Load Balancer ADC中的一个高危漏洞。

Barracuda Networks总部位于美国硅谷，是一家提供包括邮件安全和归档、Web应用安全、负载均衡等产品的网络应用厂商。根据其官网介绍，该公司在全球与5 000多家渠道合作伙伴合作，用户量超过15万，包括联合国、美国国防部、美国国土安全部、微软、波音、可口可乐、IBM、本田、铃木、哈佛大学等国际知名机构和公司。

Barracuda Load Balancer ADC是该公司的一款负载均衡器，用于优化和促进应用交付，同时提供DLP和其他安全机制。

该漏洞是由Rapid7公司的安全研究人员Steve Campbell发现的，编号为CVE-2019-5648，CVSS v3评分8.7。Rapid7表示，攻击者可利用该漏洞编辑均衡器的LDAP服务配置，攻击者修改配置之后，无需再次输入LDAP凭据就可将LDAP服务器修改成由攻击者控制的系统。但是，攻击者要利用该漏洞必须先获得设备的管理员访问权限且通过身份认证。

然而，由于运行6.2.x及之前版本固件的设备默认的管理员凭据的用户名和密码都为admin，如果在部署过程中没有修改用户名和密码，攻击者如果可以通过网络访问该设备，就能轻易地登录到设备的管理控制台，进而编辑LDAP connnector配置，将IP地址修改成由攻击者控制的系统，关闭加密功能，退出管理控制台。

下一步，攻击者就可以利用在之前的LDAP connector中配置的IP地址在自己控制的系统上使用netcat监听389/TCP端口。这时候，如果有凭据（无论是否合法）被输入到Barracuda登录表单，该负载均衡器就会把账号的明文凭据发到攻击者的系统。

攻击者可利用该漏洞收集未加密的合法LDAP凭据，并在进一步的攻击利用这些信息。如果LDAP connector被配置成连接Active Directory Domain Controller，攻击者就可利用从网络流量中捕获的合法凭据获取对Active Directory Domain Controller的访问权限，则后续攻击造成的风险更大。

CVE-2019-5648影响了运行6.5之前版本固件的Barracuda Load Balancer ADC（硬件型号440Vx）。Barracuda已经通过补丁管理系统自动分发了安全更新，用户无需手动更新，除非有意禁用了安全更新。厂商计划在2020年4月发布6.5版本固件，届时新版本固件也会包含漏洞补丁。

Rapid7最后提醒到，Barracuda的电子邮件网关和Web应用程序防火墙等其他设备的固件在LDAP身份认证方面可能也存在类似的漏洞，用户应及时关注厂商发布的安全更新。
