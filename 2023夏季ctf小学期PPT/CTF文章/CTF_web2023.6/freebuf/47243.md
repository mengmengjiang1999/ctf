智安全认证SCSA 11月份捷报不断，安全工程师认证掀热潮
2018-12-05 14:44:25


深信服智安全认证，自2017年底试运营至2018年正式推向市场，受到外界和学员一致好评。谷安天下作为智安全认证全国运营中心，其授权培训中心遍及全国各地，已覆盖的地域有北京、上海、广州、深圳、湖南、湖北、河北、河南、江苏、陕西、四川、浙江、福建、重庆、安徽、天津、山西、内蒙、黑龙江、吉林、江西、青海、宁夏、甘肃、云南、贵州及山东地域。这意味着、深信服携手谷安天下，打造渠道教育合作伙伴模式全面开启了。就目前为止，全国区域内已成功举办64期SCSA初级（安全工程师认证）培训，持证人员数量已达695人。

在过去的11月份，智安全认证技术体系第三批授权培训中心，陆陆续续的正式挂牌，在合作区域内全面开展智安全技术认证体系市场化推广运营，以快速培养“应用型安全技术人才”为目标，共同助力网络安全人才培养与建设。



随着各地授权培训中心的市场运营工作陆续步入正轨，仅11月份相继在北京、广州、厦门、石家庄、武汉、长沙、青岛、深圳、昆明等多地域开班，单月参与认证培训人数达248人，学生对于网络安全专业学习的热情不减。下图为各地域班级开班合影！


智安全认证拥有专业及系统的培训体系，认证覆盖了从初级SCSA中级SCSP高级SCSE三个层级，该认证体系侧重于应用层安全技术考察和认证。具备智安全技术认证证书的工程师是公认的企业网络安全基础架构规划、安装部署和运维能力的专业人士。在课程设置上，理论结合实操、大大提高技术实操动手能力，全面打造复合型技术人才，学员参加培训获得认证后既可达到上岗水平。认证通过率高达85%，课后调查满意度非常高。

该认证体系包括安全工程师认证（SCSA），安全资深工程师认证（SCSP）和安全专家认证（SCSE），覆盖企业网安全基础解决方案到企业网安全架构设计3个等级的技术认证。

SCSA认证

（Sangfor Certified Security Associate）定位于企业网络安全方面的基本配置和维护，满足大部分企业用户的基础安全需求。

SCSA认证包括但不限于：网络安全基础知识，网络安全产品基础知识和常见部署方案，用户认证技术，应用识别技术，流量管理技术，IPS/WAF/防DOS/APT防御技术，全网互联IPSEC VPN/SSL VPN(Virtual Private Network)技术，终端接入和终端安全管控技术介绍。

学员通过SCSA认证，将证明对中小型网络安全技术和应用有初步的了解，并具备协助设计中小型企业安全网络架构以及部署和维护能力。

通过SCSA级别的认证可以有效证明该认证人员具备以下能力：

1、具备网络运维、网络安全、应用层协议相关的基础知识；

2、具备网络安全规划和设计能力，通过不同的网络安全设备实现安全可视、安全感知、全网互联组网方案

3、能够根据企业的业务需求，基于业界主流的安全产品和技术手段有效的制定安全解决方案和企业最佳实践；

4、能够熟练的使用和操作上网行为管理、下一代防火墙、SSL VPN等主流安全产品；

5、能够诊断企业网络中常见网络和安全问题并找到相应的解决方案；


SCSP认证

（Sangfor Certified Security Professional）安全资深工程师，处于深信服智安全认证体系中的中级工程师。

SCSP认证定位在企业整体网络环境安全的测试、分析及维护等，满足大部分企业用户的安全需求。认证完成后学员具备深信服产品的高级功能交付和排错能力，具备一定渗透相关技术的原理。

SCSP 认证包括但不限于:安全概述、web安全、系统安全、安全事件应急响应、企业级安全整体解决方案及综合故障分析与排除。

通过 SCSP 认证，将证明您对中小型网络安全技术和应用有初步的了解，并具备协助设计中小型企业安全网络架构以及部署和维护能力。

通过 SCSP 级别的认证可以有效证明该认证人员具备以下能力:

✓ 对web安全、系统安全等原理有整体了解，对于安全事件能灵活的做出应急响应。

✓ 能够熟练的使用和操作数据库安全审计、终端安全感知、全网安全感知等主流安全产品

✓ 具备网络安全工程师水平，能够胜任网络安全工程师或运维工程师岗位或初级渗透工程师

✓ 具备网络安全规划和设计能力，通过不同的网络安全设备或解决方案实现安全可视、安全感知、安全审计等安全功能

✓ 能够根据企业的业务需求，基于业界主流的安全产品和技术手段有效的制定安全解决方

案和企业最佳实践

✓ 能够诊断企业网络中常见网络和安全问题并找到相应的解决方案
