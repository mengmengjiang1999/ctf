在外网利用docker搭建OWTF（腾讯云版）
2022-07-05 10:41:03

owtf介绍：https://owasp.org/www-project-owtf/

内网版（只能在内网访问owtf）

腾讯云事先搭建好docker后

docker pull ahiknsr/owtfdocker64 拉取镜像

docker run -i -t ahiknsr/owtfdocker64 /bin/bash 执行镜像bin shell

ifconfig或IP a 查看镜像ip

在bin shell中执行

python owtf/owtf.py 启动owtf

这样直接在内网访问172.17.0.xx:8009就可以访问

外网版，其实只需要做端口映射就好

docker pull ahiknsr/owtfdocker64

docker run -it -p 80:8009 ahiknsr/owtfdocker64 将镜像内的8009端口映射到腾讯云的80端口，映射到其他tcp端口也行

不需要查看docker的ip，因为直接用腾讯云ip访问。

python owtf/owtf.py 启动owtf

只要访问腾讯云的ip:80端口就能访问owtf。

小提示：大家可以在dockerhub上多寻找拉取的镜像信息，好玩的镜像有很多。
