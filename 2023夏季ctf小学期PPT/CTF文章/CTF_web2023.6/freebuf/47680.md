2018-11-13 15:00:51

前言

CaptfEncoder是一款跨平台网络安全工具套件，提供网络安全相关编码转换、古典密码、密码学、特殊编码等工具，并聚合各类在线工具。

功能介绍

编码转换

Ascii Encoding

Web Encoding

Hex Encoding

Unicode Encoding

Base64（Base16、Base32、Base58）

Url Encoding

Html Entity Encoding

Escape Encoding

Quoted-printable（可打印字符引用编码）

Morse Code（莫尔斯电码）

Tap Code（敲击码）

古典密码

Rail-fence（栅栏密码）

Atbash（埃特巴什码）

ROT13（ROT5、ROT18、ROT47）

Simple Substitution（简单替换密码）

Vigenère（维吉尼亚密码）
