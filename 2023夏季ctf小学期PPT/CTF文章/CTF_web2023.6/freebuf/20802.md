恶意软件分析：Python脚本被利用实现隐蔽攻击
2021-08-26 14:15:26

近日，研究人员发现了一个攻击链较长的攻击事件，其中利用 Python 脚本作为 Loader 实现隐蔽攻击。

在用户的启动文件夹中，发现了可疑链接文件 sysmon.lnk，经过分析后发现该文件链接到恶意 Python 文件，利用 Python 文件将 RAT 远控木马注入系统。

整体攻击链情况如下所示：

名为 sysmon.lnk的 LNK 文件位于

c:\\users\<username>\appdata\roaming\microsoft\windows\startmenu\programs\startup\sysmon.lnk处。该文件重定向到可疑的 ctfmon.exe update.py执行，这两个文件位于

c:\users\<username>\appdata\roaming\PpvcbBQh\ctfmon.exe和 c:\Users\<username>\AppData\Roaming\PpvcbBQh\update.py。

ctfmon.exe

ctfmon.exe是重命名的 IronPython 解释器，该文件在 VirusTotal 上零检出。
