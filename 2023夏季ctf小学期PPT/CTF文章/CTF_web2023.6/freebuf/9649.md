Kali Pi 安装 RTL8812AU驱动
2022-07-13 11:11:11

今天，我们来实操安装一下昨天的RTL8812​的无线网卡驱动。

说明

我们今天使用的网卡是磊科的NW392无线网卡，其主要核心为NW392。

一张32G内存卡

树莓派为树莓派4B 4G-RAM

系统为kali-linux-2022.2-raspberry-pi-arm64

动手

装载完系统，做好基础配置，接着开始​配置SSH方便我们操作。

ssh连接完成之后，我们开始进行以下工作：
更换源为国内源 （已完成请忽略）

apt update && apt upgrade

更新完成后继续下面的操作

安装​树莓派的kali linux系统核心文件：

apt install kalipi-kernel-headers kalipi-kernel -y

​​接下来，我们重启一下系统。

​​sudo reboot

重启完成，我们需要安装一些东西

apt install build-essential bc dkms git -y

创建一个目录，来保存文件​。

mkdir -p ~/src
cd ~/src
git clone https://github.com/morrownr/8812au-20210629.git
cd 8812au-20210629/


接下来，vim install-driver.sh

将箭头指向的位置更改为ARM64（如果不是ARM64的请斟酌，修改的原因完全是这个系统说自己是aarch64但是kernel中并没有aarch64的编译文件）

紧接着保存，然后执行./install-driver.sh

​显示上面的样子就是在安装了，我们等待结果（时间可能比较长，需要编译很多东西。）

​

​这样就是安装完成了，我们看看设备列表和网卡检测。

安装完成！
