if 流程控制语句

if 语句的功能是现对运算条件进行比较，然后根据比较结果选择对应语句进行执行

if 语句只能判断两种情况：

  * 0 假

  * 非0 真

if 语句

#include <stdio.h>
​
int main(int argc,char** argv)
{
if (argc == 0)
{
   printf("argc == 0");
}
return 0;
}

汇编

关于if判断在汇编中实现的部分：

115c:       83 7d fc 00             cmp    DWORD PTR [rbp-0x4],0x0
1160:       75 14                 jne    1176 <main+0x2d>

之前已经将argc的值放入通过edi放入了rbp-0x4地址处的栈空间中

  * cmp DWORD PTR [rbp-0x4],0x0

    使用CMP指令，将rbp-0x4地址处的4字节数据与0相减，并影响标志位，由于之后的jne关注的是ZF标志位，所以此处说明CMP对ZF标志位的影响：

      + 结果 = 0 则ZF = 1

  * jne 1176 <main+0x2d>

      + 若ZF = 0则进行跳转，也就是说若argc != 0则跳转到return 0;（mov eax,0x0）的语句

      + 否则继续向下执行执行if中的语句

可以发现处理的逻辑是：若不满足if判断的语句进行跳转，若满足则继续执行，这显然与C语言的逻辑是相反的：

这是由于C语言是根据代码行的位置来决定编译后二进制代码的地址高地的，便于使用标号相减得到代码的长度，所以 C语言的编译器不能随意改变代码行在内存中的顺序，所以if先进性不满足跳转的判断，若满足直接向下执行即可

所以依据这个特性，若判断的语句为argc > 0则cmp后紧跟的跳转语句的条件应该是argc <= 0的

关于if判断在汇编中实现的部分：

115c:       83 7d fc 00             cmp    DWORD PTR [rbp-0x4],0x0
1160:       7e 14                 jle    1176 <main+0x2d>

  * jle 1176 <main+0x2d>

    ZF = 1 || SF != OF则进行跳转（jle小于或等于跳转（若leftOp ≤ rightOp））

if...else 语句

#include <stdio.h>
​
int main(int argc,char** argv)
{
if (argc == 0)
{
   printf("argc == 0");
}
else
{
   printf("argc != 0");
}
return 0;
}

if...else最初的比较与跳转过程与单if是一致的，唯一的区别在于1176行的jmp语句，由于在执行完if中的语句后不能再去执行else里的语句，所以要用一个jmp跳到else后的语句

所以在还原汇编代码时，若出现上述3条汇编语句的组合，可初步判断存在if...else语句，且jmp的位置位于源代码中if语句块的末尾与else语句块的开头

关于if...else判断在汇编中实现的部分很巧妙，一步一步来看，首先是：

1151:       85 ff                 test   edi,edi        
1153:       75 20                 jne    1175 <main+0x2c>

由于我们代码中是比较argc == 0，所以此处省去了将0入栈再通过cmp与edi中argc的值相比较

而是直接使用test命令，edi（argc）中的值与自身做与运算：

  * 若argc == 0则与运算后依旧为0则ZF = 1不会通过jne跳转，而是继续往下执行if语句块中的代码

  * 若argc == 1则与运算后依旧为1则ZF = 0,所以说明if的条件不满足，转去jne到else的代码中执行

此处 最妙 的地方就来了，此处，在if的语句块与else的语句块中间并没有看见刚刚提到的jmp指令，反而看到了用于函数返回的ret指令，而却在结尾处发现了一个jmp用于跳回到ret指令的地址处

所以此时的逻辑就变成了：

  * 首先判断是否满足if的条件

      + 满足： 接着向下执行，由于本代码中除了if...else语句块外，并没有其余的代码，所以执行到1174行，直接通过ret返回即可

      + 不满足：jne跳转到else的语句块中

  * 执行完else语句块后，通过最后一个jmp跳到位于1174行的ret返回即可

  if (argc > 0 )
  {
      printf("argc > 0");
  }
  else if (argc == 0)

  else
  {

  }

 return 0;

汇编

可以看到if与else if的逻辑相同，都是通过cmp/test判断后后不满足条件的跟跳转语句，虽然他们组合在一起，但每个if和else...if又是独立的

  * if (argc > 0 )

    115c:       83 7d fc 00             cmp    DWORD PTR [rbp-0x4],0x0
    1160:       7e 16                 jle    1178 <main+0x2f>
    ; <= 则跳转

  * else if (argc == 0)

    1178:       83 7d fc 00             cmp    DWORD PTR [rbp-0x4],0x0
    117c:       75 16                 jne    1194 <main+0x4b>
    ; != 则跳转

  * jmp跳转语句

    1176:       eb 30                 jmp    11a8 <main+0x5f>
    ......
    1192:       eb 14                 jmp    11a8 <main+0x5f>
    ; 防止执行完 if 或 if...else 后再次执行 else

O1优化下的 if...else if...else

在O1优化的条件下，

1151:       85 ff                 test   edi,edi
1153:       7f 1a                 jg     116f <main+0x26>
1155:       75 38                 jne    118f <main+0x46>

此处直接看可能不止所云，好像不知道它想干什么，但仔细看我们要输出的字符串的位置已经被改变了，当前汇编代码的结构已经发生了变化

  * 1157 - 1168行对应的是满足else if (argc == 0)要执行的语句

  * 116f - 1180行对应的是满足if (argc > 0 )要执行的语句块

  * 118f - 11a0行对应的是最后都不满足走else要执行的语句块

所以通过jg 116f <main+0x26>判断若> 0则直接跳到116f if处

若不满足，再通过jne 118f <main+0x46>判断若!= 0，经前面的判断又说明不大于0所以跳到118f else处

否则== 0接着执行else if (argc == 0)

这样通过对语句顺序的改变仅使用一个判断指令 test 就完成了所有情况跳转的判断
