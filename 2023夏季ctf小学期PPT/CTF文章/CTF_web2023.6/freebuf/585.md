华云安漏洞安全周报【第127期】
2023-04-03 14:25:12

根据国家信息安全漏洞库（CNNVD）统计，本周（2023.03.20~2023.03.26）CNNVD接报漏洞474个，其中信息技术产品漏洞（通用型漏洞）141个，网络信息系统漏洞（事件型漏洞）333个，其中华云安报送72个！CNNVD收录漏洞通报112份，其中华云安报送6份！漏洞报送数量及预警报送数量均位居前列！

本周重点关注漏洞包括：CVE-2023-21036-Google Pixel 信息泄露漏洞、CVE-2023-20860-Spring Framework 身份验证绕过漏洞、CVE-2023-28432-MinIO 信息泄露漏洞、CVE-2023-28708-Apache Tomcat 信息泄露漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2023-21036-Google Pixel 信息泄露漏洞

威胁等级：中危

漏洞描述：

2023年03月21日，华云安思境安全团队监测发现 Google Android开源项目官方发布了安全更新，披露了 Google Pixel 内置工具 Markup 中存在一处信息泄露漏洞。Google Pixel 是 Google 的一款智能手机，Markup 是内置的屏幕截图编辑工具。该漏洞是由于代码中的逻辑错误，可能无法截断图像引起，成功利用此漏洞可能会泄露图像创建者在与他人共享媒体或在线发布媒体之前使用 Pixel 的标记工具编辑的敏感信息。

情报来源：

https://source.android.com/docs/security/bulletin/pixel/2023-03-01?hl=zh-cn

02 CVE-2023-20860-Spring Framework 身份验证绕过漏洞

威胁等级：高危

漏洞描述：

2023年03月22日，华云安思境安全团队监测发现 Spring 官方发布安全更新，披露了 Spring Framework 组件中存在一处身份验证绕过漏洞。Spring Framework是一个开源的JavaEE应用程序框架，它提供了一种轻量级的、非侵入性的方式来构建基于 Java 的企业应用程序，可帮助开发人员构建高质量的应用。该漏洞是由于未经身份验证的远程攻击者通过构造特制请求触发，成功利用此漏洞的攻击者可实现身份验证绕过进而访问后台信息。

情报来源：

https://spring.io/security/cve-2023-20860

03CVE-2023-28432-MinIO 信息泄露漏洞

威胁等级：高危

漏洞描述：

2023年03月23日，华云安思境安全团队监测发现 MinIO 官方发布安全更新，披露了 MinIO 组件中存在一处信息泄露漏洞。MinIO 是一款开源的对象存储服务器，该产品支持构建用于机器学习、分析和应用程序数据工作负载的基础架构。该漏洞是由于 Minio 集群进行信息交换的9000端口，在未经配置的情况下可进行未授权访问，进而导致MinIO对象存储的相关环境变量泄露。成功利用此漏洞的攻击者可通过这些信息任意访问MinIO集群中的所有文件。

情报来源：

https://github.com/minio/minio/security/advisories/GHSA-6xvq-wj2x-3h3q

04 CVE-2023-28708-Apache Tomcat 信息泄露漏洞

威胁等级：中危

漏洞描述：

2023年03月23日，华云安思境安全团队监测发现 Apache 官方发布了安全更新，披露了 Apache Tomcat 组件中存在一处信息泄露漏洞。Apache Tomcat 是一款轻量级 Web 应用服务器，该程序实现了对 Servlet 和 JavaServer Page（JSP）的支持。该漏洞是由于用户代理能通过不安全的通道传输会话 cookie 引起，从而造成敏感信息泄露。

情报来源：

https://lists.apache.org/thread/hdksc59z3s7tm39x0pp33mtwdrt8qr67
