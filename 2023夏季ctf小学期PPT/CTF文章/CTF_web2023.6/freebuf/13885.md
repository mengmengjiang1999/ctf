内网域环境的搭建

大家好，我是Nirvana，最近看我周围的大佬都在写博客，于是自己也就搭建了一个博客，把自己写的文章都存在了博客里面，也想把自己的成长经历与经验教训分享给大家，于是就想到了来这里发文章，最近在学习内网，就先简单分享一下我搭建内网域环境的过程吧。

整体流程：

创建一个域环境，首先安装一台服务器（Windows server 2012 R2），然后将其升级为域控制器，接着将2008以及XP加入到该域，三台机器的IP地址分别设置为：

Windows server 2012 R2 -------------192.168.1.1

Windows server 2008 R2 -------------192.168.1.2

Windows XP -------------192.168.1.3

具体步骤

1.安装Windows server 2012 R2以及其余实验靶机

2.设置IP

3.更改计算机名

4.安装域控制器和DNS服务

5.升级服务器

6.创建Active Directory用户

7.加入Windows server 2008 R2以及Windows XP

1. 安装Windows server 2012 R2以及其余实验靶机

到https://msdn.itellyou.cn/可以下载任意版本的操作系统镜像

考虑到网盘速度不一，综合下来选择使用阿里云网盘，速度我感觉非常快,最主要还是免费的，在此将两个连接都放在下面，由于百度网盘限制，在百度网盘的链接里面没有windows server 2012 R2，请大家移步至阿里云盘下载吧2012

提取完成后在VMware里面安装。

2. 设置Windows server 2012 R2 的IP

右击我的电脑→属性→控制面板主页→网络和Internet→查看网络状态和任务按照如下设置

设置完成之后点击确定即可，这样我们的IP地址就已经被设置为192.168.1.1

3. 更改计算机名

同样的鼠标右击我的电脑→属性→更改设置

等他升级为域控后，就会变成DC-Nirvana+域的名字

更改完成之后提醒我们要重启才能实现显示我们更改的内容了，我们选择马上重启，重启之后会自动弹出服务器管理页面

5. 升级服务器

点开服务器管理器上面那个管理右边那个小红旗，点击将此服务器提升为域管理器

设置密码，这个密码是用来干什么的，这个密码是用来开机进入安全模式，开机修复数据库的时候用的

这个地方有个提示，我们不用管直接下一步

这个也是保持默认，是根据你前面设置的而改变

可以自己设置，也可以选择默认 ，一般选择默认即可

下一步

这边先决体条件检查，如果有错误的话，会有提醒，比如密码策略，因为这台服务器升级为域控制器后，这台机器的管理员也会被升极为域管理员，所以就会要求密码策略，默认的管理员密码为空，即没有密码。然后点击安装，安装结束会自动重启计算机

这样就代表安装好了

本机的管理员已经升级为域管理员了，我们的域控制器就升级好了

最后检查一下我们的DNS服务器里面含有如下这两个文件，如果含有，则证明没有问题
