为什么要安装SSL证书？
2021-04-07 14:19:12

在互联网时代，SSL证书已成为企业网站的重要组成部分。在未部署的情况下，访问企业网站时将提示您网站不安全。因为 HTTP 协议不能加密数据，使得网络上的所有通信数据都在明文中“裸奔”，这是 HTTPS 存在安全问题的重要原因，如数据泄露、数据篡改、流量劫持、钓鱼攻击等，而 HTTPS 就是能够解决这个问题的。因为 HTTPS 的安全基础是 SSL/TLS，所以 HTTP 数据传输的安全加密的详细信息需要使用SSL证书来实现。

为何安装SSL证书？

首先，如果未安装SSL证书，数据将以 http 的形式进行明文传输，并且很容易被监听、截取和篡改。由于受到利益的驱使，这些数据很可能被黑客利用，从而给用户和网站带来一定的损失。直觉上，用户会受到各种电话、短信的骚扰，或者在访问网站时跳转广告给用户带来不好的体验感。更严重的还有可能遭遇网络诈骗，造成经济损失。

其次，像谷歌这样的主流浏览器对 http 网站都不友好，甚至会向那些没有安装SSL证书但仍然使用 http 协议的网站发出红色警告。而且百度和谷歌也明确表示，安装了SSL证书的网站将在排名上享有优先的权利。

再次，对于 http 站点易受网络攻击，尤其是流量劫持，会让用户访问其他站点，从而造成流量损失，安装SSL证书可以有效防止劫持站点。

最后，对于安装了最高等级 EV SSL证书的企业，地址栏中不仅会出现绿色的小锁和 https，还会出现企业名称，可以大大提高用户的信任度，提升企业形象。
