Trend Micro修复InterScan Web Security Virtual Applia...
2020-05-28 16:03:02

网络安全公司Trend Micro近期发布安全公告，公开该公司的InterScan Web Security VirtualAppliance（IWSVA）产品存在多个安全漏洞。IWSVA是一款针对基于web方式的威胁，为企业网络提供动态的、集成式的安全保护的Web安全网关。

根据该公告内容，IWSVA6.5版本受到四个安全漏洞的影响，涉及跨站脚本，路径遍历，命令注入和身份认证绕过。

Trend Micro的Zero Day Initiative（ZDI）团队也就IWSVA中的安全漏洞发布了公告。根据ZDI发布的安全公告，影响IWSVA最严重的一个漏洞为CVE-2020-8606，该漏洞的CVSSv3评分为9.8。该漏洞存在于Apache Solr应用程序中，远程攻击者可利用该漏洞绕过IWSVA的身份认证。

Apache Solr应用程序中还存在一个高危目录遍历漏洞，该漏洞编号为CVE-2020-8604。在解析file参数时，在将用户提交的路径用于文件操作之前，该进程未能正确地验证该路径。远程攻击者可利用该漏洞获取敏感信息。

IWSVA 6.5版本中的命令注入漏洞（CVE-2020-8605）是个高危漏洞，该漏洞存在于LogSettingHandler类中。在解析mount_device参数时，在将用户提交的字符串用于执行系统调用之前，该进程没有正确地验证用户提交的数据。远程攻击者可利用该漏洞在root的上下文中执行任意代码。虽然利用该漏洞需要经过身份认证，但是CVE-2020-8606为攻击者绕过IWSVA的身份认证打开了通道。

IWSVA6.5版本中的跨站脚本漏洞（CVE-2020-8603）存在于对已记录的URL的处理功能中，该漏洞同样源于未能正确验证用户提交的数据，攻击者可利用该漏洞注入任意脚本。如成功利用该漏洞，远程攻击者可篡改IWSVA的web接口。攻击者还可以组合利用该漏洞和其他漏洞在root的上下文执行代码。对该漏洞的利用需要用户的交互，对此，攻击者可以采用钓鱼的方式，诱使目标用户访问恶意的页面或打开恶意文件。

TrendMicro已发布IWSVA 6.5 SP2 Patch 4（Build 1901），修复了上述漏洞。
