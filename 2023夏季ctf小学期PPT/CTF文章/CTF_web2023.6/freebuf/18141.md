资产类型

社交网站和应用程序

  * 这些应用程序往往很复杂，涉及用户之间以及用户与服务器之间的大量交互。

  * 许多程序都属于这一类：示例包括 HackerOne 的漏洞赏金计划和 Facebook、Twitter、GitHub 和 LINE 的程序。

  * 这些程序有一个主要的缺点。由于他们的产品很受欢迎且进入门槛低，他们通常竞争非常激烈，并且有很多黑客在追捕他们。 Facebook 和 Twitter 等社交媒体平台是一些最有针对性的程序。

一般网络应用程序

  * 用户与服务器交互以访问应用程序的功能。 属于这些类别的目标可能包括静态网站、云应用程序、银行网站等消费者服务以及物联网 (IoT) 设备或其他连接硬件的网络门户。与社交网站一样，它们也非常多样化，适合各种技能水平。 示例包括 Google、美国国防部和 Credit Karma 的程序。

  * 它们往往比社交应用程序更难破解，而且它们的攻击面更小。

  * 您需要查找特定于应用程序技术堆栈的服务器端漏洞和漏洞。您还可以查找常见的网络漏洞，例如子域接管。

  * 这些程序的受欢迎程度不一。但是，它们中的大多数都具有较低的进入门槛，因此您很可能可以立即开始黑客攻击！

移动应用程序（Android、iOS 和 Windows）

  * 在您掌握了黑客 Web 应用程序的窍门后，您可以选择专注于移动应用程序。

  * 黑客移动应用程序需要您通过黑客网络应用程序构建的技能组合，以及有关移动应用程序结构和与平台相关的编程技术的额外知识。

  * 您应该了解攻击和分析策略，例如绕过证书锁定、移动逆向工程和密码学。

  * 黑客移动应用程序还需要比黑客网络应用程序更多的设置，因为您需要拥有一台可以进行实验的移动设备。一个好的移动测试实验室由一个普通设备、一个 root 设备和适用于 Android 和 iOS 的设备模拟器组成。有根设备是您拥有管理员权限的设备。它将允许您更自由地进行实验，因为您可以绕过移动系统的安全限制。模拟器是您在计算机上运行的移动环境的虚拟模拟。它允许您运行多个设备版本和操作系统，而无需为每个设置拥有一个设备。

  * 由于这些原因，与 Web 应用程序相比，移动应用程序在漏洞赏金猎人中不太受欢迎。然而，对于那些参与的人来说，移动程序的更高进入门槛是一个优势。这些程序的竞争力较低，因此比较容易发现错误。

  * 从古至今，每一次的技术迭代都让大量黑客将目光转移到新的方向上，因为那里发现漏洞的机会更多。

  * 是否需要学习开发？前期不是必须，如果想走不拥挤，宽松的路。答案是，需要。准备目标的技术栈前置知识或者根据自己的前置知识选择针对性的目标。

APIs

  * 应用程序编程接口 (API) 是定义其他应用程序如何与组织资产交互的规范，例如检索或更改其数据。例如，另一个应用程序可能能够通过到某个端点的超文本传输协议 (HTTP) 消息检索应用程序的数据，并且该应用程序将以可扩展标记语言 (XML) 或 JavaScript 对象表示法 (JSON) 消息的格式返回数据.

  * 一些程序在推出新版本的 API 时，会更加关注漏洞赏金计划中的 API 漏洞。安全的 API 实施是防止数据泄露和保护客户数据的关键。黑客 API 需要许多与黑客 Web 应用程序、移动应用程序和 IoT 应用程序相同的技能。但是在测试 API 时，您应该关注常见的 API 错误，例如数据泄漏和注入缺陷。

源代码和可执行文件

  * 如果你有更高级的编程和逆向技能，你可以试试源代码和可执行程序。这些程序通过直接向黑客提供开源代码库或二进制可执行文件来鼓励黑客发现组织软件中的漏洞。示例包括 Internet Bug Bounty、PHP 语言程序和 WordPress 程序。

  * 破解这些程序可能需要分析开源项目的源代码以查找 Web 漏洞，并对二进制文件进行模糊测试以查找潜在漏洞。您通常必须了解编码和计算机科学概念才能在这里取得成功。您需要了解 Web 漏洞、与项目代码库相关的编程技能以及代码分析技能。密码学、软件开发和逆向工程技能很有帮助。

  * 源代码程序可能听起来令人生畏，但请记住，它们是多种多样的，因此您有很多可供选择。您不必成为高级程序员即可破解这些程序；相反，旨在深入了解项目的技术堆栈和底层架构。因为这些程序往往需要更多的技能，所以它们的竞争力较低，只有一小部分黑客会尝试使用它们。

硬件和物联网

  * 这些程序要求您破解汽车、智能电视和恒温器等设备。例子包括特斯拉和福特汽车公司的漏洞赏金计划。

  * 您需要非常具体的技能来破解这些程序：除了了解常见的 IoT 漏洞之外，您通常还必须深入了解您要破解的设备类型。您应该了解 Web 漏洞、编程、代码分析和逆向工程。此外，研究物联网概念和行业标准，例如数字签名和非对称加密方案。最后，密码学， 无线黑客和软件开发技能也会有所帮助。

  * 尽管某些程序会为您提供免费的黑客设备，但这通常仅适用于已与公司建立关系的精选黑客。要开始破解这些程序，您可能需要资金来自行购买设备。 由于这些程序需要专业技能和设备，因此它们的竞争力往往最低。

漏洞赏金平台

  * 公司可以通过两种方式托管漏洞赏金计划：漏洞赏金平台和独立托管的网站。 漏洞赏金平台是许多公司通过其托管程序的网站。通常，该平台会直接奖励黑客声誉点和金钱。一些最大的漏洞赏金平台是 HackerOne、Bugcrowd、Intigriti、Synack 和 Cobalt。

  * 漏洞赏金平台是黑客和安全团队之间的中介。他们为公司提供支付和通信等任务的后勤协助。他们还经常通过为公司过滤、重复数据删除和分类错误报告来帮助管理传入的报告。最后，这些平台为公司提供了一种通过黑客统计数据和声誉来衡量黑客技能水平的方法。这允许不想被低质量报告淹没的公司邀请有经验的黑客参与他们的私人程序。其中一些平台在允许黑客入侵程序之前还会筛选或采访黑客。

  * 另一方面，许多组织在没有平台帮助的情况下托管和管理他们的漏洞赏金计划。 Google、Facebook、Apple 和 Medium 等公司都在这样做。您可以通过访问他们的网站或在线搜索“CompanyName 漏洞赏金计划”来找到他们的漏洞赏金政策页面。 作为漏洞赏金猎人，您是否应该在漏洞赏金平台上进行黑客攻击？还是应该选择公司的独立托管程序？

  * 而国内的平台自然更不需要说了，这些都是新手练习的好地方。

优点

漏洞赏金平台最好的一点是，它们为公司的流程提供了很大的透明度，因为它们发布了披露的报告、有关程序分类率、支付金额和响应时间的指标。独立托管的程序通常缺乏这种透明度。在漏洞赏金世界中，分流是指漏洞的确认。您也不必担心每次提交漏洞报告时向安全团队发送电子邮件、跟进报告以及提供付款和税务信息的后勤工作。漏洞赏金计划通常还具有声誉系统，可让您展示您的经验，以便您可以访问仅限邀请的漏洞赏金计划。漏洞赏金平台的另一个优点是，它们经常作为第三方介入以提供冲突解决和法律保护。如果您向非平台程序提交报告，则您对最终的赏金决定没有追索权。

归根结底，您不能总是期望公司支付或解决当前行业状况的报告，但平台提供的黑客对黑客的反馈系统是有帮助的。

缺点

然而，一些黑客避免使用漏洞赏金平台，因为他们不喜欢这些平台处理报告的方式。提交给平台管理的错误赏金计划的报告通常由分类人员处理，第三方员工通常不熟悉公司产品的所有安全细节。关于分类人员处理报告不当的投诉很常见。
平台上的程序也打破了黑客和开发者之间的直接联系。通过直接计划，您经常可以与公司的安全工程师讨论漏洞，从而获得很好的学习体验。
最后，漏洞赏金平台上的公共程序通常很拥挤，因为平台给了他们额外的曝光率。另一方面，许多私人托管的程序没有得到黑客的足够重视，因此竞争力较低。对于许多不与漏洞赏金平台签约的公司，如果您想参与他们的计划，您别无选择，只能离开平台。

范围、支出和响应时间

在选择程序时，除了资产类型和平台之外，您还应该考虑哪些其他指标？在每个漏洞赏金计划的页面上，通常会列出指标以帮助您评估该计划。这些指标可让您深入了解您发现错误的难易程度、您可能获得的报酬以及程序的运行情况。

计划范围

首先，考虑范围。程序在其策略页面上的范围指定了您可以入侵的内容和方式。有两种类型的范围：资产和漏洞。资产范围告诉您可以破解哪些子域、产品和应用程序。漏洞范围指定了公司将接受哪些漏洞作为有效错误。例如，公司可能会列出其网站范围内和范围外的子域。
注意：由于不熟悉而没有列出在范围内的子域，没有明确代表它是允许的。保险起见，需要与公司交互把情况问清楚再测。

列为范围内的资产是您可以破解的资产。另一方面，被列为超出范围的资产是漏洞赏金猎人的禁区。加倍小心，遵守规则！入侵超出范围的资产是非法的。该公司还会经常列出它认为有效的漏洞：
范围外漏洞
1.自XSS 2.点击劫持 3.缺少 HTTP 标头和其他没有直接安全影响的最佳实践 4.拒绝服务攻击 5.使用已知易受攻击的库，没有可利用性证明 6.自动扫描仪的结果，没有可利用性证明

任何具有大型资产和漏洞范围的程序都是初学者的好起点。资产范围越大，您可以查看的目标应用程序和网页的数量就越多。当一个程序的资产范围很大时，您经常可以找到被其他黑客忽略的晦涩应用程序。这通常意味着报告错误时竞争较少。

漏洞范围越大，组织愿意听取报告的错误类型就越多。这些程序更容易发现错误，因为你有更多的机会，所以可以发挥你的优势。

支付金额

您应该考虑的下一个指标是该计划的支出金额。有两种类型的支付程序：漏洞披露程序 (VDP) 和漏洞赏金计划。

VDP 是仅限声誉的计划，这意味着它们不会为发现结果付费，但通常会提供诸如声誉积分和赃物之类的奖励。如果赚钱不是您的主要目标，它们是学习黑客的好方法。由于他们不付费，他们的竞争力较弱，因此更容易发现错误。您可以使用它们来练习查找常见漏洞并与安全工程师交流。

另一方面，漏洞赏金计划为您的发现提供不同数量的金钱奖励。一般来说，漏洞越严重，报告支付的费用就越多。但是不同的程序对于每个严重程度的平均支付金额不同。您可以在其漏洞赏金页面上找到程序的支付信息，通常列在称为支付表的部分中。通常，低影响问题的费用从 50 美元到 500 美元不等，而关键问题的费用可能高达 10,000 美元。然而，漏洞赏金行业正在不断发展，高影响漏洞的支付金额也在增加。例如，Apple 现在为最严重的漏洞奖励高达 100 万美元。

响应时间

最后，考虑程序的平均响应时间。一些公司会在几天内处理和解决您的报告，而另一些公司则需要数周甚至数月才能完成修复。延迟通常是由于安全团队的内部限制而发生的，例如缺乏处理报告的人员、发布安全补丁的延迟以及缺乏及时奖励研究人员的资金。有时，延迟发生是因为研究人员在没有明确复制步骤的情况下发送了不良报告。

优先考虑具有快速响应时间的程序。等待公司的回应可能是一种令人沮丧的经历，当你第一次开始时，你会犯很多错误。您可能会误判错误的严重性，撰写不清楚的解释，或在报告中犯技术错误。安全团队的快速反馈将帮助您改进，并使您更快地成为称职的黑客。

私人程序

大多数漏洞赏金平台会区分公共程序和私有程序。公共项目是对所有人开放的项目；任何人都可以破解这些程序并将错误提交给这些程序，只要他们遵守法律和错误赏金计划的政策。另一方面，私人程序只对受邀的黑客开放。对于这些，公司要求具有一定经验和良好记录的黑客攻击公司并向其提交错误。由于参与的黑客数量有限，私人程序的竞争力远低于公共程序。因此，在其中发现错误要容易得多。私人程序通常也有更快的响应时间，因为它们平均收到的报告更少。

公司内部可以开启这方面的业务：高额的奖励回报安全社区，取之于民用之于民，也利于自己的安全部门的KPI提升。佛光普照大地。

公司会向以某种方式证明其能力的黑客发送私人邀请，因此一旦发现一些错误，获得私人程序的邀请并不难。不同的漏洞赏金平台将有不同的算法来确定谁收到邀请，但这里有一些技巧可以帮助您实现这一目标。 首先，向公共程序提交一些错误。要获得私人邀请，您通常需要在平台上获得一定数量的声望值，而开始获得这些声望的唯一方法是向公共程序提交有效的错误。您还应该专注于提交高影响漏洞。

这些漏洞通常会奖励您更高的声望点，并帮助您更快地获得私人邀请。在本书第二部分的每一章中，我都会就如何将发现的问题升级以制造影响最大的攻击提出建议。在某些漏洞赏金平台（例如 HackerOne）上，您还可以通过完成教程或解决夺旗 (CTF) 挑战来获得私人邀请。

其次，不要垃圾邮件。提交非问题通常会导致声誉点下降。大多数漏洞赏金平台都会限制对分数高于特定阈值的黑客的私人邀请。

最后，在与安全团队沟通时要礼貌和礼貌。对安全团队粗鲁或辱骂可能会使您被禁止参加该计划并阻止您获得其他公司的私人邀请。

选择正确的程序

漏洞赏金是获得网络安全经验和赚取额外收入的好方法。但这个行业的竞争越来越激烈。随着越来越多的人发现这些程序并参与对它们进行黑客攻击，初学者开始变得越来越困难。 这就是为什么选择一个你可以从一开始就成功的计划很重要。

在你培养出一个 bug 猎人的直觉之前，你通常必须依靠容易实现的成果和众所周知的技术。这意味着许多其他黑客将能够找到相同的错误，而且速度通常比您快得多。 因此，选择一个更有经验的 bug 猎人忽略的程序是一个好主意，以避免竞争。您可以通过两种方式找到这些人烟稀少的程序：寻找无偿程序或寻找范围较大的程序。

首先尝试进行漏洞披露计划。经验丰富的漏洞猎人通常会忽略无偿程序，因为他们不支付金钱奖励。但他们仍然为您赢得积分和认可！而这种认可可能正是您获得私人付费计划邀请所需要的。

选择一个大范围的程序意味着您将能够查看更多的目标应用程序和网页。这削弱了竞争，因为更少的黑客会报告任何单一资产或漏洞类型。选择具有快速响应时间的程序，以防止沮丧并尽快获得反馈。

您可以纳入决策过程的最后一件事是该计划的声誉。如果可以，通过披露的报告收集有关公司流程的信息，并从其他黑客的经验中学习。公司是否善待其记者？他们是否尊重和支持？他们帮助你学习吗？选择在您仍在学习时提供支持的计划，以及会因您提供的价值而奖励您的计划。 如果您想闯入漏洞赏金的世界，为您的技能选择合适的程序至关重要。
