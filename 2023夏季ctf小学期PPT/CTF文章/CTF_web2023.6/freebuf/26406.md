深信服-安服BG招聘安全人才！
2021-03-29 19:51:41

深信服科技股份有限公司（下称“深信服”）是一家专注于企业级安全、云计算及基础架构的产品和服务供应商。自2000年成立时推出的VPN产品，到后来不断推出的全网行为管理（原上网行为管理）、广域网优化、应用交付、下一代防火墙，到近几年的桌面云以及超融合、私有云、混合云、托管云、安全服务等产品与服务，深信服一直围绕解决企业级用户的IT问题拓展自身业务。在如今的数字化时代，公司立志于承载各行业用户数字化转型过程中的基石性工作，从而让各行业用户的IT更简单、更安全、更有价值。

通过持续不断的努力，深信服已得到海内外用户的广泛认可，全球有超过10万家用户正在使用深信服的产品。目前深信服在全球共设有50余个直属分支机构，境内每一个省、自治区、直辖市至少设立了一个分支机构，国内90%以上的政府部委单位、80%以上的全球500强中资企业、90%以上的银行、证券和保险机构、90%以上的“双一流”高校、90%以上的医疗百强机构、三大运营商集团及其95%以上的省级分公司都是深信服的用户。海外业务已覆盖美国、新加坡、马来西亚、泰国、印尼、菲律宾、越南、缅甸、韩国、巴基斯坦、中东、意大利和南非等国家和地区。

深信服安服BG招聘如下岗位：

一、传统服务规划主管

Base 深圳

岗位职责：

1.洞察中高端客户的需求，研究业内本领域的标杆企业和其商业模式，将洞察转化为业务侧设计规划的指引，聚焦行业客户的需求趋势变化、友商业务规划及技术发展，定期进行专题研究；

2.组织制定针对中高端客户的安全服务的规划、落地及竞争力设计，定义服务的结果指标和过程指标；

3.牵头制定高级安全服务装备的规划设计并推动研发落地，降低交付门槛，提升交付效果和效率；

4.对服务规划的技术风险、可行性、实施效果进行系统性评估，跟踪和分析各类服务的落地实施效果，并据此进行改善优化。

任职要求：

1.网络安全领域10年以上工作经验，其中安全服务工作经验8年以上；

2.熟悉国内外信息安全标准规范，尤其是安全服务相关的标准，如：风险评估、ISMS、等级保护、漏洞、应急等相关的标准。

3.具备大客户的安全服务项目经验，至少全流程交付过5个以上大型安全服务项目，精通政府、金融、能源、互联网等行业网络安全体系建设优先；

4.参与组织筹备并带队交付过省级以上攻防演习、CTF比赛，参加过国家顶级网络安全赛事筹备工作的优先；

5.具备战略视角与较强的政策敏感度，有敏锐的洞察力，清晰缜密的逻辑思维能力，高效总结和概括能力，良好的理解能力，注重细节，责任心强。

二、服务设计专家

Base 北京、深圳

岗位职责：

1、独立开展客户（特别行业头部）安全服务需求洞察，洞悉业内安全服务发展方向；

2、能从客户安全需求中抓到不同层次的安全服务机会，导入安全开发和服务交付团队；

3、能提炼安全服务共性需求，规划高级安全服务，提出服务模式，设计服务触点，服务流程和服务交付物；

4、能识别已有安全服务模式以及流程等存在的问题并提出有效优化措施。

任职要求：

1、计算机相关专业，网络安全行业5年以上工作经验，3年以上安全服务工作经验；

2、熟悉风险评估、应急响应等常规的安全服务工作流程；

3、具备攻击方视角，做过渗透测试或者有红队经验，了解最新红队攻击手段和常见漏洞；

4、具备防守方视角，参加过HW等重大安全保障活动；

5、加分项：做过服务设计、服务过头部客户、获得CISSP/CISP等相关安全认证。

三、头部客户项目经理

Base 北京

岗位职责：

 1. 负责金融、央企、大企业等公司头部客户的安全服务项目管理工作，解决客户提出的各类需求及问题；
 2. 负责协调攻防演习、渗透测试、等级保护测评、网络安全风险评估、安全运维应急响应、网络安全培训等工作的实施与质量把控，报告编写；
 3. 负责项目小组成员管理，确保用户现场实施工作的顺利开展；
 4. 积极沟通、协调整合公司内外资源，推进项目进度；
 5. 负责项目交付验收，完成项目资料、验收交付文档的收集和整理。

岗位要求：

 1. 熟悉网络安全相关理论知识，熟悉安全服务业务；
 2. 具有3年以上安全行业从事经验，政府部委、央企等安全类项目管理经验者优先；
 3. 具备较强的抗压能力、责任心、沟通协调能力、学习能力及文档编写能力；
 4. 具有CISP、CISSP或PMP等证书者优先 。
 5. 本科及以上学历

四、安服市场运营专家（总部）

Base 深圳

岗位职责：

1、负责行业/头部客户安全需求洞察和提炼，参与安全综合服务方案的需求评审、规划与试点交付；

2、负责设计、输出和优化面向行业客户、头部客户安全服务综合解决方案；

3、负责安全综合服务方案在公司内外部运营推广；

4、将面向行业客户的标准场景综合服务形成主需求，制作销售工具，制定推广策略和方案，最终形成区域、行业或全国主需求并保障落地效果；

5、参与重要项目客户交流和技术认可，参与公司安全服务业务流程建设和优化。

任职要求：

1、本科及以上学历，3年及以上安全行业从业经历，具备中大型项目安全服务/解决方案项目方案设计/交付经验；

2、熟悉主流系统、网络、应用攻击技术原理及防御加固方案、掌握常见的安全漏洞及利用技术；

3、熟悉等级保护、风险评估、渗透测试、安全加固等安全业务，了解相关安全标准和规范及安全体系；

4、熟悉主流安全产品、安全服务解决方案，具备安全咨询规划能力者优先；

5、具有良好的沟通、团队协作能力、客户需求理解能力和文案编写能力；

6、具备CISP、CISSP、CCIE Security资质者优先，具备公司售前、安全产品运营、安全项目管理经验者优先

五、安服行业运营专家

Base 深圳

岗位职责：

1.负责所在行业（企业/政府/医疗/教育/能源/媒体/金融/烟草）的安全服务（人工服务/安全运营服务体系/安全托管服务）的需求洞察、解决方案规划和设计，将需求形成标准化推广方法和工具，最终形成行业主需求；

2.负责制定并落实所在行业安全服务运营突破工作，包括：基于行业的市场赋能、渠道建设、样板点建设、沙龙活动等；

3.负责所在行业样板点/重点客户安全服务类项目的售前技术支持；

4.负责与所在行业的市场人员一起营造安全服务良好销售氛围，促进行业市场人员主动销售，达成安服在主要行业的销售目标。

岗位要求：

1.本科及以上；2年及以上安全行业从业经历，具备中大型安全服务项目的交付、运营与管理经验，或具备安全运营服务/安全托管服务/威胁分析与处置服务（MSS）设计、运营与管理经验；

2.熟悉主流系统、网络、应用攻击技术原理及防御加固方案、掌握常见的安全漏洞及利用技术；

3.熟悉等级保护、风险评估、渗透测试、安全加固等安全业务，了解相关安全标准和规范及安全体系；

4.熟悉安全事件应急响应流程，能够对各类安全问题和安全事件进行跟踪、分析、处理和解决；

5.具备良好的演讲能力和赋能培训能力；

6.具有良好的沟通、团队协作能力、客户需求理解能力和文案编写能力；

7.具备CISP、CISSP、CCIE Security资质者优先。

六、MSS市场运营专家

Base 深圳

岗位职责：

负责针对MSS（安全托管服务）产品线，工作包括但不限于以下内容：

1、负责内外部需求的管理工作：客户需求的洞察与运营、销售通路需求的收集与响应；

2、负责产品线销售策略与打法的输出、优化销售工具；

3、负责对同类竞品的功能、市场打法等进行分析，并输出应对策略；

4、品牌营销工作，针对产品线的内外部口碑进行建设，扩大影响力。

任职要求：

1、3年以上安全行业从业经历，具备安全运营服务/安全托管服务/威胁分析与处置服务/相关服务的设计、运营与管理经验优先；

2、熟悉行业或者商业市场，具备针对市场进行分析，解读相关政策法规的能力；

3、具备良好的市场洞察能力和竞争分析能力，能够基于发现的需求和分析的竞争情况，制定产品线相关的打法策略；

4、熟悉等级保护、风险评估、渗透测试、安全加固等安全业务，了解相关安全标准和规范及安全体系；

5、具备良好的演讲能力和赋能培训能力；

6、具有良好的沟通、团队协作能力、客户需求理解能力和文案编写能力。

七、SDL咨询专家

Base 深圳

岗位职责：

 1. 负责SDL相关课程设计；
 2. 负责SDL服务落地咨询，并输出SDL解决方案，推动方案落地。

岗位要求：

 1. 2年以上软件开发经验，具备一定架构设计能力者优先；
 2. 熟悉威胁建模，熟悉常见安全设计方法；
 3. 良好渗透测试能力，能识别常见安全问题，深入理解主流安全攻防技术；
 4. 熟悉S-SDLC/SDL安全开发流程；
 5. 熟悉CI/CD及各种主流安全开发工具链，熟练使用Linux、Docker；
 6. 有一定内部赋能或者外部咨询经验，具备一定DevSecOps落地经验优先；
 7. 持有CISSP、CISD、OSCP等证书优先。

八、安服专家岗

Base 深圳

岗位职责：

1.负责高级安全服务的交付设计及标杆样板打造，负责重大、疑难复杂的项目实施指导。

2.规划组织、工具及人员能力建设，规划人才梯队建设蓝图、打造高服务质量的安全服务交付团队。

3.建立安服知识分享及传承机制，沉淀安服组织交付经验，打造安服“藏经阁”。

任职要求：

1.深度熟悉安服业务，安服项目经验丰富，熟悉安全服务的理念和业务流程;

2.熟悉安全模型、架构、主流安全技术和产品，知识面广泛，熟悉安全相关法律法规标准，如等级保护、iso27001、风险评估、itil标准等；

3.具备优秀的沟通协调与组织能力，亲和力、演讲力极佳，有创新意识。

4.能独立承担需求诊断、培训方案设计和项目运营，有丰富的培训项目设计和运营经验优先。

九、重保服务专家

Base 深圳、北京

岗位职责：

1、负责攻防演练、应急演练、网络安全执法检查、关键信息基础设施检查等监管单位专项服务的业务设计、优化及赋能；

2、负责重保方案、重大赛事方案的设计、优化及赋能；

3、为国家监管单位、主管单位提供专家支持，如国家级重大会议活动及重大赛事的网络安全保障组织统筹、监管单位专项服务的实施指导。

任职要求：

1、了解监管单位、主管单位的组织架构、职责、业务范围；

2、具备重大会议活动、重大赛事网络安全保障组织统筹经验优先；

3、具备良好的沟通与团队协作能力。
