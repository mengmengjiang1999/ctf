Fortinet Security Fabric安全架构引领Gartner全新CSMA理念发展
2021-12-30 16:16:03

随着远程办公、云化服务的兴起，以及网络攻击技术的快速演进，网络安全威胁形势日趋严峻，传统安全防护手段已经难以为继。Gartner提出了全新“网络安全网格架构(CSMA)”理念，正与十年来不断演进的Fortinet Security Fabric安全架构不谋而合。正是因为这种前瞻和引领能力，使得Fortinet Security Fabric安全架构成为了CSMA理念的最佳落地实践。

应时而生：网络安全网格架构（CSMA）

据悉，疫情的蔓延使得随时随地办公正在成为常态，还有更多的应用和数据迁移到云服务，使得传统网络边界已经消失，造成网络安全威胁形势日益复杂。同时，网络攻击手段也在快速演进，AI和大规模自动化技术驱动的新型威胁已经层出不穷，更带来了快速增长的网络攻击数量。

在这种形势下，传统安全手段已经无以为继，加之组织普遍存在网络安全技能短缺的困境，这就需要一种全新的安全架构模式来解决新需求。 因此，Gartner全新“网络安全网格架构(CSMA)理念一经问世就获得了广泛关注，并被列入2022年网络安全主要趋势。


图：Gartner的网络安全网格架构(CSMA，Cybersecurity Mesh Architecture)

Gartner在2022年重要战略技术趋势报告中提出Cybersecurity Mesh(网络安全网格)，并指出这是一种现代化的安全方法，能够在需要的地方部署一致性的控制能力，以一种紧密集成、可扩展、高度灵活，并富有弹性/韧性的方式，通过提供支持服务层(整合策略管理整合控制台安全情报和身份矩阵)来让安全工具之间能够协作而不是各自为战。能够让任何用户和设备可以安全地访问或使用数字化资产，无关乎其所在的物理位置。

不谋而合：Fortinet Security Fabric安全架构

“英雄所见，往往略同。”令人惊异的是，CSMA的这些理念与Fortinet Security Fabric安全架构完全相同。作为全球网络安全领导者，Fortinet洞察网络安全发展趋势，在十年前就开始布局Security Fabric安全架构。经过十年的演进，可以说Security Fabric安全架构已经成为建设CSMA最佳范式。

图：Fortinet Security Fabric安全架构与Gartner CSMA

Fortinet Security Fabric安全架构是由FortiOS支持的业内出类拔萃的网络安全平台，具有丰富的开放式生态系统用户。通过Fortinet Security Fabric，在一套平台与架构中就能实现原生集成所有的安全能力，不论这些能力是否由Fortinet产品提供都能在不断扩大的攻击面中快速发现并响应威胁。

全面覆盖、深度集成、动态协同是Security Fabric安全架构的精髓，这对于在当前不断扩展的网络中降低复杂度和提高整体安全有效性至关重要。同时，这些能力也使得组织能够获得所有边缘的深度可见性，并能够获得集中管理分布式业务和体系的最佳解决方案， 实现网络和安全策略在任何位置的一致执行 。

此外，基于Fortinet Security Fabric 安全架构的安全产品，已经在全球广泛分布，能够实现对安全数据收集、分析、整理，并借助FortiGuard实验室输出为高质量威胁情报，还能集成第三方能力以更好地防御已知和未知攻击，并在不同的网络环境、不同的网络边界实现对威胁的自动响应。

Fortinet深刻理解安全生态的重要性，通过Fabric-Ready将基础架构、运维管理、IT应用云平台等不同领域的领导厂商紧密集成，借助Security Fabric内生的可见性、Al驱动防护以及自动化管理编排响应能力全面赋能，打造广泛的网络安全生态系统，也已实现450+开放生态系统集成，以Security Fabric为坚实基座打造快速响应、性能优异且“乐高化”的CSMA解决方案。

权威认可：用户、市场和权威机构

基于Fortinet Security Fabric安全架构，Fortinet产品连续多年获得Gartner权威认可。2021年，Fortinet 同时位4个Gartner魔力象限，其中网络防火墙和广域边缘基础设施都位于领导者象限。迄今为止，Fortinet 产品在不同领域内的优异表现已经获得18份Gartner年度报告提名。其中，有10份报告Fortinet都被列在Gartner 市场指引之中，这也标志着Fortinet 受到用户、市场以及第三方权威机构的广泛认可。

不仅如此，Fortinet在提供业界最佳产品的同时首创安全与组网融合的安全SD-WAN，原生协同、有机联动、全方位守护的Security Fabric安全架构等业界领先的解决方案引领安全防护理念的发展方向。
