Gartner中国在“云安全最佳实践”及“数据安全厂商概览”等报告中对天空卫士的认可
2022-04-01 15:54:35

Gartner作为全球最具权威的IT研究与顾问咨询公司，今年发布多项中国市场的数据安全调研报告，这些报告有助于协助客户进行市场分析、技术选择、项目论证、投资决策。天空卫士作为国内数据安全引领者，多次出现在Gartner的报告中。

《中国数据安全代表厂商概览》

2022年3月9日，Gartner发布“Toolkit: Vendor Identification for Cloud Security, Data Security, IAM and Security Operations in China”报告（“《中国数据安全代表厂商概览：云安全、数据安全、身份与访问控制、安全运营》”），该工具包收录了中国60多家云安全、数据安全、身份和访问管理以及安全运营提供商。天空卫士的云安全产品CASB和数据安全产品DLP位列其中。



报告发布的意义

此次，Gartner在报告中写到：该工具包的目的是帮助中国企业的安全和风险管理者评估适合其业务情况的本地产品。工具包包含一个供应商名单和他们的产品覆盖率。与任何技术一样，没有“最佳”的整体安全产品，只有更适合的产品。它不会试图对列出的供应商进行评级或排名，也不会包罗万象。

《中国云安全最佳实践》

2022年3月3日发布Top Practices for Cloud Security in China《中国云安全的最佳实践》，在本次报告中，尤其在CASB领域，Gartner给予了天空卫士非常高的评价。

Gartner对天空卫士的肯定

以下为部分内容翻译：

CASB（云安全访问代理）通过将多种类型的安全策略实施整合到SaaS、IaaS和PaaS的一个地方，为可见性、法规遵从性、数据安全和威胁保护提供了关键的云安全管理控制。示例包括授权、用户和实体行为分析（UEBA）、自适应访问控制、数据丢失预防（DLP）、设备配置、对象加密、标记化、日志记录、警报和恶意软件删除。

Gartner在选择和比较不同的CASB产品方面做了大量研究。CASB主要用于SaaS保护，大多数CASB部署基于云。CASBS正日益成为安全访问服务边缘（SASE）的组成部分。

CASB在全球范围内广泛应用于云安全领域，而中国只有少数本地CASB供应商（SkyGuard和LOCKet）。建立一个成功的CASB需要与CSP密切合作，这在中国并不容易。


报告发布的意义

Gartner分析，到2024年中国近40%的最终用户系统基础设施和基础设施软件支出将转移到云服务支出上。随着这一重大的云转移，云安全成为中国安全和风险管理领导者的关键优先事项。由于共享云安全责任和云产品的复杂性，客户需要新的安全工具组来帮助他们安全地使用云。Gartner经过大量的调研分析， 出具了本报告，协助用户在云安全产品部署和选择上做出正确的决策。

Gartner持续对天空卫士的关注

在全球范围内，Gartner已经向10000多家机构提供战略咨询服务。Gartner的研究由其研究机构独立进行，不受任何第三方的影响，所以报告以其独立性和客观性而被广泛认可。国内外厂商都将被列入Gartner报告视为一种荣誉。从2018—2021年，天空卫士已经多次出现在Gartner全球报告中。
