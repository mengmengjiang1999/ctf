CVE-2018-18778-mini_httpd任意文件读取漏洞复现
2021-08-31 09:33:32

复现

这里使用vulhub进行复现

启动容器：

cd vulhub

ls

cd mini_httpd

ls

cd CVE-2018-18778

docker-compose up -d

docker ps 查看端口为8080，

访问8080查看是否成功运行

BP抓包去掉host，/etc/passwd可换成任意文件名，即可任意文件读取

docker-compose down 关闭镜像

可能遇到的问题：

8080端口无法访问

可以使用防火墙开放8080端口

systemctl start firewalld 开启防火墙

firewall-cmd --zone=public --add-port=8080/tcp --permanent 开启8080端口

firewall-cmd --reload 重载防火墙文件

systemctl stop firewalld.service 要是不想开着就可以关闭防火墙了

这时候要重启docker,不然就会报错

systemctl restart docker
