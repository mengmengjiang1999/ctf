全球网络拓扑测绘系统--擎天神
2020-04-16 16:16:01

擎天神是全球网络拓扑测绘系统，系统界面如下图所示。该系统通过不同级别不同颗粒度的网络拓扑可视化功能，展示全球互联网的拓扑关系，包含全球、国家间、国家内、AS 域间、AS 域内的三维地理拓扑和二维逻辑拓扑。其中，以AS 为最小颗粒度，可以查看国家与国家之间的网络出口和入口；以 IP 为最小颗粒度，可以查看国家与国家、国家与 AS、AS 与 AS 之间的路由器出口和入口。

它的主要功能有：全球网络拓扑测绘，包含全球级别、国家级别（国家间与国家内）和 AS 级别（AS 域间和 AS 域内）、POP 级别、路由器级别（核心路由器、中路由器、边缘路由器）和 IP 级别。支持全球 54,772个AS域，近43亿全量 IP。网络拓扑分为地理拓扑和逻辑拓扑。国家级别拓扑提供 AS 号、AS 包含的 IP 量、AS 直连的国家或地区数量、直连的 AS 数量和节点度数。AS 级别拓扑提供 AS 名称、AS 类型、传输度数、AS 包含的 IP 量、连通的 AS 数量、连通的 IP 数量和 AS 连接的类型（包含对等互连、服务商与客户相连和同机构 AS 相连）。国家间相连的 AS 明细，AS 间相连的路由器明细。指定地区下 AS 域内拓扑，提供路由器连接关系、路由器接口 IP 和路由器详细信息（如路由器位置、在网络中承担的角色和网络带宽等）。

目前，全球网络拓扑可视化系统已完成全球级别的 AS 网络拓扑、中国香港和中国台湾的所有 AS 域内拓扑，并提供对应的网络拓扑查询服务和离线数据库。

全球级别的 AS 网络拓扑包含 224 个国家、54,772 个 AS、230,258 个 AS 边关系，统计信息如表 1.1 所示。其中，企事业机构类型 AS 占比 53.92%，对等互联(PP)类型 AS 边占比 53.66%，详细如表 1.2 所示。

中国香港网络拓扑数据统计如表 1.3 所示，包含 124,664 个路由器，411,029条路由器连接关系。

中国台湾网络拓扑数据统计如表 1.4 所示，包含 57,557 个路由器，111,161 条路由器连接关系。

全球网络拓扑测绘系统，可用于分析全球网络连通情况，优化网络建设。

古巴网络连接情况分析：

古巴网络连接情况如图1.2 所示。可以看到，古巴有三个AS，分别是AS11960、 AS27725 和 AS10569，并且 AS11960 是 AS10569 的网络出口，AS11960 是 AS27725的网络出口，所以 AS11960 在古巴网络中承担核心角色，也是古巴网络的脆弱节点，一旦 AS11960 出现网络异常，则会影响古巴所有网民的网络访问。
