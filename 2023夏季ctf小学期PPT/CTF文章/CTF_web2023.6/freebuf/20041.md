什么是堆

程序运行的时候，堆提供了动态分配的内存，允许程序申请大小未知的内存(体现在c语言上就是用malloc申请的内存)。这是一段连续的空间，由低地址向高地址方向延伸。堆管理器会去管理堆。


堆管理器做了什么？

当用户申请堆的时候，其实是向堆管理器发出请求，堆管理器向操作系统申请内存并且交给程序。并且内核会先分配一片大的内存交给堆管理器，然后堆管理器再进行进一步的分配(这个下一篇文章会写)。如果堆空间不足，堆管理器会与操作系统进行交互申请

用户释放内存的时候(c语言体现为free)并不直接交给操作系统，而是还给堆管理器。这完全是为了方便用户的下次申请。当用户下次申请的时候会查找这些堆空间

堆分配的时候，都是在虚拟内存的层面进行分配。并不会直接分配物理内存，当对一个地址进行访问的时候系统才会建立虚拟页与物理页的映射(举个例子的话就像是网盘一样，表面上给你几百GB的空间，实际上是看见有那么多，其实是你用多少给你分配多少)

有关堆的一些操作(C语言)

malloc

malloc会申请用户指定的内存，并且返回对应大小字节的内存块指针(void *malloc(unsigned int size)，从定义就可以看出它的返回值是一个指针)。还有一些特殊的情况

如果你申请的是0，那么当前系统会返回当前系统允许的堆的最小内存块

如果申请的是负数(可以看一下上面malloc的定义，参数是一个无符号数)，将会导致程序申请很大的内存空间(可以了解一下原码和补码)。很可能申请失败，因为没那么大的空间

free函数会释放一个指针(当然是申请过内存的指针)所指向的内存块。但是free会出现一些异常

p为空指针时不再进行任何操作

p被释放过以后再次被释放，会出现double free(以后会讲到)

如果释放的内存空间比较大的话，释放的这些内存空间会直接还给系统(更细节的东西后面会讲到)

系统调用

malloc函数的本质是进行了系统调用brk和mmap，free的本质是调用munmap
一个比较经典的图。

(s)brk(malloc申请的内存小于128kb的时候会使用brk)
操作系统提供了btk函数，而sbrk是glibc对brk的封装。首先下面先附上一张图
注：

如果不开启地址随机化(ASLR)，start_brk和brk会指向data/bss段的结尾

如果开启地址随机化，start_brk和brk会指向data/bss段以上的一个随机偏移地址

接下来直接上代码

/* sbrk and brk example */
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>

int main()
{
        void *curr_brk, *tmp_brk = NULL;

        printf("Welcome to sbrk example:%d\n", getpid());

        /* sbrk(0) gives current program break location */
        tmp_brk = curr_brk = sbrk(0);
        printf("Program Break Location1:%p\n", curr_brk);
        getchar();

        /* brk(addr) increments/decrements program break location */
        brk(curr_brk+4096);

        curr_brk = sbrk(0);
        printf("Program break Location2:%p\n", curr_brk);
        getchar();

        brk(tmp_brk);

        curr_brk = sbrk(0);
        printf("Program Break Location3:%p\n", curr_brk);
        getchar();

        return 0;
}
#这个代码的glibc版本我自己改成的2.21，因为版本再高一点会有一些不一样的东西，如何更改glibc版本我之前已经发过一篇文章，跟着一步一步来就行


这是第一次调用brk之前的内存，并没有出现heap segment

然后第一次调用brk
已经出现了heap segment
出现的heap segment有相应的地址，内存权限，文件偏移(由于是向内存申请的空间，而不是直接从文件中映射得到的，所以文件偏移显示为0)

那么综上所述，大家对brk也有了一定了了解。其实brk的效果就是让heap segment的顶部向上移动来达到扩充空间的效果。
代码只不过是在原来的基础上多调用一次brk，很明显堆向上增长而使空间扩充

mmap(当申请内存大于128KB时使用(其实不单单是这样，后面会有进阶版，其他情况调用mmap))

/* Private anonymous mapping example using mmap syscall */
#include <stdio.h>
#include <sys/mman.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>
#include <stdlib.h>

void static inline errExit(const char* msg)
{
        printf("%s failed. Exiting the process\n", msg);
        exit(-1);
}

int main()
{
        int ret = -1;
        printf("Welcome to private anonymous mapping example::PID:%d\n", getpid());
        printf("Before mmap\n");
        getchar();
        char* addr = NULL;
        addr = mmap(NULL, (size_t)132*1024, PROT_READ|PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
        if (addr == MAP_FAILED)
                errExit("mmap");
        printf("After mmap\n");
        getchar();

        /* Unmap mapped region. */
        ret = munmap(addr, (size_t)132*1024);
        if(ret == -1)
                errExit("munmap");
        printf("After munmap\n");
        getchar();
        return 0;
}

首先是调用mmap之前
