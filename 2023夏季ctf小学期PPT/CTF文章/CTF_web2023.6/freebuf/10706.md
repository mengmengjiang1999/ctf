华云安漏洞安全周报【第85期】
2022-05-30 11:34:20

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.5.16~2022.5.22）CNNVD接报漏洞231个，信息技术产品漏洞（通用型漏洞）47个，网络信息系统漏洞（事件型漏洞）184个，其中华云安报送漏洞5个；CNNVD接报漏洞预警101份，其中华云安报送预警13份，预警报送数量位列第二！

本周重点关注漏洞包括：CVE-2022-1654-WordPressCode Snippets Extended CSRF 漏洞、CVE-2022-22972-VMware 身份验证绕过漏洞、CVE-2022-22973-VMware 权限提升漏洞、CVE-2022-21500-Oracle E-Business Suite 信息泄露漏洞、CVE-2022-1802-Mozilla 代码执行漏洞、CVE-2022-1529-Mozilla 代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-1654-WordPressCode Snippets Extended CSRF 漏洞

威胁等级：中危

漏洞描述：

2022年5月17日，华云安思境安全团队发现 WordPress 官方发布安全更新，披露了 WordPressCode Snippets Extended 组件中存在一处权限提升漏洞。WordPress 是使用 PHP 语言开发的博客平台。该漏洞是由于浏览器的安全策略允许当前页面向任何地址发送请求引起，成功利用此漏洞的攻击者通过发送特制请求，进而破坏网页的完整性。

情报来源：

https://wordpress.org/plugins/code-snippets-extended/#developers

02CVE-2022-22972-VMware身份验证绕过漏洞

威胁等级：超危

漏洞描述：

2022年5月18日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware Cloud Foundation、VMware vRealize Automation、VMware Workspace One Access 等多款组件中存在一处访问控制绕过漏洞。VMware Cloud Foundation 是一套一体化混合云平台；VMware vRealize Automation 是一个提供自助式云服务、监管式多云自动化的管理工具；VMware Workspace One Access 是一个集中式管理控制台。该漏洞是由于在处理身份验证请求时 UI 出现错误引起，成功利用此漏洞的攻击者可绕过身份验证，从而获得对应用程序的访问管理权限。

情报来源：

http://www.vmware.com/security/advisories/VMSA-2022-0014.html

03CVE-2022-22973-VMware 权限提升漏洞

威胁等级：高危

漏洞描述：

2022年5月18日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware Cloud Foundation、VMware Workspace One Access、VMware Identity Manager 等多款组件中存在一处权限提升漏洞。VMware Cloud Foundation 是一套一体化混合云平台；VMware Workspace One Access 是一个集中式管理控制台；VMware Identity Manager 是一个 Workspace One 的身份和访问管理组件。该漏洞是由于应用程序未正确添加安全限制引起，成功利用此漏洞的攻击者可使用 root 权限执行任意代码。

情报来源：

http://www.vmware.com/security/advisories/VMSA-2022-0014.html

04 CVE-2022-21500-Oracle E-Business Suite 信息泄露漏洞

威胁等级：高危

漏洞描述：

2022年5月19日，华云安思境安全团队发现 Oracle 官方发布安全更新，披露了 Oracle E-Business Suite 组件中存在一处信息泄露漏洞。Oracle E-Business Suite 是一套集成的业务应用程序，使组织能够做出更好的决策、降低成本并提高绩效。该漏洞是由于未对请求进行正确过滤引起，成功利用此漏洞的攻击者在未经身份验证的情况下通过对 HTTP 进行网络访问，从而对关键信息和所有 Oracle E-Business Suite 可访问数据均可进行访问。

情报来源：

https://www.oracle.com/security-alerts/alert-cve-2022-21500.html#AppendixEBS

05CVE-2022-1802-Mozilla 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年5月20日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Mozilla Firefox、Mozilla Firefox ESR、Mozilla Thunderbird 等多个组件中存在一处代码执行漏洞。Mozilla Firefox 是一款开源 Web 浏览器；Mozilla Firefox ESR 是 Firefox 的一个延长支持版本；Mozilla Thunderbird 是一套从 Mozilla Application Suite 独立出来的电子邮件客户端软件。该漏洞是由于顶级 wait 在实现中出现原型污染引起，成功利用此漏洞的攻击者通过原型污染破坏 JavaScript 中的数组对象的方法，从而在上下文中执行任意 JavaScript 代码。

情报来源：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-19/

06CVE-2022-1529-Mozilla 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年5月20日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了Mozilla Firefox、Mozilla Firefox ESR、Mozilla Thunderbird 等多个组件中存在一处代码执行漏洞。Mozilla Firefox 是一款开源 Web 浏览器；Mozilla Firefox ESR 是 Firefox 的一个延长支持版本；Mozilla Thunderbird 是一套从 Mozilla Application Suite 独立出来的电子邮件客户端软件。该漏洞是由于对用户提供的输入验证不足引起，成功利用此漏洞的攻击者通过诱导用户访问一个特制的 web 页面，从而在目标系统上执行任意代码。

情报来源：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-19/
