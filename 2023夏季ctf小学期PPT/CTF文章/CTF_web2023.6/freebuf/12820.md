华云安漏洞安全周报【第79期】
2022-04-21 13:18:47

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.4.4~2022.4.10）CNNVD接报漏洞420个，信息技术产品漏洞（通用型漏洞）35个，网络信息系统漏洞（事件型漏洞）385个，其中华云安报送漏洞1个；CNNVD接报漏洞预警65份，其中华云安报送预警11份，预警报送数量位列第三！

本周重点关注漏洞包括：CVE-2022-1162-Gitlab 硬编码漏洞、CVE-2021-26114-Fortinet FortiWAN SQL 注入漏洞、CVE-2022-1097-Mozilla Firefox UAF 漏洞、CVE-2022-28281-Mozilla Firefox 越界写入漏洞、CVE-2022-28289-Mozilla Firefox 缓冲区溢出漏洞、CVE-2022-22954-VMware 代码执行漏洞、CVE-2022-22955-CVE-2022-22956-VMware 身份验证绕过漏洞、CVE-2022-22957-CVE-2022-22958-VMware 代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-1162-Gitlab 硬编码漏洞

威胁等级：高危

漏洞描述：

2022年4月4日，华云安思境安全团队发现 Gitlab 官方发布安全更新，披露了 Gitlab 组件中存在一处硬编码漏洞。GitLab 是一个用于仓库管理系统的开源项目,使用 Git 作为代码管理工具，并在此基础上搭建起来的 Web 服务。该漏洞是由于注册时对帐户设置了硬编码密码引起，成功利用此漏洞的攻击者可绕过身份验证。

情报来源：

https://gitlab.com/gitlab-org/cves/-/blob/master/2022/CVE-2022-1190.json

02CVE-2021-26114-Fortinet FortiWAN SQL 注入漏洞

威胁等级：超危

2022年4月5日，华云安思境安全团队发现 Fortinet 官方发布安全更新，披露了 Fortinet FortiWAN 组件中存在一处 SQL 注入漏洞。FortiWAN 产品可以智能地负载均衡互联网流量和跨多运营商的外部流量，同时能够降低企业使用上行和下行带宽的成本，为企业提供可靠性更加的网络连接。该漏洞是由于 FortiWAN 中特殊元素的多次不当使用引起，成功利用此漏洞的攻击者在未经授权的情况下通过发送特制的 HTTP 请求，从而执行代码或命令。

情报来源：

https://www.fortiguard.com/psirt/FG-IR-21-062

03 CVE-2022-1097-Mozilla Firefox UAF 漏洞

威胁等级：高危

漏洞描述：

2022年4月5日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Mozilla Firefox 组件中存在一处 UAF 漏洞。Firefox 是由 Mozilla 基金会与开源团体共同开发的网页浏览器。该漏洞是由于处理 NSSToken 对象时出现 usa-after-free 问题，成功利用此漏洞的攻击者通过创建恶意网页诱使用户访问，从而触发释放后使用错误，导致执行任意代码。

情报来源：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-13/

04 CVE-2022-28281-Mozilla Firefox 越界写入漏洞

威胁等级：高危

漏洞描述：

2022年4月5日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Mozilla Firefox 组件中存在一处越界写入漏洞。Firefox 是由 Mozilla 基金会与开源团体共同开发的网页浏览器。该漏洞是由于注册命令在向父进程注册命令中处理大量的 WebAuthN 扩展时出现边界错误，成功利用此漏洞的攻击者通过创建恶意网页诱使用户访问，从而触发越界写入。

情报来源：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-13/

05 CVE-2022-28289-Mozilla Firefox 缓冲区溢出漏洞

威胁等级：高危

漏洞描述：

2022年4月5日，华云安思境安全团队发现 Firefox 官方发布安全更新，披露了 Mozilla Firefox 组件中存在一处缓冲区溢出漏洞。Firefox 是由 Mozilla 基金会与开源团体共同开发的网页浏览器。该漏洞是由于处理 HTML 内容时出现的缺陷，成功利用此漏洞的攻击者通过制作恶意网页诱使用户打开，从而使内存损坏，导致执行任意代码。

情报来源：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-13/

06 CVE-2022-22954-VMware 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年4月6日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware 组件中存在一处代码执行漏洞。Vmware 是一个“虚拟 PC ”软件公司，它的产品可以使你在一台机器上同时运行二个或更多Windows、DOS、LINUX系统。该漏洞是由于 VMware Workspace ONE Access and Identity Manager 中存在一个服务器端模板注入引起，成功利用此漏洞的攻击者在具有网络访问权限的情况下通过触发服务器端模板注入，从而执行远程代码。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2022-0011.html

07 CVE-2022-22955-CVE-2022-22956-VMware 身份验证绕过漏洞

威胁等级：超危

漏洞描述：

2022年4月6日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware 组件中存在一处身份验证绕过漏洞。Vmware 是一个“虚拟 PC ”软件公司，它的产品可以使你在一台机器上同时运行二个或更多Windows、DOS、LINUX系统。该漏洞是由于 VMware Workspace ONE Access 在 OAuth2 ACS 框架中暴露的端点引起，成功利用此漏洞的攻击者可绕过身份验证。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2022-0011.html

08CVE-2022-22957-CVE-2022-22958-VMware 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年4月6日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware 组件中存在一处代码执行漏洞。Vmware 是一个“虚拟 PC ”软件公司，它的产品可以使你在一台机器上同时运行二个或更多Windows、DOS、LINUX系统。该漏洞是由于 VMware Workspace ONE Access、Identity Manager 和 vRealize Automation 中存在缺陷引起，成功利用此漏洞的攻击者在具有管理访问权限的情况下通过注入恶意 JDBC URI，从而执行任意代码

情报来源：

https://www.vmware.com/security/advisories/VMSA-2022-0011.html﻿
