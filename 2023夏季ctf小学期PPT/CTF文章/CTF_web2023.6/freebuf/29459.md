403Bypasser - 一款绕过403目录限制的burp插件

一个用于绕过403目录限制的burp插件。通过使用被动扫描(默认开启),每一个403的请求都会被该插件自动扫描，因此来试试添加和享受它吧。

Payloads: $1: HOSTNAME $2: PATH


感谢 @lohubi提供如此多的payload

安装过程

1.下载插件

git clone https://github.com/sting8k/BurpSuite_403Bypasser.git

2.在burp安装


BurpSuite -> Extender -> Extensions -> Add -> Extension Type: Python -> Select file: 403bypasser.py -> Next till Finish
