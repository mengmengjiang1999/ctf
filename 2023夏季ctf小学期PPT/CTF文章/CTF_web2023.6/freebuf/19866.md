哪些IP SSL证书支持IP地址https加密呢？
2021-09-10 15:58:57

我们都知道SSL证书能为域名加密，那么IP地址可以实现https加密吗？答案当然是肯定的。为IP地址进行https加密不仅能保护IP服务器与客户端之间数据传输安全，还能对IP服务器进行身份验证，确保用户信息安全，增强用户对IP地址的信任度。那么，支持IP SSL证书类型有哪些，支持IP SSL证书品牌又是哪几个？

申请IP SSL证书的条件

  * 申请证书的IP必须是公网IP
  * 申请者需对IP地址拥有所有权
  * 可为单个IP或多个IP申请证书，但不支持IP地址通配。

支持IP SSL证书类型

支持IP地址加密的 SSL证书类型包括DV型IP SSL证书和OV型IP SSL证书，EV型证书不支持IP地址加密。DV型IP证书签发速度快，几分钟即可获得证书，OV型IP证书则需要1-3个工作日，待企业信息验证完成后即可签发。

目前支持IP 加密的SSL证书品牌还不多，下面小编将一一列出那些支持IP SSL证书品牌。

Digicert IP SSL证书

Digicert IP SSL证书仅支持OV组织验证型证书，但可以保护一个IP地址或多个IP地址。换言之，Digicert IP 地址证书有两种类型：一个是Digicert OV证书，另一个是Digicert OV多域名证书。Digicert优势在于品牌知名度高，得到很多大型机构、金融企业的信赖。

Globalsign IP SSL证书

Globalsign 也仅支持OV IP SSL证书，保护1个IP地址。Globalsign作为全球最受信的证书颁发机构之一，兼容性高，签发速度快，1-2个工作日即可获取证书，受到各大互联网公司的追捧，如阿里、百度、天猫等。

Sectigo IP SSL证书

Sectigo 支持OV型IP SSL证书，验证企业身份信息，可保护一个IP地址，支持5年订阅模式。与Digicert、Globalsign相比，Sectigo OV IP SSL证书价格便宜，性价比高，是全球销量最高的证书品牌。

锐安信sslTrus IP SSL证书

国产品牌锐安信 sslTrus IP SSL证书与其他品牌IP证书区别比较大。锐安信sslTrus不仅有DV型IP证书，并支持默认保护3个IP地址，最高可保护250个IP地址，申请时只需验证IP地址，签发速度快。此外，锐安信sslTrus还提供OV型IP SSL证书，此款支持保护1个IP地址。锐安信sslTrus IP SSL证书与其他国际知名品牌相比，不仅支持国内OCSP验签，而且价格便宜，证书类型丰富，对那些需要保护多个IP的企业来说是最好的选择。

PositiveSSL IP SSL证书

PositiveSSL乃是Sectigo旗下品牌，可信度高，销量好，PositiveSSL DV多域名证书默认保护3个IP地址，最高可保护250个，签发速度快，价格便宜，只需516元/年即可实现多个IP地址https加密。
