介绍：这篇文章主要记录了一次带防护的靶场通过的过程。

0x00 前言

真实环境中，不可能跟自己搭建靶场一样，没有任何防护。所以就有了这一次带防护的靶场渗透，这里只是简单的通关，后续问题准备再详细研究一下。

0x01 环境信息

首先一张网上的拓扑图，目标拿到DC主机的flag。

下载后的靶场需要添加两张网卡，win的网卡好配置，mac就有点费事。

具体不多添加内容，mac可以参考https://blog.csdn.net/longzhizhui926/article/details/82585652

web的访问需要将域名和ip绑定。

0x02 web服务器渗透

2.1 信息收集

访问http://www.moonlab.com/,是个空白页面。

这种空白页面，可能是目录不对,或者我们可以通过其他端口进行突破。
首先尝试目录扫描，dirsearch来一下。扫的过程我一看一路200就感觉坏事了。

果然被搞了。

被封了几分钟。
我们设置一下延时,然后发现扫描了几秒钟，又被封了。WTF？

我们直接开挂，康康咋又封俺？

emm，这就过分了。

后面换了dirb。

dirb http://www.moonlab.com/ -z 1000

最后，瞅瞅robots.txt去，发现了几个敏感目录。

在http://www.moonlab.com/siteserver/login.aspx发现了siteserver cms。

2.2 Getshell

百度siteserver 3.6.4漏洞，发现乌云有一个"siteserver3.6.4一行代码击垮所有安全防护"的文章，这个漏洞可以执行任意sql语句。

具体利用方式可参考
https://wooyun.x10sec.org/static/bugs/wooyun-2014-053099.html

执行select * from bairong_administrator;查询管理员密码。


发现admin的密码字段被加密了，我们通过select ...;的方式，更新一下PasswordFormat列的值为Clear。

select * from bairong_administrator;UPDATE bairong_administrator set PasswordFormat='Clear' where UserName='admin';select * from bairong_administrator;

然后修改Password的值为admin888。

select * from bairong_administrator;UPDATE bairong_administrator set Password='admin888' where UserName='admin';select * from bairong_administrator;

然后使用admin/admin888成功登陆系统。

后台拿shell。通过显示管理-模板管理，添加冰蝎的aspx马，成功拿到shell。

当我准备看一下进程的时候，就whoami一下，发现我又被封了。好像是频繁访问被封了。
过了一会，又可以登了，查看进程，通过https://i.hacking8.com/tiquan杀毒识别，发现安装了安全狗和微软自带的杀软。
