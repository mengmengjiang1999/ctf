华云安漏洞安全周报【94期】
2022-08-01 09:38:45

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.7.18~2022.7.24）CNNVD接报漏洞153个，信息技术产品漏洞（通用型漏洞）59个，网络信息系统漏洞（事件型漏洞）94个；CNNVD接报漏洞预警118份，其中华云安报送预警12份，预警报送数量持续位列第三！

本周重点关注漏洞包括：CVE-2022-33891-Apache Spark Shell命令注入漏洞、CVE-2022-2385-AWS IAM Authenticator for Kubernetes 验证绕过漏洞、Oracle WebLogic 7月多个安全漏洞、CVE-2022-25277-Drupal 代码执行漏洞、CVE-2022-23631-Superjson 远程代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-33891-Apache Spark Shell命令注入漏洞

威胁等级：高危

漏洞描述：

2022年7月19日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Spark Shell 组件中存在一处命令注入漏洞。Apache Spark 是一款支持非循环数据流和内存计算的大规模数据处理引擎。该漏洞是由于 Apache Spark UI 中的 ACL 功能输入验证不正确引起，成功利用此漏洞的攻击者在未授权的情况下，通过输入创建一个 Shell 命令，从而执行任意操作系统命令。

情报来源：

https://spark.apache.org/security.html

02 CVE-2022-2385-AWS IAM Authenticator for Kubernetes 验证绕过漏洞

威胁等级：高危

漏洞描述：

2022年7月19日，华云安思境安全团队发现 AWS IAM Authenticator for Kubernetes 组件被披露了存在一处验证绕过漏洞。AWS IAM Authenticator for Kubernetes 是适用于 Kubernetes 的 AWS IAM 身份验证器，它使用 AWS IAM 凭证对 Kubernetes 集群进行身份验证。该漏洞是由于 AccessKeyID 模板参数构造用户名并根据用户名提供不同级别的访问权限时容易导致验证绕过而触发，成功利用此漏洞的攻击者可实现在目标 Kubernetes 集群上提升权限。

情报来源：

https://vigilance.fr/vulnerability/KTextEditor-Kate-code-execution-via-QProcess-37476

03 Oracle WebLogic 7月多个安全漏洞

威胁等级：严重

漏洞描述：

2022年7月20日，华云安思境安全团队发现 Oracle 官方发布 Oracle WebLogic 7月份安全更新，此次安全更新共修复了18个安全漏洞，其中包含 11 个高危及以上漏洞的信息。WebLogic 是 Oracle 公司出品的一个 Application Server，用于开发、集成、部署和管理大型分布式Web 应用、网络应用和数据库应用的 Java 应用服务器，在全球范围内有广泛的使用。此次漏洞影响范围较广，华云安建议相关用户及时到 Oracle 官方下载安装对应的安全补丁进行更新！

情报来源：

https://www.oracle.com/security-alerts/cpujul2022.html

04 CVE-2022-25277-Drupal 代码执行漏洞

威胁等级：中危

漏洞描述：

2022年7月21日，华云安思境安全团队发现 Drupal 官方发布安全更新，披露了 Drupal 组件中存在一处代码执行漏洞。Drupal 是使用 PHP 语言编写的开源内容管理框架（CMF），它由内容管理系统（CMS）和 PHP 开发框架（Framework）共同构成。该漏洞是由于对带有 “htaccess” 扩展名的上传文件上的某些文件名进行了不正确的处理引起，成功利用此漏洞的远程攻击者可以在目标系统上执行任意代码攻击。

情报来源：

https://www.drupal.org/sa-core-2022-014

05 CVE-2022-23631-Superjson 远程代码执行漏洞

威胁等级：超危

漏洞描述：

2022年7月22日，华云安思境安全团队发现 Github 官方发布安全更新，披露了 Superjson 组件中存在一处远程代码执行漏洞。Superjson 是一个将 JavaScript 表达式安全地序列化为 Json 的超集。Superjson 存在代码注入漏洞，成功利用此漏洞的攻击者在不经过验证的情况下可以在任何服务器上使用 superjson 输入运行任意代码。

情报来源：

https://github.com/blitz-js/superjson/security/advisories/GHSA-5888-ffcr-r425
