# GSM改号原理及作用
GSM改号说白了就是把采集系统里面默认的回拨号码给成你自己的。
这样才可以实现采集回拨
# GSM改频点原理及作用
GSM采集改频，这个很多玩家都不知道。
这个就像GSM嗅探一样，你要想嗅探周边的短信，首先你需要输入周边的频点才能嗅探到对应频点的短信内容
那么采集也一样，采集可以设备3个频点或者多个频点。系统本身默认的频点和你当地频点不一致，当然无法采集到号码。

1. 安装ubuntu-18.04.1-desktop-amd64，系统（百度有很多教程）
链接：https://pan.baidu.com/s/1534mR3BzsdljljDtnngMew
提取码：l61a

首次打开终端，需要设置一个ROOT密码。

命令：sudo passwd （回车）

输入3次密码（最好和用户名的密码一样，方便）

每次操作都需要进入root模式。命令：su

然后更新系统:命令：apt-get update (更新大约15-30分钟左右，根据网速来。)

以下正式开始：

每次打开终端的操作都需要进入root模式。命令：su（回车）然后输入root密码.

1.安装两个软件

squashfs-tools（压缩软件） 和 hexedit（二进制文本编辑软件）

命令：apt-get install squashfs-tools

命令：apt-get install hexedit
