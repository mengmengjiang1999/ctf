Fastly CDN 中断，Amazon、GitHub、英国政府等网站集体脱机
2021-06-09 11:27:57

6月8日，由于全球互联网内容交付网络Fastly CDN出现中断故障，包括Reddit、Spotify、PayPal、GitHub、gov.uk、CNN和BBC在内的全球大量网站遭遇了一个多小时无法访问的“困境”。

Fastly：一家美国云计算服务商，其边缘运算平台为众多网站提供内容分发、网络安全、负载均衡等服务。

受影响的网站波及数十个国家和地区，包括但不限于以下站点：

Amazon

Amazon Web Services (AWS)

CNN

Debian.org repos (https://deb.debian.org/)

GOV.UK

GitHub

Heroku (https://dashboard.heroku.com/)

PyPI.org

Reddit

RubyGems.org

Shopify

StackOverflow

TechRadar

The Verge

TomsGuide

故障期间，这些网站在被访问时，会显示“连接失败”、“错误”或者HTTP 503代码。

此外，亚马逊和GitHub网站上可能托管于Fastly CDN的图像（或头像）、JavaScript文件、CSS则完全不能正常加载。

CDN中断疑云

当Fastly的服务状态显示其正经历全球CDN中断，这导致了北美、南美、欧洲、亚太、南非和印度的服务性能遭受影响。对于此次中断的原因也引发了诸多猜测。

虽然目前有一定猜测是黑客攻击所致，但根据最新消息。Fastly主动声明，此次中断原因为“服务配置”。一个服务配置问题在全球范围内引发了其POP的中断，并禁用了该配置。现在该问题已经修复，但是Fastly也表示客户可能会继续经历一段时间的源头负载增加。
