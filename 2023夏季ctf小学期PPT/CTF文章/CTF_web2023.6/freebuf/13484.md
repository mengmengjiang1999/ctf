Hive 勒索软件将其加密器移植到 Rust 编程语言
2022-03-29 15:26:32

Hive 勒索软件团伙将其加密器移植到 Rust 编程语言并实现了新功能。

Hive 勒索软件操作开发了他们的加密器的 Rust 版本并添加了新功能，以防止好奇窥探受害者的赎金谈判。

据专注于 Linux VMware ESXi 加密器的 BleepingComputer 称，Hive 勒索软件运营商通过引入过去由BlackCat/ALPHV勒索软件操作实施的功能来更新他们的加密器。

与其他勒索软件操作不同，BlackCat 勒索软件团伙从其加密器中删除了 Tor 协商 URL，以防止第三方访问协商页面并干扰受害者与团伙之间的通信。BlackCat 方法中的 URL 在执行加密器时作为命令行参数传递。

在以前的 Hive 勒索软件感染中，受害者被要求使用分配给他们的登录凭据连接到协商页面，这些凭据以前存储在加密器可执行文件中。这是为了存储凭证代表了谈判过程中的一个弱点。

Group-IB 安全研究员rivitna发现了 Hive Linux 加密器的 Rust 版本 v5， 他强调它的检测率是 0。研究人员还注意到，Hive 勒索软件操作已使用相同的源将构建（Windows、Linux、ESXi）移植到 Rust。
