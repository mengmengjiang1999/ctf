Western Digital解决了 My Cloud OS 5 中的严重漏洞
2022-03-29 16:05:09

Western Digital 修复了一个影响 My Cloud OS 5 设备的严重漏洞，该漏洞允许攻击者以 root 权限远程执行代码。

Western Digital 已解决了一个名为CVE-2021-44142的严重漏洞，该漏洞可能允许攻击者在未修补的 My Cloud OS 5 设备上以 root 权限远程执行代码。

CVE-2021-44142 漏洞影响以下设备：

The CVE-2021-44142 flaw affects the following devices:

  * My Cloud PR2100
  * My Cloud PR4100
  * My Cloud EX4100
  * My Cloud EX2 Ultra
  * My Cloud Mirror Gen 2
  * My Cloud DL2100
  * My Cloud DL4100
  * My Cloud EX2100
  * My Cloud
  * WD Cloud


CVE-2021-44142 漏洞是 Samba 越界堆读/写， 在 smbd 中打开文件时解析 EA 元数据时会影响vfs_fruit VFS 模块。这里的VFS 模块是 samba 套件的一部分，主要提供与 Apple SMB 客户端的增强兼容性以及与 Netatalk 3 AFP 文件服务器的互操作性。

根据此漏洞发布的公告里称，“在 smbd 中打开文件时，EA 元数据解析中存在特定缺陷。要利用此漏洞，需要以对文件的扩展属性具有写入权限的用户身份进行访问。如果允许此类用户对文件扩展属性进行写访问，那么这可能是访客或未经身份验证的用户。另外，vfs_fruit 中的问题存在于使用fruit:metadata=netatalk 或fruit:resource=file 的fruit VFS 模块的默认配置中。如果这两个选项都设置为与默认值不同的设置，则系统不会受到安全问题的影响。”

根据来自 DEVCORE 的安全研究员 Orange Tsai 报告，该漏洞影响 4.13.17 之前的所有 Samba 版本，攻击者无需用户交互即可触发此漏洞。

“在 smbd 中打开文件时，扩展属性 (EA) 元数据的解析中存在此特定缺陷。如果允许未经身份验证的用户对文件扩展属性进行写访问，则此漏洞可以被利用。” 阅读西部数据发布的公告。“通过从配置的 VFS 对象列表中删除“fruit”VFS 模块并更改 EA 支持配置来解决此漏洞。”

该漏洞由 Nguyen Hoang Thach ( @hi_im_d4rkn3ss ) 和 Billy Jheng Bing-Jhong ( @st424204 ) 与 Trend Micro 的零日倡议合作报告。

西部数据通过从配置的 VFS 对象列表中删除“fruit”VFS 模块并更改 EA 支持配置来解决此问题。该公司通过 2022 年 3 月 23 日发布的 My Cloud OS 5 固件 5.21.104 解决了该漏洞。
