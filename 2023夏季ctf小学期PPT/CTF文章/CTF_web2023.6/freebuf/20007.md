不一样的资产安全 3D 可视化平台
2021-09-01 12:07:41

只有做好资产的“看见”能力，才能更好地保障资产安全。在传统IT部署方式下，一次企业资产盘点可能需要花上十个小时，而时间是安全攻防对抗的生命线。 HT for Web 在充分研究分析了企业对资产安全管理业务需求的基础上，利用 HT 丰富的 2/3D 组态搭建出一个资产安全信息平台，让资产具备“看见”能力，能让用户清晰地看到资产情况，轻松应对资产安全管理问题，提升企业的智能化水平，为智慧企业建设创造良好的技术支撑。

数字经济时代，应用好数据是企业数字化转型的关键，基于前沿科学技术进行数据的有效管控，更是对数字增值服务的新趋势。近年来，整个安全行业对资产管理的重视程度正在提高。据IDC发布的相关数据显示，到2020年，50%的教育和大型企业将考虑使用VR/AR、大屏幕电子白板、智能手环等产品来提升企业的办公效率。随着越来越多的智能设备进入企业网络，企业资产管理的重要性也逐年增加。

我们采用 HT for Web 轻量化模型以及 web 组态，创建了2D面板和3D组态两个部分：

转盘

界面中间是一个非常酷炫的三层转盘，每一层代表的是不同组织架构内资产统计情况，同时中间的圆柱上还有二进制代码进行装饰，与围绕在转盘周围的科技环一起，为整个界面营造出前卫的科幻感。

数据面板

界面两侧的数据面板分为两部分，左边以告警信息为主，右边则以统计信息为主。以图表、圆盘、柱状图等多种方式对数据进行统计，可以让管理者对资产状态一目了然，便于管控工作。

1、资产管理体系

我们将平台进行多级组织架构分配，针对不同业务设置多个标签。包括设备、软件和各类IT组件等进行实时展示和统计分析，在不同资产对应组织和业务的资产状态进行数据关联分析和数据挖掘，全方位进行资产管理，使得资产安全管理更加贴合企业业务场景。

第一层：固定资产

第二层：隐形资产

2、智能告警与监测

内置通知告警系统，我们从左侧数据面板的“健康总览”可以看到系统发出的紧急信息、事件警告、故障修复以及故障数量的统计，下方则是对企业资产进行实时监测的情况，以及对平台告警信息的统计情况，管理人员可以及时在需要时对紧急事件及时处置，避免损失扩大。

3、基于组织架构的资产统计

平台可以根据企业的组织架构来进行资产的统计，界面右侧数据面板显示了企业资产总体概况，下方是根据不同部门反馈的和统计的公司资产的使用情况统计，以及根据流程类型的资产统计。

HT将先进的 3D UI 技术与企业安全需求进行融合，以 3D 可视化的方式解决企业全网信息资产安全管理问题。

1、智能预警

从企业资产发现、新型漏洞威胁通报检测到资产趋势跟踪记录，形成企业资产安全的闭环管理机制；

2、智能分析

可对历史数据进行分析对比展示，包括资产增加、变更、消失、废弃，资产的异常变化等，辅助管理者进行安全决策；

3、智能管理

结合组织架构与业务架构，实现各级组织分层级管理，深度探测企业资产信息，详细的绘制出企业资产安全分布图，加固企业资产安全管理的城墙，构筑企业资产安全管理的防线。

作为智慧企业的一部分，该项目深化大数据挖掘，将先进的信息技术、工业技术和管理技术深度融合，实现管理的数字化感知、网络化传输、大数据处理和智能化应用，从而使企业呈现出风险识别自动化、决策管理智能化、纠偏升级自主化的柔性组织形态和新型管理模式。

HT 提供的数字技术支撑，不仅可以解决数据呈现的问题，更是可以从不同角度启发管理者对数据价值的思考，进而进入数据分析及挖掘的下一步。同时，也能提供数据治理工具，解决企业数据共享的问题，帮助实现数据资产化运营。
