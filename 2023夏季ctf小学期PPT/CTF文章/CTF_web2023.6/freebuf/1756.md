Nginx 安全加固策略
2023-03-05 21:33:43

Nginx 作为用途广泛的web服务，在安全等保的时候，要求对其进行安全加固。加固的的时候，主要加固以下内容。加固操作主要是对 nginx的配置文件【nginx.conf】进行修改，需要先测试好配置文件，再进行替换生产上的配置文件。主要的加固策略如下：

一、日志配置

备份nginx.conf 配置文件，修改配置，按如下设置日志记录文件、记录内容、记录格式，添加标签为main的log_format格式：log_format main '$remote_addr - $remote_user [$time_local] "$request" ' '$status $body_bytes_sent "$http_referer" ' '"$http_user_agent" "$http_x_forwarded_for"';

定义日志路径access_log logs/host.access.log main

二、禁止目录浏览

备份nginx.conf配置文件,编辑配置文件，HTTP模块添加如下一行内容：

autoindex off;

三、隐藏版本信息

备份nginx.conf配置文件,编辑配置文件，添加http模块中如下一行内容：

server_tokens off;

四、限制HTTP请求方法

备份nginx.conf配置文件，编辑配置文件，添加如下内容：

if ($request_method !~ ^(GET|HEAD|POST)$ ) {

return 444;

}

五、限制IP访问

备份nginx.conf配置文件,编辑配置文件，在server标签内添加如下内容【加重的IP为示例IP】：

location / {

deny 192.168.1.1; #拒绝IP

allow 192.168.1.0/24; #允许IP

allow 10.1.1.0/16; #允许IP

deny all; #拒绝其他所有IP

}

六、更新版本

将nginx更新到最新版本。

查看版本的方法：nginx -v

备注:上述配置更改完成后，需要重启nginx。nginx的reload偶尔会不生效，尽量kill或者stop再启动。
