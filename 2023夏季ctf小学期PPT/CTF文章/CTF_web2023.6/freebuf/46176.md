2019中通SRC诚招各类安全人才
2019-02-01 12:00:49

中通快递是一家集快递、物流及其他业务于一体的大型集团公司，作为中国最大的快递公司之一，一直致力于营造安全、快捷的快递服务。2016年10月27日，中通快递成功登陆美国纽约证券交易所，创当年美国证券市场最大IPO，也是继阿里巴巴2014年赴美上市以来最大规模的中国企业赴美IPO。中通快递信息安全部以保障上亿客户以及合作伙伴的利益为前提，通过长期的信息安全管理建设，已经搭建起一整套的信息安全管理基础、制度与人才体系。

工作地点: 上海（上海虹桥万科中心或中通总部任选）

一、系统架构师 （25-50K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责公司和外部机构的数据对接以及对内提供接口服务，保障数据对接和接口服务的数据质量、性能、可用性和安全性；

2．完成核心模块和核心框架的架构设计，实现核心编码；

3．负责对系统代码Review提出改进优化建议；

4．帮助团队解决日常疑难问题。

岗位要求

1. 5年以上Java编码经验

2. 精通JAVA语言：熟练掌握数据结构，算法、多线程编程，高并发设计，掌握常用的设计模式，熟悉JVM、包括内存模型、类加载机制以及性能优化

3. 精通分布式（SOA、微服务）开发模式及相关开源组件原理

4. 深入分布式领域中间件原理，包括但不限于：Dubbo,SpringBoot, SpringCloud, 分布式调用链，自动化发布流程，ZK，ELK，分库分表，消息中间件（kafka），分布式缓存，监控，分布式调度

5. 有实际落地的大规模分布式系统的设计规划和架构经验，并确保高可用高并发及安全性

6. 有信息安全、电商、互联网等行业背景者优先考虑

二、高级JAVA开发工程师（20-40K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责：

1. 负责公司和外部机构的数据对接以及对内提供接口服务，保障数据对接和接口服务的数据质量、性能、可用性和安全性

2. 完成核心模块，搭建核心框架，实现核心编码， 落地部门架构师的架构设计

3. 负责对系统代码Review提出改进优化建议

4. 帮助团队解决日常疑难问题

岗位要求

1. 5年以上Java编码经验

2. 精通JAVA语言：熟练掌握数据结构，算法、多线程编程，高并发设计，掌握常用的设计模式，熟悉JVM、包括内存模型、类加载机制以及性能优化

3. 熟悉分布式（SOA、微服务）开发模式

4. 深入分布式领域中间件原理优先考虑，包括但不限于：Dubbo,SpringBoot, SpringCloud, 分布式调用链，自动化发布流程，ZK，ELK，分库分表，消息中间件（kafka），分布式缓存，监控，分布式调度

5. 有信息安全、电商、互联网等行业背景者优先考虑

三、安全研发工程师（15-30K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责研发和维护安全检测、监控或阻断系统、安全自动化工具等

2. 负责安全开源系统的选型、定制开发和维护推广

岗位要求

1. 熟练使用python、shell、java、go等至少一门语言

2. 对安全类产品的开源框架具有研究和应用的能力

3. 熟悉主流的攻击原理及防御方案, 有POC编写经验

4. 熟悉安全知识，具有信息安全、DevOps经验者加分

5. 在wooyun、freebuf等安全平台分享过相关技术文章加分

6. 在github上有开源安全产品加分，在互联网企业有安全产品开发经验加分

四、产品经理 （15-30K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责中通安全工具/产品的需求分析、原型设计，协助研发团队理解需求并推动产品上线

2. 负责安全工具/产品的规则、策略制定和维护，对各类指标持续优化、运营和监控

3. 定期对安全工具/产品的各类指标、运营情况以数据定量分析的方式进行回顾，提出优化建议

岗位要求

1. 统计、数学、计算机等相关专业，有1年以上安全产品规划/风控/数据挖掘/数据分析经验

2. 有项目管理经验，包括建立指标、汇报分析结论、制定模型或策略、推动方案落地

3. 具有良好的文档撰写能力、表达能力、协调能力、数据分析能力、洞察力和创造性的思维

4. 在互联网企业有安全产品经验加分，负责的安全产品占有一定比例市场份额的加分

五、信息安全工程师（运维方向）（10-20K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责安全运维方案设计、开发和实施，如网络访问控制、安全基线的落实和核查等

2. 参与公司安全运维流程推进及优化，安全合规项目的实施

3. 参与安全事件应急响应，跟进问题的处理和闭环

4. 参与安全自动化工具或平台的设计与开发

岗位要求

1. 熟悉python、shell、java、go等至少一门语言

2. 1年以上安全运维经验， 有安全工具开发能力，能够自动化运维与响应

3. 熟悉主流安全产品， 如防火墙、IPS、WAF、漏洞管理、防病毒、数据库审计、SOC、安全加固等

4. 熟悉ssh、niginx、OpenResty、redis、es、kafka、Hadoop、Storm、Spark等应用的安全配置

5. 在互联网企业有安全运维经验者加分；有实际安全攻击事件处理经验者加分

六、大数据安全研发专家 （20-40K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责中通集团安全流量与风控平台开发工作，包括不限于流量监测、实时风控系统、主被动扫描系统等

2. 负责基于身份、行为、威胁情报及其他海量日志数据，通过机器学习、数据挖掘、人工智能等技术构建威胁模型、风控算法等增强安全防控效率，对各种不良行为（异常帐号、异常请求等）的识别和防控，提升中通集团整体信息安全水平

岗位要求

1. 精通Java、python、go 等任一语言

2. 擅长使用开源框架，比如：elk、kafka、storm、spark等大数据处理框架，掌握实现原理。

3. 擅长使用机器学习框架TensorFlow，掌握其原理, 熟悉常见的机器学习算法：神经网络，SVM等

4. 熟悉回归分析模型、关联规则挖掘、分类和聚类算法、协同过滤算法等数据统计模型和挖掘算法

5. 熟悉用户行为模型，熟练掌握各种行为特征处理、特征选择和建模的方法

6. 有风控相关工作经历者加分， 有互联网高并发高可用相关经验者加分

七、安全渗透测试工程师 （15-30K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1.负责中通生产网和办公网的渗透测试

岗位要求

1. 精通各种渗透方法、各种黑客工具，有自己挖掘漏洞的成功案例和POC编写的能力；

2. 熟悉社会工程学，具备灵活的渗透思路和技巧；

3. 熟悉帽子圈和黑产手法，但能保持自己的职业操守，过往无不良记录；

4. 具备代码审计能力、有通用漏洞挖掘经验和大型网站实战渗透经验优先。

八、GO开发工程师 （15-30K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责前后端完全分离的后台Web API开发工作；

2. 负责基于海量数据，后台相关应用逻辑的处理或工具开发。

岗位要求

1. 本科及以上学历；

2. 掌握GO语言，熟悉常用package，熟悉计算机网络编程，熟练掌握Tcp编程，熟悉并熟练使用golang原生数据类型；

3. 1~2年工作经验，有完整的GO项目经验；

4. 熟悉各种中间件及开发框架、工具的使用（Kafka、Redis、ORM、 Git等）；

5. 具有良好的抽象设计能力，思路清晰，善于思考，能独立分析和解决问题,责任心强，具备良好的团队合作精神和承受压力的能力；

6. 学习能力强，能够无障碍阅读英文技术文档；

7. 对自己写的代码负责并精益求精，乐于在团队内分享。

九、前端开发工程师 （15K-30K）

部门: 信息安全部

工作类型: 全职

工作地点: 上海

岗位职责

1. 负责基于web的工作台和IM的开发工作

岗位要求

1. 本科及以上学历

2. 熟练掌握React, 1~2年工作经验，了解flux状态机的特性和优点

3. 熟悉redux, react-router, redux-saga以及webpack等相关技术, 熟练使用dva更佳

4. 熟练使用Ant-design或其他组件库，熟练掌握es6语法特性, 掌握js的异步流程控制

5. 具有良好的抽象设计能力，思路清晰，善于思考，能独立分析和解决问题,责任心强，具备良好的团队合作精神和承受压力的能力

6. 学习能力强，能够无障碍阅读英文技术文档

岗位信息：
