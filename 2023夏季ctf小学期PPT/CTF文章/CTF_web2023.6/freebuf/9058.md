华云安漏洞安全周报【第97期】
2022-08-18 16:00:52

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.8.8~2022.8.14）CNNVD接报漏洞129个，信息技术产品漏洞（通用型漏洞）72个，网络信息系统漏洞（事件型漏洞）57个；CNNVD接报漏洞预警98份，其中华云安报送预警8份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-36125- Apache Avro-rs 整数溢出漏洞、Microsoft 8月多个安全漏洞、CVE-2022-0028-Palo Alto Networks PAN-OS 拒绝服务漏洞、CVE-2022-27925-Zimbra 任意文件上传漏洞、CVE-2022-31672-VMware vRealize Operations 权限提升漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-36125- Apache Avro-rs 整数溢出漏洞

威胁等级：高危

漏洞描述：

2022年8月9日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Avro 中存在一处整数溢出漏洞。Apache Avro是一个数据序列化系统，为 Apache Hadoop 提供数据序列化和数据交换服务。该漏洞是由于系统读取损坏的.avro，成功利用此漏洞的攻击者通过系统读取损坏数据导致应用程序崩溃。

情报来源：

https://lists.apache.org/thread/t1r5xz0pvhm4tosqopjpj6dz8zlsht07

02Microsoft 8月多个安全漏洞

威胁等级：超危

漏洞描述：

2022年8月10日，华云安思境安全团队发现 Microsoft 官方发布8月份安全更新，共包括121个漏洞的补丁程序，主要涵盖了 Microsoft Office Outlook、Microsoft Office Excel、Active Directory Domain Services、Windows Kerberos、Windows Storage Spaces Direct、Windows Print Spooler Components、Windows Network File System、Windows Local Security Authority (LSA)、Windows Defender Credential Guard 等多个产品组件。在漏洞安全等级方面，有超危漏洞17个，高危漏洞103个，中危漏洞1个。在漏洞类型方面，有64个为提取漏洞，31个为远程代码执行漏洞，12个为信息泄露漏洞，7个为拒绝服务漏洞，6个为安全功能绕过漏洞，以及1个欺骗漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Aug

03 CVE-2022-0028-Palo Alto Networks PAN-OS 拒绝服务漏洞

威胁等级：高危

漏洞描述：

2022年8月11日，华云安思境安全团队发现 Palo Alto Networks 官方发布安全更新，披露了 Palo Alto Networks PAN-OS 组件中存在一处拒绝服务漏洞。Palo Alto Networks PAN-OS 是 Palo Alto Networks 的一款下一代防火墙软件。该漏洞是由于过滤策略配置错误引起，成功利用此漏洞的攻击者可执行拒绝服务攻击。

情报来源：

https://security.paloaltonetworks.com/CVE-2022-0028

04 CVE-2022-27925-Zimbra 任意文件上传漏洞

威胁等级：高危

漏洞描述：

2022年8月12日，华云安思境安全团队发现 Zimbra 官方发布安全更新，披露了 Zimbra Collaboration (ZCS) 中存在一处任意文件上传漏洞。Zimbra 是一个电子邮件和协作平台，Zimbra Collaboration（又称ZCS）8.8.15和9.0具有mboximport功能，可接收ZIP存档并从中提取文件。该漏洞是由于具有管理员权限的认证用户可以将任意文件上传到系统中，从而导致目录遍历或远程代码执行。

情报来源：

https://wiki.zimbra.com/wiki/Security_Center

05 CVE-2022-31672-VMware vRealize Operations 权限提升漏洞

威胁等级：高危

漏洞描述：

2022年8月13日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware vRealize Operations 中存在一处权限提升漏洞。VMware vRealize Operations 是一个面向私有云、混合云和多云环境的 IT 运维管理平台，该平台通过 AI/ML 和预测分析，提供持续的性能、容量和成本优化、智能修复和集成合规性。成功利用此漏洞的攻击者可以将普通权限提升至 root 权限。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2022-0022.html
