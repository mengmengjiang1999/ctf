安全漏洞-linux漏洞修复命令
2022-06-09 09:47:23

1、漏洞名称：软件:gnutls 3.3.26-9.el7
修复命令：yum update gnutls -y
cve编号：CVE-2018-10844,CVE-2018-10845,CVE-2018-10846

2、漏洞名称：软件:libsss_idmap 1.16.0-19.el7
修复命令：yum update libsss_idmap -y && yum update libsss_nss_idmap -y && yum update sssd-client -y
cve编号：CVE-2018-10852

3、漏洞名称：RHSA-2019:2029-重要: 内核 security,bug fix,和 enhancement update
修复命令：yum update kernel-tools -y && yum update kernel-headers -y && yum update kernel-tools-libs -y && yum update python-perf -y && yum update kernel-devel -y
cve编号：CVE-2018-10853,CVE-2018-13053,CVE-2018-13093,CVE-2018-13094,CVE-2018-13095,CVE-2018-14625,CVE-2018-14734,CVE-2018-15594,CVE-2018-16658,CVE-2018-16885,CVE-2018-18281,CVE-2018-7755,CVE-2018-8087,CVE-2018-9363,CVE-2018-9516,CVE-2018-9517,CVE-2019-11599,CVE-2019-11810,CVE-2019-11833,CVE-2019-3459,CVE-2019-3460,CVE-2019-3882,CVE-2019-3900,CVE-2019-5489,CVE-2019-7222

4、漏洞名称：软件:yum-plugin-fastestmirror 1.1.31-45.el7
修复命令：yum update yum-plugin-fastestmirror -y && yum update yum-utils -y
cve编号：CVE-2018-10897
