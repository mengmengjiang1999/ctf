笔记：Kali2021.1的Vulhub靶场搭建步骤
2021-08-12 22:34:15

docker安装

安装docker：参考博主的博客：https://blog.csdn.net/qq_41832837/article/details/103948314

docker-compose下载安装
我按照找到的博客步骤进行下载安装，于是遇到一下问题：

（1） 下载docker-compose: sudo curl -L

https://github.com/docker/compose/releases/download/1.23.0-rc3/docker-compose-uname -s-uname -m-o /usr/local/bin/docker-compose

慢的要死等了十几分钟卡在20%不动，于是又换了国内的源，几十秒结束。

安装docker-compose:

之后查看：docker-compose version
出错：
网上查要找到进程然后杀死，结果找不到。好吧，只能删了换种方法

（2） 用pip成功了

1：sudo apt-get install python3-pip
2:pip -V查看
3:sudo pip install docker-compose
4:docker-compose version 查看，终于成了

下载vulhub

下载链接：git clone https://github.com/vulhub/vulhub.git但太慢了，我是直接下载master分支的压缩包vulhub-master.zip，把压缩包直接放进kali，然后unzip vulhub-master.zip(解压)，然后cd vulhub-master,在目下ls查看:

启用环境
进入vulhub选择复现漏洞，如solr/CVE-2017-12629-XXE(进入solr/CVE-2017-12629-XXE
对靶场进行编译：docker-compose build
运行靶场：docker-compose up -d
速度巨慢，那么换源，
参考博客：https://blog.csdn.net/weinipangbai/article/details/108589571
源的镜像感觉这个更好用一点：https://nddt8zfh.mirror.aliyuncs.com
换完源之后可以了：
查看自己ip，浏览器登录http://ip:8983/
完成漏洞检测之后，移除环境：docker-compose down

以上就是我的安装搭建全过程。
