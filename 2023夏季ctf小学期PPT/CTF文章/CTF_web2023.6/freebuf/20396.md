Mariana Trench 项目 facebook旗下Android安全静态分析平台
2021-09-02 15:43:49

前言

目前Android安全分析平台的红利期已过大多数平台都已经收费使用或者无法使用。近期在Github翻看的时候看到了facebook再今年7月发布了一个新的平台Mariana Trench（马里亚纳海沟）。具体使用方法其实官方文档已经说明的很清楚了，实测也没什么坑，我这边就简单复述一下：

基础环境

Mariana Trench 需要用到Python3环境和Android SDK

python环境

MacOS可以通过homebrew直接安装：


$ brew install python3

Debian 风格的 Linux（Ubuntu、Mint、Debian）上，可以使用apt-get安装：


$ sudo apt-get install python3 python3-pip python3-venv

Android SDK

MacOS可以通过homebrew直接安装：


$ brew install android-sdk

Debian 风格的 Linux（Ubuntu、Mint、Debian）上，可以使用apt-get安装：

sudo apt-get install android-sdk

虚拟环境配置

虚拟环境配置实测可以省略：

$ python3 -m venv ~/.venvs/mariana-trench
$ source ~/.venvs/mariana-trench/bin/activate

安装及运行平台

使用pip安装：

$ pip install mariana-trench

克隆项目并进入到指定目录：

$ git clone https://github.com/facebook/mariana-trench 
$ cd mariana-trench/documentation/sample-app

运行：

$ mariana-trench \
  --system-jar-configuration-path=$ANDROID_SDK/platforms/android-30/android.jar
  --apk-path=sample-app-debug.apk \
  --source-root-directory=app/src/main/java

参数说明：

--system-jar-configuration-path：android.jar 不知道在哪的可以直接用find命令查找，如果找不到就是没有安装Android SDK

find / -name android.jar

--apk-path：要测试的app路径

--source-root-directory：可以不用改

生成报告

依然在mariana-trench/documentation/sample-app目录下执行：

$ sapp --tool=mariana-trench analyze .
$ sapp --database-name=sapp.db server --source-directory=app/src/main/java

然后访问本地5000端口就能看到报告：

http://localhost:5000/

点击右上角的Traces就可以跟踪问题出处。

看了一下问题大概分5种

Code1："User input flows into code execution sink (RCE)",
Code2："User input flows into file resolver",
Code3："User input flows into implicitly launched intent",
Code4："User input flows into raw SQL statement",
Code5："User input flows into WebView load"

后记

总体来说配置和使用都比较简单。作为一个新平台能查出来的问题比较少，但是都是一些比较危险的问题。在我看来该项目和目前很多平台比少了一些故弄玄虚，就像其介绍里写的一样更专注于安全本身。
