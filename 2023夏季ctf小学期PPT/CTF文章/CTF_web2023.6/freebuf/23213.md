Kali系统安装Parallels Tools工具（M1芯片适用）
2021-07-07 12:55:06

一、准备工作

系统版本： Kali 2021.2（ARM版）

软件版本： Parallels Desktop 16.5

首先执行 Parallels Desktop上的Parallels tools安装程序执行 进入该安装包目录下 执行

./install

此时运行会发现没有权限

创建一个文件夹，并将 parallels tools 安装包复制出来

mkdir /root/pt              #创建pt目录
cp /media/cdrom0/ /root/pt  #将安装复制到pt目录下
cd /root/pt/cdrom0目录下     #进入到安装包目录下
./install                   #执行安装程序

一直选择 next

最终会报如下错误，因为缺少以下三个依赖包。

二、下载依赖

第一个依赖包需要手动下载两个deb安装包

在 http://http.kali.org/kali/pool/main/l/linux/下载两个包（不同的内核版本下载的包名称不一样，需要根据自己的内核版本号下载对应版本的安装包。我的是linux-headers-5.10.0-kali3，而且是arm版。）

第一个：linux-headers-5.10.0-kali3-common_5.10.12-1kali1_all.deb

第二个：linux-headers-5.10.0-kali3-arm64_5.10.12-1kali1_arm64.deb

三、执行安装

手动安装第一个包

dpkg -i linux-headers-5.10.0-kali3-common_5.10.12-1kali1_all.deb

手动安装第二个包

dpkg -i linux-headers-5.10.0-kali3-arm64_5.10.12-1kali1_arm64.deb

如果报如下错误， 执行

apt-get -f install

安装第二个依赖

apt-get install dkms

安装第三个依赖

apt-get install libelf-dev

重新回到 /root/pt/cdrom0目录下

执行安装

./install

此时显示 安装成功

重启， parallels tools就可以用了

四、调整kali分辨率

点击设置管理按钮

找到 显示

可以根据自己的需求，调整kali分辨率的大小
