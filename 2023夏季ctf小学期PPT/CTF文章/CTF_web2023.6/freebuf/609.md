杀毒软件 ( AV)

杀毒软件又称为反恶意软件，主要用于监控、检测和防止恶意软件在主机内部执行。 大多数防病毒软件应用程序都使用众所周知的功能，包括后台扫描、全系统扫描、病毒定义。在后台扫描中，杀毒软件实时工作，在后台扫描所有打开和使用过的文件。首次安装防病毒软件时，完整的系统扫描是必不可少的。最有趣的部分是病毒定义，其中防病毒软件会回复预定义的病毒。这就是防病毒软件需要不时更新的原因。

防病毒软件使用多种检测技术，包括

  * 基于签名的检测
  * 基于启发式的检测
  * 基于行为的检测

基于签名的检测是防病毒软件中用于识别恶意文件的常用和传统技术之一。通常，研究人员或用户将他们受感染的文件提交到反病毒引擎平台，供AV供应商进一步分析，如果确认为恶意文件，则签名会在他们的数据库中注册。防病毒软件 将扫描的文件与已知签名的数据库进行比较，以确定客户端可能存在的攻击和恶意软件。如果我们匹配，则它认为是威胁。

基于启发式的检测使用机器学习来确定我们是否拥有恶意文件。它实时扫描和静态分析，以发现应用程序代码中的可疑属性或检查它是否使用不常见的 Windows 或系统 API。它在做出决定时不依赖基于签名的攻击，或者有时依赖。这取决于防病毒软件的实施。

最后， 基于行为的检测依赖于监视和检查应用程序的执行以发现异常行为和异常活动，例如在注册表项中创建/更新值、终止/创建进程等。

作为一名红队队员，了解有没有杀毒软件是必不可少的。它阻止我们做我们想做的事。我们可以使用 Windows 内置的工具来 枚举AV软件，例如 使用 WMIC 命令获取有关安装的防病毒产品的信息。

HIDS代表基于主机的入侵检测系统。它是能够监视和检测主机中异常和恶意活动的软件。HIDS的主要目的是检测可疑活动，而不是阻止它们。基于主机或网络的入侵检测系统有两种工作方式，包括：

  * 基于签名的IDS- 它查看校验和和消息身份验证。
  * 基于异常的IDS查找意外活动，包括异常的带宽使用、协议和端口。

基于主机的入侵防御系统 ( HIPS) 通过保护安装位置的操作系统活动来工作。它是针对众所周知的攻击和异常行为的检测和预防解决方案。HIPS能够审计主机的日志文件、监控进程和保护系统资源。HIPS 是最佳产品功能的组合，例如防病毒、行为分析、网络、应用程序防火墙等。

还有一个基于网络的 IDS/IPS，我们将在下一个任务中介绍。

端点检测和响应 ( EDR)



它也称为端点检测和威胁响应 (EDTR)。EDR是一种网络安全解决方案，可抵御恶意软件和其他威胁。EDR 可以查找恶意文件，监控端点、系统和网络事件，并将它们记录在数据库中以供进一步分析、检测和调查。EDR 是下一代防病毒软件，可实时检测主机上的恶意活动。

EDR分析系统数据和行为以制造部分威胁，包括

  * 恶意软件，包括病毒、木马、广告软件、键盘记录程序
  * 利用链
  * 勒索软件

以下是一些常见的端点EDR软件

  * 赛伦斯
  * 人群罢工
  * 赛门铁克
  * 哨兵一号
  * 好多其它的

即使攻击者成功传递了他们的有效负载并绕过EDR接收反向 shell，EDR 仍在运行并监控系统。如果它标记警报，它可能会阻止我们做其他事情。

我们可以使用脚本来枚举机器内的安全产品，例如 Invoke-EDRChecker和SharpEDRChecker 。他们通过 检查文件元数据、进程、加载到当前进程、服务和驱动程序、目录中的DLL来检查常用的防病毒、EDR、日志监控产品。


网络安全解决方案

网络安全解决方案可以是用于监视、检测和防止网络中恶意活动的软件或硬件设备。它侧重于保护连接到合作网络的客户端和设备。网络安全解决方案包括但不限于：

  * 网络防火墙
  * SIEM（安全信息和事件管理系统，用于将日志、警报、工件和事件形式的安全信息聚合到一个集中式平台中，该平台允许安全分析师在安全监控期间执行近乎实时的分析。）
  * 入侵检测系统/IPS

网络防火墙


防火墙是到达网络的不受信任流量的第一个检查点。防火墙在将不受信任的流量传递到基于规则和策略的网络之前对其进行过滤。此外，防火墙可用于将网络与外部流量源、内部流量源甚至特定应用程序分开。 如今，防火墙产品是内置网络路由器或其他提供各种安全功能的安全产品。以下是企业可能使用的一些防火墙类型。

  * 包过滤防火墙
  * 代理防火墙
  * NAT防火墙
  * 网络应用防火墙

安全信息和事件管理 ( SIEM)


SIEM结合了安全信息管理 (SIM) 和安全事件管理 (SEM) 来监控和分析事件并实时跟踪和记录数据。SIEM 帮助系统管理员和蓝队成员在对组织造成损害之前监控和跟踪潜在的安全威胁和漏洞。

SIEM解决方案用作日志数据聚合中心，它从传感器收集日志文件并对收集的数据执行功能以识别和检测安全威胁或攻击。以下是 SIEM 可能提供的一些功能：

  * 日志管理：实时捕获和收集整个企业网络的数据。
  * 事件分析：它应用高级分析来检测异常模式或行为， 在带有图表和统计数据的仪表板中可用。
  * 事件监控和安全警报：它监控整个网络，包括连接的用户、设备、应用程序等，一旦检测到攻击，它会立即提醒管理员采取适当的措施来缓解攻击。
  * 合规管理与报表：随时生成实时报表。

SIEM能够使用集成的威胁情报和 AI 技术检测高级和未知威胁，包括内部威胁、安全漏洞、网络钓鱼攻击、Web 攻击、DDoS 攻击、数据泄露等。

以下是很多企业中常见的一些SIEM产品：

  * 斯普伦克
  * LogRhythm NextGen SIEM平台
  * SolarWinds 安全事件管理器
  * Datadog安全监控
  * 好多其它的

入侵检测系统（手工）和入侵防御系统（规则）（NIDS/NIPS）

基于网络的IDS/IPS 与基于主机的 IDS/IPS 具有相似的概念。主要区别在于基于网络的产品侧重于网络而不是主机的安全性。基于网络的解决方案将基于分布在网络设备和主机中的传感器和代理来收集数据。IDS 和 IPS 都是检测和监控网络安全解决方案，企业用来保护其内部系统。他们都读取网络数据包，寻找异常行为和预加载到先前数据库中的已知威胁。两种解决方案之间的显着区别在于 IDS 需要人工交互或第 3 方软件来分析数据以采取行动。IPS 是一种控制系统，它根据策略和规则接受或拒绝数据包。

以下是常见的企业IDS/IPS产品

  * 帕洛阿尔托网络
  * 思科的下一代
  * McAfee 网络安全平台 (NSP)
  * 趋势科技引爆点
  * 苏里卡塔

  * 安装的应用程序
  * 服务和流程
  * 共享文件和打印机
  * 内部服务：DNS和本地 Web 应用程序

有必要了解系统提供的内容，以便从信息中获益。

安装的应用程序

首先，我们通过检查应用程序的名称和版本开始为已安装的应用程序枚举系统。作为红队队员，这些信息将使我们受益。我们可能会发现安装了易受攻击的软件来利用和提升我们的系统权限。此外，我们可能会发现一些信息（例如纯文本凭证）留在属于其他系统或服务的系统上。

我们将使用 wmic Windows 命令列出所有已安装的应用程序及其版本。

> wmic product get name,version

另一件有趣的事情是寻找特定的文本字符串、隐藏目录、备份文件。然后我们可以使用PowerShellcmdlet Get-ChildItem

> Get-ChildItem -Hidden -Path C:\Users\kkidd\Desktop\

服务与流程

Windows 服务使系统管理员能够在我们自己的 Windows 会话中创建长期运行的可执行应用程序。有时 Windows 服务具有错误配置的权限，这会提升当前用户的权限访问级别。因此，我们必须查看正在运行的服务并执行服务和进程侦察。有关详细信息，您可以阅读Attack MITRE上的进程发现。

流程发现是一个枚举步骤，用于了解系统提供的内容。红队应该获得有关在系统上运行服务和进程的信息和详细信息。我们需要尽可能多地了解我们的目标。此信息可以帮助我们了解网络中其他系统上运行的常见软件。 例如，受感染的系统可能有一个用于内部目的的自定义客户端应用程序。 自定义内部开发的软件是升级向量最常见的根本原因。 因此，值得深入挖掘以获取有关当前过程的详细信息。

有关从蓝队角度看的核心 Windows 进程的更多详细信息，请查看 TryHackMe 房间：核心 Windows 进程。

共享文件和打印机

共享文件和网络资源通常用于个人和企业环境。系统管理员错误配置访问权限，他们可能掌握有关其他帐户和系统的有用信息



内部服务：DNS、本地网络应用等

内部网络服务是另一种信息来源，可以扩展我们对其他系统和整个环境的了解。要获得有关用于外部和内部网络服务的网络服务的更多详细信息，我们建议尝试以下房间：Network Service、Network Service2。

以下是我们感兴趣的一些常用的内部服务：

  * 域名服务
  * 电邮服务
  * 网络文件共享
  * Web应用程序
  * 数据库服务

尝试使用 Windows 命令提示符 net start列出正在运行的服务 ，以检查是否有任何有趣的正在运行的服务



我们可以看到一个名为 THM Demo的服务，我们想了解更多。

现在让我们寻找确切的服务名称，我们需要找到更多信息。

wmic service where "name like 'THM Demo'" get Name,PathName



我们找到文件名及其路径；现在让我们使用 Get-Process cmdlet 查找更多详细信息。

Get-Process cmdlet是PowerShell中的一个命令，用于获取本地或远程计算机上的进程。如果没有参数，此命令将获取本地计算机上的所有进程。您还可以按进程名称或进程ID（PID）指定特定进程，或通过管道将进程对象传递到此命令。

一旦我们找到它的进程 ID，让我们通过列出系统中的监听端口来检查是否提供网络服务。

netstat -noa |findstr "LISTENING" |findstr "3212"
