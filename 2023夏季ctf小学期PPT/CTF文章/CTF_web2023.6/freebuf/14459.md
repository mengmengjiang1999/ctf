网络攻击的下一个主要浪潮：开源代码

开源软件现已成为技术创新的绝佳驱动力，但开源软件的普遍存在也带来了重大的安全风险。开源攻击方法对网络犯罪分子极具吸引力，因为它可以广泛且高效展开攻击。攻击者可以使用各种方法来混淆对开源项目做出的恶意更改，并且安全隐患的审查代码也会因项目而异。如果没有严格的控制措施来检测这些恶意更改代码，这些问题可能会被忽视，直至恶意更改后的代码被分发到众多公司，然后大规模曝发安全问题。开源代码仿佛也成为了网络攻击的下一个主要浪潮。然而，通过完全放弃开源避免开源攻击是不现实的，因为所有现代软件几乎都是由开源组件构建的。

与避免使用开源不同，更现实的方法是让安全和软件团队合作开发用于测试应用程序和软件组件的策略和流程及除了全行业努力保护基于开源代码构建的软件免受网络威胁外，组织还必须对其防御战略采取内部积极主动的方法，包括为自己开发的代码和所依赖的开源代码实施测试和控制程序，制定内部政策和指南，以识别使用开源软件的风险，并确定用于管理该风险的控制措施。这样做既可以使企业能够继续利用开源代码的优势，同时也可创建一个能够抵御未来攻击的环境。

Xenomorph 银行木马瞄准多个欧洲银行展开攻击

Tag：欧洲银行，Xenomorph，银行木马，谷歌商店

事件概述：

继谷歌商店曝出存在多个恶意应用程序后，谷歌商店近日又被曝出存在恶意软件 Xenomorph。该恶意软件是一种经典的银行木马，旨在通过感染 Android 智能手机访问 Accessibility 服务，然后在移动银行应用程序上显示虚假登录屏幕，收集设备数据信息，然后将收集到的信息回传到命令和控制 (C&C) 服务器。

目前，该应用程序已在谷歌商店下架。但在下架前，超过 50,000 台设备上的“Fast Cleaner”应用程序已被感染 Xenomorph 恶意软件。

技术详情：

Xenomorph 通过 Gymdrop 投放器投放到用户的设备上，作为恶意应用程序中的第二阶段有效载荷。这些恶意应用程序通常会通过 dropper 加载，设法通过谷歌商店安全检查，然后在设备中下载更强大、更具侵入性的恶意软件展开攻击。

加密货币交易平台 Coinbase 受漏洞影响，短时间内暂停服务

Tag： Coinbase ，漏洞

事件概述：

近日，安全研究人员发现加密货币交易平台 Coinbase 关键漏洞，立即向 Coinbase 报告后，Coinbase 于2月11日短暂停止了平台服务，并在数小时内修补了漏洞，恢复了正常运营。该漏洞是由于零售经纪 API 端点缺少逻辑验证检查，从而允许用户使用一个不匹配的源账户向特定的订单簿提交交易，导致恶意攻击者可以出售其他人员的加密货币。

技术详情：

用户通过向 BTC-USD 订单簿提交市价单出售加密货币，手动编辑 API 请求并将其他帐户指定为资金参考链接，验证服务检查指定账户是否有足够的资金来完成交易。但在此过程中，它不会检查源账户是否与提议的资产账户相匹配。攻击者可以此利用漏洞非法出售他人的加密货币。

思科电子邮件安全设备产品受到严重 DoS 漏洞的影响

Tag：思科，DoS漏洞，ESA

事件概述：

近日，思科发表公告称其电子邮件安全设备(ESA)受到漏洞 CVE-2022-2065 的影响。该漏洞是一个 DoS 漏洞，是由 DNS 名称解析中的错误处理不足导致的，目前该漏洞没有被恶意利用。攻击者可以无需身份验证即可远程利用该漏洞，通过发送由受影响的设备处理的特殊格式电子邮件信息来利用这个漏洞，导致电子邮件设备系统崩溃。思科还指出该漏洞只影响启用了 DANE 功能和配置为发送退回邮件的下游邮件服务器的设备，而思科电子邮件安全设备一般默认情况下不启用 DANE 功能。此外，思科还建议客户及时更新或打补丁，以防止潜在的漏洞利用。

开源监控平台 Zabbix 被曝严重漏洞，允许绕过身份验证并执行任意代码

Tag：Zabbix，监控，严重漏洞

事件概述：

Zabbix 是一个开源监控平台，主要跟踪整个基础架构中的 CPU 负载和网络流量等指标。近日，Zabbix 被曝存在两个严重漏洞，这两个漏洞允许攻击者绕过身份验证并在目标服务器上执行任意代码。漏洞相关信息如下：

  * CVE-2022-23131：是不安全的客户端会话存储漏洞，可以通过配置 SAML 的 Zabbix Frontend 绕过身份验证/实例接管。未经身份验证的攻击者可以利用此漏洞提升权限并获得对 Zabbix 前端管理员的访问权限。
  * CVE-2022-23134：允许 setup.php 文件的某些步骤不仅可以由超级管理员访问，也可以由未经身份验证的用户访问。攻击者可以通过步骤检查更改 Zabbix 前端的配置。
  * 最后，研究人员建议将所有运行Zabbix 的版本升级到 6.0.0beta2、5.4.9、5.0.19 或 4.0.37。

俄罗斯威胁组织 Sandworm 使用 Cyclops Blink 框架展开大规模攻击

Tag：Sandworm，APT，俄罗斯，Cyclops Blink

事件概述：

美国和英国网络安全和执法机构于2月23日发布告警信息，称与俄罗斯情报机构有关联的威胁组织 Sandworm 利用恶意软件框架 Cyclops Blink 替换 VPNFilter ，并将 Cyclops Blink 部署到家庭办公室和小型网络防火墙硬件制造商 WatchGuard 的 Firebox 设备。该恶意软件通过虚假固件更新进入设备，并且即使在具有真实固件更新后仍可以在机器上持续存在，以 VPNFilter 相似的方式运行，并通过自定义僵尸网络传播。VPNFilter 曾被 Sandworm 组织用于2015年袭击乌克兰事件和2018年奥运会攻击事件。在2018年被思科研究人员曝光 VPNFilter 后，Sandworm 组织转向使用 Cyclops Blink 替换被披露的 VPNFilter。

参考链接：https://www.ncsc.gov.uk/files/Cyclops-Blink-Malware-Analysis-Report.pdf

微步点评：

1、Sandworm，也称为 Telebots，是影响工业控制系统的最危险的俄罗斯威胁参与者之一。该组织隶属于俄罗斯的主要情报局 (GRU)，对数以千计的美国和国际公司、组织、政治运动和政府进行了多次攻击。

2、Sandworm目标行业：教育、能源、政府和电信。

TunnelVision 组织利用 Log4j 漏洞部署勒索软件展开攻击

Tag：TunnelVision，Log4j，勒索软件

事件概述：

TunnelVision 组织是一个与伊朗政府结盟的威胁组织，主要活跃于美国和中东等地区。由于该威胁组织严重依赖隧道工具，以及它选择广泛部署这些工具的独特方式，SentinelLabs 将该组织活动命名为 TunnelVision。TunnelVision 组织正在广泛利用 1day 漏洞、Fortinet FortiOS (CVE-2018-13379)、Microsoft Exchange (ProxyShell) 和Log4j2 漏洞来获得对目标网络的初始访问权限以进行后期利用，运行恶意 PowerShell 命令、部署后门、创建后门用户、获取凭据并执行横向移动，用勒索软件感染未修补的 VMware Horizon 服务器。

组织关联：

  * TunnelVision 战术与Phosphorus、 Charming Kitten 和 Nemesis Kitten 战术广泛重叠。

参考链接：https://www.sentinelone.com/labs/log4j2-in-the-wild-iranian-aligned-threat-actor-tunnelvision-actively-exploiting-vmware-horizon/

UpdraftPlus 插件漏洞暴露了数百万个 WordPress 站点备份文件

Tag：WordPress，漏洞

事件概述：

UpdraftPlus 是 WordPress 的一个插件，主要为站点管理员提供备份和恢复功能。目前，该插件安装量超过三百万次。近日，UpdraftPlus 插件被曝存在一个高严重的漏洞 CVE-2022-0633。该漏洞可以导致攻击者通过恶意请求检索有关最新站点备份的信息，由于该插件没有正确验证用户角色，即使是网站上具有最低权限的帐户也可以下载备份并获得对网站数据库的访问权限。但 WordPress 指出如果攻击者要想成功利用该漏洞，攻击者需要在目标系统上拥有一个活动帐户，并且还需要通过电子邮件接收 URL 的请求。

截至目前，WordPress 官方表示还没有公开可用的针对该漏洞的概念验证漏洞利用代码（PoC），但由于漏洞的严重性，UpdraftPlus 1.22.3 强制自动更新版本已被推送，目前大多数插件已更新为修补版本。

参考链接：https://www.securityweek.com/vulnerability-updraftplus-plugin-exposed-millions-wordpress-site-backups
