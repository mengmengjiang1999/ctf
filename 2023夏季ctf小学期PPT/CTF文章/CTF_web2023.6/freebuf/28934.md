公司介绍

上海安般信息科技有限公司以当代智能模糊测试技术和程序分析技术为核心、以软件全流程负面测试为研发方向，技术原型最早发表在多个国际顶级会议，当前产品包括源代码智能模糊测试系统、固件智能模糊测试系统、协议智能模糊测试系统、API智能模糊测试系统、软件供应链管理系统等。安般科技以提高国内信息化产品质量为主要使命，在北京、西安、成都等一、二线城市设有分支机构，拥有覆盖全国的合作伙伴网络，并和四川大学等多家高校成立负面测试相关联合实验室，持续保持技术的先进性。

安般科技作为软件负面测试行业的领跑者，已与中国信息安全测评中心、国家保密局、国家安全部、中国科学院、中国工程物理研究院等业内权威机构达成合作，并多次承担科技部重大研发专项任务。产品广泛应用于国防军工、金融、信创、智能网联汽车、工业控制等关键领域，为全国上百家客户提供软件负面测试服务和解决方案，帮助用户大幅缩短开发周期，显著降低开发成本，提高软件的开发效率，最终优化整体软件质量并提升用户体验。


安般科技，期待你的加入！

岗位信息

以下岗位JD规定的是目前符合岗位胜任的最低需求，以下方向的资深从业者，对我们兴趣，也是非常欢迎大家投递简历，薪资open，也欢迎带着简历加WeChat：anban_tech咨询

Java开发工程师

岗位职责：

1.理解并掌握所负责的项目的业务模型、产品模型、技术模型，和团队一起持续创新产品功能;
2.参与产品需求分析讨论、制定技术方案并落地实施，确保项目的进度和质量；

3. 深入理解底层技术，持续提升核心系统的高性能、高可用，保证系统的安全、稳定、快速。

岗位要求：

1.JAVA基础扎实，理解io、多线程、锁、集合，了解或深入过源码实现，对JVM原理有一定的了解；
2.3-7年及以上使用JAVA开发的经验，了解常用框架的原理和机制；对Spring、mybatis、springBoot等开源框架熟练掌握并理解其原理；
3.熟悉分布式系统的设计和应用，熟悉分布式、缓存、消息等机制；能对分布式常用技术进行合理应用，解决问题；
4.可以独立设计表结构对sql优化有丰富的经验，理解mysql 索引、锁等；熟悉NoSQL解决方案及其优缺点
5.熟练使用Docker，对Docker原理有一定的理解，熟悉linux常归操作；
6.喜欢去看及尝试新技术，追求编写优雅的代码；
7.有开源项目、参与开源项目、技术博客、有重构经验等为加分项


Python开发工程师

岗位职责

1、根据开发计划,设计软件模块,完成软件模块源代码编写,实现开发需求规定的功能;
2、根据开发需求,完成开发文档,提岀模块设计的规划；根据开发文档,制定详细的开发计划；按要求完成其他相关工作。

岗位要求

1、3-5年python工作经验
2、精通python语言,熟悉Flask/Django等web框架
3、熟悉常用算法和数据结构，精通socket编程，熟悉网络协议(TCP/IP, HTTP等)
4、熟练使用git等代码管理工具
5、了解docker，K8S
6、有良好的代码编写习惯，有强烈的责任心及良好的团队合作精神

前端开发

岗位职责：

1、负责公司前端业务开发，解决软件开发过程中遇到的技术问题；
2、协助团队完成相关的测试、部署、上线工作;
3、优化代码并保持良好的浏览器兼容性（Chrome，Firefox）；

岗位要求：

1、全日制本科以上学历，具备英语读写能力；
2、精通 JS (ES2015+), CSS (Stylus、Sass、Less至少了解一种)，熟悉 Typescript 的优先；
3、精通 Vue 或 React，能熟练使用 webpack 构建工具；
4、熟练使用 Git/GitHub，了解通信协议 TCP / HTTP 及 RESTful 标准；
5、良好的编码能力和习惯，能书写适当的注释、文档，代码易于维护和扩展；
6、对前端有浓厚兴趣，有较强的主动学习能力和团队合作能力，热爱新技术，有开源项目的优先

销售总监

岗位职责

1、负责军工、汽车、工控、金融等行业产品销售；
2、 跟踪和维护公司已有客户，负责公司产品所属行业市场推广。
3、 制定自身销售计划，负责销售策划和执行，达成销售目标；
4、定期整理、归纳并更新所负责行业和客户的市场信息。
5、开拓新市场，发展新客户，增加产品销售范围；
6、规划所属行业销售计划，制定行业内市场推广计划，制定行业覆盖战略。

岗位要求

1、计算机、通信相关专业毕业，有软硬件开发经验优先；
2、有丰富的军工或汽车行业软件销售经验和一定行业资源。
3、市场感觉敏锐，具备较的客户沟通能力
4、有3年以上团队建设和管理经验。
5、强烈的责任感，良好的心理素质，能短期出差。

项目经理

岗位职责

1.按照客户要求完成技术方案咨询、规划、设计；
2.制定技术方案咨询项目计划和实施部署，项目进度、质量及范围管理和控制；
3.跟踪安全行业技术与应用发展趋势，把握产品发展方向，保证产品规划前瞻性，挖掘客户的潜在需求与业务痛点，提出有针对性的观点和建议方案；
4.与开发、测试和其他团队协作推动产品策略的制定、实施并对产品生命周期进行管理，形成完整的设计产品方案及相关功能模块；
5.整理业务相关方需求，并对竞争对手进行深入分析,不断优化产品；
6.结合行业动态和客户痛点，为公司探索新的业务方向；

岗位要求：

1. 计算机，软件工程等专业或相关专业；
2. 具有1年及以上相关工作经验，2年同类型业务工作经验者优先；
3. 对安全行业有一定的了解，熟悉行业相关业务知识者优先；
4. 热爱软件行业，有创业激情和学习精神，积极主动推进工作、不断学习提升自我。


C++实习生

岗位职责：

1、根据开发进度和任务分配，完成相应模块软件的设计、开发、编程任务；
2、协助项目工程管理人保证项目的质量；
3、负责项目工程设备运行中主要功能的代码实现。

岗位要求:

1.计算机相关专业，本科及以上学历
2.有C/C++等语言的编程基础
3.熟悉SQL SERVER数据库
4.实习表现优秀者可提供转正

高级产品经理

岗位职责

1.跟踪安全行业技术与应用发展趋势，把握产品发展方向，保证产品规划前瞻性；
2.与开发、测试和其他团队协作推动产品策略的制定、实施并对产品生命周期进行管理；
3.整理业务相关方需求，并对竞争对手进行深入分析,不断优化产品；
4.负责产品的版本规划和产品设计；

岗位要求

1.全日制统招本科及以上学历，5年以上B端产品工作经验及2年以上Java或C++开发经验，能够独立完成产品生命周期，熟悉软件测试类产品整体实现过程，会使用常规的测试类工具；
2.深刻理解软件测试行业/安全行业的商业模式和产业生态；
3.熟练使用Figma等原型设计工具，熟练使用PPT，Word，Excel等办公软件；
4.思路清晰，较强的表达能力，良好的跨部门沟通和项目协调能力，善于协调资源推动项目进展；
5.具备良好的团队合作意识及跨团队协作能力，可独立推进解决问题，能承担一定的工作压力；
