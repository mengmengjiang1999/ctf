Plex Media Server for Windows漏洞可导致系统被完全控制
2020-06-18 15:46:08

Plex已经修复影响Plex Media Server for Windows的三个漏洞，并缓解了漏洞的影响。攻击者可以结合利用这些漏洞完全控制底层系统。

Plex Media Server是一个桌面应用程序，也是Plex媒体流媒体服务的后端服务器，设计用于通过互联网和局域网进行流媒体电影、电视节目、音乐和照片收集。

这三个漏洞编号为CVE-2020-5740，CVE-2020-5741和CVE-2020-5742，是由Tenable公司的安全研究人员Chris Lyne发现，并报告给Plex的。

如果攻击者组合利用所有这些安全漏洞，他们可以以SYSTEM权限远程执行代码，完全接管操作系统，获取所有文件的访问权限，部署后门，或横向移动至同一网络上的其他设备。

Plex安全团队于4月24日发布CVE-2020-5740的补丁，于5月7日发布CVE-2020-5741的补丁，并通过服务器端修改缓解CVE-2020-5742的影响。

钓鱼攻击导致系统接管

根据Lyne描述的PoC攻击，想要控制运行未修复的Plex Media Server的计算机的攻击者必须借助伪装成电子邮件通知、设计用于将目标Plex管理用户重定向至攻击者控制的Plex Media Server的钓鱼电子邮件。

如果用户上当受骗并登录恶意服务器，“攻击者可以通过滥用CVE-2020-5742弱跨源资源共享（CORS）策略漏洞伪造对受害者的媒体服务器的请求，从而窃取用户的X-Plex-Token。

即使攻击在这里停止，恶意攻击者仍然可以访问受害者的私有媒体，并获得更改服务器设置、重新启动媒体服务器服务等能力。

“截至2020年6月15日，Plex已经在身份认证页面服务器端部署了一种缓解措施，以通知用户是否正在登录到非Plex托管的应用程序。”Tenable解释道。

下一步，攻击者必须使用窃取的管理员身份认证令牌，通过利用Plex Media Server插件框架中的CVE-2020-5741漏洞，以该媒体服务器的权限远程执行任意Python代码。

借此，攻击者能够在遭受入侵的系统上安装后门，并移动到该服务器所在的局域网上的其他设备。

接下来，攻击者必须利用CVE-2020-5740漏洞将其在Windows系统上的权限提升到SYSTEM，实际上完全接管底层系统并获取对所有文件的访问权限。

“在成功实施网络钓鱼攻击之后，攻击者可借助所获得的X-Plex-Token，利用CVE-2020-5741漏洞以该媒体服务器进程的权限执行代码。”Lyne解释道。

“然后，通过利用Plex Update Service中的CVE-2020-5740，攻击者可以将访问级别提升到SYSTEM。至此，该媒体服务器将完全遭受入侵。”

更新最新版本，缓解漏洞影响

为了确保服务器免遭利用这些漏洞的攻击，建议用户尽快更新至最新版本。

Plex安全团队说道，“我们已经对我们的更新分发服务器进行了修改。 该修改将保护PlexMedia Server 1.18.2或更新版本。1.18.2之前版本的Plex Media Server仍然存在漏洞，我们高度鼓励使用老版本的用户升级。”

“此外，Plex Media Server 1.19.1.2701版本和1.19.2.2702版本（和更新的版本）额外加固了更新器，以防止未来的漏洞。我们建议所有用户更新到其中一个版本。”

Plex还在身份认证页面服务器端启用自动警报，在Plex用户登录到非Plex托管的媒体服务器时通知用户，缓解CVE-2020-5742的影响。

CVE-2020-5742 服务器端缓解措施

“Plex Media Server默认情况下不会自动更新，但是用户可以在他们的设置中启用自动更新，”Tenable也解释道。“用户可以随时查看通用设置页面，查看是否有新的更新。”
