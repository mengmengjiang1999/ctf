像搭“乐高”一样实现整合式网络安全体系
2022-01-21 10:06:28

部署多种防护产品，却无法形成防御合力，是当前很多企业网络安全建设都面临的挑战。网络安全能力整合是企业的刚需，也是行业发展的大势所趋。虽然Gartner 提出的网络安全网格架构（CSMA，Cybersecurity Mesh Architecture )印证了这种趋势，但如何实现网络安全能力的整合则是广大企业当下最紧迫的任务。

“乐高”化思维“解困”网络安全整合

企业安全能力的整合不是一蹴而就，更不能推倒重来。企业需要在先进、完善网络安全框架指导下，借助能够协同调度的接口，在对企业多年来部署的安全防护产品“利旧”的同时，合理规划增补新的安全产品和模块，实现全面覆盖、深度集成、动态协同的“网络安全网格平台”打造。

乐高积木作为世界上最为流行的玩具之一，受到不同年龄段人群的喜爱。其每个组件本身形态各异、功能不一。通过将它颜色各异、类型不同的模块，通过标准化的接口实现相互兼容、耦合，再结合独特的框架设计，就能发生奇妙的“化学”反应。

这与企业网络安全建设不谋而合。不同类型的模块、标准化的接口加上独特的框架设计，成为乐高积木风靡全球的三大关键核心。模块类型缺乏会造成能力受限，没有标准化的接口将导致难以集成，缺少独特的框架设计则失去了灵魂。这三点同样是整合式企业网络安全建设的关键支撑，三位一体缺一不可。

Fortinet 像搭 “乐高”一样整合网络安全体系

Fortinet Security Fabric安全架构作为一个全面覆盖、深度集成和动态协同的 “网络安全网格平台”，提供集中管理和可见性，支持在一个庞大的解决方案生态系统中协同运行，自动适应网络中的动态变化。在为企业客户带来一种集成的安全方案，打造整合安全体系，推动企业数字化转型上有着“乐高”式的优势。

首先是模块叠加能力。Fortinet Security Fabric 安全架构提供符合数字化转型时代安全防护要求同时模块化的基础能力集，并以此为基础可以灵活快速的叠加自研、第三方的安全模块，形成1+1＞2的防御合力。

第二是标准接口。Fortinet Fabric-ready安全生态将领域中的基础架构、运维管理、IT应用、云平台等关键模块通过标准化的接口有机集成。通过Fabric将威胁情报、AI驱动防护等诸多能力为不同功能、类型、形态甚至品牌的模块进行赋能。

第三是框架设计。Fortinet Security Fabric安全架构作为业界最为成熟、集成度最高和自动化的安全基础框架。通过提供集中管理和可见性，实现共享的安全上下文以及端到端自动化，适应来自不断变化网络环境的安全挑战。

通过Fortinet Security Fabric“乐高化”的建设思路，覆盖的丰富组件（每一个组件都是完成安全框架的关键模块），标准化的接口（提供相互耦合的能力），统一的设计框架（业界领先且可落地的安全防护理念），帮助用户实现安全有效、简单有效且高度内聚的新一代安全防护体系。
