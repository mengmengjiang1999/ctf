WordPress Rank Math插件存在超危漏洞，黑客可获取管理员权限
2020-04-01 13:17:04

WordPressSEO插件——Rank Math插件存在一个严重提权漏洞，已注册的用户可利用该漏洞获取管理员权限。

Defiant公司的Wordfence威胁情报团队在WordPress SEO插件——Rank Math插件中发现一个严重的提权漏洞，攻击者可利用该漏洞将管理员权限赋予任意注册用户。该漏洞暂未取得CVE编号，但CVSSv3.0评分为10。

Rank Math是个WordPress插件，通过搜索引擎优化（SEO）帮助网站所有者吸引更多的流量至网站。

当前有20多万个网站安装了该WordPress插件。

Rank Math使用一个设置向导自我配置，该向导为WordPress设置SEO。

该设置向导功能支持Google Schema Markup（又称RichSnippets），关键词优化，Google Search Console集成，和Google关键词排名跟踪等。

该漏洞存在于一个未受保护的REST-API端点，未经身份认证的攻击者可利用该漏洞更新任意元数据，从而赋予任意注册用户管理员权限。

攻击者还可利用该漏洞撤销管理员的管理权限，并在网站上封锁他们。

攻击者可以通过将meta[wp_user_level]参数和meta[wp_capabilities]参数设置成空值，向wp-json/rankmath/v1/updateMeta发送一个$_POST请求利用该漏洞撤销现有管理员的权限。注意这些攻击只是最坏的可能。

安全专家还在该插件中发现了另一个安全漏洞，未经身份认证的攻击者可利用该漏洞从网站上的几乎任意位置创建重定向至恶意站点。

该漏洞存在于一个可选插件模块中，该模块帮助用户在他们的WordPress网站上创建重定向。

Wordfence表示，要执行该攻击，未经身份认证的攻击者可通过将redirectionUrl参数设置成他们想要该重定向前往的位置，将redirectionSources参数设置成重定向来源位置，和将hasRedirect参数设置成true，向rankmath/v1/updateRedirection发送一个$_POST请求利用该漏洞将访客重定向至恶意网站。通过将访客重定向至恶意网站，该攻击可被用于阻止访客访问网站现有的所有内容，除了主页之外。

根据Wordfence发布的信息，Rank Math 1.0.40.2及之前版本受到这两个漏洞的影响，不过该插件的开发团队已在Rank Math 1.0.41.2版本中修复了漏洞。

利用WordPress插件中的漏洞执行的攻击数量不断上升。

数周前NinTechNet公司的研究人员报告了一起正在进行的攻击活动，该攻击利用WordPress Flexible Checkout Fields for WooCommerce插件中的一个0-day漏洞。其他最近观察到的攻击如下：

2020/01 - InfiniteWP插件中的一个身份认证绕过漏洞，影响超过30万网站。

2020/01 - CodeSnippets插件中的一个高危跨站请求伪造漏洞致超过20万个WordPress网站暴露在攻击风险之中。

2020/02 - WordPress ThemeGrill Demo Importer主题插件中发现一个严重漏洞，该漏洞可被用于擦除网站数据并获取对网站的管理员访问权限。20多万个网站安装了该插件。

2020/02 - GDPR Cookie Consent插件中的一个存储型跨站脚本漏洞，影响70万用户。

2020/02 - 黑客利用ThemeREX Addons插件中的一个0-day漏洞创建具有管理员权限的用户账户。

2020/03 – WordPress ThemeREX Addons插件受到一个超危漏洞的影响，远程攻击者可利用该漏洞执行任意代码。

2020/03 – WordPress Popup Builder插件中的漏洞允许未经身份认证的攻击者将恶意JavaScript代码注入网站弹窗，影响超过10万个网站。
