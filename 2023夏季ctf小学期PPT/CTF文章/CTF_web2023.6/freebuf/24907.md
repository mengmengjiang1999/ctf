在远程虚拟服务器上搭建你的Kali渗透环境
2021-05-24 00:28:41

Virtual Private Server是什么

（Virtual Private Server 虚拟专用服务器）可以理解成就是一台虚拟的服务器，它与服务器一样，有独立的IP、内存、带宽等，可以安装各种操作系统以及运行各种软件。应用也比较广泛主要是做网站、运行OA、运行系统软件等。说穿了，就是一种虚拟服务器，一台远程的、具有公网IP的虚拟服务器。

为什么要用Virtual Private Server

在真实渗透环境下往往需要一个稳定（24小时开机运行）、安全（非本人IP）、可随时操作的环境（纯净、可随时更换），常用电脑不能一直开着，而且还有解决公网IP的问题，这时候我们往往需要一台Virtual Private Server。
但是国内的稍贵，而且不能自定义ISO镜像。所以很多购买之后需要一步一步配置自己需要的渗透环境。
那么今天我就介绍一款国外很好用的Virtual Private Server，并且自定义并且快速安装kali linux。

怎么在Virtual Private Server搭建自己的渗透环境

首先是选购

提供服务的厂商有很多，不建议大家在这里多折腾，只以常用的vultr为例展开，这家服务商综合评分还不错。

Vultr介绍与收费

这是一家美国的服务商，全球有十来个服务节点，我们一般应选择ping值比较低的节点，一般来说，亚洲和硅谷的比较低。

Vultr的收费策略是折算成小时计费的，举个例子，如果选择的服务器是5美元1个月，那么每小时收费为5/30/24=0.0069美元，会自动从账号中扣费，只要保证账号有余额即可，不使用机器的时候，destroy掉机器就不再计费了，需要用的时候恢复快照重新deploy即可。

支付方式：支持支付宝和VISA卡

开始创建你的第一台Virtual Private Server

购买网址：https://www.vultr.com/

创建一个账户，注册邮箱然后充值。

创建账户完成之后，登录账户；可以跳转到购买服务器的页面

对于购买服务器的地址，建议购买自己测试ping值低的（减小网络延迟）

自定义ISO ，点击Upload ISO 上传Kali linux URL

点击upload 它将会下载最新版本的kali到这个镜像库里。

上传成功后会出现对应的ISO文件，选中即可；

选择需要购买服务器的类型，根据自己的需要购买，一般来说，5刀每月的就够了。
接下来输入服务器名和标签 kali

最后点击 Deplay Now 购买即可；

安装Kali


来这个页面点击view cosole 进去远程页面安装系统

这里点击Graphical install 进入界面后选择中文简体或者你喜欢的英文。接下来与我们安装的kali操作并没什么区别。密码设置复杂一些，因为我们要开开启ssh服务，防止被人爆出密码。



开启配置ssh
设置ssh自启动
update-rc.d ssh enable //系统自动启动SSH服务
启动ssh
/etc/init.d/ssh start

至此，kali安装成功了，接下来，你需要在你的主机配置一下Xshell，便于远程SSH连接。


主机填写IP地址
然后点击连接即可，根据提示输入账户和密码完成登录。
