Log4j2-intranet-scan甲方内网log4j2批量扫描
2021-12-31 17:05:57

1.项目地址

https://github.com/k3rwin/log4j2-intranet-scan

2.项目介绍

该项目适用于不能出网的甲方内网环境，原理为本地搭建虚假的ldap or rmi服务，使用扫描脚本将构造好的ldap或rmi请求发送到内网的虚假ldap服务上，内网ldap服务会记录请求参数，即解决内网不能使用dnslog扫描的困境。

3.脚本安装

 1. git clone https://github.com/k3rwin/log4j2-intranet-scan.git

 2. cd log4j2-intranet-scan

 3. pip3 install -r requirements.txt

 4. python3 log4j2-intranet-scan.py

4.脚本使用

 1. 本地启用ldap or rmi 服务,-p指定端口:JNDIScan-Windows.exe -p 8888

 2. 记录ip:port,即ldap or rmi服务地址

 3. 使用脚本扫描内网单个资产：
    python3 log4j2-intranet-scan.py --server "192.168.130.1:8888" -u https://vultest.com/login.jsp
    --server为本地的ldap or rmi服务地址，即步骤2中的ip:port.
    -u指定扫描的页面，默认使用GET探测，使用-request-type可指定post，或者使用-run-all-tests 全部探测。

 4. 使用脚本探测多个内网资产，从url中读取：
    python3 log4j2-intranet-scan.py --server "192.168.130.1:8888" -l urls.txt --run-all-tests
