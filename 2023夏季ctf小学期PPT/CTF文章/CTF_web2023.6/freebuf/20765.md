零信任安全知识课堂丨高危 SAP 漏洞可能让攻击者接管企业服务器?
2021-08-12 18:44:37

SAP 修补了一个影响 NetWeaver 应用服务器 (AS) Java 平台中 LM Configuration Wizard 组件的关键漏洞，该漏洞允许未经认证的攻击者控制 SAP 应用程序。

据发现该漏洞的网络安全公司 Onapsis 称，该漏洞被称为 RECON，漏洞号为 CVE-2020-6287，CVSS 评分为最高分10分，可能影响超过4万名 SAP 客户。

"如果成功利用该漏洞，远程的、未经认证的攻击者可以通过创建高权限用户和执行具有 SAP 服务用户账户权限的任意操作系统命令来获得对SAP系统的无限制接入，该账户对 SAP 数据库的接入不受限制，并能够执行应用维护活动，例如关闭联合的 SAP 应用。"美国 CISA（网络安全和基础设施安全局）在咨询中表示，"SAP 应用程序托管的数据和进程的保密性、完整性和可用性受到该漏洞的威胁。"

该漏洞默认存在于运行在 SAP NetWeaver AS Java 7.3 及更高版本（最高至 SAP NetWeaver 7.5）之上的 SAP 应用程序中，使多个 SAP 业务解决方案面临风险，包括但不限于 SAP ERP（企业资源计划）、SAP PLM（产品生命周期管理）、SAP CRM（客户关系管理）、SAP SCM（供应链管理）、SAP BI（商业智能）和SAP EP（企业门户）。

▼ SAP ERP 模块

根据 Onapsis 的说法，RECON 是由于 SAP NetWeaver AS for Java 的网页组件缺乏认证，从而使攻击者能够在受影响的 SAP 系统上执行高权限活动而引起的。

"一个远程的、未经认证的攻击者可以通过 HTTP 接口来利用这个漏洞，这个接口通常暴露在终端用户面前，而且在很多情况下，暴露在互联网上。" CISA说。

通过利用该漏洞创建一个具有最高权限的新 SAP 用户，入侵者可以入侵 SAP 安装，执行任意命令，如修改或提取高度敏感信息，以及破坏关键业务流程。

虽然没有证据表明该漏洞被主动利用，但 CISA 警告说，补丁的可用性可能会使敌手更容易逆向该缺陷，以创建漏洞并针对未打补丁的系统。

鉴于 RECON 的严重性，建议企业尽快打上关键补丁，并扫描 SAP 系统的所有已知漏洞，分析系统是否存在恶意或过度的用户授权。
