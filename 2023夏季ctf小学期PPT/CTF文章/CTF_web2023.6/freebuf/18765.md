华云安漏洞安全周报【第55期】
2021-10-21 14:15:37

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 10.11~2021.10.17）CNNVD接报漏洞435，信息技术产品漏洞（通用型漏洞）179个，网络信息系统漏洞（事件型漏洞）256个；CNNVD接报漏洞预警96份，其中华云安报送预警3份！

本周重点关注漏洞包括：Microsoft 10月多个安全漏洞、CVE-2021-40449-Win32k 权限提升漏洞、CVE-2021-22033-VMware vRealize Operations SSRF 漏洞、CVE-2021-22035-VMware vRealize Log Insight CSV 注入漏洞、CVE-2021-22036-VMware vRealize Orchestrator 重定向漏洞、CVE-2021-42340-Apache Tomcat 拒绝服务漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

Microsoft 10月多个安全漏洞

严重

2021年10月13日，华云安思境安全团队发现 Microsoft 官方发布10月份安全更新，共发布了82个漏洞的补丁程序，同比上月减少了4个。主要覆盖了：Microsoft Windows 和 Windows 组件、Microsoft Edge（基于 Chromium）、Exchange Server、.NET Core 和 Visual Studio、Microsoft Office、SharePoint Server、Microsoft Dynamics、InTune、System Center Operations Manager 等多个产品和组件。在漏洞安全等级方面，有2个严重漏洞，62个高危漏洞；在漏洞类型方面，主要有27个远程代码执行漏洞，21个权限提升漏洞以及15个信息泄露漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

https://msrc.microsoft.com/update-guide/releaseNote/2021-Oct

CVE-2021-40449-Win32k 权限提升漏洞

高危

2021年10月13日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows Win32k 组件中存在一处权限提升漏洞。Windows Win32k 是微软公司的一个用于 Windows 多用户管理的系统文件。该漏洞是由于 UAF 导致的任意地址写漏洞，成功利用此漏洞的攻击者在获得权限的情况下，可通过构造恶意数据执行本地权限提升攻击。目前此漏洞已被在野利用。

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-40449

CVE-2021-22033-VMware vRealize Operations SSRF 漏洞

低危

2021年10月13日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware vRealize Operations 组件中存在一处 SSRF 漏洞。VMware vRealize Operations 是一款应用程序。一个统一的，基于 AI 的平台上为私有，混合和多云环境提供自动驾驶的 IT 运营管理。该漏洞是由于对用户提供的输入验证不足引起。成功利用此漏洞的攻击者可向服务器发送非预期的请求，从而导致服务器端请求伪造。

https://www.vmware.com/security/advisories/VMSA-2021-0021.html

CVE-2021-22035-VMware vRealize Log Insight CSV 注入漏洞


中危

2021年10月13日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware vRealize Log Insight 组件中存在一处 CSV 注入漏洞。VMware vRealize Log Insight 是一套集中式日志管理解决方案，该产品支持日志整理和日志分析等功能。具有非管理权限的经过身份验证的攻击者可能能够在通过 Log Insight 导出 CSV 工作表之前嵌入不受信任的数据，该工作表可在用户环境中执行。

https://www.vmware.com/security/advisories/VMSA-2021-0022.html

CVE-2021-22036-VMware vRealize Orchestrator 重定向漏洞

中危

2021年10月13日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware vRealize Orchestrator 组件中存在一处重定向漏洞。VMware vRealize Orchestrator 是一个现代工作流自动化平台，可简化并自动执行复杂的数据中心基础架构任务。该漏洞是由于 vRealize Orchestrator 中的路径处理不当导致敏感信息泄露，成功利用此漏洞的攻击者可以将受害者重定向到攻击者控制的域。

https://www.vmware.com/security/advisories/VMSA-2021-0023.html

CVE-2021-42340-Apache Tomcat 拒绝服务漏洞

中危

2021年10月15日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Tomcat 组件中存在一处拒绝服务漏洞。Apache Tomcat 是 Apache 基金会的一款轻量级 Web 应用服务器。该程序实现了对 Servlet 和 JavaServer Page（JSP）的支持。该漏洞是由于对 bug 63362 的修复引入了内存泄漏。一旦 WebSocket 连接关闭，用于收集 HTTP 升级连接指标的对象就不会针对 WebSocket 连接发布。这造成了内存泄漏，成功利用此漏洞的攻击者可能会通过 OutOfMemoryError 导致拒绝服务。

https://www.mail-archive.com/announ
