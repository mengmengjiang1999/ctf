烽火狼烟丨Microsoft多个安全漏洞风险提示
2022-05-12 09:58:27

1、漏洞概述

近日，WebRAY 安全服务产品线监测到Microsoft官网发布了5月安全更新，本次共发布了包含Windows LDAP、Microsoft SharePoint Server、Windows Print Spooler、Windows Network File System等产品在内的74个漏洞补丁。
其中CVE-2022-22017、CVE-2022-29972、CVE-2022-26923、CVE-2022-26931、CVE-2022-26937、CVE-2022-23270、CVE-2022-21972被评定为严重漏洞，建议广大用户及时更新系统并安装windows补丁，做好预防工作，以免遭受攻击。WebRAY安全服务产品线建议受影响客户及时进行安全更新。
WebRAY安全服务产品线将持续关注该漏洞进展，并及时为您更新该漏洞信息。


部分漏洞详细介绍：
CVE-2022-26931 Windows Kerberos 权限提升漏洞

Windows Kerberos存在权限提升漏洞。由于应用程序在Windows Kerberos中施加的安全策略不完善，导致了权限提升漏洞的存在。

CVE-2022-26937 Windows Network File System远程代码执行漏洞

Windows Network File System存在远程代码执行漏洞。由于系统对Windows Network File System中用户的输入内容验证不充分，导致远程攻击者可以将精心构造的恶意代码传递给应用程序并在目标系统上执行任意代码。

CVE-2022-22017 Windows远程桌面客户端远程代码执行漏洞

Windows远程桌面客户端存在远程代码执行漏洞。由于远程桌面客户端对用户的输入验证不足，导致目标用户在远程访问恶意的RDP服务器时，攻击者能在目标系统上执行任意代码。

WebRAY安全服务产品线风险评级：高危

4、修复建议

（1）通过Windows系统自动更新补丁，并在“Windows更新”->“查看更新历史记录”中确认更新是否成功安装；

（2）手动安装补丁包，参考链接https://msrc.microsoft.com/update-guide/releaseNote/2022-May
