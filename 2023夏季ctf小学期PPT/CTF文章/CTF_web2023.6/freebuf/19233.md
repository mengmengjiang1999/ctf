烽火狼烟丨VMware vCenter Server多个安全漏洞风险提示
2021-09-23 15:21:51

漏洞概述

2021年09月22日，WebRAY安全服务部监测到VMware 官方发布了针对vCenter Server 的安全更新，修复了包含CVE-2021-22005、CVE-2021-21991、CVE-2021-22006、CVE-2021-22011在内的多个高危漏洞，其中最为严重的漏洞是vCenter Server 文件上传漏洞，攻击者可通过此漏洞上传webshell，达到系统命令执行的目的。WebRAY安全服务部建议相关用户及时更新产品到安全版本。
VMware vCenter Server 是美国威睿（VMware）公司的一套服务器和虚拟化管理软件。该软件提供了一个用于管理 VMware vCenter 环境的集中式平台，可自动实施和交付虚拟基础架构。
WebRAY 安全服务部将持续关注该漏洞进展，第一时间为您更新该漏洞信息。
