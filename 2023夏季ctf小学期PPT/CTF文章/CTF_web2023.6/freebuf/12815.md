华云安漏洞安全周报【第80期】
2022-04-21 14:55:29

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.4.11~2022.4.17）本周CNNVD接报漏洞335个，信息技术产品漏洞（通用型漏洞）106个，网络信息系统漏洞（事件型漏洞）229个；CNNVD接报漏洞预警155份，其中华云安报送预警16份，预警报送数量持续位居前列！

本周重点关注漏洞包括：Microsoft 4月多个安全漏洞、CVE-2021-31805-Apache Struts2 代码执行漏洞、CVE-2022-20695-Cisco Wireless LAN Controller 身份验证绕过漏洞、CVE-2022-1364-Google Chrome V8 类型混淆漏洞、CVE-2022-22966-VMware Cloud Director 代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作

01Microsoft 4月多个安全漏洞

威胁等级：严重

漏洞描述：

2022年4月12日，华云安思境安全团队发现 Microsoft 官方发布4月份安全更新，共发布了111个漏洞的补丁程序，其中 Microsoft Windows 漏洞64个。主要涵盖了 Microsoft Windows、Microsoft Dynam、Microsoft Office 、Microsoft Win32K、Microsoft Kerberos、Microsoft Hyper-V、Microsoft DNS、Microsoft Lightweight Directory Access Protocol、Microsoft .NET Framework、Microsoft Azure Site Recovery、Microsoft Graphics Components 和 Microsoft Windows Fax 等多个产品和组件。在漏洞安全等级方面，有2个严重漏洞，60个高危漏洞；在漏洞类型方面，主要有37个为权限许可和访问控制问题漏洞，25个为代码注入漏洞，13个为信息泄露漏洞以及33个其他漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：https://msrc.microsoft.com/update-guide/releaseNote/2022-Apr

02 CVE-2021-31805-Apache Struts2 远程代码执行漏洞

威胁等级：高危

2022年4月12日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Struts2 组件中存在一处代码执行漏洞。Apache Struts2 是一个基于 MVC 设计模式的 Web 应用框架，它本质上相当于一个 servlet，在 MVC 设计模式中，Struts2 作为控制器来建立模型与视图的数据交互。该漏洞是由于使用 \\%{…} 语法强制 OGNL 求值，标签的一些属性仍然可以执行双重求值语法。成功利用此漏洞的攻击者可执行远程代码攻击并导致安全性降低。

情报来源：https://cwiki.apache.org/confluence/display/WW/S2-062

03CVE-2022-20695-Cisco Wireless LAN Controller 身份验证绕过漏洞

威胁等级：超危

漏洞描述：

2022年4月13日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Wireless LAN Controller 组件中存在一处身份验证绕过漏洞。Cisco Wireless LAN Controller 是一款无线局域网控制器产品，该产品在无线局域网中提供安全策略、入侵检测等功能。该漏洞是由于密码执行不当，攻击者通过使用精心构造的凭据登录受影响的设备触发此漏洞。成功利用此漏洞的攻击者可绕过身份验证并以管理员身份登录设备。

情报来源：https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-wlc-auth-bypass-JRNhV4fF

04CVE-2022-1364-Google Chrome V8 类型混淆漏洞

威胁等级：高危

漏洞描述：

2022年4月14日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome V8 组件中存在一处类型混淆漏洞。Google Chrome 是一款由 Google 公司开发的网页浏览器。该漏洞是由于 Chrome V8 引擎中存在的缺陷引起， 成功利用此漏洞的攻击者可成功读取或写入超出缓冲区边界的内存，从而导致浏览器崩溃或执行任意代码。

情报来源：

https://chromereleases.googleblog.com/2022/04/chrome-for-android-update_01436352408.html

05CVE-2022-22966-VMware Cloud Director 代码执行漏洞0

威胁等级：超危

漏洞描述：

2022年4月14日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware Cloud Director 组件中存在一处代码执行漏洞。VMware Cloud Director 是一个领先的云服务交付平台，云服务提供商使用该平台来运维和管理成功的云服务业务。该漏洞是由于后端未对用户输入的数据进行过滤的缺陷引起，成功利用此漏洞的攻击者通过输入恶意数据，从而在后端执行任意代码攻击。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2022-0013.html﻿
