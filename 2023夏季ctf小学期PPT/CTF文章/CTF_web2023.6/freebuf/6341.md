律动炫光，致强性能 耕升 GeForce RTX 4080 炫光 SOC性能解禁 DLSS 3大幅提...
2022-11-16 11:48:37

耕升 GeForce RTX 4090 的出色表现让众多玩家们感受到全新NVIDIA Ada Lovelace架构的强大性能， 让玩家们再次感受到NVIDIA DLSS 3技术对游戏的强大提升。而在耕升 GeForce RTX 4090 发售一个月后，耕升 GeForce RTX 40系列家族迎来了另一个性能强大的成员：耕升GeForce RTX 4080 追风和耕升 GeForce RTX 4080 炫光 SOC。

耕升 GeForce RTX 4080 追风和耕升 GeForce RTX 4080 炫光 SOC GPU都基于NVIDIA Ada Lovelace架构，搭载全新第三代RT Cores和全新第四代Tensor Core以及全新流光加速器。核心处理器型号为AD103-300/301，拥有9728个CUDA核心、304个Tensor Cores和76个RT Cores，让游戏玩家和艺术创作者在性能和技术方面获得巨大提升。

耕升 GeForce RTX 4080 追风 与 耕升 GeForce RTX 4080 炫光 SOC不同的是，RTX 4080 追风沿用了 追风 系列扇叶以及经典黑红配色，侧边还有 GAINWARD 字样的ARGB灯效。本次测试主要以 耕升 GeForce RTX 4080 炫光 SOC为主，耕升 GeForce RTX 4080 追风将会往后推出。

耕升 GeForce RTX 4080 炫光 SOC 同样集成NVIDIA DLSS 3。DLSS 3 是由全新第四代Tensor Cores和GeForce RTX 40系列GPU的全新光流加速器驱动，并拥有开创性的光学多帧生成功能，从而带来惊人的性能提升。除此之外，还有NVIDIA Reflex低延迟技术提供更低延迟和更出色的响应速度，从而带来出色的制胜优势。

产品图赏

产品拆解

耕升 GeForce RTX 4080炫光 SOC采用全新Ada Lovelace架构核心，GPU型号为AD103-300/301，拥有9728个CUDA核心、304个Tensor Cores和76个RT Cores。基础频率为2205MHz，加速频率为2505MHz。拥有256-bit GDDR6X 规格、16 GB容量的显存，显存速度为22.4Gbps、显存带宽为735.7GB/s。FP16（half）为48.74 TFLOPS、FP64（double）为761.5GFLOPS。

在供电模组方面，耕升 GeForce RTX 4080 炫光 SOC采用了12层PCB设计、16相核心供电、3相显存供电、全新12VHPWR 供电接口，能为显卡带来稳定高效的动力。短PCB设计加强散热，为显卡强劲降温。显卡功耗为320W，推荐使用750W及以上功率电源使用，保证显卡稳定持续输出功率安全运行。

耕升 GeForce RTX 4080 炫光 SOC采用第二代「炫之黑曜石」散热器，支持ARGB可调灯效和接主流板厂神同步。第二代「炫之黑曜石」散热器升级由2个102mm和1个92m组合而成的强效三风扇，配合第二代耕升「炫风之刃」造形扇叶，能有效散热频率的提升幅度。

耕升 GeForce RTX 4080 炫光 SOC还特别升级加量特大面积散热鳍片，内置8根复合式导热管，在热导管中加入镀镍设计加强抗氧能力，增强导热性能且延长使用寿命。穿透式金属散热背板，让显卡温度进一步下降稳定运行。

产品规格

耕升 GeForce RTX 4080 炫光 SOC 与GeForce RTX 3080 Ti 相比，CUDA处理器数量增加至9728个，加速频率增加至2625MHz，显存速度22.4Gbps。全新Ada Lovelace架构较上一代旗舰级显卡能带来高强性能提升，最新一代DLSS 3 光学多帧数生成技术的应用也能让显卡在游戏和渲染展现出非凡的性能。

基础性能测试

正式进入测试环节，为了不让CPU和主板限制GPU本身的性能，故本次测试平台处理器采用英特尔酷睿i9-12900K搭配 华硕 ROG MAXIMUS Z690 HERO主板；内存采用 芝奇 幻锋戟 DDR5 6000Hz 16GB*2；电源采用的是 耕升 星源 G850金牌 850W搭配 耕升 骇浪360 一体式水冷，能最大程度为GPU降温和供电。驱动更新至最新的 NVIDIA Game Ready驱动526.72版本。这套配置足以让耕升 GeForce RTX 4080 炫光 SOC 显卡能在稳定的环境下最大程度发挥出超强性能。

3D Mark测试数据对比

首先使用3DMark软件来进行GPU各项基准测试。从测试结果上来看，耕升 GeForce RTX 4080 炫光 SOC GPU较于RTX 3080 Ti有明显的性能提升：Fire Strike 提升了46%，Fire Strike Extreme 提升了52%，Time Spy 提升了55%，Port Royal 光追测试中提升了42%，Fire Strike Ultra 提升了48%。在与RTX 3080 Ti的DLSS 2 对比中，RTX 4080 的DLSS 3 明显有巨大的优势，帧数提升将近2倍。可见搭载了全新Ada Lovelace核心架构和光流加速器的 耕升 GeForce RTX 4080 炫光 SOC比上一代同级别旗舰级显卡在各方面性能都有大幅度提升。

GPU-Z

由检测软件GPU-Z可看到升 GeForce RTX 4080 炫光 SOC的产品规格和基本参数，以及其待机温度为31°C，功耗为7.6W。

FurMark满载测试

接下来使用负载软件FurMark来测试 耕升 GeForce RTX 4080 炫光 SOC GPU的功耗控制能力。在测试开始之前，GPU的待机情况是功耗12W，待机温度31℃；开启负载软件压榨GPU后，等待温度与功耗表现稳定，测得最终GPU的功耗为320W，温度为67℃。耕升 GeForce RTX 4080 炫光 SOC搭载了第二代「炫之黑曜石」散热器和加量特大面积散热鳍片，穿透式金属散热背板的设计能让显卡在满载时依然能保持一个优秀稳定的温度。由软件测试可得出结论显卡功耗稳定在320W左右，在游戏测试过程中通过FrameView查看实时损耗仅为240W左右。

游戏测试

本次测试的游戏分别为：《微软模拟飞行》、《赛博朋克2077》、《F1 22》、《瘟疫传说：安魂曲》、《幻塔》、《超级人类》和《毁灭全人类2：重新探测》。以1080P、2K、4K分辨率测试各游戏性能，其中1080P、2K分辨率使用DLSS 3 质量模式，4K分辨率使用DLSS 3 性能模式。以上全部游戏都支持NVIDIA DLSS 3 。

《微软模拟飞行》

首先要来进行测试的是《微软模拟飞行》，《微软模拟飞行》是NVIDIA 官方公布首批支持DLSS 3 的游戏之一，DLSS 3 的帧生成模式能大幅提升游戏性能优化游戏体验。在实机测试中，极高画质4K分辨率下，RTX 4080能跑到90帧左右，2K分辨率下也能跑到89帧上下。而开启DLSS 3 帧生成模式后，帧数有了明显的区别。在4K分辨率下，RTX 4080可以跑到137帧的成绩，2K分辨率更是能跑到182帧的优秀成绩。在DLSS 3 的提升下，玩家可以在游戏中流畅地欣赏世界各地的优美风景。

《赛博朋克2077》

作为光线追踪效果最好的游戏之一，《赛博朋克2077》也理所应当成为本次游戏测试的项目。《赛博朋克2077》同时也是首批支持DLSS 3 技术的游戏，DLSS 3 所带来的巨幅提升能让玩家们流畅地浏览夜之城的夜色。在极高画质光线追踪最高的设置下，不开启DLSS技术4K分辨率下只能跑到25帧，2K也只能跑到56帧，而在1080P下则可以跑到81帧的成绩。在开启DLSS 3 帧生成模式后，帧数有了巨大的飞跃：4K分辨率下能跑到110帧，2K分辨率跑到148帧，1080P则可以跑到198帧，开启DLSS 3 后的帧数成绩足以让玩家畅玩夜之城。

在游戏测试的过程中，许多玩家担心显卡的功耗问题，但是在实际游戏测试的过程中， 通过FrameView实时监测显卡功率，发现显卡实际运行功耗较低，游戏过程中温度也趋于正常稳定的温度。可见得益于RTX 4080 的散热模组使得显卡持续保持在一个安全稳定的运行状态。

《F1 22》

《F1 22》作为首批支持DLSS 3 里面唯一的赛车游戏，被诸多赛车游戏玩家寄予厚望。游戏本身的性能表现就已经十分不错，在经过DLSS 3 的优化过后，游戏性能则是更上一层楼。在极高画质光线追踪开启4K分辨率下，游戏依然能保持106这样一个不错的帧数，2K分辨率下能跑到199帧，1080P下更是能跑到288帧。虽然这样的帧数已经足够支持玩家游戏，但是在DLSS 3 的优化下，游戏帧数能跑到一个更高的程度。开启DLSS 3 帧生成模式后，4K分辨率下能跑到179帧，2K分辨率下能跑到253帧，1080P下更是能跑到329帧，性能提升接近2倍。

《瘟疫传说：安魂曲》

（左：DLSS 3 光学多帧 关闭 右：DLSS 3 光学多帧 开启）

《瘟疫传说：安魂曲》作为10月份的新游戏，也率先支持NVIDIA DLSS 3 技术。游戏中自带光线追踪效果，为游戏画面带来极大的画质提升，同时NVIDIA DLSS 3 帧生成模式能给游戏带来大幅的性能提升。在极高画质4K分辨率下，游戏帧数为87帧，2K分辨率下为136帧，1080P下为165帧。在开启DLSS 3 帧生成模式后，游戏性能获得大幅提升，4K分辨率下可以跑到130帧，2K分辨率可以跑到185帧，1080P更是可以跑到247帧。游戏过程中没有任何卡顿闪退等现象出现，达到完美运行的状态。

《幻塔》

《幻塔》是一款支持NVIDIA 光线追踪和DLSS 3 的游戏，光线追踪的加持让游戏呈现出拟真的光线物理效果，带来逼真的画面。在游戏测试中可以看到，RTX 4080 在极高画质光线追踪开启DLSS关闭时，4K分辨率下仅有44帧，RTX 3080 Ti 仅有29帧。而在2K分辨率下，RTX 4080就有91帧，1080P下更是有157帧。而开启DLSS 3 后，帧数就实现了质的飞跃，在4K分辨率下有153帧，在2K分辨率下有235帧，在1080P下更是有319帧，帧数提升近两倍。

《超级人类》

在《超级人类》中，RTX 4080 表现出了其强大的性能优势。在与RTX 3080 Ti的对比中可以看到，RTX 4080 与RTX 3080 Ti有明显的性能差距。在极高画质DLSS关闭的情况下，4K分辨率RTX 4080 能跑到123帧，2K分辨率能跑到233帧，1080P下能跑到289帧。当DLSS 3 帧生成技术开启的时候，帧数就有一个明显的涨幅。RTX 3080 Ti平均涨幅为46-78帧，而RTX 4080 则是最高能涨105帧，可见对比DLSS 2，DLSS 3 对游戏的性能提升是十分强大的。

《毁灭全人类2：重新探测》

在《毁灭全人类2：重新探测》中，RTX 4080 的表现依旧优异。在这款游戏中，DLSS 3 的提升十分显赫，在极高画质 DLSS 关闭 4K分辨率下，游戏只有85帧的成绩，2K分辨率下能跑到108帧，1080P能跑到119帧。而在极高画质DLSS 3 开启的情况下，4K分辨率下则是能跑到160帧，2K分辨率下则是能跑到227帧，1080P下也能跑到244帧。与关闭DLSS技术相比，性能有接近2倍的提升。

游戏更新DLSS 3 的速度特别快，往后将会有更多游戏上线时同步支持DLSS 3 ，玩家们可以在游戏发售时即可享受到DLSS 3 所带来的性能提升。

总结

作为 耕升 GeForce RTX 40系列家族的新成员，耕升 GeForce RTX 4080 炫光 OC沿用的40系列全新的NVIDIA Ada Lovelace架构，搭载全新第三代RT Cores和全新第四代Tensor Core以及全新光流加速器，为游戏和设计带来性能提升。耕升 GeForce RTX 4080 炫光 SOC 与上一代旗舰级显卡相比，CUDA处理器数量增加至9728个，加速频率增加至2625MHz。在满载测试中，显卡满载温度为67°C，满载功率为320W ，而在实际游戏测试中功耗为240W左右，玩家们使用 RTX 4080进行游戏时不用担心高功耗的问题。

在游戏测试中，RTX 4080在本次测试的7款游戏与上一代旗舰显卡对比中都表现出色。帧数均有明显的涨幅，帧数均能提升1-2倍。在开启DLSS 3 帧生成模式后，帧数对比更加明显，不少游戏都能跑出200+帧的高帧数。目前支持DLSS 3 的游戏名单正持续更新中，往后众多新游戏将同步支持DLSS 3，玩家们将会在游戏上线之时就能享受到DLSS 3 帧生成技术所带来的非凡性能提升！

NVIDIA DLSS 3作为NVIDIA DLSS 的最新技术，不仅能为各位玩家带来更高效流畅的游戏体验，还可以应用在各个行业以及领域，推动人工智能AI的发展。除此之外，NVIDIA Studio 全套创意应用，包括 NVIDIA Omniverse、NVIDIA Broadcast、NVIDIA Canvas 和NVIDIA RTX Remix，也在主播、建模、专业设计等不同领域发光发热。
