Jmeter入门篇（一）---安装运行Jmeter
2020-12-25 18:25:43

Jmeter作为大受欢迎的开源测试工具，当前支持如下协议。本篇为入门篇第一篇，介绍Jmeter 安装及运行。

  * Web - HTTP, HTTPS (Java, NodeJS, PHP, ASP.NET,...)
  * SOAP / REST Webservices
  * FTP
  * Database via JDBC
  * LDAP
  * Message-oriented Middleware (MOM) via JMS
  * Mail - SMTP(S), POP3(S) and IMAP(S)
  * Native commands or shell scripts
  * TCP
  * Java Objects

Jmeter安装包下载

在网站https://jmeter.apache.org/download_jmeter.cgi下载Jmeter 二进制包
首先在网站下选择好镜像，国内建议选择 https://mirrors.tuna.tsinghua.edu.cn/apache/镜像

随后下载 二进制zip包文件

最后 检验安装包下载是否完全，建议采用512校验 和 下载位置中的512校验对比。

Jmeter安装包运行

Jmeter 运行前确定已经安装JAVA JDK ，且版本符合要求

 1. 解压下载的zip 文件
 2. 切换到解压后文件夹的 bin 目录下
    windows 运行 Jmeter.bat文件
    Linux 运行 jmeter
