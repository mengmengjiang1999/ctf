OSIsoft PI Web API 2019存在安全漏洞，攻击者可在用户浏览器上运行恶意代码
2020-06-22 12:17:11

Otorio公司的安全研究人员在OSIsoft的PI System中发现了一个高危安全漏洞。研究人员立即通知OSIsoft Software该漏洞的详情，OSIsoft将该漏洞提交至美国ICS-CERT。


PI System架构实现

关于OSIsoft Software的PI System

安装在世界最大的一些关键基础设施设备中，OSIsoft Software的PI System是一个数据管理平台，可访问它所服务的站点中广泛的核心OT网络资产。

该平台收集、存储和组织来自所有工厂数据源的数据，公司操作员、工程师、管理人员和其他工厂人员可访问这些数据——他们通过各种HMI和客户端应用程序从其中检索数据，其中一些应用程序使用PI Web API。

PI System漏洞（ICSA-20-163-01）

Otorio公司的安全研究人员发现了PI System存在一个安全漏洞（CVE-2020-12021），攻击者可利用该漏洞在客户端浏览器上运行客户端代码，并骗取用户的凭据。

当受害者将光标传递到PI系统中的受影响的字段上时，漏洞利用就实现了。这会触发一个假登录表单，提示受害者重新输入用户名和密码。研究人员创建了一个简短的视频，说明这一利用。

Otorio应急响应团队主管Dor Yardeni说：“我们的工业网络安全专家接受过培训，能够识别像这样难以发现的漏洞——这些漏洞可能严重危及现场OT网络资产。他总结道：“与OSIsoft合作，我们能够迅速隔离和修复该漏洞，使他们能够继续为客户提供智能、安全、数字化的生产解决方案。”

OSIsoft建议受影响的用户升级到PI Web API 2019 SP1。
