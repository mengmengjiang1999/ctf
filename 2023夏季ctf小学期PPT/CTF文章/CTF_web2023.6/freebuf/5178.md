如何判断一个网站是否“安全”
2022-12-09 11:45:10

并非所有网站都可以安全访问。事实上，某些网站可能包含恶意软件（恶意软件），可能会损害您的计算机或窃取您的个人联系信息或信用卡号。

网络钓鱼是另一种常见的基于 Web 的攻击类型，诈骗者试图诱骗您向他们提供您的个人信息，如果您访问可疑网站，您可能会容易受到此攻击。

身份盗用是一个严重的问题，因此在浏览网页时保护自己很重要。在线安全威胁对于互联网用户来说可能是一个大问题，尤其是在访问新网站或关注站点链接时。

那么，如何判断您访问的是安全网站还是不安全的网站呢？您可以使用几种不同的方法。本页讨论了在网站中寻找的关键事项，以便您可以保持在线安全。

网站安全的关键标志

当您访问网站时，一些关键指标可以帮助确定该网站是否安全。本节探讨如何检查 URL 以获取安全网站的两个特定标志。

网站网址中的“https：”

网站 URL 中的“Https”表示该网站可以安全访问。“s”代表“安全”，这意味着该网站使用SSL（安全套接字层）加密来保护您的信息。经过验证的SSL证书会告诉您的浏览器该网站是安全的。在网上购物或将个人信息输入网站时，这一点尤其重要。

当您在网址中看到“https”时，该网站正在使用一种协议，该协议在信息从您的计算机发送到网站服务器之前对其进行加密。这有助于防止任何人在 传输敏感信息时拦截和读取敏感信息。

浏览器网址字段附近的锁定图标

浏览器 URL 字段附近的挂锁图标是网页可以安全访问的另一个指标。此图标通常出现在地址栏中，表示站点使用 SSL 加密。 安全工具以及图标和警告外观取决于 Web 浏览器。

让我们探索一下三种主要网络浏览器上的网络安全工具：

  * Safari。在 Mac 上的 Safari 浏览器中，您只需在地址栏中查找网站 URL 旁边的锁定图标即可。锁定图标将被锁定或解锁，具体取决于站点是否使用 SSL 加密。如果这是一个不安全的网站，当尝试在用于个人数据或信用卡号的字段中输入信息时，Safari 会在地址栏中生成一条红文警告，指出“不安全”或“网站不安全 ”。Safari 浏览器还可能会在页面上生成安全警告，指出“您的连接不是私有的”或“您的连接不安全”。
  * 谷歌浏览器。在 Google Chrome 中，当您访问具有经过验证的 SSL 证书的网站时，您会在网址左侧看到一个灰色锁图标（在以前的 Chrome 版本中为绿色）。 Chrome 还有其他指示器图标，例如小写的“i”，周围有一个圆圈。单击此图标可阅读有关网站网络安全的相关信息。 Google 安全浏览功能会使用安全工具在访问不安全的网站时提醒您。URL 左侧可能会出现一个红色警告符号，上面写着“不安全”。您可能还会看到一条页面安全消息，指出该网站由于网络钓鱼或恶意软件而不安全。
  * 火狐。与Chrome一样，Mozilla的Firefox浏览器将使用独特的标记标记所有未加密的网站。 带有三角警示牌的挂锁表示该网站仅部分加密，可能无法阻止网络犯罪分子窃听。 带有红色划线的挂锁表示网站不安全。如果您单击网站上的某个字段，它会提示您一条文本警告，指出“此连接不安全”。

深入检查网站安全性的方法

总体而言，“https”和锁定的挂锁图标是良好的信号，表明当您 在网站上输入您的个人数据时，它是安全的。但是您可以确保网站的安全性在其他方面达到标准。本节将探讨检查网站安全的五种深入方法。

网站信任印章

当您浏览网页时，能够信任您正在访问的网站非常重要。确定网站是否值得信赖的一种方法是寻找信任印章。信任印章是表明网站安全可靠的徽标或徽章。它们通常出现在网站的主页或结帐页面上。

检查隐私政策

确定网站是否可以安全访问的另一种方法是检查隐私政策。隐私政策是概述网站如何收集和使用个人信息的文件。它还应说明网站如何保护您的数据不被诈骗者、黑客或其他未经授权的个人访问或共享。

如果网站没有隐私政策，这是一个危险信号，您不应该在网站上输入任何个人信息。即使网站确实有隐私政策，仔细阅读也很重要，以便您了解该网站如何使用您的个人数据。

查看第三方评价

在访问新网站之前进行一些初步研究很重要，尤其是在您在线购物或输入 地址、信用卡或电话号码等个人数据时。确定网站是否安全可靠的一种方法是检查第三方评论。几个网站提供其他网站的评论，因此您应该能够找到任何给定网站的多个评论。

阅读评论时寻找共同主题。如果大多数评论都提到一个网站是安全且易于使用的，那么该网站很可能确实可以安全访问。但是，如果许多负面评论提到病毒或恶意软件的问题，您可能希望避免使用该网站。

查看网站设计

您还可以在决定网站是否可以安全访问时分析网站设计。查找拼写错误、语法错误以及任何出现的错误。如果一个网站看起来像是匆忙制作的，或者看起来设计得不好，这通常是一个危险信号，表明该网站可能不安全。

特别小心有很多弹出窗口的网站。这些网站通常是垃圾网站或包含恶意软件。不要从网站下载任何内容，除非您绝对确定它是安全的。这些恶意网站很少出现在搜索引擎结果的顶部，因此请考虑使用搜索引擎来查找您要查找的内容，而不是将您重定向到未知网站的链接。
