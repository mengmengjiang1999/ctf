什么书证书签名请求 (CSR)
2022-09-20 16:17:42

在数字安全领域，证书签名请求 (CSR) 是保护 Web 流量的重要组成部分。如果您想建立网站或在线服务，您需要生成 CSR 并将其提交给证书颁发机构 (CA)[1]。本文将解释什么是 CSR，它包含什么信息，以及如何生成它。

1.什么是CSR？

证书签名请求 (CSR) 是一个编码文件，其中包含有关您的网站、服务、组织和域名的信息。证书颁发机构 (CA) 使用此信息为您的网站创建 SSL/TLS 证书，以加密您网站的流量。证书 CSR 还包含您的公钥和签名，这有助于验证您的身份并保护与您站点的通信。

2.创建 SSL/TLS 证书


SSL/TLS 证书是保证您的网站流量安全的一种方式。这是通过使用唯一代码加密发送到您的网站和从您的网站发送的信息来完成的。要获得 SSL 证书，您必须创建证书签名请求 (CSR)。

2.1.怎么运作：


使用 CSR 创建 SSL/TLS 证书是一个两步过程：

2.1.1.生成私钥和公钥对。这可以使用各种工具来完成，例如 OpenSSL[2]。

2.1.2.使用私钥创建 CSR。此步骤将生成一个 CSR 文件，您必须将其提交给 CA。

3.CSR 包含哪些信息？


CSR 包含详细的信息列表，但最重要的部分是：

有关您的业务的信息，以便 CA 可以验证您的身份和业务。 CSR 应包括有关您的业务、公钥以及密钥类型和长度的信息。

3.1.有关您的业务的信息


CSR应包含与您的业务相关的所有信息，例如姓名、城市、州和国家/地区。您的电子邮件地址、域名以及您希望使用 SSL/TLS 证书保护的任何其他域名。必须确保此信息正确无误，因为它将用于在创建证书时验证您的身份。

3.2.公钥


公钥是用于加密数据的数学值。 CSR 包含您的公钥，CA 使用它来创建您的证书并验证您的 CSR 上的签名。

公钥是使用加密算法生成的，例如 RSA。 RSA 是一种流行的算法，用于创建公钥和私钥。密钥的长度（以位为单位）决定了加密的强度。较长的密钥比较短的密钥更安全。 RSA 使用两个大素数：p 和 q。 RSA 2048 是最常见的密钥长度，但您也可以选择 RSA 3072、4096 或 7168。

3.3.密钥类型和长度


CSR 还应包括您使用的密钥类型（RSA 或 DSA）和密钥长度。最常见的密钥大小是 2048 位和 4096 位。


4.证书签名请求是什么样的？


CSR 通常使用 Base-64 编码，这是一种以 ASCII 文本表示二进制数据的标准格式。 base-64 编码的 CSR 看起来像一长串随机字符。

4.1.什么是 Base-64？


Base-64 是一种标准编码格式，用于在 ASCII 文本中表示二进制数据。这种格式有助于将二进制数据转换为可以通过 Internet 轻松传输的可读格式。创建 CSR 时，您需要使用 Base-64 对其进行编码，以便 CA 对其进行处理。

4.2.什么是ASCII？


ASCII（美国信息交换标准代码）是数字世界中使用的标准字符编码系统。它为字母表中的每个字符分配一个唯一编号。

5.如何创建CSR


生成 CSR 涉及几个步骤。首先，您需要开发一个私钥。简单来说，私钥是用于加密信息的密码。此密钥应妥善保管，因为它可用于解密您网站的流量。

5.1.创建私钥


公钥是从私钥数学推导出来的。这些一起被称为“密钥对”。私钥可用于解密由相应公钥加密的数据，公钥可用于验证由相应私钥创建的数字签名。

许多 Web 服务器和运行时环境，例如 Internet 信息服务 (IIS)，都内置了 CSR 生成功能。生成私钥的另一种方法是使用 OpenSSL 命令行工具。这将生成一个名为 example.com.key 的私钥文件，长度为 2048 位。

5.2.生成 CSR


生成私钥后，您可以使用它来创建 CSR 文件。该文件将包含上述信息，通常使用 Base-64 进行编码。 CSR 文件也可以使用 OpenSSL 命令行工俱生成。

5.3.提交给 CA


生成 CSR 后，您必须将其提交给证书颁发机构 (CA)。 CA 将使用 CSR 请求中的信息为您的网站创建 SSL/TLS 证书。

5.4.安装证书 CSR


从 CA 收到 SSL/TLS 证书后，您需要将其安装在您的服务器上。安装过程因服务器类型和您使用的软件而异。但是，大多数服务器使用类似的过程来安装 SSL/TLS 证书。

您需要将证书文件（.crt 和 .key 文件）复制到服务器。接下来，您需要将服务器配置为使用 SSL/TLS 证书。此过程将根据您使用的服务器软件而有所不同，但通常涉及将证书文件添加到配置文件并重新启动服务器。

6.最后的想法

CSR 文件对于为您的网站设置 SSL/TLS 证书至关重要。它们包含用于生成证书的信息，并且必须提交给 CA 以获得证书。获得证书后，您必须将其安装在您的服务器上。

请求、颁发、更新和安装证书的过程通常是手动且繁重的，导致人为错误和中断。 WoTrus CA Limited[3]和 WoTrus Tools [4]有助于简化和自动化证书的整个生命周期，从颁发到续订。这使您可以专注于优先事项，并消除与证书管理相关的数小时繁琐且耗时的任务。
