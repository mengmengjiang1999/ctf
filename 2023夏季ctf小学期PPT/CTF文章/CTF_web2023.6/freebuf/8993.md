华云安漏洞安全周报【第92期】
2022-07-15 15:04:07

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.7.4~2022.7.10）CNNVD接报漏洞501个，信息技术产品漏洞（通用型漏洞）99个，网络信息系统漏洞（事件型漏洞）402个；CNNVD接报漏洞预警142份，其中华云安报送预警11份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-29885-Apache Tomcat 拒绝服务漏洞、CVE-2022-2294-Google Chrome 远程代码执行漏洞、CVE-2022-2274-OpenSSL RSA 远程代码执行漏洞、CVE-2022-33980-Apache Commons Configuration 远程代码执行漏洞、CVE-2022-26135-Atlassian Jira 服务端请求伪造漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-29885-Apache Tomcat 拒绝服务漏洞

威胁等级：高危

漏洞描述：

2022年7月4日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Tomcat 组件中存在一处拒绝服务漏洞。Apache Tomcat 是一款轻量级 Web 应用服务器。该程序实现了对 Servlet 和 JavaServer Page（JSP）的支持。该漏洞是由于 Tomcat 开启集群配置中存在缺陷引起，成功利用此漏洞的攻击者可在未授权的情况下，通过构造恶意数据从而造成拒绝服务攻击。

情报来源：

https://lists.apache.org/thread/2b4qmhbcyqvc7dyfpjyx54c03x65vhcv

02 CVE-2022-2294-Google Chrome 远程代码执行漏洞

威胁等级：高危

漏洞描述：

2022年7月5日，华云安思境安全团队发现Google 官方发布安全更新，披露了 Google Chrome 组件中存在一处远程代码执行漏洞。Google Chrome 是全球主流的免费浏览器之一，用户群体广泛，具有快速、高效、安全等特点。该漏洞是由于 WebRTC 中的堆缓冲区溢出引起，成功利用此漏洞的攻击者可通过构造恶意数据造成缓冲区溢出攻击，从而执行远程代码攻击。

情报来源：

https://chromereleases.googleblog.com/2022/07/chrome-for-android-update.html

03 CVE-2022-2274-OpenSSL RSA 远程代码执行漏洞

威胁等级：超危

漏洞描述：

2022年7月6日，华云安思境安全团队发现 OpenSSL 官方发布安全更新，披露了 OpenSSL RSA 组件中存在一处远程代码执行漏洞。OpenSSL 是一个开源的能够实现安全套接层（SSLv2/v3）和安全传输层（TLSv1）协议的通用加密库，该产品支持多种加密算法，包括对称密码、哈希算法、安全散列算法等。该漏洞是由于在计算过程中会发生内存损坏引起，成功利用此漏洞的攻击者可能会在执行计算的机器上触发远程代码执行。

情报来源：

https://www.openssl.org/news/secadv/20220705.txt

04 CVE-2022-33980-Apache Commons Configuration 远程代码执行漏洞

威胁等级：高危

漏洞描述：

2022年7月6日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Commons Configuration 组件中存在一处远程代码执行漏洞。Apache Commons Configuration 是一款通用的配置接口，它主要用于使 Java 应用程序从多种来源读取配置数据。该漏洞是由于 Apache Commons 配置执行变量插值，允许动态评估和扩展属性。成功利用此漏洞的攻击者在特定情况下，通过构造恶意数据从而执行远程代码攻击。

情报来源：

https://lists.apache.org/thread/tdf5n7j80lfxdhs2764vn0xmpfodm87s

05 CVE-2022-26135-Atlassian Jira 服务端请求伪造漏洞

威胁等级：中危

漏洞描述：

2022年7月7日，华云安思境安全团队发现 Atlassian 官方发布安全更新，披露了 Atlassian Jira 组件中存在一处服务端请求伪造漏洞。Atlassian JIRA Server 是一套缺陷跟踪管理系统的服务器版本，该系统主要用于对工作中各类问题、缺陷进行跟踪管理。该漏洞是由于远程攻击者在经过身份验证的情况下通过 Jira Core REST API 伪造服务端发送特制请求，从而导致服务端敏感信息泄露。

情报来源：

https://confluence.atlassian.com/display/JIRA/Jira+Server+Security+Advisory+29nd+June+2022
