1.题目 easywill

2.提示easyeasy

3.复现背景

由于该比赛以及关闭，无环境进行利用验证，为了更好的讲解该题型的解题思路，本文进行逆向思维，搭建还原题目环境；由于是Windows系统搭建，所以将flag文件放置在D：目录的下。

4.复现过程以及原理

1）搭建Apache2.4版本+php7.3版本，以及willphp2.1.5环境

a.下载 httpd-2.4.51-win64-VS16

b.下载 php-7.3.33-Win32-VC15-x64

c.下载willphp2.1.5版本https://gitee.com/willphp/willphpv2/tree/808b3a36d366f66a88fd130cc6514c20eaf15450/

2）搭建完成后，启动httpd.exe文件

3）访问本地地址http://127.0.0.1,出现It works表明Apache+php搭建成功，

4）将willphp2.1.5版本的源码放入htdos目录下，命名为willphpv，将该文件夹下的APP目录中的common.php文本写入代码：

<?php
namespace home\controller;
class IndexController{
public function index(){
highlight_file(__FILE__);
assign($_GET['name'],$_GET['value']);
return view();
}
}

5）访问http://127.0.0.1/willphpv/index.php，会执行common.php文件，该页面就是本题CTF给出的题目环境，需要我们找出flag的原始页面。

6）willphp2.1.5版本调试源码common.php。发现assign() 、view()函数的定义是显示模板，common.php该代码的assign函数get传入参数为模板函数以及显示值。

7）调试发现在renderTo()函数存在变量覆盖，include $cfile，因此我们使用cfile充当assign()函数的模板变量。

8）将分析得原理过程进行利用，获取本文一开始搭建环境存放置在D:目录下的flag：访问http://127.0.0.1/willphpv/index.php/?name=cfile&value=D:/flag
