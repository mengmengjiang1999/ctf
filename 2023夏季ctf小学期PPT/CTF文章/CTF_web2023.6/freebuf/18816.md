华云安漏洞安全周报【第54期】
2021-10-15 17:11:57

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 9.27~2021.10.10）CNNVD接报漏洞774，信息技术产品漏洞（通用型漏洞）84个，网络信息系统漏洞（事件型漏洞）690个；CNNVD接报漏洞预警69份，其中华云安报送预警3份！

本周重点关注漏洞包括：CVE-2021-36745-Trend Micro ServerProtect 身份验证绕过漏洞、CVE-2021-41617-OpenSSH 权限提升漏洞、CVE-2021-41773-Apache HTTP Server 路径遍历漏洞、CVE-2021-42013-Apache HTTP Server 远程代码执行漏洞、CVE-2021-37978-Google Chrome 远程代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

CVE-2021-36745-Trend Micro ServerProtect 身份验证绕过漏洞

超危

2021年9月27日，华云安思境安全团队发现趋势科技官方发布安全更新，披露了 Trend Micro ServerProtect 组件中存在一处身份验证绕过漏洞。Trend Micro ServerProtect 是趋势科技的一款企业级反病毒程序。用于保护网路连接储存系统，从源头拦截威胁。该漏洞源于身份验证过程中的错误。成功利用此漏洞的远程攻击者可以绕过身份验证过程，从而获得对系统的未经授权的访问。

https://success.trendmicro.com/solution/000289038

CVE-2021-41617-OpenSSH 权限提升漏洞

高危

2021年9月29日，华云安思境安全团队发现 OpenSSH 官方发布安全更新，披露了 OpenSSH 的组件 sshd(8) 中存在一处权限提升漏洞。OpenSSH（OpenBSD Secure Shell）是 Openbsd 计划组的一套用于安全访问远程计算机的连接工具。该工具是 SSH 协议的开源实现，支持对所有的传输进行加密，可有效阻止窃听、连接劫持以及其他网络级的攻击。该漏洞是由于当 sshd(8) 在执行 AuthorizedKeysCommand 或 AuthorizedPrincipalsCommand 时，未能正确地初始化，其中 AuthorizedKeysCommandUser 或 AuthorizedPrincipalsCommandUser 指令被设置为以非 root 用户身份运行。相反，这些命令将继承 sshd(8) 开始时使用的组，根据系统配置，继承的组可能允许帮助程序获得特权提升。

https://www.openssh.com/security.html

CVE-2021-41773-Apache HTTP Server 路径遍历漏洞

超危

2021年10月5日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache HTTP Server 组件中存在一处路径遍历漏洞。Apache HTTP Server 是一款开源网页服务器，该服务器具有快速、可靠且可通过简单的 API 进行扩充的特点。在路径穿越目录允许被访问的情况下，成功利用此漏洞的攻击者可读取到 Web 目录之外的其他文件，同时若 Apache HTTPd 开启了 cgi 支持，攻击者可构造恶意请求执行命令，控制服务器。

https://httpd.apache.org/security/vulnerabilities_24.html

CVE-2021-42013-Apache HTTP Server 远程代码执行漏洞

超危

2021年10月7日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache HTTP Server 组件中存在一处远程代码执行漏洞。Apache HTTP Server 是一个开源、跨平台的 Web 服务器，它在全球范围内被广泛使用。该漏洞是由于 Apache HTTP Server 2.4.50 版本中对 CVE-2021-41773 的修复不够充分，攻击者可以使用路径遍历攻击将 URL 映射到由类似别名的指令配置的目录之外的文件。如果这些目录之外的文件不受通常的默认配置 “requireall denied” 的保护，则这些请求可能会成功。如果还为这些别名路径启用了 CGI 脚本，则可以允许远程代码执行。

https://httpd.apache.org/security/vulnerabilities_24.html#CVE-2021-42013

CVE-2021-37978-Google Chrome 远程代码执行漏洞

中危

2021年10月8日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome 组件中存在一处任意代码执行漏洞。该漏洞是由于 Blink 中处理不受信任的 HTML 内容时出现边界错误。成功利用此漏洞的远程攻击者可创建一个精心构造的网页，诱骗用户打开，从而触发基于堆的缓冲区溢出，最终在目标系统上执行任意代码。

https://chromereleases.googleblog.com/2021/10/stable-channel-update-for-desktop.html
