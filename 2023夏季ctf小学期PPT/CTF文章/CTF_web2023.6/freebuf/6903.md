华云安漏洞安全周报【第101期】
2022-10-10 11:14:04

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.9.5~2022.9.11）CNNVD接报漏洞411个，信息技术产品漏洞（通用型漏洞）214个，网络信息系统漏洞（事件型漏洞）197个；CNNVD接报漏洞预警79份，其中华云安报送2份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-3075-Google Chrome 远程代码执行漏洞、CVE-2022-34747-Zyxel NAS 设备远程代码执行漏洞、CVE-2022-2639-Linux Kernel openvswitch 模块权限提升漏洞、CVE-2022-38395-HP Support Assistant 权限提升漏洞、CVE-2022-34165-IBM WebSphere Application Server 输入验证错误漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-3075-Google Chrome 远程代码执行漏洞

威胁等级：高危

漏洞描述：

2022年9月5日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome 组件中存在一处远程代码执行漏洞。Google Chrome是一款web浏览器，该浏览器基于其他开源软件撰写。该漏洞是由于 Mojo 中数据验证不足引起，攻击者可通过多种方式诱导用户访问恶意的链接触发此漏洞；成功利用此漏洞的远程攻击者可绕过安全限制，在服务器上执行任意代码攻击。

情报来源：

Stable Channel Update for Desktop

02 CVE-2022-34747-Zyxel NAS 设备远程代码执行漏洞

威胁等级：超危

漏洞描述：

2022年9月7日，华云安思境安全团队发现 Zyxel 官方发布安全更新，披露了 Zyxel NAS 设备中存在一处远程代码执行漏洞。Zyxel NAS326是中国合勤科技（Zyxel）公司的一款云存储 NAS。该漏洞是由于其允许攻击者通过精心制作的UDP包利用格式化字符串的缺陷引起，成功利用此漏洞的远程攻击者可实现未经授权的远程代码执行。

情报来源：

https://www.zyxel.com/support/Zyxel-security-advisory-for-format-string-vulnerability-in-NAS.shtml

03 CVE-2022-2639-Linux Kernel openvswitch 模块权限提升漏洞

威胁等级：高危

漏洞描述：

2022年9月7日，华云安思境安全团队发现 Github 发布安全更新，披露了 Linux Kernel openvswitch 模块中存在一处权限提升漏洞。Linux kernel是开源操作系统Linux所使用的内核。该漏洞是由于在 openvswitch 内核模块中发现整数强制错误，这可能会导致越界写入访问；成功利用此漏洞的攻击者在经过本地身份验证的情况下可提升他们在系统上的权限。

情报来源：

https://github.com/torvalds/linux/commit/cefa91b2332d7009bc0be5d951d6cbbf349f90f8

04 CVE-2022-38395-HP Support Assistant 权限提升漏洞

威胁等级：高危

漏洞描述：

2022年9月8日，华云安思境安全团队发现 HP 官方发布安全更新，披露了 HP Support Assistant 组件中存在一处权限提升漏洞。HP Support Assistant 是指惠普支持助手程序，它可通过查找更新和提供故障排除工具让 HP 电脑保持正常运转状态，被预装在大部分 HP 电脑上。该漏洞是由于当 Fusion 启动 HP Performance Tune-up 时容易受到DLL 劫持漏洞攻击触发，成功利用此漏洞的攻击者可提升系统权限。

情报来源：

Privilege escalation in HP Support Assistant

​05 CVE-2022-34165-IBM WebSphere Application Server 输入验证错误漏洞

威胁等级：中危

漏洞描述：

2022年9月9日，华云安思境安全团队发现 IBM 官方发布安全更新，披露了 IBM WebSphere Application Server 组件中存在一处输入验证错误漏洞。IBM WebSphere Application Server（WAS）是一款应用服务器产品，该产品是 JavaEE 和 Web 服务应用程序的平台，也是 IBMWebSphere 软件平台的基础。该漏洞是由于验证不当引起，容易受到 HTTP 标头注入的影响。

情报来源：

Security Bulletin: IBM WebSphere Application Server and IBM WebSphere Application Server Liberty are vulnerable to HTTP header injection (CVE-2022-34165)
