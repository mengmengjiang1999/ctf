IT项目管理人士职业生涯必备证书之DevOps系列
2021-02-23 09:33:15
在IT业务需求和技术日新月异的今天，DevOps在国内外发展的如火如荼。世界各地的大型互联网公司都已采用DevOps方法来彻底改进其性能、安全性和团队动态，DevOps专业证书也成为了企业面试的加分项。今日，我们聊一下，为什么IT人士职业生涯必备DevOps系列证书！


01、开发模式的演变

多年来，DevOps从现有的软件开发策略/方法发展而来，以响应业务需求。从模型上看演变过程：


缓慢而繁琐的瀑布模型演变成敏捷，开发团队在短时间内完成软件开发，帮助开发团队处理客户反馈，并将其与bug修复一起合并到下一个版本中。虽然这种敏捷的SCRUM方法为开发带来了敏捷性，但它在运维方面却失去了敏捷实践的速度。开发人员和运维工程师之间缺乏协作仍然会减慢开发过程和发布。DevOps方法就是基于对更好的协作和更快的交付的需求而产生的，DevOps允许用较少复杂问题的持续软件交付来修复和更快地解决问题。


02、市场需求的变化

DevOps原来只存在互联网、电信、金融等企业，主要是因为他们这些行业因为业务的原因需要自主开发大型的面向普通消费者的系统，例如电商系统、网上银行等。而这些系统的共同特点，即有业务吞吐量大、功能变化频率大、系统故障率要求低，而且系统访问量也随着季节、活动等有较大变化等特点。其实不难发现系统的演进也是业务不断发展的迫切需求。现在大家都在关注企业的数字化转型，尤其是传统企业，外有竞争环境的日益加剧，传统模式受到来自互联网企业的挑战，不转型等死的状态。企业内在渠道下沉，开拓新领域新模式的需求，以及现在信息化技术的发展，互联网化、移动化、大数据化等，也催促企业内部不断迭代甚至换代自身老旧的IT系统。所以，不仅是互联网、电信、金融等大型的企业在使用DevOps，而且传统的企业也在不断的探索，落地自己的DevOps。DevOps专业人员已经成为市场上最抢手的工作角色，认证考试越来越重要。82%的招聘经理更倾向于雇佣拥有专业证书的人士，高于两年前的 47%。附Devops相关岗位月薪图：


03、企业实践DevOps

DevOps早在2019年成为企业能否在行业内脱颖而出的关键性因素。真正能够实践 DevOps 的团队也会为自身的业务带来巨大的提升。根据 Puppt 的2017 DevOps State Report，DevOps 团队将部署频率提高46倍，交付速度提高 440 倍。国际上DevOps 已经处于企业爆发性需求的前夜。而在国内公司中，新兴企业的成功实践也在为中国企业的 DevOps 输送方法论与有经验的专家。字节跳动是DevOps 最佳践行者之一，在其创始人张一鸣看来：公司的业务越复杂，人越多，组织就越大。这导致信息失效、（下属）向上管理和业务变大。他把类似组织的负规模效应称为“自嗨”，这是他所不能接受的。故而字节跳动在组织架构上，总共只有 3 个核心部门：技术、Growth 和商业化，分别负责研发、推广和收入。

今日头条、抖音、西瓜视频……字节跳动的每款 App 都基于这三个部门来发展。在项目开始时，公司会为每个项目设置虚拟项目组，由三个核心部门抽调人员组成，试水成功后直接推广。所有产品共用一条技术线，快速试错。针对 App 类产品的快速迭代的业务特性，字节跳动依据 DevOps 理念对组织架构进行调整和优化，从结构上保证了技术支持业务创新的能力。


04、DevOps资质认证

拥有专业领域证书的人员已成为企业招聘者首选候选人。作为从事软件和网站开发人员、系统工程师、DevOps工程师、产品和服务负责人、项目经理、测试工程师、IT服务管理操作和支持人员、流程经理、精益IT从业人员、Agile Scrum从业者应⽤程序开发人员、产品负责人、敏捷Scrum Master、测试经理和IT服务经理，必备DevOps资质认证。

1、EXIN DevOps Foundation（基础级）

EXIN DevOps Foundation（简称DOF）作为 EXIN DevOps Professional/Master认证的进阶基础，本认证确认是否了解 DevOps 的起源以及 DevOps 原则和实践对组织的益处。该认证旨在帮助 IT 专业人员掌握关于 DevOps 的基本知识和理解。学习目标：1) 面向管理者的DevOps理念与精髓；2) 剖析5大基本原则、10个关键实践；3) 揭示DevOps转型的可行性和限制性；4) 加速技术组织绩效提升的核心能力；5) 通过培训考试，获得EXIN颁发的DevOps Foundation国际认证证书；

2、EXIN DevOps Professional（专业级）

EXIN DevOps Professional（简称DOP）是EXIN DevOps认证体系中的实践应用级课程，也作为高级认证“Master”的进阶前置认证。它是全球范围内唯一以DevOps Handbook这本被誉为”DevOps领域的圣经“的集大成之作为核心教材的认证。该认证旨在考察考生对DevOps实践的理解程度，它适用于更加广泛领域的IT从业者。此门认证的主要目的是检测考生是否能熟练掌握DevOps实践的“三步工作法”。包括：流动原则、反馈原则、持续学习与实验原则，以及其中的大量技术实践。通过学习和考试，考生将充分理解这些组织层面和技术层面的变革对其日常工作的影响。通过培训学习可以掌握学习目标：1) 建立对DevOps理念，关键实践的深度认知；2) 遵循体系化的三步工作法，有效实施DevOps；3) 世界500强企业DevOps真实案例解析；4) 誉为“DevOps领域圣经”的《DevOps Handbook》为核心教材；5) 通过培训考试，获得EXIN颁发的DevOps Professional国际认证证书；

3、EXIN DevOps Master（专家级）

EXIN DevOps Master课程(简称DOM),是EXIN DevOps系列认证课程中的最高级别。DevOps Master是EXIN DevOps认证体系中最高级认证，它将原则、知识和实践技能结合在了一起。这使他们能够在组织中引入和促进DevOps, 以便更好地管理应用程序和服务生命周期，同时促进团队协作。该认证不仅关注理论知识，更加关注实践技能的培养和考察，使 DevOps Master 能够成功地将DevOps应用于一个企业团队中，并促成 DevOps原理被组织广泛采用和实行。DevOps Master认证对于那些希望扩展知识体系，以及覆盖IT管理的最新发展模式的IT专业人⼠来说非常有吸引力。学习目标：1) 提升产品/服务交付质量与效率；2) 通过响应变化提升客户价值；3) 成为企业内部DevOps推动者；4) 正确启动DevOps转型；5) 持续学习和改进，减少瓶颈和浪费；6) 通过培训考试，获得EXIN颁发的DevOps Master国际认证证书；
