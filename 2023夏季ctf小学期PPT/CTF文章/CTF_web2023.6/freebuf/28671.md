身份云平台 Authing 完成 500 万美元 Pre-A 轮融资
2021-01-15 12:05:06

身份云平台 Authing 宣布完成 500 万美元 Pre-A 轮融资，由 GGV 纪源资本独家投资，由远识资本担任独家财务顾问。Authing 曾在 2020 年获得来自华创资本和奇绩创坛的千万级天使轮融资。Authing 表示， 本轮融资将主要用于产品研发以及市场扩张。

Authing 于 2019 年正式上线，是国内首款 以开发者为中心的全场景身份云（IDaaS），为应用程序提供身份验证、授权和用户管理服务，是云计算领域的身份基础设施，致力于连接全球人与应用。

GGV 纪源资本执行董事吴陈尧表示

“在 GGV 全球的企业服务软件投资过程中，我们清晰的看到了「传统软件-SaaS-API/SDK化」的发展趋势，用几行代码就可以把非核心业务的功能模块集成到自己的服务中，让企业可以专注于自己的核心业务，Twilio、Stripe 都是这方面的佼佼者。在中国，我们也清晰的看到了企业数字化转型和 IT 基础设施革新的快速发展。我们相信，Authing 作为一家从 Day1 开始就提供云原生架构的创新企业服务公司，有着广阔的发展空间，我们看好团队的持续创新能力，期待有更多的全球企业从中受益。”

Authing CEO 谢扬表示

“Authing 是一款代表信任的身份产品。代表信任的核心是客户成功，我们对整体的客户体验非常重视。客户成功除了确保服务可靠性、稳定性和安全性之外核心就是做好三件基本功： 嵌入，集成和连接。嵌入就是基础设施，开发者和企业基于 Authing 提供的丰富 SDK 和 API 可以将身份嵌入到任何应用，赢得用户体验的同时释放生产力；集成就是构建一个预集成的应用生态，Authing 会消除所有应用之间的摩擦，并使每个人轻松使用任何应用；在夯实前两步的基础上，Authing 可以为企业安全连接员工、供应商、合作伙伴和外部客户，并在多个应用之间实现用户供应和身份流转。”

Authing CMO 许子强表示

“企业采购 Authing 的投资回报率高达 5 倍，其价值在云优先、移动优先的生态中长期演进。Authing 在上轮融资后的半年内经历了客户数量的翻倍，也逐渐发现最大的竞争对手是仍然在试图自己维护身份设施的组织和个人。”

Authing COO 李宇航表示

“身份是一个严肃的事情，我们是一群严肃的人在帮助客户解决严肃的问题，以用户为中心的绩效指标使得 120 分的创新产品能更好更快的为客户解决问题。”

自云计算诞生以来，企业上云浪潮席卷全球。但大量企业上云后还由于惯性继续沿用原有的身份系统，这让数据泄露、用户系统崩溃等事件在世界各地屡屡发生，据 IBM 统计，2019 年数据泄露事件给企业造成的平均成本为 386 万美元。Authing 利用「 云加无边界安全」的思路解决了企业在数字化转型过程中遇到的身份难题。Authing 是一款标准化产品，同时基于云原生架构在灵活性和扩展性方面的优势，通过提供一整套开发工具，完整封装了单点登录、自适应多因素认证、社交登录、基于策略的集中式授权和审计等功能，灵活满足了企业在内部员工身份管理、外部用户身份管理、老应用兼容、新应用开发等全部场景的复杂需求。

以中国石油为代表的众多大型组织将 Authing 作为他们专属的身份云基础设施，在内部员工身份管理场景（EIAM）中，Authing 帮助 IT 人员快速兼容老旧应用和系统上云，实现精细化权限管控和安全审计以及可视化运维，助力企业大幅提升安全性和管理效率。在外部用户身份管理场景（CIAM）中，Authing 完善的 API 和 SDK 不仅可以让企业在开发新应用时大幅缩短上线时间，还能助力政府实现公民数字身份，实现「一地注册，多地互认」。身份云可以构建一个身份共享的生态，摆脱数据孤岛，助力企业大幅提升运营效率和营收规模。

Authing CTO 尚斯年表示

“身份基础设施是一件非常有挑战的事情，需要安全、性能、用户体验和可扩展性都做到极致。在 Authing ，我们从不给自己设限，不断挖掘技术潜能，给开发者和企业带来效率的提升。”

Authing 是国内唯一的云原生身份服务提供商，在技术侧强势领先，研发团队来自字节跳动、阿里云、爱奇艺、滴滴等一线厂商。Authing 采用 Kubernetes 容器化技术，同时支持公共云、混合云和私有云部署，支持分钟级别弹性扩容，最大可支持亿级别用户认证访问场景。 Authing 支持 OAuth 2.0、OIDC、SAML、AD/LDAP 等所有国际主流的认证授权协议，同时，Authing 具备完善的开发者服务，提供十几种编程语言的 SDK 支持。比如在国内开发者最常见的微信场景中，Authing 提供了一整套的微信接入方案，包括扫码登录、移动端拉起微信登录、微信 PC 端扫码登录的能力。

Authing 在 SaaS 产品之下开发了 PaaS 平台，成功地避免了陷入定制化的困境中。PaaS 平台为开发者提供身份认证 RPA、应用集成网关和通用登录组件（Guard），前者的作用是兼容老旧应用，这些老旧应用经常没有标准协议或无人维护，利用身份 RPA 和应用集成网关就可自动适配。Guard 是一种可嵌入的登录表单，可根据客户的需求进行配置。 Authing 通过不断深耕身份基础设施建设，在分布式身份（DID）、数字身份、知识图谱等新兴技术上寻找突破点，通过技术手段降低客户的研发成本，提升企业效率。

基于 Authing 管理用户身份大幅提高了企业和开发者的生产力。在 2020 下半年，Authing SaaS 收入高速增长，越来越多的企业客户意识到了购买 Authing 比自己构建身份体系更便捷、更安全。截至 2020 年末，已有超过 1000 万企业员工和客户通过 Authing 安全登入超过 10000 个系统和应用中，累计认证次数高达 5 亿。中国石油、国家电网、日本丰田、安永、德高集团、华西医院、意大利裕信银行等众多国内外优秀企业选择 Authing 作为其身份解决方案。伴随着新一轮融资的结束，Authing 将继续深耕身份基础设施，同时加速市场扩张，致力于连接全球人与应用。
