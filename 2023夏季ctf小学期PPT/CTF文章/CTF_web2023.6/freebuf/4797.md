SharkTeam与NFMS达成合作，提供Move合约审计服务
2022-12-05 16:20:45

12月5日，SharkTeam 与 NFMS 正式达成安全审计合作伙伴关系。SharkTeam将为 为 Move 上的 NFT 项目NFMS提供安全审计服务，并持续通过人工审计和形式化验证技术打造最安全的 Move 生态。

NFMS（Infamous） 是第一个在Aptos链上构建的游戏化动态 NFT 项目。每个动漫风格的 NFT 都可以通过不同的闲置机制升级，变得更强大并解锁新武器、外观和内容。 具有固定元数据的静态 NFT 限制太多，因此NFMS NFT 开发了一种新技术，称为 Traceable Dynamic NFT Ledger。这使他们的 NFT 能够根据游戏事件动态更新其元数据。


SharkTeam 为 NFMS 提供最专业的合约审计服务，通过人工审计和形式化验证技术，帮助 NFMS为 Move 生态（Aptos Blockchain）设计一套完整的 dNFT解决方案。


关于 NFMS


NFMS由Matrix Labs制作，是第一款在Aptos区块链上构建的游戏化动态NFT项目。Matrix Labs 在构建 Web3 应用程序和基础设施方面经验丰富，在各种区块链上共同制作了多个 NFT 和 metaverse 项目，包括 Matrix World、 PhantaBear和 Rivermen。

Twitter：https://twitter.com/NFMS_nft

Website: https://infamousnft.xyz/


关于 SharkTeam


SharkTeam的愿景是全面保护Web3世界的安全。团队由经验丰富的安全研究人员组成，精通区块链和智能合约的底层理论，提供包括智能合约审计、链上分析、应急响应等服务。已与区块链生态系统各个领域的关键参与者,如Polkadot、Moonbeam、polygon、OKC、Huobi Global、imToken、ChainIDE等建立长期合作关系。
