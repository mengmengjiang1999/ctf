微软5月补丁日修复111个安全漏洞
2020-05-13 16:39:54

微软（Microsoft）12日发布了本月Windows操作系统和其他产品的软件安全更新，共计修复111个安全漏洞，其中14个严重（Critical）漏洞，93个重要（Important）漏洞，2个中危漏洞和2个低危漏洞。需要注意的是，微软产品漏洞的危害等级会因受影响产品不同而定级不同。

根据微软发布的安全公告，成功利用这些漏洞，攻击者可以在目标系统上提升权限，远程执行代码，发动欺骗攻击，绕过安全特性，造成拒绝服务，导致信息泄露。

这些漏洞影响到微软多款产品和系统，包括Windows，Microsoft Office，开发人员工具，浏览器，SQL Server，Microsoft Dynamics，Paint 3D和3D Viewer。

本次微软公布的严重漏洞详情如下：

1. Microsoft SharePoint远程代码执行漏洞（CVE-2020-1024）

Microsoft SharePoint中存在一个远程执行代码漏洞，该漏洞源于软件未能检查应用程序数据包的源标记。攻击者可利用该漏洞在SharePoint应用程序池和SharePoint server farm账户的上下文中运行任意代码。

2. Media Foundation内存损坏漏洞（CVE-2020-1028）

Media Foundation中存在一个内存损坏漏洞，该漏洞源于Media Foundation以错误的方式处理了内存中的对象。攻击者可通过诱使用户打开特殊构造的文档，或诱使用户访问恶意网页利用该漏洞安装程序，查看、修改或删除数据，或创建具有完全用户权限的新账户。

3. Microsoft Color Management远程代码执行漏洞（CVE-2020-1117）

Color Management Module（ICM32.dll）处理内存中的对象的功能存在一个远程代码执行漏洞。攻击者可利用该漏洞控制受影响的系统。

4. MicrosoftGraphics组件远程代码执行漏洞（CVE-2020-1153）

Microsoft Graphics组件处理内存中的对象的功能存在一个远程代码执行漏洞。攻击者可通过诱使用户打开一个特制的文件利用该漏洞在目标系统上执行任意代码。

5. Media Foundation内存损坏漏洞（CVE-2020-1126）

Media Foundation中存在一个内存损坏漏洞，该漏洞源于Media Foundation以错误的方式处理了内存中的对象。攻击者可通过诱使用户打开特殊构造的文档，或诱使用户访问恶意网页利用该漏洞安装程序，查看、修改或删除数据，或创建具有完全用户权限的新账户。

6. 脚本引擎内存损坏漏洞（CVE-2020-1065）

ChakraCore脚本引擎处理内存中的对象的功能存在一个内存损坏漏洞。攻击者可利用该漏洞在当前用户的上下文中执行任意代码。

7. Microsoft SharePoint Server远程代码执行漏洞（CVE-2020-1069）

Microsoft SharePoint Server中存在一个远程代码执行漏洞，源于SharePoint Server未能正确地识别和过滤不安全的ASP.NETWeb控件。经身份认证的攻击者可借助特制的页面利用该漏洞在SharePoint应用程序池的安全上下文中执行操作。

8. Visual Studio Code Python扩展程序远程代码执行漏洞（CVE-2020-1192）

当Python扩展程序从笔记本文件加载工作区设置时，Visual Studio Code中会出现一个远程代码执行漏洞。攻击者可通过诱使用户在 Visual Studio Code 中打开经特制的文件利用该漏洞在当前用户的上下文中运行任意代码。

9. Chakra脚本引擎内存损坏漏洞（CVE-2020-1037）

Chakra脚本引擎处理Microsoft Edge（基于HTML）中的内存对象的功能存在一个内存损坏漏洞。攻击者可利用该漏洞在当前用户的上下文中执行任意代码。

10. Microsoft SharePoint远程代码执行漏洞（CVE-2020-1023）

Microsoft SharePoint中存在一个远程执行代码漏洞，该漏洞源于软件未能检查应用程序数据包的源标记。攻击者可利用该漏洞在SharePoint应用程序池和SharePointserver farm账户的上下文中运行任意代码。

11. Media Foundation内存损坏漏洞（CVE-2020-1136）

Media Foundation中存在一个内存损坏漏洞，该漏洞源于Media Foundation以错误的方式处理了内存中的对象。攻击者可通过诱使用户打开特殊构造的文档，或诱使用户访问恶意网页利用该漏洞安装程序，查看、修改或删除数据，或创建具有完全用户权限的新账户。

12. Microsoft SharePoint远程代码执行漏洞（CVE-2020-1102）

Microsoft SharePoint中存在一个远程执行代码漏洞，该漏洞源于软件未能检查应用程序数据包的源标记。攻击者可利用该漏洞在SharePoint应用程序池和SharePoint server farm账户的上下文中运行任意代码。

13. VBScript远程代码执行漏洞（CVE-2020-1093）

VBScript引擎处理内存中的对象的功能存在一个远程代码执行漏洞。攻击者可利用该漏洞在当前用户的上下文中执行任意代码。

14. MicrosoftEdge提权漏洞（CVE-2020-1056）

Microsoft Edge中存在一个提权漏洞，源于Edge未能正确地强制实施跨域策略。攻击者可利用该漏洞从一个域中访问信息并将其注入到其他域中。

微软已经发布漏洞补丁，建议用户尽快应用最新的安全补丁，保护计算机免遭入侵和攻击。
