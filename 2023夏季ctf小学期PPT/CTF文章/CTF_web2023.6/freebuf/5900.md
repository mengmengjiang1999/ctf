IDC MarketScape ：百度安全位居NESaaS市场领导者位置
2022-11-04 14:55:29

近日，国际权威咨询机构IDC发布了《IDC MarketScape: 中国公有云网络边缘安全即服务（NESaaS）市场》报告(以下简称IDC报告），凭借领先的AI安全技术能力，百度在2022年中国公有云网络边缘安全即服务市场评估中处于领导者位置。

IDC报告指出，基于百度多年安全实践的总结与提炼，依托人工智能和大数据，在百度安全的全方位技术支撑与护航下，百度拥有太字节（TB）级的云安全防护能力，每年拦截恶意网页与用户搜索风险超千亿次。同时，百度智能云云安全是百度安全的五大安全领域之一，结合 AI 领域的技术优势与云计算领域的长期服务经验，逐步建立了完善、全面的多类安全产品矩阵以及适应多种业务需求的安全解决方案，形成安全可靠的云基座，有效保护政企资产安全。

这是继百度安全今年入选IDC《中国数据安全技术发展路线图，2022》推荐厂商后的又一次推荐，表明百度安全已经在AI安全、数据安全、云安全、业务安全、移动安全等多个方向处于行业领先水平。

近年来，随着云上资产种类、数量、重要性的不断提升，其对网络攻击者的诱惑力也在不断增强。基于以上网络安全需求，为了更好地指引企业解决复杂 IT 环境下的网络安全建设，IDC在 2022 年提出网络边缘安全即服务（NESaaS）的概念。IDC认为，NESaaS作为综合网络安全能力堆栈，能够很自然的将各类安全能力高效整合，从而全面体现软件定义安全访问的理念。

IDC报告重点提到了百度智能威胁狩猎平台，它是百度融合深度学习、大数据分析等技术的产物。该平台拥有“强大的智能溯源”、“立体化的 API 防护”、“支持 0day/Nday 攻击检测”、“自动引流蜜罐”、“丰富的攻防演习工具箱”、“低误报低漏报”等6大优势，以网关的形态对客户的网络流量进行分析，通过强大的智能溯源机制识别攻击者的身份，并结合实时数据和智能算法模型，辅助客户进行高级安全决策，赋能安全运维人员，为企业保驾护航。

百度智能威胁狩猎平台基于大数据情报、AI分析模型的攻击者精准画像与溯源能力，实现用户、设备、网络 IP 三级的溯源分析和封禁，结合情报库进行关联分析，可以识别潜在攻击者身份，彻底颠覆了过去基于 IP 溯源的被动模式，相比业界常见的蜜网溯源方案，溯源成功率提升2~5倍，突破性地解决了行业中溯源成功率低且容易被绕过的问题。

目前百度智能威胁狩猎平台已经广泛应用于能源、政务、交通、互联网等行业，凭借其突出的AI安全能力为政企及能源等头部客户在网络攻防演练、红蓝对抗行动中做出了卓越的攻防与溯源表现，助力政企机构在攻防演练中获得了第一名的佳绩。

在某能源公司项目案例中,凭借产品对未知威胁高效的感知和防护能力，帮助客户更为高效地应对0day/Nday、APT攻击等高级威胁事件，实现对于安全威胁的快速检测和响应，提升安全运维工作的效率。不仅能构建完整的纵深防御体系，结合实时数据和人工智能算法模型，辅助客户进行高级安全决策，赋能安全运维人员，有效应对已知与未知威胁，对抗 0-Day、N-Day，通过强大的智能溯源系统识别攻击者身份，彻底颠覆了过去基于 IP 溯源的被动模式，高效地为关键基础设施系统保驾护航。

随着百度领先的AI安全能力全面融入百度大脑各项模块，并全面覆盖于百度智能云各项业务，在“云智一体”的独特优势下，未来，百度安全将继续秉持创新务实的初心，承接市场与企业对于安全的强劲需求，基于百度AI与大数据的丰厚技术沉淀，致力于打造基于AI和大数据的智能一体化安全体系，推动企业智能安全一体化进程的加速。
