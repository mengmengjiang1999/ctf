【威胁趋势】

回首2021年，新崛起的8大 macOS 恶意软件

回首2021年，ELectroRAT、SilverSparrow、XcodeSpy、ElectrumStealer、WildPressure、XLoader、ZuRu 等多个新的 macOS 恶意软件家族崛起。

  * 1月，研究人员发现了旨在窃取加密货币的跨平台 RAT ElectroRAT 。该恶意软件主要通过木马应用程序交付，其功能包括键盘记录、截屏、下载/上传文件和执行命令。
  * 2月，研究人员发现了新型恶意软件 SilverSparrow ，大约 30,000 台 macOS 设备受到影响。但就目前而言，它依然是一个相对较神秘的恶意软件，因为它的分发方式、目标及第二个有效载荷仍未被研究人员发现。
  * 3月，研究人员发现了 XcodeSpy 和 EggShell 。XcodeSpy 似乎只针对软件开发人员，主要是通过恶意 Xcode 项目交付的，然后安装一个名为 EggShell 的自定义后门变体，允许其运营商监视用户。ElectrumStealer 主要利用后门从受感染的系统中窃取加密货币。
  * 7月，研究人员披露了 macOS 恶意软件 WildPressure，主要针对中东的工业组织。该恶意软件活动疑似始于2019年5月，但最初只涉及 Windows 恶意软件。
  * 9月，研究人员在中国发现 ZuRu 恶意软件。该恶意软件主要通过百度搜索结果传播，提供赞助广告和木马化应用程序。

2021年，研究人员还发现了 XLoader 和 CDDS ， XLoader 是一种旨在窃取密码的跨平台恶意软件；CDDS(MacMa) 是2021 年发现的最后一个 macOS 恶意软件程序。据信一个威胁组织一直在利用 macOS 0day 漏洞通过水坑网站向香港用户提供恶意软件 CDDS。

随着 macOS 系统在企业中的持续增长和普及，研究人员预测在2022年肯定会崛起一批新的 macOS 恶意软件。

【金融威胁情报】

FluBot 银行木马新活动：伪装成 Flash Player 应用程序针对欧洲展开攻击

Tag：FluBot，银行木马，Flash Player，Android

事件概述：

FluBot 是 Android 银行木马，主要通过显示覆盖全球许多银行的登录表单来窃取凭据。近日，研究人员监测到 FluBot 银行木马瞄准欧洲的新活动，伪装成 Flash Player进行分发，并且添加了新的功能。

技术详情：

FluBot 银行木马主要通过 smishing（SMS 网络钓鱼）进行传播，诱饵包括虚假安全更新、 虚假 Adob​​e Flash 播放器、 语音邮件备忘录和虚假的包裹快递通知。当目标点击恶意链接后，会被重定向到一个虚假的 Flash Player APK [ VirusTotal ] 页面，安装 FluBot 银行木马，然后窃取网上银行凭据、发送或拦截 SMS 消息（和一次性密码），并捕获屏幕截图。由于恶意软件使用受害者的设备向他们的所有联系人发送新的短信，FluBot 银行木马通常会快速大规模的传播。

来源：https://www.bleepingcomputer.com/news/security/flubot-malware-now-targets-europe-posing-as-flash-player-app/

微步点评：

1、FluBot 最新版本中的新功能：
在通信方面，新的 FluBot 版本现在主要通过 HTTPS 上的 DNS 隧道连接到 C2，而之前它使用直接 HTTPS 端口 443 进行通信。

2、在 FluBot 5.0、5.1 和 5.2 版本的恶意软件上新增加的功能：

更新 DNS 解析器

远程更新 DGA 种子

使用多部分分割功能发送更长的短信

3、如何远离 FluBot?

  * 在许多情况下，下载 FluBot 的链接将通过您的一个联系人（甚至可能是朋友或家人）到达您的设备。

  * 因此，如果您收到一条不寻常的短信，其中包含一个 URL 并敦促您点击它，这很可能是 FluBot 恶意软件生成的一条消息。

  * 最后，避免安装来自异常来源的 APK 文件，定期检查您的 Android 设备上是否启用了 Google Play Protect，并使用信誉良好的供应商提供的移动安全解决方案。


【政府威胁情报】

FIN7 组织使用 BadUSB 设备瞄准美国国防公司展开攻击

Tag：FIN7，APT，美国

事件概述：

近日，美国联邦调查局发布紧急告警信息，称 FIN7 组织使用包含 LilyGO 标志的武器化 USB 设备 BadUSB 瞄准美国国防工业展开攻击。该组织还曾是 Darkside 和 BlackMatter 勒索软件运营的幕后黑手。自2021年8月以来，FIN7 使用这种技术针对运输和保险行业的企业展开攻击，而自2021年11月起开始针对国防公司展开攻击。

技术详情：

威胁组织通过伪装成来自美国卫生与公众服务部（HHS）和亚马逊的包裹：伪装成美国卫生与公众服务部]的包裹通常包含武器化的 USB，还有 COVID-19 指南的信件；伪装成亚马逊的包裹则是一个包含一封欺诈性的感谢信、伪造的礼品卡和一个武器化USB 的礼盒。二者包裹都通过使用美国邮政服务和联合包裹服务向美国运输、保险、国防行业的企业投递。

如果接收者将武器化的 USB 驱动器插入他们的计算机，这些设备将执行 BadUSB 攻击，其中武器化的 USB 驱动器会将自己注册为键盘，并向用户的 PC 发送一系列预配置的自动按键操作。这些按键操作将运行 PowerShell 命令，下载并安装各种恶意软件，充当攻击者进行入受害者网络后门。然后获取管理员权限，进行横向移动，并使用 Metasploit、Cobalt Strike、PowerShell 脚本、Carbanak、GRIFFON、DICELOADER、TIRION进行恶意操作，或在受感染的网络上部署包括 BlackMatter 和 REvil 在内的勒索软件。


来源：https://therecord.media/fbi-fin7-hackers-target-us-companies-with-badusb-devices-to-install-ransomware/


【能源威胁情报】

2022年，全球能源网络安全七大趋势

Tag：能源，安全趋势

事件概述：

随着各组织在积极努力应对2022年将带来的变化，西门子副总裁发表报道指出2022年全球能源网络安全的七大趋势：

1. 更多的袭击

大多数行业企业要为网络攻击做好相应的准备、制定计划并实践、帮助组织抵御打击。网络安全应该是设计参数的一部分，而不是附加物。

2. 更多的工业物联网

主要的业务收益来自于模糊信息技术(IT)和运营技术(OT)之间的界限，如涡轮机、制造设备或充电站。建立一个工业物联网(IoT)可以使一个团队灵活、高效、响应客户。

3.强调可持续性

随着世界各地的组织寻求低碳解决方案，更多的系统将采用全电动，数字化管理来优化效率。正如我们所看到的，随着能源行业的巨大转变，数字化程度的提高使得强大的网络安全变得更加重要。

4. 更多的董事会讨论

由于远程工作的爆炸式发展和物联网的发展，网络安全比以往任何时候都成为更多组织的核心业务能力。董事会和投资者将会更加关注能源行业企业是如何应对网络安全风险的。

5. 更多的人工智能

众所周知，网络安全需要日复一日地监控数以百万计的数据点。在处理上下文方面，自动化变得越来越智能。而直到今年，这些上下文都需要人类的智能，将常规的、高容量的监控从人类转移到机器有很大的优势。探测威胁的自动化可以以电子的速度移动。但或许更重要的是，自动化可以让人类分析师得以解放出来，去搜寻威胁和调查异常情况，这些都是在早期阶段发现新威胁所需的行动。

6. 更多的政府干预

像2021年殖民管道攻击事件，关键的基础设施现在已成为威胁组织的攻击目标。越来越多的政府将会要求具备成熟的网络安全能力，并确保法规为强大的、创新的防御提供一个下限，而不是上限。

7. 减少暴力，增加监控和检测

要阻止攻击者掠夺公司网络，万无一失的方法就是关闭一切。但是这种暴力解决方案是治根不治本的。监控内部系统可以发现威胁并追溯其来源，可以为企业提供更微妙的选择——这可能是关闭单个受损风力涡轮机还是关闭整个风力发电厂的区别。适当调整应对措施的规模可以将成本降至最低，并促使领导人更愿意采取预防性或先发制人的行动。

Chitubox 3D 打印机插件 AnyCubic 被曝安全漏洞

Tag：Chitubox，3D打印机，AnyCubic，漏洞
事件概述：

Chitubox 是一款3D打印软件，用户可以下载并处理模型的3D打印预处理工具，特定的AnyCubic 插件允许软件将 Chitubox 切片机(通用格式文件)的输出转换为 AnyCubic 系列打印机所期望的格式，这些转换后的文件将直接用于打印机提供的所有功能。

截至目前，Chitubox AnyCubic 漏洞依然未发表官方修复程序。

黑客利用木马化的 dnSpy 针对安全研究人员、开发人员展开复杂的恶意软件攻击

Tag：dnSpy，恶意软件攻击

事件概述：

近日，外媒报道称黑客发起了一场针对网络安全研究人员和开发人员的恶意软件活动。该活动分发恶意版本的 dnSpy .NET 应用程序，用来安装加密货币窃取软件、远控木马和挖矿软件。dnSpy 是网络安全研究人员分析 .NET 恶意软件通常使用的程序，是一种流行的调试器和 .NET 程序集编辑器，用于调试、修改和反编译 .NET 程序。目前，该软件已经不再由最初的开发人员开发，但恶意软件原始代码暴露在 GitHub 账户上。一位攻击者使用 dnSpy 编译版本创建了一个 GitHub 存储库，存储用于窃取加密货币的剪贴板劫持者、Quasar 远程访问木马、矿工和各种未知有效负载等一系列恶意软件。

此外，攻击者还在 dnSpy[.]net 上创建了一个设计精美且外观专业的网站，进行搜索引擎优化来推广该网站，并执行一系列命令创建计划任务以提升权限，禁用一些安全服务进行防御规避。

目前，用于支持该活动的 dnSpy[.]net 和 GitHub 存储库均已关闭。但安全研究人员和开发人员需要不断地注意那些在他们的设备上安装恶意软件进行恶意克隆的流行项目。

【高级威胁情报】

KONNI不按套路出牌，使用新手法针对俄罗斯方向持续展开攻击

Tag：KONNI，APT，俄罗斯

事件概述：

KONNI APT 组织是疑似由特定政府支持的黑客组织，该组织长期针对俄罗斯、韩国等地区进行定向攻击活动，其擅长使用社会热点话题对目标进行鱼叉式网络钓鱼攻击。

微步情报局近期通过威胁狩猎系统监测到 KONNI 组织借助 “COVID-19疫苗接种”主题对俄罗斯方向的定向攻击活动，分析有如下发现：

  * 攻击者向目标发送“疫苗接种预约”相关诱饵文档，并附带木马模块，根据相关诱饵文件内容，研判攻击目标为俄罗斯方向相关团体；

  * 木马使用 dll 劫持的方法借助相关安装包程序、PDF阅读器执行，后续加载执行的恶意模块与该组织以往攻击活动中所使用的样本高度一致；

  * 与该组织以往攻击活动不同的是，在本次攻击活动中，攻击者并没有使用宏文档进行攻击，而是将木马模块与正常程序打包在一起进行 dll 劫持攻击；

APT35 利用 Log4j 漏洞分发新的模块化 PowerShell 工具包

Tag：APT35，Log4j，漏洞

事件概述：
APT35（又名 Charming Kitten、TA453 、 Phosphorus）疑似是伊朗背景的威胁组织。仅在 Log4j 漏洞被披露四天后，该组织就开始广泛扫描并试图在面向公众的系统中利用 Log4j 漏洞。攻击者的攻击设置显然是仓促的，因为他们使用了基本的开源工具进行攻击，并基于之前的基础设施进行操作，这使得攻击更容易检测和归因。

技术详情：

在此次攻击中，威胁组织选择公开可用的开源 JNDI Exploit Kits 开展攻击，主要功能模块从 Amazon S3 存储桶 URL 下载 PowerShell 模块后门 CharmPower，枚举系统信息、与 C2 服务器进行基本通信以及接收命令、解密后续模块。在此攻击过程中、攻击者会通过多模块运作，每个模块都负责特定功能：列出已安装的应用程序、截屏、列出正在运行的进程、获取操作系统和计算机信息、从 C2 执行预定义的命令、清理由不同模块创建的任何痕迹，但这些模快均由主要模块生成。


来源：https://research.checkpoint.com/2022/apt35-exploits-log4j-vulnerability-to-distribute-new-modular-powershell-toolkit/



【漏洞情报】

Apple 发布更新修复 HomeKit DoS 漏洞 CVE-2022-22588

Tag：Apple，HomeKit，DoS 漏洞

事件概述：

继 Apple 被曝 HomeKit DoS 漏洞后，Apple 于1月12日发布适用于 iOS 和 iPadOS 的软件更新，以修复影响 HomeKit 智能家居框架的持续拒绝服务 (DoS)漏洞 CVE-2022-22588。如果该漏洞被攻击者成功利用，只需将 HomeKit 设备的名称更改为超过 500,000 个字符的字符串并诱骗目标接受恶意 Home 邀请，iPhone 和 iPad 就会陷入崩溃状态。由于 HomeKit 设备名称已备份到 iCloud，重新登录与 ‌HomeKit‌ 设备关联的受影响 iCloud 帐户可能会重新触发 DoS 条件，并导致设备进入无休止的崩溃和重启循环，只能通过将它们恢复到出厂设置结束崩溃和重启循环。

尽管该公司试图通过限制应用程序或用户可以设置的名称长度来缓解该问题，但依然没有采取任何措施来阻止攻击者运行允许过长设备名称的早期版本，攻击者依然可以通过网络钓鱼电子邮件向受害者发送触发漏洞的恶意请求。

IT 供应商 Finalsite 遭到勒索软件攻击，数千所学校受到影响

2022年1月7日，一家声称为全球8000所学校提供服务的 IT 供应商 Finalsite 遭到勒索软件攻击，数以千计的全球客户受到影响。1月6日， Finalsite 在 Twitter上发文为攻击导致长时间停机的客户表示歉意。Finalsite 称此次攻击首次于1月4日发现，其安全、基础设施和工程团队一直在夜以继日地工作，以安全可靠的方式恢复备份系统及Finalsite 的网络性能。

【钓鱼专题】

ESTsecurity ：新的网络钓鱼活动滥用 Google Docs 评论功能

2022年1月7日，ESTsecurity 发表报告指出新的网络钓鱼活动滥用 Google Docs 评论功能。2021年12 月，Avanan 研究人员发现了一个主要针对 Outlook 用户的网络钓鱼活动，该活动使用了一种利用 Google Docs 中的评论功能发送恶意消息的新技术。此次攻击链非常简单，攻击者使用谷歌账号创建谷歌文档。为了自动从 Google 发送消息，攻击者在 Google Docs 中添加了引用带有“@”的目标的评论，评论内容包含恶意链接，以此滥用 Google Docs 评论功能。然后便会向提及目标的收件箱发送一封通知电子邮件，通知他们在提及目标的文章中添加了新评论。
