ADB-Toolkit：一款针对Android设备的测试工具
2020-07-26 04:30:03

工具介绍

ADB-Toolkit是一款针对Android设备的测试工具，简而言之，ADB-Toolkit不仅可以帮助研究人员测试目标Android设备，而且还可以实现针对Android手机的渗透测试。

ADB-Toolkit是一个基于Bash开发的脚本工具，它提供了28种操作选项以及一个METASPLOIT组件，该组件拥有6种操作选项，可以帮助研究人员轻松对目标Android设备进行渗透测试。该脚本基于ADB（Android调试桥）实现其功能，研究人员可以利用ADB-Toolkit实现很多任务，包括测试目标Android设备的安全性在内。

METASPLOIT组件

这个组件由一系列脚本构成，其中包括相关的Metasploit Payload，当然了，研究人员也可以创建自己的Payload，然后安装并启用这些Payload。毫无疑问，大家都知道Metasploit的强大！

工具要求

在使用该工具之前，我们需要在目标Android设备上开启USB调试功能：

  * 点击“设置”，找到“关于设备”；
  * 点击设备的Android版本号，点击七次；
  * 此时设备将会出现“开发者选项”菜单；
  * 找到USB调试选项，并开启该选项；

工具安装

广大研究人员可以使用下列命令将该项目源码克隆至本地，或进行工具更新：

git clone https://github.com/ASHWIN990/ADB-Toolkit.git
cd ADB-Toolkit
sudo chmod +x install.sh
sudo ./install.sh -i "or" sudo bash install.sh -i

工具使用

广大研究人员可以直接使用下列命令运行ADB-Toolkit：

sudo ./ADB-Toolkit.sh

或者运行下列命令：

sudo bash ADB-Toolkit.sh
