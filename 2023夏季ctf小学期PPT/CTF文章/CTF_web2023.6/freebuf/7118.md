Frida安卓Hook实战

一、Adb下载与使用

adb连接mumu模拟器 adb connect 127.0.0.1:7555

启动 adb start-server

关闭 adb kill-server

安装apk adb install -r (APK路径)

卸载apk adb uninstall C:\\xx.apk

断开连接 adb disconnect 192.168.1.61

执行端口转发 adb forward tcp:27042 tcp:27042

Adb连接异常则执行adb nodaemon server

二、Frida安装与使用

pip install frida

pip install frida-tools

Frida版本需与frida-server版本一致

下载 frida-server-15.1.6-android-arm.xz版本

将下载到的frida-server安装包解压后重命名为frida-server放进手机data/local/tmp目录下

adb push frida-server /data/local/tmp/

adb shell

cd data/local/tmp

chmod 777 frida-server

./frida-server 注意，运行时一直无回显也不结束属于正常，新开另一cmd窗户即可

三、启动frida-server

连接mumu模拟器

adb connect 127.0.0.1:7555

进入指定目录启动frida-server

四、反编译代码分析

Jadx-gui打开apk文件

下载的apk，启动后界面如下

通过点击R/P/S显示不同的内容。DRAW/WIN/LOSE。即平局/赢/输

进行全文搜索定位如何控制输赢的代码，进行hook为本次实例的目的.

这3行处于同一文件，进入该文件

继续跟进this.showMessageTask

本次保障无论如何点击均会执行圈中的最后7行代码。需赋予m,n固定值。使得n-m!=1&m-n!=1&m!=n&m>=n.能满足该条件m-n>=2即可。所以m=2,n=0满足可执行else内代码

若执行if内代码，需要cnt=1000.在else中执行一次MainActivity.this.cnt++.所以cnt=999,可满足条件

此时打印出的值应为固定值。SECCON{(1000+7)*107}为SECCON{107749}

编写python脚本并运行后，成功hook

五、Python脚本编写

import frida, sys

def on_message(message, data):

if message['type'] == 'send':

print("[*] {0}".format(message['payload']))

else:

print(message)

jscode = """

Java.perform(function () {

var MainActivity = Java.use('com.example.seccon2015.rock_paper_scissors.MainActivity');

MainActivity.onClick.implementation = function (v) {

send("Hook Start...");

this.onClick(v);

this.n.value = 0;

this.m.value = 2;

this.cnt.value = 999;

console.log(this.calc())

send("Success!")

console.log("Success!")

}

});

"""

process = frida.get_remote_device().attach(4199)

script = process.create_script(jscode)

script.on('message', on_message)

script.load()

sys.stdin.read()

具体解析如下：

1》获知类的对象为com.example.seccon2015.rock_paper_scissors.MainActivity

所以，py脚本应包含如下：m=2,n=0,cnt=999.

2》查看mumu模拟器运行的应用程序进程为4199.

此时绑定远程进程process = frida.get_remote_device().attach(4199)

若是usb连接则为get_usb_device()

3》107749值由来。(MainActivity.this.cnt + MainActivity.this.calc()) * 107

Cnt=999+1=1000

MainActivity.this.calc()打印值为7

(1000 + 7) * 107=107749
