Proxmark3 Easy 如何流畅的在Linux中操作？
2022-07-13 10:32:46

前言

Hi~

Proxmark3 Easy可谓是国内能买到的比较便宜的RFID卡防设备了，曾在部分hv中出现。

Proxmark3 Easy是国内简化的一种设备，利用的是较早的Proxmark3的开源，基础的功能也能满足很多人，加上240-260左右的售价也较为亲民。


​国内买到Proxmark3的最好的途径也无非就淘宝的那几家屈指可数的店铺，但是网上所谓的售后服务比较好的店铺如“*达科技”，但是他们的售后也有点一言难尽的意思了。

分析

我们购买回来的Proxmark3，只能在我们的Windows系统使用Proxmark3 Easy Gui这款软件来控制，不能使用Linux，想通过树莓派等Linux环境去操作显然不太合适，并且新版本的软件也不能使用。

但是不得不说，Proxmark3 Easy Gui的软件挺符合国人的操作习惯的。

特别是低频读卡区，也非常方便，比现在的 Proxmark3 GUI好多了有没有。

当然啊，我们手中512K的Proxmark Easy的固件基本上是可以刷新版本的固件的，以方便在Linux中使用。

我们可以在这里进行下载一些较新的较为流行的固件 ↓

https://www.proxmarkbuilds.org/

注意：如果使用较为流行的固件，我们曾经的Proxmark3 Easy GUI的程序就无法使用了，但是刷老款固件可以解决这个问题。

使用箭头所指的推荐版本固件即可刷入到512K的Proxmark3 Easy上来使用最新的程序。

动手

Github不知道大家最近都能不能入呢！如果可以的话，推荐看github上的。

​在Release里找到最新的固件，下载，解压。

根据提示刷Pm3的固件，通常低版本的固件会需要先刷一次bootrom之后再刷全部（all）。

接着我们就可以使用Pm3.bat进行命令行控制了。

这里有请我的proxmark3 easy出场。

连上pm3，打开固件，就可以看到下面自检，就是正常的了。

那么有的人

就来问题了

我们linux怎么连接呢？

以kali linux举例，我们需要先通过apt安装软件proxmark3

apt install proxmark3

接着，将文件夹拖到Linux中，打开V0.2.5-win64-rrg_other-v4.14831\client中的pm3

需要先chmod +x pm3一下

然后./pm3即可运行

接着就像我们正常的命令行模式运行就行了，

下面给大家一些命令教程供大家学习（基础功能基本上都ok）

proxmark命令
说明
这里使用了4.1的冰人固件。
auto 自动识别
ID卡操作
lf search 读ID卡类型（主要）
lf search -u 寻找已知类型的低频卡
lf em 410x reader 读取卡号
[图片 33.jpg]
lf em 410x clone --id 0F0368568B 写T55x7 ID卡 lf em 410x clone --id 0F0368568B --q5 写Q5/T5555
hf 14a info 读卡信息
hf mf chk --1k 检测m1卡默认密码
hf mf rdsc --sec 0 -a -k FFFFFFFFFFFF
读取0块内容
hf mf nested --1k --blk 24 -a -k D3F7D3F7D3F7 nested攻击（已知密钥攻击，知一求全）
hf mf hardnested --blk 7 -a -k D3F7D3F7D3F7 --tblk 0 --tb
（hardnested攻击）知一求一（针对0块b区密码爆破，已知为7块a密码）
hf mf hardnested --blk 24 -b -k FFFFFFFFFFFF --tblk 0 --ta
（已知24块b求0块a）
hf mf darkside darkside攻击
hf mf csetuid --uid 0459AD2A --atqa 0004 --sak 08
设置UID卡参数
hf mf cwipe 擦除UID卡数据
hf mf cgetsc --sec 0
hf mf cgetsc --sec 1
读取UID卡内容（后面数字是分区）
hf mf csetblk --blk 60 -d 00000000000000000000000000000000
hf mf csetblk --blk 61 -d 00000000000000000000000000000000
hf mf csetblk --blk 62 -d 00000000000000000000000000000000
hf mf csetblk --blk 63 -d FFFFFFFFFFFF08778F00FFFFFFFFFFFF
写UID卡
hf mf wrbl --blk 63 -a -k D3F7D3F7D3F7 -d FFFFFFFFFFFF08778F00FFFFFFFFFFFF
写m1卡（加密s50） k是key，-a和-b来区分ab块，ab都要写，-d是内容（数据）blk是区域，从0-63共64个，共0-15个块，每个块4个区
hf mf wrbl --blk 63 -b -k FFFFFFFFFFFF -d FFFFFFFFFFFF08778F00FFFFFFFFFFFF
