密信云时间戳使用指南
2021-04-23 15:24:35

密信时间戳服务 采用国家授时中心权威时间源，由360安全云提供安全可靠的互联网基础设施和安全运行维护保障，遵循国际标准和国家标准，符合《密码法》和《电子签名法》对商用密码应用的法律要求，为全球用户提供了电子政务服务和电子商务服务所需的具有全球法律效力的时间戳服务，为各类电子数据、电子文件提供时间可信证明。


1.注册账号

打开网站https://www.mesign.com/zh-cn/tsa/index.html，选择“申请试用”或者“立即购买”，提交注册信息。


2.客服审核

注册完成后，在用户中心，我的订单中可以看到时间戳服务，请等待密信客服审核；


3.登录时间戳管理系统

审核完成后，我的订单中，请先下载“时间戳接口文档”，再点“管理”进入时间戳管理系统，


4.时间戳设置

进入时间戳管理系统，点击“设置管理”-“访问策略”，选择“IP地址”或者“Token码”方式。

IP 地址：设置 IP 后，用户可直接使用请求地址调用时间戳接口，适用于IP 地址固定的环境；

Token 码：用户根据 Token 码，组装请求 URL，然后使用该 URL 调用时间戳接口。适

用于 IP 地址会变化的环境；


5、API应用接口

密信提供完善的技术解决方案及标准的API应用接口，通过API接口轻松集成权威第三方时间戳服务，详细请参考“时间戳接口文档”。


更多内容可咨询官网https://www.mesign.com在线客服。
