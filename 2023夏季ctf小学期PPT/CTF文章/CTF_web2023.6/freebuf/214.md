Command Injection-黑盒测试
2023-04-01 12:40:17

Low级别：

1.根据输入框的提示，我们输入一个127.0.0.1点击Submit提交数据，可以看到返回信息和Win下CMD当中的ping命令一样

2.接着我们尝试拼接其他的命令

Win下命令拼接符号：

A&B A无论真假都会执行B
A&&B A执行成功才会执行B
A|B 直接执行B
A||B A执行失败才会执行B

当我们某一个拼接符被过滤时就可以换其他的

先使用&拼接一个systeminfo命令，可以看到拼接成功了，

Payload：127.0.0.1&systeminfo

3.此时我们就可以拼接一些其他的DOS命令来探测系统信息

ipconfig 查看内网ip

whoami 查看当前用户

query user 查看用户登陆情况

netstat -ano 查看端口情况

Medium级别：

1.首先还是先输入一个IP或域名测试，系统正常返回

2.此时我们使用&&进行拼接其他命令

Payload：127.0.0.1&&whoami

可以看到出错了，返回信息当中可以看到我们输入的&&被过滤了变成了127.0.0.1whoami因此没被识别

3.猜测它可能过滤了&&，拿我们就输入三个&&&

Payload：127.0.0.1&&&whoami

可以看到成功绕过了过滤，

此时我们可以继续测试其他的拼接符是否被过滤，或者直接使用&&&拼接上DOS命令即可


High级别：

1.输入www.baidu.com测试，可以看到正常返回信息

2.接着我们使用&拼接DOS命令测试

Payload：www.baidu.com&ipconfig

从返回信息中可以看到我们的&符号又被过滤，变成了www.baidu.comipconfig因此没有被识别

3.接着我们换一个使用&&&来拼接命令

A&&&B，

如果它只过滤1个&就变成A&&B，代表A执行成功才会执行B

如果它过滤2个&就变成A&B，代表无论A的真假都会执行B

如果它全部过滤了，那我们只能考虑换一个符号

Payload：www.baidu.com&&&ipconfig

可以看到依然被过滤了，说明这次可能是使用循环语句检测过滤的

4.我们再换一个使用|拼接，执行结构是

A|B 会直接执行B

Payload：127.0.0.1|ipconfig

可以看到成功的绕过了系统的过滤接着就可以拼接其他DOS命令探测系统了

因为|拼接的命令只会执行后面的所以，没有输出ping命令的返回结果，而是输出了ipconfig的返回结果
