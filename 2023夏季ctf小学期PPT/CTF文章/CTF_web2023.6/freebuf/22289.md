Burp2021.7安装遇到的问题（激活、汉化）
2021-07-29 09:18:04

环境配置

Java环境：https://repo.huaweicloud.com/java/jdk/

Burp 2021.7下载地址：https://portswigger.net/burp/releases

激活软件下载地址：https://github.com/h3110w0r1d-y/BurpLoaderKeygen/releases

汉化地址： https://github.com/h3110w0r1d-y/BurpLoaderKeygen/releases/download/2.0/BurpLoaderKeygenCn.jar

一、java的安装以及环境的配置。

1.先下载java文件。

2.双击下载的文件，选择安装路径。（D:\Program Files\Java）

3.配置环境变量。

配置jdk环境：
添加系统环境变量JAVA_HOME：D:\Program Files\Java\jdk-11.0.12
添加到Path: %JAVA_HOME%\bin。

4.验证是否安装成功。

二、burp2021.7的安装。

双击下载的exe可执行文件，选择安装路径。（D:\BurpSuitePro）

三、激活。

1.把下载的激活工具移动到burp安装的路径下。

2.双击jar，点击Run，burp运行。

3.把jar 中的Liscense内容复制到出现的窗口中，点击下一步。


4.点击NEXT,再次点击Mannal Activation（手工激活）。

5.选择copy request,复制到激活工具的Activation Request中，返回Activation Response值。

6.把Activation Response值再复制到burp中，点击Next。

7.激活成功。


四、burp 汉化。（Loader Keygen 汉化三合一，支持检测Burp更新，自动启动Burp）

觉得窗口适应的不太好。

五、遇到的问题。

1.抓包鼠标偏移的问题。

解决办法：

2.Java 环境问题。（a java exception has occurred）

解决办法：（1）检查环境变量是否配置成功。（2）java安装是否重复，或者javaw.exe版本不兼容https://www.cnblogs.com/jasy/p/14704456.html

3.一键启动脚本。

@echo off

start java --illegal-access=permit -Dfile.encoding=utf-8 -javaagent:BurpLoaderKeygenCn.jar=cn -noverify -jar burpsuite_pro.jar
