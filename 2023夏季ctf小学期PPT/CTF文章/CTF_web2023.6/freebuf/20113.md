2021年Linux威胁报告
2021-08-30 20:47:15

Linux 为当今的许多云基础架构提供支持。然而，它也不能免受威胁和风险的影响。

根据 W3Techs 的一项调查，世界 500 强超级计算机 100% 运行在 Linux 上，世界前 1000 名网站中有 50.5% 也使用 Linux。尽管 Linux 功能强大、通用且可靠，但也并非没有缺陷。与其他操作系统一样，它仍然容易受到攻击。

本文讨论了 2021 年上半年的 Linux 安全状况，并深入了解了 Linux 威胁形势。

无处不在的 Linux

Linux 用户占 Trend Micro Cloud One 企业客户的大多数，达到 61%，而 Windows 用户仅占 39%。

Red Hat 的发行版最受企业用户喜爱，其次是 AWS Linux 和 Ubuntu。其中大约 2.6% 是 IBM AIX 和 Oracle Solaris。众所周知，AIX 和 Oracle Solaris 以其稳定性和健壮性而著称。

Red Hat Enterprise Linux（RHEL）和 Amazon Linux AMI 通常首先为其支持的版本提供补丁。

暴露的系统

通过 Censys 的数据，截至 2021 年 7 月 6 日可搜索公网暴露的 Linux 操作系统接近 1400 万。

而查看 SSH 协议使用的 22 端口，互联网上有接近 1900 万设备开放了该端口。

一旦攻击者在 Linux 系统中立足，就会滥用这些端口发起恶意活动。

威胁检测

趋势科技基于数百万次的威胁检测进行数据分析。其中近 40% 的检测来自美国，其次是泰国（19%）和新加坡（14%）。

检测中发现，运行生命周期到达终止的 Linux 发行版的大多数（44%）都是 CentOS 7.4 到 7.9 版本，其次是 CloudLinux Server 占到 40%，Ubuntu 接近 7%。

OWASP TOP 10

Web 应用程序是最常见的攻击目标。Linux 系统中 76% 的攻击是基于 Web 的，而只有 24% 是非 Web 的。

OWASP 的 TOP 10 是非常重要的，最然总占比较低（21.22%），但非 TOP 10 较多的原因是暴力破解。

仅查看 OWASP 的 TOP 10 风险，XSS 攻击和往常一样多。反序列化漏洞则异常突出，命令注入的数量也高于预期。

在非 TOP 10 的风险中，暴力破解、目录遍历和请求 Smuggling 是最多的。

供应链安全

根据 Snyk 的报告，错误配置是云原生环境中的第二大事件类型。

2021 年 5 月 12 日，美国总统拜登签署了一项行政命令，以改善美国的网络安全并保护其联邦政府网络。行政命令第 4 节中详细介绍了软件供应链安全性的增强。

结论

Linux 是极其流行的，了解影响 Linux 的威胁以正确保护系统非常重要。作为云基础设施和物联网（IoT）不可或缺的一部分，Linux 的安全性必须得到重视。
