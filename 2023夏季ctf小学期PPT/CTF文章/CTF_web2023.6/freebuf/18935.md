int func()  #func()函数
{
  int result; // eax   #定义了result为整型
  char v1; // [rsp+0h] [rbp-30h]  #定义了v1为字符串型
  float v2; // [rsp+2Ch] [rbp-4h]  #定义了v2为浮点型

  v2 = 0.0;#v2赋值为0.0
  puts("Let's guess the number.");
  gets(&v1);#从stdin读取字符并放到v1所指向的地址中
  if ( v2 == 11.28125 )#如果v2等于11.28125 执行system函数读取flag
    result = system("cat /flag");
  else
    result = puts("Its value should be 11.28125");
  return result;
}


4、思路：

这题要想使函数执行system函数读取flag就要是的if判断v2 == 11.28125但是前面已经定义了变量v2的值为0.0。
在puts函数下面看到gets()函数，这里要很敏感gets()函数只有遇到换行符时，或者到达文件末尾时才会停止，但是这里的输入是我们可以控制的因此只要我们不输入换行符gets() 函数会无限制读取字符导致栈溢出。所以这题我们可以利用gets()函数使程序发生栈溢出修改v2指针的值为0x41348000（指针v2的值可以在ida中找到）
