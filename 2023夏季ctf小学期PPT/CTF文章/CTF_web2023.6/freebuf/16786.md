速查！Log4j高危漏洞，星阑API-Intelligence帮你全方位检测！
2021-12-10 19:37:21

12月10日消息，被全球广泛应用的组件Apache Log4j近日被曝出一个已存在在野利用的高危漏洞，攻击者仅需一段代码就可远程控制受害者服务器。不少行业都受到该漏洞影响，包括全球多家知名科技公司、电商网站等。


漏洞描述

Apache Log4j是一个基于Java的日志记录工具，Log4j 2是Log4j的升级产品。该组件存在Java JNDI注入漏洞，当程序将用户输入的数据进行日志，即可触发此漏洞，成功利用此漏洞可以在目标服务器上执行任意代码。

经专家研判，该漏洞影响范围极大，且利用方式十分简单，攻击者仅需向目标输入一段代码，不需要用户执行任何多余操作即可触发该漏洞，使攻击者可以远程控制用户受害者服务器，90%以上基于java开发的应用平台都会受到影响。

漏洞等级：

高危

影响版本：

Apache Log4j 2.x <= 2.14.1

据悉，Apache Log4j2 日志远程代码执行漏洞影响了所有Minecraft服务器。

解决方案：

通过星阑科技安全团队分析该漏洞利用成本极低危害极大，目前补丁可能存在被多次绕过的情况，受影响的企业可通过星阑科技安全技术支持通道及时获取最新检测方式、漏洞补丁和缓解措施。

1、Apache Log4j 2.x版本升级至2.15.0-rc2最新版本可修复

2、升级已知受影响的应用及组件，如 srping-boot-strater-log4j2 / Apache Solr / Apache Flink / Apache Druid

3、缓解措施：

① 修改jvm参数：Dlog4j2.formatMsgNoLookups=true

② 修改配置：log4j2.formatMsgNoLookups=True

③ 将系统环境变量：FORMAT_MESSAGES_PATTERN_DISABLE_LOOKUPS 设置为 true

目前星阑科技萤火产品已覆盖支持Apache Log4j2远程代码执行漏洞检测分析和攻击防护。已经购买使用星阑科技安全产品的用户，请联系相应的技术团队进行支持。
