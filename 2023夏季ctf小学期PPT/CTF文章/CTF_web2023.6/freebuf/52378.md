Adafruit 遭受 GitHub 数据泄露
2022-03-14 15:15:23


发生了什么？

先看来自 Adafruit 的公开报告：

无意泄露涉及用于员工培训的审计数据集在与学习数据分析的不活跃前员工帐户相关联的 GitHub 存储库上公开。该存储库包含一些姓名、电子邮件地址、送货/账单地址和/或订单是否通过信用卡处理器和/或 PayPal 成功下达，以及一些订单的详细信息。数据分析集中没有用户密码或信用卡等财务信息。


从公司通知的字里行间看，似乎泄露的数据已经公开存在了至少两年，因为暴露的数据库条目不会超过 2019 年。

（遗憾的是，报告没有说明泄露的数据是谁报告的、什么时候发现的、暴露的程度如何、相关的前员工何时离开公司、数据是从公司的实时数据中提取的，或者有多少涉及客户或记录。）

Adafruit 声称，它在听到问题后 15 分钟内删除了违规信息，联系了前雇员以删除数据，并开始分析以试图找出还有谁可能看到了它，以及他们可能会用它做什么。

从报告来看，专家分析的结果似乎没有定论——该公司无法确定数据是否被访问，但它确实评论说：“我们还不知道任何被实际滥用的信息”。

尽管如此，Adafruit 还是发布了提醒，此类违规行为确实为网络犯罪分子提供了强有力的借口。

该公司警告客户一定要注意明显的网络钓鱼活动，这些活动“警告”潜在的“受害者”采取纠正措施，例如通过一个随手提供但虚假的网站重置密码，以及声称提供“官方服务”的虚假呼叫者支持”并要求“确认”个人信息：

提醒一下，为了您的安全，作为安全警报的一部分，我们绝不会向您发送重置密码的链接，我们的客户支持团队绝不会联系您询问您的密码。如果您收到此类性质的电子邮件，或怀疑有人试图访问您的帐户或索取您的个人信息，或对此过程有任何其他疑问，请通过 security@adafruit.com 与我们联系。

如果网络钓鱼犯罪分子确实可以从公司数据库泄露中获得真实姓名、地址和订单详细信息，那么通过将真实历史数据包含为可信但虚假“证明”来证明他们的诈骗警告是真实的，他们的欺诈性电子邮件就会变得更加可信。

该怎么办？

  * 如果您是客户，并且您在 2020 年之前购买了任何 Adafruit 产品。请听从 Adafruit 系统的建议，并注意可能的网络钓鱼企图，这些企图试图通过据称因此违规行为而必须采取的“紧急行动”来吓唬您。
  * 如果您在自己的公司发生了违规行为。无论如何，请使用 Adafruit 的官方报告作为如何回应的部分示例，但请尝试在您的通知中包含一些 Adafruit 省略的内容。首先，真诚地道歉——毕竟，如果你不后悔，为什么客户会认为你现在比以前更关心他们的安全呢？其次，如果您已经进行或仍在进行法医分析，正如 Adafruit 声称的那样，请明确您已经发现的内容（包括承认您不知道且不太可能发现的内容），或提供日期您希望通过它跟进更多详细信息。
  * 如果您需要在实时系统之外使用测试或训练数据。不要为了这些目的而简单地浏览真实数据并将其分发到您的安全服务器之外。存在许多工具，既可用于编辑真实数据以使其在不泄露个人细节的情况下反映现实，也可用于生成适合训练的逼真但人工的数据。
  * 如果您被委托访问真实的公司数​​据。请勿将其复制或上传到公司官方位置以外的任何地方。尤其不要将其上传到个人云帐户，例如 GitHub 存储——即使你的动机是诚实的并且你的意图无可挑剔——公司无法履行自己的数据保护义务，也无法可靠地撤销你对它的访问权限如果你走。
