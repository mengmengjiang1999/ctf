02CVE-2021-21978

基本信息

编号：CVE-2021-21978

名称：VMware View Planner 代码问题漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-03-03

漏洞描述及危害

VMware View Planner是美国VMware公司的一个应用软件。提供了一种可捕获部署平台的整体可扩展性以及给定桌面内每个单独的应用程序操作性能的方法。VMware View Planner 4.x prior to 4.6 存在安全漏洞，该漏洞允许具有网络访问权的未经授权的攻击者可以上传和执行一个特别制作的文件，导致在logupload容器中远程执行代码。

影响范围

vmware:view_planner: 4.6

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://www.vmware.com/security/advisories/VMSA-2021-0003.html

03 CVE-2022-24260

基本信息

编号：CVE-2022-24260

名称：VoIPmonitor SQL注入漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2022-2-04

漏洞描述及危害

VoIPmonitor是VoIPmonitor团队的一个开源网络数据包嗅探器。具有用于在 Linux 上运行的 SIP RTP RTCP SKINNY(SCCP) MGCP WebRTC VoIP 协议的商业前端。Voipmonitor 存在SQL注入漏洞，该漏洞源于Voipmonitor GUI 中存在 SQL 注入漏洞，允许攻击者将权限提升到管理员级别。

影响范围

VoIPmonitor<v24.97

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://www.voipmonitor.org/changelog-gui?major=5

04CVE-2021-21234

基本信息

编号：CVE-2021-21234

名称：Lukashinsch Spring Boot Actuator Logview 路径遍历漏洞

等级：HIGH

CVSS：7.7

发布时间：2022-01-05

漏洞描述及危害

Lukashinsch Spring Boot Actuator Logview是Ffay（Lukashinsch）个人开发者的一个为Spring Boot提供通过Web界面查看日志功能的代码库。spring-boot-actuator-logview 0.2.13之前版本存在路径遍历漏洞，该漏洞源于filename参数未被检查。

影响范围

spring-boot-actuator-logview< 0.2.13

解决方案

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://github.com/lukashinsch/spring-boot-actuator-logview/commit/760acbb939a8d1f7d1a7dfcd51ca848eea04e772

05CVE-2021-21315

基本信息

编号：CVE-2021-21315

名称：Systeminformation 操作系统命令注入漏洞

等级：HIGH

CVSS：7.8

发布时间：2021-02-16

漏洞描述及危害

Systeminformation中存在操作系统命令注入漏洞，该漏洞源于外部输入数据构造操作系统可执行命令过程中，网络系统或产品未正确过滤其中的特殊字符、命令等。攻击者可利用该漏洞执行非法操作系统命令。

影响范围

Systeminformation < 5.3.1

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：https://github.com/sebhildebrandt/systeminformation/commit/07daa05fb06f24f96297abaa30c2ace8bfd8b525

06CVE-2021-26855

基本信息

编号：CVE-2021-26855

名称：Microsoft Exchange Server SSRF漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-03-02

漏洞描述及危害

Microsoft Exchange Server是美国微软（Microsoft）公司的一套电子邮件服务程序。它提供邮件存取、储存、转发，语音邮件，邮件过滤筛选等功能。Microsoft Exchange Server 安全漏洞。攻击者可构造恶意HTTP请求，并通过Exchange Server进行身份验证。进而扫描内网，获取用户敏感信息。

影响范围

Microsoft Exchange Server 2013 Cumulative Update 23

Microsoft Exchange Server 2019 Cumulative Update 7

Microsoft Exchange Server 2016 Cumulative Update 18

Microsoft Exchange Server 2016 Cumulative Update 19

Microsoft Exchange Server 2019 Cumulative Update 8

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。
