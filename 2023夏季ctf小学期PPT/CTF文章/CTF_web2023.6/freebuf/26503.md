Apache OFBiz rmi反序列化(CVE-2021-26295)复现
2021-03-25 13:47:15


一、漏洞描述

Apache OFBiz存在RMI反序列化前台命令执行，未经身份验证攻击者可构造恶意请求，触发反序列化，从而造成任意代码执行，控制服务器。

二、影响范围

Apache OFBiz：<17.12.06

三、环境搭建&漏洞复现

docker run -d -p 8000:8080 -p 8443:8443 opensourceknight/ofbiz
