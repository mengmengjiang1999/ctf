2022-05-26 11:26:22

当今网络不同以往，但永不消逝

随着网络中的一切都在向云上迁移，很多企业组织贸然断定传统网络必将因此消逝。然而，事实并非如此。更糟糕的是，对此深信不疑的企业组织正将自身置于危险之中。

毋庸置疑，与以往相比，当下的网络环境瞬息万变。数字化加速使得用户和设备能够在任意位置访问企业关键资源，彻底改变了企业的传统运营方式。然而，这并不意味着企业为了谋求安全一致的用户体验而必须彻底放弃固有网络。相反，全球各行各业的企业组织都在加速构建混合网络，以全面支持传统数据中心、企业园区与多云基础设施、SaaS平台、分支机构、家庭办公室以及移动用户和设备之间的互连互通。

IDC高级研究分析师Brandon Butler表示：“网络是实现安全、可扩展和高效使用云、边缘和物联网应用的基础。”因此，混合网络不仅不会消亡，更是数字化加速的有力推动者。混合网络可以实现应用程序和工作流端到端无缝切换，并支持任意用户或设备从任意物理位置的互联访问。

然而，企业组织应破除传统观念，不应再将网络和安全视为有效部署混合网络架构的单独策略。相反，安全防护数字化加速进程，要求基础设施和安全团队融合各自愿景，将二者合而为一。随着应用程序开启上云之旅，设备对每个人均越来越可见，网络安全对于这些域的高效互联而言至关重要。

要构建此类安全架构，所有规模的企业和服务提供商均应摒弃仅能在小范围网络内孤立运行的单点产品，转而部署在设计之初即能作为集成式架构组件运行的解决方案，该集成式架构还需具备全面可见性并能自适应不断扩展的网络环境。随着网络边缘和动态基础设施的不断迭代，单一用途或孤立的安全解决方案只会让组织面临更多挑战，难以部署和构建一个紧密集成且全面防护的安全体系。因此，企业组织亟需一个将运营效率和安全自动化与底层网络全面融合的平台方法。

业内首款，为全面保护当今混合网络而设计的安全平台

Fortinet Security Fabric是迄今业内独有、旨在全面保护和动态适应当今任意边缘混合网络的安全平台。作为该平台的强劲支撑，FortiOS 7.2助力企业组织将Fortinet Security Fabric安全组件覆盖至网络的每一个边缘，支持安全效能随着网络的迭代更新实现动态扩展与适应。这种广泛的集成方法还支持AI（人工智能）驱动的自动化功能，将源自全网以及全球威胁情报相互关联，以快速检测并实时响应最复杂的网络威胁。

FortiOS 7.2为网络和安全领域赋予全新定义，进一步强势赋能Security Fabric安全平台屡获殊荣的功能及服务，助力广大用户及合作伙伴在当今风起云涌的数字化市场破浪乘风，奋勇争先。现在及可预见的未来将是混合网络主宰的时代。唯有以安全为核心，混合网络才能行稳致远，更快速、更具规模地适应网络环境的不断演进，安全守护所有边缘环境。二十多年来，Fortinet始终聚焦有机研发，抓实契机，成为全球网络安全创新的持续领航者。当下，随着FortiOS 7.2全新版本的强势发布，Fortinet再破藩篱，奠定网络和安全融合解决方案新行业标准。

融合网络和安全关键功能的Fortinet Security Fabric

支持单点安全解决方案全面整合至统一安全平台

高性能AI驱动的威胁情报和支持服务

全新AI（人工智能）赋能的FortiGuard安全服务，助力企业组织实现安全系统自动化，实时提前预防前所未有的威胁攻击。作为最重要的增强功能之一，FortiOS 7.2支持协调一致的安全效能，精准、快速检测和预防各类威胁，高效保护企业组织不断扩展的攻击面。

传统而言，通过沙箱技术对可疑文件进行带外流量检测等性能密集型活动，会导致内容交付延迟，或在文件被感染后不得不在网内四处追踪恶意软件。FortiOS 7.2全新在线沙箱服务通过将传统的沙箱检测功能优化为实时防御技术，高效阻断已知和未知恶意软件威胁的同时，确保卓越用户体验及网络性能。同时支持全新在线CASB、IPS专用防护、适用于OT和IoT系统的高级设备保护，以及针对SOC服务组合的其他增强功能，为用户交付高级安全服务，全方位提升用户安全态势。由于这些技术服务在Fortinet Security Fabric安全平台和生态系统中作为订阅服务提供，支持实时主动更新，以确保企业持续运营，并简化网络扩展部署。

此外，Fortinet全新爆发检测服务包括自动识别和响应新兴威胁的即时警报和威胁狩猎脚本服务，支持更快速地检测和响应突然爆发的攻击。所有 FortiGuard支持服务均由可信赖的机器学习和人工智能驱动。FortiGuard全球威胁研究与响应实验室，每日分析全球现场生产环境中的安全事件超1000亿件，对这些海量数据高效、高质量处理对于防范安全威胁尤为关键。

网络与安全的关键融合

现代安全解决方案最基本的功能之一，便是其覆盖、扩展和适应不断演进的混合网络的能力。要实现这一功能的落地，需要网络与安全的高效融合。这种融合能够使安全系统无缝适应网络变化，满足网络环境不断演变的安全需求。然而，市面上鲜少有安全解决方案能够真正交付这一关键功能，这也是当下大多数企业组织所面临的挑战和困境。

Fortinet安全驱动网络互联是业内首款能够覆盖整个网络开发和部署生命周期的安全策略，可确保所有业务驱动型基础设施决策以安全防护为重。有了安全为核心，攻击面激增的新生网络边缘、应用和服务将自动得以保护。

FortiOS 7.2为用户交付融合网络和安全关键功能的全新方法，进一步增强Fortinet创新优势。全新ZTNA增强功能使WFA技术更易于部署。支持优化业内最全面的安全广域网边缘解决方案组合，如SD-WAN、SD-Branch、5G和ZTNA，帮助企业团队实现更佳投资回报率。采用全新自动化部署和零接触配置功能的先进自动化技术，进一步确保广域网和局域网边缘持续安全运行。NGFW、身份认证、微隔离、SASE、AIOps以及数字体验监控等技术的额外升级功能，为网络和安全进一步融合提供了强大的创新技术支撑。

坚实效能、可见性和安全控制筑牢统一安全防线

目前，采用最佳安全方法的企业组织面临着安全提供商的产品和解决方案不断叠加的无尽困扰。随着攻击面的不断扩大，除了高效融合网络和安全之外，企业组织亟须全面整合已部署的单点安全产品，打造兼具深度可见性、安全策略集中管理和编排的统一安全防线，实现威胁快速、自动检测及实时响应。

FortiOS 7.2为Fortinet所有网络、端点和云解决方案赋能增强优势，强效赋能Fortinet将单点安全产品全面整合至全面覆盖、深度集成及动态协同的单一管理平台。这种深度集成方法支持高级漏洞关联和虚拟补丁修复，为物联网设备和高级流程自动化提供更出色的安全性，助力NOC和SOC团队进一步简化和自动化其工作流，打造更卓越的全方位防护体系。

除了FortiOS系统的强劲支撑，Fortinet Security Fabric安全平台还围绕通用标准和开放式API而构建，助力企业组织全面整合其他安全技术投资，打造深度集成的网络安全网格架构。Fortinet Fabric-Ready技术联盟合作伙伴计划是业内最大的技术联盟生态系统之一，将全球资深技术合作伙伴汇聚一堂。与480多家以上的技术提供商合作伙伴鼎力协作，助力用户更轻松构建集成式、自动化解决方案的混合平台，为用户交付更高安全效能、更低组网复杂性，以及更简化管理的网络安全防护体系。

Fortinet行业领先地位赋能高级安全策略

Fortinet始终不变的创新承诺，催生了全面覆盖、深度集成的安全和网络融合解决方案组合。Fortinet拥有 1,255项已授予专利，专利数量领先同类网络安全公司近3倍。此外，Fortinet还定期将最新产品交付业内最知名的机构组织，进行公正的性能和有效性测试，始终斩获鼓舞人心的测评结果。凭借一贯的骄人业绩，加之连续多年获得业内优秀分析师及行业组织的权威认可和各项殊荣，以及全球各地研发团队对创新与技术投入的坚定承诺，Fortinet采用网络和安全融合创新方法，帮助企业构建协调一致的安全体系，彻底摆脱性能表现和安全效能二选一的两难窘境。
