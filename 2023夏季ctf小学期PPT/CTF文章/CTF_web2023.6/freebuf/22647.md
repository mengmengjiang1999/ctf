华为首次发布HarmonyOS职业认证，助力开发者实现职业进阶
2021-07-16 13:36:35

自HarmonyOS发布以来，越来越多企业加入并持续建设鸿蒙应用及硬件生态，同时也催生了相关产业对HarmonyOS人才需求的井喷式增长。7月16日，华为在HarmonyOS Connect伙伴峰会重庆站首次发布了HarmonyOS职业认证，为鸿蒙生态开发者、企业工程师、院校学生提供更广阔、清晰的职业发展路径，也为产业带来源源不断的人才输送。

HarmonyOS职业认证基于华为成熟的人才培训与认证体系，从低到高分为工程师（HCIA）、高级工程师（HCIP）、专家（HCIE）三个级别，分为应用开发和设备开发两个方向，开发者可根据自身需求选取相应的认证方向。

目前，面向工程师级的HCIA-HarmonyOS认证已正式发布，后续将逐步深入提供高级工程师（HCIP）以及专家（HCIE）级别的HarmonyOS职业认证。

HCIA-HarmonyOS认证——培养HarmonyOS应用与设备开发领域工程师

本次发布的HCIA-HarmonyOS认证包括HCIA-HarmonyOS Application Developer V1.0与HCIA-HarmonyOS Device Developer V1.0，分别定位于培养HarmonyOS应用与设备开发领域具备专业知识和技能水平的工程师。

HCIA-HarmonyOS Application Developer V1.0认证包括HarmonyOS应用开发的基础知识（如：系统架构、分布式特性等）、HarmonyOS布局设计与开发（如：Ability、UI设计与开发等）、HarmonyOS应用功能设计与开发（如：线程管理、数据管理、网络管理、日志管理、AI等）、HarmonyOS应用调测与发布等知识技能。

而HCIA-HarmonyOS Device Developer V1.0认证包括HarmonyOS设备开发基础知识（如：系统架构、分布式特性等）、HarmonyOS设备功能开发与调测（如：内核基础功能、HDF驱动框架、子系统与组件模块、功能调测等）、HarmonyOS移植等知识技能。

开发者通过HCIA-HarmonyOS Application Developer V1.0与HCIA-HarmonyOS Device Developer V1.0两个认证，可证明其已系统地理解并掌握HarmonyOS应用开发或设备开发基础知识，有能力胜任HarmonyOS应用开发或设备开发工程师、产品经理、项目经理、软件或嵌入式软件开发工程师、售前工程师、售后工程师等岗位。

从怎么学、怎么考到怎么用，全流程助力开发者实现职业进阶

对于想要通过HCIA-HarmonyOS职业认证的开发者，华为还将提供从学习、报考到就业等全流程服务，助力开发者实现职业进阶。

怎么学：华为提供了权威的官方教学资源，同时授权培训合作伙伴(HALP)，双管齐下帮助开发者精进学习。其中官方教学资源包括认证考试、认证培训教材、学员用书、在线学习课程、认证试验手册以及实验环境搭建指南等，开发者通过官方资料的学习，能够快速夯实HarmonyOS开发基础。华为也授权培训合作伙伴(HALP)，面向公众提供学习规划、认证培训、联合学习解决方案等服务，培养符合华为产业链需求的人才，开发者可以更加系统有效地进行HarmonyOS职业认证备考。开发者可根据自身能力水平及相应需求选取适合自己的学习方式。

怎么考：目前HCIA-HarmonyOS认证笔试考试平台为Pearson | VUE，开发者只需在该平台注册并预约考试，支付考试费用就能参加考试，考试通过的开发者即可获取华为官方认证的HCIA-HarmonyOS证书。

怎么用：对于成功获得HarmonyOS职业认证的开发者，华为将通过线上人才双选平台、线下ICT人才联盟双选会两大渠道，帮助开发者直通华为产业伙伴，实现快速就业。仅2020年，华为就开设了52场线上线下人才双选会，吸引了中国区800家生态伙伴、超过12000名高校学子参加，达成就业意向2000多个。

目前，HarmonyOS职业认证已正式发布，感兴趣的开发者可登陆华为人才在线官网：https://e.huawei.com/cn/talent了解认证信息、获取备考材料、进行考试预约，更多HCIA-HarmonyOS认证资讯、考试政策也可关注华为认证微信公众号。
