华云安漏洞安全周报【第61期】
2021-12-02 18:31:22

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 11.22~2021.11.28）CNNVD接报漏洞463，信息技术产品漏洞（通用型漏洞）127个，网络信息系统漏洞（事件型漏洞）336个；CNNVD接报漏洞预警92份，其中华云安报送预警6个，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2021-41277-Metabase 任意文件读取漏洞、CVE-2021-42321-Microsoft Exchange Server 远程代码执行漏洞、CVE-2021-21980-VMware vCenter Server 任意文件读取漏洞、CVE-2021-44140-Apache JSPWiki 访问控制错误漏洞、CVE-2021-40369-Apache JSPWiki 跨站脚本漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

CVE-2021-41277-Metabase 任意文件读取漏洞

高危

2021年11月22日，华云安思境安全团队发现 Github 披露了 Metabase 组件中存在一处任意文件读取漏洞。Metabase 是一个开源的数据分析平台，通过给公司成员提问，从得到的数据中进行分析、学习。该漏洞源于产品的 admin-＞settings-＞maps-＞custom maps-＞add a map 操作缺少权限验证，成功利用此漏洞的攻击者能够读取任意文件从而获得敏感信息。

https://github.com/metabase/metabase/security/advisories/GHSA-w73v-6p7p-fpfr

CVE-2021-42321-Microsoft Exchange Server 远程代码执行漏洞

高危

2021年11月22日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Microsoft Exchange Server 组件中存在一处远程代码执行漏洞。Microsoft Exchange Server 是一套电子邮件服务程序，它提供邮件存取、储存、转发，语音邮件，邮件过滤筛选等功能。成功利用此漏洞的攻击者在经过身份验证的前提下，可在 Exchange Server 上执行任意代码。目前该漏洞相关 poc 已公开。

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42321

CVE-2021-21980-VMware vCenter Server 任意文件读取漏洞
高危

2021年11月25日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware vCenter Server 组件中存在一处任意文件读取漏洞。VMware vCenter Server 是一套服务器和虚拟化管理软件，该软件提供了一个用于管理 VMware vSphere 环境的集中式平台，可自动实施和交付虚拟基础架构。该漏洞源于网络系统或产品未能正确地过滤资源或文件路径中的特殊元素，成功利用此漏洞的攻击者可访问受限目录之外的位置，从而获取敏感信息。

https://www.vmware.com/security/advisories/VMSA-2021-0027.html

CVE-2021-44140-Apache JSPWiki 访问控制错误漏洞
超危

2021年11月25日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache JSPWiki 组件中存在一处访问控制错误漏洞。Apache JSPWiki 是一款基于 Java、Servlet 和 JSP 构建的开源 WikiWiki 引擎。成功利用此漏洞的远程攻击者可在注销时凭借精心构造的 http 请求删除托管 JSPWiki 实例的系统中的任意文件。

https://lists.apache.org/thread/5qglpjdhvobppx7j550lf1sk28f6011t

CVE-2021-40369-Apache JSPWiki 跨站脚本漏洞
中危

2021年11月25日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache JSPWiki 组件中存在一处跨站脚本漏洞。Apache JSPWiki 是一款基于 Java、Servlet 和 JSP 构建的开源 WikiWiki 引擎。该漏洞源于精心构造的插件链接调用可能会在 Apache JSPWiki 上触发与 Denounce 插件相关的 XSS 漏洞，成功利用此漏洞的攻击者通过在受害者的浏览器中执行 javascript 从而获取敏感信息。

https://lists.apache.org/thread.html/rc9400a70d0ec5cdb8a3486fc5ddb0b5282961c0b63e764abfbcb9f5d%40%3Cdev.druid.apache.org%3E
