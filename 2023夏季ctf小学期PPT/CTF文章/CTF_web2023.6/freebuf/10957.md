华云安漏洞安全周报【第87期】
2022-06-13 10:44:31

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.5.30~2022.6.5）CNNVD接报漏洞197个，信息技术产品漏洞（通用型漏洞）39个，网络信息系统漏洞（事件型漏洞）158个；CNNVD接报漏洞预警108份，其中华云安报送预警11份，预警报送数量持续位列第三！

本周重点关注漏洞包括：CVE-2022-30190-Microsoft MSDT 代码执行漏洞、CVE-2022-31741-Mozilla Firefox 安全漏洞、CVE-2022-31740-Mozilla Firefox 缓冲区溢出漏洞、CVE-2022-24848-DHIS2 SQL 注入漏洞、CVE-2022-26134-Confluence OGNL 注入漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-30190-Microsoft MSDT 代码执行漏洞

威胁等级：高危

漏洞描述：

2022年5月30日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Microsoft MSDT 组件中存在一处代码执行漏洞。MSDT （Microsoft Support Diagnostics Tool，微软支持诊断工具）是一种实用程序，用于排除故障并收集诊断数据以供专业人员分析和解决问题。该漏洞是由于 Word 等调用应用程序使用 URL 协议调用 MSDT 时引起，成功利用该漏洞的攻击者可以使用调用应用程序的权限运行任意代码，并在用户权限允许的范围内进行增删改。

情报来源：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2022-30190

02CVE-2022-31741- Mozilla Firefox 安全漏洞

威胁等级：高危

漏洞描述：

2022年5月31日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Mozilla 组件中存在一处安全漏洞。Mozilla Firefox 是一款开源 Web 浏览器。该漏洞是由于未对变量进行初始化引起，成功利用此漏洞的攻击者通过发送恶意制作的 CMS 消息，导致无效的内存读取。

情报来源：

https://www.mozilla.org/en-US/security/advisories/

03CVE-2022-31740- Mozilla Firefox 缓冲区溢出漏洞

威胁等级：高危

漏洞描述：

2022年5月31日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Mozilla 组件中存在一处缓冲区溢出漏洞。Mozilla Firefox 是一款开源 Web 浏览器。该漏洞是由于 arm64 上 WASM 中与寄存器分配出现边界错误引起，成功利用此漏洞的攻击者可触发缓冲区溢出。

情报来源：

https://www.mozilla.org/en-US/security/advisories/

04CVE-2022-24848-DHIS2 SQL 注入漏洞

威胁等级：高危

漏洞描述：

2022年6月1日，华云安思境安全团队发现研究人员公开披露了 DHIS2 组件中存在一处 SQL 注入漏洞。DHIS2 是一种用于收集、验证、分析和呈现汇总和基于患者的统计数据的工具，为综合健康信息管理活动量身定制。该漏洞是由于 API 中存在对特殊元素的不当使用缺陷引起，成功利用此漏洞的攻击者可执行任意 SQL 命令。

情报来源：

https://github.com/dhis2/dhis2-core/security/advisories/GHSA-52vp-f7hj-cj92

05CVE-2022-26134-Confluence OGNL 注入漏洞

威胁等级：超危

漏洞描述：

2022年6月2日，华云安思境安全团队发现 Atlassian 官方发布安全更新，披露了 Confluence 组件中存在一处 OGNL 注入漏洞。Confluence 是 Atlassian 公司开发的一款专业的企业知识管理与协同软件，常用于构建企业 wiki。该漏洞是由于对用户发送的请求未进行合理的验证引起，成功利用此漏洞的攻击者在未经身份验证的情况下通过发送恶意制作的 Web 请求，从而在 Confluence Server 或 Data Center 实例上执行任意代码。

情报来源：

https://confluence.atlassian.com/doc/confluence-security-advisory-2022-06-02-1130377146.html
