记录3道遇到的比较有意思的CTF题

“ping命令”

先看第一道题 “ping命令”

提示信息是，可以利用分号结束命令

打开传送门页面没有什么提示信息

传个参试试

?url=www.baidu.com

可以看到页面回显了ping www.baidu.com后的一些数据

PING www.baidu.com (14.215.177.39): 56 data bytes 64 bytes from 14.215.177.39: seq=0 ttl=52 time=16.953 ms 64 bytes from 14.215.177.39: seq=1 ttl=52 time=16.249 ms 64 bytes from 14.215.177.39: seq=2 ttl=52 time=16.748 ms 64 bytes from 14.215.177.39: seq=3 ttl=52 time=16.684 ms --- www.baidu.com ping statistics --- 4 packets transmitted, 4 packets received, 0% packet loss round-trip min/avg/max = 16.249/16.658/16.953 ms

按照之前做这个系列的CTF题的套路，大概已经可以猜到，主要就是利用命令执行去读取flag文件获取flag值就可以了

但是要怎么绕过 ping命令的固定执行 是个问题

https://blog.csdn.net/stpeace/article/details/51870812

了解到Linux命令中 分号可以将多条命令进行分割执行

构建payload测试一下

?url=www.baidu.com;ls

可以看到 ls命令确实生效了，查看到了flag所在的文件名

flag.php

现在我们读取出flag.php的内容就可以获得flag了

构建payload读取一下flag.php文件

?url=www.baidu.com;cat flag.php

提示非法字符，看来过滤了cat flag.php中的字符

?url=www.baidu.com;cat index.php

测试这个payload还是同样的提示，试试其他的和cat功能差不多的命令

rev 
​
more
​
tailf
​
head
​
tail
​
tac

发现都不可行，看来只能从cat命令的修改上做一些文章~

https://www.cnblogs.com/ZoeyCLM/p/10412170.html

发现在命令中添加反斜杠 \ ，不会影响命令的执行

构建payload

?url=www.baidu.com;ca\t flag.php

看来flag.php也被过滤了

不过这里我们可以利用Linux命令的通配符 问号来代替文件名

????.???

构建payload

?url=www.baidu.com;ca\t ????.???

终于过了，成功打到了flag

"2048"

还有一道比较有意思的题目，是一个比较有名的游戏”2048“

这道题的解法很简单，但是感觉也是一道比较有意思的题目。

这是题目界面

提示我们需要合成2048才能获取flag

我的思路是直接检查元素查看源码

直接修改格子中的值，改成2048

修改后再任意按下 WASD键就获取到flag了

”汉字解密“

还有一道汉字解密题，当时想了很久都没有什么头绪

试过了utf-8以及gbk编码

这是题目的样子，意思很明确

flag是”皎若云间月“这句话的一段汉字编码

但是下面还有一个0a，印象中0a代表16进制

一开始是以为是直接将汉字16进制编码

转码后的结果提交后，发现不行

后来发现是一个组合编码先进行gbk的编码

然后再16进制编码

flag:

6630613863386634643463366263653464346332
