华云安漏洞安全周报【第63期】
2021-12-17 09:52:35

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 12.6~2021.12.12）CNNVD接报漏洞412个，其中信息技术产品漏洞（通用型漏洞）154个，网络信息系统漏洞（事件型漏洞）258个；CNNVD接报漏洞预警65份，其中华云安报送预警4个，预警报送数量持续位居前列！


本周重点关注漏洞包括：CVE-2021-44077-Zoho ManageEngine ServiceDesk Plus 认证绕过漏洞、CVE-2021-43936-Distributed Data Systems WebHMI 文件上传漏洞、CVE-2021-43931-Distributed Data Systems WebHMI 身份验证绕过漏洞、CVE-2021-43798-Grafana 目录遍历漏洞、Apache Log4j 2 远程代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。


超危

CVE-2021-44077-Zoho ManageEngine ServiceDesk Plus 认证绕过漏洞

2021年12月6日，华云安思境安全团队发现 ManageEngine 官方发布安全更新，披露了 ManageEngine ServiceDesk Plus 和 ManageEngine ServiceDesk Plus MSP 两个组件中存在一处认证绕过漏洞。ZOHO ManageEngine ServiceDesk Plus（SDP）是一套基于 ITIL 架构的 IT 服务管理软件，该软件集成了事件管理、问题管理、资产管理 IT 项目管理、采购与合同管理等功能模块。该漏洞是由于 ServiceDesk Plus 中使用了不正确的安全配置过程，这将允许攻击者通过其应用程序的一些 URL 获得对应用程序数据的未授权访问。成功利用此漏洞的攻击者可以上传可执行文件并放置 webshell 。

https://pitstop.manageengine.com/portal/en/community/topic/security-advisory-authentication-bypass-vulnerability-in-servicedesk-plus-versions-11138-and-above



超危

CVE-2021-43936-Distributed Data Systems WebHMI 文件上传漏洞

2021年12月6日，华云安思境安全团队监测发现 Distributed Data Systems（分布式数据系统）的 WebHmi 组件中存在一处文件上传漏洞。Distributed Data Systems WebHmi 是一个带有内置网络服务器的 Scada 系统，用于通过计算机和移动设备监视和控制本地网络上以及通过 Internet 的任何自动化系统。该漏洞是由于产品未对上传文件类型进行有效验证，成功利用此漏洞的攻击者可通过上传恶意文件执行任意代码攻击。

https://us-cert.cisa.gov/ics/advisories/icsa-21-336-03


超危

CVE-2021-43931-Distributed Data Systems WebHMI 身份验证绕过漏洞

2021年12月6日，华云安思境安全团队监测发现 Distributed Data Systems（分布式数据系统）的 WebHmi 组件中存在一处身份验证绕过漏洞。该漏洞是由于分布式数据系统 WebHmi 中存在认证错误，成功利用此漏洞的攻击者可以以管理员账户登录并且不需要经过身份验证，从而执行远程代码攻击。

https://us-cert.cisa.gov/ics/advisories/icsa-21-336-03


高危

CVE-2021-43798-Grafana 目录遍历漏洞

2021年12月7日，华云安思境安全团队发现 Grafana 官方发布安全更新，披露了 Grafana 组件中存在一处目录遍历漏洞。Grafana 是一款用 Go 语言开发的开源数据可视化工具，该工具主要用于监控和分析 Graphite、InfluxDB 和 Prometheus 等。成功利用此漏洞的攻击者可以执行目录遍历攻击，从而访问本地文件。

https://grafana.com/blog/2021/12/07/grafana-8.3.1-8.2.7-8.1.8-and-8.0.7-released-with-high-severity-security-fix/


超危

Apache Log4j 2 远程代码执行漏洞

2021年12月9日，华云安思境安全团队监测发现 Apache Log4j2 组件中存在一处远程代码执行漏洞。Apache Log4j2 是一款 Java 日志框架，是 Log4j 的升级版，可以控制每一条日志的输出格式。由于其易用性被广泛集成于各种服务器和组件中。该漏洞是由于 Apache Log4j2 某些功能存在递归解析功能，成功利用此漏洞的攻击者在未授权的情况下，通过构造恶意数据执行远程代码攻击。

https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc2
