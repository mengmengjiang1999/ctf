不能在import引用的脚本中执行。一个python文件通常有两种使用方法，第一是作为脚本直接执行，第二是 import 到其他的 python 脚本中被调用（模块重用）执行。因此 if name== 'main': 的作用就是控制这两种情况执行代码的过程，在 if name== 'main': 下的代码只有在第一种情况下
