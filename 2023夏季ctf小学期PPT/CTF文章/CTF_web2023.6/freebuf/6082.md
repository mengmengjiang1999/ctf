搭建vulfocus漏洞平台

vulfocus 本质上是一个漏洞集成平台，里面集成了大量的CVE漏洞环境，采用的是docker环境部署安装，使用起来方便，可作为一个优秀靶场环境，提升实战能力。可本地部署安装，也可以直接使用线上环境。
Vulfocus 官网：https://fofapro.github.io/vulfocus/
在线 Vulfocus：

http://vulfocus.fofa.so/

    http://vulfocus.io/

    http://vulfocus.club/


1.安装docker环境

1.执行安装命令：apt install docker.io

2.查看是否安装成功：dockers -v

2.拉取vulfocus镜像

执行命令：docker pull vulfocus/vulfocus:latest

3.运行vulfocus

1.创建容器
docker create -p 80:80 -v /var/run/docker.sock:/var/run/docker.sock -e VUL_IP=服务器ip vulfocus/vulfocus

默认密码admin/admin

2.启动容器
docker start *** （创建容器返回的长串）

3.停止容器
docker stop *** （创建容器返回的长串）
或停止所有
docker stop $(docker ps -a -q)

4.删除容器
docker rm *** （创建容器返回的长串）
或删除所有
docker rm $(docker ps -a -q)

4.访问页面

http://ip:80

默认密码;admin/admin
