华云安漏洞安全周报【第88期】
2022-06-20 11:15:40

根据国家信息安全漏洞库(CNNVD)统计，本周（2022.6.6~2022.6.12）CNNVD接报漏洞329个，信息技术产品漏洞（通用型漏洞）137个，网络信息系统漏洞（事件型漏洞）192个。

本周重点关注漏洞包括：CVE-2022-26377-Apache HTTP 请求走私漏洞、CVE-2022-31625-PHP 代码执行漏洞、CVE-2022-31626-PHP 代码执行漏洞、CVE-2022-32563-Couchbase 权限提升漏洞、CVE-2021-37404-Apache Hadoop 缓冲区溢出漏洞。

01CVE-2022-26377-Apache HTTP 请求走私漏洞

威胁等级：中危

漏洞描述：

2022年6月8日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache HTTP 组件中存在一处请求走私漏洞。Apache HTTP Server 是 Apache的一个开放源代码的网页服务器。该漏洞是由于 Apache HTTP Server的mod_proxy_ajp 中的 HTTP 请求解释不一致引起，成功利用此漏洞的攻击者可将请求走私到它转发请求的 AJP 服务器。

情报来源：

https://httpd.apache.org/security/vulnerabilities_24.html

02CVE-2022-31625-PHP 代码执行漏洞

威胁等级：高危

漏洞描述：

2022年6月9日，华云安思境安全团队发现 PHP 官方发布安全更新，披露了 PHP 组件中存在一处代码执行漏洞。PHP（PHP: Hypertext Preprocessor） 即“超文本预处理器”，是在服务器端执行的脚本语言，尤其适用于 Web 开发并可嵌入 HTML 中。该漏洞是由于 PHP_FUNCTION 分配在堆上的 char* 数组没有被清除引起，成功利用此漏洞的攻击者通过其错误转化调用 _php_pgsql_free_params() 函数，从而使缺乏初始化的数组释放之前请求的值，导致代码执行。

情报来源：

https://bugs.php.net/bug.php?id=81720

03 CVE-2022-31626-PHP 代码执行漏洞

威胁等级：高危

漏洞描述：

2022年6月9日，华云安思境安全团队发现 PHP 官方发布安全更新，披露了 PHP 组件中存在一处代码执行漏洞。PHP（PHP: Hypertext Preprocessor）即“超文本预处理器”，是在服务器端执行的脚本语言，尤其适用于 Web 开发并可嵌入 HTML 中。该漏洞是由于服务器对用户输入未进行合理验证引起，成功利用此漏洞的攻击者通过连接 php 连接数据库的权限建立恶意 MySQL 服务器并使受害主机通过 mysqlnd 主动连接该服务器，从而触发缓冲区溢出，导致拒绝服务或远程执行代码。

情报来源：

https://bugs.php.net/bug.php?id=81719

04CVE-2022-32563-Couchbase 权限提升漏洞

威胁等级：超危

漏洞描述：

2022年6月10日，华云安思境安全团队发现 Couchbase 官方发布安全更新，披露了 Couchbase 组件中存在一处权限提升漏洞。Couchbase 是用于企业应用程序的现代 NoSQL 云数据库。该漏洞是由于对 Couchbase 服务器身份验证时不会验证管理员凭证引起，成功利用此漏洞的攻击者在未经身份验证的情况下通过 Admin REST API 的管理员凭据被忽略，从而实现权限提升。

情报来源：

https://www.couchbase.com/alerts

05CVE-2021-37404-Apache Hadoop 缓冲区溢出漏洞

威胁等级：高危

漏洞描述：

2022年6月11日，华云安思境安全团队发现研究人员披露了 Apache Hadoop 组件中存在一处缓冲区溢出漏洞。Apache Hadoop 是一套用于在由通用硬件构建的大型集群上运行应用程序的框架。该漏洞是由于 libhdfs native 出现边界错误引起，成功利用此漏洞的攻击者在未经验证的情况下通过打开用户提供的文件路径，导致拒绝服务或代码执行。

情报来源：

https://www.mail-archive.com/announce@apache.org/msg07374.html
