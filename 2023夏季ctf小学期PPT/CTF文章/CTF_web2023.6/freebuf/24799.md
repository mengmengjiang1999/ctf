开发者活动预告 | Algorand 无国界金融区块链黑客松
2021-05-10 14:51:55

​​由 Algorand 基金会主办的区块链黑客松正式上线啦！

区块链技术虽然已经发展了十年有余，但仍然是一个新兴的技术领域。对很多开发者来说，区块链这个名次依然显得陌生。区块链是什么，它能用来干什么，这两个问题阻拦了很多对新技术有兴趣的开发者们进入这个领域。


本次比赛旨在为国内更多的开发者提供一个了解和学习区块链技术的机会，让更多人能够进入区块链技术这一新兴领域。


本次比赛是由 Algorand 基金会和力扣联合主办的区块链黑客松竞赛，Algorand 基金会将提供比赛奖金以及免费技术培训，助力开发者们学习区块链技术，并以比赛的形式让开发者们能够发挥自己的创造力，迈入区块链这一领域。

比赛日程

05/01 比赛报名开始

05/16 比赛报名截止；作品提交开放

05/22-05/23 Algorand 区块链技术培训 1-2

05/29-05/30 Algorand 区块链技术培训 3-4

06/16 提交作品截止

06/20 比赛结果公布

​

奖品设置

第1名：5,000 ALGO (价值 5万元人民币)

2-3名：3,000 ALGO (价值 3万元人民币)

4-6名：1,000 ALGO (价值 1万元人民币)

7-10名：250 ALGO (价值 2500元人民币)

以上所有获奖者将额外获得 Algorand 基金会创业基金的投资机会以及海外初创公司实习机会。

参与奖：所有其他完成作品但未获奖的参赛队伍也将获得 Algorand Foundation 提供的周边产品礼包。

​

比赛报名

本次黑客松比赛以组队赛形式进行。每个队伍需要有3-5名成员报名参加，并且由队长提供队伍和队员相关信息。

报名页面：https://e.leetcode-cn.com/contest/landing/hackathon/algorand-0001/

想要订阅赛程，加入比赛社群，或者获取培训信息和技术支持，请关注“Algorand中文”公众号并回复“黑客松”。

​

作品提交

  * 参赛团队需要在6月17日00:00之前通过本网站的作品提交通道完成作品提交
  * 作品提交内容分为项目代码和项目介绍两个部分
  * 项目代码：参赛团队需要提交存储有项目代码的 Github 项目仓库链接；项目需要有 Readme 文件，内容包括：战队名称，项目名称以及进行项目部署和运行的必需介绍和描述
  * 项目介绍文件：参赛团队需能够充分展示创意和设计实现的项目介绍文件链接；项目介绍文件形式可以选择视频，文档，演示文稿三者的一个或多个；项目介绍文件需要上传至 Github 或其他网络存储服务保存，并在作品提交时提交相关链接
  * 请参赛团队自行保证提交作品的完整性，如项目代码是否能够正常运行，或者项目介绍文件能否正常阅览或下载
  * 主办方将在收到提交的作品后对各参赛团队进行反馈，但不会校验作品的完整性以及提供作品评审相关的信息

​

黑客松挑战主题

本次黑客松比赛提供三个挑战主题供参赛队伍选择：

 1. 数字货币与社交网络
 2. 基于区块链的虚拟物品交易平台
 3. 去中心化金融产品

*了解关于挑战主题的详细解析，请关注"Algorand中文“公众号，后台回复关键词“黑客松”获取

​

大赛规则

本次 Algorand 中国黑客松为开放命题比赛，参赛团队需要从提供的三个大赛主题中选择一个进行项目设计和开发。

大赛从5月1日起开放报名，5月16日报名截止并开放作品提交通道；6月16日作品提交通道关闭并由主办方进行评审；6月20日左右将公布最终获奖名单。

大赛主办方将为参赛者提供免费的线上 Algorand 区块链技术培训，相关信息将在报名结束后发送给所有参赛者，也请参赛者们关注主办方公众号并加入社群了解最新动态。

参赛作品需基于 Algorand 官方测试网；使用其他区块链技术平台的作品将不参于评审；Algorand 平台提供 Java，Javascript，Python，Golang 等多种语言的 SDK 和开发工具供参赛者使用，培训中我们也将介绍这些开发工具的使用方法，并给出完整的项目示例。

报名成功后参赛队伍信息将无法变更；未在指定时间进行报名的队伍依然可以提交作品参与评选，但无法获取主办方推送的大赛相关信息；请关注主办方公众号并加入社群了解最新动态。

作品评审不设固定评审分数，主办方将基于作品的创意，完成度，作品是否贴合主题，以及是否充分利用了 Algorand 平台的特性和工具等方面进行评审。

​

​

补充说明

本次大赛为技术创意大赛，所使用的开发平台为 Algorand 测试网，该网络上的所有数字货币均为无实际价值的开发测试用虚拟物品

大赛奖励为 Algorand 主网络上的基础数字货币 ALGO，上述参考人民币价值为基于该比赛发布时的市场价格计算得出，主办方不对该奖品的实际价值做出保证，并且不承担相关责任。

大赛奖励将在大赛结束后的15个工作日内发放到战队提交作品时填写的钱包地址中；对于案件的奖励分配由队伍自行决定，主办方不做干涉；获得奖励后的队伍可自行决定奖品的使用方法，主办方不做干涉，并且不承担相关责任。

主办方将对大赛中的违规行为做出处理，并有参赛团队自行承担责任；违规行为包括但不限于

  * 提交错误信息
  * 多次提交相同信息
  * 抄袭他人作品
  * 一人参与多个战队

本次大赛由 Algorand 基金会主办，最终解释权归 Algorand Foundation (HK) Limited 官方所有。
