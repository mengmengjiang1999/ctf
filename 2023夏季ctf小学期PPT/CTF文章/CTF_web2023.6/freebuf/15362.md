微信小程序的反编译
2022-02-15 16:15:53

在对于目标是小程序时，反编译是一个非常好用的技巧。

########如果写的不够好和清楚请多多包涵；如果文章书写有错误请在评论中指出########

一、反编译的总体思路

手机访问微信小程序-->本地找到小程序生成的本地包-->导出本地包使用wxappunpacker
反编译-->反编译后使用微信开发者工具打开（反编译就完成了）

二、环境的准备

安卓模拟器；任意文件管理器（笔者这里使用的是逍遥模拟器和re文件管理；re文件管理需要root权限）

wxappunpacker（运行此工具需要node环境）

下载链接https://github.com/xuedingmiaojun/wxappUnpacker

然后解压就行了；

node

node安装链接https://my.oschina.net/u/574036/blog/1818488?hmsr=kaifa_aladdin

node下载链接http://nodejs.cn/download/

三、反编译流程

在模拟器微信上点击需要反编译的小程序；然后在使用re文件管理进入/data/data/com.tencent.mm/MicroMsg/185338126f75c74b9b734d8de6c10b59/appbrand/pkg/；中间的185338是随机的目录每个人都不一样，可以看下级目录来分辨。

进入后看到的就都是小程序程序包，如果有很多就删除重新进入就找到想要的那个了（如果一个小程序有多个包可以全部尝试反编译）

再用一些小办法吧文件分享出来，可以使用微信的发送功能、或者模拟器的共享文件；

文件在放到某个文件里面、然后在反编译脚本处打开powershell

运行一下命令
node .\wuWxapkg.js D:\fby\wxappUnpacker-master\xcx\_146210159_24.wxapkg
node是之前的环境变量、.\wu是反编译脚本 后面这是程序包的完整的文件路径

反编译过程中可能会报错我就报了如下错误
Error: Cannot find module 'uglify-es'
##缺少uglify-es模块用下面的命令就可以了
npm install uglify-es

接下来使用微信开发者工具打开调试就可以了
导入反编译后的文件，选择使用调试号，如果没有就注册一个。


再使用真机调试这样就这样直接开始调试了。（反编译后如果有登录的代码，可以删除登录代码绕过登录）
