FreeBuf早报 | 欧盟警告卫星通信网络恐受威胁；乌克兰企业遭受DoubleZero攻击
2022-03-24 16:27:00

全球动态

1. 全球超过 200,000 台 MicroTik 路由器受到僵尸网络恶意软件的控制

Avast的高级恶意软件研究员Martin Hron说，近230,000个易受攻击的MikroTik路由器受到僵尸网络的控制。【外刊-阅读原文】

2. 欧盟和美国机构警告：国际卫星通信网络可能受到威胁

美国和欧洲机构发出俄罗斯可攻击卫星通信网络的警告。【阅读原文】

3. 安全人员发现新型恶意软件，文件伪装成 Windows 激活工具并可绕过系统保护

安全研究公司 ASEC 发现网络上近期出现了一种新的恶意软件大肆传播，它会伪装成以 Windows 激活工具的形式，但实际上是 BitRAT 远程访问木马。【阅读原文】

4. 永利、澳门的酒店遭到黑客组织攻击，客人敏感信息或被窃取

最近一份新的报告说，DarkHotel黑客组织的网络钓鱼攻击活动侵入了众多豪华酒店的网络，其中包括永利皇宫和澳门的Grand Coloane度假村。 【阅读原文】

5. 复杂危险的勒索软件 BlackCat 或将开启新的攻击模式

BlackCat于2021年11月首次出现，此后在过去几个月里针对世界各地的几个组织，它被称为与BlackMatter相似。【阅读原文】

6. 医疗服务泄露 12,000 张敏感患者图像

在云配置错误似乎泄露了包括婴儿在内的数千名患者的敏感图像后，一家医疗问答服务提供商正面临有关其安全流程的问题。【外刊-阅读原文】

安全事件

1.匿名者的目标是在俄罗斯活跃的西方公司，包括欧尚、乐华梅林和迪卡侬

Anonymous 对仍在俄罗斯运营的西方公司发起攻势，它入侵了欧尚、乐华梅林和迪卡侬网站。【外刊-阅读原文】

2. 俄罗斯因谷歌发布不实的乌克兰战争信息而禁止谷歌新闻

俄罗斯电信监管机构 Roskomnadzor 已禁止 Alphabet 的新闻聚合服务 Google News 并阻止访问 news.google.com 域，因为它提供了有关乌克兰正在进行的战争的“不可靠信息”的访问权限。【外刊-阅读原文】

3. 联邦调查局警告称，与俄罗斯有关的对美国能源公司的攻击风险越来越大

据美联社报道，联邦调查局正在警告能源公司注意与俄罗斯有关的威胁行为者进行网络攻击的风险。【外刊-阅读原文】

4. GIMMICK 植入程序现瞄准 macOS

Volexity 研究人员调查了他们正在监控的环境中的一次入侵，并发现了一台运行 macOS 11.6 的 MacBook Pro，该 MacBook Pro 被一种以前未知的被追踪为 GIMMICK 的 macOS 恶意软件所破坏。 【外刊-阅读原文】

5. 乌克兰企业遭受DoubleZero攻击

乌克兰 CERT-UA 警告名为 DoubleZero 的网络攻击针对乌克兰企业。【外刊-阅读原文】

6. FBI 将俄罗斯网络犯罪市场所有者列入通缉名单

一名俄罗斯国民已被美国司法部起诉，并因涉嫌创建和管理网络犯罪市场而被列入 FBI 的网络通缉犯名单。【外刊-阅读原文】

1. 斗象科技CEO谢忱：中美网安市场分化明显，“平行宇宙”初现

当今世界，以云计算、大数据、人工智能为代表的科技革命在全球蓬勃兴起，随着国内外具有共识性的热门技术在各行各业广泛地应用，整个世界似乎正在迅速地融为一体。【阅读原文】

2. 微软确认遭Lapsus$ 勒索组织入侵

据Bleeping Computer消息，微软已经确认他们的一名员工受到了 Lapsus$ 黑客组织的入侵，使得黑客访问和窃取了他们的部分源代码。【阅读原文】

3. 戴尔曝出五大漏洞，影响数百万 Inspiron、Vostro、XPS、Alienware 系统

据thehackernews消息，戴尔BIOS存在五个新的安全漏洞，如果这些漏洞被黑客利用，可能会导致在易受攻击的系统上执行代码。这与最近在Insyde Software 的InsydeH2O和 HP 统一可扩展固件接口 ( UEFI ) 中发现的固件漏洞类似。【阅读原文】
