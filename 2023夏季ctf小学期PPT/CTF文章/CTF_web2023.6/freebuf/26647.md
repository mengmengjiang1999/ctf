等保2.0 AIX系统检查命令
2021-03-18 11:19:16

uname -a 查看相关的内核信息

oslevel -s 查看内核的相关信息

lssrc -a 查看本地所有子系统的状态信 息

lslpp -l 操作系统补丁更新情况

crontab -l 服务中心的日常任务相关信息

who -r 最近的登录信息

ps -ef 进程相关信息

netstat -nr 网络连接的相关信息

ifconfig -a 网络配置相关信息

cat /etc/profile 系统环境设置的相关信息

cat /etx/syslog.conf syslog的相关信息

cat /etc/passwd 系统的密码信息

cat /etc/inittab 启动项的相关配置信息

cat /etc/inetd.conf 多余服务是否禁用

cat /etc/security 查看安全配置的相关信息

cat /etc/security/passwd 查看系统安全的密码策略信息

cat /etc/security/user 查看安全配置的用户信息

cat /etc/security/login.cfg 查看安全登录安全配置信息

cat /etc/security/limits 查看系统安全中的限制信息

cat /etc/hosts.allow 允许

cat /etc/hosts.deny 拒绝

cat /etc/host.equiv 查看主机的配置信息

cat /etc/ssh/sshd_config 查看服务中心的ssh服务配置信息

df -h 查看系统的磁盘相关信息
