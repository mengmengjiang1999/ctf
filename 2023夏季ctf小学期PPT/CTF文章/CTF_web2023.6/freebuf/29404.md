Linux 虚拟机使用 vim（Visual interface）编辑器之神

  * 若没有安装 vim，执行 sudo apt install vim 安装
  * vim 文件 可以建立一个新文件，也可以直接打开编辑文件
  * vim test.py 这里没有test.py，直接新建一个test.py，编辑过程中若未保存则无文件
  * 命令模式常用命令
  * i 、I、a、A、o、O 都是进入编辑模式
  * i、I，分别把光标定位于光标前一个字符、这行首个字符
  * a、A，分别把光标定位于光标后一个字符、这行的最后一个字符
  * o、O，分别把光标定位于新增下一行的行首、新增上一行的行首（先增加新的一行，再定光标于首个字母）
  * 编辑模式下，可以按正常的习惯编辑，按 Esc 退到命令模式
  * r、R 进入取代模式(Replace mode)
  * r 只会取代光标所在的那一个字符一次
  * R 一直取代光标所在的文字，直到按下 ESC 为止
  * 光标普通移动
  * 上下左右4个方向键就是光标的4个移动方向
  * h、j、k、l 分别表示向左、向下、向上、向右移动
  * 10l 表示光标向右移动10个字符，其他方向键跟 h、j、k 也同理操作
  * 0或功能键[Home] 光标移动到这一行的行首，$或功能键[End] 光标移动到行尾
  * H M L
  * H 光标移动到这个屏幕第一行的开头
  * L 光标移动到这个屏幕最后一行的开头
  * M 光标移动到这个屏幕内容的中间行的开头
  * G gg nG
  * gg 光标移动到整个文档的第一行的开头，即 1G 同作用
  * G 光标移动到整个文档的最后一行的开头
  * nG n为数字，跳转到文档的第n行，如10G，快速跳转到文档的第10行
  * PgUp PgDn
  * PgUp 或 Ctrl+f 向下翻一页
  * PgDn 或 Ctrl+b 向上翻一页
  * dd ndd
  * dd 功能实际上是剪切，若不粘贴则有删除作用
  * dd 剪切/删除 所在的这一行，当 n=1 时，即 dd 的作用类似于 ndd
  * 
      + ndd n 为数字，剪切/删除 光标所在行在内的向下 n 行，如 10dd 则是删除 10 行
  * /字符串、?字符串 查找字符串
  * 
      + 如 /family 在光标之下寻找一个名称为 family 的字符串
      + 如 ?user 在光标只上寻找一个名称为 user 的字符串
  * yy nyy
  * yy 复制这一行内容，当 n=1 时，即 yy 的作用类似于 nyy
  * nyy n 为数字，复制光标所在的向下 n 行，如 20yy 则是复制 20 行
  * p P
  * p 将已复制的数据在光标下一行粘贴
  * P 则是将已复制的数据在光标上一行粘贴
  * u Ctrl+r
  * u 复原上一个动作，即撤销功能
  * Ctrl+r 再次重做上一个动作，恢复被撤销的内容，即反撤销
  * 如 复制一行数据，按了 u 撤销，可以按 Ctrl+r 恢复被撤销的内容
  * 底线命令模式常用命令
  * 替换指定字符串
  * :%s/原字符串/替换字符串/gc（推荐gc，g是不带确认操作的替换），如 :%s/hello/Hello/gc 将整个文档中的所有的hello都替换成Hello
  * 
      + 如 :a, bs/原字符串/替换字符串/gc a，b都是表示行数，如 :2,5s/hello/Hello/gc 将第2-5行的所有hello都替换成Hello
  * :w :q
  * :w 将编辑的数据写入硬盘档案中
  * :q 离开 vim/vi
  * :w! 将编辑的数据强制写入硬盘档案中，! 有强制的含义
  * :wq :wq!
  * :wq w和q组合使用，存储并离开，其中w是存储，q是离开
  * :wq! 强制存储并离开
  * :w 文件名 :r 文件名
  * :w 文件名 将编辑的数据储存成另一个档案（类似另存新档）
  * :r 文件名 在编辑的数据中，读入另一个档案的数据，即追加到
  * :set nu :set nonu
  * :set nu 显示行号，设定之后，会在每一行的前缀显示该行的行号
  * :set nonu 与上述的 set nu 相反，取消行号
  * 
      + *

Vi/Vim 的补充

基本上 Vi/Vim 共分为三种模式，分别是 命令模式（Command mode），输入模式（Insert mode）和 底线命令模式（Last line mode）

命令模式：

用户刚刚启动 vi/vim，便进入了命令模式。此状态下敲击键盘动作会被Vim识别为命令，而非输入字符。比如我们此时按下i，并不会输入一个字符，i被当作了一个命令。以下是常用的几个命令：

  * i 切换到输入模式，以输入字符。
  * x 删除当前光标所在处的字符。
  * : 切换到底线命令模式，以在最底一行输入命令。

若想要编辑文本：启动Vim，进入了命令模式，按下i，切换到输入模式。命令模式只有一些最基本的命令，因此仍要依靠底线命令模式输入更多命令。

输入模式：

在命令模式下按下i就进入了输入模式。在输入模式中，可以使用以下按键：字符按键以及Shift组合，输入字符

  * ENTER，回车键，换行
  * BACK SPACE，退格键，删除光标前一个字符
  * DEL，删除键，删除光标后一个字符
  * 方向键，在文本中移动光标
  * HOME/END，移动光标到行首/行尾
  * Page Up/Page Down，上/下翻页
  * Insert，切换光标为输入/替换模式，光标将变成竖线/下划线
  * ESC，退出输入模式，切换到命令模式

底线命令模式：

在命令模式下按下:（英文冒号）就进入了底线命令模式。底线命令模式可以输入单个或多个字符的命令，可用的命令非常多。在底线命令模式中，基本的命令有：

  * :q 退出程序
  * :w 保存文件
  * :wq 退出并保存文件

按ESC键可随时退出底线命令模式。
