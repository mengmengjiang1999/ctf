恶意软件潜入设备的 8 种方式
2022-12-07 16:11:33

恶意软件可以对设备和系统发动毁灭性攻击，导致敏感数据和金钱被盗、硬件和文件损坏、网络和数据库完全崩溃等等。

电子邮件和 Web是恶意软件潜入组织的主要媒介，但还有许多其他方式。下面我们将讨论恶意软件感染设备的一些最常见方式，以及可用于阻止它的安全措施。

01 恶意软件进入设备的 8 种方式


恶意广告

只需上网，恶意软件就可以注入系统，而无需单击任何下载、插件或故意打开任何文件。恶意广告是黑客实现这一目标的一种方式，通过将恶意或包含恶意软件的广告注入合法的在线广告网络和网页。

防止恶意广告的一个很好的防御方法是在首选的网络浏览器上使用广告拦截器。虽然许多合法网站（例如数字新闻）要求用户关闭他们的广告拦截器，但一个好的广告拦截器可能是过滤掉大量恶意广告内容的绝佳方法。此外，启用点击播放插件将阻止使用 Java 或 Flash 的恶意广告播放，除非直接单击它们。

鱼叉式网络钓鱼

鱼叉式网络钓鱼是最常见的电子邮件攻击媒介之一，攻击者将自己伪装成其他员工，试图窃取登录凭据或诱骗用户汇款。通过鱼叉式网络钓鱼，黑客以组织为目标获取机密或高度敏感的数据。当针对像首席执行官这样的更高级别的员工时，它被称为捕鲸。

二维码已成为鱼叉式网络钓鱼攻击的新载体。通过在看似无害的电子邮件中嵌入恶意二维码，诈骗者找到了另一种诱骗用户交出敏感信息的方法。

在处理鱼叉式网络钓鱼时，员工培训可以有很大帮助。良好的培训使用户能够更好地发现鱼叉式网络钓鱼尝试的一些特征，例如邮件中的紧迫感和模仿合法的电子邮件地址。

网页木马下载

Chrome扩展程序，WordPress插件等已经开发出一种模式;一开始安全的软件通过漏洞利用或软件更新变成了恶意软件。合法软件的初始下载被用作特洛伊木马。当用户安装第三方软件时，现有安全机制无法检测到它是否是恶意软件。

针对此类特洛伊木马的主要防御措施是个人警惕。避免从不需要的来源下载软件。员工培训是企业提高员工网络安全警惕性的可能方法。

武器化文件

PDF和Microsoft Office文档（如Word和PowerPoint）渗透到Web中。这是我们通常不会注意到的。Chrome 和 Firefox 等流行浏览器包含内置的 PDF 查看器，使文档查看能够与本机 Web 体验无缝融合。但是，轻松查看文档是有代价的。只需单击一下（无论是在 Web 上还是在电子邮件中），都可能导致文档被武器化并充满恶意软件。

这种威胁也在不断发展。当 Microsoft 开始默认阻止宏在不受信任的文件上运行时，黑客通过使用压缩文件（如 .zip、.rar）找到了解决此问题的方法。或.iso成功将包含恶意软件的文件走私到的设备上。

与特洛伊木马一样，对此类文档的最佳防御是个人警惕。仅打开来自受信任来源的文档。

欺骗性网站

将恶意软件注入设备的一种流行方法是设置外观合法的网站来吸引用户。这可以有多种形式，例如更改合法网站URL中的单个字母（通常称为域名仿冒），或者复制网站的整个网站设计和布局，但添加恶意链接。

对欺骗性网站的最佳防御是个人警惕。请注意点击的链接将发送到何处。一个好的防病毒程序还可以帮助抵御在欺骗网站上发现的一些恶意软件。

欺诈性移动应用程序

就像上面提到的恶意Chrome扩展程序和WordPress插件一样，移动应用程序是恶意软件的危险载体。无论是通过冒充流行应用程序、实施隐藏广告、键盘记录还是其他技术，移动应用程序都拥有多种感染用户设备的方法。然而，这些类型的应用程序并不是什么新鲜事，它们通常不会在Google Play商店或Apple App Store这两个最受欢迎的应用程序市场上出现。

与其他依赖伪造和社会工程的感染媒介一样，针对欺诈性移动应用程序的最佳防御措施之一是保持警惕。确保下载的应用程序来自合法来源，并与这些来源核实他们在应用商店中销售此应用程序。此外，请务必报告在商店中发现的欺诈性应用程序，以帮助保护其他用户。

远程桌面协议 （RDP）

远程桌面协议 （RDP） 允许两台计算机通过网络相互连接。虽然由微软为Windows开发，但该技术被广泛使用，并拥有大多数流行操作系统的客户端，包括Linux，MacOS，Android和iOS。

RDP 有时很容易被较旧或保护不力的系统上的黑客利用，一旦他们通过 RDP 获得对计算机的访问权限，他们就可以毫不费力地注入恶意软件或从受害者的机器中窃取文件。

可移动硬件

最后，闪存驱动器等可移动硬件是恶意软件的可行载体。虽然鱼叉式网络钓鱼等远程方法更为常见，但每当用户将未知闪存驱动器插入其计算机时，仍然存在危险。然后，这些闪存驱动器可以注入各种恶意软件，例如键盘记录器，以获取其数据。

如果在公共场所使用设备，用户还应该警惕图书馆、咖啡馆或机场的公共 USB 充电器，因为黑客可以利用这些充电器窃取数据并感染用户设备，这种做法称为“果汁劫持”。

02 如何关闭攻击媒介

数据泄露和恶意软件攻击每年给企业造成不可计量的损失。启发式、行为分析或机器学习等高级方法可以检测可能表示恶意软件感染的行为变化。然而，它们并非万无一失，即使使用市场上最好的网络安全解决方案和员工培训，感染仍然可能发生。因此，安全、隔离的数据备份应该是每个网络防御系统的一部分。

安全解决方案不应专注于为数百万种不同的恶意软件变体创建签名，而应关注攻击媒介、攻击者和恶意软件闯入计算机和 IT 系统的路径。尽管有无数种恶意软件，但只有少数几种媒介，其中一些包括网上冲浪、网络钓鱼电子邮件、特洛伊木马下载和恶意文档，如便携式文档格式 （PDF）。

尽管越来越复杂，但感染媒介保持不变。每个漏洞都以相同的向量开始，两个最大的存储桶包括 Web 和电子邮件。唯一的区别是恶意软件在违规后所做的事情。如果我们要开始真正打击恶意软件，我们需要从保护攻击媒介开始。
