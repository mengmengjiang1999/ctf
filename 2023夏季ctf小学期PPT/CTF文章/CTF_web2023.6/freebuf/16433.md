什么是 WHQL 驱动程序？
2021-12-17 14:14:20

WHQL是 Windows 硬件质量实验室的首字母缩写词。

实验室为硬件和软件提供各种测试套件，包括允许测试和“签名”设备驱动程序的套件。“签名”驱动程序被认为是稳定的，可以在特定操作系统（如 Windows XP）上使用，Microsoft 允许供应商声称它是“专为 Microsoft Windows XP 设计”。符合兼容性要求的产品还可以在产品包装、广告和其他营销材料上显示 Windows 标志，表明该产品符合 Microsoft 的标准，并且该产品设计为可与 Windows 操作系统配合使用。


问：驱动程序签名如何工作？

答：当驱动程序被“签名”后，整个安装文件集（驱动程序可执行文件、INF 文件、README 等）都会附上一个加密的数字签名（密钥），证明特定版本已成功通过最新的 WHQL 测试。然后生成一个独特的“目录”文件，该文件成为驱动程序安装的一个组成部分，并被操作系统“识别”。

问：是否在所有 Microsoft 操作系统上都启用了驱动程序签名？

答：不可以。驱动程序签名在 Windows 98、98 SE、Millennium、Windows 2000、Windows XP 和更高版本中实现，但默认情况下仅在 Windows XP、Windows 2000 和 Windows Millennium 和更高版本操作系统中启用（打开）。

问：我可以安装未签名的驱动程序吗？

答：是的。将出现一条警告消息，指出您正在安装的驱动程序未签名。根据管理设置，您现在可以继续或取消。
