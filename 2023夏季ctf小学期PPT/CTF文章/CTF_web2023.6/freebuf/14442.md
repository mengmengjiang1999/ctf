新的信息窃取程序ColdStealer
2022-02-25 15:08:14

2月25日，ASEC 分析小组发布一篇报告，披露了新型的信息窃取程序 ColdStealer 的细节信息。

ColdStealer简述

该恶意软件通常会将自己伪装成破解软件，通过一个 dropper 恶意软件进行分发，具体过程如下图所示。

图 1. ColdStealer 的感染过程

ColdStealer 具有多层结构，使用 .NET 混淆打包的方法，旨在收集各种用户信息并将其发送到 C2。它是在 .NET 中配置的，由于功能简单，大小只有 80KB。因其样本的命名空间是“ColdStealer”，便以此得名。

图 2. ColdStealer

该恶意软件会将收集到的信息以 ZIP 形式保存，然后将内存流发送到 C2。这样做没有文件和执行的痕迹，以此可以绕过安全检测。

图 3. 收集信息时使用 ZIP

ColdStealer的六大功能

该恶意软件有六个主要功能：窃取浏览器信息、窃取加密货币钱包信息、窃取文件、窃取FTP服务器信息、窃取系统信息和发送异常（错误）信息。

窃取浏览器信息

其目标是多个基于 Chromium 的浏览器、Opera 和 FireFox。其中基于 Chromium 的浏览器包括：

Battle.net、Chromium、Google Chrome 、Google Chrome (x86),、MapleStudio ChromePlus、 Iridium,、7Star,、CentBrowser,、Chedot,、Vivaldi、Kometa,、Elements、 Epic、uCozMedia Uran、 Sleipnir5、Citrio、Coowon、Liebao、QIP Surf、Orbitum、Comodo Dragon、Amigo、Torch、Yandex Browser、Comodo、360Browser、Maxthon3、K-Melon、Sputnik、Nichrome、CocCoc、Uran、Chromodo、Atom、BraveSoftware、 Microsoft Edge、Nvidia、Steam、CryptoTab

图 4. Chromium 浏览器信息收集代码

该代码可支持浏览器的最新版本，收集保存在浏览器中的 ID、密码、cookie 和 Web 数据文件。并且，扩展程序也会被查询，下面列出的程序也是恶意软件的目标，其中包括与加密货币钱包或用户验证相关的程序。

Metamask、YoroiWallet、Tronlink、NiftyWallet、MathWallet、Coinbase、BinanceChain，BraveWallet、GuardaWallet、EqualWallet、JaxxLiberty、BitAppWallet、iWallet、Wombat、AtomicWallet、MewCx、GuildWallet、SaturnWallet、RoninWallet、PhantomWallet、Arweave、Auro、Celo、Clover、Coin98、Crypto.com、Cyano、Cyano PRO、Dune、Fractal、Gero、Harmony、Hiro、Iconex、Kardia Chain、Keplr、KHC、Lamden、Liquality、Maiar、Mew CEX、Mobox、NeoLine、Nami、Oasis、Polymesh、Rabby、Solflare、Sollet、Solong、Temple、Terra Station、TezBox、Theta、XDeFi、ZebeDee、Authenticator CC

此外，ColdStealer并不是窃取整个文件，而是在内部解析文件，然后只发送必要的信息。然而，由于它没有考虑Unicode编码，因此在解析以韩语为系统语言的浏览器(SQLite格式)的文件时，会发生错误。

图 5. SQLite 解析错误

解析成功后，浏览器访问记录保存在“Domain.text”中，帐号和密码保存在“Passwords.text”中。

图 6. 收集的浏览器密码

窃取文件

目标是桌面中的文件和用户帐户的子目录。它会收集所有带有“wallet”字符串或扩展名的.txt 和 .dat文件。

图 7. 窃取文件的代码

窃取FTP服务器信息

收集保存在最常见的 FTP 程序 FileZilla 中的服务器列表和密码。

图 8. 窃取 FTP 服务器信息的代码

窃取系统信息

收集各种系统信息，包括 Windows 版本、语言、CPU 类型、剪贴板数据、执行权限等。

图 9. 窃取系统信息的代码

窃取加密货币钱包信息

收集保存在漫游目录、本地目录、注册表等中的钱包程序信息。

Zcash、Armory、Bytecoin、JaxxClassic、JaxxLiberty、Exodus、Ethereum、Electrum、Electrum-LTC、Electrum-BCH、Atomic、Guarda、Wasabi、Daedalus、Coinomi、Litecoin、Dash、Bitcoin、monero-core、Binance。

收集和发送错误信息

记录并发送程序运行时发生的每个错误（异常）。

图 10. 收集错误的代码

信息在完成收集后会被发送到C2。该恶意软件使用 HTTP POST 方法，而C2 URL已被硬编码在特定位置。

图 11. C2 URL
