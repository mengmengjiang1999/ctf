root-me:network(一)
2021-12-28 18:25:35
  * 前言：根据靶场学习了一下网络协议，这仅是部分题目，后面还有暂时因个人考试问题，以后补上
  * FTP-authentication
      + 地址：Challenges/Network : FTP - authentication [Root Me : Hacking and Information Security learning platform] (root-me.org)
      + 题目：通过 FTP 实现的经过身份验证的文件交换。恢复用户使用的密码。（FTP请求过程中的流量抓取生成了文件，我们要从其中进行数据包捕获分析）
      + 步骤：
          o 开始挑战，会给一个ch1.pcap文件
          o 使用wireshark进行网络数据包分析
              - 导入
              - 追踪tcp流
              - 显示FTP TCP流的整个信息，并获取用户名和密码（答案就是密码）
      + 总结：wireshark抓包后，对数据进行数据流分析，查看信息是否泄露
          o FTP协议：计算机网络基础知识——【FTP协议】概述篇 - 知乎 (zhihu.com)
          o 提醒：别把用户名和密码通过FTP传输啊，共享文件就真的成共享了，你也不想女朋友看到你的隐私的啦（虽然我没有，母胎solo！）
  * Bluetooth-Unknown
      + 地址：Challenges/Network : Bluetooth - Unknown file [Root Me : Hacking and Information Security learning platform] (root-me.org)
      + 题目：找到mac地址和手机远程名称，进行sha1哈希加密
      + wireshark分析ch18.bin，进行HCI协议流量分析
      + sha1加密
      + 参考：
          o BT Snoop文件格式：(16条消息) BTSnoop 文件格式_生命不息，奋斗不止!-CSDN博客
          o 蓝牙Beacon广播数据包格式以及解析：(17条消息) 蓝牙Beacon广播数据包格式以及解析_晨曦的博客-CSDN博客_蓝牙广播包数据格式
  * cisco-mot de passe
      + 地址：Challenges/Réseau : CISCO - mot de passe [Root Me : plateforme d'apprentissage dédiée au Hacking et à la Sécurité de l'Information] (root-me.org)
      + 题目：找到密码"Enable"。
      + cisco内建有针对config做保护的指令，cisco内密码加密的方式是可逆的
          o config内容
          o 解码密码工具：IFM - Cisco Password Cracker
              - hub 6sK0_hub
              - admin 6sK0_admin
              - guest 6sK0_guest
          o 依照逻辑顺序执行，hub解出hub，密码：enable:6sK0_enable
  * DNS-transfert de zone
      + 地址：Challenges/Réseau : DNS - transfert de zone [Root Me : plateforme d'apprentissage dédiée au Hacking et à la Sécurité de l'Information] (root-me.org)
      + 题目：一个不诚实的管理员为域"ch11.challenge01.root-me.org"设置了DNS服务...
      + 工具：dig
          o Windows安装：(17条消息) win10 安装dig工具与使用dig命令_你和萤火虫有两个共同点，在我的眼里都会发光，同时，都已经很多年没见了-CSDN博客_dig windows
          o dig使用教程：(17条消息) DNS篇之dig使用详解_新雪兰-CSDN博客_dig dns
      + dig @212.129.38.224 -p 54011 axfr ch11.challenge01.root-me.org
          o DNS区域传输与DNS爆破：(17条消息) DNS区域传输 && DNS爆破__LsOutLook-CSDN博客_dns区域传送
          o DNS域传送漏洞利用总结：dns 域传送漏洞利用总结 - 简书 (jianshu.com)
  * ip-time to live
      + 地址：挑战/网络：IP - 生存时间[Root Me：致力于黑客和信息安全的学习平台] (root-me.org)
      + 题目：查找用于到达此 ICMP 数据包交换所针对的主机的 TTL。
      + TTL：存活时间(Time To Life)，一个封包在经过一个路由器时，可传递的最长距离(跃点数)。每通过一个路由器该值减1. (17条消息) IP协议之TTL_浴血重生-学习空间-CSDN博客_ttl协议
      + 打开一个封包来看是type8
      + 注意到TTL最后停在13，ttl=13，destination：24.6.126.218，reply写着超出范围（exceed），但最后收到ttl 13后就没有这个讯息，接着出现了ttl 51
      + Linux系统，ttl 51最接近64，64-51=13，猜测是13跳
  * LDAP-null bind
      + 地址：挑战/网络：LDAP - 空绑定 [Root Me：致力于黑客和信息安全的学习平台] (root-me.org)
      + 题目：
      + ldap协议：LDAP概念和原理介绍 - WilburXu - 博客园 (cnblogs.com)
      + 在unix系统上，用ldapsearch对ldap服务器执行查询
          o ldapsearch -x -b "ou=anonymous,dc=challenge01,dc=root-me,dc=org" -H "ldap://challenge01.root-me.org:54013"
  * Authentifcaion twitter
      + 地址：Challenges/Réseau : Authentification twitter [Root Me : plateforme d'apprentissage dédiée au Hacking et à la Sécurité de l'Information] (root-me.org)
      + 题目：捕获了 Twitter 身份验证会话。在此网络捕获中查找用户的密码。
      + 步骤：
          o 开始挑战，给出ch3.pcap文件，用wireshark进行http流追踪
          o 对密钥进行base64解密（得到密码password）
  * ethernet-frame
      + 地址：Challenges/Network : ETHERNET - frame [Root Me : Hacking and Information Security learning platform] (root-me.org)
      + 题目：在此以太网帧中查找（应该是）机密数据。
      + 步骤：
          o 开始挑战
          o 给予我们一个十六进制的文件，十六进制进行转换ascii码（head头部得到基本认证的密钥）
              - Authorization: Basic Y29uZm***GVudGlhbA==
              - User-Agent: InsaneBrowser
              - Host: www.myipv6.org
          o 将basic authorization 密钥进行base64格式解码
              - basic authorization
  * telent-authentication
      + 地址：挑战/网络：TELNET - 身份验证[Root Me：黑客和信息安全学习平台] (root-me.org)
      + 题目：在此 TELNET 会话捕获中查找用户密码。
      + 步骤：
          o 开启挑战，会下载文件ch2.pcap
          o wireshark进行tcp数据流追踪分析
          o 得到结果：密码为user
  * SIP-authentification
      + 地址：Challenges/Réseau : SIP - Authentification [Root Me : plateforme d'apprentissage dédiée au Hacking et à la Sécurité de l'Information] (root-me.org)
      + 题目：查找用于向 SIP 基础结构进行身份验证的密码。
      + sip认证：(17条消息) sip 认证_好记性不如写博客！-CSDN博客_sip用户认证密码
      + 数据包register包内plain部分即为明文密码
