华云安漏洞安全周报【第111期】
2022-12-22 09:52:50

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.11.21~2022.11.27）CNNVD接报漏洞407个，其中信息技术产品漏洞（通用型漏洞）170个，网络信息系统漏洞（事件型漏洞）237个，其中华云安报送1个；CNNVD接报漏洞预警53份，其中华云安报送预警4份！预警报送数量持续位居前列！

数据来源：（https://www.cnnvd.org.cn/group1/M00/00/2A/rBBlZ2OFw06AaMwlAAOTJCB6sJ4133.pdf ）

本周重点关注漏洞包括：CVE-2022-40189 Apache Airflow 操作系统命令注入漏洞、CVE-2022-45470 Apache Hama 输入验证错误漏洞、CVE-2022-45919 Linux kernel 资源管理错误漏洞、CVE-2022-45462 Apache DolphinScheduler 命令注入漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-40189 Apache Airflow 操作系统命令注入漏洞

威胁等级：超危

漏洞描述：

2022年11月21日，华云安思境安全团队发现Apache发布了安全更新， 修复了Apache Airflow Pig Provider 4.0.0之前版本存在操作系统命令注入漏洞。Apache Airflow是一套用于创建、管理和监控工作流程的开源平台，该平台具有可扩展和动态监控等特点。该漏洞被攻击者利用后，可导致远程命令执行。

情报来源：

https://airflow.apache.org/docs/apache-airflow-providers-apache-pig/4.0.0/index.html

02 CVE-2022-45470 Apache Hama 输入验证错误漏洞

威胁等级：高危

漏洞描述：

2022年11月21日，华云安思境安全团队发现Apache官方发布安全更新，披露了 Apache Hama存在输入验证错误漏洞。Apache Hama是一个基于批量同步并行计算技术的分布式计算框架BSP (Bulk Synchronous Parallel大容量同步并行)计算技术，主要针对大规模科学的计算。该漏洞被攻击者利用后，可导致信息泄露。

情报来源：

https://lists.apache.org/thread/ztvoshd4kxvp5vlro52mpgpfxct4ft8l

03 CVE-2022-45919 Linux kernel 资源管理错误漏洞

威胁等级：高危

漏洞描述：

2022年11月21日，华云安思境安全团队发现Linux kernel官方发布安全更新，披露了 Linux kernel 6.0.10及以前版本存在释放后使用漏洞。Linux kernel 是一种开源的类 Unix 操作系统内核。该漏洞被攻击者利用后，可导致在打开后断开连接发生释放后重用。

情报来源：

https://lore.kernel.org/linux-media/20221121063308.GA33821@ubuntu/T/#u

04CVE-2022-45462 Apache DolphinScheduler 命令注入漏洞

威胁等级：超危

漏洞描述：

2022年11月23日，华云安思境安全团队发现Apache官方发布安全更新，Apache DolphinScheduler 2.0.5 之前版本存在命令注入漏洞。Apache DolphinScheduler是一个分布式的基于DAG可视化的工作流任务调度系统。该漏洞被攻击者利用后，可导致命令注入。

情报来源：

https://lists.apache.org/thread/2f126y32bf1v3mvxkdgt2jr5j3l1t01w
