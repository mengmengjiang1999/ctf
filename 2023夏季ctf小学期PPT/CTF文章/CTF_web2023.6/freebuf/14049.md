如何在Oracle Wallet Manager中安装SSL证书
2022-03-31 14:52:59

Oracle Wallet Manager是一个用于存储与SSL相关的经过身份验证的安全凭证、私钥、证书的应用程序。Oracle Wallet Manager在创建钱包、生成证书请求、钱包存储、密码管理、导入和导出第三方 PKCS #12 格式钱包等方面也很有用。

1、导入根证书和中间证书

1）打开您的证书提供商发送的电子邮件，提取SSL证书和支持文件到您希望存储这些证书文件的特定目录/硬盘，这些文件包含根证书和中间证书。

2）打开Oracle Wallet Manager并在Operation菜单下，单击Import Trusted certificate。

3）选择包含证书的文件。

4）搜索您保存在特定目录/硬盘上的根证书和中间证书，然后单击确定按钮。

您已成功安装根证书和中间证书，下一步是在 Oracle Wallet Manager 上安装 SSL 证书。

2、安装 SSL 证书

1）打开Oracle Wallet Manager，浏览Operation菜单并单击Import User Certificate。

2）单击包含名为 your_sitename.crt 的主服务器证书的证书文件。

3）单击确定按钮。

安装后，在导航窗格中，证书节点将从Certificate:[Requested] 更改为 Certificate:[Ready]。

接下来可以借助SSL证书在线检测工具检查一下SSL证书是否安装成功。
