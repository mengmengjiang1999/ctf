凯捷咨询招聘｜System Specialist
2021-08-31 16:40:36

凯捷集团创建于1967年，是全球最著名的管理咨询、技术和外包服务的供应商之一。 凯捷拥有自己独特的客户合作方式，称之为协同业务体验。 凭借40多年来不断发展的行业和服务经验，在我们世界领先的技术合作伙伴和专业协作方法及工具的支持下，协同业务体验为客户提供了更好、更快、更持久的解决方案

System Specialist 要求

地点：中国上海

工作时间：全职

当涉及到日常运营时，您还有责任根据商定的服务水平确保可用性。这可能包括以下内容：

监控和分析系统活动，以确保生产环境中的最高性能、效率和可用性。

为我们的生产环境中的日常运营执行常规和紧急系统管理任务，其范围从中等到高度复杂。

确保所有生产服务器的可靠系统状态和数据备份。

处理硬件迁移、软件升级和新服务器安装

执行故障排除和事件分析，以隔离、诊断和解决与 Windows Server 相关的问题。

能力/知识

要成功担任系统专家，您需要：

3年以上 Windows 服务器工程师/管理员工作经验

Windows Server 2016 的深厚技术功底

熟悉VMWare虚拟化解决方案，有HCI知识者优先

扎实的 PowerShell 脚本技能

良好的 HP/DELL 服务器硬件知识

能够在多元文化的全球团队中工作。具备有效的人际交往能力，较强的沟通能力

勇于表达意见，勇于采取行动并承担行动的后果

主动改进工作流程并保持您的能力更新。

即使在复杂的情况下，也能够承担自己的责任并做出必要的决定，并知道何时以及如何升级。

能够确定工作的优先级并以结构化的方式工作

流利的英语，口语和写作。

了解超融合基础架构（SimpliVity/Nutanix）、Citrix Presentation Server 和 BMC Remedy 都是加分项。

——————————————————————————————————————————————

When it comes to daily operation you are also responsible to ensure availability in accordance with agreed service levels. This may include the following:

Monitoring and analyzing system activities to ensure maximum performance, efficiency and availability within the production environment.

Performing both routine and emergency systems management tasks for daily operations in our production environment which range from moderately to highly complex in nature.

Ensuring reliable system state and data backups for all Production servers.

Handling hardware migrations, software upgrades and new server installations

Performing troubleshooting and analysis of incidents to isolate, diagnose and resolve problems related to Windows Server.

Competence/Knowledge

To be successful in the role as a System Specialist, you need:

3+ years proven working experience as windows server engineer/administrator

Deep technical skills of the Windows Server 2016

Familiar with VMWare virtualization solution, HCI knowledge is preferred

Solid PowerShell scripting skill

Good hardware knowledge of HP/DELL servers

Ability to work in a multicultural global team. Have effective interpersonal skills, strong communication skills

Have the courage to express opinions, to act and take the consequences of actions

Use own initiative to improve working processes and keep your competence updated.

Ability to take your responsibilities and make necessary decisions even under complex circumstances and know when and how to escalate.

Able to prioritize work and work in a structured way

Be fluent in English, spoken and written.

Knowledge of the Hyper-Converged Infrastructure (SimpliVity/Nutanix), Citrix Presentation Server and BMC Remedy are all a plus.
