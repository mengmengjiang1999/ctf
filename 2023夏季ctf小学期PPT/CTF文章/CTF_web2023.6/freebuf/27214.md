云服务器安装安全狗后discuz后台登陆不了
2021-03-04 12:48:57

喜欢使用discuz论坛建站的朋友都是知道的，QQ互联的bug太多了，但是呢就是那么几种错误来围绕我们的站长朋友，请看小编的解决思路吧！
1、首先我们要知道提示QQ互联不能用的原因:
A、是否启用这个插件。
B、uc通讯是否成功。
C、云平台是否有异常。
D、数据库表是否升级。
2、基本上把上面几个原因排除了就可以正常的使用我们的QQ互联了。下面讲讲具体的实现方法吧：
（1）第一种情况是很简单的，看看是否安装了这个插件，如果没有安装即可。
（2）登录后台，具体的路径大概站长朋友都是知道的，进行检测通讯是否成功，但是如果通讯成功的话，那么就没有问题了。但是有一点您要看看通讯的url是否带有www的 如果没有的话及时成功了，上传头像的时候还是无法上传的，所以不行加www，小编提醒的是安装的时候使用带www的安装即可。
（3）可能有写站长朋友的在云平台诊断哪里突然没有站点ID和站点密钥了，那这个怎么办呢，其实是很简单的，首先是有的直接点击手动修改key，清空ID和KEY，然后选择未开通进行提交，然后输入以下链接：http://域名/admin.php?action=cloud&operation=open，按照步骤进行开通云平台，如果点击开通的时候需要什么修复之类的按照这个流程做下去即可，如果是没有站点ID和KEY直接点击修改为未开通，同上面的步骤完成即可。
（4）点击开通了，但是当点击用QQ登录的时候又会数据库出错了，哎，出现这个错误就简单了，只需要对数据库表进行升级就可以完成了。
A、首先我们需要修改一个数据库配置文件，如果您不修改的话，无法是在discuz后台进行升级的。修改配置文件的路径如下:/config/config_global.php，打开这个文件并且找到如图所示：

discuz

把他改为‘1’就可以了，这个的意思就是说运行在后台执行sql语句。
然后登录后台——站长—–数据库—-升级！然后把下面升级语句复制进去，进行升级即可：
ALTER TABLE `pre_common_member_connect` ADD `conuintoken` CHAR( 32 ) NOT NULL ;

ALTER TABLE `pre_common_connect_guest` ADD `conuintoken` CHAR( 32 ) NOT NULL ;如图所示:

discuz

点击提交就可以进行升级了数据库表的字段了，说明白一点就是增加字段。
