工控安全 | 利用python识别工控协议
2022-12-02 16:15:58

在工控领域，我们通常会遇到各式各样的协议，也存在众多的私有协议。如果仔细发现，成熟的厂商一般都会有自己的私有协议，例如西门子的s7comm、三菱的melsec-q、罗克韦尔的EtherNet/IP等

工控协议的指纹识别可以通过端口，modbus协议是502，s7comm的是102，但是存在很大的误差，也可以通过发送该协议能识别的特定数据包到服务端，如果服务端有返回数据包，就能证明是该协议

常用的工控协议端口

本文通过python来识别BACnet协议。 BACnet是用于智能建筑的通信协议，是国际标准化组织（ISO）、美国国家标准协会（ANSI）及美国采暖、制冷与空调工程师学会（ASHRAE）定义的通信协议。

BANnet协议主要通过47808端口来传输数据，可以通过搭建BACnet协议仿真再利用wireshark来抓取通信时的数据包

下图是通过wireshark抓取到的数据包

从数据包中可以看出，BACnet协议是通过udp来进行传输的，而且是通过类似于一问一答的形式来返回设备信息的

下面是其中的一次通信

客户端通过发送特定的socket套接字“询问”服务端的firmware-revision 信息是什么

如果服务端可以通过BACnet协议进行通信，它就会返回一个“答案”数据包，否则服务端不回应

下面是客户端发送的“询问”数据包

红色部分就是客户端发送的byte数据



如果服务端的协议是BACnet，它就会返回一个BACnet的数据包，其中就包含着所需要的设备信息

以下是具体实现代码：

import argparse
import socket
import re
from binascii import unhexlify


class Banner(object):
def __init__(self, addr, port):
self.addr = addr
self.port = port
self.output = {"IP": self.addr, "PORT": self.port,
"DATA": {"protocol": "", "vendor_name": "",
"application_software_revision": "",
"object_name": "", "model_name": ""}}

def getcontent(self, response):
# 通过四个正则提取相关字段
vendor_name_obj = re.compile(r'\?(?P<vendor_name>.*?)00x\\', re.S)
application_software_revision_obj = re.compile(r'\?(?P<application_software_revision>.*?)00x\\', re.S)
object_name_obj = re.compile(r'\?(?P<object_name>.*?)00x\\', re.S)
model_name_obj = re.compile(r'\?(?P<model_name>.*?)00x\\', re.S)

if response:
self.output["DATA"]["protocol"] = "bacnet"

# response[0]内容为 "\x81\n\x00\x1c\x01\x000\x01\x0c\x0c\x02\x00\x00\x01\x19y>u\x08\x00Tridium?"
# 将字符串倒序匹配？和 00x\之间的内容，得到的结果再次倒序输出即为指纹结果
self.output["DATA"]["vendor_name"] = (vendor_name_obj.findall(str(response[0])[::-1])[0])[::-1]
self.output["DATA"]["application_software_revision"] = (application_software_revision_obj.findall(
str(response[1])[::-1])[0])[::-1]
self.output["DATA"]["object_name"] = (object_name_obj.findall(str(response[2])[::-1])[0])[::-1]
self.output["DATA"]["model_name"] = (model_name_obj.findall(str(response[3])[::-1])[0])[::-1]

print(self.output)

def run(self):
global udp_sock
response = {}
target = (self.addr, self.port)
try:
# udp连接，如果第一次发送数据异常直接退出
udp_sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
udp_sock.settimeout(5)
udp_sock.sendto(unhexlify('810a001101040005010c0c023fffff1979'), target)  # vendor_name
response[0] = udp_sock.recv(1024)
except:
self.getcontent('')
exit(1)

# bacnet将指纹信息分开发送
udp_sock.sendto(unhexlify('810a001101040005010c0c023fffff190c'), target)  # 用来获取 application_software_revision
response[1] = udp_sock.recv(1024)
udp_sock.sendto(unhexlify('810a001101040005010c0c023fffff194d'), target)  # 用来获取 object_name
response[2] = udp_sock.recv(1024)
udp_sock.sendto(unhexlify('810a001101040005010c0c023fffff1946'), target)  # 用来获取 model_name
response[3] = udp_sock.recv(1024)
udp_sock.close()
self.getcontent(response)


if __name__ == '__main__':
parser = argparse.ArgumentParser(description="bacnet-47808")
parser.add_argument("--ip", type=str)
parser.add_argument("--port", type=int)
args = parser.parse_args()

Banner = Banner(args.ip, args.port)
Banner.run()

总结：

其他工控协议的指纹识别大致相同，“询问”数据包通常都是服务端返回指纹信息的前一个数据包

发送特定的数据包到服务端后，如果服务端不支持该协议，就不会返回对应的数据包
