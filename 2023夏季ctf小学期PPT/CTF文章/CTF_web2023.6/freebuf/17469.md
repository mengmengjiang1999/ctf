华云安漏洞安全周报【第59期】
2021-11-18 15:21:25

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 11.8~2021.11.14）CNNVD接报漏洞604，信息技术产品漏洞（通用型漏洞）161个，网络信息系统漏洞（事件型漏洞）443个，其中华云安报送漏洞100个，漏洞报送数量位居第一！CNNVD接报漏洞预警64份，其中华云安报送预警8个，漏洞报送数量位居第二！

本周重点关注漏洞包括：Samba 11月多个安全漏洞、Microsoft 11月多个安全漏洞、CVE-2021-42292-Microsoft Excel 安全特征绕过漏洞、CVE-2021-38666- Windows Remote Desktop Client 远程代码执行漏洞、CVE-2021-3064-PAN-OS 远程代码执行漏洞、CVE-2021-22048-VMware vCenter Server 权限提升漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

Samba 11月多个安全漏洞

高危

2021年11月9日，华云安思境安全团队发现 Samba 官方发布安全更新，披露了 Samba 组件中的多个安全漏洞，包括 CVE-2020-25719、CVE-2020-25721、CVE-2020-25722、CVE-2021-3738 和 CVE-2021-23192 等。Samba 是在 Linux 和 UNIX 系统上实现 SMB 协议的一个免费软件，由服务器及客户端程序构成。对此，华云安建议相关用户及时到 Samba 官方下载更新到 Samba 4.15.2、4.14.10 或 4.13.14！

https://www.samba.org/samba/history/security.html

Microsoft 11月多个安全漏洞

严重

2021年11月9日，华云安思境安全团队发现 Microsoft 官方发布11月份安全更新，共发布了55个漏洞的补丁程序，同比上月减少了27个。主要涵盖了 Azure Sphere、Microsoft Dynamics、Microsoft Office、Microsoft Windows、Visual Studio、Windows Core Shell、Windows Defender、Windows NTFS、Windows Scripting、Windows Virtual MachineBus、Windows Kernel 和 Windows RDP 等多个产品和组件。在漏洞安全等级方面，有6个严重漏洞，49个高危漏洞；在漏洞类型方面，主要有20个权限提升漏洞，2个安全功能绕过漏洞，15个远程代码执行漏洞，10个信息泄露漏洞，3个拒绝服务漏洞，以及4个欺骗漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

https://msrc.microsoft.com/update-guide/releaseNote/2021-Nov

CVE-2021-42292-Microsoft Excel 安全特征绕过漏洞

高危

2021年11月10日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Microsoft Excel 组件中存在一处安全特征绕过漏洞。Microsoft Office 是微软公司的一款办公软件套件产品，该产品常用组件包括 Word、Excel、Access、Powerpoint、FrontPage 等。该漏洞是由于 Excel 组件存在安全功能绕过漏洞，成功利用此漏洞的攻击者可以通过构造恶意文档并诱使用户打开，从而绕过 Excel 的安全功能，在用户机器上执行恶意代码。

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42292

CVE-2021-38666- Windows Remote Desktop Client 远程代码执行漏洞

高危

2021年11月10日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows Remote Desktop Client 组件中存在一处远程代码执行漏洞。Windows Remote Desktop Client 使用户可以使用并控制一台远程的 PC，对远程 PC 进行一切可以对物理 PC 进行的操作。该漏洞是由于客户端未对服务端传来的数据进行严格的校验，导致内存破坏，成功利用此漏洞的攻击者可在未授权的情况下，构造恶意数据从而执行远程代码执行攻击。

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-38666

CVE-2021-3064-PAN-OS 远程代码执行漏洞

超危

2021年11月11日，华云安思境安全团队发现 Palo Alto 官方发布安全更新，披露了 PAN-OS Global Protect 接口和网关接口存在一处远程代码执行漏洞。Palo Alto Networks Global Protect 是一套网络防护软件，该软件可提供防火墙监控及威胁预防等功能。未经身份验证的基于网络的攻击者，能够扰乱系统进程，并可能使用 root 权限执行任意代码，攻击者必须通过网络访问 Global Protect 接口才能利用这个漏洞。

https://web.archive.org/web/20211110194020/https://security.paloaltonetworks.com/CVE-2021-3064

CVE-2021-22048-VMware vCenter Server 权限提升漏洞
中危

2021年11月11日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 VMware vCenter Server 组件中存在一处权限提升漏洞。VMware vCenter Server 是一套服务器和虚拟化管理软件，该软件提供了一个用于管理 VMware vSphere 环境的集中式平台，可自动实施和交付虚拟基础架构。成功利用此漏洞的对 vCenter Server 具有非管理访问权限的攻击者可能会将权限提升到更高权限组。

https://www.vmware.com/security/advisories/VMSA-2021-0025.html
