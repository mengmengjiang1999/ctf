EMOTET卷土重来
2023-03-10 10:51:15

Emotet是一种臭名昭著的恶意软件，具体介绍我就不浪费文字了，有兴趣的可以去参考wiki，简单而言，它会通过电子邮件传播含有恶意微软Word和Excel文档附件。自2022年11月的某个时候起，Emotet已经停止发送任何新的垃圾邮件，这已经持续了大约3个半月到4个月之久，而仅仅三个月的时间，Emotet又开始卷土重来。其于2023年3月7日周二开始重新发送恶意邮件，并且重新建立其网络，以感染全球各地的设备。当用户打开这些文档并启用宏时，Emotet DLL将被下载并加载到内存中。一旦Emotet被加载，该恶意软件将等待来自远程命令和控制服务器的指示。最终，该恶意软件将窃取受害者的电子邮件和联系人，用于未来的Emotet活动，或下载其他的有效载荷，如Cobalt Strike等常用于勒索软件攻击的恶意软件。

-- 参考来源：https://twitter.com/Cryptolaemus1/status/1633099154623803394

而目前在已发现的Emotet的第4波攻击中，Emotet的电子邮件通常具有以下特征：

 1. 包含一个压缩附件，其中包括一个超过500MB的膨胀Word文档和Emotet的自启动宏。
 2. 这些Word宏会生成一个超过500MB的膨胀的64位DLL文件，该DLL文件属于Emotet。
 3. 除了这些超大的Word文档和DLL文件外，Emotet的感染模式与其停运前的模式相似。

本次攻击中，Emotet依然采用传统邮件攻击形式，携带ZIP压缩包进行攻击，该ZIP压缩包并没有启用密码保护，如下图所示：

邮件附件压缩包仅为几百 KB，但解压后的DOC文档将 膨胀到 500MB 左右，因此绕过了绝大多数的邮件沙箱检测，用户打开恶意DOC文件后会引导启用宏，并写入自启动注册表项，同时将联系外部失陷的网站下载 DLL 文件，该DLL文件采用同样的手段膨胀到500MB左右，用以绕过沙箱检测。如下为Palo Alto的攻击模型示意图：

从下图可以看到文件膨胀到500多兆，从而绕过沙箱检测

文档采用标准的“红色黎明”模板，且附带了自启动宏

高度混淆的宏在运行后，会重新下载采用同样手段的压缩包释放一个500多兆的DLL文件，并写入用户权限的自启动项

为了保护自己免受Emotet恶意软件攻击，用户应该避免打开来自未知或不受信任的发送者的电子邮件，并确保其设备上安装了最新版本的杀毒软件和EDR程序。此外，应该避免下载来自不受信任的网站的文件，并且不要启用任何未知的宏或脚本。

高压缩比异常文件检测Yara规则:

https://github.com/elceef/yara-rulz/blob/main/rules/ZIP_High_Ratio_Single_Doc.yara

/*
	This signature detects ZIP archives with the following conditions:
	- contains single file with .doc extension
	- uncompressed size > 100MB
	- compressed size < 1MB
*/

rule ZIP_High_Ratio_Single_Doc
{
	meta:
		description = "Detects ZIP archives containing single MS Word document with unusually high compression ratio"
		author = "marcin@ulikowski.pl"
		date = "2023-03-08"
		hash1 = "4d9a6dfca804989d40eeca9bb2d90ef33f3980eb07ca89bbba06d0ef4b37634b"
		hash2 = "4bc2d14585c197ad3aa5836b3f7d9d784d7afe79856e0ddf850fc3c676b6ecb1"

	strings:
		$magic = { 50 4b 03 04 }
		$ext = ".doc"

	condition:
		filesize < 1MB and
		$magic at 0 and
		#magic == 1 and
		uint32(22) > 1024*1024*100 and
		$ext at (uint16(26) + 26)
}
