php管理数据库

php连接数据库函数——mysqli_connect

格式：mysqli_connect(servername,user,pass,database)

  * servername：数据库地址

  * user：数据库用户名

  * pass：数据库密码

  * database：数据库名

连接数据库

<?php
	header('content-type:text/html;charset=utf-8');
	$con = @mysqli_connect("localhost","root","root","cms");
	if(!$con)
	{
		die('连接失败:'.mysqli_connect_error());
	}
	else{echo "连接成功";}
	mysqli_close($con);
?>

php执行SQL语句函数——mysqli_query(conn,sql)

  * conn:数据库连接函数

  * sql:SQL语句

<?php
	header('content-type:text/html;charset=utf-8');
	$con = @mysqli_connect("localhost","root","root","cms");
	if(!$con)
	{
		die('连接失败:'.mysqli_connect_error());
	}
	else{echo "连接成功";}
	$sql="select * from admin limit 0,1";
	$result=mysqli_query($con,$sql);
	var_dump($result);
	
	mysqli_close($con);
?>

php获取执行结果函数——mysqli_fetch_array(query)

  * query:执行SQL语句函数的结果

  * mysqli_num_rows(query):获取结果数组长度
