企业数字化转型的四个阶段，星环科技自研数据云平台全部搞定
2021-12-02 17:12:41

数字化转型可以分成信息化、数据资产化、数据业务化、数据生态化四个阶段，任何企业、任何行业想要全面数字化转型都要经过这四个阶段。企业在信息化阶段产生海量数据，在数据资产化阶段把信息化阶段产生的数据集中治理形成数据资产，在数据业务化阶段又需要第二阶段形成的数据资产来驱动业务本身，而到了数据生态化阶段，数据已经不再只服务于某个组织或者某个企业，而是作为生产要素开始在组织之间、企业之间流通，发挥出更大的价值。这四个阶段环环相扣，缺一不可，基于这四个阶段的底层技术支撑也需要同步升级，于是，数据云应运而生。

目前，大型企业普遍缺乏能够满足多租户、弹性、灵活的数字化基础设施。传统烟囱式系统架构导致资源重复投入、数据孤岛等问题，很难完成数字化转型四个阶段的完整演进。而星环科技大数据云平台 Transwarp Data Cloud （TDC）以数据、模型和应用三者为核心，以云原生技术为基础，构建数据 PaaS，分析 PaaS 和应用 PaaS ，解决企业各个阶段的数字化问题。

星环科技大数据云平台 TDC 作为业界数据云先驱，2015 年就发布了云原生操作系统 TCOS，2018 年发布 TDC 1.0 版本。星环科技比国外厂商早 1 到 2年提出了数据云架构和产品。经过多个版本的打磨和迭代，数据云已经在多个行业成功落地，星环科技数据云 TDC 获得上海大数据中心、江苏省农信等大客户的认可，主要归功于 TDC 扎实过硬的关键技术，其中包括：

高性能、高性价比的大数据存储和分析能力

星环科技数据云 TDC 可以通过整个平台的计算、存储能力以及数据云产品架构的优化，为大数据服务提供高性能的存储和分析能力。同时，也基于整个数据云平台底层资源的复用和服务的有效调度，为大数据的存储和计算提供更高性价比的实现。

数据，分析和应用 PaaS 三者统一

星环科技数据云 TDC 将星环科技的大数据和 AI 能力以 PaaS 云服务形式提供给企业，同时也提供了针对企业应用的部署，运行和治理能力，实现了数据，分析和应用 PaaS三者统一。

云原生调度实现数据与计算局部性

为了兼顾弹性和性能，星环 科技TDC 把分布式计算层和存储层统一在一个集群中，根据计算对存储节点的计算局部性需求，将它们调度到同一个物理节点上，完成高效计算。当存储节点计算资源不足时，也可以使用远程的计算单元。这种架构兼顾了性能和弹性需求的平衡，同时可极大地提升资源利用率。

分布式计算执行单元场景化扩缩容

以潮汐计算为例，星环 科技TDC 可以根据业务的特点，从时间的维度来做扩缩容方案，白天交易型计算需求增多的时段开始自动扩容 OLTP 服务，晚上分析型计算需求增多的时候开始扩容 OLAP 服务，从而有效利用集群资源，完成不同时间段的需求。另外，星环科技 TDC 还可以基于负载做扩缩容，当相应的计算负载增加时，对计算单元做扩容，当计算负载减少时缩容，从而轻松应对业务波峰波谷场景。

联邦数据云平台支撑企业数字化转型

企业用户为了业务和数据的安全性，一般会有多个数据中心承载业务，包括多个私有云数据中心及公有云，星环科技数据云 TDC 联邦云解决方案通过将跨多个数据中心甚至公有云的数据、应用和基础设施资源进行统一管理，协同管理企业内部已有的资源和数据，从而构建一套完整、统一、互联互通的数字化基础设施。TDC 联邦云以打通企业数据与应用，构建数字化应用为主要目标，满足各种数据管理规范要求，兼顾业务灾备等需求，通过一套 TDC 联邦数据云平台支撑企业数字化转型。

支持 GPU 独占与共享调度

企业的 GPU 资源， 在共享调度实现之前，只能整块使用，造成了资源的极大浪费。TDC 2.4 本次升级实现了支持 GPU 共享调度，让 GPU 资源利用更合理。星环科技 TDC 可以支持单机多 GPU，多机多 GPU 的统一管理、高效的分配以及合理的规划和使用。对于应用而言，星环 科技TDC 可以支持 GPU 的独占，保证在模型训练场景中对 GPU 的高使用要求，同时也支持单块 GPU 的共享，以提升 GPU 资源的利用率。

支持异构 CPU 和操作系统混合部署

随着企业国产意识的逐步升级，国产 CPU 和操作系统市场占有率正在逐步上升，底层异构基础设施的统一管理将成为行业的刚需。星环科技数据云 TDC 2.4 基于统一的云原生操作系统 TCOS，支持 X86、ARM 等多种主流 CPU 架构以及 Linux / Windows / 国产操作系统，可以更好实现企业不同场景的需求，满足企业软硬件国产化的需求。

多重安全防护，守护大数据安全

星环科技的大数据安全中间件包含身份认证与权限管理组件 Transwarp Guardian、数据审计与泄露防护组件 Transwarp Audit、数据安全治理工具 Transwarp Defensor、数据流通门户Transwarp Foresight 及隐私计算平台 Transwarp Sophon FL，且对星环科技极速大数据平台Transwarp Data Hub 完美兼容。星环科技数据云包含了基于零信任架构的基础设施及数据云服务的整体安全，包括软件定义边界，服务统一身份认证，安全态势感知等，全方位守护大数据安全。

目前，星环科技新一代智能大数据云平台 Transwarp Data Cloud（TDC）已经在上海大数据中心、中国南方电网、江苏省农村信用社联合社、中国石油等多个行业落地，满足了各种数据处理场景的需求，实现了企业数据与应用的生态化建设。
