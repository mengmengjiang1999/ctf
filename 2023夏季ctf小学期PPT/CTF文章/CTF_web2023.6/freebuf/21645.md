华云安漏洞安全周报【第45期】
2021-08-06 16:10:31

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 7.26~2021 .8.1）CNNVD接报漏洞784个，信息技术产品漏洞（通用型漏洞）99个，网络信息系统漏洞（事件型漏洞）685个，其中华云安报送漏洞60个；CNNVD接报漏洞预警82份，其中华云安报送预警8份，漏洞及预警报送数量持续位居前列！（数据来源于CNNVD）


本周重点关注漏洞包括：CVE-2021-20399-IBM QRadar SIEM XML 外部实体注入（XXE）漏洞、CVE-2021-30551-Chrome v8 类型混淆漏洞、CVE-2021-30807-Apple 远程代码执行漏洞、CVE-2021-32749-Fail2ban 远程代码执行漏洞、Trend Micro Apex One 7月多个安全漏洞、WebKit2GTK 多个安全漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。



CVE-2021-20399-IBM QRadar SIEM XML 外部实体注入（XXE）漏洞

高危

2021年7月26日，华云安思境安全团队发现 IBM 官方发布安全更新，披露了 IBM QRadar SIEM 组件中存在一处 XML 外部实体注入漏洞。IBM QRadar SIEM 是一套利用安全智能保护资产和信息远离高级威胁的解决方案，提供了对整个 IT 架构范围进行监督、生成详细的数据访问和用户活动报告等功能。成功利用此漏洞的攻击者可以向 IBM QRadar SIEM 传输恶意 XML 数据，从而读取文件、扫描站点或触发拒绝服务。


情报来源：

https://www.ibm.com/support/pages/node/6475263



CVE-2021-30551-Chrome v8 类型混淆漏洞

高危

2021年7月27日，华云安思境安全团队发现 Chrome 组件中存在一处类型混淆漏洞。Google Chrome 是由 Google 开发的一款设计简单、高效的 Web 浏览工具，特点是简洁、快速。Google Chrome 基于更强大的 JavaScript V8 引擎，提升浏览器的处理速度。该漏洞是由于 Chrome 没有正确的处理访问的 Object 的命名属性引起，成功利用此漏洞的攻击者可在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终获取服务器权限。


情报来源：

https://chromereleases.googleblog.com/2021/06/stable-channel-update-for-desktop.html



CVE-2021-30807-Apple 远程代码执行漏洞

高危

2021年7月27日，华云安思境安全团队发现 Apple 官方发布安全更新，披露了 macOS、iOS、iPadOS 中存在远程代码执行漏洞。macOS、iOS、iPadOS 是 Apple 公司的操作系统。macOS、iOS、iPadOS 操作系统中的 IOMobileFrameBuffer 内核拓展中存在一处任意代码执行漏洞。成功利用此漏洞的远程攻击者可以通过诱使用户打开特定的应用程序，从而以最高权限在用户设备上执行任意代码攻击。


情报来源：

https://support.apple.com/en-us/HT212623

https://support.apple.com/en-us/HT212622



CVE-2021-32749-Fail2ban 远程代码执行漏洞

高危

2021年7月28日，华云安思境安全团队发现 Fail2ban 被披露存在一个远程代码执行漏洞。Fail2ban 是一个应用软件，主要用于禁止导致多个身份验证错误的主机。该漏洞是由于 Fail2ban 中存在安全问题，导致邮件操作 mail-whois 中可能存在远程代码执行漏洞。要利用该漏洞，攻击者需要通过 MITM 攻击或接管 whois 服务器将恶意字符插入到 whois 服务器发送的响应中。




Trend Micro Apex One 7月多个安全漏洞

高危

2021年7月28日，华云安思境安全团队发现 Trend Micro（趋势科技）官方发布安全更新，披露了 Apex One 和 Apex One as a Service（Apex One SaaS）组件中存在 CVE-2021-32464-Apex One 权限提升漏洞、CVE-2021-32465-Apex One 身份验证绕过漏洞、CVE-2021-36741-Apex One 任意文件上传漏洞、CVE-2021-36742-Apex One 本地提权漏洞等多个安全漏洞。ApexOne 是一套能够提供自动威胁检测和响应功能的端点安全防护软件。成功利用这些漏洞的攻击者可以绕过身份认证、上传任意文件、提升权限或执行其它未授权操作。目前，部分漏洞已被在野利用，华云安建议相关用户及时安装补丁。


情报来源：

https://success.trendmicro.com/solution/000287819


WebKit2GTK 多个安全漏洞

高危

2021年7月29日，华云安思境安全团队发现 WebKit2GTK 组件中存在释放后重用、整形溢出、缓冲区溢出、跨站脚本、访问限制绕过、输入验证不当等多个高危漏洞。WebKit 是 KDE、Apple、Google 等公司共同开发的一套开源的 Web 浏览器引擎，WebKitGTK 是 WebKit 引擎基于 GTK 环境的实现，包含 WebKit 的全部功能。成功利用此漏洞的远程攻击者可通过特制的网页内容执行任意代码或泄露敏感信息。


情报来源：

https://www.openwall.com/lists/oss-security/2021/07/23/1
