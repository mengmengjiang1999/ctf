华云安漏洞安全周报【第86期】
2022-06-10 13:25:01

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.5.23~2022.5.29）CNNVD接报漏洞1761个，信息技术产品漏洞（通用型漏洞）107个，网络信息系统漏洞（事件型漏洞）1654个，其中华云安报送漏洞9个；CNNVD接报漏洞预警146份，其中华云安报送预警17份，预警报送数量位列第三！

本周重点关注漏洞包括：CVE-2022-22497-IBM Aspera 未授权访问漏洞、CVE-2022-1854-Google Chrome UAF 漏洞、CVE-2022-26532-Zyxel 命令注入漏洞、CVE-2022-29405-Apache Archiva 密码重置漏洞、CVE-2022-1883-GitHub SQL 注入漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-22497-IBM Aspera 未授权访问漏洞

漏洞描述：

2022年5月24日，华云安思境安全团队发现 Oracle 官方发布安全更新，披露了 Oracle E-Business Suite 组件中存在一处信息泄露漏洞。IBM Aspera 支持分布式团队安全可靠地交换存储在任何本地数据中心或主要云环境中的多个大型文件和文件夹 支持全球分布的团队轻松开展协作 为了高效开展协作。该漏洞是由于对安全令牌验证不正确引起，成功利用此漏洞的攻击者通过发送恶意数据包，从而绕过安全验证访问数据。

情报来源：

https://www.ibm.com/support/pages/node/6589601

02CVE-2022-1854-Google Chrome UAF 漏洞

威胁等级：高危

漏洞描述：

2022年5月24日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome 组件中存在一处 UAF 漏洞。Google Chrome 是一款由 Google 公司开发的网页浏览器。该漏洞是由于 Google Chrome 中 ANGLE 组件中存在 UAF 的缺陷引起，成功利用此漏洞的攻击者通过创建一个特制的网页并诱使用户访问，从而导致在目标系统上执行任意代码。

情报来源：

https://chromereleases.googleblog.com/2022/05/stable-channel-update-for-desktop_24.html

03CVE-2022-26532-Zyxel 命令注入漏洞

威胁等级：高危

漏洞描述：

2022年5月24日，华云安思境安全团队发现 Zyxel 官方发布安全更新，披露了 Zyxel 组件中存在一处命令注入漏洞。Zyxel USG/ZyWALL 等都是ZyXEL 公司的防火墙产品。该漏洞是由于 packet-trace CLI 命令中的不正确的输入验证引起，成功利用此漏洞的攻击者可在目标系统上执行任意 shell 命令。

情报来源：

https://www.zyxel.com/support/multiple-vulnerabilities-of-firewalls-AP-controllers-and-APs.shtml

04CVE-2022-29405-Apache Archiva 密码重置漏洞

威胁等级：高危

漏洞描述：

2022年5月25日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Archiva 组件中存在一处密码重置漏洞。Archiva 是一个管理一个和多个远程存储的软件。该漏洞是由于受影响的版本未对密码重置功能的权限充分限制引起，成功利用此漏洞的攻击者可重置任何用户的密码。

情报来源：

https://archiva.apache.org/docs/2.2.8/release-notes.html

05 CVE-2022-1883-GitHub SQL 注入漏洞

威胁等级：超危

漏洞描述：

2022年5月25日，华云安思境安全团队发现 GitHub 官方发布安全更新，披露了 GitHub 组件中存在一处 SQL 注入漏洞。GitHub 是一个面向开源及私有软件项目的托管平台。该漏洞是由于 camptocamp/terraboard 中存在 SQL 注入引起，成功利用此漏洞的攻击者通过发送恶意请求，从而使程序获取请求参数并将它们传递给 db.SearchAttribute 方法，导致字符串拼接执行注入语句。

情报来源：

https://github.com/camptocamp/terraboard/commit/2a5dbaac015dc0714b41a59995e24f5767f89ddc
