华云安漏洞安全周报【第118期】
2023-01-28 10:59:35

根据国家信息安全漏洞库（CNNVD）统计，本周（2023.01.09~2023.01.15）CNNVD接报漏洞219个，其中信息技术产品漏洞（通用型漏洞）143个，网络信息系统漏洞（事件型漏洞）76个，CNNVD接报漏洞预警99份。其中华云安报送预警7份！预警报送数量均持续位居前列！

本周重点关注漏洞包括：CVE-2023-23559 Linux kernel 安全漏洞、CVE-2023-21764 Microsoft Exchange Server 安全漏洞、CVE-2023-21775 Microsoft Edge 安全漏洞、CVE-2023-22602 Apache Shiro 安全漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2023-23559 Linux kernel 安全漏洞

威胁等级：超危

漏洞描述：

2023年01月10日，华云安思境安全团队发现 Kernel 官网发布了安全更新，披露了Linux kernel 6.1.5及之前版本存在安全漏洞。Linux kernel是Linux基金会的开源操作系统Linux所使用的内核。披露版本中drivers/net/wireless/rndis_wlan.c中的rndis_query_oid存在整数溢出，攻击者会利用整数溢出可能导致的堆栈溢出或堆溢出在某些特定条件下来执行任意代码。

情报来源：

https://patchwork.kernel.org/project/linux-wireless/patch/20230110173007.57110-1-szymon.heidrich@gmail.com/

02CVE-2023-21764 Microsoft Exchange Server 安全漏洞

威胁等级：高危

漏洞描述：

2023年01月10日，华云安思境安全团队发现 Microsoft 官方网站发布了安全更新，披露了 Microsoft Exchange Server存在安全漏洞，该漏洞影响到 Microsoft Exchange Server 2019 Cumulative Update 11，Microsoft Exchange Server 2019 Cumulative Update 12,Microsoft Exchange Server 2016 Cumulative Update 23 等产品。Microsoft Exchange Server 是个消息与协作系统。它可以被用来构架应用于企业、学校的邮件系统。建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：

https://msrc.microsoft.com/update-guide/cn-ZH/vulnerability/CVE-2023-21764

03 CVE-2023-21775 Microsoft Edge 安全漏洞

威胁等级：高危

漏洞描述：

2022年01月12日，华云安思境安全团队发现 Microsoft 官方网站发布了安全更新，披露了 Microsoft Edge存在安全漏洞。Microsoft Edge是由 Microsoft 开发的基于 Chromium 开源项目及其他开源软件的网页浏览器。攻击者会利用该漏洞在某些特定条件下远程执行代码。

情报来源：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2023-21775

04CVE-2023-22602 Apache Shiro 安全漏洞

威胁等级：高危

漏洞描述：

2023年01月14日，华云安思境安全团队发现 Apache 官网发布了安全更新，披露了 Apache Shiro 1.11.0之前版本存在安全漏洞存在安全漏洞。Apache Shiro是一套用于执行认证、授权、加密、会话管理等功能丰富的综合安全框架。当该框架与Spring Boot 2.6+一起使用时，攻击者会构造特定的HTTP请求在某些特定条件下进行身份验证绕过。

情报来源：

https://lists.apache.org/thread/dzj0k2smpzzgj6g666hrbrgsrlf9yhkl
