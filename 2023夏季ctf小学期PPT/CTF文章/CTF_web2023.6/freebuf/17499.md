【威胁趋势】

卡巴斯基发表《2022年高级威胁预测报告》

Tag：威胁趋势，卡巴斯基，2022年

事件概述：

近日，卡巴斯基发表了《2022年高级威胁趋势预测报告》以预测2022年的高级威胁趋势。具体威胁趋势如下：

 1. APT威胁组织可能将会利用暗网从网络犯罪分子手中购买网络初始访问权限的资源；
 2. 网络事件通过起诉等法律手段而不是依赖外交渠道来处理的转变会促使越来越多的国家会将法律起诉作为其网络战略的一部分；
 3. 越来越多的美国公司会对0day 采取行动；
 4. 5G漏洞的出现；
 5. 由于执法机构对勒索软件组织的打压，促使勒索软件生态系统趋势发生转变，2022年，增强型勒索策略可能不再是勒索软件组织的重点；
 6. 2021年， Colonial Pipeline的勒索软攻击，伊朗铁路系统的 Wiper 攻击等多起具有破环性的攻击发生，可能促使2022年的攻击趋势更具破坏性；
 7. 新冠疫情肆虐，攻击者可能在2022年将继续利用新冠疫情开展攻击活动；
 8. 私营部门支持新的威胁组织的加入；
 9. 由于移动设备的不可替代性，2022年移动设备可能受到广泛攻击；
10. 供应链攻击可以为攻击者攻击许多其他目标铺下垫脚石，2022年供应链攻击可能会大幅增加；
11. 新冠肺炎盛行，在家办公成为不可抵挡的新趋势。2022年，攻击者可能会继续寻找机会利用未受保护或未打补丁的家用计算机，作为入侵企业网络的初始入口向量；
12. 地缘政治局势往往会促进APT攻击，而由于非洲引进了大规模投资，许多国家海上贸易处于战略地位，这一地理政治局势可能在2022年加剧针对非洲的APT攻击；
13. 由于越来越多的公司将云计算纳入其业务模式，云安全和外包服务在2022年将成为APT组织的主要攻击目标；
14. 低级攻击回归，bootkits 可能在2022年将被大幅利用；
15. 许多国家将会发布网络攻击分类法，准确详细说明禁止攻击向量的类型。

【金融威胁情报】

新型 Android 银行木马 SharkBot 针对美国和欧洲银行展开攻击

Tag：银行木马，SharkBot，欧洲银行
事件概述：

Cleafy 研究人员于10月末发现了一个新型 Android 银行木马 SharkBot 。该银行木马主要针对意大利和英国在内的22家国际银行以及美国的5个加密货币应用程序展开攻击，旨在通过绕过多因素身份验证机制（例如 SCA）的自动转账系统 (ATS) 技术从受感染设备发起资金转账，窃取货币。

技术详情：

SharkBot 银行木马通常伪装成"Live Net TV"、"UItData_Recovery"、"Media Player HD"合法应用程序的名称和图标，诱使目标安装伪装后的 SharkBot 银行木马。该木马会在安装的过程中不断弹出窗口请求权限启用无障碍服务，直至受害者授予权限。当木马在受害者设备上成功安装后，会通过模拟器检查、隐藏APP图标、加密通信进行防御规避。SharkBot 还可以读取/发送文本消息、执行覆盖攻击窃取凭据，并且通过REQUEST_IGNORE_BATTERY_OPTIMIZATIONS权限绕过 Android 的休眠组件与 C2 服务器保持通信，以继续执行其恶意行为。

参考链接：https://www.cleafy.com/cleafy-labs/sharkbot-a-new-generation-of-android-trojan-is-targeting-banks-in-europe

微步点评：
1、什么是ATS技术？
ATS（自动转账系统）是一种先进的攻击技术，攻击者可以利用ATS技术自动填充合法移动银行应用程序中的字段，并从受感染的设备启动资金转账。这可以促使在攻击者可以在最少的用户干预下扩展他们的操作。

  * ATS攻击不需要新设备注册阶段；
  * ATS攻击可以绕过任何双重身份验证机制；
  * ATS 攻击能够绕过行为检测机制；
  * .........

2、ATT&CK

  * 初始接入：伪装成合法应用
  * 权限提升：设备管理员权限
  * 防御规避：隐藏应用程序图标+规避分析环境+文件或信息混淆
  * 发现：规避分析环境+文件和目录发现
  * 凭据访问：输入提示+输入注入+输入捕获+捕获短信


【政府威胁情报】

伊朗驻阿布扎比大使馆网站遭到水坑攻击

Tag：伊朗，阿布扎比，水坑攻击

事件概述：

ESET 于近日发表报告称其监测到了针对伊朗驻阿布扎比大使馆网站的水坑攻击，接下来几周内还陆续发现了针对中东相关网站的水坑攻击。此次水坑攻击活动最早可追溯至2020年4月，攻击者将恶意代码注入了伦敦数字新闻网站中东之眼，7月底，攻击者将感染网站上的恶意代码清楚干净，这也是此次水坑活动的第一波攻击；第二波水坑攻击浪潮出现在2021年，直至8月的时候，所有感染网站的恶意代码再次被清理干净。目前，水坑攻击背后的运营商疑似暂停运营。

技术详情：

第一阶段：攻击者将 JavaScript 代码注入目标网站，此注入加载名为 reconnects.js 的远程 JavaScript 代码和合法的第三方库 GeoJS，用于查找 IP 地理位置。

第二阶段：指纹识别脚本，或者利用脚本检索默认语言、浏览器支持的字体列表、时区、浏览器插件列表等，并且在与 C&C 服务器的网络通信使用 AES 会话密钥进行加密。

MITRE ATT&CK：

  * 资源开发：收购基础设施（域、服务器）+失陷的基础设施（服务器）+获取能力（恶意软件、漏洞利用）+阶段能力(目标失陷)
  * 初始接入：水坑攻击+附件钓鱼
  * 执行：命令和脚本解释器(VB)
  * 命令与控制：应用层协议(Web)

【工控威胁情报】

数百万的路由器和物联网设备面临BotenaGo恶意软件的威胁

Tag：BotenaGo，物联网，漏洞

事件概述：

近日，AT&T Alien Labs 研究人员指出 BotenaGo 恶意软件部署了30多个漏洞利用程序，疑似针对数百万个路由器和物联网设备展开攻击。该恶意软件首次于2007年被发现，利用 Golang 语言编写。目前，该恶意软件的 AV 检测率极低，但尚不清楚恶意软件背后的攻击者和受感染设备的数量。

技术详情：

BotenaGo恶意软件首先会打印输出全局感染的数量，然后查找 “dlrs” 文件夹加载 shell 脚本文件，调用函数 “scannerInitExploits” 映射目标系统字符串。恶意软件还会通过创建31412 、19412端口的后门与 C2 通信和接收 C2 指令。

MITRE ATT&CK：

  * 横向移动：远程服务利用+入口工具转移
  * 命令与控制：非标准端口

参考链接：https://cybersecurity.att.com/blogs/labs-research/att-alien-labs-finds-new-golang-malwarebotenago-targeting-millions-of-routers-and-iot-devices-with-more-than-30-exploits


【流行威胁情报】

TrickBot 团伙滥用 Windows 10 应用安装程序部署 BazarLoader

Tag：TricikBot，BazarLoader，后门

事件概述：

Sophos Labs 研究人员在最近的攻击活动中发现了TrickBot 团伙开展的攻击活动，滥用 Windows 10 应用安装程序在目标系统上部署 BazarLoader 恶意软件。BazarLoader（又名 BazarBackdoor、BazaLoader、BEERBOT、KEGTAP 和 Team*9Backdoor）是一种隐蔽的后门木马，通常用于破坏高价值目标的网络并将对失陷资产的访问权出售给其他网络犯罪分子。它还被用于提供额外的有效载荷，例如 Cobalt Strike ，可帮助威胁组织访问受害者的网络并最终部署危险的恶意软件。

技术详情：

攻击者通过冒充 Sophos 首席经理助理向目标投递包含威胁性语言的电子邮件，受害者可以通过邮件中包含的超链接查看 Microsoft 云存储（*.web.core.windows.net）上的PDF 格式的投诉文件。并且攻击者还使用双重诱骗受害者使用 adobeview 子域安装 BazarLoader 后门，当后门在受害者设备上部署成功后，会收集系统信息并将信息通过 HTTP 协议回传到 C2 服务器。

参考链接：https://news.sophos.com/en-us/2021/11/11/bazarloader-call-me-back-attack-abuses-windows-10-apps-mechanism/


【高级威胁情报】

伊朗威胁组织利用 Microsoft Exchange 和 Fortinet 漏洞针对多个基础设施部门展开攻击

Tag：伊朗，威胁组织，基础设施，漏洞

事件概述：

11月17日，美国 CISA 发布告警信息称伊朗国家背景的威胁组织正在积极利用 Microsoft Exchange 和 Fortinet 漏洞针对运输部门、医疗保健部门、公共卫生部门在内的多个美国基础设施部门和澳大利亚组织展开攻击活动。

攻击时间线：

  * 2021年3月，威胁组织通过4443、8443、10443 端口扫描 Fortinet FortiOS 漏洞 CVE-2018-13379 ，并枚举存在FortiOS 漏洞 CVE-2020-12812 和 CVE- 2019-5591的设备。
  * 2021年5月，威胁组织利用 Fortigate 设备访问托管美国市政府域名的网络服务器，威胁组织还可能使用该用户名 elie 创建帐户，进一步开展恶意软件活动。
  * 2021年6月，这些威胁组织利用 Fortigate 设备访问了一家专门从事儿童医疗保健的美国医院相关的网络。
  * 截至2021年10月，这些威胁组织利用Microsoft Exchange ProxyShell 漏洞 CVE-2021-34473获取了一系列系统的初始访问权限。

【漏洞情报】

速自查！微步支持检测大规模在野利用的SonarQube未授权访问漏洞CVE-2020-27986

Tag：SonarQube，未授权访问漏洞，在野利用，严重漏洞

事件概述：

近日，微步情报局监测发现了大规模在野利用的SonarQube 未授权访问漏洞CVE-2020-27986。该漏洞是由于配置不当造成的未授权访问，攻击者可以利用该漏洞在未授权的情况下访问 api/settings/values 接口从而获取到 SMTP、SVN、GitLab 凭据，进一步获取其它敏感代码和数据信息，造成严重危害。

截至目前，微步在线威胁感知平台 TDP在内的多款产品均已支持检测。您可通过“微步在线研究响应中心”查看原文，或者直接在公众号后台回复“986”获取 SonarQube 未授权访问漏洞 CVE-2020-27986 的检测代码。

参考链接：https://mp.weixin.qq.com/s/iNVIgFW6dfZiwQUB2SGEvA


警惕！GitLab 严重漏洞在野被广泛利用，企业需立即自查

Tag：GitLab，在野利用，严重漏洞

事件概述：

双十一前夕，微步情报局利用 HFish 蜜罐与 OneEDR 联合行动捕获并处置了一起真实利用 GitLab 未授权远程命令执行漏洞（CVE-2021-22205）在野利用，攻击成功后可以进行挖矿攻击。由于该漏洞无需进行身份验证即可利用，危害极大，微步建议您及时查看是否属于以下受影响版本，并及时更新版本。

GitLab 受该漏洞影响的版本：

  * 9 <= GitLab（CE/EE）< 13.8.8
  * 9 <= GitLab（CE/EE）< 13.9.6
  * 10 <= GitLab（CE/EE）< 13.10.3

英特尔处理器被曝存在高严重性的权限提升漏洞
