华云安漏洞安全周报【第46期】
2021-08-13 13:23:42

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 8.2~2021.8.8）CNNVD接报漏洞1914个，信息技术产品漏洞（通用型漏洞）93个，网络信息系统漏洞（事件型漏洞）1821个，其中华云安报送漏洞138个；CNNVD接报漏洞预警88份，其中华云安报送预警7份，漏洞及预警报送数量持续位居前列！（数据来源于CNNVD）

本周重点关注漏洞包括：Google Chrome 多个安全漏洞、CVE-2021-29696-IBM Cloud Pak for Security 远程命令执行漏洞、CVE-2021-29741-IBM AIX 特权提升漏洞、CVE-2021-22930-Node.js 远程代码执行漏洞、Fortinet 8月多个安全漏洞、CVE-2021-1609-Cisco Small Business VPN 路由器任意代码执行漏洞、CVE-2021-22002-VMware 未授权访问漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

Google Chrome 多个安全漏洞

高危

2021年8月3日，华云安思境安全团队发现 Chrome 官方发布安全更新，本次更新共修复了10个漏洞，主要涉及堆缓冲区溢出、释放后重用、越界写入、越界读取、释放后重用、用户界面（UI）对关键信息的误传等多个类型的漏洞。Google Chrome 浏览器是一个由 Google 开发的网页浏览器。远程攻击者可创建一个特殊构造的网页，诱导用户访问，从而触发这些漏洞造成任意代码执行、仿冒网页内容、敏感信息泄露等。

情报来源：

https://chromereleases.googleblog.com/2021/08/the-stable-channel-has-been-updated-to.html

CVE-2021-29696-IBM Cloud Pak for Security 远程命令执行漏洞
高危

2021年8月3日，华云安思境安全团队发现 IBM 官方发布安全更新，披露了 IBM Cloud Pak for Security (CP4S) 组件中存在一处远程命令执行漏洞。IBM Cloud Pak for Security 是 IBM 公司的一款应用软件，一个开放的安全平台，可连接到现有的数据源以产生更深刻的见解，并能够更快地采取自动化行动。成功利用此漏洞的远程身份验证的攻击者可通过发送一个特制的请求，从而在系统上执行任意命令。

情报来源：

https://www.ibm.com/support/pages/node/6476940

CVE-2021-29741-IBM AIX 特权提升漏洞


高危

2021年8月3日，华云安思境安全团队发现 IBM 官方发布安全更新，披露了 IBM AIX 组件中存在一处特权提升漏洞。IBM AIX 是 IBM 公司的一款为 IBM Power 体系架构开发的一种基于开放标准的 UNIX 操作系统。本地用户可以利用 Korn Shell (ksh) 中的漏洞，从而获得最高（root）权限。

情报来源：

https://www.ibm.com/blogs/psirt/security-bulletin-vulnerability-in-ksh-affects-aix-cve-2021-29741/

CVE-2021-22930-Node.js 远程代码执行漏洞


高危

2021年8月3日，华云安思境安全团队发现 Node.js 官方发布安全更新，披露了 Node.js 组件中存在一处远程代码执行漏洞。Node.js 是一个基于 ChromeV8 引擎的 JavaScript 运行环境通过对 Chromev8 引擎进行了封装以及使用事件驱动和非阻塞 IO 的应用让 Javascript 开发高性能的后台应用成为了可能。该漏洞是由于在 Node.js 解析传入的 RST_STREAM 帧时，对接收到的 RST_STREAM 帧的处理中没有错误代码和取消错误代码（nghttp2_cancel），接收器将试图强制清除收到的任何数据。这会造成 nghttp2 关闭已经破坏的数据流，从而导致 double-free 错误。成功利用此漏洞的攻击者可通过构造恶意数据，最终造成远程代码执行。

情报来源：

https://nodejs.org/en/blog/vulnerability/july-2021-security-releases-2/

Fortinet 8月多个安全漏洞

超危

2021年8月3日，华云安思境安全团队发现 Fortinet 官方发布安全更新，修复了其产品中的22个安全漏洞，这些漏洞涉及 FortiSandbox 、FortiPortal、 FortiManager、FortiAnalyzer、 FortiOS和FortiAuthenticator。FortiPortal 是 Fortinet 公司的托管云安全策略管理和威胁分析产品，专为满足托管服务提供商 (MSP) 的托管服务需求而设计，其在多租户、多层级管理框架内提供一套全面的 Wi-Fi 和安全管理功能，使得 MSP 能够通过单一管理平台查看并管理其客户网络。成功利用这些漏洞的远程攻击者，可实现以 root 身份执行任意命令、在底层SQL数据库上执行任意命令、执行未授权的代码或命令等。

情报来源：

https://www.fortiguard.com/psirt?date=08-2021

CVE-2021-1609-Cisco Small Business VPN 路由器任意代码执行漏洞


超危

2021年8月4日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Small Business VPN 路由器中存在一处任意代码执行漏洞。未经身份验证的远程攻击者可以通过向受影响的设备发送恶意 HTTP 请求来利用此漏洞。成功利用此漏洞的攻击者能够在受影响的设备上执行任意代码或导致设备重新加载，从而造成拒绝服务（DoS）。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-rv340-cmdinj-rcedos-pY8J3qfy

CVE-2021-22002-VMware未授权访问漏洞


高危

2021年8月5日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Vmware vRealize Automation 组件中存在一处未授权访问漏洞。Vmware vRealize Automation 是 Vmware 公司的一个提供自助式云服务、监管式多云自动化的管理工具。该漏洞是由于软件对于 /cfg web 应用程序和诊断断点中的用户提供的输入缺乏充分验证引起。未经身份验证的能够访问443端口的远程攻击者可以通过篡改主机头来访问8443端口上的 /cfg web 应用程序和诊断端点。

情报来源：

https://www.vmware.com/security/advisories/VMSA-2021-0016.html
