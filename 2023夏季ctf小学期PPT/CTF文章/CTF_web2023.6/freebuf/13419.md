前言：

hackmyvm打靶系列文章。

本次文章只用于技术讨论，学习，切勿用于非法用途，用于非法用途与本人无关！

所有环境均为在线下载的靶场，且在本机进行学习。

一、信息收集

netdiscover -r 192.168.56.0/24

nmap -sV -Pn -sC 192.168.56.129

可以看见一个github的开源地址：https://github.com/rskoolrash/Online-Admission-System

这就很简单了，先去看看有没有exp，没有就审计

二、反弹shell

python3 -c "import pty;pty.spawn('/bin/bash');"获得一个较稳定的shell

三、提权

在/var/www/html下有隐藏文件

ls -a

密码：Myyogaiseasy

cat /etc/passwd，发现有个sandra的用户

尝试利用上面的密码进行登录，登录成功

瞅瞅有没有可以利用的suid的文件，但是没有

sudo -l 可以看见一个文件以root权限运行，且不需要密码

百度发现gerapy是一个管理框架，其有漏洞CVE-2021-43857，估计应该是启动这个服务，然后利用exp提权到root

启动gerapy，并且设置一个账号和密码

sudo gerapy init

sudo gerapy migrate

sudo gerapy createsuperuser﻿

sudo gerapy runserver 192.168.56.129:8080

之后exp使用反弹shell即可
