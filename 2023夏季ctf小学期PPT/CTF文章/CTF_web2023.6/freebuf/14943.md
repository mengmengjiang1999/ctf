2.ew实现网络代理

2.1 ew简介

ew 全称是EarchWorm，是一套轻量便携且功能强大的网络穿透工具，基于标准C开发，具有socks5代
理、端口转发和端口映射三大功能，可在复杂网络环境下完成网络穿透，且支持全平台(Windows/Linux/Mac)。该工具能够以“正向”、“反向”、“多级级联”等方式打通一条网络隧道，直达网络
深处，用蚯蚓独有的手段突破网络限制，给防火墙松土。

参考地址:EarthWorm (rootkiter.com)

2.2 ew模式以及常用参数

下载地址:https://github.com/idlefire/ew

1>ew的六种模式:(1)ssocksd;(2)rcsocks;(3)rssocks;(4)lcx_slave;(5)lcx_listen;(6)lcx_tran

ssocksd是用于普通网络环境下的正向连接。
rcsocks 和 rssocks 用于反向连接。
lcx_slave 、lcx_listen 和 lcx_tran 用于复杂网络环境的多级连接。

2>常用的参数

-l：指定要监听的本地端口
-d：指定要反弹到的机器 ip
-e：指定要反弹到的机器端口
-f：指定要主动连接的机器 ip
-g：指定要主动连接的机器端口
-t：指定超时时长,默认为 1000

2.3EW反向内网穿透

反向代理就是服务端(攻击机）监听，目标客户端主动连接我们的服务端。也就是红队人员的机器称之为客户端，开启一个监听，跳板机器来连接我们的机器。

靶机(10.10.20.12 192.168.44.129)

红队的服务器(192.168.44.128)把外网监听的888端口转发到本地的1008端口

客户端网络边界DMZ(192.168.44.129)连接我们服务端的888端口

如果我们的攻击机中显示出现rssocks cmd_socket OK!则代表隧道建立成功

2.4正向代理（目标机器有公网ip)

如果是Linux系统
./ew_for_linux64 -s ssocksd -l 1080 #监听本地的1080端⼝
如果是Windows系统
ew_for_Win.exe -s ssocksd -l 1080 #监听本地的1080端

主机设置:

（1）如果是Linux系统，配置proxychains代理链的配置⽂件，将代理设置成 100.100.10.12的1080端
⼝：socks5 100.100.10.12 1080
然后命令前⾯加上 proxychains即可。如：proxychains curl 192.168.10.19
(2)如果是Windows系统，直接浏览器中设置代理为 100.100.10.12的1080端⼝，或者利⽤ Proxifier
、sockscap64 设置全局代

7.pystinger(毒刺)

下载地址:https://github.com/FunnyWolf/pystinger/releases

毒刺(pystinger)通过webshell实现内网SOCK4代理,端口映射.

首先我们需要将webshell中对应的脚本语言上传到网站目录下。

然后将string_server.exe文件上传到目标服务器上(受害机器)

然后创建一个string.server.vbs文件来启动string_server.exe(string_server.exe不能直接使用命令启动)

string_server.vbs的内容为:

Set ws = CreateObject("Wscript.Shell")

ws.run "cmd /c xxxx\stinger_server.exe 0.0.0.0",vbhide

然后再终端中启动.vbs程序

将string_client上传到公网攻击机器,-w指定proxy的url地址

将会在攻击机的6000端口启用socks4a代理,然后可以使用SocksCap64 添加代理访问内网中的机器
