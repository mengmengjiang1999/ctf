华云安漏洞安全周报【第89期】
2022-06-28 10:52:26

本周重点关注漏洞包括：Microsoft 6月多个安全漏洞、CVE-2022-22979-Spring Cloud Function 拒绝服务漏洞、CVE-2021-33036-Apache Hadoop 命令执行漏洞、CVE-2022-20825-Cisco Small Business代码执行漏洞、CVE-2022-33140-Apache NIFI 命令注入漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 Microsoft 6月多个安全漏洞

威胁等级：高危

漏洞描述：

2022年6月14日，华云安思境安全团队发现 Microsoft 官方发布6月份安全更新，共61个漏洞的补丁程序。主要涵盖了Microsoft Windows 和 Windows 组件、Microsoft Azure Real Time Operating System、Microsoft Windows Defender、Microsoft Windows ALPC、Microsoft Windows File History Service、Microsoft Windows Local Security Authority Subsystem Service等。在漏洞安全等级方面，有高危漏洞29个，中危漏洞32个。在漏洞类型方面，主要有55个安全漏洞，1个输入验证错误漏洞，1个代码问题漏洞，1个操作系统命令注入漏洞，1个权限许可和访问控制问题漏洞，1个产品资源管理错误漏洞，1个安全特征问题漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Jun

02 CVE-2022-22979-Spring Cloud Function 拒绝服务漏洞

威胁等级：高危

漏洞描述：

2022年6月15日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Spring Cloud Function 组件中存在一处拒绝服务漏洞。Spring Cloud Function 是 Spring Boot 开发的一个 Servless 中间件（FAAS），支持基于 SpEL 的函数式动态路由。该漏洞是由于框架的 Function Catalog 组件的缓存中存在缺陷引起，成功利用此漏洞的攻击者通过直接与框架提供的查找功能交互，从而执行拒绝服务攻击。

情报来源：

https://tanzu.vmware.com/security/cve-2022-22979

03 CVE-2021-33036-Apache Hadoop 命令执行漏洞

威胁等级：高危

漏洞描述：

2022年6月15日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Hadoop 组件中存在一处命令执行漏洞。Apache Hadoop 是一套用于在由通用硬件构建的大型集群上运行应用程序的框架。该漏洞是由于对用户的身份未进行合理的权限限制引起，成功利用此漏洞的攻击者通过升级为 yarn 用户，从而执行以 root 身份的任意命令。

情报来源：

https://lists.apache.org/thread/ctr84rmo3xd2tzqcx2b277c8z692vhl5

04 CVE-2022-20825-Cisco Small Business 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年6月15日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了Cisco Small Business 组件中存在一处代码执行漏洞。Cisco Small Business RV110W、RV130、RV130W和RV215W Routers是美国思科（Cisco）公司 VPN 路由器产品。该漏洞是由于对传入 HTTP 数据包的用户输入验证不足引起，成功利用此漏洞的攻击者在未经身份验证的情况下通过向基于 Web 的管理界面发送精心设计的请求，从而在 root 权限执行任意命令。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-sb-rv-overflow-s2r82P9v

05 CVE-2022-33140-Apache NIFI 命令注入漏洞

威胁等级：高危

漏洞描述：

2022年6月16日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache NIFI 组件中存在一处命令注入漏洞。Apache NIFI 是一个易用、强大、可靠的数据处理与分发系统。该漏洞是由于 ShellUserGroupProvider 不会中和、解析命令的参数引起，成功利用此漏洞的攻击者在经过身份验证的情况下可在 Linux 和 macOS 平台上注入操作系统命令。

情报来源：

https://lists.apache.org/thread/bzs2pcdjsdrh5039oslmfr9mbs9qqdhr
