华云安漏洞安全周报【第83期】
2022-05-16 14:21:06

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.5.2~2022.5.8）CNNVD接报漏洞428个，信息技术产品漏洞（通用型漏洞）59个，网络信息系统漏洞（事件型漏洞）369个；CNNVD接报漏洞预警102份，其中华云安报送预警9份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-29917-Firefox 缓冲区溢出漏洞、CVE-2022-20777-Cisco Enterprise NFV Infrastructure Software 权限提升漏洞、CVE-2022-20779-Cisco Enterprise NFV Infrastructure Software 命令注入漏洞、CVE-2022-20780-Cisco Enterprise NFV Infrastructure Software XXE 漏洞、CVE-2022-27588-QNAP QVR 命令注入漏洞、CVE-2022-1388-F5 BIG-IP iControl REST 身份验证绕过漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-29917-Firefox 缓冲区溢出漏洞

威胁等级：高危

漏洞描述：

2022年5月3日，华云安思境安全团队发现 Mozilla 官方发布安全更新，披露了 Firefox 组件中存在一处缓冲区溢出漏洞。Firefox 是一个由 Mozilla 开发的自由及开放源代码的网页浏览器。该漏洞是由于 HTML 内容被处理时出现边界错误引起，成功利用此漏洞的攻击者通过诱使用户打开精心创建的恶意网页，从而触发内存损坏，导致在目标系统上执行任意代码攻击。

情报来源：

https://www.mozilla.org/en-US/security/advisories/mfsa2022-16/

02CVE-2022-20777-Cisco Enterprise NFV Infrastructure Software 权限提升漏洞

威胁等级：超危

漏洞描述：

2022年5月4日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Enterprise NFV Infrastructure Software 组件中存在一处权限提升漏洞。Cisco Enterprise NFV Infrastructure Software 是 Cisco 的一套 NVF 基础架构软件平台，该平台可以通过中央协调器和控制器实现虚拟化服务的全生命周期管理。该漏洞是由于 NGIO 功能中对用户访问的限制不足引起，成功利用此漏洞的攻击者在经过身份验证的情况下通过从 VM 发送 API 进行调用，从而在 NFVIS 主机上获得未经授权的root级访问权限。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-NFVIS-MUL-7DySRX9

03CVE-2022-20779-Cisco Enterprise NFV Infrastructure Software 命令注入漏洞

威胁等级：高危

漏洞描述：

2022年5月4日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Enterprise NFV Infrastructure Software 组件中存在一处命令注入漏洞。Cisco Enterprise NFV Infrastructure Software 是 Cisco 的一套 NVF 基础架构软件平台，该平台可以通过中央协调器和控制器实现虚拟化服务的全生命周期管理。该漏洞是由于输入验证不正确引起。未经身份验证的远程攻击者利用此漏洞能够在映像注册过程中注入在 NFVIS 主机上的 root-level 执行的命令。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-NFVIS-MUL-7DySRX9

04 CVE-2022-20780-Cisco Enterprise NFV Infrastructure Software XXE 漏洞

威胁等级：高危

漏洞描述：

2022年5月4日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Enterprise NFV Infrastructure Software 组件中存在一处 XXE 漏洞。Cisco Enterprise NFV Infrastructure Software 是 Cisco 的一套 NVF 基础架构软件平台，该平台可以通过中央协调器和控制器实现虚拟化服务的全生命周期管理。该漏洞是由于 XML 解析器未对外部实体解析进行禁止引起，成功利用此漏洞的攻击者在未经身份验证的情况下诱使管理员导入一个精心制作的文件，从而将系统数据从主机泄漏到任何已配置的虚拟机。

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-NFVIS-MUL-7DySRX9

05CVE-2022-27588-QNAP QVR 命令执行漏洞

威胁等级：超危

漏洞描述：

2022年5月5日，华云安思境安全团队发现 QNAP 官方发布安全更新，披露了 QNAP QVR 组件中存在一处命令执行漏洞。QNAP QVR 是中国台湾威联通公司的一个专业视频管理系统。该漏洞是由于系统中对输入验证不当引起，成功利用此漏洞的攻击者通过发送特制的数据传递给应用程序，从而在目标系统上执行任意命令攻击。

情报来源：

https://www.qnap.com/en/security-advisory/qsa-22-07

06CVE-2022-1388-F5 BIG-IP iControl REST 身份验证绕过漏洞

威胁等级：超危

漏洞描述：

2022年5月5日，华云安思境安全团队发现 F5 官方发布安全更新，披露了 F5 BIG-IP iControl REST 组件中存在一处身份验证绕过漏洞。F5 BIG-IP 是一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用交付平台。该漏洞是由于 BIG-IP 对用户发送的数据包过滤不足引起，成功利用此漏洞的攻击者通过发送恶意制作的请求，绕过 BIG-IP 中的 iControl REST 身份验证，从而执行任意系统命令、创建或删除文件以及禁用BIG-IP上的服务。

情报来源：

https://support.f5.com/csp/article/K23605346﻿
