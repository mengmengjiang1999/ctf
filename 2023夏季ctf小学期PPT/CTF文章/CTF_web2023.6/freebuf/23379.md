循环结构：FOR循环

FOR循环一般用于有明显边界范围的情况。

常用代码如下：

#coding=utf-8
Sum = 0
for i in range(1,101):
Sum = Sum + i
else:
print 'Sum=',Sum

循环结构：WHILE循环

WHILE循环一般用于循环次数难以确定的情况下：

常用代码如下：

#coding=utf-8
x = int(input('x='))
Sum = 0
while x!=0:
Sum = Sum + x
x = x-1
else:
print 'sum:',Sum
