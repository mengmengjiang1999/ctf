华云安一直持续跟进和研究前沿漏洞、复现和编写漏洞检测脚本（PoC），并赋能给自身产品。

01CVE-2021-35587

基本信息

编号：CVE-2021-35587

名称：Oracle Fusion Middleware 输入验证错误漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-01-18

漏洞描述及危害

Oracle Fusion Middleware（Oracle融合中间件）是美国甲骨文（Oracle）公司的一套面向企业和云环境的业务创新平台。该平台提供了中间件、软件集合等功能。Oracle BI Publisher是一款智能商务发布产品。该产品可将一定格式的数据输出成报表格式。Oracle Fusion Middleware 存在输入验证错误漏洞，该漏洞源于OpenSSO Agent组件中不正确的输入验证。攻击者可利用该漏洞执行任意代码。

影响范围

Oracle Access Manager 11.1.2.3.0

Oracle Access Manager 12.2.1.3.0

Oracle Access Manager 12.2.1.4.0

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://www.oracle.com/security-alerts/cpujan2022.html

02CVE-2021-21307

基本信息

编号：CVE-2021-21307

名称：Lucee Server 授权问题漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-02-11

漏洞描述及危害

Lucee server是一种动态的、基于Java的（JSR-223）标记和脚本语言，用于快速web应用程序开发。Lucee简化了webservices（REST、SOAP、HTTP）、ORM（Hibernate）、搜索（Lucene）、数据源（MSSQL、Oracle、MySQL等）、缓存（infinispan、ehcache和memcached）等技术。Lucee为Adobe ColdFusion©CFML提供了一个兼容层，使用更少的资源并提供更好的性能。Lucee Server中存在授权问题漏洞，该漏洞源于网络系统或产品中缺少身份验证措施或身份验证强度不足。

影响范围

5.3.5.00=<lucee_server<5.3.5.96

5.3.6.00=<lucee_server<5.3.6.68

5.3.7.00=<lucee_server<5.3.7.47

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://github.com/lucee/Lucee/commit/6208ab7c44c61d26c79e0b0af10382899f57e1ca

03 CVE-2021-21881

基本信息

编号：CVE-2021-21881

名称：Lantronix PremierWave 2050 操作系统命令注入漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2021-11-15

漏洞描述及危害

Lantronix PremierWave 2050是美国Lantronix公司的一个嵌入式企业 Wi-Fi 模块。用于提供可靠且始终在线的 5G Wi-Fi 连接。Lantronix PremierWave 2050 8.9.0.0R4版本存在操作系统命令注入漏洞，攻击者可利用该漏洞发送特殊设计的HTTP请求进行任意命令执行。

影响范围

Lantronix PremierWave 2050 8.9.0.0R4版本

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://www.lantronix.com/products/premierwave2050/

04CVE-2021-32305

基本信息

编号：CVE-2021-32305

名称：websvn 操作系统命令注入漏洞

等级：CRITICAL

CVSS：9.8

发布时间：2022-05-18

漏洞描述及危害

websvn是一个应用软件。一个在线Subversion存储库浏览器。WebSVN 2.6.1之前版本存在安全漏洞，该漏洞允许远程攻击者通过搜索参数中的shell元字符执行任意命令。

影响范围

WebSVN <2.6.1

解决方案

目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：https://github.com/websvnphp/websvn

05CVE-2021-20114

基本信息

编号：CVE-2021-20114

名称：Tecnick.com TCExam 信息泄露漏洞

等级：HIGH

CVSS：7.5

发布时间：2021-07-22

漏洞描述及危害

Tecnick.com TCExam是英国Tecnick.com公司的一套基于Web的开源电子考试系统。该系统主要用于在线考试等。TCExam 存在信息泄露漏洞，该漏洞源于默认设置中的访问限制错误。远程攻击者可利用该漏洞访问缓存备份目录，其中包括敏感的数据库备份文件。该漏洞允许远程攻击者获得未经授权的访问权限。

影响范围

TCExam：12.0.013 - 14.8.1

解决方案

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁及时更新官方的安全补丁。

补丁链接：

https://zh-cn.tenable.com/security/research/tra-2021-32?tns_redirect=true
