华云安漏洞安全周报【第52期】
2021-09-27 13:57:39

根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 9.13~2021.9.19）CNNVD接报漏洞428，信息技术产品漏洞（通用型漏洞）82个，网络信息系统漏洞（事件型漏洞）346个；CNNVD接报漏洞预警57份！（数据来源于CNNVD）

本周重点关注漏洞包括：Chrome 多个安全漏洞、Microsoft 多个安全漏洞、CVE-2021-41079-Apache Tomcat 拒绝服务漏洞、CVE-2021-38639-Windows win32k 本地提权漏洞、CVE-2021-36963-Windows 通用日志文件系统本地提权漏洞、CVE-2021-41303-Apache Shiro 权限绕过漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

Chrome 多个安全漏洞


高危

2021年9月14日，华云安思境安全团队发现 Google 官方发布9月份安全更新，披露了 Chrome 的组件中存在 CVE-2021-30625-Selection API UAF漏洞、CVE-2021-30626-ANGLE 内存越界漏洞、CVE-2021-30627-Blink layout 类型混淆漏洞、CVE-2021-30628-ANGLE 栈溢出漏洞、CVE-2021-30632-V8 越界写漏洞等多个高危漏洞。Chrome 是 Google 的一款 Web 浏览器，同时底层的 V8 引擎也是最重要的浏览器内核之一。成功利用这些漏洞的攻击者可以在浏览器上下文执行任意代码。

情报来源：

https://chromereleases.googleblog.com/2021/09/stable-channel-update-for-desktop.html

Microsoft 多个安全漏洞


严重

2021年9月15日，华云安思境安全团队发现 Microsoft 官方发布9月份安全更新，共发布了86个漏洞的补丁程序，同比上月增加了35个，主要覆盖了：Azure、Microsoft Edge、Microsoft Office、Microsoft Windows DNS、Visual Studio、Windows Installer、Windows SMB、Windows Kernel 和 Windows Update 等多个产品和组件。在漏洞安全等级方面，有3个严重漏洞，62个高危漏洞；在漏洞类型方面，主要有30个远程代码执行漏洞，27个权限提升漏洞以及13个信息泄露漏洞。对此，华云安建议相关用户及时到 Microsoft 官方下载安装对应的安全补丁进行更新！

情报来源：

https://msrc.microsoft.com/update-guide/releaseNote/2021-Sep

CVE-2021-41079-Apache Tomcat 拒绝服务漏洞


中危

2021年9月15日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Tomcat 组件中存在一处拒绝服务漏洞。Tomcat 是由 Apache 软件基金会下属的 Jakarta 项目开发的一个 Servlet 容器，实现了对 Servlet 和 JavaServer Page（JSP）的支持。该漏洞源于程序处理某些 TLS 数据包时存在无限循环，远程攻击者可以向应用程序发送特制的数据包，消耗所有可用的系统资源并导致拒绝服务条件。

情报来源：

https://lists.apache.org/thread.html/rccdef0349fdf4fb73a4e4403095446d7fe6264e0a58e2df5c6799434%40%3Cannounce.tomcat.apache.org%3E

CVE-2021-38639-Windows win32k 本地提权漏洞


高危

2021年9月16日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows win32k 组件中的存在一处本地提权漏洞。win32k 是 Windows 内核中提供 GUI 相关功能的内核模块，例如桌面、窗口的创建和管理，是 Windows 桌面系统的最重要的内核模块之一。该漏洞是由于 win32k 组件中存在 UAF 导致的任意地址写漏洞，成功利用此漏洞的攻击者在获得低权限的情况下，构造恶意数据执行本地权限提升攻击。

情报来源：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-38639

CVE-2021-36963-Windows 通用日志文件系统本地提权漏洞


高危

2021年9月16日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows 通用日志文件系统中存在一处本地提权漏洞。Windows 通用日志文件系统是一个通用目的的日志文件系统，它可以从内核模式或用户模式的应用程序访问，用以构建一个高性能的事务日志。该漏洞是由于 clfs.sys 组件中存在整数溢出漏洞，成功利用此漏洞的攻击者在获得权限的情况下，构造恶意数据执行本地提权攻击，最终获取服务器最高权限。

情报来源：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-36963

CVE-2021-41303-Apache Shiro 权限绕过漏洞


高危

2021年9月17日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Shiro 组件中存在一处权限绕过漏洞。Apache Shiro 是一套用于执行认证、授权、加密和会话管理的 Java 安全框架。该漏洞是由于 Apache Shiro 与 Spring 结合使用时存在绕过问题，成功利用此漏洞的攻击者在未授权的情况下，使用精心构造的 HTTP 请求可能会绕过身份验证。

情报来源：https://lists.apache.org/thread.html/re470be1ffea44bca28ccb0e67a4cf5d744e2d2b981d00fdbbf5abc13%40%3Cannounce.shiro.apache.org%3E
