OSCP-Vulnhub靶机记录-digitalworldlocal-fall
2022-09-11 15:48:21

vulnhub和htb有很多为OSCP准备的靶机，都可以打一打。

靶机下载地址;

https://www.vulnhub.com/entry/digitalworldlocal-fall,726/

一、安装靶机

这里可以得到靶机ip 192.168.179.132

二、信息收集

很多人用nmap,我一般用这个脚本，集成的扫描、枚举、漏洞检测各种功能：

https://github.com/21y4d/nmapAutomator

安装过程略

常用功能

./nmapAutomator.sh-h

Usage: nmapAutomator.sh-H/--host <TARGET-IP> -t/--type <TYPE>

Optional: [-r/--remote <REMOTE MODE>] [-d/--dns <DNS SERVER>] [-o/--output <OUTPUT DIRECTORY>] [-s/--static-nmap <STATIC NMAP PATH>]

Scan Types:

Network : Shows all live hosts in the host's network (~15 seconds)

Port : Shows all open ports (~15 seconds)

Script : Runs a script scan on found ports (~5 minutes)

Full : Runs a full range port scan, then runs a thorough scan on new ports (~5-10 minutes)

UDP : Runs a UDP scan "requires sudo" (~5 minutes)

Vulns : Runs CVE scan and nmap Vulns scan on all found ports (~5-15 minutes)

Recon : Suggests recon commands, then prompts to automatically run them

All : Runs all the scans (~20-30 minutes)

常用方法

./nmapAutomator.sh--host 10.1.1.1 --type All

./nmapAutomator.sh-H 10.1.1.1 -t Basic

./nmapAutomator.sh-H academy.htb-t Recon -d 1.1.1.1

./nmapAutomator.sh-H 10.10.10.10 -t network -s ./nmap

我们这里直接用All 方法

./nmapAutomator.sh-H 192.168.179.132 -t All

扫描结果保存在当前目录下，文件夹名是ip

用leafpad打开txt

开放端口还比较多：

80端口看看是什么

出现了一个用户名：qiu（后面有用）

再用wappalyzer插件看一下

中间件信息都有了

再回leafpad，搜索一下“enum”，看看枚举出什么目录

/admin/login.php: Possible admin folder

| /test.php: Test page

| /robots.txt: Robots file

| /phpinfo.php: Possible information file

| /doc/: Potentially interesting folder

| /icons/: Potentially interesting folder w/ directory listing

| /lib/: Potentially interesting folder

| /modules/: Potentially interesting folder w/ directory listing

| /tmp/: Potentially interesting folder w/ directory listing

|_ /uploads/: Potentially interesting folder

每个目录都去看一下

/test.php显示缺少GET参数：

那么，我们可以试一下，用哪个参数可以拼接进去

这里用wfuzz工具：

wfuzz -u 192.168.179.132/test.php?FUZZ-w /usr/share/wfuzz/wordlist/general/big.txt--hh 80

FUZZ就是插入参数的位置

-w 指定字典文件

--hh 隐藏char值为80的结果（错误的参数都这里报80，第一次wfuzz没有加此参数）

这里的GET参数是 file，可以尝试文件包含

打开burp,发送到repeater调试

尝试/etc/passwd:（https://blog.csdn.net/liukaitydn/article/details/83046083）

发现前面的qiu用户

qiu:x:1000:1000:qiu:/home/qiu:/bin/bash

权限高，能用bash

尝试用读取/home/qiu目录下默认存ssh密钥文件，通过前面扫描端口知道他是开了ssh的

我们需要知道ssh默认存私钥的目录，搜一下，告诉我们生成私钥的命令和位置：

ssh-keygen

/home/user/.ssh/id_rsa

复制保存到攻击机，key文件最后要有一个回车，否则登录不上去

尝试ssh登录qiu

ssh qiu@192.168.179.132-i sshkey

登陆成功：

ls 一下，提示我们是低权限用户

看一下历史输入命令：

remarkablyawesomE

这个应该就是密码，切一下root试试：

登录成功，root权限
