银行木马Numando的新攻击
2021-09-20 23:19:24

背景

拉丁美洲银行木马 Numando 自从 2018 年以来就一直保持活跃，尽管它不像 Mekotio 或 Grandoreiro 那样活跃，但它仍然会使用新技术，例如使用看似无用的 ZIP 文件或将 Payload 和 BMP 图片捆绑传递。Numando 几乎完全专注于巴西，并在墨西哥和西班牙也展开了攻击。

特征

Numando 是用 Delphi 编写的，并利用虚假的覆盖窗口从受害者那里窃取敏感信息。一些 Numando 变种将图片存储在资源段（.rsrc）内的加密 ZIP 文件中，而其他变种使用单独的 Delphi DLL 进行存储。

Numando 会模拟鼠标和键盘操作、重启机器、显示覆盖窗口、屏幕截图、终止浏览器进程。与其他拉丁美洲银行木马不同的是，命令是以数字的方式下发的，而非字符串。

Numando 会收集受害机器的 Windows 版本和位数信息。

分发与执行

Numando 几乎完全通过垃圾邮件进行分发。根据遥测信息，它最多影响了数百名受害者，其成功率远低于最成功的拉丁美洲银行木马，如 Mekotio 和 Grandoreiro。最近的攻击行动只是向每封垃圾邮件添加一个包含 MSI 安装程序的 ZIP 文件。

该安装程序包含一个 CAB 文件，其中包含一个合法应用程序、一个 Injector 和一个加密的 Numando 银行木马 DLL 文件。如果受害者执行 MSI 文件，最终也会运行合法的应用程序加载 Injector，然后使用带有多字节密钥的简单异或算法进行解密。

对于 Numando 来说，Payload 和 Injector 通常命名相同，带有 .dll扩展名的 Injector 和没有扩展名的 Payload，这使得 Injector 很容易加载加密的 Payload。令人惊讶的是，Injector 不是用 Delphi 编写的，这在拉丁美洲银行木马中非常罕见。

诱饵 ZIP 和 BMP

最近发现的攻击行动以 Delphi 编写的 Downloader 下载诱饵 ZIP 文件开始。Downloader 会从 ZIP 文件的注释中提取一个十六进制编码的加密字符串，Downloader 不解析 ZIP 文件结构而是查找整个文件的最后一个字符（用作标记）。解密字符串会产生一个不同的 URL，该 URL 指向实际的 Payload。

ZIP 文件包含一个合法的应用程序、一个 Injector 和一个可疑的 BMP 图片。Downloader 提取文件的内容并执行合法应用程序，侧加载 Injector 后再从 BMP 文件中提取 Numando 银行木马再执行。

配置

像许多其他拉丁美洲银行木马一样，Numando 也滥用公共服务来存储其配置信息，例如 YouTube 和 Pastebin。

格式十分简单，在 DATA:{和 }标记之间由 :分隔的三个条目。每部分都以与 Numando 中的其他字符串相同的方式单独加密，而且密钥硬编码在二进制文件中。这使得没有相应二进制文件的情况下很难进行解密，但 Numando 又不会经常更改解密密钥，这使得分析成为可能。

结论

Numando 是一种用 Delphi 编写的拉丁美洲银行木马。主要针对巴西、墨西哥和西班牙进行攻击，也使用虚假的覆盖窗口窃取信息，且植入恶意后门。
