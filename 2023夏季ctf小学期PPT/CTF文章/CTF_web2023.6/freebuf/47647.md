CISP-BDSA、CISP-CSE认证培训“黄埔班”开讲
2018-11-21 17:45:05

2018年11月20日，安恒信息联合中国信息安全测评中心（简称“国测”）在北京举行了注册信息安全专业人员-大数据安全分析师（Certified Information Security Professional-Big Data Security Analyst，简称CISP-BDSA）和注册信息安全专业人员-云安全工程师（Certified Information Security Professional-Cloud Security Engineer，简称CISP-CSE）培训班开班仪式。被誉为“黄埔班”的培训学员主要来源大型央企、部委等多家单位的信息安全技术人员和信息安全管理人员。

安恒信息首席安全官刘志乐出席认证培训班开班典礼并致辞，首席科学家刘博出席开班仪式，副总裁段平霞主持了本次会议。

CISP培训已经为我国培养了数万名信息安全专业人才，成为我国信息安全人才培养的重要力量。2017年，CISP启用的新知识体系，形成了设计与规划安全、安全实现、安全运营、安全管理、安全测评、软件安全开发及法规政策与标准等多个知识域。同时，新的知识体系融入了云计算、物联网、移动互联网、大数据安全/工业控制系统安全等新技术知识，为学员构建了一个完整的信息安全保障知识体系框架。

安恒信息首席安全官 刘志乐

刘志乐表示，大数据安全，云计算已经成为信息安全发展趋势。安恒信息凭借多年的行业实践经验及技术积累与中国信息安全测评中心成熟的认证体系相结合，推出了国内第一批面向新技术领域的专业系统化的安全认证培训：注册大数据安全分析师、注册云安全工程师及注册工业控制系统安全工程师，将人员培训和认证的领域细分到新兴的云计算、大数据、工控安全等领域。

安恒信息副总裁 段平霞

段平霞介绍，随着基础设施发生巨大转变，安全问题成为制约大数据平台、云计算平台落地的主要问题。在2018年中国信息安全从业人员现状调查中，职业教育已经取代自我学习成为信息安全人才能力成长的首选方式，云安全和大数据安全是首选的两大方向。今天参加培训的学员，无疑是这项培训的“黄埔班”。

安恒信息首席科学家 刘博

安恒信息是国测认定的“授权培训机构”之一， 是CISP-BDSA、CISP-CSE培训的授权运营机构。2017年“西湖论剑”期间，国测联合安恒信息举行网络空间安全人才培养战略合作发布仪式，正式启动CISM-WSE、CISP-ICSSE、CISP-BDSA和CISP-CSE四大认证项目。

安恒信息仍在身体力行地探索国内网络安全人才培养体系的建设，并将继续以培育一流网络安全人才为己任，充分发挥自身在网络安全人才培训、攻防实训、创新研发等领域的先进经验，把网络安全人才培养作为重中之重，集中优势资源，促进国家网络安全人才与创新基地发展。



关于CISP你了解多少？

什么是CISP

注册信息安全专业人员（简称 CISP）是经测评认证中心实施的国家认证，代表国家对信息安全人员资质的最高认可，也是信息安全企业申请安全服务资质必备的条件。 CISP 即“注册信息安全专业人员”，英文为Certified Information Security Professional (简称 CISP)，根据实际岗位工作需要， CISP 分成两类,分别是“注册信息安全工程师”（ CISE） ; “注册信息安全管理人员”（ CISO）。其中 CISE 主要从事信息安全技术开发服务工程建设等工作， CISO从事信息安全管理等相关工作。这两类注册信息安全专业人员是信息安全企业，信息安全咨询服务机构、信息安全测评认证机构（包含授权测评机构）、社会各组织团体、企事业单位中进行信息系统建设、运行和应用管理的技术部门（含标准化部门）所必备的专业岗位人员，其基本职能是对信息系统提供安全保障，其所具备的专业资质和能力，系经中国信息安全产品测评认证中心所注册的国家信息安专业人员。

什么是CISP-CSE

注册信息安全专业人员-云安全工程师（Certified Information Security Professional-Cloud Security Engineer，简称CISP-CSE）是中国信息安全测评中心实施的专业云安全工程师国家认证，旨在通过专业的系统化云安全培训，培养一批精通云计算原理，掌握云计算安全理论和实践的专业安全人才，帮助企业制定行之有效的上云安全策略，充分满足企业云上业务对安全、可靠、稳定、连续、高效等方面的要求。

CISP-CSE持证人员掌握云计算体系架构及关键技术、云计算安全威胁与需求分析、云计算安全技术、云计算安全防护应用、云计算安全管理、云安全政策法规与标准规范等知识内容，具备从事云计算安全规划和系统运维等安全工作的技能，可从事云计算安全设计、服务、运维、安全管理等工作。

CISP-CSE的价值在哪里

CISP-CSE是目前国内云安全领域最权威的认证。对于持证人员而言，获得CISP-CSE证书的过程本身就是全面学习掌握云安全领域前沿知识和技术的过程，有助于提升个人在云安全领域的竞争能力，使个人职业生涯稳步提升。信息安全专业认证已经逐步成为各行各业的对信息安全人才认定的方式，信息安全人员持证上岗已经成为大势所趋。

对于企业而言，通过专业的CISP-CSE培训培养自己的认证安全专家，能够满足企业业务向云上迁移时对信息安全规划、建设、维护能力要求，解决企业遇到的各类云上安全问题，降低云上业务风险，满足等级保护2.0时代监管部门对云上业务的合规性要求；尤其是对于专业的信息安全服务机构而言，拥有CISP-CSE证书持证雇员可以为客户提供更可信、更安全的云上服务，也是企业申请信息安全服务资质的必备加分项。

什么是CISP-BDSA

注册信息安全专业人员-大数据安全分析师（Certified Information Security Professional-Big Data Security Analyst，简称CISP-BDSA）是中国信息安全测评中心实施的大数据安全分析专业技术人员国家认证，旨在通过系统化实战化大数据安全分析培训，培养一批具有扎实的大数据分析理论基础和丰富的安全分析实战经验的专业人才，为安全行业提供完善的大数据技术服务和保障。

CISP-BDSA持证人员通过对大数据安全分析预备知识、大数据安全分析概述、大数据安全分析理论基础、大数据安全工程实现、大数据安全常见案例、大数据安全相关政策法规等知识内容的学习，具备大数据安全分析理论基础和实践能力，可从事大数据安全分析方案设计、大数据分析系统实现、大数据安全分析汇报、安全管理实施等工作。

CISP-BDSA的价值在哪里

CISP-BDSA是目前国内大数据安全领域最权威的认证。对于持证人员而言，获得CISP-BDSA证书的过程本身就是全面学习掌握大数据安全领域前沿知识和技术的过程，有助于提升个人在大数据安全领域的竞争能力，使个人职业生涯稳步提升。信息安全专业认证已经逐步成为各行各业的对信息安全人才认定的方式，信息安全人员持证上岗已经成为大势所趋。

对于企业而言，面对日趋复杂的网络环境和威胁态势，信息与网络安全需要基于大数据的安全分析。借助大数据安全分析技术，能够更加智能地洞悉信息与网络安全的态势，更加主动、弹性地应对无所不在的信息安全威胁和未知多变的风险。通过专业的CISP-BDSA培训培养自己的认证安全专家，能够满足企业长远的信息安全规划、建设、维护能力要求，有效解决企业遇到的信息安全问题，尤其是以0day、APT为代表的新一代高级安全威胁：对于专业的信息安全服务机构而言，拥有CISP-BDSA证书持证雇员可以为客户提供更可信的安全服务，也是企业申请信息安全服务资质的必备加分项。
