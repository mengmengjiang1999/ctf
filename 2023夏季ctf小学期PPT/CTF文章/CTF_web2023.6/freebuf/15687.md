前言

什么是文件上传漏洞？

文件上传漏洞是指利用WEB服务器上传某些特定文件到其文件系统。通常，文件上传漏洞是指用户上传可执行脚本文件，并通过该脚本文件获得执行服务器端命令的能力。

文件上传漏洞的原理

起因：

对允许用户上传的文件没有任何限制,导致可执行程序上传到网站的目录.

危害：

攻击者可能会上传一个充当 Web shell 的服务器端代码文件，从而有效地授予他们对服务器的完全控制权；

攻击者通过上传同名文件来覆盖关键文件；

容易受到目录遍历的攻击；

拒绝服务 (DoS) 攻击....

利用 条件：

上传文件的路径可知

上传的文件可以被访问

上传的文件可以被执行或包含

Web shell

Web shell 是一种恶意脚本，攻击者只需将 HTTP 请求发送到正确的端点，就可以在远程 Web 服务器上执行任意命令。

文件上传常见问题

文件上传对渗透测试的意义

文件上传属于获取Getshell的一种方法，属于最常规获取webshell的方法，所以寻找上传点比进入后台还重要，如果前台上传点你直接上传上去一个一句话木马，整个站点就拿下来了。

文件上传也需要做信息收集

信息收集中对web容器和用的动态语言和动态语言版本对文件上传非常有用，一个ASP的站，你传一个PHP的马，如果说没有特殊设置，那么这个马是不可能执行（但是有些情况下，他设置了解析，也是可以解析的）然后web容器也会存在一些解析漏洞，如iis6.0畸形解析、CGI解析漏洞。

客户端检测

客户端校验

一般是在网页上写一段Js脚本，用Js去检测，校验上传文件的后缀名，有白名单也有黑名单。

判断方式

在浏览加载文件，但还未点击上传按钮时便弹出对话框，内容如：只允许上传.jpg/.jpeg/.png后缀名的文件，而此时并没有发送数据包，所以可以通过抓包来 判断，如果弹出不准上传，但是没有抓到数据包，那么就是前端验证

前端验证非常不可靠，传正常文件改数据包就可以绕过，甚至关闭JS都可以尝试绕过。

黑白名单机制

黑名单：不允许上传什么

白名单：只允许上传什么

白名单比黑名单更安全

实战

Pass-01 前端验证绕过

1.上传 .jpg/png/gif 然后抓包改后缀 php

修改木马文件 tx.php 的后缀为 tx.jpg，上传jpg文件在使用Burpsuite拦截修改文件名为 tx.php，再连接蚁剑即可获取 Web shell.


2.直接关闭 JavaScript

关闭 JavaScript,然后可以直接上传木马文件 1.php，连接蚁剑即可获取 Web shell.

  



服务器检测

服务端检测几个常见的手段：

检查 Content-Type （内容类型）

检查后缀 （检查后缀是主流）

检查文件头

如何绕过Content-Type （内容类型）和文件头检测，这个时候我们可以去制作一个图片马，图片马可以很好的绕过内容类型和文件头。

图片马制作

1.写一个一句话木马放在 txt 文件然后找一张你喜欢的图片（注意文件大小，越小越好）

2.打开 cmd，

输入

copy tx.png/b + tx.txt tx.jpg (将 tx.png 和 tx.txt 合并为 tx.jpg (注：这个是效果))

实战

Pass-02 Content-Type方式绕过

文件类型修改绕过

只要上传的文件后缀是 .php 就行

上传 .php 类型文件，抓包修改 content-type 的值为 image/gif 即可

Pass-03 黑名单绕过

不允许上次 .asp，.aspx，.php，.jsp 后缀的文件

黑名单绕过机制其实不严谨，很明显这个过滤不严谨，

在php中

默认状态下 .php3,.php4,.php5,.phtml 都是会被解析为php的

所以这里上传一个 phtml 类型文件即可

能被解析的文件拓展名列表

 1. jsp jspx jspf
 2. asp asa cer aspx
 3. php php3 php4 php5 phtml
 4. exe exee


Pass-04 .htaccess文件绕过

.htaccess （Hypertext Access）:超文本入口/分布式配置文件

提供了针对目录改变配置的方法，在一个特定的文档目录中放置一个包含一个或多个指令的文件， 以作用于此目录及其所有子目录。

功能:

文件夹密码保护、用户自定义重定向、自定义404页面、扩展名伪静态化、禁止特定IP地址的用户、只允许特定IP地址的用户、禁止目录列表...

但，这个功能在Apache默认是不开启的。

例如：

AddType application/x-httpd-php .jpg 这个指令代表着 .jpg 文件会当做 php 来解析

注：若无法将文件名命名为 .htaccess ，可以使用 cmd 的重命名

命令：

ren tx.txt .htaccess

所以这里先上传一个写入 AddType application/x-httpd-php .jpg 指令的 .htaccess文件，然后在上传一个 .jpg文件即可。

  


Pass-05 后缀大小写绕过

由于开发不严谨没有写入大小写规则导致被绕过

这里可以直接上传 .Php/PHp/PHP 文件即可


Pass-06 文件后缀（空）绕过

在文件名后面留一个空格，然后上传上去后空格会被自动的省略。

所以可以先上传 .php 文件，然后抓包在文件名后面加一个空格进行绕过即可。


Pass-07 文件后缀(点)绕过

windows有一个特性，会自动去掉后缀名最后的.

所以可以先上传 .php 文件，然后抓包在文件名后面加 . 即可绕过。


Pass-08 ::$DATA（Windows文件流绕过）

利用到了NTFS交换数据流（ADS），ADS是NTFS磁盘格式的一个特性，在NTFS文件系统下，每个文件都可以存在多个数据流。

通俗的理解，就是其它文件可以“寄宿”在某个文件身上，而在资源管理器中却只能看到宿主文件，找不到寄宿文件。

藏文件的小福利：

打开cmd输入

echo 123456>>a.txt:b.txt 将123456写入 a.txt:b.txt，很明显生成一个a.txt

然后再试试 a.txt::$DATA

::$DATA就是默认不修改文件流的情况

echo 123456>>a.txt::$DATA

生成一个正常的a.txt

所以可以利用windows特性，可在后缀名中加 ”::$DATA” 即可绕过。


Pass-09 构造文件后缀绕过

由于开发不严谨，过滤空格和点，只写了一次检测没有进行循环检测。

所以可以用BurpSuite抓包上传.php. .一句话木马文件即可绕过。

Pass-10 双写文件后缀绕过

这里的意思就是讲检测到的危险字符替换为空，php 被替换为空是空，那么 pphphp 被替换为空就会变为php,不就达到了绕过。

所以可以用BurpSuite抓包上传.pphphp一句话木马文件即可绕过。
