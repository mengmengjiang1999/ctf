python使用语雀Api快速搭建hexo博客
2021-08-19 22:36:08

前言：

之前就搭建过hexo，无奈于其md格式文件，麻烦的很，图片还要存储桶，我这种懒人也不想去运营。

在网上发现此法进行快速上线文章,关键是还可以白嫖语雀的图床（网上采用nodejs，本人改了一个python的脚本出来）（光速上线还就那个乱杀），故此分享给大家

基本环境：hexo博客系统+python+语雀api进行文章读取。

一、hexo环境搭建（有环境的可以跳过这一步）

Tips：

hexo只是我们生成静态文章的工具人，随便在哪搭建都可

第一步：腾讯云启动node.js镜像

腾讯云直接选择node.js的应用镜像，因为hexo的seveeless组件只支持10.0版本以上了。

第二步：安装hexo

使用如下命令安装hexo以及需要的组件。

npm install -g serverless
npm install -g hexo-cli

可以使用 hexo v 查看是否安装成功

第三步：hexo初始化

初始化博客目录，也可以采用hexo init blog

git clone https://github.com/hexojs/hexo-starter.git blog
cd blog
git submodule init
git submodule update
npm config set registry http://registry.npm.taobao.org
npm i

第四步：检测是否安装成功

切换到blog目录下，运行hexo s查看是否成功

二、申请语雀Token

点击账户设置——>Token

这里选择读取你的知识库、读取你的文档即可

需要注意的是：此Token可以读取任意知识库包括仅个人可见，所以推荐使用小号新建一个知识库使用

三、调用语雀Api读取知识库文档

第一步：获取知识库id

import requests
import sys
import json
url = 'https://www.yuque.com/api/v2'
heard={
'user-agent' : "yuque-hexo with python",
'X-Auth-Token' : "填写你的语雀Token"
}
# 访问API并鉴权
Request = requests.get(url+'/user',headers=heard)
if Request.status_code == 401:
print("Make sure your Yuque Token is correct!!!")
sys.exit(0)
# 获取 login
userinfo_dic = json.loads(Request.text) # print(data_dic['data']['login'])
login = userinfo_dic['data']['login']
# 获取 知识库 id
Request = requests.get(url + '/users/' + login +'/repos',headers=heard)
bloginfo_dic = json.loads(Request.text)
for i in range(len(bloginfo_dic['data'])):
name = bloginfo_dic['data'][i]['name']
id = str(bloginfo_dic['data'][i]['id'])
print("知识库\"{0}\"的id是：{1}".format(name,id))

第二步：获取知识库文档

需要注意的点：

1、python脚本放在hexo 生成的 blog目录下

2、在脚本中填写完token和知识库id

3、文章获取一遍不会重新获取，需要删除./source/_posts/中的md文件即可重新获取

4、记得语雀中一定要点击发布文章，文章内容才可以被读取

import requests
import sys
import json
import re
import os
import shutil
import time
#获取时间
localtime = time.asctime( time.localtime(time.time()) )
localtime = time.strftime("%Y-%m-%d %H:%M:%S", time.localtime()) 
url = 'https://www.yuque.com/api/v2'
heard={
'user-agent' : "yuque-hexo with python",
'X-Auth-Token' : "填写你的语雀Token"
}
# 访问API并鉴权
Request = requests.get(url+'/user',headers=heard)
if Request.status_code == 401:
print("Make sure your Yuque Token is correct!!!")
sys.exit(0)
print("Token正确！！！")
# 获取 知识库 文档的信息
id = '填写你的知识库id'
Request = requests.get(url + '/repos/'+id+'/docs',headers=heard).text
posts_info_dict = json.loads(Request)
# 获取 知识库 文档的具体内容
for i in range(len(posts_info_dict['data'])):
# 获取所有文章内容
print("")
file_name = posts_info_dict['data'][i]['title']
exits_file_dict = os.listdir('./source/_posts/')
if file_name+'.md' in exits_file_dict:
print("文章已存在\""+file_name+"\"，抬走下一个")
continue
print("正在获取文章\""+file_name+"\"，请稍等")
os.system('hexo new '+file_name)
print("hexo 新建文章成功！")
slug = posts_info_dict['data'][i]['slug']
Request = requests.get(url + '/repos/'+id+'/docs/'+slug,headers=heard).text
print("获取文章\""+file_name+"\"成功，请稍等")
posts_test_dict = json.loads(Request)
posts_text = posts_test_dict['data']['body']
posts_text = re.sub(r'\\n', "\n", posts_text)
result = re.sub(r'<a name="(.*)"></a>', "", posts_text)
f = open('./source/_posts/'+file_name+'.md','a',encoding="utf-8")
f.writelines(result)
print("写入文章\""+file_name+"\"成功，请查看./source/_posts/目录下")
f.close()

四、解决语雀图床检测referer

我使用的是next主题，在主题中的themes\next\layout这个目录下可以找到hexo的模板文件_layout.swig，在<head>中添加<meta name="referrer" content="never">即可解决

五、启动hexo查看效果

在blog目录下使用hexo s命令启动hexo

当然还可以使用 hexo g 生成静态文件，然后自己再魔改主题一下。
