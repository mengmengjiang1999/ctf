英国国家彩票公益基金发生数据泄露

Tag：彩票，基金，数据泄露，英国

事件概述：

英国国家彩票公益基金于7月22日披露数据泄露事件，此次数据泄露影响UK Portfolio、England Fund 和Building Better Opportunities客户在 2013 年 9 月至 2019 年 12 月期间提供的数据。英国国家彩票公益基金表示此次数据泄露事件不会影响通过北爱尔兰、苏格兰和威尔士国家彩票资助项目提交资助申请的人员。此次事件泄露的数据是拨款申请期间以及现有拨款持有人提供额外信息时提交的数据，具体包括姓名、实际地址、电子邮件地址、固定电话、手机号码、出生日期、银行详细信息(银行账户名称、分类代码、账号)以及申请组织的地址和网站，并且该组织强调不涉及银行账户 PIN 码、密码和银行卡详细信息。

截至目前，英国国家彩票公益基金已向信息专员办公室（ICO）报告该数据泄露事件，但并未透露攻击事件的详情以及受此事件影响的受害者数量。英国国家彩票公益基金对于此次事件造成的影响表示歉意，还敦促可能受到影响的人员及时更新在线账户的密码，警惕并防范电子邮件、电话、银行账户中的欺诈活动。

美国弗洛里达州经济机会部披露数据泄露事件

Tag：DEO，数据泄露

事件概述：

美国弗洛里达州经济机会部（DEO）于近日报道称遭到恶意攻击，数据发生泄露，57920 个账户受到影响。一位 ID 名为 GReg Angel 的用户于7月24日在推特上转载了 DEO 关于此次事件声明的电子邮件，邮件显示恶意攻击者可能在今年4月27日至7月16期间通过 CONNECT 公共申请门户网站攻击了申请人的账户，申请人的社会安全号码、驾驶证号码、银行账号、申请信息、地址、电话号码和出生日期等信息遭到泄露。CONNECT 是民众用来提交失业救济金的数据库，报道还提到恶意攻击者可能已经获取了用户用来访问CONNECT 账户的 PIN。

作为安全防范措施，DEO在表示会为受影响的用户提供身份保护服务的同时，还表示会主动锁定 CONNECT 帐户，增强其身份验证程序和网络安全系统，以抵御未来的威胁。此外，DEO 建议受影响的用户监控其信用账户中是否存在未经授权的活动，如果存在可疑活动应及时与所在的金融机构取得联系。

TA456 针对国防承包商展开攻击活动

Tag：TA456，国防承包商

事假概述：

Proofpoint 的安全研究人员发现，伊朗黑客组织 TA456（也称为“Tortoiseshell”和“Imperial Kitten”）使用恶意软件对国防承包商多次展开针对性的攻击活动。据 Facebook 透露，该组织的主要目标是是美国、英国和欧洲的大约 200 多家航空航天国防公司。研究人员指出，该活动至少持续了 18 个月。在整个过程中，黑客伪装成来自英国利物浦的健美操教练发起攻击活动，破坏他们的系统以泄露敏感数据。据报道，名为“Marcella Flores”的虚假个人资料账户已被威胁组织停用。

技术详情：

攻击者利用在 Facebook 和 Instagram 上创建的“Marcella Flores”的个人账户，并利用这个虚假的个人资料伪装健美操教练尝试与目标建立联系，通过邮件和私人消息与目标通信，然后该组织试图通过在持续的电子邮件通信线程中向客户发送客户端恶意软件LEMPO。该恶意软件会在目标机器上收集日期、时间、 计算机名、用户名、系统信息 、任务列表 软件和版本等信息。

MeteorExpress 活动：伊朗铁路系统服务中断

Tag：铁路，Wiper

事件概述：

多家媒体于早期报道，伊朗火车系统于2021年7月9日遭到黑客组织恶意攻击，火车系统发生瘫痪，但并没有包含技术细节。SentinelLabs 的研究人员对此次攻击链的大部分进行了重建，其中包括一个以前并未出现的擦除器。研究人员还通过 OPSEC 错误发现了攻击者对此擦除器的命名“Meteor”，然后并将此次活动命名为 “MeteorExpress”。

技术详情：

研究人员发现攻击者利用组策略分发CAB 文件进行攻击活动，整个工具包由批处理文件组合而成，这些批处理文件协调了从RAR归档文件中释放的不同组件。cache.bat 在整个攻击过程中会断开受感染设备与网络的连接，然后检查计算机上是否安装了卡巴斯基防病毒软件，如果安装，它将退出执行。Meteor 根据加密配置对文件系统进行加密，nti.exe破坏 MBR 和利用mssetup.exe 锁定系统。

两部委发布《关于加快推动新型储能发展的指导意见》

Tag：新型储能发展

事件概述：

7月23日,国家发改委、国家能源局发布《关于加快推动新型储能发展的指导意见》。指导意见以实现新型储能从商业化初期向规模化发展转变为主要目标。以指导意见提出坚持储能技术多元化,推动锂离子电池等相对成熟新型储能技术成本持续下降和商业化规模应用,实现压缩气、液流电池等长时储能技术进入商业化发展初期,加快飞轮储能、钠离子电池等技术开展规模化试验示范,以需求为导向,探索开展储氢、储热及其他创新储能技术的研究和示范应用。

《指导意见》还提出，统筹开展储能专项计划，一是要各地区规模及项目布局，并做好与相关规划的衔接；二要积极推动电网侧储能合理化布局，通过关键节点布局电网侧储能，提升大规模高比例新能源及大容量直流接入后系统灵活调节能力和安全稳定水平。三是积极支持用户侧储能多元化发展。鼓励围绕分布式新能源、微电网、大数据中心、5G基站、充电设施、工业园区等其他终端用户，探索储能融合发展新场景。

工控威胁情报

Newark 发布《2021年全球物联网趋势报告》

Tag：物联网，安全趋势

事件概述：

Newark 是一家为电子系统设计、维护和维修提供技术产品、服务、解决方案的高服务分销商。该公司在2020年9月至2020年12月期间通过与全球客户群取得联系进行物联网问卷调查，汇总来自60多个国家物联网解决方案工程师的2,095份问卷，发表了《2021年物联网趋势报告》。

研究报告对物联网的发展趋势做出如下五项总结：

  * 物联网实施方面处于领先地位的三个行业是工业自动化和控制（25%）、家庭自动化（18%）和人工智能（12%）；
  * 医疗保健行业应用物联网将会大幅增长，该行业将成为下一个利用物联网创新造福人类健康福祉的大行业；
  * 工业 4.0 和工业物联网在制造业中的缓慢增长的最主要是有3类原因：对数据安全的担忧（32%）、缺乏商业战略（30%）和现有复杂遗留系统中改造的难度和技术限制（29%）；
  * 人们更倾向于使用内部设计进行物联网系统开发工作，而不是使用任何第三方物联网系统设计；
  * 互操作性 (19%)、易于开发 (19%)、需要开放标准 (19%)、连接标准 (16%)成为参会者认为加速物联网发展的因素等。

南非铁路、港口和管道公司 Transnet 遭到网络攻击，导致港口停止运营

Tag：港口，运营，网络攻击

事件概述：

南非国有铁路、港口和管道公司 Transnet 于7月22日遭到网络攻击，导致其在德班、恩古拉、伊丽莎白港和开普敦的集装箱码头停止运营。Transnet 称此次的网络攻击、安全入侵和破坏行为，导致TPT正常流程、功能中断和设备信息被破坏或损坏。

Transnet 在7月27日声明称不可抗力影响因素将很快解除，大多数受影响的应用程序已于2021年7月26日（周一）启动，预计在接下来的几天内一些程序可能会继续缓慢运行，所有操作系统将以交错的方式恢复，以尽量减少进一步的风险，并且会按计划停泊船只，促进航运公司的装卸作业。Transnet 还透露：“除集装箱码头除外，整个系统的港口码头都在运行，因为卡车运输方面的 Navis 系统受到了影响。在东开普省，由于恶劣的天气条件，终端运营已经停止，一旦安全，将继续手动操作”。

据路透社报援引两名熟悉此事的消息人士的话语报道称，Transnet 已要求一些未参与运营的员工休假，直到问题得以解决。

CODESYS 修补工业自动化产品中的十几个漏洞

Tag：CODESYS，工业，自动化，漏洞

事件概述：

工业自动化软件供应商 CODESYS 本月向客户通报了影响各种产品的十几个漏洞，其中这些不安全反序列化漏洞 CVE-2021-21863、CVE-2021-21864、CVE-2021-21865、CVE-2021-21866、CVE-2021-21867、CVE-2021-21868、CVE-2021-21869 是由思科发现的，其细节已于周一公布。CODESYS 漏洞 CVE-2021-33485 是 CODESYS V3 Web 服务器中基于堆的缓冲区溢出漏洞，攻击者可利用该漏洞进行 DoS 攻击，或使用特制请求进行远程代码执行。

CODESYS 于7月22日发布了新的公告，针对其开发系统、V3 web服务器、网关、VxWorks 运行时工具包和 EtherNetIP 产品的远程代码执行、拒绝服务(DoS)和信息泄露漏洞提供了补丁。

黑客组织疑似针对2021东京奥运会展开攻击活动

Tag：东京，奥运会，wiper，数据泄露

事件概述：

近日外媒报道称，一家日本安全公司 MBSD 发现了一个以奥运会为主题的恶意软件样本，其中包含在受感染系统上擦除文件的功能，并且似乎该样本只针对日本 PC。Wiper 是 MBSD 于2021年东京奥运会开幕式前两天发现的，该 Wiper 不仅能删除电脑上的所有数据，还能搜索用户 Windows 下C:/User/<username> 的文件，Microsoft Office文件、TXT、LOG、CSV文件也是其删除的目标。此外，该 Wiper 还针对由日本文字处理器 Ichitaro创建的文件。该 Wiper 还具有大量反分析和反 VM 检测技术，以及擦除完成后自行删除的能力。在进行擦除时，Wiper 还会使用cURL 应用程序访问 XVideos 成人视频门户上的页面。恶意软件使用 PDF 图标进行伪装，仅针对用户文件夹下的数据，MBSD 研究人员认为该恶意软件可能旨在感染没有管理员权限的账户。

据共同通讯社报道称，东京奥运会购票人信息在网上泄露，但负责人表示泄露规模不大，并且已经采取措施防止此类信息传播。

LemonDuck 恶意软件分析报告

Tag：LemonDuck，Windows，Linux

事件概述：

微软于上周发表文章表示 LemonDuck 是一种积极更新和强大的恶意软件，主要以其僵尸网络和加密货币挖掘目标而闻名，主要专注于制造业和物联网等领域发起攻击，其受害者主要位于美国、俄罗斯、德国、英国、印度、韩国、加拿大和越南。

LemonDuck 的活动于2019年5月在中国首次被发现，之后它在2020年开始在电子邮件攻击中采用COVID -19主题的诱饵，甚至利用“ProxyLogon”Exchange Server 漏洞以访问未修补的系统。另一个值得注意的策略是，它能够“通过清除竞争恶意软件，并通过修补用于访问的相同漏洞，防止任何新的感染，从而消除其他攻击者”。

当 LemonDuck 采取更复杂的行为并升级其操作时，它遵循了同样的轨迹。LemonDuck 除了将资源用于其传统的机器人和挖矿活动之外，LemonDuck 还会窃取凭据、移除安全控制、通过电子邮件传播、横向移动，并最终为人工操作的活动释放更多工具。

Praying Mantis 威胁组织利用 Web 应用程序中的漏洞展开攻击活动

Tag： Praying Mantis，Web，漏洞

事件概述：

近日，安全公司 Sygnia 表示 Praying Mantis 威胁组织正在通过利用面向互联网的 Web 应用程序中的漏洞对美国企业发起攻击活动，窃取凭据和其他数据。Sygnia 将Praying Mantis威胁组织称为 TG1021，并表示该活动自 2020 年 6 月以来一直在进行。在某些情况下，该组织利用 Checkbox Survey（一个云托管的调查和报告分析平台）中的 0day 漏洞，使其能够破坏用于 Web 托管的 Windows Internet 信息服务服务器。Sygnia 还表示该组织在利用漏洞后，该组织部署了一个恶意软件后门来收集系统信息，还部署额外的 Java Script 恶意软件执行 HTTP 和 SQL 流量转发，收集凭据并危害更易受攻击的服务器。

Sygnia 还表示由于该威胁组织使用大量 Web 应用程序漏洞，行动的迅速性和多功能性，再加上开发后活动的复杂性，表明该组织是一个先进且技术娴熟的威胁组织。

技术详情：

Praying Mantis威胁组织通过利用各种针对 Windows IIS 服务器的反序列化漏洞和针对 Web 应用程序的漏洞，在网络中获得了最初的立足点。该组织还利用为 IIS 服务器量身定制的完全易变的自定义恶意软件框架，核心组件加载到面向 Internet 的 IIS 服务器的，拦截并处理服务器收到的任何 HTTP 请求，并使用额外的隐蔽后门和几个后利用模块来执行网络侦察、提升特权和在网络内部进行横向移动。

FIN7 针对律师事务所展开攻击活动

Tag：FIN7，APT，律师事务所，逮捕

事件概述：

近日，eSentire 报道称多名 FIN7（又名 Carbanak Group）的多名成员虽然遭到逮捕和定罪，但该组织依然继续发展其商业模式和工具集。在2021年6月的第一周，FIN7 组织发起投机性的恶意垃圾活动，围绕美国大型葡萄酒和烈酒公司 Brown-Forman进行虚假法律投诉。6月10日，研究人员观察到 USPS 邮件投送的通知诱饵，它与法律投诉诱饵相同的基础设施相关联。6月底，ProofPoint 研究人员记录了用于传送 JSSLoader 的 Windows 11 诱饵。

恶意法律投诉活动的受害者之一是一家律师事务所，诱饵成功绕过了律所的电子邮件过滤器，而且律所的所有员工都没有发现该恶意邮件存在可疑之处，eSentire 的 TRU 团队通过威胁搜索活动识别了该恶意文件。

技术详情：

FIN7 在初始阶段向受害者投递 Excel 文件，该恶意 Excel 文档利用 Windows Management Instrumentation (WMI) 来安装 RAT，安装后，JSSLoader 会为威胁组织提供一个访问受害者计算机和组织的后门。

漏洞情报

Tag:Kaseya Unitrends，0day

事件概述：

荷兰漏洞披露研究所 (DIVD) 于近期发布公告称其研究人员在 Kaseya Unitrends 备份产品中发现三个 0day 漏洞。这些漏洞是经过身份验证的远程代码执行、经过身份验证的权限提升和客户端未经身份验证的远程代码执行漏洞，影响Kaseya Unitrends 10.5.2之前的所有版本。

  * 7月2日，DIVD 研究人员发现Kaseya Unitrends 存在的漏洞；
  * 7月3日，DIVD告知供应商；
  * 7月14日，DIVD 开始每日扫描以检测易受攻击的 Kaseya Unitrends 服务器，一旦发现易受攻击的系统，DIVD 将直接或通过政府 CERT、CSIRT 和其他可信渠道通知服务器所有者；
  * 7月15日，DIVD开始识别可能存在漏洞的面向互联网的系统。

DIVD 建议用户在 Kaseya 修补这些漏洞之前，不要将此服务或客户端（在端口 80、443、1743、1745 上默认运行）直接暴露给 Internet。截至外媒报道之前， Kaseya 并未透露何时发布相关补丁。

Apple 于近日修复今年的第11个 0day 漏洞

Tag：Apple，0day

事件概述：

Apple 于近日发布了 macOS 和 iOS中 CVE-2021-30807 漏洞的更新补丁。该漏洞是 macOS 和 iOS 中的一个安全漏洞，存在于 IOMobileFramebuffer 中。它是用于管理屏幕帧缓冲区的内核扩展，由用户端框架 IOMobileFramework 控制。

攻击者可以通过触发 CVE-2021-30807 在易受攻击的设备上使用内核权限执行任意代码，控制目标设备。此次漏洞影响iPhone 6s 及更新机型、iPad Pro（所有机型）、iPad Air 2 及更新机型、iPad 第 5 代及更新机型、iPad mini 4 及更新机型以及 iPod touch（第 7 代），Apple 于 macOS Big Sur 11.5.1、iOS 14.7.1 和 iPadOS 14.7.1 版本进行了修复。

据 Apple 获悉报告称，此漏洞可能在野外被积极利用。Apple 于7月26日发布补丁更新通过改进内存处理解决了内存损坏问题。

https://support.apple.com/en-us/HT212623
