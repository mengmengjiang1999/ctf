IT 基础架构演变史（上）
2022-04-27 10:11:35

IT 基础架构的组成包括企业运营所需的所有核心技术组件，其中硬件、软件和网络通常都被认为是 IT 基础架构的支柱。然而，新的技术趋势正在改变当下的工作方式和网络连接方式。

过去十年，云、身份、数字化转型和分布式工作模式的地位日益凸显，这些新技术也带来了新的机遇和挑战，而这也是IT 基础架构需要考虑的。本文将带您了解 IT 基础架构的核心支柱，以及其他实现系统现代化的技术和功能。

一、什么是 IT 基础架构？

根据定义，IT 基础架构是指企业使用和管理现有技术为员工、客户和合作伙伴提供 IT 服务和解决方案。

IT 基础架构的三个基本要素如下所列：

1）硬件

硬件包括计算机、Web 服务器、数据中心、路由器、交换机等设备和数据中心的容纳设施、冷却设施和供电设施等配套设备。

2）软件

软件指企业内外所使用的向客户提供服务的应用，包括 Web 服务、企业资源规划和 SaaS 应用等，另外还包括管理系统资源和硬件的操作系统（OS）。

3）网络

网络是支持企业内外部系统和设备之间连接、通信和操作的组件。支持网络启用的组件包括 Internet 访问、防火墙、安全监控、配置管理和设备访问管理，还包括路由器、交换机和网络服务提供商（ISP）。

二、IT 基础设施有哪些主要类型？

企业可以通过多种方式存储、部署和配置其基础架构。

1）传统基础架构

传统架构指企业在自有设施内管理所有组件。运行大量硬件（如数据中心和服务器）需要消耗大量资源、电力和物理空间，因此成本十分高昂。另一个问题是，网络或硬件出现故障出现故障时，传统基础架构可能缺乏容错能力。

2）云基础架构

云基础架构的搭建方法包括构建私有云或从基础架构即服务（IaaS）提供商处租用现成的云基础架构。

3）超融合基础架构

超融合基础架构是一个分布式基础架构平台，组合了计算、存储和网络资源并进行虚拟化。有了这些构建块，企业可以更轻松地替换遗留架构，扩大存储容量并提高存储的灵活性。

三、什么是 IT 基础架构管理？

IT 基础架构管理指协调和控制构成系统的资源和功能。不同的基础架构管理的范围也不同，企业可能已经覆盖了部分或所有常见管理领域：

云管理：管理员可以通过监督资源的部署、集成和灾备从而控制在云端运行的终端用户、数据、应用和服务。

操作系统管理：更新 OS 的补丁、升级、配置和订阅管理等要素。

IT 运营管理：对企业正在进行的业务流程进行建模、分析和优化，从而实现战略目标。

虚拟化管理：使用软件连接虚拟环境和物理硬件，简化资源管理、IT 基础架构操作和数据分析。

IT 自动化：创建可重复的流程以替换或减少与 IT 系统的手动交互。

配置管理：维护系统、软件、服务器和网络，使其保持理想状态。

API 管理：分发、控制和分析连接所有业务应用和数据的 API。

风险管理：识别分析风险，并制定风险管控计划。

四、为什么企业需要 IT 基础设施的现代化？如何实施？

随着企业的 IT 基础架构不断发展，硬件、软件和网络也不再是企业 IT 的全部和最终目标。

企业应将这些组件视为进一步发展架构的新起点，从而与最新的业务和技术趋势同步：

1）数字化转型

对于想要与时俱进的企业而言，构建灵活可扩展的基础架构至关重要，此外还有助于确保 IT 服务的效用，以高度安全性保障用户体验。如今，每家企业似乎都成为了一家技术企业，都用到各种内部工具、第三方应用、API 集成和数字空间，也正因如此，企业需要灵活使用技术堆栈或运营所用技术技术加上资源来保持竞争力和高效性。

2）分布式工作

远程办公背景下，动态化的工作模式也成为了常态，需要企业的基础架构支持员工在不同的设备、网络和时区之间无缝访问所需资源，还需要提供适当工具帮助团队协作，保持生产力。

3）零信任

移动和云在办公场景中已经司空见惯，传统的网络边界安全框架也早已无法保护企业。在移动办公和互联的背景下，企业需要为员工、合作伙伴和承包商设置不同的访问级别，以便在安全环境中访问相应资源。为此，企业基础架构需要包含强身份验证、访问权限控制和用户摩擦最小化这些部署零信任所需的功能。
