什么是Web3 ?它是如何工作的?
2022-11-09 16:45:43

Web3提供了一种潜在的解决方案，可以更容易地在万维网上找到内容的原始来源。我们将讨论Web 3是什么以及它是如何工作的。

万维网一直以来都是一个不受限制地创造和分享信息和思想的平台。虽然这让世界感觉更小，但它也有它的缺点，即难以确定内容的原始来源。这种不容易归因的做法为那些声称是合法来源的不可信网站和出版商打开了大门。没有对出版商的可靠认证，人们对在线内容的信任越来越少。

Web3或Web 3.0是解决这个问题的潜在方案。该技术可以将内容归因于特定的已知发布者，而不管网站或在线渠道。通过Web3，用户将能够以加密方式验证任何内容的来源，因为存储在区块链中的发布者身份算法确保了安全性和透明度。

Web3 基础

在深入研究 Web 3.0 的基础知识之前，了解 Web 的历史以及将我们带到这一点的底层架构是很有价值的。万维网或 Web 1.0 的第一次迭代由主机生成的内容和主机生成的权限组成。在这个版本的互联网中，绝大多数用户是内容的消费者，而不是内容生产者本身。

我们目前所处的网络的第二次迭代起源于 2004 年的 Web2。Web2 或 Web 2.0 见证了从“托管网络”到更具参与性的“发布网络”的转变，在这种网络中，每个人都有能力成为出版商。但是，该内容的权限仍然在很大程度上由主持人控制。例如，社交媒体网站可以关闭用户、提升或降级帖子，甚至完全审查主题。尽管仍无法验证发布者的身份，但中央权威的感知担忧已导致当前对在线内容缺乏信任。

Web3 建立在 Web2 的历史之上。 有了 Web3，不仅会有像今天这样的用户生成的内容，而且这些内容的权限和身份将是去中心化的和用户生成的。 这意味着用户可以通过加密签名验证内容作者的有效性，而无需考虑主机。 因此，Web3 通常被称为“签名网络”，Security Boulevard 分析师已经确定当前的加密/解密和零信任框架可以成功地用于确保身份和数据的保护。

Web3 技术如何工作？

那么，Web3 将如何工作？区块链与用于创建加密货币的技术相同，是 Web3 的基础技术，并提供了一种安全签署交易和发布每个人都可以同意的全球状态的机制。然而，区块链技术并不是 Web3 中使用的唯一类型。

与公钥基础设施 (PKI) 技术中常用的密钥对一样，加密密钥对也是 Web3 架构的基础。就像今天在文档签名和代码签名中使用 PKI 一样，建立加密公钥和私钥来对 Web3 上发布的内容进行签名。这种密钥对结构既可以验证发布者是他们所说的那个人，也可以验证内容自签名后没有被更改或篡改。基于 PKI 的身份验证和数据通信加密是 Web2 的重要组成部分，它们也将成为 Web3 的一部分。

目前在 Web2 中，当用户想要创建内容时——例如，在社交媒体平台上发帖——他们需要通过中介，比如社交媒体平台本身。然后，平台将负责确保用户已授权创建内容。然而，在 Web3 中，用户将能够授权创建内容而无需依赖中介。这可以使用公钥加密技术实现，因为数据和身份都经过身份验证和签名。

Hypercore 协议和 IPFS（行星际文件系统）等其他协议也很重要，它们提供了轻量级机制以在对等方之间安全地共享文件。 IPFS 的去中心化意味着它是抗审查的，因此用户文件不能被第三方删除或阻止。 此外，IPFS 允许用户对他们的文件进行加密签名，证明所有权和真实性。 此功能使用户可以在不依赖集中式主机的情况下安全地共享文件。

归根结底，Web3 的未来是光明的，但还有一个大问题：用户将如何发现他们需要的内容？ Web3 可能需要一种新的搜索引擎——一种可以索引整个去中心化网络的搜索引擎——并识别受信任的发布者。
