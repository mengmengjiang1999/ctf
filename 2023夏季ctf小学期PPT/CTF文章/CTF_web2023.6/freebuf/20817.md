华云安漏洞安全周报【第47期】
2021-08-19 11:52:52

​根据国家信息安全漏洞库（CNNVD）统计，本周（2021. 8.9~2021.8.15）CNNVD接报漏洞404，信息技术产品漏洞（通用型漏洞）73个，网络信息系统漏洞（事件型漏洞）331个，其中华云安报送漏洞131个；CNNVD接报漏洞预警88份，其中华云安报送预警14份；漏洞报送数量位列第一！（数据来源于CNNVD）

本周重点关注漏洞包括：Microsoft 8月多个安全漏洞、CVE-2021-34535-RDP 客户端远程代码执行漏洞、CVE-2021-36958-Windows Print Spooler 远程代码执行漏洞、CVE-2021-37608-Apache OFBiz 任意文件上传漏洞、CVE-2021-3050-Palo Alto Networks PAN-OS 命令注入漏洞、CVE-2021-22931-Node.js 远程代码执行漏洞、CVE-2021-38207-Linux kernel 拒绝服务漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

Microsoft 8月多个安全漏洞

严重

2021年8月11日，Microsoft 发布了8月份的安全更新，共发布了51个 CVE 的补丁程序，同比上月减少了66个。此次更新主要涉及：Windows 操作系统、Microsoft Graphics Component、Remote Desktop Client、Windows NTLM、Windows TCP/IP、Windows Update Assistant 等众多组件和软件。共包含7个严重漏洞，37个高危漏洞。其中，主要有13个远程代码执行漏洞、8个信息泄露漏洞、2个拒绝服务漏洞、4个欺骗漏洞，以及 Microsoft Edge（Chromium-based）中的7个未知漏洞。对此，华云安建议相关用户及时进行 Microsoft Windows 版本更新并且保持 Windows 自动更新开启。

情报来源：

https://msrc.microsoft.com/update-guide/releaseNote/2021-Aug

CVE-2021-34535-RDP 客户端远程代码执行漏洞

高危

2021年8月11日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows RDP 客户端中存在一处远程代码执行漏洞。远程程桌面协议（RDP）是一个多通道（multi-channel）的协议，让使用者连上提供微软终端机服务的计算机。该漏洞是由于客户端未能正确处理服务端传入的数据，导致产生了整数溢出，进而导致了越界写。成功利用此漏洞的攻击者未授权的情况下，可诱导用户登录恶意 RDP 服务器，构造恶意数据，从而实现远程代码执行攻击。

情报来源：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34535

CVE-2021-36958-Windows Print Spooler 远程代码执行漏洞

超危

2021年8月12日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows Print Spooler 组件中存在一处远程代码执行漏洞。Windows Print Spooler 是用于管理打印机的后台服务，对于办公场景该服务是一定会被频繁使用，且持续在电脑中运行。这就给予了攻击者相应的攻击场景。该漏洞风险等级较高，且无漏洞补丁，若无打印机使用需求，华云安建议相关用户服务器可禁用打印机服务。

情报来源：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-36958

CVE-2021-37608-Apache OFBiz 任意文件上传漏洞

高危

2021年8月12日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache OFBiz 组件中存在一处任意文件上传漏洞。Apache OFBiz 是一款企业流程自动化软件，可以帮助用户实现企业内业务的自动化，软件中为用户提供 ERP 企业资源规划、CRM 客户关系管理等功能。该漏洞是由于 Apache OFBiz 存在校验错误引起，成功利用此漏洞的攻击者可上传任意文件，并远程执行恶意代码攻击。

情报来源：

http://mail-archives.apache.org/mod_mbox/www-announce/202108.mbox/%3C40716d3e-150d-10d6-ee27-aca4ae0480fb@apache.org%3E

CVE-2021-3050-Palo Alto Networks PAN-OS 命令注入漏洞

高危

2021年8月12日，华云安思境安全团队发现 Palo Alto Networks 官方发布安全更新，披露了 PAN-OS 组件中存在一处命令注入漏洞。PAN-OS 是 Palo Alto Networks 为其防火墙设备开发的操作系统。该漏洞是由于 Palo Alto Networks PAN-OS web 界面上存在一个操作系统命令注入漏洞。要利用此漏洞，攻击者需访问 PAN-OS Web 界面进行身份验证，成功利用此漏洞的攻击者可执行任意的操作系统命令来提升权限。

情报来源：

https://security.paloaltonetworks.com/CVE-2021-3050

CVE-2021-22931-Node.js 远程代码执行漏洞

高危

2021年8月12日，华云安思境安全团队发现 Nodejs 官方发布安全更新，披露了 Node.js 组件中存在一处远程代码执行漏洞。Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行环境，它使用高效、轻量级的事件驱动、非阻塞 I/O 模型。该漏洞是由于 Node.js DNS 库中的域名服务器返回的主机名缺少输入验证，这可能导致域名劫持和代码注入。成功利用此漏洞的远程攻击者可执行 XSS 攻击、拒绝服务攻击或远程执行恶意代码。

情报来源：

https://nodejs.org/en/blog/vulnerability/aug-2021-security-releases/

CVE-2021-38207-Linux kernel 拒绝服务漏洞

高危

2021年8月13日，华云安思境安全团队发现到 Linux kernel 组件中存在一处拒绝服务漏洞。Linux kernel 是 Linux 基金会发布的开源操作系统 Linux 所使用的内核，Linux 内核是一种开源的类 Unix 操作系统宏内核。该漏洞是由于 ll_temac_main.c 文件缓冲区对输入内容的校验存在问题引发，成功利用此漏洞的攻击者通过发送大约十分钟的大量网络流量来导致缓冲区溢出，从而造成拒绝服务攻击。

情报来源：

https://cdn.kernel.org/pub/linux/kernel/v5.x/ChangeLog-5.12.13
