华云安漏洞安全周报【第104期】
2022-10-19 11:14:09

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.9.26~2022.10.2）CNNVD接报漏洞116个，信息技术产品漏洞（通用型漏洞）24个，网络信息系统漏洞（事件型漏洞）92个； CNNVD接报漏洞通报102份。


本周重点关注漏洞包括：CVE-2022-3236-Sophos Firewall 代码注入漏洞、CVE-2021-43980-Apache Tomcat 信息泄露漏洞、CVE-2022-41082-Microsoft Exchange Server 远程代码执行漏洞、CVE-2022-41040-Microsoft Exchange Server 服务器端请求伪造 (SSRF) 漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-3236-Sophos Firewall 代码注入漏洞

威胁等级：超危

漏洞描述：

2022年9月27日，华云安思境安全团队发现 Sophos 官方发布安全更新，披露了 Sophos Firewall 组件中存在一处代码注入漏洞。Sophos Firewall是一款防火墙产品。该漏洞是由于在 Sophos Firewall v19.0 MR1 及之前版本的 User Portal and Webadmin 中存在代码注入漏洞，成功利用此漏洞的攻击者可以执行代码攻击。

情报来源：

https://www.sophos.com/en-us/security-advisories/sophos-sa-20220923-sfos-rce

02 CVE-2021-43980-Apache Tomcat 信息泄露漏洞

威胁等级：高危

漏洞描述：

2022年9月29日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Tomcat 组件中存在一处信息泄露漏洞。Apache Tomcat 是一个流行的开源 Web 服务器和 Java 代码的 Servlet 容器。该漏洞是由于某些 Tomcat 版本中的阻塞式读写的简化实现导致存在并发错误，可能使客户端连接共享一个 Http11Processor 实例，导致响应或部分响应被错误的客户端接收，因此成功利用此漏洞可造成信息泄露。

情报来源：

Apache Tomcat 10 vulnerabilities

03 CVE-2022-41082-Microsoft Exchange Server 远程代码执行漏洞

威胁等级：高危

漏洞描述：

2022年9月30日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Microsoft Exchange Server 组件中存在一处远程代码执行漏洞。Microsoft Exchange Server是一套电子邮件服务程序，它提供邮件存取、储存、转发，语音邮件，邮件过滤筛选等功能。成功利用此漏洞的攻击者可执行远程代码攻击。

情报来源：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2022-41082

04 CVE-2022-41040-Microsoft Exchange Server 服务器端请求伪造 (SSRF) 漏洞

威胁等级：高危

漏洞描述：

2022年9月30日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Microsoft Exchange Server 组件中存在一处服务器端请求伪造 (SSRF) 漏洞。Microsoft Exchange Server是一套电子邮件服务程序，它提供邮件存取、储存、转发，语音邮件，邮件过滤筛选等功能。Microsoft Exchange Server存在安全漏洞，成功利用此漏洞的攻击者提升权限。

情报来源：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2022-41040
