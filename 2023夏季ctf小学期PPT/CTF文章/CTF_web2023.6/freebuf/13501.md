DevSecOps热度的增长是一个可喜的迹象，表明软件和应用程序服务提供商越来越多地将安全性集成到软件开发生命周期 (SDLC) 中。顶级 DevSecOps 供应商提供一整套应用程序安全测试工具，包括静态应用程序安全测试 (SAST)、动态和交互式分析测试（DAST 和 IAST）以及软件组合分析 (SCA)。在国外（米国），DevSecOps已经发展成一个成熟的市场，外媒（esecurityplanet）评选出了几家脱颖而出的 DevSecOps 供应商，这类供应商提供容器工具、持续集成和持续交付 (CI/CD) 管道以及API管理。“本文着眼于最好的商业和开源DevSecOps 工具，以及在评估 DevSecOps 解决方案时要考虑的事项。” 我们将本文搬运过来，供国内从业者参考。

什么是DevSecOps？

DevSecOps 工具是一系列网络安全产品和服务，使组织能够安全地开发和操作软件系统。随着 Web 应用程序的不断增长，DevSecOps 工具可确保传统 CI/CD 管道在系统（或软件）开发生命周期 (SDLC) 的每个阶段保持安全。虽然组织以前将软件开发 ( Dev ) 和 IT 运营 ( Ops ) 分开，但这些流程的合并为 SDLC 流程提供了显着的效率。提高对软件供应链中漏洞的认识已将普遍接受的标准 DevOps 和敏捷软件开发实践置于显微镜下。

近年来，出现了一些新的 DevSecOps 工具，旨在保护组织的 DevOps 管道和流程，并最终提供更可靠的最终产品或系统。开发人员可以使用 DevSecOps 工具在整个开发过程中测试应用程序，同时确保安全性和合规性。

DevSecOps工具都有哪些？

传统的应用程序安全测试 (AST) 工具套件包括：

  * 静态应用程序安全测试 (SAST)

  * 动态应用程序安全测试 (DAST)

  * 交互式应用程序安全测试 (IAST)

  * 软件组成分析 (SCA)

  * 静态代码分析

  * 漏洞扫描

DevSecOps 工具系列中包含的其他工具包括：

  * 容器安全

  * 持续集成/持续交付 (CI/CD)

  * 日志分析

  * 渗透测试

  * Web 应用程序防火墙 (WAF)

如何选择DevSecOps工具？

与大多数网络安全产品一样，理想的 DevSecOps 工具可以满足组织或团队的特定需求。上述解决方案之间的定价和功能存在很大差异，使组织可以根据预算进行大量评估。大多数企业计划每年的预算都限制在数万美元以内；因此，选择一个全面的 DevSecOps 解决方案绝非易事。优秀的供应商可基于构建强大安全软件模型进行功能列表的不断增加。应用程序的激增意味着软件开发将受到越来越多的监管关注。DevSecOps 工具可以在为客户或利益相关者构建可靠、安全和合规的软件解决方案方面发挥重要作用。
