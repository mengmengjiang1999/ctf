如何使用 Nuclei 测试暴露的 API 密钥

大家好..！！

希望你一切顺利

我今天回来讲述了一个关于如何使用 Nuclei“token-spray”模板测试公开的 API 密钥或令牌的故事。

我希望他们中的大多数人都知道或听说过 keyhacks github 存储库，其中包含验证 API 密钥是否有效的各种方法。

https://github.com/streaak/keyhacks

所以，今天我想告诉你还有另一种使用 Nuclei 令牌喷射模板验证公开的 API 密钥和令牌的快速方法。

这个“Token-Spray”目录包含具有静态 API URL 端点的模板。通过使用标志提供令牌输入，Nuclei 将针对 API 模板中的所有已知 API 端点测试令牌，并返回任何成功的结果。通过将 API 检查合并为 Nuclei 模板，用户可以测试没有上下文的 API 密钥（即，不指示它们所指的 API 端点的 API 密钥）

查看下面的 git repo 以更详细地了解该过程。

https://github.com/projectdiscovery/nuclei-templates/blob/master/token-spray/README.md

以下是可用于验证 API 密钥或令牌的命令：

# 针对单个令牌运行令牌喷射模板以测试
nuclei -t token-spray/ - var token=paste-token-here 

# 针对包含多个新行分隔令牌的文件运行令牌喷射模板
nuclei -t token-spray/ - var token=file_with_tokens.txt

您可以查看上面的屏幕截图，我在命令末尾粘贴了暴露的令牌，以了解它属于哪个服务，稍后您需要打开端点以及 API 令牌来验证它。

如果有多个 API 令牌需要测试，请将它们保存到一个文本文件中，然后使用以下命令一次性测试所有这些令牌。

总结使用Nuclei检测暴露的API密钥的步骤：

 1. 下载并安装Nuclei。
 2. 从您要检测的目标网站上收集数据。
 3. 将从目标站点收集的数据到Nuclei中。
 4. 运行Nuclei，并等待输出。

Nuclei将会检测出可能暴露的API密钥，并将其输出到报告中。
