Python _ithcat 持续登陆错误 KeyError: User
2022-06-07 10:48:17

(itchat.auto_login(hotReload=True) 错误KeyError: 'User'

本人学习了一学期Python，需要定时给某人发送消息，四个月左右，每天两次。嫌麻烦，所以编写代码，也学习了网上一些代码，根据自己实际情况进行改写，过程很痛苦，结果很享受。经历了三天左右，第一次把消息发出去，心情只有自己可以感受到。随后进行了三、四次改进升级，自己感觉代码完美（哈哈）。过程中遇到一些不懂得问题，慢慢改进代码，无意间就会理解前面的错误，（多问为什么会这样？）代码敲的多了，慢慢就理解了。过程中的错误与大家共勉。

Python _ithcat 持续登陆错误 KeyError: 'User'原因：

我认为：登陆小号微信没有登陆成功，从而把持续登陆信息没有写入itchat.pkl文件，从而下一次登陆使用上一次的登陆信息，所以无法登陆，产生错误（有更准确的描述，更专业，请评论）。

Python _ithcat持续登陆问题(itchat.auto_login(hotReload=True)错误信息：

Traceback (most recent call last):
  File "F:/root/Desktop/itchat/itchat_send_test.py", line 69, in <module>
    itchat.auto_login(hotReload=True)
  File "E:\Python 3.7.0\lib\site-packages\itchat\components\register.py", line 29, in auto_login
    loginCallback=loginCallback, exitCallback=exitCallback):
  File "E:\Python 3.7.0\lib\site-packages\itchat\components\hotreload.py", line 54, in load_login_status
    self.loginInfo['User'] = templates.User(self.loginInfo['User'])
KeyError: 'User'

解决办法：

 1. 删除代码（*.py）文件夹下的，itchat.pkl 文件，重新用微信大号登陆。

 2. 删除代码中 “hotReload=True” 部分,重新登陆微信号。
