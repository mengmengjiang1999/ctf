Onex：一款针对渗透测试人员的工具库
2020-07-29 18:02:09

Onex

Onex是一款专为渗透测试人员设计的渗透工具安装器和包管理器，Onex中包含了针对Termux以及其它Linux发行版的渗透测试工具，并且还允许广大研究人员在其中安装其他第三方的渗透测试工具。

从本质上来说，Onex是一个Kali Linux渗透工具安装器，主要针对的是Termux和其他Linux发行版，该工具可以帮助管理大量的渗透测试工具，并且能够实现一键安装。也就是说，在Onex的帮助下，您可以在Termux和其他基于Linux的发行版中安装所有的渗透测试工具。目前，Onex可以直接安装超过370款Kali Linux渗透测试工具，整个过程只需要运行Onex命令“onex install [tool_name]”即可。

操作系统要求

Onex支持在下列操作系统平台中运行：

  * Android（使用Termux App）
  * Linux（基于Linux的操作系统平台）

工具安装

打开命令行终端窗口，然后输入并执行下列命令即可：

apt update

 

apt install git

 

git clone https://github.com/rajkumardusad/onex.git

 

chmod +x onex/install

工具运行

sh onex/install

如果上述的sh命令无法执行的话，可以使用下列命令进行尝试：

./onex/install

工具使用

命令行接口模式

广大研究人员可以使用下列命令查看工具的帮助信息：

onex -h

onex help

工具选项：

onex install [tool_name] 安装任意工具

onex -i [tool_name] 安装任意工具

onex search [tool_name] 搜索任意工具

onex -s [tool_name] 搜索任意工具

onex list 列举所有工具

onex list -a 列举所有工具

onex -l 列举所有工具

onex -l -a 列举所有工具

onex help 获取帮助信息

onex -h 获取帮助信息

菜单模式

使用下列命令即可开启Onex的菜单模式：

onex start

广大研究人员可以根据自己的需求，并输入对应数字来使用相应的功能：

(1) : 显示所有可用工具，输入数字安装对应工具

(2) : 显示工具目录

(3) : 更新Onex及其他工具

(4) : 关于工具&联系我们

(5) : 退出工具
