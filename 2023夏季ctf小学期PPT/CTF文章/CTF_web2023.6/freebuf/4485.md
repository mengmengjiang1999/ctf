Passwordstate 企业密码管理器中存在多个安全漏洞
2022-12-30 14:10:21

Passwordstate密码管理解决方案中披露了多个高危漏洞，未经身份验证的远程攻击者可利用这些漏洞获取用户的明文密码。

瑞士网络安全公司 modzero AG在本周发布的一份报告中表示 “未经身份验证的攻击者成功利用漏洞可以从实例中泄露密码，覆盖数据库中所有存储的密码，或提升他们在应用程序中的特权。”

“一些单独的漏洞可以被链接起来，在 Passwordstate 主机系统上获得一个外壳，并以明文形式转储所有存储的密码，从一个有效的用户名开始。”

Passwordstate 由一家名为 Click Studios 的澳大利亚公司开发，拥有超过29000名客户，并被超过 370,000 名 IT 专业人员使用。

其中一个缺陷还影响Chrome 网络浏览器的Passwordstate 版本 9.5.8.4。浏览器插件的最新版本为 9.6.1.2，于 2022 年 9 月 7 日发布。

漏洞列表：

  * CVE-2022-3875（CVSS 分数：9.1）- 密码状态 API 的身份验证绕过
  * CVE-2022-3876（CVSS 分数：6.5）- 通过用户控制的密钥绕过访问控制
  * CVE-2022-3877（CVSS 分数：5.7）-每个密码条目的 URL 字段中存在存储的跨站点脚本漏洞（XSS）
  * 无 CVE（CVSS 分数：6.0）- 使用服务器端对称加密保护密码的机制不足
  * 无 CVE（CVSS 分数：5.3）- 使用硬编码凭据列出经过 API 的密码请求和用户帐户更改等审计事件
  * 无 CVE（CVSS 分数：4.3）- 对密码列表使用未充分保护的凭据

利用这些漏洞可能会导致知道用户名的攻击者以明文形式提取保存的密码，覆盖数据库中的密码，甚至提升权限以实现远程代码执行。

在 Chrome 浏览器扩展程序中发现的不当授权流程（CVSS 分数：3.7）可能会被用作攻击工具，将所有密码发送到参与者控制的域。

在 modzero AG 演示的攻击链中，威胁行为者可以为管理员帐户伪造 API 令牌并利用 XSS 漏洞添加恶意密码条目以获得反向 shell 并获取实例中托管的密码。

建议用户更新至2022年11月7日发布的Passwordstate 9.6 - Build 9653或更高版本，以缓解潜在威胁。
