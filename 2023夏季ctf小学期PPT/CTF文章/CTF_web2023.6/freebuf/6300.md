ubuntu搭建awvs扫描器

AWVS是一款常用的漏洞扫描工具，全称为Acunetix Web Vulnerability Scanner，它能通过网络爬虫测试你的网站安全，检测流行安全漏洞，大大提高了渗透效率。

1.安装docker

执行安装命令：apt install docker和apt install docker.io

2.安装awvs

1.通过以下命令查看镜像

docker search awvs


2.使用以下命令安装awvs

docker pull secfa/docker-awvs


3.使用以下命令查看下载的镜像

docker images


4.启动awvs

docker run -d -p 3443:3443 --name my-awvs secfa/docker-awvs


至此安装完成

3.访问

https://localhost:3443
