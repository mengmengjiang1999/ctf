netwitness介绍

RSA NetWitness Live服务是一种基于云的平台，可24小时不间断地提供威胁情报，该平台经过精心设计，以汇集大约100个可信来源的安全信息，对其加以分析并突出显示最有意义的安全信息内容，这些内容中包括来自RSA专有威胁研究部门的信息。在RSA NetWitness平台内部，RSA NetWitness Live服务会谨慎地对信息进行组织，并实时将组织后的信息与企业网络及日志中的数据相结合，以发现其中的联系。这种数据的联系和融合可为信息安全运行中心提供有效信息，因此有助于加速对意外事件的响应时间，增强对有针对性的网络攻击的抵御能力。

rsa解决方案

流量解析设计：Meta

Netwitness中META就是对网络会话的描述，

当你尝试描述一条网络会话 ：

这是什么种类的会话? service

谁创建了这个会话? ip.src

他们出示了什么证明? username, password

他们到达了哪里? directory, filename

他们做了什么? action

以及其他。。。

要注意的是meta和ips/ids特征是有区别的：

alert tcp any [!80,!445] -> any [!80,!445] (msg:"FOX-SRT - Suspicious - SSLv3 Large Heartbeat Response"; flow:established,to_client; content:"|18 03 00|"; depth: 3; byte_test:2, >, 200, 3, big; byte_test:2, <, 16385, 3, big; threshold:type limit, track by_src, count 1, seconds 600; reference:cve,2014-0160; classtype:bad-unknown; sid: 1000000; rev:4;) (Reproduced from: http://ics-cert.us-cert.gov/alerts/ICS-ALERT-14-099-01E, 04/30/2014)

降噪

我们降噪的目的是为了区分授权与未授权流量 ：

导入资产信息

为了实现正确的审计，我们需要先导入资产的信息，包括：

资产基本信息：IP、责任人、物理位置

资产业务信息：开放的端口、运行的业务

资产网络安全策略：允许外部哪些地址访问哪些端口

资产协议安全策略：允许外网访问哪些端口上的哪些协议

资产外连控制：是否允许资产对外发起连接

资产价值信息：资产经济价值

资产法律信息：遭攻击后遭受的法律纠纷

资产历史上遭遇的攻击：已处理攻击事件

资产正经历的攻击：未处理攻击事件

资产漏洞信息

通过这些信息进一步与RSA ARCher集成
