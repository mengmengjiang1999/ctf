GitHub 封禁部分俄罗斯开发者账户
2022-04-18 13:36:01

据 Bleeping Computer 网站披露，Github 开始陆续封禁受美国制裁的俄罗斯公司开发者账户，其中包括俄罗斯银行 Sberbank、俄罗斯最大的私人银行 Alfa-Bank 和其他公司的账户，以及部分个体开发者的账户。

据俄罗斯媒体 Habr 报道，封禁浪潮从 4 月 13 日开始，没有明确区分公司和个人账户。据悉，只要是在受美国制裁的公司中工作，甚至是以前在这些公司工作的开发者都受到了不同程度的波及与影响。一般来说，俄罗斯用户遭受账户封禁后，其负责的项目会被抹去，所有的存储库都会立即失去联系。

值得一提的是，封禁名单中包含几十个和制裁实体没有关系的私人账户。

Habr.com 报道称，一些俄罗斯开发者与 GitHub 沟通了关于封禁事宜之后，收到了一封名为 "GitHub和贸易管制 "的电子邮件，邮件中解释他们的账户因美国制裁而被禁用。

另外，邮件中还包含了一个 GitHub 页面链接，解释了该公司关于制裁和贸易管制的政策，其中一部分提示用户如何对封禁提出上诉。据悉，上诉表格中要求提供受制裁的实体没有使用他们的 GitHub 账户的证明。

不久前，美国财政部开始制裁部分俄罗斯企业，GitHub 作为一家属于微软的美国公司，紧跟其政府行动并不意外，

封禁行为充满争议

值得一提的是，GitHub 曾宣称，作为所有开发者共同拥有的开源大家庭，将会为所有国家/地区的开发者提供使用 GitHub 的同时，还会确保所有人都可以免费使用开源服务，当然也包括俄罗斯开发者们。

Bleeping Computer 与 GitHub 取得联系了，要求其对报道中的封禁潮发表看法。就封锁俄罗斯开发者账号一事，GitHub 在回复中表示:

与在美国开展业务的任何公司一样，GitHub 可能必须限制被美国特别指定的国民名单（SDN，美国财政部海外资产管理办公室维护的名单），或根据美国和其他适用的制裁法律被拒绝或被阻止的用户，以及可能代表被阻止使用 GitHub 的用户和客户团体。

同时，GitHub 的愿景是成为开发者协作的全球平台，无论开发者居住在哪里。我们会彻底审查政府制裁，以确保用户和客户不会受到超出法律要求的影响。
