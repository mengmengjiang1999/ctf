知识私域-帮会

为你提供高质量的知识服务

汇聚网安大V、实现知识变现

覆盖渗透、红蓝对抗、安全情报等领域

随时随地，在线学习，一键直达

助你变得更优秀、知识更富有！

帮会是安全圈内容创作者的私域沉淀平台，创作者可以用帮会连接铁杆粉丝，进行创作分享与深度交流，实现知识变现。

在帮会里，帮主可随时随地输出碎片化内容，与粉丝们深度接触，碰撞出思维的火花，同时能更专注地投入创作，你的创作也将获得丰厚的回报。

创作者可以创建帮会后对外发布，粉丝们付费加入帮会。帮会的规则与玩法多种多样：针对热点技术大家一起畅谈，针对某个工具的使用讨论，安全资讯类。所有内容最终沉淀，能分类可检索。

注：安卓用户直接点击帮会介绍页面“加入我们”即可加入帮会，ios用户添加帮主微信或通过微信分享链接加入。

内测帮会概览

// 谢公子的小黑屋

致力于分享红蓝对抗中内网渗透、域渗透、云安全、集权设备相关的知识，旨在帮助广大红蓝对抗人员提升攻防实战技能。

// 赛博回忆录

汇集经典实战漏洞攻防技巧，由业内诸多安全研究卷王长期贡献精彩技巧，在这里你可以从完成从burp操作员到安全研究员的进阶升级。

// 炼石计划@Java代码审计

一个系统化从入门到提升学习Java代码审计的成长型帮会。这里不仅注重夯实基础，更加专注项目级实战进阶。从基础概念知识开始学习，配合项目级系统实战，共六大学习阶段约120节课，手把手教程带你提升真正的技术。

// 网络安全情报攻防站

高质量网络运维与安全攻防领域帮会，致力于路由交换、云计算、存储、网络实战运维、Web安全、APP安全、内网安全、红蓝安全攻防等资料分享，并提供视频教程、工具、最新漏洞POC、EXP等。

// 渗透知识库（HACK之道）

致力于红队攻防实战、内网渗透、代码审计、社工、安卓逆向、CTF比赛技巧、安全运维等技术干货及常用渗透工具、教程、书籍等资源分享，是你学习过程中好帮手。

更多帮会持续开放中......敬请关注FreeBuf知识大陆APP。
