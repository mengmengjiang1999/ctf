分析：

3、代码审计：

1、

main()#主函数伪c代码
int __cdecl main(int argc, const char **argv, const char **envp)
{
  write(1, "Hello, World\n", 0xDuLL);#write()函数会把字符串"Hello, World\n"输出0xD个字节
  return vulnerable_function(1LL, "Hello, World\n");#返回到定义的vulnerable_function()函数
}


2、跟进vulnerable_function()

ssize_t vulnerable_function()
{
  char buf; // [rsp+0h] [rbp-80h]#定义了一个字符串类型的buf这里可以看出buf在栈里开辟的大小为0x80=128

  return read(0, &buf, 0x200uLL);#返回利用read函数往buf里写入0x200个字符unsign long long
}


4、思路：

在read函数这里我们可以看到该程序利用read函数读取了 0x200个字符串到buf里而从前面可以看出实际上buf大小只能存128个字符很明显这里一旦将这0x200个字符存入buf会造成栈溢出，而多出的数据会覆盖掉高8个字节RIP使得程序无法正常在执行完read函数之后ret到下一跳地址。

而RIP存放的就是下一跳的地址即多出的数据覆盖掉正常的返回地址导致程序无法正常运行。所以我们可以利用栈溢出覆盖掉填充buf然后利用溢出覆盖掉返回地址把我们想要程序跳转的地址填充进去让程序执行即覆盖掉RIP的地址getshell
