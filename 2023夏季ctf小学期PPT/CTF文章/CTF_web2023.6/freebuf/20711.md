ADAMoracle的异军突起，市场对ADAM奖励机制提高了更多的关注

区块链是一个确定性的、封闭的系统环境，目前区块链只能获取到链内的数据，而不能获取到链外真实世界的数据，区块链与现实世界是割裂的。
一般智能合约的执行需要触发条件，当智能合约的触发条件是外部信息时（链外），就必须需要预言机来提供数据服务，通过预言机将现实世界的数据输入到区块链上，因为智能合约不支持对外请求。
这是理想中预言机的工作流程，即用户的智能合约把请求给链上 Oracle 合约，通过链下的 API 接口获得外部数据，更确切的说是外部把数据给链上的 Oracle 合约，然后 Oracle 合约再把数据给用户的智能合约。


目前市场预言机大致分为以下这几种类型
软件预言器：这样的预言机通过API从第三方经营者和网站获得数据，作为智能合同的输入数据。最常用的是天气数据、航班数据、证券市场数据等。
硬件预测器：这种预言机通常表现为物联网中的数据收集器，可以将物理世界的事件结果数字化发送给智能合同，可以追踪供应链中的货物运输过程。
共识型预言机：这种预言机与前两种预言机的中心化不同，通常也称为中心化预言机。该预言机通过分散参与者投票，根据共识提供最终数据和信息化的结果。




总之，无论是哪种类型的预言机，其核心都是确保信息传递的可靠性， ADAMoracle是去中心化预言机网络服务设施，是连接现实世界数据和块链系统，为许多应用场景提供标准化解决方案，实现与区块链外的服务无缝交互的中间部件。ADAMoracle的诞生，为链上的智能合约开发者提供全面的工具和数据，为智能合约开发者提供更安全、更方便的预言机整体解决方案。 使用中心预言机有明显的缺点，主要有以下三点：
1、可靠性差，容易受到攻击，中心化预言机有单点故障和单点攻击的问题
2、用户需要信赖中心化平台和第三者独立机构，违反了区块链的信赖、中心化的基本原则
3、单平台和第三方机构掌握所有用户Query数据信息，无法保证用户隐私。


奖励机制
ADAMoracle 是通过支付通证 ADAM 来激励数据的提供方，即持续 地提供有效数据的提供方将持续地获得 ADAM 的奖励。同时，数据 的使用者将需要支付一定额度的 ADAM，以此形成良性的循环。
ADAM 是 ADAMoracle 对参与者的奖励Token。它是生态系统的价值核心。它的价值来自于生态成员的贡献。ADAM总量为1亿。【节点奖励】60%的奖励产出，6000万个ADAM用于节点奖励。【流动性奖励】9%，900万。用于流动性奖励和质押奖励。【早期融资】16%，1600万。共有三轮：种子轮、私募轮和公开发售轮。【社区贡献者奖励】5%，500万。【团队预留】5%，500万。【社区/市场运营】5%，500万。
ADAM的奖励产出将分阶段进行。第一阶段的总奖励为 1200 万 ADAM。每个后续阶段的总奖励将减少 20%。1200万ADAM用完后，进入第二阶段。第二阶段的奖励总量比第一阶段减少20%，为960万；该规则将在后期继续，直到所有 6000 万 ADAM 全部产出。

ADAMoracle的异军突起，市场对ADAM奖励机制提高了更多的关注，区块链的世界并不能独立于真实世界之外，预言机作为这其中最重要的桥梁，必将在这个市场有它的城堡，有心之人已经在与ADAMoracle煮酒论江湖了，无心之人还在市场迷茫，让我们对这个领域保持持续关注。
