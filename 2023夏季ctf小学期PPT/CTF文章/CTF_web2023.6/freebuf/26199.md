kali2020.1的快速搭建
2021-04-12 20:36:34

最开始安装kail的时候，安装iso的那个版本，踩了很多坑，后来才发现可以用vmware版的导入。这里呢分享了一点点小技巧，请各位师傅多多指教。

1、vmware版本的kali直接导入

[KALI官网]：https://www.kali.org/downloads/

我们拉到下面

[vmware版本的也可以直接点这里]https://www.offensive-security.com/kali-linux-vm-vmware-virtualbox-image-download/

选择32或者64位的，选择下载种子，因为kali官方太慢。

2、解压缩到D盘自己创建的虚拟机目录下

tips：为了方便管理，我在固态盘里面创建了vmware文件夹，这里面只放虚拟机。

3、切换到root登录

打开vmware：文件——打开——找到以.vmx结尾的文件，运行它

第一次开机，我们只能用kali / kali登录

用kali身份设置root密码,我设置的root / root

┌──(kali㉿kali)-[~/Desktop]
└─$ sudo passwd root

4、更换kali默认源（修改为国内源）

vim /etc/apt/sources.list

5、升级kali（导入不升级很多命令无法使用）

过程中如跳出其他界面（尝试q或者回车）

（1）apt-get update //下载索引文件
（2）apt-get upgrade  //系统将现有的Package升级,如果有相依性的问题,而此相依性需要安装其它新的Package或影响到其它Package的相依性时,此Package就不会被升级,会保留下来。
（3）apt-get dist-upgrade  //可以聪明的解决相依性的问题,如果有相依性问题,需要安装/移除新的Package,就会试着去安装/移除它。
（4）apt-get clean  //清理安装包
（5）apt-get auto-clean  //清理安装包


运行完上述命令两次后，重启一下

6、apt源的java环境

apt源：

sudo apt install default-jre

sudo apt install default-jdk


javac检验一下（出现以下为成功）

运行完重启一下

7、ssh连接kali

kali默认没有开ssh服务；kali的ssh默认禁止root登录。

下面我们打开ssh的root登录
vim /etc/ssh/sshd_config
34行:修改为PermitRootLogin yes
39行:取消注释


下面我们打开kali的ssh服务
service ssh start


8、kali汉化（稍微懂点英语的建议使用英文）

更新kali，并且安装字体包！

root@kali:~$ sudo apt-get update
root@kali:~$ sudo apt-get install ttf-wqy-microhei ttf-wqy-zenhei xfonts-wqy fonts-wqy-zenhei fonts-wqy-microhei


终端输入如下命令：

root@kali:~$ sudo dpkg-reconfigure locales


按空格勾选如下三个（方括号中出现*就表示已选中），三个都全部选中后回车确定

下面的效果即为安装成功

9、kali的默认时间是美国时间，这里我们可以用命令调整

sudo timedatectl set-timezone "Asia/Shanghai"    #修改时区为上海
sudo hwclock -w   #将系统时间写入到硬件时钟，防止重启系统后更改失效~~~~
