张小龙对微信思考最深刻的地方
2021-01-25 20:33:53

本文作者唐韧，文章出自公众号「唐韧」。

昨晚的「微信之夜」很多人应该都看了，这是「微信公开课」的一个保留节目。过往多年，都有张小龙的压轴演讲。

龙哥这次照样没让人失望，虽然晚点了半个小时开始，但干货和金句很多，可以称之为互联网界的「春晚」了。

整体有个感觉，那就是逻辑之美。

我看完了全程演讲，对龙哥的产品思考自然是相当佩服，他已经是神一般的存在，正如他自己开玩笑说，自己是被上帝选中的人。

这次演讲时间不长，但信息量依然很大，细的我就不说了，你们应该也在很多地方都看到了演讲文字稿。

这里说下我认为他对微信思考最牛逼的一点，就是他在演讲中回答视频号是什么时提到的关于 ID（身份）的思考。

用龙哥的原话说，「长期以来，微信的最大价值是每个人的微信 ID」。

接下来，我会从自己的角度分享下为什么我认为他关于微信 ID 的思考如此牛逼。

分成三部分，先讲第一点。

我们需要先建立几个概念，分别是微信号 ID、公众号 ID、视频号 ID。

在我看来，他们三者的结构关系是这样的。

微信号 ID 是社交领域的唯一识别，公众号 ID 是媒体领域的唯一识别，视频号 ID 是公开领域的唯一识别。

最关键的一点，公众号和视频号是以微信号为基础的。

首先看微信号 ID，我们注册完微信后，就会默认生成一个微信号 ID，实际上这是一个不方便记忆的 ID 串码。

为了方便记忆，微信推出了「微信号」，让用户自己编辑，全网唯一。

我画了一些图，你们可以看下。

这个 ID 是用户在微信里的唯一身份识别，是和好友建立通讯社交关系的连接点，也是将其他工具和用户身份绑定的连接点。

比如，我们可以使用微信支付，那是因为微信号 ID 和你的钱包唯一绑定。我们能发朋友圈，那是因为你拥有唯一可识别的身份。

微信属于私密社交产品，你只能和你的好友进行通讯和互动，如果你朋友的朋友跟你没有 ID 上的关联，你是无法联系到对方的。

所以，这个 ID 就是私密社交网络的钥匙。

拥有了微信号 ID，微信的基本框架就成立了，这是一切演化的开始。

其次，是公众号 ID。

用过公众号产品的都知道，注册公众号是一套独立的账户体系，用邮箱和密码登录。不过，可以将个人微信号作为管理员或者运营者与公众号关联。

在用户关系逻辑上，好友和公众号粉丝是没有必然联系的，你的好友不一定是你的粉丝，只有关注了你才是你的粉丝。

在消息触达逻辑上，如果没有人主动关注你，你的公众号消息就无法触达粉丝。

在用户互动逻辑上，就算别人在文章底部评论，我们也无法和评论者建立好友关系。最多只能看到评论者的头像和名称。

公众号的产品设计，决定了它一定是一个重运营的产品。

对于公众号作者来说，需要通过持续运营文章和用户来获得不断的曝光和增长。

我们现在看公众号的设计觉得顺理成章，但当时关于公众号规则的思考，是非常厉害的。

公众号 ID 既独立，又和微信号 ID 产生了连接，让它独立发展且不产生深度耦合，这为产品演变提供了非常好的底层设施。

公众号的出现，将微信从一款通讯社交工具，升级成了一个社交媒体平台，同时也蕴含了一个新的商业机会。后来的故事，你们都知道了。

最后，是视频号 ID。

视频号相对于公众号来说，门槛更低了，不管是开通成本、创作成本、运营成本，都更低了。

视频号 ID 同样是独立于微信号 ID 至上的一个全新的 ID，它跟公众号 ID 也是独立的。

在用户关系逻辑上，视频号是一个公开领域的产品，它既可以实现基于朋友点赞的社交推荐，也可以实现基于算法匹配的机器推荐。

相比于公众号更重要的一点，视频号能让创作者有机会触达更广阔的微信天地。

说得直白点，视频号出圈能力比公众号更强。视频号同时具备了微信号和公众号的特点。

这也是为什么龙哥说视频号可以成为每个人的名片、可以成为每个机构的名片的原因。

在消息触达逻辑上，虽然视频号的权重还不如公众号那么高，但未来这方面的能力一定会有所增强。

在用户互动逻辑上，视频号比公众号更进一步。不仅能看到，而且能触达到，可以直接跟社交好友外的用户进行互动。而且，还能进行身份的选择。

这也再一次说明，视频号在微信里其实就是一款独立的产品，它只是和用户的微信号实现了绑定，且完美地复用了微信的基础设施。

从某种程度上说，视频号本身也能够成为一个独立的基础设施。

对以上三个基本概念有了认知后，接着看为什么我认为龙哥这个思考如此牛逼的第二点。

可以这么说，微信号 ID 是根，公众号 ID 和视频号 ID 是树杈，他们彼此连接，公众号和视频号都可以直接复用微信号 ID 带来的基础能力。

我举一个例子，用户可以在公众号里实现商品购买，这是公众号支持微信支付的原因。准确说，是微信号 ID 将微信支付带到了公众号，而前提是二者彼此连接。

再举一个例子，微信有 5000 人朋友圈限制，超过这个人数虽然可以继续加人，但朋友圈对新增的好友是不可见的，这是微信号 ID 的边界。

对于上面提到的这一点，视频号 ID 延展了微信号 ID 的边界，视频号被关注数是无上限的。这再一次证明了为什么说视频号是每个人的新名片的原因。

试想一下，在现实场景中你能认识的人是有限的，能记住的也是有限的，但不妨碍认识且记得你的人是无限的。

所以，视频号是个人和机构的新名片，这突破了微信号 ID 的边界限制，又不破坏微信号 ID 所建立的基础规则。

你再看，他们三者之间的关系既独立、又彼此连接，微信号是基础设施，向上输送各种能力，公众号和视频号是独立产品，复用并享受基础设施带来的赋能。

也就是说，只要微信号 ID 这个基础设施的能力不断升级，还可以长出各种各样的独立产品，小程序就是最好的体现。

就凭这一点，这个底层思考带来的演变能力，就足够牛逼！

很多人觉得视频号就是视频化的公众号，其实仔细拆开他们的逻辑看，二者是截然不同的。

还有很多人说视频号干不过抖音和快手。在我看来，这是一种比较表层的判断。

你无法用同一个标准去判断这几个产品，比如 DAU、比如内容丰富度和质量。归根结底，还是得看产品的底层逻辑。

抖音和快手最缺失的就是社交领域，而这一点恰恰是微信的优势，要知道，社交领域一旦建成，往上做公开领域的视频号是不难的。而往下做，没有根基，没有关系，没有连接点。

打个比方，抖音和快手对应的其实是公众号，都是大V网红的表演。

而视频号，是进化版的个人微信，是对应文字和图片的升级，人人都可以用。

如果说微信号 ID 建立的边界是社交领域，那公众号 ID 建立的就是媒体领域，且是半公开的互动领域，而视频号就是一个完全公开的全新领域，生命力更强。

昨晚龙哥整场分享里，提到了 58 次「视频号」，对视频号的解读和分享，也是篇幅最长的。

这意味着什么，就不用多说了吧。

在他的分享中有一段话，我觉得每个人都可以多看几遍，十年的思考，归结于几点。

微信十年，如果非要用两个词来描述微信，我想，一个是连接，一个是简单。 连接是很美的。因为世界的运行就是靠万事万物的连接而进行的。 对产品来说，做连接，意味着做服务的底层设施，因为基于连接可以演变出来的结果是最丰富的。

而对做产品启发最大的一点，就是做「底层设置」，微信的 ID 就是底层设施，这也是龙哥所说的最大的价值。

最后，说下为什么我认为龙哥对微信的这个思考如此牛逼的第三点，就是「简单」。

他用简单来作为美观、实用、合理、优雅的代名词，说起来简单，背后却蕴含了大量的思考和思辨。

从他的分享中，处处体现了一个词，思辨。

产品里的每一处设计、每一个策略、每一个优化，都有理由，而这些理由背后的逻辑，都是不断的思辨。

作为一款日活跃用户 10.9 亿的产品，它远没有看起来那么「简单」，这就是产品经理能力的体现了。

用这次龙哥分享中我很喜欢的一段话来结束今天的文章，与你共勉！

「希望，它能一直保持自己的风格，一直像一个小而美的产品一样，有自己的灵魂，有自己的审美，有自己的创意，有自己的观念。而不仅仅是数字的奴隶。——张小龙」。
