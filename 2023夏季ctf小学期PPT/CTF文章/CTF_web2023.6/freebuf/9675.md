magisk 一键集成逆向环境
2022-07-08 17:09:29

换了新的逆向机器后需要安装一大堆的工具，然后发现一个magisk模块，这个模块可以直接安装一些常用App，解放双手，省不少时间，并且可以自行定制自己需要安装的内容

默认功能

集成工具：MT管理器、Igniter、启用webView调试、HTTPCanary(小黄鸟)、proxydroid(代{过}{滤}理)、SSLping

  * proxydroid可以将设备数据转发到目标代{过}{滤}理，对于某些有代{过}{滤}理检测或设置了NO_PROXY的App效果不错，其他都是常用工具应该不必赘述了吧

集成模块：lsposed、Shamiko(隐藏Root)

  * lsposed 不必多说大家都知道

  * Shamiko论坛里也有个帖子“[url=https://www.52pojie.cn/forum.php?mod=viewthread&tid=1582872&highlight=����Root]https://www.52pojie.cn/forum.php ... ht=����Root[/url]”

开机自启：frida-server android-server

证书迁移：默认抓包证书从用户证书存储移动到系统目录下

自行定制

模块结构

制作自己独有的一键安装环境：

通过修改results中的App名称并在apks文件夹下增删对应的apk即可（必须将apk名字和配置名字都改为和包名一致，脚本中会根据配置中的包名名字检查apk是否已安装）

ui_print "检查——安装应用"
results="bin.mt.plus cn.wankkoree.xposed.enablewebviewdebugging com.guoshi.httpcanary io.github.trojan_***.igniter.debug mobi.acpm.sslunpinning org.proxydroid"
for pag_name in $results
do
    # ui_print $i
    res=$(pm list packages -3 | cut -d':' -f2 |grep $pag_name)
    if [ $res = $pag_name ]; 
    then
      echo "$pag_name ，已安装"
    else
      echo "$pag_name  安装中**"
      pm install $MODPATH/apks/$pag_name.apk
     fi 
done


替换自带的frida、android-server版本

其中也有自带的frida-server、android-server，叼大的筒子们也可以自行更换

增删magisk模块

可以在model模块增加需要安装的magisk模块并在脚本中增加对应安装命令即可

安装常用模块
ui_print "安装常用模块"
magisk --install-module $MODPATH /modle/LSPosed.zip 
magisk --install-module $MODPATH/modle/Shamiko.zip
