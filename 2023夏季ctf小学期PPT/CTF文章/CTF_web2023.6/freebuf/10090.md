2022-07-08 18:42:58

【全球动态】

1. 漏洞百出的 "用谷歌登录 "API让加密货币面临账户接管风险

一家全球加密货币钱包服务提供商的API漏洞，可能导致个人和企业账户的账户控制权和数百万美元的损失，这个漏洞会让恶意行为者有充分的权限，并有能力代表该用户执行多种金融行动，包括将资金转移到他们选择的任何地点。【外刊-阅读原文】

2. 欧盟网络安全组织ENISA发布新威胁态势分析法

欧盟网络安全组织ENISA的目标是利用其专业知识的基础上加强网络安全活动，使相关者获得相关和及时的信息，用于政策制定、决策和应用安全措施，以及为专门的网络安全社区增加知识和信息，或建立对与新技术相关的网络安全挑战的坚实理解。【外刊-阅读原文】

3. OrBit，一种新出现的复杂未知的 Linux 恶意软件

Intezer公司的网络安全研究人员发现了一种新的Linux恶意软件，这是一个完全未被检测到的Linux威胁。该恶意软件可以作为一个不稳定的植入物安装，或者在被攻击的系统上实现持久化。【外刊-阅读原文】

4. 针对 NPM JavaScript 包存储库的大规模加密货币挖掘活动

Checkmarx 研究人员发现了一个新的大规模加密货币挖掘活动，被跟踪为CuteBoi，它的目标是 NPM JavaScript 包存储库。该活动背后的威胁行为者在存储库中发布了 1,283 个恶意模块，并使用了 1,000 多个不同的用户帐户。研究人员在注意到大量可疑的 NPM 用户和自动创建的软件包后发现了供应链攻击。【外刊-阅读原文】

5. QNAP警告说新勒索软件Checkmate正针对NAS设备

台湾厂商QNAP警告说，有一个新的勒索软件系列针对其使用弱口令的NAS设备。威胁者的目标是启用SMB服务的在线暴露设备，他们对使用弱密码的账户进行暴力攻击。【外刊-阅读原文】

6. 开发者考虑 Gtk 5 停止支持 X11

GNOME 桌面环境项目的开发者 Emmanuele Bassi 发起讨论，考虑 Gtk 的下一个版本停止支持 X11。X 视窗系统(X Window System 或 X11) 已经相当陈旧，其最新的稳定版本 X11R7.7 还是在 2012 年发布的。【阅读原文】

【安全事件】

1.量子勒索软件攻击已经影响 657 个医疗保健机构

提供全方位服务的应收账款管理公司 Professional Finance Company Inc. (PFC) 表示，2 月下旬的勒索软件攻击导致数据泄露，影响了 600 多家医疗机构。该公司于 5 月 5 日开始通知受影响的医疗保健提供者的患者，称正在进行的调查发现攻击者在加密 PFC 的某些系统之前访问了包含其个人信息的文件。【外刊-阅读原文】

2.黑客公布伊朗钢铁制造企业近20G绝密文件，疑似以色列幕后支持

攻击三家伊朗钢铁制造企业的黑客组织Predatory Sparrow近日发布了所谓的近20GB绝密数据，其中包含公司文件，这些文件揭示了这些设施与伊朗强大的伊斯兰革命卫队的隶属关系。【阅读原文】

3. Systemd 主管 Lennart Poettering 离开 Red Hat 转投微软

领导了 PulseAudio、Avahi 和 Systemd 等项目的知名开源开发者 Lennart Poettering 。据报道离开了 Red Hat。这一消息尚未公开宣布，但消息源称他的账号已经从 Red Hat 内部员工数据库里移除了，向他的 Red Hat 邮箱地址发送给邮件会返回邮箱不再使用的信息。【外刊-阅读原文】

4. 针对美国执法部门的网络攻击在增加

位于洛杉矶的网络安全公司Resecurity为全球财富500强企业提供保护，该公司近期透露从2022年第二季度开始，针对执法机构的恶意活动有所增加。攻击者正在入侵属于执法人员的电子邮件和其他账户以及他们的内部系统。【外刊-阅读原文】

5. API安全形势严峻：38万台K8s API服务器暴露在公网

Shadowserver Foundation的研究人员发现，超过38万台开放Kubernetes API服务器暴露在互联网上，占全球可观测在线Kubernetes API实例的84%。【阅读原文】

6. Apple 宣布“锁定模式”以保护记者和人权工作者免受间谍软件的侵害

Apple宣布了一套新的 iPhone 功能，称为“锁定模式”。周三在一篇博文中披露，锁定模式将于今年秋季登陆 iOS 16、iPadOS 16 和 macOS Ventura 设备，并提供多项安全功能。苹果称这种模式为“为极少数用户提供的一种极端的、可选的安全级别，因为他们是谁或他们做什么，可能会成为一些最复杂的数字威胁的个人目标。【外刊-阅读原文】
