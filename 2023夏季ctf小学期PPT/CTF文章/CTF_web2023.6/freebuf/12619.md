开源容器安全检测工具，长亭问脉安装使用
2022-04-24 15:51:58

注：veinmind-tools 是由长亭科技自研，基于veinmind-sdk打造的容器安全工具集。

项目地址：https://github.com/chaitin/veinmind-tools

工具列表：

veinmind-malicious  扫描镜像中的恶意文件  
veinmind-weakpass   扫描镜像中的弱口令   
veinmind-sensitive  扫描镜像中的敏感信息  
veinmind-backdoor   扫描镜像中的后门    
veinmind-history    扫描镜像中的异常历史命令


官方文档中有本地安装使用和平行容器使用两种方法，本次以本地安装使用为例

安装过程

1、安装之前需要先安装libveinmind，安装方法可以参考官方文档

本地环境安装libveinmind：

（1）在 Ubuntu 和 Debian 平台下，添加问脉 SDK 的 APT 仓库即可安装所需软件包：


echo 'deb [trusted=yes] https://download.veinmind.tech/libveinmind/apt/ ./' | sudo tee /etc/apt/sources.list.d/libveinmind.list
sudo apt-get update
sudo apt-get install libveinmind-dev


（2）在 RedHat 和 CentOS 平台下，添加问脉 SDK 的 yum 仓库即可安装所需软件包：


sudo cat > /etc/yum.repos.d/libveinmind.repo << ==EOF==
[libveinmind]
name=libVeinMind SDK yum repository
baseurl=https://download.veinmind.tech/libveinmind/yum/
enabled=1
gpgcheck=0
==EOF==
sudo yum install libveinmind-devel


我这里已经安装过了，显示Nothing to do


2、直接下载编译好的工具包，就可以直接在本地使用了。下载地址：Release


3、使用veinmind-weakpass检查镜像中的弱口令情况

将下载的veinmind-weakpass_linux_amd64工具包赋予可执行权限


chmod +x veinmind-weakpass_linux_amd64


然后执行检查命令


./veinmind-weakpass_linux_amd64 scan


检查完成后可以看到检查结果


一些常用的命令：

（1）指定镜像名称或镜像ID并扫描 (需要本地存在对应的镜像)：


./veinmind-weakpass_linux_amd64 scan [imagename/imageid]


（2）扫描所有本地镜像


./veinmind-weakpass_linux_amd64 scan


（3）指定容器运行时类型


./veinmind-weakpass_linux_amd64 scan --containerd


容器运行时类型

  * dockerd

  * containerd

（4）指定扫描用户名类型


./veinmind-weakpass_linux_amd64 scan -u username


（5）指定自定义扫描字典


./veinmind-weakpass_linux_amd64 scan -d ./pass.dict


veinmind-malicious与veinmind-weakpass使用方式类似，不做演示。

遇到的问题：

执行扫描任务时可能会遇到该问题：


是因为操作系统中glibc版本过低导致的，可以将glibc版本进行升级，具体方式参照本篇文章：https://blog.csdn.net/weixin_44479465/article/details/112703715?spm=1001.2101.3001.6650.1&utm_medium=distribute.pc_relevant.none-task-blog-2~default~CTRLIST~default-1.pc_relevant_default&depth_1-utm_source=distribute.pc_relevant.none-task-blog-2~default~CTRLIST~default-1.pc_relevant_default&utm_relevant_index=2

4、使用veinmind-sensitive检查镜像中的敏感信息

将veinmind-sensitive.tar.gz压缩包解压


tar -zvxf veinmind-sensitive.tar.gz


然后安装veinmind-sensitive所需要的python依赖


pip install -r requirements.txt


最后执行扫描命令


python3 scan.py scan-images mikesplain/openvas:latest


检查完后可以看到检查的结果

一些常用的命令：

（1）指定镜像名称或镜像ID并扫描 (需要本地存在对应的镜像)


python3 scan.py scan-images [imagename/imageid]


（2）扫描所有本地镜像


python3 scan.py scan-images


（3）指定镜像类型


python3 scan.py scan-images --containerd


镜像类型

  * dockerd

  * containerd

（4）指定输出类型


python3 scan.py --output [outputtype] scan-images


veinmind-history和veinmind-backdoor使用方式类似，不做演示。
