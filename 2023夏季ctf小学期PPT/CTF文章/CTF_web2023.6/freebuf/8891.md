华云安漏洞安全周报【第98期】
2022-08-25 17:40:34

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.8.15~2022.8.21）CNNVD 接报漏洞177个，信息技术产品漏洞（通用型漏洞）116个，网络信息系统漏洞（事件型漏洞）61个；CNNVD接报漏洞预警119份，其中华云安报送预警6份，预警报送数量持续位居前列！

本周重点关注漏洞包括：CVE-2022-36446-Webmin命令注入漏洞、CVE-2022-28756- Zoom Client 本地提权漏洞、CVE-2022-38362-Apache Airflow 远程代码执行漏洞、CVE-2022-34711-Windows Defender Credential Guard 权限提升漏洞、CVE-2022-2856-Google Chrome 远程代码执行漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01 CVE-2022-36446-Webmin命令注入漏洞

威胁等级：超危

漏洞描述：

2022年8月15日，华云安思境安全团队发现 Github 官方发布安全更新，披露了 Webmin 组件中存在一处命令注入漏洞。Webmin 是 Webmin 社区的一套基于 Web 的用于类 Unix 操作系统中的系统管理工具。该漏洞是由于其 software/apt-lib.pl 组件缺少对 UI 命令的 HTML 转义引起，成功利用此漏洞的攻击者可以通过在新软件包安装期间执行 OS 命令注入实现任意命令执行。

情报来源：

https://github.com/webmin/webmin/commit/13f7bf9621a82d93f1e9dbd838d1e22020221bde

02 CVE-2022-28756- Zoom Client 本地提权漏洞

威胁等级：高危

漏洞描述：

2022年8月16日，华云安思境安全团队发现 Zoom 官方发布安全更新，披露了 Zoom Client 组件中存在一处本地提权漏洞。Zoom Client 是一款支持多种平台的视频会议客户端应用程序。该漏洞是由于 Zoom Client for MacOS（标准版和IT管理版） 5.7.3至5.11.5之前的版本中存在密码验证不当，成功利用此漏洞的本地用户攻击者可以利用自动更新过程中将其权限升级为 root。

情报来源：

https://explore.zoom.us/en/trust/security/security-bulletin/

03 CVE-2022-38362-Apache Airflow 远程代码执行漏洞

威胁等级：高危

漏洞描述：

2022年8月17日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache Airflow 组件中存在一处拒绝服务漏洞。Apache Airflow 是一套用于创建、管理和监控工作流程的开源平台，该平台具有可扩展和动态监控等特点。该漏洞是由于提供的示例 DAG 容易导致Airflow worker主机上经过身份验证的远程代码攻击。

情报来源：

https://lists.apache.org/thread/614p38nf4gbk8xhvnskj9b1sqo2dknkb

04 CVE-2022-34711-Windows Defender Credential Guard 权限提升漏洞

威胁等级：高危

漏洞描述：

2022年8月17日，华云安思境安全团队发现 Microsoft 官方发布安全更新，披露了 Windows Defender Credential Guard 组件中存在一处权限提升漏洞。Windows Defender Credential Guard 使用虚拟化将凭据存储在与操作系统分开的受保护容器中，以保护信息安全。成功利用此漏洞的攻击者可以通过权限提升获得 SYSTEM 权限。

情报来源：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2022-34711

05 CVE-2022-2856-Google Chrome 远程代码执行漏洞

威胁等级：高危

漏洞描述：

2022年8月18日，华云安思境安全团队发现 Google 官方发布安全更新，披露了 Google Chrome 中存在一处远程代码执行漏洞。Google Chrome是 Google 开发的Web浏览器。该漏洞是由于 Intents 对不可信输入数据的验证不足引起，成功利用此漏洞的攻击者可通过诱导用户打开特制页面，从而导致远程代码执行。

情报来源：

https://chromereleases.googleblog.com/2022/08/stable-channel-update-for-desktop_16.html
