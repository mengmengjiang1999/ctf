华云安漏洞安全周报【第81期】
2022-05-10 14:39:35

根据国家信息安全漏洞库（CNNVD）统计，本周（2022.4.18~2022.4.24）CNNVD接报漏洞349个，信息技术产品漏洞（通用型漏洞）165个，网络信息系统漏洞（事件型漏洞）184个，其中华云安报送漏洞2个；CNNVD接报漏洞预警150份，其中华云安报送预警22份，预警报送数量位列第二！

本周重点关注漏洞包括：CVE-2022-21441-Oracle WebLogic Server 拒绝服务漏洞、CVE-2022-21420-Oracle Coherence 代码执行漏洞、CVE-2022-27862-WordPress VikBooking 任意文件上传漏洞、CVE-2022-29266-Apache APISIX 信息泄露漏洞、CVE-2022-20732-Cisco Virtualized Infrastructure Manager 权限提升漏洞、CVE-2022-22969-Spring Security OAuth 拒绝服务漏洞。漏洞影响范围较广，华云安建议相关用户做好资产自查与预防工作。

01CVE-2022-21441-Oracle WebLogic Server 拒绝服务漏洞

威胁等级：高危

漏洞描述：

2022年4月19日，华云安思境安全团队发现 Oracle 官方发布安全更新，披露了 Oracle WebLogic Server 组件中存在一处拒绝服务漏洞。Oracle WebLogic Server 是一款适用于云环境和传统环境的应用服务中间件。该漏洞是由于服务器未做访问限制引起，成功利用此漏洞的攻击者在未经身份验证的情况下通过 T3/IIOP 访问服务器，从而导致 Oracle WebLogic Server 挂起或 DOS。

情报来源：

https://www.oracle.com/security-alerts/cpuapr2022.html#AppendixFMW

02CVE-2022-21420-Oracle Coherence 代码执行漏洞

威胁等级：超危

漏洞描述：

2022年4月19日，华云安思境安全团队发现 Oracle 官方发布安全更新，披露了 Oracle Coherence 组件中存在一处代码执行漏洞。Oracle Coherence 是业界领先的内存数据网格解决方案，通过提供对常用数据的快速访问，使组织能够以可预测的方式扩展任务关键型应用程序。该漏洞是由于程序未未做访问限制引起，成功利用此漏洞的攻击者在未经身份验证的情况下通过 T3 访问服务器，从而破坏 Oracle Coherence，导致接管 Oracle Coherence。

情报来源：

https://www.oracle.com/security-alerts/cpuapr2022.html#AppendixFMW

03CVE-2022-27862-WordPress VikBooking 任意文件上传漏洞

威胁等级：超危

漏洞描述：

2022年4月19日，华云安思境安全团队发现 WordPress 官方发布安全更新，披露了 WordPress VikBooking 组件中存在一处任意文件上传漏洞。WordPress 是使用 PHP 语言开发的博客平台，用户可以在支持 PHP 和 MySQL 数据库的服务器上架设属于自己的网站。该漏洞是由于预订表单在上传文件时存在验证不足引起，成功利用此漏洞的攻击者通过上传恶意文件，从而在服务器中执行代码攻击。

情报来源：

https://wordpress.org/plugins/vikbooking/#description

04CVE-2022-29266-Apache APISIX 信息泄露漏洞

威胁等级：超危

漏洞描述：

2022年4月20日，华云安思境安全团队发现 Apache 官方发布安全更新，披露了 Apache APISIX 组件中存在一处信息泄露漏洞。Apache APISIX 是一个动态、实时、高性能的 API 网关。该漏洞是由于依赖库 lua-resty-jwt 中的逻辑错误引起，成功利用此漏洞的攻击者通过向受 jwt-auth 插件保护的路由发送恶意制作的 JSON Web Token，从而获得插件配置的敏感信息。

情报来源：

https://lists.apache.org/thread/6qpfyxogbvn18g9xr8g218jjfjbfsbhr

05CVE-2022-20732-CiscoVirtualized Infrastructure Manager 权限提升漏洞

威胁等级：高危

漏洞描述：

2022年4月20日，华云安思境安全团队发现 Cisco 官方发布安全更新，披露了 Cisco Virtualized Infrastructure Manager 组件中存在一处权限提升漏洞。Cisco Virtualized Infrastructure Manager (VIM) 是思科公司一款虚拟化基础设施管理器软件。该漏洞是由于 Cisco Virtualized Infrastructure Manager (VIM) 的配置文件访问权限不正确引起，成功利用此漏洞的攻击者在经过身份验证的情况下可获得内部数据库凭据，导致访问敏感信息并提升受影响设备的权限

情报来源：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-vim-privesc-T2tsFUf

06CVE-2022-22969-Spring Security OAuth 拒绝服务漏洞

威胁等级：超危

漏洞描述：

2022年4月21日，华云安思境安全团队发现 VMware 官方发布安全更新，披露了 Spring Security OAuth 组件中存在一处拒绝服务漏洞。Spring 是一个开放源代码的 J2EE 应用程序框架。该漏洞是由于 OAuth 2.0 客户端应用程序中启动授权请求数量过多引起，成功利用此漏洞的攻击者通过发送多个请求，启动授权代码授予的授权请求，从而导致拒绝服务并耗尽系统资源。

情报来源：

https://tanzu.vmware.com/security/cve-2022-22969
