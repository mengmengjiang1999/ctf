android攻防之drozer（基础篇）
2021-09-26 17:31:16

对于安卓攻防具体在哪个平台这个问题，我强烈建议在linux。因为后期我们要用到adt，drozer。adt在win上面还是可以的，但是安装比较烦，更新源是google，被华夏墙了… …drozer我在windows上面好像就没成功过… …

所以说为什么要在win上面运行呢？下面我就来推荐一下安卓攻防专业系统santoku

这是一个基于ubuntu的发行版本，很酷

下面介绍的就是drozer。具体安装就不说了，santoku上面集成好了

首先就是通过adb连接到电脑，然后安装好drozeragent

设置好端口转发 adb forward tcp:31415 tcp:31415

drozer agent开启

drozer console connect 连接，成功

下面介绍一下指令：

run app.package.list -f app名字

对安卓包管理api封装

run app.package.info -a 包名

run app.package.info -p 权限标志

信息枚举

run app.activity.info --filter activity名

枚举activity

run app.provider.info

枚举content provider

run app.server.info --package 包名

枚举service

run app.broadcast.info

枚举broadcast server

app.package.attacksurface

枚举app受攻击面
