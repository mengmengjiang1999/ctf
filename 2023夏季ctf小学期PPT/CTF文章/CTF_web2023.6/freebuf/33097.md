嘉宾介绍

耿志峰，京东安全首席架构师，负责京东产品和基础设施安全、数据安全和蓝军建设等工作，具有多年大数据安全、威胁情报、黑产对抗等经验，是资深的大数据安全专家、企业安全架构设计和攻防对抗专家。

社招职位

安全专家T6及以上1人

岗位职责：

负责开展特定安全域的风险评估、提供安全解决方案、并跟踪落实;

负责特定安全域技术防御体系的构建、有效运营和持续优化

业务和产品安全设计，发现业务和产品中的安全隐患，制定安全策略

岗位要求：

信息安全或计算机相关专业本科以上学历

熟悉行业主流的安全标准、安全模型、安全解决方案、安全体系。

熟悉常见漏洞和原理，能指导开发避免和修复漏洞

有良好的计算机相关技术基础知识，对网络、操作系统有较深的了解；

具备良好的沟通表达能力，一定的项目管理能力，良好的团队合作意识。

java服务端开发工程师T6以上1人

岗位描述：

1、负责物联网云平台设计和开发工作；

2、承担核心功能代码编写，开发与维护系统公用核心模块；

岗位要求：

1、JAVA 技术知识扎实，熟悉 IO，多线程，异步处理和常用中间件产品，熟悉缓存，消息等机制；

2、对各种 Java 应用框架如 Spring、ibatis 等有深入了解和应用实践

3、熟悉分布式系统原理，熟悉 MySQL 或 Oracle 数据库的基础原理；

4、有大型分布式、高并发、高性能、高可用系统的设计开发经验；

5、具备良好的系统分析能力，良好的抽象思维和逻辑思维能力，独立分析问题解决问题的能力；

6、优秀的沟通推动能力，有创新精神，乐于接受挑战，能承受工作压力;

平台开发架构师

岗位职责：

负责数字化运营平台系统架构规划演进、架构方案设计、系统SLA模型建立、软硬件优化、基础设施规划等工作，通过技术影响力和团队协作能力持续开展数字运营平台的技术研究和架构。

1. 负责数字化运营平台产品服务端的架构设计与搭建，参与技术规划以及建设路线图的制定，对系统软件架构、系统模块、关键组件、接口的设计；

2. 参与到核心功能的架构域代码模板的编写，高并发、分布式、微服务等一个或多个领域有过深入研究，持续提升团队的技术水平；

3. 参与理解平台新业务的需求、场景、后续发展方向，进行系统分析、技术架构评审，把控技术设计环节的设计质；

4. 负责数字化平台全链路监控、容灾、硬件运营、过保迁移等基础平台的设计及开发，推动数字化运营平台 稳定性／效率／成本／性能 方面的提升；

5. 对新技术、行业动向保持敏锐的感知度，对未来技术发展走向提出指导决策，结合实际应用需求及业务规划运用于系统架构中。

岗位要求

1. 具备10年以上的信息化项目设计开发经验，具有国外企业工作经历

2. 熟练应用Java、C++、Python等开发语言，熟练使用各类主流关系型、非关系型数据库，具有全栈设计和开发能力，主持设计开发的在用大型信息系统不少于5；

3. 熟悉云计算、大数据、人工智能等IT平台技术，熟悉Hadoop、Spark、Flink等大数据平台，熟悉TensorFlow、CNTK、Keras、Caffe等主流AI框架；

4. 熟悉Docker和Kubernetes，熟悉云原生设计和开发模式，具有中台战略思想及相应技术能力，熟悉中间件的选型和应用技术；

5. 熟悉并掌握微服务架构和敏捷开发技术，并有不少于5个以上的大型在运行项目的设计开发实操经验；

6. 了解国内外互联网企业的信息化和安全现状和发展方向。

移动安全工程师T5及以上1个

工作内容：

1、Android/Ios平台应用的安全相关分析，开发，集成，测试。

2、Android/Ios安全模块的设计和开发。

3、移动安全技术研究及漏洞跟踪。

4、公司产品技术难点的技术攻关。

5、学习和研究新的移动互联网技术以满足技术与产品的需求。

任职要求：

1、计算机及相关专业本科以上学历，有良好的编程技术功底。

2、熟悉C/C++、JAVA、ARM汇编、SMALI等语言，了解Android/Linux底层架构，熟悉系统的工作原理和细节。

3、熟悉Android系统架构及相关技术，具有Android平台开发经验。

4、熟悉App的反编译、静态分析、动态调试、安全加固等安全相关技术。

5、熟悉Android安全机制以及常见Android安全漏洞和检测方法。

资深研发

岗位职责：

1、负责京东应用安全和数据安全产品的设计，开发和维护工作；

2、持续对线上系统进行性能优化及稳定性提升；

3、负责攻克团队遇到的技术难题；

4、拆解产品需求，提出技术实现方案和步骤。

任职要求：

1、3年以上互联网开发领域的设计与开发经验，精通一种开发语言（Java，Go）及对应开发领域相关的技术与常用服务框架；

2、良好的开发基础，精通一种编程语言基础，熟练掌握多线程开发技术，熟练掌握常用开发工具和开源技术栈（如Spring框架）

3、熟悉常用数据库软件(MySQL)的原理和使用，熟悉常用ORM和连接池组件,对数据库的优化有一定的理解；

4、具备丰富的大型互联网系统设计经验，熟悉分布式、缓存、消息、负载均衡等机制和实现，具备海量数据研发和处理经验优先；

5、（可选项）熟悉权限管理，统一认证（SSO），加密算法，数字水印等并且有相关研发和处理经验优先；

6、熟悉软件开发，测试流程；

7、良好的沟通能力，有责任心，有良好的团队合作合作精神。

企业介绍

京东(NASDAQ:JD)是一家以技术为成长驱动的公司，从成立伊始，就投入大量资源开发完善可靠、能够不断升级、以应用服务为核心的自有技术平台，从而驱动电商、金融、物流等各类业务的成长。

未来，京东将更加重视技术的战略地位，发展云计算、大数据、智慧物流、人工智能、ARVR、智能硬件等最新技术，以推动京东实现快速、可持续增长。未来十二年，京东集团将坚定地朝着技术转型，用技术将第一个十二年建立的所有商业模式进行改造，打造一个包括智能商业、智能金融、智能保险在内的全球领先的智能商业体。
