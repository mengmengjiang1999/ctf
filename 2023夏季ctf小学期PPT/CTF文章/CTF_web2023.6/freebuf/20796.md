ubantu 20.04 搭建 Vulhub 环境
2021-08-19 09:30:14

一、配置docker环境

​ 虚拟机环境：ubantu 20.04

sudo passwd                          #更改密码
su root                              #切换为root权限账号
apt install curl                     #安装curl模块


curl -s https://get.docker.com/ | sh #安装docker


docker -v


​ 这里我也忘了当时是怎么添加的pip了，网上有教程自己找吧。

pip --version                        #查看pip版本信息
pip install docker-compose           #安装docker-compose


​ 到 https://github.com/vulhub/vulhub 下载vulhub的源码包，然后上传到靶机中。执行

unzip vulhub-master.zip               #解压zip


​ cd 到解压目录下。

二、启动环境

这是在绿盟的时候扫出来的一个漏洞，在这里记录一下它的原理，验证方法及利用过程。

​ CVE-2017-10271是Weblogic的漏洞，这里直接进入Weblogic的目录下。

​ 这里有CVE-2017-10271，进去，然后执行下面的命令。

docker-compose build
docker-compose up -d


如果出现ERROR: Get https://registry-1.docker.io/v2/: dial tcp: lookup registry-1.doc问题，重启就完了。

执行docker ps 查看是否开启成功

访问http://ip:7001 如果出现这个页面说明Weblogic CVE-2017-10271已经启动成功。
