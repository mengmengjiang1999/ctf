公司简介

UCloud是基础云计算服务提供商，长期专注于移动互联网领域，深度了解移动互联网业务场景和用户需求。针对特定场景，UCloud通过自主研发提供一系列专业解决方案，包括计算资源、存储资源和网络资源等企业必须的基础IT架构服务，满足互联网研发团队在不同场景下的各类需求。运维团队只需注册UCloud云平台，即可在管理界面中实现各服务的统一管理和使用。已有数千家移动互联网团队将其核心业务迁移至UCloud云计算服务平台上。

招聘详情

前端工程师

工作职责

 1. 负责 Web 产品的前端实现
 2. 负责 Web 产品的性能、用户体验优化
 3. 协助进行研发团队的技术指导工作
 4. 负责推动与优化已有前端项目的基础架构

基本要求

 1. 本科及以上学历，计算机相关专业，两年以上前端开发工作经验(经验丰富可放宽限制）
 2. 熟练掌握 HTML，CSS 和 JavaScript 等前端开发技术
 3. 掌握主流的前端开库和 MVC/MVVM 框架（如 react/angularjs/vue 等)，且有使用经验* 者优先
 4. 对服务端（ NodejsJavaPythonGo 等）有一定实际的开发经验
 5. 个性乐观开朗，思路清晰，具备良好的自我管理能力
 6. 具有强烈的进取心，能够积极主动跟进业界的步伐 ,工作细致，有激情
 7. 具备良好的编码习惯及开发文档书写习惯，有良好的英语读写能力

后端研发工程师

工作职责

 1. 应用层防火墙产品后端安全引擎、通信组件等的研发
 2. 产品需求功能设计、实现、产品化
 3. 协助解决售前售后项目问题

基本要求

 1. 计算机相关专业，本科两年以上工作经验（经验丰富可放宽限制）
 2. 具有至少一年的 Linux 开发经验，熟悉 Linux 编程和调试环境
 3. 熟练掌握 C 语言、Python、Lua 等
 4. 了解数据结构与网络通讯，能够对程序活数据做抓包性能分析和调优
 5. 熟悉 TCP/IP 协议、路由、交换等网络基础知识
 6. 熟悉 HTTP 协议，熟悉 SSLTLS 以及 x509 等协议
 7. 有信息安全、网络攻防等经验和基础者优先
 8. 具备良好的沟通表达能力和学习能力，积极的工作态度，较强的责任心

大数据方向

工作职责

 1. 负责大数据应用中的统计分析，用户画像和文本挖掘等工作。
 2. 负责多种应用场景的数据挖掘，dashboard 开发。
 3. 负责捕获异常数据，数据建模，行为调整等。

基本要求

 1. 计算机相关专业，本科两年以上工作经验（经验丰富可放宽限制）
 2. 扎实掌握常用机器学习、最优化算法，概率统计、自然语言处理至少熟悉 1 种以上
 3. 熟悉 Linux 操作系统，熟练使用至少一门脚本语言
 4. 熟悉 Java/Python/Scala 语言特性，熟悉常用的数据结构、算法
 5. 熟悉 Spark/Hadoop/Storm 等数据平台和 MapReduce 的实现机制
 6. 扎实的编程和数学基础,对常用的机器学习算法、特征选择方法、数据建模过程有深入理解

福利简介

10K-30K 具体看各人的面试结果，以及与老板协商的价格，根据个人工作时长，技能树，岗位匹配度等多方面要求肯定会有所不同。
