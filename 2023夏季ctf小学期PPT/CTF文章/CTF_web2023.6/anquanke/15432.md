活动简介

POC++ 平台是数字观星科技有限公司自主开发并运营的 POC 收录平台，旨在通过凝聚全社会的安全技术力量，打造覆盖面更广、检测能力更强的一流漏洞扫描、验证平台。 新版本上线之际，数字观星 POC++ 奖励平台真挚邀请您参与线上奖励升级活动！奖励多多多！！！周期长长长！！！

活动时间

2019.04.05-2019.04.19

主办方

北京数字观星科技有限公司

活动详情

活动范围

活动期间，平台注册用户可以向平台提交新的漏洞及新的 POC，也可以为平台已收录但没有 POC 的漏洞补充 POC。
奖励情况
活动金额：上不封顶
奖励增幅：+5%
最高奖励：173.25 星豆/POC，1 星豆=1 RMB
奖励数量：不限量

参与人员

平台所有可用注册用户

平台地址

http://poc.shuziguanxing.com/ (请使用 Chrome 或 Firefox 访问本平台)

活动规则

接收的漏洞范围
平台接受常见的可远程利用的通用安全漏洞及 POC ，主要包括：
各种操作系统漏洞，如 Windows 远程代码执行漏洞
各种应用服务服务漏洞，如 SSH 越权访问漏洞
常见通用 Web 应用漏洞，如 Discuz 漏洞、某通用业务系统漏洞
常见协议漏洞，如 DNS 协议漏洞
常见硬件漏洞，如某路由器漏洞、某摄像头漏洞
工业控制设备/协议漏洞，如某智能电表漏洞
智能硬件、物联网设备漏洞，如某冰箱漏洞、某 AI 盒子漏洞
未在列表中列出的其它漏洞请向我们确认后再提交。

不接收的漏洞范围
所有事件型漏洞均不在平台接收范围内。
公开网站的事件型漏洞
例如：某网站存在 SQL 注入漏洞（能证明漏洞属于网站使用的通用框架的除外）
各种需要本地、物理接触、近场通讯才能利用的漏洞
例如：NFC 漏洞、蓝牙漏洞

其他规则请参照平台漏洞、POC 收录规则：https://poc.shuziguanxing.com/#/news
