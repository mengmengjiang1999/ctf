关于长亭

北京长亭科技有限公司（简称长亭科技），是国内顶尖的网络信息安全公司，专注于为企业级用户提供高质量的网络信息安全解决方案。

长亭科技坚持以技术为导向，历经数年研发，在全球范围内，首发基于语义分析的非规则运算引擎，颠覆了传统Web应用层的安全防护原理，为企业用户带来更快、更精准、更智能的产品及服务。

公司拥有顶尖的安全研究和技术研发团队，专注于解决互联网安全问题，致力提高国内安全水平，接轨国际最高标准。

公司官网：https://chaitin.cn

工作地点

北京海淀区

招聘职位

前端开发工程师

工作职责：

构建安全产品的前端页面功能、微信端页面等。

职位要求：

熟悉 HTML5 / CSS3 / JavaScript，掌握前端整个技术栈

熟悉各种标准，框架和预处理器，如 ES6 / CoffeeScript / Vue / jQuery / Angular / React / Sass

有过单页面应用 (Single Page App) 开发经验，了解现代构建系统的使用如 webpack, browserify 等

能够与设计师协作，掌握基本切图技巧

能够与后端工程师协作，略懂后端服务器原理

有一定的用户交互设计的经验和思维，能够与产品经理碰撞

热爱前端工作，能够自我驱动，紧跟技术潮流


竞赛服务部安全研究员

工作职责：

CTF命题

CTF赛事组织、运维

CTF培训

参加国际CTF大赛

职位要求：

做事认真、细心

1年以上CTF参赛经验

擅长Web、二进制安全中至少一个方向

有CTF竞赛组织经验者优先


安全研究员

工作职责：

研究最新黑客攻防技术

参加安全行业会议

参加国内外黑客竞赛

撰写研究报告

方向包括但不限于: 二进制安全、Web 安全等

工作要求：

至少在一个领域有着较深的经验和积累，有较强漏洞挖掘能力

优先条件：

有过CTF比赛经验者优先

有过漏洞挖掘经验者优先

拥有CVE编号者优先

员工福利：免费午餐晚餐 、每月交通补助、零食水果、健身器材、游戏设备、全员 Mac 等

补充福利：补充医疗保险，人身意外险

薪资待遇：丰厚的薪酬，年终奖
