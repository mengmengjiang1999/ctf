【北京招聘】长亭科技诚招安全人才（各岗位均接受实习，外地实习生提供住宿）

公司简介

北京长亭科技有限公司（简称长亭科技）是一家以技术为导向的安全公司，专注于解决互联网安全问题。

长亭科技拥有技术水平顶尖的安全研究团队与技术研发团队，致力于发展新型网络安全技术，提高国内安全水平，接轨国际顶尖技术。

公司目前主营高度定制化的安全服务与安全产品，旨在通过发展新技术新方法，为企业提供有效的定制化安全解决方案，全面提高企业安全防御能力。

招聘信息

算法工程师

职位要求

1、在编译原理与自动机、机器学习等方向有一定的基础知识积累；

2、至少熟练使用 C / Python / Java 其中一门语言，能够快速编码实现算法原型，检验算法和调优参数；

3、有 OI / ACM / TopCoder / GCJ / Codeforces 等算法竞赛获奖经历者优先；

4、有过算法研究经历的博士优先。

后端开发工程师

职位要求

1、熟悉 Python / Go / Java 中至少一门编程语言

2、有一定的 Web 后端开发经验，熟悉前后端分离的开发模式

3、熟悉关系型数据库的使用与基本设计优化方法，了解常见的 NoSQL 数据库如MongoDB, Redis等

4、良好的编码风格及测试习惯

加分项

1、有前端开发的经验

2、个人在Github上有活跃的开源项目

3、有DevOps实践经验

底层研发工程师

职位要求

1、熟练使用 C / C++ / Python，能够编写稳定高效可靠的代码，有一定的工程经验

2、牢固掌握算法、数据结构、网络通信、计算机原理知识

3、有 Star 较多的开源项目者优先

4、自行实现过 mini 操作系统者优先

5、会使用 Rust 加分

前端开发工程师

职位要求

1、熟悉 HTML5 / CSS3 / JavaScript，掌握前端整个技术栈

2、熟悉各种标准，框架和预处理器，如 ES6 / CoffeeScript / Vue / jQuery / Angular / React / Sass

3、有过单页面应用 (Single Page App) 开发经验，了解现代构建系统的使用如 webpack, browserify 等

4、能够与设计师协作，掌握基本切图技巧

5、能够与后端工程师协作，略懂后端服务器原理

6、有一定的用户交互设计的经验和思维，能够与产品经理碰撞

7、热爱前端工作，能够自我驱动，紧跟技术潮流

测试与质量控制工程师

职位要求

1、了解掌握测试原理，并能编写单元测试、集成测试、冒烟测试、压力测试、内存测试、打包测试等的测试用例。

2、善于发现系统死角，用不一样的思维寻找和发现问题。

3、至少掌握 Python/C++/Java/Ruby/Go 其中一门语言。

4、良好的逻辑推理能力，能够让测试做到充分覆盖。

5、具有一年以上的测试工作经验。

运维工程师

职位要求

1、熟悉常见 Linux 系统命令，能够熟练地排查和解决系统问题。

2、熟练使用各种监控系统，能够监控系统正常运转状态，合理规划和部署系统资源。

3、掌握计算机网络的原理和实践，维护公司内网。

4、了解现代证书体系，管理公司证书发放、撤销等。


安全服务工程师/实习生

职位要求

1、认真踏实

2、已具备完成岗位职责的能力

3、若不完全具备完成岗位职责的能力，能有信心在短时间内在同事的带领下具备上述能力

4、实习生北京学校优先

加分项

1、在相关漏洞平台、SRC提交过优质漏洞

2、参与过CTF类竞赛并有较好的成绩，独立完成过大量 WEB 或渗透类题目

3、实战渗透经验丰富，有复杂环境渗透经验

售前/售后工程师

职位要求

1、大学本科毕业，计算机相关专业；

2、熟悉Ubuntu、CentOS等Linux操作系统;

3、熟悉常用Shell命令，能够编写Python简单程序；

4、了解WAF、IPS、IDS、抗DDOS、漏洞扫描、堡垒机、数据库审计、网络准入、SOC等网络安全技术；

5、了解Nginx、Tengine、Apache、Tomcat等常用Web软件的配置和管理；

6、学习能力强，对企业IT 架构和业务需求有较深入的理解；

7、优秀的沟通能力和演讲能力，能够与客户方进行有效沟通交流。

8、有中大型项目的售前、研发、运维或互联网系统架构经验者优先考虑；

以上各岗位均接受实习，外地实习生提供住宿。

公司福利

五险一金、补充医疗、带薪年假、全薪病假、团队建设、年度体检；

交通补贴、工作日午餐及晚餐、不限量零食饮料、实习生宿舍。

更多福利筹备中，敬请期待！
