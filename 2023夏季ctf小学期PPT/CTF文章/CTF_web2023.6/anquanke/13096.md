突发：俄罗斯警方突袭NGINX莫斯科代表处拘留两名联合创始人

阅读量222042

|评论3

发布时间 : 2019-12-13 11:50:41

编译：奇安信代码卫士团队

俄罗斯执法部门官员突袭 Nginx 在莫斯科的代表处，原因是俄罗斯互联网门户和邮件服务提供商、俄罗斯最大的搜索引擎 Rambler 起诉其侵犯版权。Nginx 是全球第二大最流行的 web 服务器软件。

当地媒体和社交媒体报道称，警方搜查并拘留了该公司的多名员工，其中包括 Nginx 的元老开发人员 Igor Sysoev 以及该公司的另外一名合伙人 Maxim Konovalov。公司设备遭没收，员工被传讯。

当前超过30%的网站包括全球最流行的站点如Netflix 和 Twitch均在Nginx 服务器上运行。

2009年，Igor Sysoev 创建了美国公司 NGINX. Inc. ，总部位于旧金山不过其代表处遍布全球，主要为 NGINX 部署提供工具和支持服务。2004年该公司开源服务器源代码。2019年2月，NGINX最终打败Apache HTTPD 成为互联网上部署最广泛的服务器。根据 Netcraft 公司在2019年12月发布的 Web 服务器调查获知，NGINX 的市场份额达到38%。一个月之后该公司被 F5 Networks 收购。

根据推特上分享的起诉书可知，Rambler 公司起诉 Sysoev 在担任 Rambler 公司系统管理员期间创立了 Nginx 软件公司，因此起诉要求获取该应用程序的版权。据悉，发表该推特的用户被警方要求删除所发布内容。

另外Rambler公司还起诉Sysoev 在和公司存在劳动关系的工作期间开发该项目，之后非法分发该项目，导致 Rambler 损失5140万卢布（1人民币折合8.9968俄罗斯卢布）。

Rambler 公司告知俄罗斯当地一家媒体称，“Nginx 是工作期间的产物，它的开发始于21世纪初，当时 Igor Sysoev和 Rambler 公司尚存在劳动关系。因此任何未经 Rambler 集团同意使用该项目的行为该项目均违反了专有权。”

然而，根据2012年另外一家俄罗斯网站的采访，Sysoev证实称自己确实是在Rumbler 任职期间开始着手准备该项目，但利用的是业余时间。

他在访谈中表示，“应该提到的一点是编程并非我的工作职责，但由于时间和精力的限制，我做的第一件事是修改补丁以压缩 Apache 响应。随后我被要求接手 mod_proxy 模块。我查看后决定从头开始编写，要比适应原有内容更容易。”Sysoev 表示 Rambler 公司多年来并未意识到 NGINX 的存在，该服务器最初部署在Rate.ee 和 zvuki.ru 网站，而 Rambler 只是在一个同事问到时才开始使用该服务器。

目前该诉讼根据俄罗斯联邦《刑法》第146条第3款（违反版权法及相关权利）提出。但俄罗斯总统侯选人 Alexei NavaIny 的参谋长 Leonid Volkov 批评该突袭行动表示15年后提出版权侵权诉讼的时效法令已失效。

Nginx 并未就此事做出任何回应或公开发布任何声明。
