UCloud多职位招聘，福利多多

阅读量243776

发布时间 : 2018-12-25 17:53:54

联系方式：owen.he@ucloud.cn（请注明来自安全客）

公司简介

UCloud （优刻得科技股份有限公司）是国内领先的云计算服务平台，坚持中立，不涉足客户业务领域，致力于打造一个安全、可信赖的云计算服务平台。自主研发IaaS、PaaS、AI服务平台、大数据流通平台等一系列云计算产品，深入了解互联网、传统企业、为客户提供优质服务。

工作地点

深圳南山深大北门

联系方式

owen.he@ucloud.cn（请注明来自安全客）

招聘岗位

网络产品研发（后端）

base:深圳

工作职责

应用层防火墙产品后端安全引擎、通信组件等的研发独立完成需求分析、模块设计、软件开发和自检。

基本要求

 1. 计算机相关专业，本科三年以上工作经验（经验丰富可放宽限制）
 2. 具有至少一年的 Linux 开发经验，熟悉 Linux 编程和调试环境
 3. 熟练掌握 C 语言、Python、Lua、Go 等（至少有两种语言的探索经验）
 4. 了解数据结构与网络通讯，能够对程序活数据做抓包性能分析和调优
 5. 熟悉 TCP/IP 协议、路由、交换等网络基础知识
 6. 熟悉 HTTP 协议，熟悉 SSL\TLS 以及 x509 等协议
 7. 有信息安全、网络攻防等经验和基础者优先
 8. 具备良好的沟通表达能力和学习能力，积极的工作态度，较强的责任心

C++/Go 后端开发

base:深圳

工作职责

服务端框架、功能设计、开发和实现现有系统的维护

基本要求

 1. 计算机相关专业，本科三年（经验丰富可放宽限制）以上 c++/Go 开发经验
 2. 熟悉 TCP/IP 协议，HTTP/WebSocket 协议以及网络编程和多线程编程，具有高并发服务开发经验
 3. 掌握 mysql、redis 或其他数据库，能够独立设计数据库表格并优化数据库语句
 4. 善于思考，能提出高质量的问题，系统性地分析并从根源上解决问题
 5. 具备良好的代码习惯，主动积极

安全研发（大数据方向）

base:深圳

工作职责

 1. 负责大数据应用中的统计分析，用户画像和文本挖掘等工作
 2. 负责多种应用场景的数据挖掘，dashboard 开发
 3. 负责捕获异常数据，数据建模，行为调整等
 4. 负责异常数据的画像描述，产品化输出等职责

基本要求

 1. 计算机相关专业，本科两年以上工作经验（经验丰富可放宽限制）
 2. 扎实掌握常用机器学习、最优化算法，概率统计、自然语言处理至少熟悉 1 种以上
 3. 熟悉 Linux 操作系统，熟练使用至少一门脚本语言
 4. 熟悉 Java/Python/Scala 语言特性，熟悉常用的数据结构、算法
 5. 熟悉 Spark/Hadoop/Storm 等数据平台和 MapReduce 的实现机制
 6. 扎实的编程和数学基础,对常用的机器学习算法、特征选择方法、数据建模过程有深入理解

研发类岗位优先：

 1. 有安全产品开发背景优先；
 2. 具备网络安全（ FW/IDS/IPS/UTM/Anti-Ddos/WAF/日志审计 /网络内容审计等）、主机安全（主机入侵防护 /防病毒 /内网安全管理等）、虚拟化安全和安全管理等，并熟悉相关开源项目者优先；
 3. 有海量数据处理经验者优先；
 4. 对性能优化和多核编程理解深刻者优先。

安全运营

base:深圳

工作职责

运营公司云安全系列相关产品安全产品的测试、上线、维护及事件处理分析客户需求的响应，评估，分析，及出具可行的参考意见安全事件的分析，应急事件的支持，相应的文档编写能力

基本要求

 1. 三年以上的安全行业工作经验，有大型公司及互联网公司从业经历
 2. 熟悉主流信息安全安全产品的配置及使用，如 IPS、WAF、防火墙、NGFW、VPN、网络防病毒、堡垒机、网络管理软件等
 3. 熟悉 tcp/ip，HTTP 协议、熟悉网络安全技术：包括端口、服务漏洞扫描、程序漏洞分析检测、熟悉入侵和攻击分析追踪、网站渗透、病毒木马防范等
 4. 熟悉常见 OWASP TOP 10 相关原理和检测方法
 5. 对安全风险评估有一定的经验，能够独立处理安全事件

安全专家

base:上海

工作职责

 1. 主动跟踪和深入研究最新的安全技术，能灵活运用信息安全专业技术与信息安全管理体系的相关方法提供定制化的信息安全解决方案
 2. 具备一定知识广度，能针对安全功能、行业场景、业务需求等多种视角输出总体安全解决方案
 3. 建立系统、全面、有效的信息安全管理、运营、监管体系，并主导实施落地
 4. 能够与相关合作伙伴、监管部门或兄弟部门紧密合作，共同打造信息安全防线
 5. 在防入侵、防泄漏领域，针对流程、机制、策略、架构、监控等不断进行升级、优化

任职资格

 1. 五年以上的安全行业工作经验，熟悉信息安全体系标准体系
 2. 具有非常强的学习能力，较好的分析问题解决问题的能力、归纳总结和文档能力，能够从行业发展趋势等角度，分析安全需求，准备技术交流材料
 3. 熟悉常见的网络攻击技术、入侵检测思路、防御加固方案，熟悉常见的网络访问控制手段和方案
 4. 了解国内外信息安全产品、技术、政策与标准，具有风险评估、安全策略设计、等级保护、安全管理体系、安全体系规划、安全集成等实施经验和项目管理经验
 5. 对业界安全标准有一定的了解

福利介绍

薪资待遇：20k-40k （大概范围，能力突出者不受此限制）

工作时间：弹性

招聘人数：人数无限制，多多益善（行业寒冬，逆势扩招）

员工福利：员工旅游、六险二金、带薪年假、年底多薪、佳节礼品、定期体检
