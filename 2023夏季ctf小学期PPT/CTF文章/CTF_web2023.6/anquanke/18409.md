公司简介

蓝盾股份是中国信息安全行业的领军企业，公司成立于1999年，并于2012年3月15日在深交所创业板上市（股票代码：300297）。公司构建了以安全产品为基础，覆盖安全方案、安全服务、安全运营的完整业务生态，为各大行业客户提供一站式的信息安全整体解决方案。公司近年提出“大安全”产业发展战略，紧抓信息安全产业外延不断扩大的机遇，通过”内生+外延”双轮驱动的方式，发展出以网络安全为核心，以军工安全、互联网应用安全以及云计算安全等新兴技术安全为重要方向的“大安全”产业生态体系。

公司始终以自主创新为发展源动力，以技术研发领先优势抢占市场，经过多年的探索和积累，形成和巩固了公司“智慧安全领导者”的市场地位。截至2016年年底，公司及主要子公司共拥有专利86项、软件著作权430项。安全产品涵盖了物理及工控安全、网络及应用安全、云计算大数据安全、移动安全、风险管控及安全管理、电商安全及个人安全、城市应急及生产应急安全、军工及保密安全等8大类别80个系列300多个型号的产品。公司凭借领先的技术优势及丰富的案例优势，已拥有商用密码产品生产定点单位证书、国军标质量管理体系认证证书、涉密信息系统产品检测证书18项、军用信息安全产品认证证书13项、产品销售许可证32项、中国信息安全认证中心产品认证证书35项、中国节能产品认证证书12项，以及一系列其他相关资质。基本获得了包括信息安全产品、信息安全集成及信息安全服务在内的业务类别的高级别资质或许可，是业内资质或许可持有量位列前茅的企业之一。

公司将继续秉承“智慧安全领导者”的理念与使命，长期专注于信息安全领域，深化安全技术内涵，提升品牌影响力，力争成为国内龙头、国际一流的信息安全企业。未来，公司将推进全线安全产品的高性能化和国际化，并将“云计算安全、大数据安全、移动安全、工控安全”等新兴技术应用安全提升至新的战略高度，加强云安全及云解决方案能力的构建与输出，加快公司“云战略”及“云框架”的设计与布局。此外，公司将继续发挥“大安全”产业发展战略的差异化优势，有效连结和协同网络安全、军工安全、互联网安全三大方向的技术价值、渠道价值、品牌价值及行业应用价值，通过持续的自主研发、技术合作及投资并购，构建更为完整、更具价值的“大安全”产业生态版图。

招聘职位

安全技术咨询顾问

薪资范围：15K-25K/月，招聘人数：2

岗位职责：

主要负责安全咨询服务项目的技术实施，包括安全体系梳理规划、安全架构设计、风险评估、等保建设方案设计、管理体系制定、安全技术培训等。

岗位要求：

 1. 对政府、央企、电力等行业领域具有深厚的信息安全咨询服务经验（3年以上工作经验）；
 2. 优秀的语言表达和文稿撰写能力，能够独立策划和指导行业用户整体网络与信息安全体系架构设计；
 3. 具有很强的学习能力和钻研能力，及时跟踪掌握行业领域最新的政策、新业务方向等信息；
 4. 拥有扎实的IT系统基础知识，熟悉网络、系统、云计算、大数据、移动互联、工控与物联网等；
 5. 熟悉常见网络安全攻防技术，并具备一定的动手实操能力；
 6. 熟悉ISO2700X、等级保护、SOX及IT内控等；
 7. 踏实稳定、认真积极的工作态度。

渗透测试工程师

薪资范围：12K-20K/月，招聘人数：2人

岗位职责：

负责攻防技术研究和渗透测试专项技术支持。

岗位要求：

 1. 对安全攻防技术具有深入的研究（重点是web安全），具备独立渗透测试能力和经验；
 2. 具有很强的学习能力和钻研能力，以及较强的语言表达和文稿撰写能力；
 3. 踏实稳定、认真积极的工作态度。

BM产品经理

薪资范围：8K-15K/月，招聘人数：2人

岗位职责：
1. 代表公司参与国家部委的相关会议，在技术层面与国家部委进行沟通交流；
2. 配合部署公司相关产品，参与国家部委对公司产品的认证检测；
3. 了解国家部委的政策方向，收集、整理、分析业务和产品的需求，对公司相关产品提出了意见和建议。

岗位要求：
1. 本科及以上，计算机、信息工程及相关专业；
2. 熟悉交换机、防火墙等常用网络设备；
3. 熟悉Linux操作系统，有性能调试经验者优先；
4. 具备保密意识；
5. 了解等保、分保者优先；
6. 了解大数据、虚拟化、国产化等新技术新应用者优先；
7. 自主学习能力强，语言表达能力强，文档写作能力强，协作沟通能力强。

产品经理（入侵防御，IPS）

薪资范围：15K-20K/月，招聘人数：2人

岗位职责：

 1. 市场调研：收集行业及竞争对手信息，协助确定产品发展目标及战略；进行市场调研，对行业及相关行业的发展进行调研；及时收集、处理所负责产品的各方面信息，为本人和相关人员的决策提供依据；组织对所负责产品进行市场调研，跟踪并研究相关产品的用户需求，收集和分析竞争对手信息，研究其发展动态和行业动态，并提出市场研究成果报告。
 2. 产品定义和设计：根据市场调研结果，对新产品的前景进行分析；参与制定产品战略和产品平台规划；负责新产品开发的立项 并组织实施；根据市场变化及时提出调整价格的建议和方案；
 3. 市场推广：参与新产品的市场前期推广及销售工作；负责对新的销售人员进行产品知识、市场和竞争信息的培训；
 4. 部门沟通：以产品负责人的角色，协调营销总部、研发部等部门的关系。

岗位要求：

 1. 本科及以上，计算机、信息工程及相关专业；
 2. 具有3到5年及以上相关工作经验，有信息安全行业相关背景者优先；
 3. 计算机应用开发、需求分析管理，熟悉安全产品及发展状况，熟悉网络安全产品者优先；
 4. 思维敏锐，沟通能力、组织协调管理能力强，有一定的策划实施能力，能承受较大的工作压力。

安全服务工程师

薪资范围：10K-15K/月，招聘人数：3人

岗位职责：

 1. 负责运营商安全服务、运营管理工作；
 2. 负责依据客户需求，利用特定工具，对客户的安全监控服务、分析服务、安全事件处理服务等；
 3. 负责安全服务、安全评估、咨询等项目的实施工作；
 4. 负责为客户提供应急响应等现场安全服务工作；
 5. 负责安全事件上报、跟踪和通报处理流程，实现安全事件的响应时效跟踪管理。跟踪安全事件处理过程，对于重大安全事件提供支撑服务，分析定位事件发生原因，对事件进行分析，提供事件处置建议和解决建议；
 6. 细化安全态势感知与分析、客户信息保护、大数据安全管理、云计算安全管理等新领域策略规则，细化安全态势分析、客户信息保护等方面的安全策略；
 7. 通过多种手段、渠道收集各类安全知识相关信息，包括：权威机构的安全预警、安全通报以及安全漏洞库信息；安全事件处理过程、解决方案和分析报告；安全态势趋势分析报告；审计分析处理结果等信息，建立安全知识库。

岗位要求：

 1. 大专及以上学历，2年以上安全及服务类管理和处理经验；
 2. 熟悉信息安全主流技术、标准及规范，具有较强的沟通、协调能力，能够承担项目的组织、协调工作；
 3. 熟悉ISO27000标准，有PMP、CISP、CISSP、ITIL等相关资质认证者优先；
 4. 熟悉常见的企业内部安全、互联网安全防御及保障技术；
 5. 熟悉各类安全工具的使用和结果分析；
 6. 对安全技术研究有兴趣，并能够恪守安全职业道德；具备较强的责任感，团队协作精神及良好的沟通能力。

售前技术咨询顾问（工作地点：天津）

薪资范围：8K-15K/月，办公地点：天津，招聘人数：2人

岗位职责：

 1. 负责面向客户的售前技术交流；包括：了解、整理、捕捉并完善客户需求；讲解和展示公司产品等；
 2. 负责撰写技术方案；制作交流展示PPT；
 3. 负责搜索市场需求，提出产品设计方案，并与研发部门沟通，推动产品开发；收集市场反馈意见，提供产品改进建议；
 4. 负责跟踪公司项目所需开发工具及主要第三方软件产品的技术和产品发展趋势，掌握主流技术及产品的最新动态，为项目提供合适的数据库、开发工具及第三方软硬件件产品建议；
 5. 负责并参与项目投标过程中应标文件准备和应答工作。

岗位要求：

 1. 大学专科及以上学历,计算机、网络或相关专业;
 2. 3年以上信息安全行业集成工作经验;
 3. 熟练使用项目投标技术、能够独立完成项目各阶段需要提交的报告;
 4. 了解系统架构设计、销售公关技巧、了解政府行业或网络安全行业的业务特点；
 5. 熟悉解决方案、招投标业务流程、网络及网络安全知识。
