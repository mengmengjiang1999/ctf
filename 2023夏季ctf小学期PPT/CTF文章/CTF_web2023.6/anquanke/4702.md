IPv6 Enable资质花落5家｜长亭雷池首批持证

阅读量46718

发布时间 : 2021-11-01 16:06:37

IPv6 Enabled Security Logo安全认证（下文简称“Enabled”）于10月21-22日广州“2021 全球下一代互联网峰会”横空出世，作为首批5家获此资质厂商之一,长亭科技雷池（SafeLine）下一代Web应用防火墙荣获Enabled 认证。

和已经较为普遍的IPv6 Ready Logo测试认证相比（下文简称“Ready”），Enabled认证价值何在，是IPv6认证也有“卷”的迹象了么？

首先，从两者名称可窥差别一二。
以两者名字中关键字进行汉语造句，
放在生活中举个例子：
Ready：我准备好减肥（计划）了。
Enabled：我已启动减肥（做）必备技能了。
简言之：两者落地阶段不同。

回到两个认证差异性本身。

“十四五”时期国家将深入推进 IPv6 规模部署和应用。全球IPv6论坛副主席刘东表示，随着互联网接入设备的快速增加以及IPv6等新技术的快速普及，互联网在基础设施、数据、网络和应用等方面受到的安全威胁也将越来越多并越来越多样化。IPv6 Enabled Security Logo安全认证体系的正式建立，将全面助力全球IPv6网络安全产业规范、健康发展。

可见， Enabled为网络安全厂商设备的在L4-L7 层IPv6支持升级中，提供强大支撑，确保IPv6改造的安全性，为IPv6网络安全保驾护航，步入更成熟高阶时段。


图：全球IPv6论坛副主席刘东为长亭颁发证书

长亭科技雷池（SfeLine）下一代Web应用防火墙荣获首批IPv6 Enabled Security Logo认证。在IPv6场景下应用层的威胁将以新的方式出现，雷池（SafeLine）下一代Web应用防火墙有效保障用户IPv4到IPv6过度期间应用层业务安全。

稳定的检测能力｜IPv6场景适配

IPv4向IPv6过渡过程中，IPv6协议栈会挤占IPv4业务的CPU和内存等资源，导致现有的IPv4业务在会话表容量、吞吐率上会出现不同程度的下降。雷池（SafeLine）对检测和处理能力进行了全面升级，保障在IPv6场景下检测能力“加量不加价”。

丝滑过度｜IPV4&IPV6双栈支持

为了向IPv6网络逐步演进，需要选用合适的过渡支撑技术，以保证金融、互联网等企业在IPv6改造后，能够同时对IPv4-only、IPv6-only以及IPv4/IPv6共用的用户提供访问。雷池（SafeLine）同时支持 IPv4-only、IPv6-only 和 IPv4/IPv6 双栈协议的部署模式。

“超能”负载｜内核支持 IPv6 流量处理能力

IPv6 时代，互联网流量较从前大幅攀升，随之为应用层流量分析设备的负载和安全性造成压力。雷池（SafeLine）成熟的大流量高负载的解决方案，能够在 IPv6 环境下进行部署，并对 IPv6 流量进行精准检测。

“硬核”升级｜内核支持 IPv6 报文解析

IPv6 的报文结构与 IPv4 有较大区别，雷池（SafeLine）引入多首部的概念，改变 IPv4 报文首部的部分字段名称与格式、取消了“首部校验”字段，同时，支持 IPv6 的报文解析能力，通过语义分析引擎解决了IPv6环境中检测丰富程度不够的问题。
