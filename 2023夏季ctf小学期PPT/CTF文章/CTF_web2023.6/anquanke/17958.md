苏宁易购 | 安全部门诚聘安全开发工程师、安全产品经理

阅读量73925

发布时间 : 2018-04-03 11:07:28

联系邮箱：huangfdy@cnsuning.com（请注明来自安全客）

公司简介

苏宁创立于1990年，在中国和日本拥有两家上市公司，是中国领先的商业企业，位居中国民营企业500强第二名。秉承 “引领产业生态、共创品质生活”的企业使命，苏宁产业经营不断拓展，形成苏宁易购、苏宁物流、苏宁金融、苏宁科技、苏宁置业、苏宁文创、苏宁体育、苏宁投资八大产业板块协同发展的格局。其中，苏宁易购跻身2017《财富》世界500强。

工作地址

江苏省南京市玄武区苏宁大道(徐庄软件园)1号

联系邮箱

huangfdy@cnsuning.com（请注明来自安全客）

招聘岗位

安全开发工程师（12k-20k）

岗位职责

 1. 负责苏宁WEB安全产品核心功能的设计、开发、维护等工作
 2. 跟踪和分析最新安全相关的技术，相关入侵事件应急响应

任职要求

 1. 有两年以上安全领域相关工作经验，能独立进行安全漏洞的分析和研究，有POC编写或攻防相关工作经验优先
 2. 熟悉各类安全漏洞的原理、利用方式，能够独立进行渗透测试，具有一定的逆向分析能力
 3. 熟练至少一门编程语言(Java/Python/Perl/Go/Lua)，对C/C++有一定了解
 4. 有WAF、漏洞扫描、入侵检测相关产品开发经验者优先
 5. 熟悉ELK、Spark、Hadoop等大数据分析框架，并能分析处理数据者优先
 6. 有机器学习方面经验，对异常行为分析或异常检测模型有研究者优先

高级web安全工程师（渗透测试方向）（10k-20k）

岗位职责：

 1. 安全事件排查与分析，编写安全分析报告
 2. 跟踪最新漏洞信息，进行业务产品的安全检查
 3. 定期进行安全审计、安全渗透测试，给出加固建议
 4. 参与制定规范、标准，协助产品安全开发生命周期的管理与控制

任职要求：

 1. 对常见Web安全漏洞的原理、危害、利用方式及修复方案有较深入理解
 2. 具有分析研究安全漏洞的能力，能够挖掘各种安全漏洞，有丰富的实战经验
 3. 熟悉常见脚本语言，能够独立进行WEB渗透测试，恶意代码检测和分析
 4. 有一定代码编写能力(python、golang、perl、java、php等其中一种)
 5. 有在各个SRC、漏洞盒子等安全平台提交过有价值的漏洞加分
 6. 对移动安全有所了解，熟悉加固、反编译、漏洞挖掘及解决方案等，有移动安全经验加分，有域渗透经验的加分
 7. 工作作风严谨细致，吃苦耐劳。具备较强的责任感，团队协作精神及良好的沟通能力
 8. 纯安全工作经验须满1年。学历大专及以上。特殊大牛可放宽条件

安全产品经理（12k-20k）

岗位职责：

 1. 负责集团内部沟通协调合作，需求分析，推动产品研发
 2. 负责应用安全平台功能及原型设计，用户手册、竞品调研、产品白皮书等发布文档编写
 3. 负责集团应用安全产品平台建设与规划，跟进业界最新发展趋势，提出产品优化与改进方案

任职要求：

 1. 有2年以上的安全产品经理相关工作经验，具有较好的产品架构能力，拥有完整的产品未来发展思路
 2. 熟悉交互设计，具备优秀的沟通能力和产品文档编写能力，熟悉Axure、Xmind、Visio等工具
 3. 有较强的跨部门的能力与团队协调能力，有责任心，积极主动
 4. 具有一定的数据分析和数据决策能力，了解机器学习基本的算法原理或者海量数据的处理优先

安全运营

岗位职责：

 1. 负责SRC（漏洞平台）日常运营，策划和组织线上线下安全活动
 2. 负责与安全行业以及行业安全人员积极沟通，树立公司在安全行业良好形象
 3. 维护微博微信公众号，文案写作
 4. 员工信息安全意识培训及安全知识宣传
 5. 跟踪关注国内外的安全动态，及时发布安全预警

任职要求

 1. 有策划和落实线下活动的能力，有组织各类活动经验
 2. 有较强的活动策划、文章写作能力，英语阅读、翻译、沟通能力
 3. 有新媒体运营的经验，有一定的创造力和文字功底，会使用常见的图文排版工具
 4. 了解黑产运作、互联网公司产品业务特点、行业技术发展趋势等
 5. 熟悉OWASP TOP 10漏洞攻击手段及验证方法，信息安全、计算机相关专业优先
 6. 一年以上工作经验，条件优秀者放宽至应届毕业生，有第三方安全公司从业经验优先

员工福利

 1. 丰厚的薪酬待遇与晋升空间
 2. 五险一金+双休+法定假日
 3. 午餐补贴、通讯补贴等各种补贴
 4. 每年一次员工体检
 5. 带薪假期
 6. 组织内部资料分享、技术交流、员工培训
 7. 各类团建活动
