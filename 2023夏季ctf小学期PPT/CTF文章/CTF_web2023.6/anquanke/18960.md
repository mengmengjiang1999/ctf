公司简介

蚂蚁金服（全称：蚂蚁金融服务集团），成立于2014年10月16日，蚂蚁金服旗下拥有支付宝、支付宝钱包、余额宝、招财宝、蚂蚁小贷及网商银行等品牌。

工作地点

浙江杭州、四川成都

联系方式

简历投递邮箱：baixiang.sjj@antfin.com（请注明来自安全客）

招聘岗位

高级安全工程师/安全专家_sdl

渗透测试，漏洞挖掘方向

岗位职责：

1、负责支付宝业务的安全代码审计、渗透测试和漏洞挖掘等工作，根据安全风险提供安全建议和解决方案；

2、应急响应事件处理。

3、安全攻防技术研究。

4、负责蚂蚁SDL标准制定，流程优化，工作效率提升

5、负责蚂蚁某业务线的SDL工作。

岗位要求：

1、熟悉 WEB 安全渗透和漏洞挖掘（黑盒和白盒），熟悉漏洞的内在原理、检测方法、利用手段以及对应解决方案。

2、熟悉JAVA/PHP/python/C/C++至少一门语言。

加分项：

1、机器学习算法或数据挖掘实践经验。

2、参与过大型 web 应用项目。

3、SRC top 核心白帽子或者通用漏洞提报者。

4、掌握移动端安全测试和逆向能力。

高级安全工程师/安全专家(大数据安全方向)

我们提供真实的交易数据，上亿级消费者的商业行为，百万级商户的经营数据；我们面对的是动态、复杂、多变的欺诈风险；基于AI大数据分析、风控能力。我们每天保护数亿支付宝账号，资金安全，致力于用数据产生价值、让支付体验更加便捷与安全。
岗位职责：

1.基于历史交易数据和经验，基于数据分析、挖掘，机器学习等技术控制欺诈，作弊，等用户行为，并持续优化。
岗位要求：

2.统计学、应用数学、计算机、信息安全相关专业毕业，深厚的机器学习理论知识和实际经验，有丰富的风控场景平台体系化能力者优先。

Web 安全高级工程师（2人）

岗位职责：

1、负责支付宝业务的安全代码审计、渗透测试和漏洞挖掘等工作，根据安全风险提供安全建议和解决方案；

2、应急响应事件处理。

3、安全攻防技术研究。

岗位要求：

1、熟悉 WEB 安全渗透和漏洞挖掘（黑盒和白盒），熟悉漏洞的内在原理、检测方法、利用手段以及对应解决方案。

2、熟悉JAVA/PHP/python/C/C++至少一门语言。

加分项：

1、机器学习算法或数据挖掘实践经验。

2、参与过大型 web 应用项目。

3、SRC top 核心白帽子或者通用漏洞提报者。

4、掌握移动端安全测试和逆向能力。

其他：

预招岗位级别：P6 ／ P7 （ P7 带蚂蚁金服期权）

工作年限：两年及以上

学历：大专或以上
