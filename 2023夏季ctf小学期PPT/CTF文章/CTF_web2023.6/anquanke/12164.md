公司简介

杭州安恒信息技术股份有限公司于2007年成立，一直专注于网络信息安全领域，主营业务为网络信息安全产品的研发、生产及销售，并为客户提供专业的网络信息安全服务。产品及服务涉及应用安全、大数据安全、云安全、物联网安全、工业控制安全及工业互联网安全等领域。

公司秉承“助力安全中国、助推数字经济”的企业使命，以“共同成长，成就客户，责任至上，开放创新，以人为本，诚信正直”作为企业的价值观，不断提高核心技术创新能力，致力于成为一家具有优秀企业文化和社会责任感的新时代网络信息安全产品和服务提供商。

招聘详情

服务经理

【岗位职责】

 1. 项目管理：对项目实施的过程和质量负责，包括项目实施、需求跟踪、培训、质量交付等。
 2. 技术处理：精通网络协议如tcp、http、dns，负责技术问题排查，跟踪闭环及信息同步。
 3. 技术赋能：渠道技术和办事处售后技术的赋能培训工作。
 4. 产品提升：形成可落地的提升工作效率和产品质量的需求文档并跟踪落实。
 5. 区域服务营销：针对性开展服务营销工作，增强用户粘性。

【基本要求】

 1. 深入理解网络协议，如TCP/IP、DNS、HTTP、HTTPS等，有数通基础。
 2. 熟悉waf和ddos设备的原理和配置
 3. 具备独立的网络故障排查能力。
 4. 精通Web攻击方法 sql注入、Xss攻击、命令注入、CSRF攻击、上传漏洞、解析漏洞等。
 5. 熟练使用Phthon/shell/perl至少一种脚本语言；熟练使用Excel/Word/PPT/Project等办公软件，熟练使用Axure、Photoshop等原型工具，具备一定审美；
 6. 良好的思维能力、信息收集及数据分析能力、文档撰写能力。

服务质量管理专员

【工作职责】

 1. 根据产品规划或项目要求，组织收集和分析用户需求，完成产品或项目的需求说明。
 2. 负责产品的需求和bug管理工作、跟踪、验证需求实现等。
 3. 根据市场和运营需求，对产品、交付文档等进行分析设计，包括框架设计、UI设计等。
 4. 对于产品质量提升提出建设性建议并跟踪实现。

【岗位要求】

 1. 具有网络安全、SaaS服务经验，至少2年以上。
 2. 具有较强的沟通能力、逻辑分析能力和文档编写能力。
 3. 掌握需求分析方法，熟悉需求和项目管理，了解开发流程。
 4. 具有较强的责任心、团队合作精神及用户服务意识。

安全运营经理

【工作职责】

 1. 根据公司的网络安全数据服务（DaaS）的运营方向，和产品团队制定面向客户、内部各销售线的运营战略计划；
 2. 负责清晰地向管理层、研究团队、研发团队传递客户的需求，并且规划内部资源与团队协同；
 3. 负责面向客户与销售团队开展产品运营服务的培训、推广；
 4. 负责通过各类营销宣传推广，配合互联网团队进行获客与客户关系跟踪维系，并用数据推动运营

【岗位要求】

 1. 具有网络安全从业经验，安全服务、安全产品技术支持等均可，掌握基本的计算机与网络知识，熟悉网络攻击事件与WEB安全；
 2. 具有优秀的文档编写能力，独立承担过专项报告编写者或发表过文章者优先；
 3. 具有互联网运营思维者更佳。

产品售前经理

【岗位职责】

 1. 根据公司的战略计划，和产品团队，技术团队一起制定新产品新功能的上市战略，支持产品的销售和客户的增长。
 2. 负责产品市场定位、产品包装及价格策略提出规划。
 3. 清晰地向管理层、产品技术团队传递产品的市场价值和发展，并且规划与产品相关的资源或团队的协同。
 4. 负责面向销售与用户开展产品的培训、推广与售前支持。

【岗位要求】

 1. 具有安全产品的售前、技术、产品经验，至少2年以上。
 2. 独立负责过一个产品的市场推广实现销售增量。
 3. 具有面向政府机关单位的产品影响经验。

高级测试工程师

【岗位职责】

 1. 根据软件设计需求制定测试计划，设计测试数据和测试用例；
 2. 有效地执行测试用例，提交测试报告，完成相关产品的操作手册等的更新和维护；
 3. 准确地重现、定位并跟踪问题，推动问题及时合理地解决；
 4. 完成对产品的集成测试与系统测试，对产品的软件功能、性能及其它方面的测试；
 5. 搭建测试相关环境
 6. 配合研发进行模块测试。

【任职要求】

 1. 计算机、软件测试或相关专业大学本科或以上，两年以上测试经验；
 2. 熟悉软件测试流程，掌握软件测试理论和方法，能够熟练应用多种测试工具；
 3. 有较强的逻辑分析能力和学习能力；
 4. 具有Linux、UNIX等操作系统下测试经验者优先考虑；
 5. 具有性能、自动化相关测试经验者优先考虑；
 6. 具有网络安全相关软件产品测试经验者优先。
 7. 热爱软件测试工作，可以胜任重复性工作和承担高强度工作压力，工作细致认真，有耐心，富有团队合作精神与良好的沟通技巧。

解决方案经理

【岗位职责】

 1. 负责编写行业级SaaS化产品解决方案；
 2. 负责政府、金融、运营商、教育等行业市场拓展；
 3. 协助销售针对标杆客户的拓展和落地；
 4. 负责智慧城市安全方案落地；
 5. 负责协同技术输出标准化安全解决方案。

【岗位要求】

 1. 具有政府、金融、教育、运营商等多个行业的安全解决方案经验；
 2. 具备较强的市场分析、营销、推广能力和良好的人际沟通、协调能力，文案编写能力、分析和解决问题的能力；
 3. 具备较强的语言表达能力，有一定的宣讲经验；
 4. 抗压能力强，创新意识强，能适应出差；
 5. 对云安全防护、云安全监测等技术或解决方案者优先；
 6. 具备CISP、CISSP、PMP等认证优先。

安全产品经理

【岗位职责】

 1. 用户技术交流，产品介绍和方案宣讲，并针对性挖掘用户需求，进行分析和引导；
 2. 掌握所负责产品的各功能和技术细节，了解主要竞争对手的基本特性和功能列表，并制定应对策略和市场策略；
 3. 协同研发规划及发展方向，明晰产品定位、目标、策略；
 4. 负责产品标准营销材料的输出，并面向销售和客户进行推广和讲解；
 5. 负责将用户需求转换成研发需求，包括需求文档、原型的输出，并做好研发需求跟踪与把控；
 6. 负责产品市场推广工作，包括政策研究、软文编写、市场宣讲等工作。

【岗位要求】

 1. 具有3年以上信息安全售前或产品经理工作经验；
 2. 具备较强的语言表达能力，有一定的宣讲经验；
 3. 具备较强的市场分析、营销、推广能力和良好的人际沟通、协调能力，文案编写能力、分析和解决问题的能力；
 4. 抗压能力强，创新意识强，能适应出差；
 5. 具备较强的需求理解能力，能完成需求落地和跟踪工作；
 6. 具备CISP、PMP等认证优先；
 7. 熟悉整体信息安全体系架构，熟悉网络安全、WEB应用安全、云安全等技术，具有CDN、DDOS、WAF等产品运营经验优先。

安全分析专家

【岗位职责】

 1. 负责重大网络安全事件的跟踪研究分析（包括不限于DDOS攻击、境内外黑客组织攻击动向、信息泄露等）
 2. 负责网络灰色产业链的跟踪研究分析

【岗位要求】

 1. 具备1年以上的安全相关工作经验。
 2. 有一定的编程能力，可以使用任一编程语言快速处理数据编写demo。
 3. 有红蓝对抗或渗透测试实操能力的优先。
 4. 有修过统计学、数据分析的能力优先。

【加分项】

 1. 有一定的二进制文件逆向分析能力优先。
 2. 参与过重大安全事件、黑客团伙的攻击活动的分析。
 3. 发布过安全分析相关paper者优先。

逆向分析专家

【职位描述】

 1. 配合蜜罐团队，分析蜜罐捕获的“僵木蠕”等样本；
 2. 分析样本文件，提取样本中的威胁信息。

【任职要求】

 1. 熟悉x86/arm等平台的汇编语言，对软件逆向领域和软件安全领域有强烈的爱好；
 2. 熟练掌握软件逆向静态分析、动态调试、代码跟踪等；
 3. 熟练掌握SoftIce、IDAPro、OllyDebug、WinDBG等调试、逆向工具；
 4. 有沙箱开发、使用经验的优先；
 5. 精通网络协议HTTP、DNS等的优先；
 6. 有网络安全攻防能力优先；
 7. 有其他特别优秀的能力，可以适当放宽上述条件。

安全运营工程师（实习）

【岗位职责】

 1. 负责风暴中心远程一线技术支持，主要处理云防护（waf）的售后技术支持；
 2. 接听处理售后电话和其他即时沟通软件反馈的售后问题；
 3. 为需要加入云防护的新网站做接入服务；
 4. 协助有需要的客户进行网络排障。

【任职要求】

 1. 熟悉TCP/IP、DNS、HTTP、HTTPS等协议，具有数通基础；
 2. 具有良好的学习能力、服务意识和沟通能力，做事认真负责、踏实肯干；
 3. 能接受晚上值班。

DDOS架构师

【岗位职责】

1.负责DDos产品架构设计和实现。

【任职要求】

1.计算机相关专业，三年以上Linux C研发经验，大学本科及以上学历;
2.精通Linux环境C语言开发，熟悉TCP/IP协议栈；
3.精通DDoS攻击原理和防御方法，如tcp flood、udp flood、CC和各种异常包；
4.熟悉DDoS产品的代码架构和各功能的实现原理和方法；
5.有进取心，有较强的抗压能力，能自我激励。
薪资待遇：15K-30K

Linux C高级研发工程师

【岗位职责】

1.负责云waf产品的稳定性和安全防护功能的研发。
2.负责云waf产品的功能设计和实现。

【任职要求】

1.计算机相关专业，具有三年及以上Linux C研发经验，大学本科及以上学历;
1.精通Linux环境高级编程和网络编程，熟悉TCP/IP协议、路由、代理等网络基础知识;
2.精通C语言、数据结构;
3.有防火墙、WAF、DDos、VPN等网络安全设备研发经验者优先;
4.熟悉Nginx、Haproxy、DNS、DPDK等优先;
5.有进取心，有较强的抗压能力，能自我激励。
薪资待遇：15K-30K
