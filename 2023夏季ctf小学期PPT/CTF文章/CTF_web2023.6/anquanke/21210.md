公司简介

致象尔微电子科技(上海)有限公司成立于2014年，总部位于上海张江，在北京设有研发分部。创业团队来自于国际芯片产业巨头、曾获多项国际大奖的资深技术、战略管理人。 公司致力于开拓新一代运算平台，包括核心控制芯片、系统软件、应用开发环境和云服务，通过开创性的软硬件生态圈建设和商业模式创新，为全球智能硬件及创客运动提供强大、灵活、易用、高性价比的系统引擎。

CEO是前Intel副总裁，公司的其他核心负责人也大都是知名外企高管背景，目前在上海新组建芯片安全团队，致力于x86芯片安全软件的开发，技术负责人是前Intel亚太研究院安全技术专家，公司获得中科院和海光半导体基金支持。

官方网站：http://www.tangramtek.com/

招聘岗位

Linux Kernel developer/Linux内核开发

岗位描述：

将专注于内核安全,虚拟化,性能,与x86 CPU的co-design

任职资格：

1. Experience on debug and patch the Linux kernel

2. 精通C语言

3. 熟悉企业Linux版本 (Oracle, Ubuntu, CentOS, SuSE)

4. 精通脚本语言, 比如. bash, python, perl.

5. 至少5年大型软件项目工作经验

6. 具有x86上的性能调试经验

7. 具有安全和加密知识的优先

8. 具有虚拟化技术的优先

9. 懂X86汇编编程的优先


Secure Software development manager/安全软件开发经理

高级专业管理人员职位，负责安全软件开发团队

3、熟悉计算机安全领域的研发工作，熟悉各种加解密算法;

4、有安全软件产品和团队实际管理经验；

5、英语文献阅读能力

Secure Software validation manager/安全软件验证经理

岗位描述：

高级专业管理人员职位，负责安全软件验证团队

任职资格：

1、计算机技术或电子信息以及电子工程等相关专业本科以上学历；

2、管理沟通能力强, 熟悉产品开发验证流程.

3、 精通软件测试

4、精通计算机安全领域的研发工作，熟悉各种加解密算法; 熟悉安全软件验证的整个软件流程,工具

5、有安全软件产品和团队实际管理经验； 有能力领导安全软件工具,测试框架,和测试用例开发

6、英语文献阅读能力

Secure Software architect/安全软件架构师

岗位描述：

高级专业技术人员职位，负责安全软件验证系统的架构设计和团队技术培训

1、计算机技术或电子信息以及电子工程等相关专业本科以上学历；

2、管理沟通能力强, 熟悉产品开发验证流程.

3、精通软件测试

4、精通计算机安全领域的研发工作，熟悉各种加解密算法; 熟悉安全软件验证的整个软件流程,工具

5、有能力领导并设计安全软件工具,测试框架,和测试用例开发

6、英语文献阅读能力

高级安全软件工程师

岗位描述：

1、高级专业技术人员职位，独立负责工作小组，给下级成员提供引导或支持并监督他们的日常活动；

2、参与安全软件产品项目规划工作，制定具体项目实施方案；

3、整合并优化项目开发所需各种资源；

4、负责软件开发技术和规范及标准流程的改进；

5、参与软件系统的设计和分析；

6、根据开发进度和任务分配，完成相应模块软件的设计、开发、编程任务。

任职资格：

1、计算机技术或电子信息以及电子工程等相关专业本科以上学历；

2、熟悉计算机安全领域的研发工作，熟悉各种加解密算法;

3、受过软件测试、产品知识等方面的培训；

5、3-5年以上编程经验和产品开发经验；

6、熟悉Linux操作，扎实的C语言基础，有丰富的底层软件开发经验；热爱产品研发和技术发展；具有强烈的责任意识和开放的心态；

7、事业心强，勤奋好学，有团队精神；

8、英语文献阅读能力。

高级安全软件测试

岗位描述：

1、高级技术人员职位，独立负责工作小组，给下级成员提供引导或支持并监督他们的日常活动；

2、参与安全软件的设计, 领导组织和实施软件测试项目；

3、完成安全软件的功能测试；

4、跟踪分析测试情况，解决测试过程遇到的问题；

5、建立、维护测试工作的相关文档。

任职资格：

1、计算机或相关专业本科学历；

2、3-5年以上测试工作经验；有独立领导测试项目经验；

3、熟悉Linux相关开发语言，具备软件测试平台搭建的能力，熟练编写测试脚本和使用测试工具；

4、了解软件工程学思想和方法，了解基本数据库系统及网络知识；

5、较强的发现问题，分析问题的能力；较强的语言表达能力和文档撰写能力，良好的英文阅读能力；

6、工作责任心强，细致，耐心。


薪水范围：工程师/架构师 15K-35K/M, 经理 30K-50K/M，一般全年14-15M薪水
