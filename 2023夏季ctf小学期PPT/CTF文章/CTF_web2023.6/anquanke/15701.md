F5 以6.7亿美金收购 NGINX

阅读量264132

|评论2

发布时间 : 2019-03-12 18:26:00

编译：360代码卫士团队

NGINX 公司以 6.7 亿美金的价格被 F5 Networks收购。

NGINX 为全球超过半数的最繁忙的网站提供服务。如今互联网上的大多数网站以及数十万款应用如 Instagram、Pinterest、Neflix和 Airbnb 都托管在运行 NGINX 的web 服务器上。

NGINX web 服务器是全球第三大使用最广泛的服务器，仅次于微软和 Apache，且比谷歌还要靠前。简言之，如果没有 NGINX，互联网就不会存在。

F5 收购旨在连接 NetOps 和 DevOps

F5 Networks 是云和安全应用基础设施的行业领导者，帮助企业更加安全并管理其软件和web 应用。

当NGINX 推出收费服务 NGINX Plus 以帮助开发人员为元云服务如亚马逊 Web 服务、微软Azure 和其它顶级云计算服务构建现代 app 时，和 F5 成为对手。

而这也是收购发生的合理原因。

F5 公司的总裁兼首席执行官 Francois Locoh-Donou 表示，“F5 收购 NGINX 加速了我们的软件和多云变革，从而增强了我们的增长轨迹。结合 F5 世界级的旨在改进性能、可用性和管理的应用安全和丰富的应用服务组合以及 NGINX 的顶级软件应用交付和 API 管理解决方案、在 DevOps 社区的无与伦比的可靠性和品牌认可，以及广泛的开源用户库，我们为企业的多云环境中以一致的应用服务缩小了 NetOps 和 DevOps 之间的距离。”

本收购也将使 NGINX 受益，因为 F5 Networks 将利用其全球的销售能力、渠道基础设施和合作伙伴生态系统扩大 NGINX 对企业的销售机会。

NGINX 首席执行官 Gus Robertson 在宣布本次收购的新闻发布会上表示，“我认为 F5 将成为技术、开源项目和社区以及促使 NGINX 成功的家庭的聚集地。我非常高兴，能够将NGINX 的开源创新融入 F5 的 ADC 领导力和企业范围，继续这段旅程。F5通过旨在DevOps 的解决方案获得深度，而 NGINX 通过访问数万客户和合作伙伴而获得宽度。”

在周一发布的新闻稿中，F5 公司宣布了以约6.7亿美元收购 NGINX 全部股份的计划，不过可能会有某些调整。

F5 Networks 表示，NGINX 品牌以及其位于旧金山的总部将会继续存在，收购完成后，NGINX 首席执行官 Robertson 和创始人 Igor Sysoev 以及 Maxim Konovalov 将继续领导 NGINX。

收购完成后，Robertson 将会加入 F5 的高级领导团队并直接向 Locoh-Donou 汇报。

F5 和 NGINX 的董事会均已批准该收购，预计将于2019年的第二个季度完成收购。
