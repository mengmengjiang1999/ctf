公司简介

上海岂安信息科技有限公司（简称“岂安科技”），专注于为企业提供互联网业务风控解决方案。所服务的行业覆盖互联网金融、银行、电商、政府、航旅、互娱等诸多领域，为企业解决发展过程中与业务、交易、用户相关的安全问题，并提供完善的业务风控产品、技术和服务。

公司网站：bigsec.com

工作地点

上海

我们的福利

弹性工时，不打卡！！open的晋升空间、良好的工作环境、不定期国内外旅游、还有更多隐性福利~

招聘岗位

JAVA专家（20K-50K）

职位描述：

1、设计与实现海量数据的存储和实时大规模计算系统；
2、设计和实现海量数据的离线分析系统；
3、负责公司高性能、跨数据中心的 Java 中间件（soa，mq，storage…）开发；
4、探索和改进新技术和产品。

岗位要求：

1、有扎实的编程功底，热爱编程；
2、注重代码质量，有良好的编程习惯；
3、熟悉 Linux 操作系统下的程序开发和调优；
4、精通 Java 语言和环境，精通 Java 高并发编程，熟悉JVM；
5、有一些开源中间件使用经验，如redis，rabbitmq等等
6、有海量数据计算和存储引擎开发经验的优先。
7、熟悉 Elasticsearch 使用和运维调优的优先；

Python开发（10K-25K）

岗位职责：

1、负责公司核心产品功能模块设计与实现，具有独立完成能力。
2、负责公司核心系统及框架的设计、开发、维护。
3、探索和改进新技术和产品。

岗位要求：

1、熟练使用Linux/Unix系统，Linux/Mac 作为开发环境。
2、精通Python，熟练使用大部分py包和WEB框架。
3、编写代码质量高，偏向面向对象开发。
4、熟悉主流结构化和kv数据库。
5、至少一年工作经验。

资深前端开发工程师（20K-50K）

岗位职责：

1、参与公司各产品线的前端应用设计、开发以及维护工作；
2、参与前端基础建设工作，包括新技术的调研、标准组件/工具的设计与开发等；
3、参与数据可视化方向的研究，标准图表组件的设计、开发以及维护工作。

岗位要求

1、计算机相关专业本科及以上学历，3年及以上Web前端开发经验；
2、扎实的HTML、CSS和JavaScript技术基础，遵循良好的编程规范；
3、熟悉Linux系统常用操作命令以及以Git为版本控制系统的开发流程；
4、熟悉各种前端开发范式，对设计模式、工程化和组件化等有自己的认识和实践经验；
5、有较强的学习能力、求知欲以及逻辑思维能力，能够自主解决实际生产问题；
6、有丰富的业务应用开发/基础框架设计、开发以及重构的经验，能够从零开始搭建应用；
7、熟悉Angular、React或Vue的设计思想和应用，有单页应用的设计以及开发经验；
8、熟悉D3.js的应用，有相关的项目开发经验，有原生Canvas或SVG技术项目经验者优先考虑；
9、有Node.js或移动端应用开发经验者加分。

业务风险分析师（10K-20K）

岗位职责：

1、根据客户具体业务模式，分析可能存在的风险点，结合风险点利用策略引擎制定可行有效的规则模型
2、高效响应客户需求，总结产品反馈和产品运营数据，提出产品改善意见
3、对行业内新的业务风险事件保持关注和学习
4、与产品经理紧密合作，提升产品效果

岗位要求：

1、至少1年以上toB端产品运营工作经验
2、了解互联网爬虫、撞库、羊毛党等常见黑产的运作模式及判断方式
3、对数据敏感，能从基础数据中总结显著特征，并转化为策略或模型
4、熟练使用抓包工具、mysql、tableau、R等常用分析工具，会python加分
5、优秀的问题解决能力和良好的沟通协作能力
加分项：
1、负责过某一互联网产品的账号安全、反爬虫、反欺诈工作
2、独特的风险判断方式和维度
3、深入了解设备指纹、验证码等常见实现方式与具体优缺点

运维工程师（10K-20K）

职位描述:

1、负责公司大数据产品的实施售后工作
2、负责为客户搭建数据分析平台提供解决方案并主导落地

岗位要求：
1、精通LINUX操作系统下主要服务的部署。 精通系统排错。
2、熟悉nagios、zabbix，并可以自写插件满足运维需求；熟悉puppet,ansible等
3、精通Linux操作系统，熟悉python开发优先，熟悉至少一种python web框架，并能独立完成一定的代码编写任务
4、熟悉openresty+lua、python、docker、jenkins、ELK优先
5、有强烈的责任心，良好的沟通能力
6、主动性强，善于发现问题和解决问题
7、具有优秀的自主学习能力，自我管理能力

测试工程师（10K-20K）

职位描述:

1、参与产品测试的全流程，包括参与需求分析、评审；参与制定测试计划、设计和执行测试用例，进行缺陷跟踪和系统质量分析等；
2、根据产品需求进行测试用例的编写、用例评审；
3、协助开发人员查找并提交Bug，提交产品功能优化、性能改进的建议；
4、每次测试结束后，对每轮测试结果进行数据整理，提交测试报告。
5、协助参与自动化测试平台搭建，参与自动化测试相关工作；

岗位要求：

1、本科及以上计算机相关专业背景，2年以上实际web系统测试经验；
2、掌握基本的软件测试理论，熟悉软件测试的基本方法、流程和规范；
3、熟练运用各种测试用例设计方法，熟悉常用的测试管理工具；
4、熟悉Linux常用命令，熟悉sql进行数据库辅助测试；
5、有接口测试和数据类测试经验优先考虑；
6、学习能力强，良好的责任心、沟通能力和团队协作能力；

项目经理（8K-25K）

岗位职责：

1、指导团队成员对项目管理规范的执行；
2、参与前期的项目立项、可行性分析、项目方案的制定，功能需求等；
3、负责项目日常管理，定期收集项目信息和数据，发现并协助解决项目的各类问题，以保证项目按质量、4、成本及时间进度要求顺利完成；
5、参与技术相关的架构评审，把关技术设计环节的设计质量；
6、负责及时指导、处理、协调和解决开发过程中出现的技术问题；

岗位要求：
1、本科及以上学历，计算机或相关专业毕业,
2、有3年以上软件项目管理经验
3、有较强的对内、对外沟通协调能力
4、熟悉软件工程或系统工程方法论，并且具备实际经验
5、做事认真，仔细，有很强的责任感，项目跟踪、项目执行力较强

资深售前顾问（18K-25K）

岗位职责：

1、负责公司产品与服务的售前技术支撑工作，包括技术咨询应答、产品资料编写、客户及行业解决方案编制、招投标相关技术资料拟制、销售人员的产品方案讲解培训，等。
2、配合销售完成与客户的技术交流、技术方案宣讲、应用演示、客户需求发掘及响应、协调产品部门落实需求实现等工作，促成合同落地。
3、协调实施工程师完成与客户的技术测试、对接、协调等工作。
4、协助销售发掘项目与市场机会。
5、了解和收集客户、行业的技术新需求和新趋势，并向产品、研发部门反馈，以推进我司产品改进。

岗位要求：

1、拥有计算机软硬件、信息安全专业或其他IT相关专业本科及以上学历；
2、拥有2年以上网络安全、信息安全软硬件产品或系统开发项目的售前、需求分析或者开发工作经验；
3、拥有反欺诈风险或信贷风险管理工作经验者优先；
4、拥有主动学习的热情和快速学习新业务新知识的能力，能够独立编写技术性方案及文档；5、有责任心和团队合作意识；思路清晰，思维敏捷；具备良好的人际沟通与协调能力。

高级招聘专员（8K-12K）

岗位职责：

1、全面协助公司内部的招聘工作；
2、进行职位需求分析，能迅速甄选有效简历推荐给用人部门；
3、通过有效的电话沟通技巧与候选人进行沟通，预约面试；
4、录入和维护招聘信息，即时向主管进行信息反馈；
6、跟踪招聘进度，采取有效措施改进工作中的不足，确保目标达成；
7、招聘渠道拓展和候选人脉资源的挖掘；
8、Offer洽谈和入职安排；
9、配合公司其他各项工作的开展。

岗位要求：

1、大专及以上学历，人力资源相关专业优先；
2、3年及以上互联网IT相关行业招聘经验优先；
3、善于积极思考和快速学习；
4、强大的抗压能力，有创业心态者优先考虑；
5、良好的执行力和团队合作，能按时、按质完成日常招聘相关工作；
6、有猎头行业或相关招聘经验者优先考虑。

大客户销售经理/总监（15K-18K）

岗位职责：

1、了解和发掘客户需求，为客户提供专业的咨询，并促成销售；
2、有效执行公司的销售策略，能够对销售过程提出合理化建议；
3、严格按照公司要求进行销售，对销售过程进行记录、分析、跟踪和管理；
4、根据市场和公司的战略规划，制定个人的销售计划和目标，完成公司要求的业绩指标。

职位要求：

3-5年以上大型计算机软件相关的销售经验，并拥有优秀的过往业绩
