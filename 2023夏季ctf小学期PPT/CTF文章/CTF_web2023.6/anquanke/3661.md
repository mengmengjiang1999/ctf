火山引擎云安全入选“隐私计算2021年度优秀应用案例TOP10”

阅读量60086

发布时间 : 2022-01-26 10:09:37

近日，开放隐私计算OpenMPC对外公布了“隐私计算2021年度优秀应用案例TOP10”。火山引擎云安全凭借“融合差分隐私的火山引擎DPSQL服务”案例，成功入选TOP10。

开放隐私计算OpenMPC是国内第一个隐私计算开放社区。为了推动隐私计算行业高质量发展，开放隐私计算社区在2022新年伊始拉开了『隐私计算2021年度最具潜力企业TOP10』和『隐私计算2021年度优秀应用案例TOP10』的评选序幕。本次评选专委会由北京大数据研究院莫晓康教授、中科院信工所王利明教授、某大厂安全部负责人、耀途资本、云启资本等专家和投资界人士组成，经过调研、初评、专家评审、终评等多轮遴选，最终得出获奖榜单。

▲隐私计算2021年度优秀应用案例TOP10

站在数据成为比肩石油的基础性关键战略资源的当下，隐私计算为需求强烈但瓶颈重重的数据流通提供了破局思路。Gartner发布的2021年前沿科技战略趋势中，将隐私计算列为未来几年科技发展的九大趋势之一。

火山引擎云安全在隐私计算技术方面一直长期关注和投入，本次成功入选TOP10的“融合差分隐私的火山引擎DPSQL服务”，已在银行、车企、零售等众多行业中应用，未来也会进一步向外部客户进行开放。

融合差分隐私的火山引擎DPSQL服务

目前业界拥有一定数据资源的服务商，会为企业客户提供群体洞察等服务。为保护用户的隐私，所有数据的使用都会遵循GDPR、CCPA、《个人信息保护法》等法律法规，并最大限度消除用户隐私泄漏风险。

火山引擎云安全致力于差分隐私技术的研发，能有效解决洞察分析报告中的隐私泄露风险。

解决方案

针对洞察报告中的隐私泄漏风险，火山引擎云安全的安全研究团队将差分隐私与 SQL 分析技术结合，提供隐私保护的数据分析能力，可自适应的根据 SQL 查询语义，完成查询语义分析、语句重写、联合敏感度分析、隐私预算管理、噪声添加、数据可用性评估等差分隐私处理逻辑，最终输出平衡可用性和隐私性的查询结果。

在本案例中，使用 DPSQL 对交集人群数据进行查询，提供了低成本的接入方案，使业务系统快速具备了保护用户隐私的能力，同时由于 SQL 语义的丰富性，可提供灵活多样的分析能力，满足不同的应用场景。

应用案例

DPSQL服务在火山引擎的客户数据平台业务中已经接入了多家客户，包括银行、车企、零售等行业。DPSQL服务不仅帮助业务满足了隐私保护和业务合规的需求，同时也成为行业中隐私保护应用的典范案例。未来火山引擎DPSQL服务也将持续为抖音、今日头条等业务提供更广泛的隐私保护能力。

火山引擎云安全致力于为用户构建透明可信的安全云，火山引擎云安全将持续结合字节跳动内部安全防护体系、最佳实践和技术创新，为企业用户提供更为全面的网络安全解决方案。
