公司简介

二向箔安全团队，成立于2017年，隶属于四川风物长宜信息技术有限公司。 团队由众多知名白帽组成，主要专注于网络空间安全领域。

团队目前主要方向为安全研究与安全知识的传播，以及部分前沿云计算技术的探索。团队曾获得过 Google、Chrome、Apple、微软、Adobe、腾讯、阿里 的 官方认可。也是国内少有的对万维网标准做出过贡献的团队，获得了 W3C 的认可。 2017 年至今，团队较少做事务性安全服务，大部分时间都在最前沿技术如 serverless 的研究与应用上，已经有部分相对完整的研发成果与可应用平台。 未来会在云安全与网络安全知识的传播方面有所输出。

招聘详情

职位一【安全研究员】

岗位职责：

1、确保安全服务项目高效实施；负责安全技术部门人员培养；

2、参与公司创新型安全研究；

任职要求：

1、熟悉Web安全技术，熟悉OWASP TOP10漏洞，并了解漏洞原因以及解决方案；

2、熟悉渗透测试流程，并有较强渗透测试和漏洞挖掘能力;

4、熟悉应急响应流程，可独立处理安全事件；

5、具有一定的开发能力，可以熟练使用Java/C/C++/Python/Perl/bash至少一种语言；

6、具有独立思考能力，主动发现问题解决问题。责任感强、有较强的逻辑思维能力、沟通能力和抗压能力；

加分项：

1、有丰富乙方团队项目实施经验，项目流程管理经验；

2、独立完成或者主导完成较大的渗透测试项目；

3、分析是一种大本事，凭直觉从千端万绪中直取重大观念更为不易

薪资：10k-15k

职位二【开发工程师】

岗位职责：

1.参与公司小型web项目的开发

2.负责官网与课程平台的设计与开发工作

3.负责公司相关产品的维护

任职资格：

1.使用 node.js 开发过具有一定复杂度的 web 项目

2.熟悉 http 规范，比如 http 包常见构成、常见字段的作用

3.有责任心，团队精神和良好的沟通能力;有较强的学习能力，对新技术和领域能快速掌握并实践;具有较强的逻辑思维能力，能够独立承担系统设计任务。

加分项：熟悉 Electron 开发、AWS 的使用、serverless 架构、 web 安全的攻防

薪资：8k-15k
