【IBM 多城市招聘】IBM招聘高级信息安全顾问（北京，上海，深圳，待遇优厚）

阅读量66147

|

发布时间 : 2017-03-10 17:21:24

简历接收邮箱：xukeju@cn.ibm.com （请注明来自安全客）

公司简介

IBM（国际商业机器公司）或万国商业机器公司，简称IBM（International Business Machines Corporation）。总公司在纽约州阿蒙克市。1911年托马斯·沃森创立于美国，是全球最大的信息技术和业务解决方案公司，拥有全球雇员 30多万人，业务遍及160多个国家和地区。

2016年6月8日，《2016年BrandZ全球最具价值品牌百强榜》公布，IBM 排第10名。10月，IBM排2016年全球100大最有价值品牌第6名。北京时间1月9日，IBM宣布，公司2016年在美国获得了8088项专利，连续24年高居榜首。

公司官网：https://www.ibm.com/cn-zh/


招聘岗位

高级信息安全顾问

岗位职责：

1. 为IBM大中华区各行业的客户设计并执行信息安全战略规划，建立信息安全管理体系，包括合规、网络安全及信息安全风险的评估项目；

2. 云安全战略规划,私有云、公有云及混合云的安全体系及数据安全合规规划等；

3. 数据安全策略及规划；

4. 安全运营中心规划(SOC)；

5. 数据中心安全规划；

6. 企业客户安全培训等。

任职要求：

1. 10年以上IT行业,金融行业,制造研发,电商,等中大型企业集团工作经验（包括作为乙方为此类行业实施咨询项目的经验）；

2. 5年以上信息安全相关工作经验及乙方信息安全管理咨询项目实施经验 ；

3. 深入了解中国信息安全法规政策, 精通ISO27001、Cobit、IT审计等相关标准和法规要求, 希望有ITIL/CMMI顾问经验者；

4. 熟悉中国信息安全等级保护要求及金融行业信息安全相关合规政策，隐私保护法等；

5. 熟悉云安全框架和传统IT安全架构, 有混合云安全咨询项目经验。希望有IoT(物联网)安全解决方案经验；

6. 本科及以上学历，希望有以下安全资格证书：CISSP, ISO27001, CCSP,CMMI/ITIL；

7. 热爱安全事业，优秀的沟通能力， 快速学习能力；

8. 出差比例>50%（大中华区 包括港澳台）中文流利，英文读写及基本沟通能力。

9. 优先考虑如下背景人选：惠普，绿盟，360，启明星辰，安永，埃森哲，德勤，华为。


高级信息安全顾问

岗位职责：

1. 为IBM大中华区客户制定并执行ERP(SAP为主也包含其他ERP系统）系统的信息安全策略和控制实施方案；

2. 了解ERP/SAP的系统弱点,漏洞和常见风险 了解ERP系统数据泄漏的路径,常见原因和防范方法；

3. 拥有ERP/SAP系统的网络安全风险及漏洞风险分析的经验；

4. 了解对ERP/SAP系统、核心网络、数据仓库、门户网站的常见攻击方式及影响范围 ；

5. 帮助IBM的客户提高SAP系统安全级别，建立持续监控，符合保密性、可用性、完整性及合规性要求的流程体系和技术手段

任职要求:

1. 5年以上ERP/SAP信息安全相关工作经验及乙方信息安全咨询项目实施经验；

2. 了解中国信息安全法规政策, ISO27001、Cobit、IT审计等相关标准和法规要求；

3. 热爱安全事业 优秀的沟通能力. 快速学习能力；

4. 本科及以上学历，希望有以下安全资格证书：CISSP, ISO27001；

5. 出差比例>50%（大中华区 包括港澳台）中文流利，英文读写及基本沟通能力。

6. 优先考虑如下背景人选：惠普，绿盟，360，启明星辰，安永，埃森哲，德勤，华为。

安全专员

岗位职责：

负责企业级 CRM 系统安全,主要涉足 UI 和 API 的安全验证,代理服务器安全以及企业级应用安全准则的检查及维护。

任职要求：

1. 3 年以上软件安全的工作经验。

2. 有 UI 安全验证和 API 安全验证方面的经验。

3. 熟练掌握 Linux, Unix 系统命令和 shell script

4. 精通 SAML, OIDC, OAuth, mutual authentication, SSL, 安全加密等任任意 3项

5. 了解 PHP 开发,SQL, Database

6. CET4 or CET6 or IELTS 5.5

7. 有应用版本控制管理系统的经验

入职地点：北京/上海/深圳/大连
