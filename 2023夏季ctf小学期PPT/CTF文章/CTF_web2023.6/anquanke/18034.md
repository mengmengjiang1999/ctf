公司简介

北京知道创宇信息技术有限公司（以下简称知道创宇）是国内最早提出网站安全云监测及云防御的高新企业，始终致力于为客户提供基于云技术支撑的下一代 Web 安全解决方案。
自创立以来，知道创宇业绩卓著，得到了各大互联网管理机构、多家世界五百强企业的高度认可。2009年公司被亚洲 CIO 杂志评选为20家最有价值企业，中国地区仅有知道创宇与阿里巴巴获此殊荣。知道创宇卓越的解决方案覆盖众多行业领域，拥有极高的客户忠诚度，这得益于精湛的技术、合理的总拥有成本、产品的易管理性以及优质的客户服务。

工作地点

北京、武汉、广州、合肥、甘肃、云南、厦门

职业详情

404 实习安全研究员 base:北京、武汉

岗位职责：

  * 国内外安全技术的跟进和重现，方向包括但不限于：二进制安全、web 安全；
  * 对业界目前的攻击和防御办法进行研究和跟踪，研究新的攻击和防御方法；
    撰写研究报告；
  * 为公司安全产品提供代码级技术原型支持，需要足够的编码能力；

任职要求：

  * 至少在一个领域有过漏洞挖掘经验者优先；
  * 有编程思维，能熟练使用 C/C++、python、java、golang 或其他脚本编程语言至少一种，有过独立的开发经验者优先；
  * 有 CTF 比赛经验者,独立发表过漏洞分析文章者或参与 IDS 建设，恶意流量分析，海量日志分析者优先;
  * 具有良好的沟通能力、协调能力、理解能力，并拥有强烈的责任心和团队管理能力，能承受一定强度的工作压力者优先；
  * 2019 届毕业生

渗透测试 /安全服务工程师实习生 base:全国

岗位职责：

  * 在指导下完成渗透测试、应急响应、网站加固；
  * 完成各种安全分析报告。
  * 按照公司要求，对重点单位提供重要时期安全保障支撑活动，包括渗透测试、远程监控、现场值守及应急响应等；
  * 对公安部、网信办等安全主管机构提供日常技术支撑，对突发安全事件进行快速应急；
  * 对政企事业部提供内部安全服务支持，包括重点客户预渗透、风险验证及服务项目售前交流等工作；

任职要求：

  * 计算机网络相关专业，毕业优先编制；
  * 熟悉常见的 web 安全漏洞，业务逻辑漏洞；
  * 理解渗透测试的步骤方法流程，熟练使用各种渗透工具；
  * 2019 届毕业生

安全分析师实习生 base：北京

岗位职责：

  * 负责安全监测类产品的技术支持工作；
  * 负责漏洞验证和基于流量检测产品的安全分析工作；
  * 负责为客户撰写安全分析报告；
  * 负责记录、反馈产品缺陷问题，协助产品经理完善公司产品。

任职要求：

  * 计算机或信息安全专业；
  * 对网络安全有浓厚的兴趣，具有良好的沟通能力、团队合作能力和高度责任心；
  * 了解常见的网络攻击手段及原理，Web 安全攻防方面最佳；
  * 了解渗透测试步骤流程，使用过渗透工具；
  * 有一定网络基础知识，了解网络应用层相关协议；
  * 2019 届毕业生

安全工程师实习生 （ base：广州、武汉、合肥、甘肃、云南、厦门）

岗位职责：

  * 负责产品和平台类相关实施安装、故障处理、定期巡检及操作培训等售后工作；
  * 配合安全顾问进行产品和平台类的相关测试和试用工作；
  * 负责网络安全事件的分析工作和应急处理工作。

任职要求：

  * 语言表达和思维逻辑清晰、乐观外向、书面表达能力强；
  * 良好的心理素质和学习能力，对安全技术有浓厚兴趣；
  * 熟悉网络，熟悉 Linux 和 Windows 操作系统；
  * 计算机网络相关专业，毕业优先编制；
  * 2019 届毕业生

安全研究工程师实习生 （ base: 北京）

岗位职责：

  * 负责 Zoomeye 系列产品网络空间雷达产品的漏洞检测插件（ POC ）开发维护和产品安全能力建设。
  * 负责产品的安全知识库应急更新和远程漏洞扫描相关技术研究，漏洞相关客户支持。
  * 围绕漏洞能力进行相关创新预研工作

任职要求：

  * 熟悉网络安全领域相关知识，熟悉系统漏洞 /WEB 漏洞的原理和相关知识背景；
  * 思维逻辑清晰，语言 /书面表达能力强，同时具备较强的学习能力；
  * 富有责任心，能在较大压力下完成工作；
  * 对安全漏洞有强烈的兴趣，了解漏洞形成的机理，远程检测原理；
  * 熟练使用 Python 语言；
  * 熟悉网络知识，各网络协议；
  * 2019 届毕业生
