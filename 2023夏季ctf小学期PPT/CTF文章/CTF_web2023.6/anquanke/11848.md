关于金山云

“金山云，创立于2012年，业务范围遍及全球100多个国家和地区。成立7年多来，金山云始终坚持以客户为中心的服务理念，提供安全、可靠、稳定、高品质的云计算服务。

当前，金山云已经构建了完备的云计算基础架构和运营体系，并通过与人工智能、大数据、物联网、区块链、边缘计算、AR/VR等优势技术的有机结合，提供适用于政务、金融、AIoT、医疗、工业、传媒、视频、游戏、教育、互联网、内容服务等行业的解决方案。

当前，金山云已经在北京、上海、广州、杭州、苏州、天津等国内地区，以及俄罗斯、新加坡、美国等国际区域设有绿色节能数据中心或运营机构。未来，金山云将持续开展国际化战略，通过构建一张覆盖全球的云计算网络，连通更多设备和人群，让云计算的价值惠及全球。”

工作地点

北京市海淀区金山软件大厦

在招岗位

岗位名称：安全合规工程师

岗位职责：

1. 跟进国家、业界云安全、数据安全等相关标准撰写

2. 为信息安全相关资质的申请提供合规支持

3. 提供合规咨询，做出合规分析与建议
4. 跟踪各项合规要求的落实情况，推动不符合项整改

任职要求：

1. 本科及以上学历；

2. 熟悉信息安全、数据安全、个人隐私保护等相关标准和流程等

3. 沟通能力强，推动能力强，富有团队协作精神，能承担较大工作压力

4. 具有互联网数据安全、个人隐私保护经验优先考虑

5. 参与过CSA STAR/ISO27018/可信云等认证工作优先

薪资范围：20k-40k

岗位名称：安全评估实习生

岗位职责：

1. 参与SDL项目安全评估工作

2. 参与应急响应处置和分析溯源工作

3. 参与漏洞工单跟进和处置工作

任职要求：

1. 熟悉web常见安全漏洞原理

2. 有良好的沟通能力

3. 在漏洞盒子、补天及各大SRC提交过高危漏洞的优先考虑

4. 实习期不少于3个月

岗位名称：安全运营实习生

岗位职责：

1. 参与推动信息安全制度的落地执行

2. 协助推动安全项目、跟进漏洞修复

3. 参与内部信息安全文化内容策划、宣导

任职要求：

1. 大三或研二在校生，信息安全专业优先

2. 有策划组织活动经验、有较好的文字功底优先

3. 责任心强，善于沟通，积极主动

4. 全职实习不少于3个月

公司福利

免费三餐、下午茶、健身房、五险一金、补充医疗、定期体检等
