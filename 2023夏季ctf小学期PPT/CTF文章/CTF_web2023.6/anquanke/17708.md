继微软推出物联网操作系统后，谷歌推出物联网平台Android Things

阅读量47483

发布时间 : 2018-05-10 16:04:53

译文仅供参考，具体内容表达以及含义原文为准。

不到一个月前，微软宣布推出专为物联网安全构建的操作系统，如今谷歌宣布推出物联网平台 Android Things。

谷歌推出的管理式操作系统旨在通过谷歌的基础设施为制造商提供物联网所需的一切：认证硬件、丰富的开发者 API 以及安全管理软件更新。

谷歌表示，该平台在这周前均处于开发者预览状态，而 SDK 的下载量已超过10万次。超过1万名开发者为 Android Things 平台提供了反馈意见，最终促成该平台的首次发布。

Android Things 1.0 支持基于 NXP i.MX8M、高通 SDA212、高通 SDA624 和 联发科 MT8516 硬件平台的新型模块上系统 (SoMs)。该平台继续支持 Raspberry Pi 3 Model B 和 NXP i.MX7D 设备（但不支持 NXP i.MX6UL）以服务于开发目的。

谷歌指出，“这些模块已通过生产使用认证，并得到三年的长期支持，这就使其更容易上市。这些 SoMs 的开发硬件和参考设备将在未来几个月内推出。”

然而，更重要的是，谷歌计划为运行 Android Things 平台的设备提供及时的空中传输 (OTA) 软件更新。在默认情况下所有设备将接收自动更新，而且稳定修复方案和安全补丁将会出现在生产硬件平台上。

目前，谷歌正在发布月度安全设备补丁，以便改进平台的整体安全状况。2015年出现的Stagefright 缺陷据称影响近10亿台设备，自此谷歌开始推出月度更新。

开发者如想要推出运行 Android Things 平台的商业产品，就需要和谷歌签订分发协议，从而向所有设备（目前平台控制台仅支持100台活跃设备）推出软件更新。

谷歌解释称，“对于每个长期支持版本，谷歌将提供为期三年的免费稳定修复方案和安全补丁，另外还提供延长支持服务。即使官方支持窗口期结束，你也可继续向设备推送 app 更新。”

Android Things 控制台还提供了配置硬件外围设备的可能性。

谷歌已经和领先制造商共同发布 Android Things 设备。因此LG 的 Smart Speakers，iHome，联想、LG 和 JBL 的 Smart Display 产品有望在今夏面世。

开发者如对构建运行 Android Thins 的产品感兴趣，可申请一个特别的限定计划和 Android Things 团队合作推出技术指导和支持内容。
