公司简介

北京安普诺，由北京大学白帽黑客团队“Xmirror”主导创立，专注于动态数据中心和云计算租户侧的高级定向攻击防护，核心业务主要包括悬镜云卫士、云鉴网站威胁扫描系统等自主创新产品及以实战攻防对抗为特色的政企安全服务，专注为媒体云、政务云、教育云等平台用户提供创新灵活的自适应安全智能管家解决方案。

投递邮箱

有意者请将简历发送至：zhangtao@anpro-tech.com

邮件主题按以下格式发送：姓名-应聘职位

工作地点

北京安普诺信息技术有限公司：北京市海淀区中关村软件园一期23号楼202室

招聘详情

职位：安全服务工程师

部门：悬镜安全实验室

招聘人数：2

岗位职责

 1. 参与安全服务项目实施，包括信息化系统渗透测试（外网/内网）、防黑加固及针对入侵事件的应急响应处理；
 2. 完成安全服务项目报告编写，为客户提供安全解决方案；

任职要求

 1. 熟悉OWASP TOP 10漏洞原因与修复方案；
 2. 熟悉安全测试工具使用，可独立完成Web或APP安全测试；
 3. 熟悉Linux操作系统，熟悉掌握一种或多种编程语言；
 4. 具有良好的学习能力和团队合作精神；

加分项

 1. 有源代码审计经验或逆向分析经验；
 2. 处理过木马、病毒、入侵、网络攻击等突发安全事件经验；
 3. 参与过国内外厂商的漏洞奖励计划；
 4. CISP或其它信息安全认证；

职位：安全开发工程师

部门：悬镜安全实验室

招聘人数：2

安全知识及技术要求

 1. 熟悉常见漏洞原理、利用及防护方法（参考OWASP TOP 10）；
 2. 熟悉Linux操作系统的各项操作及相关运行原理；
 3. 熟悉常见漏洞POC的编写；
 4. 加分项：熟悉应急响应、熟悉系统加固。

开发知识及技术要求

 1. 熟练使用python、shell语言进行编程；
 2. 有过实际项目开发经验；

加分项

 1. 熟悉C语言编程。

其它要求

 1. 具有良好的学习能力与团队合作精神；
 2. 良好的抗压能力；

岗位职责

 1. 各类POC的编写；
 2. 与漏扫相关的各类子模块的开发及优化（爬虫、通用漏洞检测脚本等）；
 3. 安全事件的分析；
 4. 应急响应及系统加固。

职位：安全运维工程师

部门：技术服务部

招聘人数：2

岗位职责

 1. 参与公司核心产品在用户使用过程中的异常数据跟踪分析、企业网站服务器安全运维和对外安全服务的技术支撑等；
 2. 参与大客户的电话对接，完成相关工作，为客户提供完善的安全产品技术支持服务；
 3. 参与服务客户技术支持，包括高防和WAF等公有云产品（DDoS和CC攻击）的应急响应处理；
 4. 参与公司项目的安全加固、安全应急响应等相关工作；

任职要求

 1. 计算机相关专业，本科及以上学历，1-3年互联网公司安全运维工程师工作经验以上；
 2. 熟悉网络的各种测试命令，可独立排查解决客户网络问题；
 3. 有防护加固生产系统，应急响应等相关安全运维工作经验；
 4. 善于解决处理各种网络安全问题，思维逻辑敏捷；
 5. 熟悉Linux、Windows操作系统，熟悉各种web等各种常见服务；
 6. 熟悉掌握shell,python,java,C和C++等一种或多种编程语言；
 7. 具有良好的学习能力，沟通表达能力和团队合作精神；

加分项

 1. 熟悉主流公有云的主要产品（ECS，RDS,CDN）等；
 2. 熟悉DDoS攻击和CC攻击的原理和防护等；
 3. 通过公有云厂商个人能力相关认证、CISP或其它信息安全认证优先；

职位：品牌文案策划工程师

部门：品牌运营部

岗位职责

 1. 负责品牌规划及公司宣传内容、广告、软文、海报、产品业务等相关文案编辑，通过前 瞻性观点输出、案例推广、产品包装、视频包装等不同的文案形式，提升公司品牌形象；
 2. 跟踪、洞察行业的最新趋势及竞争对手的资讯，对页面内容进行及时更新和维护；
 3. 从品牌推广和市场营销角度理解公司核心产品线，完成“用户使用手册”、“技术白皮 书”、“行业解决方案”、“产品演示胶卷”等宣传材料的撰写；
 4. 按照项目或产品规划制定文档计划，完成项目投标文件、企业资质认证文件、专利申请 文件等文档的撰写工作；
 5. 持续改进、提升公司面向客户、开发者的文档质量和创新性，提高可用性和易用性，提 升用户和客户体验 ；

任职要求

 1. 本科及以上学历，计算机、新闻传媒、市场营销及相关专业；
 2. 熟悉信息安全行业，掌握基础信息安全知识，有较强的快速学习能力，具备信息安全行 业科技文档撰写能力；
 3. 较强文字驾驭能力和文案功底，能够使用清晰、明确、易理解的语言进行文档编写；具 备良好的写作、编辑、审校能力；
 4. 较强的沟通能力和执行能力，工作态度积极，责任心强，良好的团队合作精神 ；

职位名称：产品经理

招聘人数：1

部门：产品设计部

岗位职责

 1. 负责云安全相关产品的需求整理，版本管理等工作；
 2. 负责产品的业务模式设计和功能设计；
 3. 跟踪并定期收集用户反馈，持续改进产品；
 4. 负责产品开发过程中的协调、进度质量跟踪和管理；
 5. 编写产品使用手册等相关文档；
 6. 负责用户的技术交流，产品介绍和方案宣讲；
 7. 行业安全解决方案规划、设计、编写；负责对用户及销售的培训工作；

任职要求

 1. 本科及以上学历，计算机相关专业，1年以上产品工作经验；
 2. 能独立承担功能模块的需求制定；
 3. 熟悉主流信息安全产品（如防火墙、IPS、威胁情报）优先考虑；
 4. 有信息安全相关工作经验者优先。

职业素质

 1. 有较强的自我学习能力，工作踏实认真；
 2. 具备良好的主动意识和抗压能力；
 3. 良好的沟通与表达能力、思路清晰，较强的动手能力与逻辑分析能力；
 4. 良好的团队合作和积极主动的沟通意识。

职位名称：WEB后端研发工程师

招聘人数：2

工作地点：北京

部门：研发一部

岗位职责

 1. 根据总体设计完成模块设计；
 2. 完成模块代码编写、单元测试、代码维护等工作；
 3. 编写技术文档，并对有关人员进行培训。

任职要求

 1. 大专及以上学历，计算机相关专业；
 2. 熟练使用Linux操作系统；
 3. 熟悉nginx、apache、tomcat等web环境搭建；
 4. 精通PHP、JAVA、Python等一种以上后端开发语言；
 5. 熟练使用Mysql、MongoDB等一种以上数据库读写操作；
 6. 熟悉kafka，hive，hbase、elasticsearch等大数据平台及应用开发
 7. 熟练使用NetBean、HBuilder等工具进行开发和调试；
 8. 有高并发情况下的系统开发经验优先

职业素质

 1. 有较强的学习能力，良好的沟通能力，工作踏实认真；
 2. 良好的沟通与表达能力、思路清晰，较强的动手能力与逻辑分析能力；
 3. 良好的团队合作和积极主动的沟通意识。

招聘人数：2

岗位职责

 3. 参与主机防护规则的开发与维护；
 4. 解决产品测试和使用中出现的问题；

任职要求

 1. 编程基础扎实，2年以上linux C开发经验；
 2. 熟悉TCP/IP网络协议，精通Socket编程，熟悉Linux环境下编程特性。

 1. 有较强的学习能力，良好的沟通能力，工作踏实认真；
 2. 良好的团队合作和积极主动的沟通意识。
 3. 对信息安全领域有浓厚的兴趣。
