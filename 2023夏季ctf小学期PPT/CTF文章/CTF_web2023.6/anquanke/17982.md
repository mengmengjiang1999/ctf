Cloudflare 宣布推出更隐秘更快的 DNS 解析服务 1.1.1.1

4月1日，免费 DNS 解析服务 1.1.1.1 面世，它不仅让互联网地址的查询更加快速也更加隐秘。该服务由拥有 1.1.1.1 地址的 APNIC 和 使用该网络托管 DNS 服务的 Cloudflare 公司创建。

他们创建该服务的原因是认为现有的 DNS 解析服务速度太慢，而且很多这类服务记录用户查询甚至将数据卖给第三方服务。鉴于此，他们联合创建了新服务 1.1.1.1，它不仅围绕隐私而生，而且在 Cloudflare 的分布式网络上运行的非常快。

承诺保护用户隐私

Cloudflare 和 APNIC 认为现有 DNS 服务的一个主要问题在于，有些服务记录用户 IP 地址以及相关的 DNS 查询，这样它们就能追踪用户所访问的每个站点。更糟糕的是，其中某些服务还可能将用户数据卖给第三方，供后者用于精准广告中。

该服务1.1.1.1承诺将永远不会将用户的 IP 地址写于磁盘并在24小时内擦除所有的交易日志。

Cloudflare 指出，“我们和浏览器厂商谈论它们想从 DNS 解析器中获得什么。他们一直都在提到的一个关键词是‘隐私’。除了承诺不会将浏览数据用于精准广告外，他们还想确保我们会在一周内擦除所有的交易日志。这是一个很容易实现的请求。事实上，我们知道我们会做得更好。我们承诺永远不会将查询 IP 地址写入磁盘并承诺在24小时内擦除所有的日志。”

他们还表示已经聘请毕马威会计事务所审计代码和实践，以便确保他们实现诺言。

通过使用 Cloudflare 的网络加速 DNS 解析

不管何时连接到主机名，用户的计算机必须首先查询 DNS 解析服务以便判断这台计算机所连接的 IP 地址。如果 DNS 查询耗时太长，那么联网速度也会变慢。

凭借使用 Cloudflare 的网络和现有的 DNS 基础设施，1.1.1.1 声称 DNSPerf 指出，它的联网速度要比其它 DNS 服务快28%。

易于使用的 1.1.1.1

好消息是，1.1.1.1是一款免费的 DNS 解析服务，而且很容易设置在用户自己的移动设备、计算机或路由器上。如果用户了解如何配置静态的 DNS 服务器，用户可将设备配置为使用 1.1.1.1 作为 DNS 服务器。

更好的消息是，如果用户将家庭路由器设置为使用 1.1.1.1 作为 DNS 服务器，连接到该服务器上并通过 DHCP 接收 IP 地址的计算机将自动使用该服务器。

如果需要更改设备上的 DNS 服务器，1.1.1.1 站点上详细说明了 iPhone、安卓、macOS、Windows、Linux 和路由器的更改方法。
