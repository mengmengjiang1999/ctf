招聘岗位

1.信息安全工程师（渗透方向）（1-2年）
2.售前工程师

岗位具体信息如下：

一、信息安全工程师（渗透方向）（1-2年工作经验）

[ 职位信息 ]
1.参与公司的渗透测试、威胁响应、攻击溯源等常规安全服务业务
2.撰写渗透测试报告以及相关服务测试文档
3.参与编写辅助渗透测试工具
[ 职位要求 ]
1.本科以上，1-2年渗透工作经验；
2.熟悉 Windows/Unix 操作系统 ；
3.熟悉 HTTP 协议，常见数据库及 IIS、Apache、Tomcat 等中间件的使用，了解 SQL语句；
4.熟悉渗透测试的步骤、方法、流程，熟练掌握各种渗透测试工具 ；
5.熟练掌握 C、python、 java 等编程语言至少一种 ；
6.良好的团队合作精神和较强的沟通能力 ；
7.对网络攻防技术具有浓厚的兴趣爱好 。
[加分项]
1.有 CTF 比赛或其他有参赛经验者优先
2.有漏洞挖掘经验者优先
3.有 CVE 编号者优先
4.有相关实战经历者优先
5.能够独自分析及编写相关 exp 优先

二、售前工程师

[ 岗位职责 ]
1.配合销售人员与客户充分沟通，进行项目前期的需求分析、可行性分析；
2.通过前期售前沟通，根据项目要求理解和引导客户需求，并负责项目建议书及解决方案的撰写；
3.配合销售人员进行项目招投标工作，负责编写项目技术标书，技术方案和相关技术文档等；
4.结合项目需求，编织项目汇报所需的PPT文档、产品和服务资料以及进行技术方案报告的演示、汇报和讲解；
5.负责公司信息安全整体解决方案的设计与撰写，负责公司服务、产品文案宣传资料的撰写；
6.完成领导交办的其他任务。
[ 岗位要求 ]
1.计算机、信息安全等相关专业，本科以上学历，三年以上相关行业工作经验；
2.熟悉信息安全领域相关知识，熟悉各类安全产品；
3.责任心强，有良好的敬业精神，合作态度和团队精神，能适应高强度的工作；
4.具备良好的沟通表达能力，能与客户在业务和技术等方面进行良好的沟通交流；
5.有扎实的文字功底，较好的分析和归纳能力，善于编写各类分析研究报告、咨询方案和项目建设方案；
6.熟悉常见的web漏洞的原理、测试方法以及解决措施，具有分析研究安全漏洞的能力者优先。
