团队介绍

360 核心安全高级威胁自动化团队（混天零实验室）成立于2015年，负责高级威胁自动化检测项目，专注于通过自动化监测手段高效发现高级威胁攻击；依托于 360 安全大数据，多次发现和监测到在野漏洞利用、高级威胁攻击、大规模网络挂马等危害网络安全的攻击事件，多次率先捕获在野利用 0day 漏洞的网络攻击并获得厂商致谢，在野 0day 漏洞的发现能力处于国内外领先地位，并在国际知名会议发表相关演讲，为上亿用户上网安全提供安全能力保障。

在团队中工作，不但能够接触研究各种利用和对抗技术的实时海量威胁样本任务，研究最前沿的漏洞利用和攻防对抗技术，探索创新的漏洞检测和防御机制方案；还可以依托海量数据，设计和构建高效的自动化响应解决方案，为高级威胁判定和关联分析提供强有力支持；还可以探索研究 AI 和机器学习相关技术，探索人工智能在高级威胁判定方面的最新应用和进展，为安全技术的未来提供更多可能性；工作自由度高，具有挑战性，发展前景广阔，新人能够获得迅速成长的机会。

招聘详情

Windows 安全开发工程师

岗位职责

 1. 负责高级威胁自动化检测项目的检测模块设计、开发和改进优化。
 2. 负责研究新的威胁检测技术，增强和提升恶意代码行为检测能力。
 3. 负责分析恶意程序的功能及攻防手段，研究相关防御机制和缓解措施，并在项目中实现应对方案。
 4. 安全事件响应相关任务，为上亿用户上网安全提供安全能力保障。

任职要求

 1. 本科及以上计算机相关专业毕业，专业基础扎实，能熟练使用 C/C++ 编程语言，熟悉汇编语言，具备良好的代码风格。
 2. 熟悉 Win32 应用程序开发或 Windows 内核驱动程序开发。
 3. 熟悉 Windows 操作系统各模块 API，用户层和内核层原理，PE 文件格式和进程加载、运行机制，了解内核对象、注册表、文件系统、分页机制等原理。
 4. 熟悉 Windows 平台的各种 Hook 技术和注入技术。
 5. 熟练使用 IDA、WinDBG 等逆向分析和调试工具，具备良好的问题定位追踪能力。
 6. 对网络攻防和操作系统有浓厚兴趣，具备良好的团队合作精神以及高度的责任心，具有钻研精神和解决问题的能力。
 7. 具有漏洞挖掘或漏洞分析经验，了解各种系统防御机制的绕过技术，了解病毒木马、漏洞利用程序常用的技术手段和对抗方法的优先考虑。
 8. 参与过相关项目开发的、或发布过自主完成的优秀开源项目的、或发表过相关技术文章的优先考虑。

Windows 漏洞分析工程师

岗位职责

 1. 负责安全技术研究，追踪国内外最新的操作系统及常用软件漏洞。
 2. 负责分析最新漏洞利用样本文件，研究漏洞成因和完整利用路径。
 3. 负责研究和实现最新漏洞的利用程序，并为项目输出相关防御机制和缓解措施，在项目中实现应对方案。
 4. 安全事件响应相关任务，为上亿用户上网安全提供安全能力保障。

任职要求

 1. 本科及以上计算机相关专业毕业，专业基础扎实，熟悉汇编语言，了解数据结构和编译原理。
 2. 熟悉 PE 文件格式，或常见的非 PE 文件格式（包括但不限于：PDF，Flash，Office，VBScript），满足其一即可。
 3. 熟悉 Windows 内核漏洞，或常用应用程序（如 Microsoft Office，Adobe Reader 等）漏洞，满足其一即可。
 4. 熟练掌握软件逆向静态分析、动态调试、代码跟踪，熟练掌握 IDA、WinDBG、OllyDBG 等分析和调试工具，具备良好的问题定位追踪能力。
 5. 了解各种系统防御机制的绕过技术，了解病毒木马、漏洞利用程序常用的技术手段和对抗方法。
 6. 对网络攻防和操作系统有浓厚兴趣，具备良好的团队合作精神以及高度的责任心，具有钻研精神和解决问题的能力。
 7. 研究过自动化漏洞挖掘工具的、或发表过相关漏洞分析文章的优先考虑。

安全算法工程师

岗位职责

 1. 基于大数据和机器学习算法，提升对恶意软件与攻击行为的自动化发现与处理能力。
 2. 针对恶意软件行为数据进行清洗与特征提取等工作。
 3. 分析恶意软件行为模式，构建恶意行为模型，对软件行为进行分类。
 4. 对安全攻击事件进行建模和数据关联，并构建自动化响应解决方案。
 5. 对相关成果进行可视化展示。

任职要求

 1. 编程基础扎实，熟悉算法数据结构，熟悉 C++/Python 等语言。
 2. 熟练掌握分类、聚类、关联规则等常见数据挖掘算法。
 3. 熟练使用 Spark/Hive/Hadoop 等大数据框架工具，至少熟悉一个深度学习框架。
 4. 对机器学习深度学习有浓厚的兴趣，自主学习能力强。
 5. 有安全相关从业经历者优先。

大数据开发工程师

岗位职责

 1. 构建基于开源组件的离线/在线分析存储系统。
 2. 设计并构建安全大数据分析体系。
 3. 负责服务端创新探索，优化代码逻辑，提高其易维护性、稳定性、可用性、吞吐量和效率等。

任职要求

 1. 编程基础扎实，熟悉 Java、Python、Go 等语言，熟练掌握 Linux 操作系统；
 2. 掌握 HDFS、MapReduces、Flink、Spark、HBase、ElasticSearch 等开源大数据技术，并能结合不同的业务场景深入使用；
 3. 对大数据治理有比较系统的实践，有分布式计算或海量数据应用经验；
 4. 拥有良好的编码习惯, 喜欢创新挑战, 自我驱动能力强, 具备良好的沟通能力和团队协作精神。

Python 后端开发工程师

岗位职责

 1. 负责自动化检测产品相关模块开发. 维护和改进工作。
 2. 设计技术方案和系统架构，重构已有不完善的系统。
 3. 编写系统核心代码，解决开发中的疑难问题。
 4. 承担重要系统模块的维护工作，保证系统服务的稳定可靠。
 5. 能为团队引入创新的技术. 创新的解决方案，用创新的思路解决问题。

任职要求

 1. 熟练掌握 Python 及相关开发框架。
 2. 熟练掌握 Linux 基础操作，可以很好的完成在 Linux 上进行开发、调试、部署等工作。
 3. 熟悉常用的存储技术，如 MySQL/PostgreSQL/MongoDB。
 4. 熟悉常用的消息中间件，如 RabbitMQ/ZeroMQ/Kafka。
 5. 熟悉常用的缓存组件，如 Memcached/Redis/Pika。
 6. 熟悉常用的搜索组件，如 Solr/Elasticsearch。
 7. 能根据业务需求设计性能良好. 扩展性高. 稳定可靠的系统组件。
 8. 熟悉服务部署及优化，理解负载均衡和系统调优。
 9. 具备优良的团队合作和沟通协作能力，善于学习，乐于分享。
10. 有安全行业从业经历者优先，有分布式系统开发经验者优先。

Web 前端开发工程师

岗位职责

 1. 负责项目 web 前端相关需求的设计与实现。
 2. 推进项目数据平台的可视化展现与使用。
 3. 对项目的用户体验进行持续性的优化与改善。

任职要求

 1. 网络、操作系统等计算机相关基础知识扎实。
 2. 熟练掌握 HTML/CSS/JS 等前端相关知识。
 3. 了解前端自动化和工程化。
 4. 熟悉并使用过Vue或其他类似框架，有相关项目经验。
 5. 对互联网产品有良好的感觉，对交互体验有较为深入的了解，对数据可视化有独到的认知。
 6. 对技术有强烈的进取心，具有良好的沟通能力和团队合作精神、优秀的分析问题和解决问题的能力。
 7. 熟悉 Python/Go 等任一后端编程语言者优先。
 8. 有优秀开源项目经验的优先。

虚拟化开发工程师

职责描述

 1. 负责自动化检测产品中虚拟化相关模块开发、维护和改进工作；
 2. 设计技术方案和系统架构，重构已有不完善的系统；
 3. 编写系统核心代码，解决开发中的疑难问题；
 4. 能为团队引入创新的技术、创新的解决方案，用创新的思路解决问题。

任职要求

 1. 熟练掌握 Python、C/C++ 等编程语言，熟悉相关开发框架；
 2. 熟练掌握 Linux 基础操作，可以很好的完成在 Linux 上进行开发、调试、部署等工作；
 3. 熟悉 Xen/KVM/Docker 等主流虚拟化技术，有 Xen/KVM/Docker 的开发或应用经历；
 4. 有 OpenStack/Mesos/Kubernetes 等开源或自研的大规模集群系统设计、开发或运营经历；
 5. 能根据业务需求设计性能良好、扩展性高、稳定可靠的系统组件；
 6. 具备优良的团队合作和沟通协作能力，善于学习，乐于分享；
 7. 有安全行业从业经历者优先。

其他说明

 1. 薪资视能力水平而定，具体面议。
 2. 本科及以上计算机相关专业毕业；工作能力强的，可不限制学历。
 3. 两年以上工作经验，优秀的应届生或实习生亦可。
