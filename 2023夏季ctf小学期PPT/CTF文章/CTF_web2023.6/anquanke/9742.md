公司简介

上海端御信息科技有限公司（简称端御科技或RTShield） 是一家有着红队基因的信息安全企业。公司核心团队具有十年以上的国家级APT对抗经验，曾为多个行业的头部客户提供定制化的红队演练服务及应对突发安全事件的威胁响应服务，得到客户的高度认可。公司结合多年的攻防经验与大数据分析技术自主研发了针对APT攻击的威胁猎杀系统，可为不同行业的客户提供针对APT攻击的“检测、追踪、聚合、驱离”一体化纵深防御体系，是客户现有防御体系的最佳补充。

“极矛之端，铸盾之御” ，端御科技以差异化优势不断获得市场关注和认可，正积极拓展更广阔的应用场景，深入践行“最先的威胁预警、最快的威胁响应、最低的安全损失”的客户承诺。

简历投递方式：join@rtshield.com（请注明信息来源于安全客）

招聘详情

Go开发工程师

岗位要求

 1. 1年以上Linux下go开发经验；
 2. 熟悉go并发控制和应用场景；
 3. 了解go的缓存、垃圾回收机制；
 4. 常见通信技术及原理：tcp/udp,http,grpc等通信协议；
 5. 使用gin、beego、iris等至少一种go web框架，且拥有实际项目使用经验；
 6. 熟悉git flow开发工作流程；
 7. 熟悉MySQL、mongodb、postgresql等至少一种关系型数据库，且有相应的go-orm使用经验；
 8. 熟练使用Redis、Memcache等至少一种缓存数据库；
 9. 了解docker容器化技术；
10. 熟练使用kafka、rabbitmq、nsq等至少一种消息队列的原理和操作。

加分项

 1. 对网络安全有浓厚兴趣；
 2. 有ELK等工具部署、配置及二次开发经验；
 3. 有Prometheus、Grafana二次开发经验；
 4. 有k8s相关开发经验；
 5. 有Go自动化爬虫开发经验。

安全研究员

岗位要求

 1. 熟悉 C/C++或 Golang 编程并有良好的编程习惯；
 2. 有windows开发项目经验；
 3. 有安全相关行业经验；
 4. 具备一定的外语能力，能够无障碍查阅外语资料；
 5. 具备钻研精神，愿意在安全领域做出技术突破；
 6. 具有团队合作精神，乐于接受挑战，勤奋踏实，抗压能力强。

岗位职能

 1. 着重解决包括但不限于开发方向上的技术难点。

信息安全工程师（实习）

岗位要求

 1. 熟悉 Windows/Unix 操作系统 ；
 2. 熟悉 HTTP 协议，常见数据库及 IIS、Apache、Tomcat 等中间件的使用，了解 SQL 语句 ；
 3. 熟悉渗透测试的步骤、方法、流程，熟练掌握各种渗透测试工具 ；
 4. 熟练掌握 C、python、 java 等编程语言至少一种 ；
 5. 良好的团队合作精神和较强的沟通能力；
 6. 对网络攻防技术具有浓厚的兴趣爱好 。

加分项

 1. 有 CTF 比赛或其他有参赛经验者优先；
 2. 有漏洞挖掘经验者优先；
 3. 有 CVE 编号者优先；
 4. 有相关实战经历者优先；
 5. 能够独自分析及编写相关 exp 优先。
