公司简介

蚂蚁金服（全称：蚂蚁金融服务集团），成立于2014年10月16日，蚂蚁金服旗下拥有支付宝、蚂蚁财富、网商银行、芝麻信用等品牌。

投递邮箱

安全应急响应专家：luting.xiaolt@alibaba-inc.com（请注明来自安全客）

研发岗位、安全运营、解决方案工程师：hongshan.ltt@antfin.com（请注明来自安全客）

工作地点

北京、杭州

岗位详情

安全应急响应专家

工作地点：杭州工作经验：三年以上岗位职责：
 1. 负责蚂蚁金服生态圈的应急响应体系，制定对内、对外的漏洞响应标准，并监督执行。
 2. 负责蚂蚁金服安全产品和生态合作运营，服务蚂蚁金服商户安全。

任职要求：

 1. 需要对运营有深刻的理解，对人性有充分的体察
 2. 超强的责任心和沟通能力
 3. 具备良好商业敏感性，具备产品创新意识
 4. 能够整合资源，具备跨团队协作能力
 5. 学习能力强，愿意接受挑战，有很强的抗压性

研发岗位

工作地点：北京岗位职责：负责公司安全产品的设计与研发，提供稳定、可靠、易用的安全解决方案，包括但不限于防护、监控、扫描、数据分析、风险控制、审计等产品。任职要求：1. 有扎实的开发功底，熟悉C/C++，Java，Python，Golang至少一种开发语言，具备系统调优经验者优先；
2. 有良好的系统及架构设计能力，熟悉高并发应用开发者优先；
3. 有强烈的求知欲和良好的学习能力，熟悉业动向，及时跟进新技术；
4. 具备以下条件者优先录用：
1）有安全产品设计及研发相关工作经验者；
2）有大数据分析、机器学习经验者。

安全运营

工作地点：北京&杭州岗位职责：1. 负责日常安全事件的发现、分析、应急响应；2. 负责日常漏洞分析、渗透分析和入侵检测，及时发现安全隐患并采取有效的防护措施。任职要求：1. 3年以上的安全从业经验，能适应运营和运维工作；
2. 熟悉漏洞分析、渗透测试的方法，能熟练使用各类安全检测工具；
3. 具备网络攻防及应急相应的经验，具备较强的分析能力；
4. 有强烈的责任心和学习意愿，能够随时跟进最新的行业动态；自律能力强；
5. 有互联网公司安全工作经验者优先。

解决方案工程师

工作地点：北京&杭州 岗位职责：1. 作为安全专家，对合作伙伴进行全面的安全评估，为他们量身定做解决方案，并推动方案的落地实施；2. 收集用户需求，将解决方案以产品化的形式提供给用户。任职要求：1. 有很强的安全背景及相关工作经验，5年以上的工作经历；
2. 精通网络攻防技术，对DDoS、CC、Web攻防、系统攻防的原理及防御方法有较深入的理解；
3. 有一定的架构设计能力，熟悉云计算、网络架构的知识体系；
4. 善于沟通表达，思维缜密，有敏锐的洞察力；
5. 有安全产品相关经验，或者英语能力较强者优先。
